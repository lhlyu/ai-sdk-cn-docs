### 什么是 RAG？

RAG 代表检索增强生成。简单来说，RAG 是向大型语言模型（LLM）提供与提示词相关的特定信息的过程。

### 为什么 RAG 很重要？

虽然 LLM 功能强大，但它们能够推理的信息仅限于训练数据。当向 LLM 询问训练数据之外的信息时，这个问题就变得很明显，比如专有数据或模型训练截止日期之后发生的常识。RAG 通过获取与提示词相关的信息并将其作为上下文传递给模型来解决这个问题。

用一个基本示例来说明，想象一下询问模型您最喜欢的食物：

```txt
**输入**
我最喜欢的食物是什么？

**生成**
我无法访问个人的私人信息，包括他们最喜欢的食物。
```

毫不奇怪，模型不知道。但想象一下，除了您的提示词之外，模型还收到了一些额外的上下文：

```txt
**输入**
仅使用提供的上下文回应用户的提示词。
用户提示词：'我最喜欢的食物是什么？'
上下文：用户喜欢吃鸡块

**生成**
您最喜欢的食物是鸡块！
```

就这样，您通过向查询提供相关信息，增强了模型的生成能力。假设模型拥有适当的信息，它现在极有可能对用户的查询返回准确的响应。但它如何检索相关信息呢？答案依赖于一种称为嵌入的概念。

<Note>
  您可以为 RAG 应用获取任何上下文（例如 Google 搜索）。
  嵌入和向量数据库只是实现语义搜索的一种特定检索方法。
</Note>

### 嵌入

[嵌入](/docs/ai-sdk-core/embeddings) 是一种将单词、短语或图像表示为高维空间中向量的方法。在这个空间中，相似的单词彼此靠近，单词之间的距离可以用来衡量它们的相似性。

实际上，这意味着如果您嵌入 `cat` 和 `dog` 这两个词，您会期望它们在向量空间中被绘制在彼此附近。计算两个向量之间相似度的过程称为“余弦相似度”，值为 1 表示高度相似，值为 -1 表示高度对立。

<Note>
  如果这看起来很复杂，不用担心。只需高层次的理解就可以开始了！
  有关嵌入的更深入介绍，请查看
  [本指南](https://jalammar.github.io/illustrated-word2vec/)。
</Note>

如上所述，嵌入是一种表示**单词和短语**语义含义的方式。这意味着嵌入的输入越大，嵌入的质量就越低。那么，您如何处理比简单短语更长的内容的嵌入呢？

### 分块

分块是指将特定源材料分解成更小片段的过程。有许多不同的分块方法，值得尝试，因为最有效的方法可能因用例而异。一种简单且常见的分块方法（也是您将在本指南中使用的方法）是按句子分隔书面内容。

一旦您的源材料被适当地分块，您就可以嵌入每个块，然后将嵌入和块一起存储在数据库中。嵌入可以存储在任何支持向量的数据库中。在本教程中，您将使用 [Postgres](https://www.postgresql.org/) 以及 [pgvector](https://github.com/pgvector/pgvector) 插件。

### 创建嵌入表

目前，您的应用程序有一个表（`resources`），其中有一个列（`content`）用于存储内容。请记住，每个 `resource`（源材料）都必须被分块、嵌入，然后存储。让我们创建一个名为 `embeddings` 的表来存储这些块。

创建一个新文件（`lib/db/schema/embeddings.ts`）并添加以下代码：

```tsx filename="lib/db/schema/embeddings.ts"
import { nanoid } from '@/lib/utils';
import { index, pgTable, text, varchar, vector } from 'drizzle-orm/pg-core';
import { resources } from './resources';

export const embeddings = pgTable(
  'embeddings',
  {
    id: varchar('id', { length: 191 })
      .primaryKey()
      .$defaultFn(() => nanoid()),
    resourceId: varchar('resource_id', { length: 191 }).references(
      () => resources.id,
      { onDelete: 'cascade' },
    ),
    content: text('content').notNull(),
    embedding: vector('embedding', { dimensions: 1536 }).notNull(),
  },
  table => ({
    embeddingIndex: index('embeddingIndex').using(
      'hnsw',
      table.embedding.op('vector_cosine_ops'),
    ),
  }),
);
```

该表有四列：

- `id` - 唯一标识符
- `resourceId` - 与完整源材料的外键关系
- `content` - 纯文本块
- `embedding` - 纯文本块的向量表示

为了执行相似性搜索，您还需要在此列上包含一个索引（[HNSW](https://github.com/pgvector/pgvector?tab=readme-ov-file#hnsw) 或 [IVFFlat](https://github.com/pgvector/pgvector?tab=readme-ov-file#ivfflat)）以获得更好的性能。

要将此更改推送到数据库，请运行以下命令：

<Snippet text="pnpm db:push" />

### 生成块

请记住，要创建嵌入，您将从一段源材料（长度未知）开始，将其分解为更小的块，嵌入每个块，然后将块保存到数据库中。让我们首先创建一个函数来将源材料分解为小块。

```tsx filename="lib/ai/embedding.ts"
const generateChunks = (input: string): string[] => {
  return input
    .trim()
    .split('.')
    .filter(i => i !== '');
};
```

此函数将接受一个输入字符串，并按句点分割，过滤掉任何空项。这将返回一个字符串数组。值得在您的项目中尝试不同的分块技术，因为最佳技术会有所不同。

### 生成嵌入

让我们添加一个生成嵌入的函数。将以下代码复制到您的 `lib/ai/embedding.ts` 文件中。

```tsx filename="lib/ai/embedding.ts" highlight="1,3,12-21"
import { embedMany } from 'ai';

const embeddingModel = 'openai/text-embedding-ada-002';

const generateChunks = (input: string): string[] => {
  return input
    .trim()
    .split('.')
    .filter(i => i !== '');
};

export const generateEmbeddings = async (
  value: string,
): Promise<Array<{ embedding: number[]; content: string }>> => {
  const chunks = generateChunks(value);
  const { embeddings } = await embedMany({
    model: embeddingModel,
    values: chunks,
  });
  return embeddings.map((e, i) => ({ content: chunks[i], embedding: e }));
};
```

在这段代码中，您首先定义要用于嵌入的模型。在此示例中，您使用的是 OpenAI 的 `text-embedding-ada-002` 嵌入模型。

接下来，您创建一个名为 `generateEmbeddings` 的异步函数。此函数将源材料（`value`）作为输入，并返回一个对象数组的 Promise，每个对象包含一个嵌入和内容。在函数内部，您首先为输入生成块。然后，您将这些块传递给从 AI SDK 导入的 [`embedMany`](/docs/reference/ai-sdk-core/embed-many) 函数，该函数将返回您传入的块的嵌入。最后，您以准备保存到数据库的格式映射并返回嵌入。

### 更新服务器操作

打开 `lib/actions/resources.ts` 文件。此文件有一个函数 `createResource`，顾名思义，它允许您创建资源。

```tsx filename="lib/actions/resources.ts"
'use server';

import {
  NewResourceParams,
  insertResourceSchema,
  resources,
} from '@/lib/db/schema/resources';
import { db } from '../db';

export const createResource = async (input: NewResourceParams) => {
  try {
    const { content } = insertResourceSchema.parse(input);

    const [resource] = await db
      .insert(resources)
      .values({ content })
      .returning();

    return 'Resource successfully created.';
  } catch (e) {
    if (e instanceof Error)
      return e.message.length > 0 ? e.message : 'Error, please try again.';
  }
};
```

此函数是一个 [服务器操作](https://nextjs.org/docs/app/building-your-application/data-fetching/server-actions-and-mutations#with-client-components)，由文件顶部的 `“use server”;` 指令表示。这意味着它可以在您的 Next.js 应用程序中的任何地方调用。此函数将接受输入，通过 [Zod](https://zod.dev) 模式运行以确保其符合正确的模式，然后在数据库中创建新资源。这是生成和存储新创建资源的嵌入的理想位置。

使用以下代码更新文件：

```tsx filename="lib/actions/resources.ts" highlight="9-10,21-27,29"
'use server';

import {
  NewResourceParams,
  insertResourceSchema,
  resources,
} from '@/lib/db/schema/resources';
import { db } from '../db';
import { generateEmbeddings } from '../ai/embedding';
import { embeddings as embeddingsTable } from '../db/schema/embeddings';

export const createResource = async (input: NewResourceParams) => {
  try {
    const { content } = insertResourceSchema.parse(input);

    const [resource] = await db
      .insert(resources)
      .values({ content })
      .returning();

    const embeddings = await generateEmbeddings(content);
    await db.insert(embeddingsTable).values(
      embeddings.map(embedding => ({
        resourceId: resource.id,
        ...embedding,
      })),
    );

    return 'Resource successfully created and embedded.';
  } catch (error) {
    return error instanceof Error && error.message.length > 0
      ? error.message
      : 'Error, please try again.';
  }
};
```

首先，您调用上一步中创建的 `generateEmbeddings` 函数，传入源材料（`content`）。一旦您有了源材料的嵌入（`e`），您就可以将它们保存到数据库中，将 `resourceId` 与每个嵌入一起传递。

### 创建根页面

太好了！让我们构建前端。AI SDK 的 [`useChat`](/docs/reference/ai-sdk-ui/use-chat) hook 允许您轻松地为您的智能体创建对话式用户界面。

用以下代码替换您的根页面（`app/page.tsx`）。

```tsx filename="app/page.tsx"
'use client';

import { useChat } from '@ai-sdk/react';
import { useState } from 'react';

export default function Chat() {
  const [input, setInput] = useState('');
  const { messages, sendMessage } = useChat();
  return (
    <div className="flex flex-col w-full max-w-md py-24 mx-auto stretch">
      <div className="space-y-4">
        {messages.map(m => (
          <div key={m.id} className="whitespace-pre-wrap">
            <div>
              <div className="font-bold">{m.role}</div>
              {m.parts.map(part => {
                switch (part.type) {
                  case 'text':
                    return <p>{part.text}</p>;
                }
              })}
            </div>
          </div>
        ))}
      </div>

      <form
        onSubmit={e => {
          e.preventDefault();
          sendMessage({ text: input });
          setInput('');
        }}
      >
        <input
          className="fixed bottom-0 w-full max-w-md p-2 mb-8 border border-gray-300 rounded shadow-xl"
          value={input}
          placeholder="Say something..."
          onChange={e => setInput(e.currentTarget.value)}
        />
      </form>
    </div>
  );
}
```

`useChat` hook 支持从您的 AI 提供商（您将通过 Vercel AI Gateway 使用 OpenAI）流式传输聊天消息，管理聊天输入的状态，并在收到新消息时自动更新 UI。

运行以下命令启动 Next.js 开发服务器：

<Snippet text="pnpm run dev" />

前往 [http://localhost:3000](http://localhost:3000/)。您应该看到一个空屏幕，底部有一个浮动输入栏。尝试发送一条消息。消息在 UI 中显示一小段时间然后消失。这是因为您还没有设置相应的 API 路由来调用模型！默认情况下，`useChat` 将向 `/api/chat` 端点发送 POST 请求，请求体为 `messages`。

### 创建 API 路由

在 Next.js 中，您可以使用 [路由处理器](https://nextjs.org/docs/app/building-your-application/routing/route-handlers) 为给定路由创建自定义请求处理器。路由处理器在 `route.ts` 文件中定义，可以导出 `GET`、`POST`、`PUT`、`PATCH` 等 HTTP 方法。

使用以下命令在 `app/api/chat/route.ts` 创建一个文件：

<Snippet text="mkdir -p app/api/chat && touch app/api/chat/route.ts" />

打开文件并添加以下代码：

```tsx filename="app/api/chat/route.ts"
import {
  convertToModelMessages,
  createUIMessageStreamResponse,
  streamText,
  toUIMessageStream,
  UIMessage,
} from 'ai';

// 允许流式响应最长 30 秒
export const maxDuration = 30;

export async function POST(req: Request) {
  const { messages }: { messages: UIMessage[] } = await req.json();

  const result = streamText({
    model: 'openai/gpt-4o',
    messages: await convertToModelMessages(messages),
  });

  return createUIMessageStreamResponse({
    stream: toUIMessageStream({ stream: result.stream }),
  });
}
```

在这段代码中，您声明并导出了一个名为 POST 的异步函数。您从请求体中获取 `messages`，然后将它们与您想要使用的模型一起传递给从 AI SDK 导入的 [`streamText`](/docs/reference/ai-sdk-core/stream-text) 函数。最后，您以 `UIMessageStreamResponse` 格式返回模型的响应。

回到浏览器，再次尝试发送消息。您应该看到模型的响应直接流式传输进来！

### 优化您的提示词

虽然您现在有一个可用的智能体，但它并没有做任何特别的事情。

### 使用工具

[工具](/docs/foundations/tools) 是模型可以调用来执行特定任务的函数。您可以将工具视为您提供给模型的程序，它可以在认为必要时运行。

让我们看看如何创建一个工具，让模型能够创建、嵌入和保存资源到您的智能体的知识库中。

### 添加资源工具

使用以下代码更新您的路由处理器：

```tsx filename="app/api/chat/route.ts" highlight="25-36"
import { createResource } from '@/lib/actions/resources';
import {
  convertToModelMessages,
  createUIMessageStreamResponse,
  streamText,
  tool,
  toUIMessageStream,
  UIMessage,
} from 'ai';
import { z } from 'zod';

// 允许流式响应最长 30 秒
export const maxDuration = 30;

export async function POST(req: Request) {
  const { messages }: { messages: UIMessage[] } = await req.json();

  const result = streamText({
    model: 'openai/gpt-4o',
    instructions: `You are a helpful assistant. Check your knowledge base before answering any questions.
    Only respond to questions using information from tool calls.
    if no relevant information is found in the tool calls, respond, "Sorry, I don't know."`,
    messages: await convertToModelMessages(messages),
    tools: {
      addResource: tool({
        description: `add a resource to your knowledge base.
          If the user provides a random piece of knowledge unprompted, use this tool without asking for confirmation.`,
        inputSchema: z.object({
          content: z
            .string()
            .describe('the content or resource to add to the knowledge base'),
        }),
        execute: async ({ content }) => createResource({ content }),
      }),
    },
  });

  return createUIMessageStreamResponse({
    stream: toUIMessageStream({ stream: result.stream }),
  });
}
```

在这段代码中，您定义了一个名为 `addResource` 的工具。该工具有三个元素：

- **description**：工具的描述，将影响何时选择该工具。
- **inputSchema**：[Zod 模式](/docs/foundations/tools#schema-specification-and-validation-with-zod)，定义工具运行所需的输入。
- **execute**：一个异步函数，使用工具调用的参数调用。

简单来说，在每次生成时，模型将决定是否应该调用该工具。如果它认为应该调用该工具，它将提取输入，然后将类型为 `tool-call` 的新 `message` 追加到 `messages` 数组中。然后 AI SDK 将使用 `tool-call` 消息提供的参数运行 `execute` 函数。

### 使用多步调用改善用户体验

如果模型也能总结操作，那就太好了。然而，从技术上讲，一旦模型调用了一个工具，它就完成了生成，因为它“生成”了一个工具调用。您如何实现这种期望的行为？

AI SDK 有一个名为 [`stopWhen`](/docs/ai-sdk-core/tools-and-tool-calling#multi-step-calls) 的功能，它允许在模型生成工具调用时设置停止条件。如果这些停止条件没有被触发，AI SDK 将自动将工具调用结果发送回模型！

打开您的根页面（`api/chat/route.ts`）并向 `streamText` 配置对象添加以下键：

### 检索资源工具

模型现在可以向您的知识库添加和嵌入任意信息。然而，它仍然无法查询它。让我们创建一个新工具，让模型能够通过在知识库中查找相关信息来回答问题。

要找到相似的内容，您需要嵌入用户的查询，在数据库中搜索语义相似性，然后将这些项目作为上下文与查询一起传递给模型。为了实现这一点，让我们更新您的嵌入逻辑文件（`lib/ai/embedding.ts`）：

```tsx filename="lib/ai/embedding.ts" highlight="1-3,26-48"
import { embed, embedMany } from 'ai';
import { db } from '../db';
import { cosineDistance, desc, gt, sql } from 'drizzle-orm';
import { embeddings } from '../db/schema/embeddings';

const embeddingModel = 'openai/text-embedding-ada-002';

const generateChunks = (input: string): string[] => {
  return input
    .trim()
    .split('.')
    .filter(i => i !== '');
};

export const generateEmbeddings = async (
  value: string,
): Promise<Array<{ embedding: number[]; content: string }>> => {
  const chunks = generateChunks(value);
  const { embeddings } = await embedMany({
    model: embeddingModel,
    values: chunks,
  });
  return embeddings.map((e, i) => ({ content: chunks[i], embedding: e }));
};

export const generateEmbedding = async (value: string): Promise<number[]> => {
  const input = value.replaceAll('\\n', ' ');
  const { embedding } = await embed({
    model: embeddingModel,
    value: input,
  });
  return embedding;
};

export const findRelevantContent = async (userQuery: string) => {
  const userQueryEmbedded = await generateEmbedding(userQuery);
  const similarity = sql<number>`1 - (${cosineDistance(
    embeddings.embedding,
    userQueryEmbedded,
  )})`;
  const similarGuides = await db
    .select({ name: embeddings.content, similarity })
    .from(embeddings)
    .where(gt(similarity, 0.5))
    .orderBy(t => desc(t.similarity))
    .limit(4);
  return similarGuides;
};
```

在这段代码中，您添加了两个函数：

- `generateEmbedding`：从输入字符串生成单个嵌入
- `findRelevantContent`：嵌入用户的查询，在数据库中搜索相似项目，然后返回相关项目

完成这些后，进入最后一步：创建工具。
