# 多模态智能体

在本指南中，你将构建一个能够理解图像和 PDF 的多模态智能体。

多模态指的是智能体能够以多种格式理解和生成响应。在本指南中，我们将重点介绍图像和 PDF——这是现代语言模型能够原生处理的两种常见文档类型。

<Note>
  如需查看完整的提供商列表及其多模态能力，请访问
  [提供商文档](/providers/ai-sdk-providers)。
</Note>

我们将使用 OpenAI 的 GPT-4o 构建此智能体，但相同的代码可以无缝地与其他提供商配合使用——你只需更改一行代码即可在它们之间切换。

## 前提条件

要遵循本快速入门指南，你需要：

- 在本地开发机器上安装 Node.js 22+ 和 pnpm。
- 一个 Vercel AI Gateway API 密钥。

如果你尚未获取 Vercel AI Gateway API 密钥，可以通过在 Vercel 网站上[注册](https://vercel.com/d?to=%2F%5Bteam%5D%2F%7E%2Fai&title=Go+to+AI+Gateway)来获取。

</Note>

## 实现计划

要构建一个多模态智能体，你需要：

- 创建一个路由处理程序来处理传入的聊天消息并生成响应。
- 连接 UI 以显示聊天消息、提供用户输入，并处理提交新消息。
- 添加上传图像和 PDF 的功能，并将其与聊天消息一起附加。

## 创建路由处理程序

创建一个路由处理程序 `app/api/chat/route.ts`，并添加以下代码：

```tsx filename="app/api/chat/route.ts"
import {
  streamText,
  convertToModelMessages,
  createUIMessageStreamResponse,
  toUIMessageStream,
  type UIMessage,
} from 'ai';

// 允许流式传输响应最长 30 秒
export const maxDuration = 30;

export async function POST(req: Request) {
  const { messages }: { messages: UIMessage[] } = await req.json();

  const result = streamText({
    model: 'openai/gpt-4o',
    messages: await convertToModelMessages(messages),
  });

  return createUIMessageStreamResponse({
    stream: toUIMessageStream({ stream: result.stream }),
  });
}
```

让我们看看这段代码中发生了什么：

1. 定义一个异步的 `POST` 请求处理程序，并从请求体中提取 `messages`。`messages` 变量包含你和智能体之间的对话历史，为智能体提供生成下一步响应所需的上下文。
2. 使用 `convertToModelMessages` 将 UI 消息转换为模型消息，该函数将面向 UI 的消息格式转换为语言模型期望的格式。
3. 调用从 `ai` 包导入的 [`streamText`](/docs/reference/ai-sdk-core/stream-text) 函数。此函数接受一个配置对象，其中包含 `model` 提供商和 `messages`（在步骤 2 中转换）。你可以传递额外的[设置](/docs/ai-sdk-core/settings)来进一步自定义模型的行为。
4. `streamText` 函数返回一个 [`StreamTextResult`](/docs/reference/ai-sdk-core/stream-text#result-object)。将其 `stream` 传递给 `toUIMessageStream`，并使用 `createUIMessageStreamResponse` 返回它，以创建一个流式传输的响应对象。
5. 最后，将结果返回给客户端以流式传输响应。

此路由处理程序在 `/api/chat` 处创建了一个 POST 请求端点。

## 连接 UI

现在你已经有了一个可以查询大型语言模型（LLM）的路由处理程序，是时候设置你的前端了。[AI SDK UI](/docs/ai-sdk-ui) 将聊天界面的复杂性抽象为一个 Hook，即 [`useChat`](/docs/reference/ai-sdk-ui/use-chat)。

使用以下代码更新你的根页面（`app/page.tsx`），以显示聊天消息列表并提供用户消息输入：

```tsx filename="app/page.tsx"
'use client';

import { useChat } from '@ai-sdk/react';
import { DefaultChatTransport } from 'ai';
import { useState } from 'react';

export default function Chat() {
  const [input, setInput] = useState('');

  const { messages, sendMessage } = useChat({
    transport: new DefaultChatTransport({
      api: '/api/chat',
    }),
  });

  return (
    <div className="flex flex-col w-full max-w-md py-24 mx-auto stretch">
      {messages.map(m => (
        <div key={m.id} className="whitespace-pre-wrap">
          {m.role === 'user' ? '用户: ' : 'AI: '}
          {m.parts.map((part, index) => {
            if (part.type === 'text') {
              return <span key={`${m.id}-text-${index}`}>{part.text}</span>;
            }
            return null;
          })}
        </div>
      ))}

      <form
        onSubmit={async event => {
          event.preventDefault();
          sendMessage({
            role: 'user',
            parts: [{ type: 'text', text: input }],
          });
          setInput('');
        }}
        className="fixed bottom-0 w-full max-w-md mb-8 border border-gray-300 rounded shadow-xl"
      >
        <input
          className="w-full p-2"
          value={input}
          placeholder="说点什么..."
          onChange={e => setInput(e.target.value)}
        />
      </form>
    </div>
  );
}
```

<Note>
  确保在文件顶部添加 `"use client"` 指令。这允许你使用 JavaScript 添加交互性。
</Note>

此页面使用了 `useChat` Hook，并通过 `DefaultChatTransport` 配置了 API 端点。`useChat` Hook 提供了多个实用函数和状态变量：

- `messages` - 当前的聊天消息（一个对象数组，每个对象包含 `id`、`role` 和 `parts` 属性）。
- `sendMessage` - 用于向 AI 发送新消息的函数。
- 每条消息包含一个 `parts` 数组，可以包含文本、图像、PDF 和其他内容类型。
- 文件在发送前会被转换为 data URL，以保持跨不同环境的兼容性。

## 添加文件上传

为了使你的智能体具备多模态能力，让我们添加上传图像和 PDF 并将其发送给模型的功能。在 v5 中，文件作为消息的 `parts` 数组的一部分发送。文件在发送到服务器之前，会使用 FileReader API 转换为 data URL。

使用以下代码更新你的根页面（`app/page.tsx`）：

```tsx filename="app/page.tsx" highlight="4-5,10-12,15-39,46-81,87-97"
'use client';

import { useChat } from '@ai-sdk/react';
import { DefaultChatTransport } from 'ai';
import { useRef, useState } from 'react';
import Image from 'next/image';

async function convertFilesToDataURLs(files: FileList) {
  return Promise.all(
    Array.from(files).map(
      file =>
        new Promise<{
          type: 'file';
          mediaType: string;
          url: string;
        }>((resolve, reject) => {
          const reader = new FileReader();
          reader.onload = () => {
            resolve({
              type: 'file',
              mediaType: file.type,
              url: reader.result as string,
            });
          };
          reader.onerror = reject;
          reader.readAsDataURL(file);
        }),
    ),
  );
}

export default function Chat() {
  const [input, setInput] = useState('');
  const [files, setFiles] = useState<FileList | undefined>(undefined);
  const fileInputRef = useRef<HTMLInputElement>(null);

  const { messages, sendMessage } = useChat({
    transport: new DefaultChatTransport({
      api: '/api/chat',
    }),
  });

  return (
    <div className="flex flex-col w-full max-w-md py-24 mx-auto stretch">
      {messages.map(m => (
        <div key={m.id} className="whitespace-pre-wrap">
          {m.role === 'user' ? '用户: ' : 'AI: '}
          {m.parts.map((part, index) => {
            if (part.type === 'text') {
              return <span key={`${m.id}-text-${index}`}>{part.text}</span>;
            }
            if (part.type === 'file' && part.mediaType?.startsWith('image/')) {
              return (
                <Image
                  key={`${m.id}-image-${index}`}
                  src={part.url}
                  width={500}
                  height={500}
                  alt={`附件-${index}`}
                />
              );
            }
            if (part.type === 'file' && part.mediaType === 'application/pdf') {
              return (
                <iframe
                  key={`${m.id}-pdf-${index}`}
                  src={part.url}
                  width={500}
                  height={600}
                  title={`pdf-${index}`}
                />
              );
            }
            return null;
          })}
        </div>
      ))}

      <form
        className="fixed bottom-0 w-full max-w-md p-2 mb-8 border border-gray-300 rounded shadow-xl space-y-2"
        onSubmit={async event => {
          event.preventDefault();

          const fileParts =
            files && files.length > 0
              ? await convertFilesToDataURLs(files)
              : [];

          sendMessage({
            role: 'user',
            parts: [{ type: 'text', text: input }, ...fileParts],
          });

          setInput('');
          setFiles(undefined);

          if (fileInputRef.current) {
            fileInputRef.current.value = '';
          }
        }}
      >
        <input
          type="file"
          accept="image/*,application/pdf"
          className=""
          onChange={event => {
            if (event.target.files) {
              setFiles(event.target.files);
            }
          }}
          multiple
          ref={fileInputRef}
        />
        <input
          className="w-full p-2"
          value={input}
          placeholder="说点什么..."
          onChange={e => setInput(e.target.value)}
        />
      </form>
    </div>
  );
}
```

在这段代码中，你：

1. 添加了一个辅助函数 `convertFilesToDataURLs`，用于将文件上传转换为 data URL。
2. 创建了状态来保存输入文本、文件以及文件输入字段的 ref。
3. 使用 `DefaultChatTransport` 配置了 `useChat` 以指定 API 端点。
4. 使用 `parts` 数组结构显示消息，并适当地渲染文本、图像和 PDF。
5. 更新了 `onSubmit` 函数，以使用 `sendMessage` 函数发送消息，包括文本和文件部分。
6. 在表单中添加了一个文件输入字段，并包含一个 `onChange` 处理程序来处理文件状态的更新。

## 使用其他提供商

借助 AI SDK 的统一提供商接口，你可以轻松切换到其他支持多模态功能的提供商：

```tsx filename="app/api/chat/route.ts"
// 使用 Anthropic
const result = streamText({
  model: 'anthropic/claude-sonnet-4-20250514',
  messages: await convertToModelMessages(messages),
});

// 使用 Google
const result = streamText({
  model: 'google/gemini-2.5-flash',
  messages: await convertToModelMessages(messages),
});
```

安装提供商包（`@ai-sdk/anthropic` 或 `@ai-sdk/google`），并在 `.env.local` 中更新你的 API 密钥。代码的其余部分保持不变。

<Note>
  不同的提供商可能有不同的文件大小限制和性能特征。请查看[提供商文档](/providers/ai-sdk-providers)了解具体细节。
</Note>
