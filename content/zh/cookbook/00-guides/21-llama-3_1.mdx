# Llama 3.1 入门指南

<Note>
  当前一代 Llama 模型为 3.3。请注意，虽然本指南重点介绍 Llama 3.1，但更新的 Llama 3.3 模型现已可用，可能提供更强的能力。本文描述的概念和集成技术仍然适用，但您可能希望使用最新一代模型以获得最佳性能。
</Note>

随着 [Llama 3.1 的发布](https://ai.meta.com/blog/meta-llama-3-1/)，现在是开始构建 AI 应用的最佳时机。

[AI SDK](/) 是一个强大的 TypeScript 工具包，用于结合 Llama 3.1 等大型语言模型（LLM）以及 React、Next.js、Vue、Svelte、Node.js 等流行框架来构建 AI 应用。

## Llama 3.1

Meta 发布的 Llama 3.1 是 AI 发展的重要时刻。作为首个最先进的开源权重 AI 模型，Llama 3.1 正在帮助加速开发者构建 AI 应用。该模型提供 8B、70B 和 405B 三种尺寸，这些经过指令调优的模型非常适合对话生成、翻译、推理和代码生成等任务。

## 基准测试

Llama 3.1 在常见行业基准测试中超越了大多数可用的开源聊天模型，甚至在某些方面优于一些闭源模型，在语言细微差别、上下文理解和复杂多步任务方面表现出卓越性能。该模型精细的后训练过程显著改善了响应对齐、降低了错误拒绝率，并增强了答案多样性，使 Llama 3.1 成为构建生成式 AI 应用的强大且易用的工具。

## 选择模型尺寸

Llama 3.1 包含一个全新的 405B 参数模型，成为目前最大的开源模型。该模型专为处理最复杂和苛刻的任务而设计。

在选择不同尺寸的 Llama 3.1 模型（405B、70B、8B）时，需要考虑性能与计算需求之间的权衡。405B 模型在复杂任务中提供最高的准确性和能力，但需要大量的计算资源。70B 模型在大多数应用中提供了性能和效率的良好平衡，而 8B 模型适用于更简单的任务或资源受限的环境，在这些环境中速度和较低的计算开销是优先考虑的因素。

## AI SDK 入门

AI SDK 是专为帮助开发者使用 React、Next.js、Vue、Svelte、Node.js 等构建 AI 驱动应用而设计的 TypeScript 工具包。将 LLM 集成到应用中非常复杂，并且高度依赖于您使用的特定模型提供商。

AI SDK 抽象了不同模型提供商之间的差异，消除了构建聊天机器人的样板代码，并允许您超越文本输出，生成丰富的交互式组件。

AI SDK 的核心是 [AI SDK Core](/docs/ai-sdk-core/overview)，它提供了统一的 API 来调用任何 LLM。以下代码片段是使用 AI SDK 调用 Llama 3.1（使用 [DeepInfra](https://deepinfra.com)）所需的全部内容：

```ts
import { deepInfra } from '@ai-sdk/deepinfra';
import { generateText } from 'ai';

const { text } = await generateText({
  model: deepInfra('meta-llama/Meta-Llama-3.1-405B-Instruct'),
  prompt: '什么是爱？',
});
```

<Note>
  Llama 3.1 可与许多 AI SDK 提供商一起使用，包括
  [DeepInfra](/providers/ai-sdk-providers/deepinfra)、[Amazon
  Bedrock](/providers/ai-sdk-providers/amazon-bedrock)、
  [Baseten](/providers/ai-sdk-providers/baseten)、
  [Fireworks](/providers/ai-sdk-providers/fireworks) 等。
</Note>

AI SDK Core 抽象了不同模型提供商之间的差异，让您可以专注于构建出色的应用。更喜欢使用 [Amazon Bedrock](/providers/ai-sdk-providers/amazon-bedrock)？统一的接口也意味着您只需更改两行代码即可轻松切换模型。

```tsx highlight="2,5"
import { generateText } from 'ai';
import { amazonBedrock } from '@ai-sdk/amazon-bedrock';

const { text } = await generateText({
  model: amazonBedrock('meta.llama3-1-405b-instruct-v1'),
  prompt: '什么是爱？',
});
```

### 流式传输响应

要流式传输模型生成时的响应，请将代码片段更新为使用 [`streamText`](/docs/reference/ai-sdk-core/stream-text) 函数。

```tsx
import { streamText } from 'ai';
import { deepInfra } from '@ai-sdk/deepinfra';

const { textStream } = streamText({
  model: deepInfra('meta-llama/Meta-Llama-3.1-405B-Instruct'),
  prompt: '什么是爱？',
});
```

### 生成结构化数据

虽然文本生成可能很有用，但您可能希望生成结构化的 JSON 数据。例如，您可能希望从文本中提取信息、对数据进行分类或生成合成数据。AI SDK Core 提供了带有 `Output` 的 [`generateText`](/docs/reference/ai-sdk-core/generate-text) 和 [`streamText`](/docs/reference/ai-sdk-core/stream-text) 来生成结构化数据，允许您将模型输出限制为特定的模式。

```ts
import { generateText, Output } from 'ai';
import { deepInfra } from '@ai-sdk/deepinfra';
import { z } from 'zod';

const { output } = await generateText({
  model: deepInfra('meta-llama/Meta-Llama-3.1-70B-Instruct'),
  output: Output.object({
    schema: z.object({
      recipe: z.object({
        name: z.string(),
        ingredients: z.array(
          z.object({ name: z.string(), amount: z.string() }),
        ),
        steps: z.array(z.string()),
      }),
    }),
  }),
  prompt: '生成一个千层面食谱。',
});
```

此代码片段将生成一个符合指定 zod 模式的类型安全的食谱。

### 工具

虽然 LLM 具有令人难以置信的生成能力，但它们在离散任务（例如数学）和与外部世界交互（例如获取天气）方面存在困难。解决方案：工具，它们就像您提供给模型的程序，模型可以根据需要选择调用。

### 使用 AI SDK 中的工具

AI SDK 在其多个函数中支持工具使用，包括 [`generateText`](/docs/reference/ai-sdk-core/generate-text) 和 [`streamUI`](/docs/reference/ai-sdk-rsc/stream-ui)。通过向 `tools` 参数传递一个或多个工具，您可以扩展 LLM 的能力，使它们能够执行离散任务并与外部系统交互。

以下是如何使用 AI SDK 和 Llama 3.1 使用工具的示例：

```ts
import { generateText, tool } from 'ai';
import { deepInfra } from '@ai-sdk/deepinfra';
import { z } from 'zod';

const { text } = await generateText({
  model: deepInfra('meta-llama/Meta-Llama-3.1-70B-Instruct'),
  prompt: '今天天气怎么样？',
  tools: {
    getWeather: tool({
      description: '获取某个位置的天气',
      inputSchema: z.object({
        location: z.string().describe('要获取天气的位置'),
      }),
      execute: async ({ location }) => ({
        location,
        temperature: 72 + Math.floor(Math.random() * 21) - 10,
      }),
    }),
  },
});
```

在此示例中，`getWeather` 工具允许模型获取实时天气数据，增强其提供准确和最新信息的能力。

### 智能体

智能体通过允许模型以非确定性的方式执行多个步骤（即工具），根据上下文和用户输入做出决策，将您的 AI 应用提升到一个新的水平。

智能体使用 LLM 来选择问题解决过程中的下一步。它们可以在每一步进行推理，并根据不断变化的上下文做出决策。

### 使用 AI SDK 实现智能体

AI SDK 通过 `stopWhen` 参数和内置的停止条件支持智能体实现。这允许模型在单次交互中做出多个决策和工具调用。

以下是一个解决数学问题的智能体示例：

```tsx
import { generateText, tool, isStepCount } from 'ai';
import { deepInfra } from '@ai-sdk/deepinfra';
import * as mathjs from 'mathjs';
import { z } from 'zod';

const problem =
  '如果收入为 5000 美元，支出为 3500 美元，计算一天的利润。';

const { text: answer } = await generateText({
  model: deepInfra('meta-llama/Meta-Llama-3.1-70B-Instruct'),
  instructions:
    '你在解决数学问题。逐步推理。必要时使用计算器。',
  prompt: problem,
  tools: {
    calculate: tool({
      description: '用于计算数学表达式的工具。',
      inputSchema: z.object({ expression: z.string() }),
      execute: async ({ expression }) => mathjs.evaluate(expression),
    }),
  },
  stopWhen: isStepCount(5),
});
```

在此示例中，智能体可以根据需要多次使用计算器工具，逐步推理问题。

### 构建交互式界面

AI SDK Core 可以与 [AI SDK UI](/docs/ai-sdk-ui/overview)（AI SDK 的另一个强大组件）配合使用，以简化使用 Next.js、Nuxt 和 SvelteKit 等流行框架构建聊天、补全和助手界面的过程。

AI SDK UI 提供了强大的抽象，简化了在前端管理聊天流和 UI 更新的复杂任务，使您能够更高效地开发动态的 AI 驱动界面。

通过四个主要的 Hook —— [`useChat`](/docs/reference/ai-sdk-ui/use-chat)、[`useCompletion`](/docs/reference/ai-sdk-ui/use-completion) 和 [`useObject`](/docs/reference/ai-sdk-ui/use-object) —— 您可以将实时聊天功能、文本补全、流式 JSON 和交互式助手功能集成到您的应用中。

让我们探索使用 [Next.js](https://nextjs.org)、AI SDK 和 Llama 3.1（通过 [DeepInfra](https://deepinfra.com)）构建聊天机器人：

```tsx filename="app/api/chat/route.ts"
import { deepInfra } from '@ai-sdk/deepinfra';
import {
  convertToModelMessages,
  createUIMessageStreamResponse,
  streamText,
  toUIMessageStream,
  UIMessage,
} from 'ai';

// 允许流式响应最长 30 秒
export const maxDuration = 30;

export async function POST(req: Request) {
  const { messages }: { messages: UIMessage[] } = await req.json();

  const result = streamText({
    model: deepInfra('meta-llama/Meta-Llama-3.1-70B-Instruct'),
    messages: await convertToModelMessages(messages),
  });

  return createUIMessageStreamResponse({
    stream: toUIMessageStream({ stream: result.stream }),
  });
}
```

```tsx filename="app/page.tsx"
'use client';

import { useChat } from '@ai-sdk/react';
import { useState } from 'react';

export default function Page() {
  const [input, setInput] = useState('');
  const { messages, sendMessage } = useChat();

  const handleSubmit = (e: React.FormEvent<HTMLFormElement>) => {
    e.preventDefault();
    if (input.trim()) {
      sendMessage({ text: input });
      setInput('');
    }
  };

  return (
    <>
      {messages.map(message => (
        <div key={message.id}>
          {message.role === 'user' ? '用户：' : 'AI：'}
          {message.parts.map((part, index) => {
            if (part.type === 'text') {
              return <span key={index}>{part.text}</span>;
            }
            return null;
          })}
        </div>
      ))}
      <form onSubmit={handleSubmit}>
        <input
          name="prompt"
          value={input}
          onChange={e => setInput(e.target.value)}
        />
        <button type="submit">提交</button>
      </form>
    </>
  );
}
```

根页面（`app/page.tsx`）上的 useChat Hook 会在用户提交消息时向您的 AI 提供商端点（`app/api/chat/route.ts`）发出请求。然后消息会实时流式返回并显示在聊天界面中。

这实现了无缝的聊天体验，用户可以在 AI 响应可用时立即看到，而无需等待整个响应接收完成。

### 超越文本

AI SDK 的 React 服务器组件（RSC）API 使您能够创建超越简单文本生成的丰富交互式界面。使用 [`streamUI`](/docs/reference/ai-sdk-rsc/stream-ui) 函数，您可以动态地将 React 组件从服务器流式传输到客户端。

让我们深入了解如何利用 [AI SDK RSC](/docs/ai-sdk-rsc/overview) 与 Next.js（App Router）构建生成式用户界面。

首先，创建一个服务器操作。

```tsx filename="app/actions.tsx"
'use server';

import { streamUI } from '@ai-sdk/rsc';
import { deepInfra } from '@ai-sdk/deepinfra';
import { z } from 'zod';

export async function streamComponent() {
  const result = await streamUI({
    model: deepInfra('meta-llama/Meta-Llama-3.1-70B-Instruct'),
    prompt: '获取旧金山的天气',
    text: ({ content }) => <div>{content}</div>,
    tools: {
      getWeather: {
        description: '获取某个位置的天气',
        inputSchema: z.object({ location: z.string() }),
        generate: async function* ({ location }) {
          yield <div>加载中...</div>;
          const weather = '25c'; // await getWeather(location);
          return (
            <div>
              {location} 的天气是 {weather}。
            </div>
          );
        },
      },
    },
  });
  return result.value;
}
```

在此示例中，如果模型决定使用 `getWeather` 工具，它将首先在获取天气数据时生成一个 `div`，然后返回一个包含获取数据的天气组件（注意：此示例中使用的是静态数据）。这允许构建更动态和响应式的 UI，能够根据 AI 的决策和外部数据进行调整。

在前端，您可以像调用应用中的任何其他异步函数一样调用此服务器操作。在这种情况下，该函数返回一个常规的 React 组件。

```tsx filename="app/page.tsx"
'use client';

import { useState } from 'react';
import { streamComponent } from './actions';

export default function Page() {
  const [component, setComponent] = useState<React.ReactNode>();

  return (
    <div>
      <form
        onSubmit={async e => {
          e.preventDefault();
          setComponent(await streamComponent());
        }}
      >
        <button>流式组件</button>
      </form>
      <div>{component}</div>
    </div>
  );
}
```

## 从 OpenAI 迁移

AI SDK 的关键优势之一是其统一的 API，这使得在不同 AI 模型和提供商之间切换变得非常容易。这种灵活性在您想要从一个模型迁移到另一个模型时特别有用，例如从 OpenAI 的 GPT 模型迁移到 DeepInfra 上托管的 Meta 的 Llama 模型。

以下是迁移过程可以多么简单：

**OpenAI 示例：**

```tsx
import { generateText } from 'ai';
import { openai } from '@ai-sdk/openai';

const { text } = await generateText({
  model: openai('gpt-4.1'),
  prompt: '什么是爱？',
});
```

**DeepInfra 上的 Llama 示例：**

```tsx
import { generateText } from 'ai';
import { deepInfra } from '@ai-sdk/deepinfra';

const { text } = await generateText({
  model: deepInfra('meta-llama/Meta-Llama-3.1-70B-Instruct'),
  prompt: '什么是爱？',
});
```

得益于统一的 API，代码的核心结构保持不变。主要区别在于：

1. 创建 DeepInfra 客户端
2. 将模型名称从 `openai("gpt-4.1")` 改为 `deepinfra("meta-llama/Meta-Llama-3.1-70B-Instruct")`。

只需这几处更改，您就从使用 OpenAI 的 GPT-4-Turbo 迁移到了 DeepInfra 上托管的 Meta 的 Llama 3.1。`generateText` 函数及其用法保持不变，展示了 AI SDK 统一 API 的强大功能。

此功能允许您轻松试验不同的模型、比较它们的性能，并为您的特定用例选择最佳模型，而无需重写大部分代码库。

## 提示词工程与微调

虽然 Llama 3.1 模型系列开箱即用功能强大，但通过有效的提示词工程和微调技术可以增强其性能。

### 提示词工程

提示词工程是精心设计输入提示词以从语言模型中引出所需输出的实践。它涉及以引导模型产生更准确、相关和连贯响应的方式构建和措辞提示词。

有关提示词工程技术的更多信息（特定于 Llama 模型），请查看以下资源：

- [官方 Llama 3.1 提示词指南](https://llama.meta.com/docs/how-to-guides/prompting)

- [如何为 Llama 3 编写提示词](https://huggingface.co/blog/llama3#how-to-prompt-llama-3)

### 微调

微调涉及在特定数据集或任务上进一步训练预训练模型，以针对特定用例定制其性能。此过程允许您将 Llama 3.1 适应到您的特定领域或应用，可能提高其准确性和与您需求的相关性。

要了解更多关于微调 Llama 模型的信息，请查看以下资源：
