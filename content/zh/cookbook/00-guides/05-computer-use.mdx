# 开始使用 Computer Use

随着 [Claude 3.5 Sonnet 中 Computer Use 的发布](https://www.anthropic.com/news/3-5-models-and-computer-use)，你现在可以指示 AI 模型像人类一样与计算机交互——移动光标、点击按钮和输入文本。这一能力在利用 Claude 高级推理能力的同时，实现了复杂任务的自动化。

AI SDK 是一个强大的 TypeScript 工具包，用于结合 Anthropic 的 Claude 等大型语言模型（LLM）以及 React、Next.js、Vue、Svelte、Node.js 等流行框架来构建 AI 应用。在本指南中，你将学习如何将 Computer Use 集成到你的 AI SDK 应用中。

<Note>
  Computer Use 目前处于测试阶段，存在一些[限制](https://docs.anthropic.com/en/docs/build-with-claude/computer-use#understand-computer-use-limitations)。
  该功能有时可能会出错。Anthropic 建议从低风险任务开始，并实施适当的安全措施。
</Note>

## Computer Use

Anthropic 最近发布了新版本的 Claude 3.5 Sonnet 模型，它具备“Computer Use”能力。这允许模型通过以下基本操作与计算机界面交互：

- 移动光标
- 点击按钮
- 输入文本
- 截取屏幕截图
- 读取屏幕内容

## 工作原理

Computer Use 使模型能够通过一系列协调的步骤读取屏幕内容并与之交互。以下是该流程的工作原理：

1. **从提示词和工具开始**

   将 Anthropic 定义的 Computer Use 工具添加到你的请求中，并为模型提供一个任务（提示词）。例如：“将一张图片保存到你的下载文件夹。”

2. **选择合适的工具**

   模型会评估哪些计算机工具可以帮助完成任务。然后它会发送格式化的 `tool_call` 来使用合适的工具。

3. **执行操作并返回结果**

   AI SDK 通过运行所选工具来处理 Claude 的请求。随后可以通过 `tool_result` 消息将结果发送回 Claude。

4. **通过迭代完成任务**

   Claude 会分析每个结果，以确定是否需要更多操作。它会持续请求工具使用并处理结果，直到完成你的任务或需要额外输入。

### 可用工具

Computer Use API 中提供了三个主要工具：

1. **Computer Tool**：支持基本的计算机控制，如鼠标移动、点击和键盘输入
2. **Text Editor Tool**：提供查看和编辑文本文件的功能
3. **Bash Tool**：允许执行 bash 命令

### 实现注意事项

AI SDK 中的 Computer Use 工具是预定义的接口，需要你自己实现执行层。虽然 SDK 提供了这些工具的类型定义和结构，但你需要：

1. 为 Computer Use 执行设置受控环境
2. 实现鼠标控制和键盘输入等核心功能
3. 处理屏幕截图捕获和处理
4. 为 Claude 如何与你的系统交互设置规则和限制

推荐的做法是从 [Anthropic 的参考实现](https://github.com/anthropics/anthropic-quickstarts/tree/main/computer-use-demo)开始，它提供了：

- 为安全的 Computer Use 配置的容器化环境
- 可直接使用的（Python）Computer Use 工具实现
- 用于 API 交互和工具执行的智能体循环
- 用于监控和控制的 Web 界面

此参考实现可作为基础，帮助你在构建自己的自定义解决方案之前理解相关需求。

## 开始使用 AI SDK

<Note>
  如果你以前从未使用过 AI SDK，请先按照[入门指南](/docs/getting-started)进行操作。
</Note>

<Note>
  如需查看使用 Next.js 和 AI SDK 实现 Computer Use 的可运行示例，请查看我们的 [AI SDK Computer Use 模板](https://github.com/vercel-labs/ai-sdk-computer-use)。
</Note>

首先，确保你已安装 AI SDK 和 [Anthropic AI SDK 提供商](/providers/ai-sdk-providers/anthropic)：

<Snippet text="pnpm add ai @ai-sdk/anthropic" />

你可以使用提供商定义的客户端工具将 Computer Use 添加到你的 AI SDK 应用中。这些工具接受各种输入参数（例如 computer 工具的显示高度和宽度），然后要求你定义一个 execute 函数。

以下是如何使用 AI SDK 设置 Computer Tool 的示例：

```ts
import { anthropic } from '@ai-sdk/anthropic';
import { getScreenshot, executeComputerAction } from '@/utils/computer-use';

const computerTool = anthropic.tools.computer_20250124({
  displayWidthPx: 1920,
  displayHeightPx: 1080,
  execute: async ({ action, coordinate, text }) => {
    switch (action) {
      case 'screenshot': {
        return {
          type: 'image',
          data: getScreenshot(),
        };
      }
      default: {
        return executeComputerAction(action, coordinate, text);
      }
    }
  },
  toModelOutput({ output }) {
    return typeof output === 'string'
      ? [{ type: 'text', text: output }]
      : [{ type: 'file-data', data: output.data, mediaType: 'image/png' }];
  },
});
```

`computerTool` 处理两个主要操作：通过 `getScreenshot()` 截取屏幕截图，以及通过 `executeComputerAction()` 执行鼠标移动和点击等计算机操作。请记住，你必须实现此执行逻辑（例如 `getScreenshot` 和 `executeComputerAction` 函数）来处理实际的计算机交互。`execute` 函数应处理与操作系统的所有底层交互。

最后，要将工具结果发送回模型，请使用 [`toModelOutput()`](/docs/foundations/prompts#multi-modal-tool-results) 函数将文本和图像响应转换为模型可以处理的格式。在使用 Anthropic 的模型时，AI SDK 对这些多模态工具结果提供了实验性支持。

<Note>
  Computer Use 需要采取适当的安全措施，例如使用虚拟机、限制对敏感数据的访问，以及对关键操作实施人工监督。
</Note>

### 将计算机工具与文本生成结合使用

定义好工具后，你可以将其与 [`generateText`](/docs/reference/ai-sdk-core/generate-text) 和 [`streamText`](/docs/reference/ai-sdk-core/stream-text) 函数一起使用。

对于一次性文本生成，使用 `generateText`：

```ts
const result = await generateText({
  model: 'anthropic/claude-sonnet-4-20250514',
  prompt: 'Move the cursor to the center of the screen and take a screenshot',
  tools: { computer: computerTool },
});

console.log(result.text);
```

对于流式传输响应，使用 `streamText` 实时接收更新：

```ts
const result = streamText({
  model: 'anthropic/claude-sonnet-4-20250514',
  prompt: 'Open the browser and navigate to vercel.com',
  tools: { computer: computerTool },
});

for await (const chunk of result.textStream) {
  console.log(chunk);
}
```

### 配置多步骤（智能体）生成

要允许模型在无需用户干预的情况下执行多个步骤，请使用 `stopWhen` 参数。这会自动将任何工具结果发送回模型，以触发后续生成：

```ts highlight="1,7"
import { isStepCount } from 'ai';

const stream = streamText({
  model: 'anthropic/claude-sonnet-4-20250514',
  prompt: 'Open the browser and navigate to vercel.com',
  tools: { computer: computerTool },
  stopWhen: isStepCount(10), // experiment with this value based on your use case
});
```

### 组合多个工具

你可以在单个请求中组合多个工具，以实现更复杂的工作流。AI SDK 支持 Claude 的全部三个 Computer Use 工具：

```ts
const computerTool = anthropic.tools.computer_20250124({
  ...
});

const bashTool = anthropic.tools.bash_20250124({
  execute: async ({ command, restart }) => execSync(command).toString()
});

const textEditorTool = anthropic.tools.textEditor_20250728({
  execute: async ({
    command,
    path,
    file_text,
    insert_line,
    new_str,
    insert_text,
    old_str,
    view_range
  }) => {
    // Handle file operations based on command
    switch(command) {
      return executeTextEditorFunction({
        command,
        path,
        fileText: file_text,
        insertLine: insert_line,
        newStr: new_str,
        insertText: insert_text,
        oldStr: old_str,
        viewRange: view_range
      });
    }
  }
});


const response = await generateText({
  model: 'anthropic/claude-sonnet-4-20250514',
  prompt: "Create a new file called example.txt, write 'Hello World' to it, and run 'cat example.txt' in the terminal",
  tools: {
    computer: computerTool,
    bash: bashTool,
    str_replace_editor: textEditorTool,
  },
});
```

</Note>

### Computer Use 的最佳实践

要在使用 Computer Use 时获得最佳结果：

1. 指定简单、定义明确的任务，并为每个步骤提供明确的指令
2. 提示 Claude 通过屏幕截图验证结果
3. 当 UI 元素难以操作时，使用键盘快捷键
4. 为可重复的任务提供示例屏幕截图
5. 在系统提示词中为已知任务提供明确的提示

## 安全措施

请记住，Computer Use 是一项测试版功能。请注意，它会带来不同于标准 API 功能或聊天界面的独特风险。在使用 Computer Use 与互联网交互时，这些风险会加剧。为将风险降至最低，请考虑采取以下预防措施：

1. 使用权限最小的专用虚拟机或容器，以防止直接的系统攻击或意外。
2. 避免让模型访问敏感数据，例如账户登录信息，以防止信息被盗。
3. 将互联网访问限制在域名允许列表中，以减少接触恶意内容的风险。
4. 对于可能产生重大现实后果的决策，以及任何需要明确同意的任务（例如接受 cookie、执行金融交易或同意服务条款），请让人类确认。
