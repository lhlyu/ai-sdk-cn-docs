# Claude 3.7 Sonnet 入门

<Note type="warning">
  本指南已弃用。[Claude 3.7 Sonnet 已于 2026 年 2 月 19 日退役](https://platform.claude.com/docs/en/about-claude/model-deprecations#2025-10-28-claude-sonnet-3-7-model)，
  无法再与 Anthropic API 一起使用。
</Note>

随着 [Claude 3.7 Sonnet 的发布](https://www.anthropic.com/news/claude-3-7-sonnet)，现在是开始构建 AI 应用的最佳时机，尤其是那些需要复杂推理能力的应用。

[AI SDK](/) 是一个强大的 TypeScript 工具包，用于结合 Claude 3.7 Sonnet 等大型语言模型（LLM）以及 React、Next.js、Vue、Svelte、Node.js 等流行框架来构建 AI 应用。

## Claude 3.7 Sonnet

Claude 3.7 Sonnet 是 Anthropic 迄今为止最智能的模型，也是首个提供扩展思考能力的 Claude 模型——能够通过细致、逐步的推理来解决复杂问题。借助 Claude 3.7 Sonnet，你可以在标准思考（近乎即时的响应）与扩展思考或高级推理之间进行选择，从而平衡速度与质量。Claude 3.7 Sonnet 在编码方面处于最先进水平，并在计算机使用、智能体能力、复杂推理和内容生成方面取得了进步。凭借前沿的性能和对速度的更强控制，Claude 3.7 Sonnet 是驱动 AI 智能体（尤其是面向客户的智能体）和复杂 AI 工作流的绝佳选择。

## AI SDK 入门

AI SDK 是一个 TypeScript 工具包，旨在帮助开发者使用 React、Next.js、Vue、Svelte、Node.js 等构建 AI 驱动的应用。将 LLM 集成到应用中既复杂又高度依赖于你所使用的特定模型提供商。

AI SDK 抽象掉了模型提供商之间的差异，消除了构建聊天机器人的样板代码，并让你能够超越文本输出，生成丰富、可交互的组件。

AI SDK 的核心是 [AI SDK Core](/docs/ai-sdk-core/overview)，它提供了统一的 API 来调用任何 LLM。下面的代码片段就是使用 AI SDK 调用 Claude 3.7 Sonnet 所需的全部内容：

```ts
import { anthropic } from '@ai-sdk/anthropic';
import { generateText } from 'ai';

const { text, reasoningText, reasoning } = await generateText({
  model: anthropic('claude-3-7-sonnet-20250219'),
  prompt: 'How many people will live in the world in 2040?',
});
console.log(text); // text response
```

统一的接口还意味着，你只需更改两行代码即可轻松在提供商之间切换。例如，通过 Amazon Bedrock 使用 Claude 3.7 Sonnet：

```ts
import { amazonBedrock } from '@ai-sdk/amazon-bedrock';
import { generateText } from 'ai';

const { reasoning, text } = await generateText({
  model: amazonBedrock('anthropic.claude-3-7-sonnet-20250219-v1:0'),
  prompt: 'How many people will live in the world in 2040?',
});
```

### 推理能力

Claude 3.7 Sonnet 引入了新的扩展思考能力——能够通过细致、逐步的推理来解决复杂问题。你可以使用 `thinking` 提供商选项并指定以 token 为单位的思考预算来启用它：

```ts
import { anthropic, AnthropicLanguageModelOptions } from '@ai-sdk/anthropic';
import { generateText } from 'ai';

const { text, reasoningText, reasoning } = await generateText({
  model: anthropic('claude-3-7-sonnet-20250219'),
  prompt: 'How many people will live in the world in 2040?',
  providerOptions: {
    anthropic: {
      thinking: { type: 'enabled', budgetTokens: 12000 },
    } satisfies AnthropicLanguageModelOptions,
  },
});

console.log(reasoningText); // reasoning text
console.log(reasoning); // reasoning details including redacted reasoning
console.log(text); // text response
```

### 构建交互式界面

AI SDK Core 可以与 [AI SDK UI](/docs/ai-sdk-ui/overview) 搭配使用，后者是 AI SDK 的另一个强大组件，可简化使用 Next.js、Nuxt 和 SvelteKit 等流行框架构建聊天、补全和助手界面的过程。

AI SDK UI 提供了强大的抽象，简化了在前端管理聊天流和 UI 更新等复杂任务，使你能够更高效地开发动态的 AI 驱动界面。

借助三个主要的 Hook——[`useChat`](/docs/reference/ai-sdk-ui/use-chat)、[`useCompletion`](/docs/reference/ai-sdk-ui/use-completion) 和 [`useObject`](/docs/reference/ai-sdk-ui/use-object)——你可以将实时聊天能力、文本补全、流式 JSON 和交互式助手功能整合到你的应用中。

让我们探索如何使用 [Next.js](https://nextjs.org)、AI SDK 和 Claude 3.7 Sonnet 构建一个聊天机器人：

在一个新的 Next.js 应用中，首先安装 AI SDK 和 Anthropic 提供商：

<Snippet text="pnpm install ai @ai-sdk/anthropic" />

然后，为聊天端点创建一个路由处理器：

```tsx filename="app/api/chat/route.ts"
import { anthropic, AnthropicLanguageModelOptions } from '@ai-sdk/anthropic';
import {
  streamText,
  convertToModelMessages,
  createUIMessageStreamResponse,
  toUIMessageStream,
  type UIMessage,
} from 'ai';

export async function POST(req: Request) {
  const { messages }: { messages: UIMessage[] } = await req.json();

  const result = streamText({
    model: anthropic('claude-3-7-sonnet-20250219'),
    messages: await convertToModelMessages(messages),
    providerOptions: {
      anthropic: {
        thinking: { type: 'enabled', budgetTokens: 12000 },
      } satisfies AnthropicLanguageModelOptions,
    },
  });

  return createUIMessageStreamResponse({
    stream: toUIMessageStream({
      stream: result.stream,
      sendReasoning: true,
    }),
  });
}
```

<Note>
  你可以在 `toUIMessageStream` 辅助函数中使用 `sendReasoning: true`
  将模型的推理 token 转发到客户端。
</Note>

最后，更新根页面（`app/page.tsx`）以使用 `useChat` Hook：

```tsx filename="app/page.tsx"
'use client';

import { useChat } from '@ai-sdk/react';
import { DefaultChatTransport } from 'ai';
import { useState } from 'react';

export default function Page() {
  const [input, setInput] = useState('');
  const { messages, sendMessage } = useChat({
    transport: new DefaultChatTransport({ api: '/api/chat' }),
  });

  const handleSubmit = (e: React.FormEvent) => {
    e.preventDefault();
    if (input.trim()) {
      sendMessage({ text: input });
      setInput('');
    }
  };

  return (
    <>
      {messages.map(message => (
        <div key={message.id}>
          {message.role === 'user' ? 'User: ' : 'AI: '}
          {message.parts.map((part, index) => {
            // text parts:
            if (part.type === 'text') {
              return <div key={index}>{part.text}</div>;
            }
            // reasoning parts:
            if (part.type === 'reasoning') {
              return <pre key={index}>{part.text}</pre>;
            }
          })}
        </div>
      ))}
      <form onSubmit={handleSubmit}>
        <input
          name="prompt"
          value={input}
          onChange={e => setInput(e.target.value)}
        />
        <button type="submit">Send</button>
      </form>
    </>
  );
}
```

<Note>
  你可以通过消息 `parts` 上的 `reasoning` 部分访问模型的推理 token。
</Note>

根页面（`app/page.tsx`）上的 useChat Hook 会在用户提交消息时向你的 LLM 提供商端点（`app/api/chat/route.ts`）发起请求。随后消息会显示在聊天 UI 中。
