# 开始使用 Claude 3.7 Sonnet

<Note type="warning">
  本指南已弃用。[Claude 3.7 Sonnet 已于 2026 年 2 月 19 日退役](https://platform.claude.com/docs/en/about-claude/model-deprecations#2025-10-28-claude-sonnet-3-7-model)，无法再通过 Anthropic API 使用。
</Note>

随着 [Claude 3.7 Sonnet 的发布](https://www.anthropic.com/news/claude-3-7-sonnet)，现在正是开始构建 AI 应用的最佳时机，尤其是那些需要复杂推理能力的应用。

[AI SDK](/) 是一个强大的 TypeScript 工具包，用于结合 React、Next.js、Vue、Svelte、Node.js 等流行框架，构建基于 Claude 3.7 Sonnet 等大语言模型（LLM）的 AI 应用。

## Claude 3.7 Sonnet

Claude 3.7 Sonnet 是 Anthropic 迄今为止最智能的模型，也是首个提供扩展思考能力的 Claude 模型——即通过细致、逐步推理来解决复杂问题的能力。借助 Claude 3.7 Sonnet，您可以在标准思考（近乎即时响应）和扩展思考（高级推理）之间灵活选择，平衡速度与质量。Claude 3.7 Sonnet 在编码方面达到前沿水平，并在计算机使用、智能体能力、复杂推理和内容生成方面取得了进步。凭借前沿性能和对速度的更强控制，Claude 3.7 Sonnet 是驱动 AI 智能体（尤其是面向客户的智能体）和复杂 AI 工作流的绝佳选择。

## 开始使用 AI SDK

AI SDK 是一个 TypeScript 工具包，旨在帮助开发者使用 React、Next.js、Vue、Svelte、Node.js 等构建 AI 驱动的应用。将 LLM 集成到应用中非常复杂，且高度依赖于您使用的特定模型提供商。

AI SDK 抽象了不同模型提供商之间的差异，消除了构建聊天机器人的样板代码，并允许您超越文本输出，生成丰富的交互式组件。

AI SDK 的核心是 [AI SDK Core](/docs/ai-sdk-core/overview)，它提供了一个统一的 API 来调用任何 LLM。以下代码片段展示了使用 AI SDK 调用 Claude 3.7 Sonnet 所需的所有内容：

```ts
import { anthropic } from '@ai-sdk/anthropic';
import { generateText } from 'ai';

const { text, reasoningText, reasoning } = await generateText({
  model: anthropic('claude-3-7-sonnet-20250219'),
  prompt: '2040 年全球将有多少人口？',
});
console.log(text); // 文本响应
```

统一的接口还意味着您只需更改两行代码即可轻松切换提供商。例如，通过 Amazon Bedrock 使用 Claude 3.7 Sonnet：

```ts
import { amazonBedrock } from '@ai-sdk/amazon-bedrock';
import { generateText } from 'ai';

const { reasoning, text } = await generateText({
  model: amazonBedrock('anthropic.claude-3-7-sonnet-20250219-v1:0'),
  prompt: '2040 年全球将有多少人口？',
});
```

### 推理能力

Claude 3.7 Sonnet 引入了新的扩展思考能力——通过细致、逐步推理来解决复杂问题。您可以使用 `thinking` 提供商选项并指定思考预算（以 token 为单位）来启用它：

```ts
import { anthropic, AnthropicLanguageModelOptions } from '@ai-sdk/anthropic';
import { generateText } from 'ai';

const { text, reasoningText, reasoning } = await generateText({
  model: anthropic('claude-3-7-sonnet-20250219'),
  prompt: '2040 年全球将有多少人口？',
  providerOptions: {
    anthropic: {
      thinking: { type: 'enabled', budgetTokens: 12000 },
    } satisfies AnthropicLanguageModelOptions,
  },
});

console.log(reasoningText); // 推理文本
console.log(reasoning); // 推理详情（包括已编辑的推理）
console.log(text); // 文本响应
```

### 构建交互式界面

AI SDK Core 可以与 [AI SDK UI](/docs/ai-sdk-ui/overview) 结合使用，后者是 AI SDK 的另一个强大组件，可简化使用 Next.js、Nuxt 和 SvelteKit 等流行框架构建聊天、补全和助手界面的流程。

AI SDK UI 提供了强大的抽象，简化了前端管理聊天流和 UI 更新的复杂任务，使您能够更高效地开发动态的 AI 驱动界面。

通过四个主要 Hook——[`useChat`](/docs/reference/ai-sdk-ui/use-chat)、[`useCompletion`](/docs/reference/ai-sdk-ui/use-completion) 和 [`useObject`](/docs/reference/ai-sdk-ui/use-object)——您可以将实时聊天功能、文本补全、流式 JSON 和交互式助手功能集成到应用中。

让我们探索如何使用 [Next.js](https://nextjs.org)、AI SDK 和 Claude 3.7 Sonnet 构建一个聊天机器人：

在一个新的 Next.js 应用中，首先安装 AI SDK 和 Anthropic 提供商：

<Snippet text="pnpm install ai @ai-sdk/anthropic" />

然后，为聊天端点创建一个路由处理程序：

```tsx filename="app/api/chat/route.ts"
import { anthropic, AnthropicLanguageModelOptions } from '@ai-sdk/anthropic';
import {
  streamText,
  convertToModelMessages,
  createUIMessageStreamResponse,
  toUIMessageStream,
  type UIMessage,
} from 'ai';

export async function POST(req: Request) {
  const { messages }: { messages: UIMessage[] } = await req.json();

  const result = streamText({
    model: anthropic('claude-3-7-sonnet-20250219'),
    messages: await convertToModelMessages(messages),
    providerOptions: {
      anthropic: {
        thinking: { type: 'enabled', budgetTokens: 12000 },
      } satisfies AnthropicLanguageModelOptions,
    },
  });

  return createUIMessageStreamResponse({
    stream: toUIMessageStream({
      stream: result.stream,
      sendReasoning: true,
    }),
  });
}
```

<Note>
  您可以通过 `toUIMessageStream` 辅助函数中的 `sendReasoning: true` 将模型的推理 token 转发给客户端。
</Note>

最后，更新根页面（`app/page.tsx`）以使用 `useChat` Hook：

```tsx filename="app/page.tsx"
'use client';

import { useChat } from '@ai-sdk/react';
import { DefaultChatTransport } from 'ai';
import { useState } from 'react';

export default function Page() {
  const [input, setInput] = useState('');
  const { messages, sendMessage } = useChat({
    transport: new DefaultChatTransport({ api: '/api/chat' }),
  });

  const handleSubmit = (e: React.FormEvent) => {
    e.preventDefault();
    if (input.trim()) {
      sendMessage({ text: input });
      setInput('');
    }
  };

  return (
    <>
      {messages.map(message => (
        <div key={message.id}>
          {message.role === 'user' ? '用户: ' : 'AI: '}
          {message.parts.map((part, index) => {
            // 文本部分：
            if (part.type === 'text') {
              return <div key={index}>{part.text}</div>;
            }
            // 推理部分：
            if (part.type === 'reasoning') {
              return <pre key={index}>{part.text}</pre>;
            }
          })}
        </div>
      ))}
      <form onSubmit={handleSubmit}>
        <input
          name="prompt"
          value={input}
          onChange={e => setInput(e.target.value)}
        />
        <button type="submit">发送</button>
      </form>
    </>
  );
}
```

<Note>
  您可以通过消息 `parts` 上的 `reasoning` 部分访问模型的推理 token。
</Note>

根页面（`app/page.tsx`）上的 `useChat` Hook 会在用户提交消息时向您的 LLM 提供商端点（`app/api/chat/route.ts`）发起请求。然后，消息会显示在聊天 UI 中。
