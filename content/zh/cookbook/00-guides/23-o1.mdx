# OpenAI o1 入门

<Note>
  本指南涵盖 o1 模型系列，并有意保留其模型 ID。
  如需了解当前模型，请参阅 [OpenAI 提供商文档](/providers/ai-sdk-providers/openai)。

随着 [OpenAI o1 系列模型的发布](https://openai.com/index/learning-to-reason-with-llms/)，现在正是开始构建 AI 应用的最佳时机，尤其是那些需要复杂推理能力的应用。

[AI SDK](/) 是一个强大的 TypeScript 工具包，用于结合 OpenAI o1 等大型语言模型（LLM）以及 React、Next.js、Vue、Svelte、Node.js 等流行框架来构建 AI 应用。

## OpenAI o1

OpenAI 发布了一系列旨在回答前花费更多时间思考的 AI 模型。它们能够推理复杂任务，并在科学、编程和数学领域解决比以往模型更难的问题。这些模型被命名为 o1 系列，通过强化学习训练，能够“先思考再回答”。因此，它们能够在响应提示词之前产生一长串内部思维链。

API 中可用的主要推理模型是：

1. [**o1**](https://platform.openai.com/docs/models#o1)：旨在利用广泛的通用世界知识来推理难题。

### o1 模型的提示词工程

o1 模型在简洁直接的提示词下表现最佳。一些提示词工程技巧，如少样本提示或指示模型“逐步思考”，可能不会提升性能，有时甚至会适得其反。以下是一些最佳实践：

1. 保持提示词简单直接：这些模型擅长理解和响应简短、清晰的指令，无需大量引导。
2. 避免思维链提示：由于这些模型在内部进行推理，提示它们“逐步思考”或“解释你的推理”是不必要的。
3. 使用分隔符提高清晰度：使用三引号、XML 标签或章节标题等分隔符来明确标示输入的不同部分，帮助模型正确解读不同部分。
4. 限制检索增强生成（RAG）中的额外上下文：在提供额外上下文或文档时，只包含最相关的信息，以防止模型过度复杂化其响应。

## AI SDK 入门

AI SDK 是一个 TypeScript 工具包，旨在帮助开发者使用 React、Next.js、Vue、Svelte、Node.js 等构建 AI 驱动的应用。将 LLM 集成到应用中既复杂又高度依赖于你所使用的特定模型提供商。

AI SDK 抽象了模型提供商之间的差异，消除了构建聊天机器人的样板代码，并让你超越文本输出，生成丰富的交互式组件。

AI SDK 的核心是 [AI SDK Core](/docs/ai-sdk-core/overview)，它提供了统一的 API 来调用任何 LLM。下面的代码片段就是使用 AI SDK 调用 OpenAI o1 所需的全部内容：

```ts
import { generateText } from 'ai';
import { openai } from '@ai-sdk/openai';

const { text } = await generateText({
  model: openai('o1'),
  prompt: 'Explain the concept of quantum entanglement.',
});
```

<Note>
  要使用 o1 模型，你必须使用 @ai-sdk/openai 0.0.59 或更高版本，或者设置 `temperature: 1`。
</Note>

AI SDK Core 抽象了模型提供商之间的差异，让你能够专注于构建出色的应用。统一的接口也意味着你可以通过仅更改一行代码轻松切换模型。

```ts highlight="5"
import { generateText } from 'ai';
import { openai } from '@ai-sdk/openai';

const { text } = await generateText({
  model: openai('o1'),
  prompt: 'Explain the concept of quantum entanglement.',
});
```

<Note>
  系统消息会自动转换为 OpenAI 开发者消息。
</Note>

### 调整推理强度

你可以通过 `reasoningEffort` 参数控制 o1 花费的推理强度。
该参数可以设置为 `'low'`、`'medium'` 或 `'high'`，以调整模型在生成响应之前在内部推理上花费的时间和计算量。

```ts highlight="9"
import { generateText } from 'ai';
import { openai } from '@ai-sdk/openai';

// Reduce reasoning effort for faster responses
const { text } = await generateText({
  model: openai('o1'),
  prompt: 'Explain quantum entanglement briefly.',
  providerOptions: {
    openai: { reasoningEffort: 'low' },
  },
});
```

<Note>
  `reasoningEffort` 参数仅受 o1 支持，对其他模型没有影响。
</Note>

### 生成结构化数据

虽然文本生成很有用，但你可能希望生成结构化的 JSON 数据。例如，你可能想从文本中提取信息、对数据进行分类或生成合成数据。AI SDK Core 提供了 [`generateText`](/docs/reference/ai-sdk-core/generate-text) 和 [`streamText`](/docs/reference/ai-sdk-core/stream-text) 以及 `Output` 来生成结构化数据，让你能够将模型输出约束到特定的 schema。

```ts
import { generateText, Output } from 'ai';
import { openai } from '@ai-sdk/openai';
import { z } from 'zod';

const { output } = await generateText({
  model: openai('o1'),
  output: Output.object({
    schema: z.object({
      recipe: z.object({
        name: z.string(),
        ingredients: z.array(
          z.object({ name: z.string(), amount: z.string() }),
        ),
        steps: z.array(z.string()),
      }),
    }),
  }),
  prompt: 'Generate a lasagna recipe.',
});
```

这段代码片段将生成一个符合指定 zod schema 的类型安全食谱。

<Note>o1 支持结构化对象生成。</Note>

### 工具

虽然 LLM 具有令人难以置信的生成能力，但它们在处理离散任务（例如数学）和与外部世界交互（例如获取天气）方面存在困难。解决方案是：[工具](/docs/foundations/tools)，它们就像你提供给模型的程序，模型可以根据需要选择调用。

### 在 AI SDK 中使用工具

AI SDK 在其多个函数中支持工具使用，例如 [`generateText`](/docs/reference/ai-sdk-core/generate-text) 和 [`streamText`](/docs/reference/ai-sdk-core/stream-text)。通过向 `tools` 参数传递一个或多个工具，你可以扩展 LLM 的能力，使其能够执行离散任务并与外部系统交互。

以下是如何在 AI SDK 和 o1 中使用工具的示例：

```ts
import { generateText, tool } from 'ai';
import { openai } from '@ai-sdk/openai';
import { z } from 'zod';

const { text } = await generateText({
  model: openai('o1'),
  prompt: 'What is the weather like today?',
  tools: {
    getWeather: tool({
      description: 'Get the weather in a location',
      inputSchema: z.object({
        location: z.string().describe('The location to get the weather for'),
      }),
      execute: async ({ location }) => ({
        location,
        temperature: 72 + Math.floor(Math.random() * 21) - 10,
      }),
    }),
  },
});
```

在此示例中，`getWeather` 工具允许模型获取实时天气数据（为简单起见进行了模拟），增强其提供准确和最新信息的能力。

<Note>工具与 o1 兼容。</Note>

### 构建交互式界面

AI SDK Core 可以与 [AI SDK UI](/docs/ai-sdk-ui/overview) 搭配使用，后者是 AI SDK 的另一个强大组件，可简化使用 Next.js、Nuxt 和 SvelteKit 等流行框架构建聊天、补全和助手界面的过程。

AI SDK UI 提供了强大的抽象，简化了在前端管理聊天流和 UI 更新的复杂任务，使你能够更高效地开发动态的 AI 驱动界面。

通过四个主要的 Hook —— [`useChat`](/docs/reference/ai-sdk-ui/use-chat)、[`useCompletion`](/docs/reference/ai-sdk-ui/use-completion) 和 [`useObject`](/docs/reference/ai-sdk-ui/use-object) —— 你可以将实时聊天功能、文本补全、流式 JSON 和交互式助手功能整合到你的应用中。

让我们探索使用 [Next.js](https://nextjs.org)、AI SDK 和 OpenAI o1 构建聊天机器人：

```tsx filename="app/api/chat/route.ts"
import { openai } from '@ai-sdk/openai';
import {
  convertToModelMessages,
  createUIMessageStreamResponse,
  streamText,
  toUIMessageStream,
  UIMessage,
} from 'ai';

// Allow responses up to 5 minutes
export const maxDuration = 300;

export async function POST(req: Request) {
  const { messages }: { messages: UIMessage[] } = await req.json();

  const result = streamText({
    model: openai('o1'),
    messages: await convertToModelMessages(messages),
  });

  return createUIMessageStreamResponse({
    stream: toUIMessageStream({ stream: result.stream }),
  });
}
```

```tsx filename="app/page.tsx"
'use client';

import { useChat } from '@ai-sdk/react';

export default function Page() {
  const { messages, input, handleInputChange, handleSubmit, error } = useChat();

  return (
    <>
      {messages.map(message => (
        <div key={message.id}>
          {message.role === 'user' ? 'User: ' : 'AI: '}
          {message.content}
        </div>
      ))}
      <form onSubmit={handleSubmit}>
        <input name="prompt" value={input} onChange={handleInputChange} />
        <button type="submit">Submit</button>
      </form>
    </>
  );
}
```

根页面（`app/page.tsx`）上的 useChat Hook 将在用户提交消息时向你的 AI 提供商端点（`app/api/chat/route.ts`）发出请求。然后消息会显示在聊天 UI 中。
