# OpenAI o1 入门指南

随着 [OpenAI o1 系列模型的发布](https://openai.com/index/learning-to-reason-with-llms/)，现在正是构建 AI 应用的最佳时机，尤其是那些需要复杂推理能力的应用。

[AI SDK](/) 是一个强大的 TypeScript 工具包，可用于结合 OpenAI o1 等大型语言模型 (LLM) 以及 React、Next.js、Vue、Svelte、Node.js 等流行框架来构建 AI 应用。

## OpenAI o1

OpenAI 发布了一系列 AI 模型，旨在响应前花更多时间思考。它们能够推理复杂任务，并在科学、编程和数学领域解决比以往模型更棘手的问题。这些模型被称为 o1 系列，通过强化学习训练，能够“先思考再回答”。因此，它们能在响应提示词之前产生一个较长的内部思维链。

API 中可用的主要推理模型是：

1. [**o1**](https://platform.openai.com/docs/models#o1)：旨在利用广泛的世界通用知识推理难题。

### 基准测试

OpenAI o1 模型在科学推理方面表现出色，在各个领域都有令人印象深刻的表现：

- 在编程竞赛题 (Codeforces) 中排名第 89 百分位
- 在美国数学奥林匹克 (AIME) 资格赛中位列全美前 500 名学生
- 在物理、生物和化学问题基准测试 (GPQA) 中超过人类博士水平的准确率

### o1 模型的提示词工程

o1 模型在简洁直接的提示词下表现最佳。一些提示词工程技术，如少样本提示或指示模型“逐步思考”，可能不会提升性能，有时甚至会适得其反。以下是一些最佳实践：

1. 保持提示词简洁直接：该模型擅长理解并响应简短清晰的指令，无需过多指导。
2. 避免思维链提示：由于这些模型在内部进行推理，提示它们“逐步思考”或“解释你的推理”是不必要的。
3. 使用分隔符提高清晰度：使用三重引号、XML 标签或章节标题等分隔符来清晰指示输入的不同部分，帮助模型正确解释不同部分。
4. 在检索增强生成 (RAG) 中限制额外上下文：提供额外上下文或文档时，只包含最相关的信息，以防止模型过度复杂化其响应。

## AI SDK 入门

AI SDK 是一个 TypeScript 工具包，旨在帮助开发者使用 React、Next.js、Vue、Svelte、Node.js 等构建 AI 驱动的应用。将 LLM 集成到应用中很复杂，并且高度依赖于你使用的特定模型提供商。

AI SDK 抽象了不同模型提供商之间的差异，消除了构建聊天机器人的样板代码，并允许你超越文本输出，生成丰富的交互式组件。

AI SDK 的核心是 [AI SDK Core](/docs/ai-sdk-core/overview)，它提供了一个统一的 API 来调用任何 LLM。下面的代码片段就是你使用 AI SDK 调用 OpenAI o1 所需的全部内容：

```ts
import { generateText } from 'ai';
import { openai } from '@ai-sdk/openai';

const { text } = await generateText({
  model: openai('o1'),
  prompt: '解释量子纠缠的概念。',
});
```

<Note>
  要使用 o1 模型，你必须使用 @ai-sdk/openai 0.0.59 或更高版本，或者设置 `temperature: 1`。
</Note>

AI SDK Core 抽象了不同模型提供商之间的差异，让你能够专注于构建出色的应用。统一的接口也意味着你可以通过更改一行代码轻松切换模型。

```ts highlight="5"
import { generateText } from 'ai';
import { openai } from '@ai-sdk/openai';

const { text } = await generateText({
  model: openai('o1'),
  prompt: '解释量子纠缠的概念。',
});
```

<Note>
  系统消息会自动转换为 OpenAI 开发者消息。
</Note>

### 调整推理努力

你可以通过 `reasoningEffort` 参数控制 o1 付出的推理努力量。
此参数可以设置为 `'low'`、`'medium'` 或 `'high'`，以调整模型在产生响应之前在内部推理上花费的时间和计算量。

```ts highlight="9"
import { generateText } from 'ai';
import { openai } from '@ai-sdk/openai';

// 减少推理努力以获得更快的响应
const { text } = await generateText({
  model: openai('o1'),
  prompt: '简要解释量子纠缠。',
  providerOptions: {
    openai: { reasoningEffort: 'low' },
  },
});
```

<Note>
  `reasoningEffort` 参数仅受 o1 支持，对其他模型无效。
</Note>

### 生成结构化数据

虽然文本生成很有用，但你可能希望生成结构化的 JSON 数据。例如，你可能想从文本中提取信息、对数据进行分类或生成合成数据。AI SDK Core 提供了带有 `Output` 的 [`generateText`](/docs/reference/ai-sdk-core/generate-text) 和 [`streamText`](/docs/reference/ai-sdk-core/stream-text) 来生成结构化数据，允许你将模型输出约束到特定的模式。

```ts
import { generateText, Output } from 'ai';
import { openai } from '@ai-sdk/openai';
import { z } from 'zod';

const { output } = await generateText({
  model: openai('o1'),
  output: Output.object({
    schema: z.object({
      recipe: z.object({
        name: z.string(),
        ingredients: z.array(
          z.object({ name: z.string(), amount: z.string() }),
        ),
        steps: z.array(z.string()),
      }),
    }),
  }),
  prompt: '生成一个千层面食谱。',
});
```

此代码片段将生成一个符合指定 zod 模式的类型安全食谱。

<Note>结构化对象生成受 o1 支持。</Note>

### 工具

虽然 LLM 具有令人难以置信的生成能力，但它们在离散任务（例如数学）和与外部世界交互（例如获取天气）方面存在困难。解决方案是：[工具](/docs/foundations/tools)，它们就像你提供给模型的程序，模型可以根据需要选择调用。

### 在 AI SDK 中使用工具

AI SDK 在其多个函数中支持工具使用，例如 [`generateText`](/docs/reference/ai-sdk-core/generate-text) 和 [`streamText`](/docs/reference/ai-sdk-core/stream-text)。通过向 `tools` 参数传递一个或多个工具，你可以扩展 LLM 的能力，使它们能够执行离散任务并与外部系统交互。

以下是如何在 AI SDK 和 o1 中使用工具的示例：

```ts
import { generateText, tool } from 'ai';
import { openai } from '@ai-sdk/openai';
import { z } from 'zod';

const { text } = await generateText({
  model: openai('o1'),
  prompt: '今天天气怎么样？',
  tools: {
    getWeather: tool({
      description: '获取某个位置的天气',
      inputSchema: z.object({
        location: z.string().describe('要获取天气的位置'),
      }),
      execute: async ({ location }) => ({
        location,
        temperature: 72 + Math.floor(Math.random() * 21) - 10,
      }),
    }),
  },
});
```

在此示例中，`getWeather` 工具允许模型获取实时天气数据（为简单起见进行了模拟），增强了其提供准确和最新信息的能力。

<Note>工具与 o1 兼容。</Note>

### 构建交互式界面

AI SDK Core 可以与 [AI SDK UI](/docs/ai-sdk-ui/overview) 配对使用，后者是 AI SDK 的另一个强大组件，可简化使用 Next.js、Nuxt 和 SvelteKit 等流行框架构建聊天、补全和助手界面的过程。

AI SDK UI 提供了强大的抽象，简化了在前端管理聊天流和 UI 更新的复杂任务，使你能够更高效地开发动态的 AI 驱动界面。

通过四个主要的 Hook — [`useChat`](/docs/reference/ai-sdk-ui/use-chat)、[`useCompletion`](/docs/reference/ai-sdk-ui/use-completion) 和 [`useObject`](/docs/reference/ai-sdk-ui/use-object) — 你可以将实时聊天功能、文本补全、流式 JSON 和交互式助手功能集成到你的应用中。

让我们探索使用 [Next.js](https://nextjs.org)、AI SDK 和 OpenAI o1 构建一个聊天机器人：

```tsx filename="app/api/chat/route.ts"
import { openai } from '@ai-sdk/openai';
import {
  convertToModelMessages,
  createUIMessageStreamResponse,
  streamText,
  toUIMessageStream,
  UIMessage,
} from 'ai';

// 允许最长 5 分钟的响应时间
export const maxDuration = 300;

export async function POST(req: Request) {
  const { messages }: { messages: UIMessage[] } = await req.json();

  const result = streamText({
    model: openai('o1'),
    messages: await convertToModelMessages(messages),
  });

  return createUIMessageStreamResponse({
    stream: toUIMessageStream({ stream: result.stream }),
  });
}
```

```tsx filename="app/page.tsx"
'use client';

import { useChat } from '@ai-sdk/react';

export default function Page() {
  const { messages, input, handleInputChange, handleSubmit, error } = useChat();

  return (
    <>
      {messages.map(message => (
        <div key={message.id}>
          {message.role === 'user' ? '用户: ' : 'AI: '}
          {message.content}
        </div>
      ))}
      <form onSubmit={handleSubmit}>
        <input name="prompt" value={input} onChange={handleInputChange} />
        <button type="submit">提交</button>
      </form>
    </>
  );
}
```

根页面 (`app/page.tsx`) 上的 useChat Hook 会在用户提交消息时向你的 AI 提供商端点 (`app/api/chat/route.ts`) 发起请求。然后消息会显示在聊天 UI 中。
