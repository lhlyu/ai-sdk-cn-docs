# OpenAI o3-mini 入门指南

随着 [OpenAI o3-mini 模型的发布](https://openai.com/index/openai-o3-mini/)，现在正是构建 AI 应用的最佳时机，尤其是那些需要复杂 STEM 推理能力的应用。

[AI SDK](/) 是一个强大的 TypeScript 工具包，可用于结合 React、Next.js、Vue、Svelte、Node.js 等流行框架，构建基于 OpenAI o3-mini 等大语言模型（LLM）的 AI 应用。

## OpenAI o3-mini

OpenAI 最近发布了一款专为 STEM 推理优化的新 AI 模型，在科学、数学和编程任务上表现出色。o3-mini 在这些领域与 o1 性能相当，同时响应速度更快、成本更低。该模型支持工具调用、结构化输出和系统消息，是广泛应用的绝佳选择。

o3-mini 提供三种推理努力级别：

1. [**低**]：在保持可靠推理能力的同时优化速度
2. [**中**]：平衡方案，与 o1 性能水平相当
3. [**高**]：增强推理能力，在许多 STEM 领域超越 o1

### o3-mini 的提示词工程

o3-mini 模型在简洁直接的提示词下表现最佳。某些提示词工程技术（如少样本提示或指示模型“逐步思考”）可能不会提升性能，有时甚至会适得其反。以下是一些最佳实践：

1. 保持提示词简单直接：该模型擅长理解并响应简短清晰的指令，无需过多引导。
2. 避免思维链提示：由于模型内部已进行推理，无需提示其“逐步思考”或“解释推理过程”。
3. 使用分隔符增强清晰度：使用三重引号、XML 标签或章节标题等分隔符，明确区分输入的不同部分。

## AI SDK 入门

AI SDK 是一个 TypeScript 工具包，旨在帮助开发者使用 React、Next.js、Vue、Svelte、Node.js 等框架构建 AI 驱动的应用。将 LLM 集成到应用中过程复杂，且高度依赖于具体的模型提供商。

AI SDK 抽象了不同模型提供商之间的差异，消除了构建聊天机器人的样板代码，并允许你超越文本输出，生成丰富的交互式组件。

AI SDK 的核心是 [AI SDK Core](/docs/ai-sdk-core/overview)，它提供了统一的 API 来调用任何 LLM。以下代码片段展示了如何使用 AI SDK 调用 OpenAI o3-mini：

```ts
import { generateText } from 'ai';
import { openai } from '@ai-sdk/openai';

const { text } = await generateText({
  model: openai('o3-mini'),
  prompt: '解释量子纠缠的概念。',
});
```

<Note>
  要使用 o3-mini，你必须使用 @ai-sdk/openai 1.1.9 或更高版本。
</Note>

<Note>
  系统消息会自动转换为 OpenAI 开发者消息。
</Note>

### 调整推理努力

你可以通过 `reasoningEffort` 参数控制 o3-mini 的推理努力程度。
该参数可设置为 `low`、`medium` 或 `high`，以调整模型在生成响应前用于内部推理的时间和计算量。

```ts highlight="9"
import { generateText } from 'ai';
import { openai } from '@ai-sdk/openai';

// 降低推理努力以加快响应速度
const { text } = await generateText({
  model: openai('o3-mini'),
  prompt: '简要解释量子纠缠。',
  providerOptions: {
    openai: { reasoningEffort: 'low' },
  },
});
```

### 生成结构化数据

虽然文本生成很有用，但你可能希望生成结构化的 JSON 数据。例如，从文本中提取信息、对数据进行分类或生成合成数据。AI SDK Core 提供了 [`generateText`](/docs/reference/ai-sdk-core/generate-text) 和 [`streamText`](/docs/reference/ai-sdk-core/stream-text) 配合 `Output` 来生成结构化数据，从而将模型输出约束到特定模式。

```ts
import { generateText, Output } from 'ai';
import { openai } from '@ai-sdk/openai';
import { z } from 'zod';

const { output } = await generateText({
  model: openai('o3-mini'),
  output: Output.object({
    schema: z.object({
      recipe: z.object({
        name: z.string(),
        ingredients: z.array(
          z.object({ name: z.string(), amount: z.string() }),
        ),
        steps: z.array(z.string()),
      }),
    }),
  }),
  prompt: '生成一份千层面食谱。',
});
```

此代码片段将生成一个符合指定 zod 模式的类型安全食谱。

### 在 AI SDK 中使用工具

o3-mini 原生支持工具调用，使其能够与外部系统交互并执行离散任务。以下是在 AI SDK 中使用工具调用的示例：

```ts
import { generateText, tool } from 'ai';
import { openai } from '@ai-sdk/openai';
import { z } from 'zod';

const { text } = await generateText({
  model: openai('o3-mini'),
  prompt: '今天旧金山的天气怎么样？',
  tools: {
    getWeather: tool({
      description: '获取某个位置的天气',
      inputSchema: z.object({
        location: z.string().describe('要获取天气的位置'),
      }),
      execute: async ({ location }) => ({
        location,
        temperature: 72 + Math.floor(Math.random() * 21) - 10,
      }),
    }),
  },
});
```

在此示例中，`getWeather` 工具允许模型获取实时天气数据（为简化起见使用模拟数据），从而增强其提供准确和最新信息的能力。

### 构建交互式界面

AI SDK Core 可与 [AI SDK UI](/docs/ai-sdk-ui/overview)（AI SDK 的另一个强大组件）配合使用，以简化使用 Next.js、Nuxt 和 SvelteKit 等流行框架构建聊天、补全和助手界面的过程。

AI SDK UI 提供了强大的抽象，简化了在前端管理聊天流和 UI 更新的复杂任务，使你能够更高效地开发动态的 AI 驱动界面。

通过四个主要 Hook —— [`useChat`](/docs/reference/ai-sdk-ui/use-chat)、[`useCompletion`](/docs/reference/ai-sdk-ui/use-completion) 和 [`useObject`](/docs/reference/ai-sdk-ui/use-object) —— 你可以将实时聊天功能、文本补全、流式 JSON 和交互式助手功能集成到应用中。

让我们探索如何使用 [Next.js](https://nextjs.org)、AI SDK 和 OpenAI o3-mini 构建一个聊天机器人：

在一个新的 Next.js 应用中，首先安装 AI SDK 和 OpenAI 提供商：

<Snippet text="pnpm install ai @ai-sdk/openai @ai-sdk/react" />

然后，为聊天端点创建一个路由处理程序：

```tsx filename="app/api/chat/route.ts"
import { openai } from '@ai-sdk/openai';
import {
  convertToModelMessages,
  createUIMessageStreamResponse,
  streamText,
  toUIMessageStream,
  UIMessage,
} from 'ai';

// 允许最长 5 分钟的响应时间
export const maxDuration = 300;

export async function POST(req: Request) {
  const { messages }: { messages: UIMessage[] } = await req.json();

  const result = streamText({
    model: openai('o3-mini'),
    messages: await convertToModelMessages(messages),
  });

  return createUIMessageStreamResponse({
    stream: toUIMessageStream({ stream: result.stream }),
  });
}
```

最后，更新根页面（`app/page.tsx`）以使用 `useChat` Hook：

```tsx filename="app/page.tsx"
'use client';

import { useChat } from '@ai-sdk/react';

export default function Page() {
  const { messages, input, handleInputChange, handleSubmit, error } = useChat();

  return (
    <>
      {messages.map(message => (
        <div key={message.id}>
          {message.role === 'user' ? '用户: ' : 'AI: '}
          {message.content}
        </div>
      ))}
      <form onSubmit={handleSubmit}>
        <input name="prompt" value={input} onChange={handleInputChange} />
        <button type="submit">提交</button>
      </form>
    </>
  );
}
```

根页面（`app/page.tsx`）上的 useChat Hook 会在用户提交消息时向 AI 提供商端点（`app/api/chat/route.ts`）发起请求。消息随后会显示在聊天界面中。
