# DeepSeek V3.2 快速入门

随着 [DeepSeek V3.2 的发布](https://api-docs.deepseek.com/news/news251201)，现在正是开始构建需要高级推理和智能体能力的 AI 应用的最佳时机。

[AI SDK](/) 是一个强大的 TypeScript 工具包，用于结合 React、Next.js、Vue、Svelte、Node.js 等流行框架，构建基于 DeepSeek V3.2 等大语言模型（LLM）的 AI 应用。

## DeepSeek V3.2

DeepSeek V3.2 是一个前沿模型，它协调了高计算效率与卓越的推理和智能体性能。它引入了多项关键技术突破，使其性能可与 GPT-5 媲美，同时保持开源。

该系列包含两个主要变体：

- **DeepSeek V3.2**：V3.2-Exp 的官方继任者。一个在推理和推理效率之间取得平衡的优化模型，提供 GPT-5 级别的性能。

## AI SDK 快速入门

AI SDK 是一个 TypeScript 工具包，旨在帮助开发者使用 React、Next.js、Vue、Svelte、Node.js 等构建 AI 驱动的应用。将 LLM 集成到应用中很复杂，并且高度依赖于你使用的特定模型提供商。

AI SDK 抽象了不同模型提供商之间的差异，消除了构建智能体的样板代码，并允许你超越文本输出，生成丰富的交互式组件。

AI SDK 的核心是 [AI SDK Core](/docs/ai-sdk-core/overview)，它提供了一个统一的 API 来调用任何 LLM。以下代码片段是使用 AI SDK 调用 DeepSeek V3.2 所需的全部内容：

```ts
import { deepSeek } from '@ai-sdk/deepseek';
import { generateText } from 'ai';

const { text } = await generateText({
  model: deepSeek('deepseek-chat'),
  prompt: '解释 Transformer 中稀疏注意力的概念。',
});
```

### 构建交互式界面

AI SDK Core 可以与 [AI SDK UI](/docs/ai-sdk-ui/overview) 配对使用，后者是 AI SDK 的另一个强大组件，可以简化使用 Next.js、Nuxt 和 SvelteKit 等流行框架构建聊天、补全和助手界面的过程。

AI SDK UI 提供了强大的抽象，简化了在前端管理聊天流和 UI 更新的复杂任务，使你能够更高效地开发动态的 AI 驱动界面。

通过三个主要的 Hook —— [`useChat`](/docs/reference/ai-sdk-ui/use-chat)、[`useCompletion`](/docs/reference/ai-sdk-ui/use-completion) 和 [`useObject`](/docs/reference/ai-sdk-ui/use-object) —— 你可以将实时聊天功能、文本补全、流式 JSON 和交互式助手功能集成到你的应用中。

让我们探索如何使用 [Next.js](https://nextjs.org)、AI SDK 和 DeepSeek V3.2 构建一个智能体：

在一个新的 Next.js 应用中，首先安装 AI SDK 和 DeepSeek 提供商：

<Snippet text="pnpm install ai @ai-sdk/deepseek @ai-sdk/react" />

然后，为聊天端点创建一个路由处理器：

```tsx filename="app/api/chat/route.ts"
import { deepSeek } from '@ai-sdk/deepseek';
import {
  convertToModelMessages,
  createUIMessageStreamResponse,
  streamText,
  toUIMessageStream,
  UIMessage,
} from 'ai';

export async function POST(req: Request) {
  const { messages }: { messages: UIMessage[] } = await req.json();

  const result = streamText({
    model: deepSeek('deepseek-reasoner'),
    messages: await convertToModelMessages(messages),
  });

  return createUIMessageStreamResponse({
    stream: toUIMessageStream({ stream: result.stream, sendReasoning: true }),
  });
}
```

最后，更新根页面（`app/page.tsx`）以使用 `useChat` Hook：

```tsx filename="app/page.tsx"
'use client';

import { useChat } from '@ai-sdk/react';
import { useState } from 'react';

export default function Page() {
  const [input, setInput] = useState('');
  const { messages, sendMessage } = useChat();

  const handleSubmit = (e: React.FormEvent<HTMLFormElement>) => {
    e.preventDefault();
    if (input.trim()) {
      sendMessage({ text: input });
      setInput('');
    }
  };

  return (
    <>
      {messages.map(message => (
        <div key={message.id}>
          {message.role === 'user' ? '用户: ' : 'AI: '}
          {message.parts.map((part, index) => {
            if (part.type === 'text' || part.type === 'reasoning') {
              return <div key={index}>{part.text}</div>;
            }
            return null;
          })}
        </div>
      ))}
      <form onSubmit={handleSubmit}>
        <input
          name="prompt"
          value={input}
          onChange={e => setInput(e.target.value)}
        />
        <button type="submit">提交</button>
      </form>
    </>
  );
}
```

当用户提交消息时，根页面（`app/page.tsx`）上的 `useChat` Hook 会向你的 AI 提供商端点（`app/api/chat/route.ts`）发出请求。然后消息会显示在聊天 UI 中。

## 使用工具增强你的智能体

DeepSeek V3.2 的关键优势之一是其智能体能力。你可以通过添加允许模型执行特定操作或检索信息的工具来扩展智能体的功能。

### 更新你的路由处理器

让我们为你的智能体添加一个天气工具。更新你的路由处理器 `app/api/chat/route.ts`：

```tsx filename="app/api/chat/route.ts"
import { deepSeek } from '@ai-sdk/deepseek';
import {
  convertToModelMessages,
  createUIMessageStreamResponse,
  isStepCount,
  streamText,
  tool,
  toUIMessageStream,
  UIMessage,
} from 'ai';
import { z } from 'zod';

export async function POST(req: Request) {
  const { messages }: { messages: UIMessage[] } = await req.json();

  const result = streamText({
    model: deepSeek('deepseek-reasoner'),
    messages: await convertToModelMessages(messages),
    tools: {
      weather: tool({
        description: '获取某个位置的天气',
        inputSchema: z.object({
          location: z.string().describe('要获取天气的位置'),
        }),
        execute: async ({ location }) => ({
          location,
          temperature: 72,
          unit: 'fahrenheit',
        }),
      }),
    },
    stopWhen: isStepCount(5),
  });

  return createUIMessageStreamResponse({
    stream: toUIMessageStream({ stream: result.stream, sendReasoning: true }),
  });
}
```

这添加了一个天气工具，模型可以在需要时调用它。`stopWhen: isStepCount(5)` 参数允许智能体继续执行多个步骤（最多 5 步），使其能够迭代地使用工具和推理，然后停止。了解更多关于 [循环控制](/docs/agents/loop-control) 的信息，以自定义智能体何时以及如何停止执行。
