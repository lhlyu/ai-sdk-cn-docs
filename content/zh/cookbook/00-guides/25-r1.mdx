# DeepSeek R1 入门

<Note>
  DeepSeek 已于 2026 年 7 月 24 日停用 `deepseek-reasoner` API 别名。本历史指南中直接调用
  DeepSeek API 的示例仅作参考保留，已无法在当前服务上运行。对于当前的 DeepSeek 推理
  工作负载，请使用 `deepseek-v4-pro`。
</Note>

随着 [DeepSeek R1 的发布](https://api-docs.deepseek.com/news/news250528)，现在正是开始构建 AI 应用的最佳时机，尤其是那些需要复杂推理能力的应用。

[AI SDK](/) 是一个强大的 TypeScript 工具包，可用于结合 DeepSeek R1 等大型语言模型（LLM）以及 React、Next.js、Vue、Svelte、Node.js 等流行框架来构建 AI 应用。

## DeepSeek R1

DeepSeek R1 是一系列先进 AI 模型，专为应对科学、编程和数学领域的复杂推理任务而设计。这些模型经过优化，能够“先思考再回答”，生成详细的内部思维链，以帮助解决具有挑战性的问题。

该系列包含两个主要变体：

- **DeepSeek R1-Zero**：仅通过强化学习（RL）训练，未进行任何监督微调。它展现出先进的推理能力，但在可读性和格式方面可能表现不佳。
- **DeepSeek R1**：将强化学习与冷启动数据和监督微调相结合，以提升推理性能和输出的可读性。

### 基准测试

DeepSeek R1 模型在推理任务中表现出色，在关键基准测试中提供了具有竞争力的性能：

- **AIME 2024 (Pass\@1)**：79.8%
- **MATH-500 (Pass\@1)**：97.3%
- **Codeforces（百分位）**：前 4%（96.3%）
- **GPQA Diamond (Pass\@1)**：71.5%

[来源](https://github.com/deepseek-ai/DeepSeek-R1?tab=readme-ov-file#4-evaluation-results)

### DeepSeek R1 模型的提示词工程

DeepSeek R1 模型在处理结构化和简洁的提示词时表现出色。以下最佳实践有助于实现最佳性能：

1. **使用结构化格式**：利用模型偏好的输出结构，使用 `<think>` 标签表示推理过程，使用 `<answer>` 标签表示最终结果。
2. **优先使用零样本提示词**：避免使用少样本提示词，因为它可能会降低性能；相反，应直接清晰地陈述问题。
3. **明确输出预期**：通过定义所需格式来引导模型，例如使用 markdown 提高可读性，或使用类 XML 标签提高清晰度。

## AI SDK 入门

AI SDK 是一个 TypeScript 工具包，旨在帮助开发者使用 React、Next.js、Vue、Svelte、Node.js 等构建 AI 驱动的应用。将 LLM 集成到应用中非常复杂，并且在很大程度上取决于你使用的具体模型提供商。

AI SDK 抽象了模型提供商之间的差异，消除了构建聊天机器人的样板代码，并允许你超越文本输出，生成丰富的交互式组件。

AI SDK 的核心是 [AI SDK Core](/docs/ai-sdk-core/overview)，它提供了统一的 API 来调用任何 LLM。下面的代码片段就是使用 AI SDK 调用 DeepSeek R1 所需的全部内容：

```ts
import { deepSeek } from '@ai-sdk/deepseek';
import { generateText } from 'ai';

const { reasoningText, text } = await generateText({
  model: deepSeek('deepseek-reasoner'),
  prompt: 'Explain quantum entanglement.',
});
```

统一的接口还意味着，只需更改两行代码，你就可以轻松地在提供商之间切换。例如，通过 Fireworks 使用 DeepSeek R1：

```ts
import { fireworks } from '@ai-sdk/fireworks';
import {
  generateText,
  wrapLanguageModel,
  extractReasoningMiddleware,
} from 'ai';

// middleware to extract reasoning tokens
const enhancedModel = wrapLanguageModel({
  model: fireworks('accounts/fireworks/models/deepseek-r1'),
  middleware: extractReasoningMiddleware({ tagName: 'think' }),
});

const { reasoningText, text } = await generateText({
  model: enhancedModel,
  prompt: 'Explain quantum entanglement.',
});
```

或者使用 Groq 的 `deepseek-r1-distill-llama-70b` 模型：

```ts
import { groq } from '@ai-sdk/groq';
import {
  generateText,
  wrapLanguageModel,
  extractReasoningMiddleware,
} from 'ai';

// middleware to extract reasoning tokens
const enhancedModel = wrapLanguageModel({
  model: groq('deepseek-r1-distill-llama-70b'),
  middleware: extractReasoningMiddleware({ tagName: 'think' }),
});

const { reasoningText, text } = await generateText({
  model: enhancedModel,
  prompt: 'Explain quantum entanglement.',
});
```

<Note id="deepseek-r1-middleware">
AI SDK 提供了一个[中间件](/docs/ai-sdk-core/middleware)
（`extractReasoningMiddleware`），可用于从模型输出中提取推理
token。

在通过 Together AI 等第三方提供商使用 DeepSeek-R1 系列模型时，我们建议在 `extractReasoningMiddleware`
函数中使用 `startWithReasoning`
选项，因为这些提供商往往会跳过思考模式。

</Note>

### 构建交互式界面

AI SDK Core 可以与 [AI SDK UI](/docs/ai-sdk-ui/overview) 搭配使用，后者是 AI SDK 的另一个强大组件，可简化使用 Next.js、Nuxt 和 SvelteKit 等流行框架构建聊天、补全和助手界面的过程。

AI SDK UI 提供了强大的抽象，简化了在前端管理聊天流和 UI 更新的复杂任务，使你能够更高效地开发动态的 AI 驱动界面。

通过三个主要的 Hook —— [`useChat`](/docs/reference/ai-sdk-ui/use-chat)、[`useCompletion`](/docs/reference/ai-sdk-ui/use-completion) 和 [`useObject`](/docs/reference/ai-sdk-ui/use-object) —— 你可以将实时聊天功能、文本补全、流式 JSON 和交互式助手功能集成到你的应用中。

让我们来探索如何使用 [Next.js](https://nextjs.org)、AI SDK 和 DeepSeek R1 构建一个聊天机器人：

在一个新的 Next.js 应用中，首先安装 AI SDK 和 DeepSeek 提供商：

<Snippet text="pnpm install ai @ai-sdk/deepseek @ai-sdk/react" />

然后，为聊天端点创建一个路由处理器：

```tsx filename="app/api/chat/route.ts"
import { deepSeek } from '@ai-sdk/deepseek';
import {
  convertToModelMessages,
  createUIMessageStreamResponse,
  streamText,
  toUIMessageStream,
  UIMessage,
} from 'ai';

export async function POST(req: Request) {
  const { messages }: { messages: UIMessage[] } = await req.json();

  const result = streamText({
    model: deepSeek('deepseek-reasoner'),
    messages: await convertToModelMessages(messages),
  });

  return createUIMessageStreamResponse({
    stream: toUIMessageStream({
      stream: result.stream,
      sendReasoning: true,
    }),
  });
}
```

<Note>
  你可以在 `toUIMessageStream` 辅助函数中使用
  `sendReasoning: true` 将模型的推理 token 转发到客户端。
</Note>

最后，更新根页面（`app/page.tsx`）以使用 `useChat` Hook：

```tsx filename="app/page.tsx"
'use client';

import { useChat } from '@ai-sdk/react';
import { useState } from 'react';

export default function Page() {
  const [input, setInput] = useState('');
  const { messages, sendMessage } = useChat();

  const handleSubmit = (e: React.FormEvent<HTMLFormElement>) => {
    e.preventDefault();
    if (input.trim()) {
      sendMessage({ text: input });
      setInput('');
    }
  };

  return (
    <>
      {messages.map(message => (
        <div key={message.id}>
          {message.role === 'user' ? 'User: ' : 'AI: '}
          {message.parts.map((part, index) => {
            if (part.type === 'reasoning') {
              return <pre key={index}>{part.text}</pre>;
            }
            if (part.type === 'text') {
              return <span key={index}>{part.text}</span>;
            }
            return null;
          })}
        </div>
      ))}
      <form onSubmit={handleSubmit}>
        <input
          name="prompt"
          value={input}
          onChange={e => setInput(e.target.value)}
        />
        <button type="submit">Submit</button>
      </form>
    </>
  );
}
```

<Note>
  你可以通过 `message` 对象上的 `parts` 数组访问模型的推理 token，
  其中推理部分的 `type: 'reasoning'`。
</Note>

根页面（`app/page.tsx`）上的 useChat Hook 会在用户提交消息时向你的 AI 提供商端点（`app/api/chat/route.ts`）发起请求。随后消息会显示在聊天 UI 中。

## 限制

虽然 DeepSeek R1 模型功能强大，但它们也有一定的限制：

- 不支持工具调用：DeepSeek R1 无法直接与 API 或外部工具交互。
- 不支持对象生成：DeepSeek R1 不支持结构化对象生成。不过，你可以将其与支持结构化对象生成的模型（如 gpt-4o-mini）结合使用来生成对象。更多信息请参阅[使用推理模型进行结构化对象生成的配方](/cookbook/node/generate-object-reasoning)。
