# Claude 4 入门指南

随着 Claude 4 的发布，现在正是开始构建 AI 应用的最佳时机，尤其是那些需要复杂推理能力和高级智能的应用。

[AI SDK](/) 是一个强大的 TypeScript 工具包，用于结合 React、Next.js、Vue、Svelte、Node.js 等流行框架，使用 Claude 4 等大语言模型（LLM）构建 AI 应用。

## Claude 4

Claude 4 是 Anthropic 迄今为止最先进的模型系列，在推理、指令遵循、编码和知识任务方面均表现出卓越能力。Claude 4 提供 Sonnet 和 Opus 两个版本，在增强可靠性和可控性的同时，实现了业界领先的性能。Claude 4 基于 Claude 3.7 引入的扩展思考能力，通过细致、逐步的推理实现更复杂的问题求解。

Claude 4 擅长复杂推理、代码生成与分析、详细内容创作以及智能体能力，非常适合驱动复杂的 AI 工作流、面向客户的智能体，以及需要细致理解和响应的应用。Claude Opus 4 是一款出色的编码模型，在 SWE-bench（72.5%）和 Terminal-bench（43.2%）上领先，能够持续处理需要专注力和数千步骤的长时任务。Claude Sonnet 4 在 Sonnet 3.7 基础上大幅改进，在 SWE-bench 上达到 72.7%，同时兼顾性能与效率。

### Claude 4 模型的提示词工程

Claude 4 模型对清晰、明确的指令响应良好。以下最佳实践有助于获得最佳性能：

1. **提供明确的指令**：清晰说明你希望模型做什么，包括响应的具体步骤或格式。
2. **包含上下文和动机**：解释执行任务的原因，帮助模型更好地理解底层目标。
3. **避免负面示例**：提供示例时，只展示你希望看到的行为，而不是要避免的行为。

## AI SDK 入门

AI SDK 是专为帮助开发者使用 React、Next.js、Vue、Svelte、Node.js 等构建 AI 驱动应用而设计的 TypeScript 工具包。将 LLM 集成到应用中非常复杂，且高度依赖于你使用的具体模型提供商。

AI SDK 抽象了不同模型提供商之间的差异，消除了构建聊天机器人的样板代码，并允许你超越文本输出，生成丰富的交互式组件。

AI SDK 的核心是 [AI SDK Core](/docs/ai-sdk-core/overview)，它提供了调用任何 LLM 的统一 API。以下代码片段是使用 AI SDK 调用 Claude 4 Sonnet 所需的全部内容：

```ts
import { anthropic } from '@ai-sdk/anthropic';
import { generateText } from 'ai';

const { text, reasoningText, reasoning } = await generateText({
  model: anthropic('claude-sonnet-4-20250514'),
  prompt: '到 2050 年，量子计算将如何影响密码学？',
});
console.log(text);
```

### 推理能力

Claude 4 增强了 Claude 3.7 Sonnet 首次引入的扩展思考能力——通过细致、逐步的推理解决复杂问题。此外，Opus 4 和 Sonnet 4 现在都可以在扩展思考过程中使用工具，使 Claude 能够在推理和工具使用之间交替，以改进响应。你可以使用 `thinking` 提供商选项并指定以 token 为单位的思考预算来启用扩展思考。对于交错思考（Claude 可以在工具调用之间进行思考），你需要使用 `anthropic-beta` 标头启用一个测试版功能：

```ts
import { anthropic, AnthropicLanguageModelOptions } from '@ai-sdk/anthropic';
import { generateText } from 'ai';

const { text, reasoningText, reasoning } = await generateText({
  model: anthropic('claude-sonnet-4-20250514'),
  prompt: '到 2050 年，量子计算将如何影响密码学？',
  providerOptions: {
    anthropic: {
      thinking: { type: 'enabled', budgetTokens: 15000 },
    } satisfies AnthropicLanguageModelOptions,
  },
  headers: {
    'anthropic-beta': 'interleaved-thinking-2025-05-14',
  },
});

console.log(text); // 文本响应
console.log(reasoningText); // 推理文本
console.log(reasoning); // 推理详情，包括已编辑的推理内容
```

### 构建交互式界面

AI SDK Core 可以与 AI SDK 的另一个强大组件 [AI SDK UI](/docs/ai-sdk-ui/overview) 配合使用，以简化使用 Next.js、Nuxt、SvelteKit 和 SolidStart 等流行框架构建聊天、补全和助手界面的过程。

AI SDK UI 提供了强大的抽象，简化了在前端管理聊天流和 UI 更新的复杂任务，使你能够更高效地开发动态的 AI 驱动界面。

通过三个主要的 Hook —— [`useChat`](/docs/reference/ai-sdk-ui/use-chat)、[`useCompletion`](/docs/reference/ai-sdk-ui/use-completion) 和 [`useObject`](/docs/reference/ai-sdk-ui/use-object) —— 你可以将实时聊天功能、文本补全和流式 JSON 集成到你的应用中。

让我们探索如何使用 [Next.js](https://nextjs.org)、AI SDK 和 Claude Sonnet 4 构建一个聊天机器人：

在一个新的 Next.js 应用中，首先安装 AI SDK 和 Anthropic 提供商：

<Snippet text="pnpm install ai @ai-sdk/anthropic" />

然后，为聊天端点创建一个路由处理器：

```tsx filename="app/api/chat/route.ts"
import { anthropic, AnthropicLanguageModelOptions } from '@ai-sdk/anthropic';
import {
  streamText,
  convertToModelMessages,
  createUIMessageStreamResponse,
  toUIMessageStream,
  type UIMessage,
} from 'ai';

export async function POST(req: Request) {
  const { messages }: { messages: UIMessage[] } = await req.json();

  const result = streamText({
    model: anthropic('claude-sonnet-4-20250514'),
    messages: await convertToModelMessages(messages),
    headers: {
      'anthropic-beta': 'interleaved-thinking-2025-05-14',
    },
    providerOptions: {
      anthropic: {
        thinking: { type: 'enabled', budgetTokens: 15000 },
      } satisfies AnthropicLanguageModelOptions,
    },
  });

  return createUIMessageStreamResponse({
    stream: toUIMessageStream({
      stream: result.stream,
      sendReasoning: true,
    }),
  });
}
```

<Note>
  你可以通过 `toUIMessageStream` 辅助函数中的 `sendReasoning: true` 将模型的推理 token 转发到客户端。
</Note>

最后，更新根页面（`app/page.tsx`）以使用 `useChat` Hook：

```tsx filename="app/page.tsx"
'use client';

import { useChat } from '@ai-sdk/react';
import { DefaultChatTransport } from 'ai';
import { useState } from 'react';

export default function Page() {
  const [input, setInput] = useState('');
  const { messages, sendMessage } = useChat({
    transport: new DefaultChatTransport({ api: '/api/chat' }),
  });

  const handleSubmit = (e: React.FormEvent) => {
    e.preventDefault();
    if (input.trim()) {
      sendMessage({ text: input });
      setInput('');
    }
  };

  return (
    <div className="flex flex-col h-screen max-w-2xl mx-auto p-4">
      <div className="flex-1 overflow-y-auto space-y-4 mb-4">
        {messages.map(message => (
          <div
            key={message.id}
            className={`p-3 rounded-lg ${
              message.role === 'user' ? 'bg-blue-50 ml-auto' : 'bg-gray-50'
            }`}
          >
            <p className="font-semibold">
              {message.role === 'user' ? '你' : 'Claude 4'}
            </p>
            {message.parts.map((part, index) => {
              if (part.type === 'text') {
                return (
                  <div key={index} className="mt-1">
                    {part.text}
                  </div>
                );
              }
              if (part.type === 'reasoning') {
                return (
                  <pre
                    key={index}
                    className="bg-gray-100 p-2 rounded mt-2 text-xs overflow-x-auto"
                  >
                    <details>
                      <summary className="cursor-pointer">
                        查看推理过程
                      </summary>
                      {part.text}
                    </details>
                  </pre>
                );
              }
            })}
          </div>
        ))}
      </div>
      <form onSubmit={handleSubmit} className="flex gap-2">
        <input
          name="prompt"
          value={input}
          onChange={e => setInput(e.target.value)}
          className="flex-1 p-2 border rounded focus:outline-none focus:ring-2 focus:ring-blue-500"
          placeholder="向 Claude 4 提问..."
        />
        <button
          type="submit"
          className="bg-blue-500 text-white px-4 py-2 rounded hover:bg-blue-600"
        >
          发送
        </button>
      </form>
    </div>
  );
}
```

<Note>
  你可以通过消息 `parts` 上的 `reasoning` 部分访问模型的推理 token。推理文本可在 `reasoning` 部分的 `text` 属性中获取。
</Note>

根页面（`app/page.tsx`）上的 `useChat` Hook 会在用户提交消息时向你的 LLM 提供商端点（`app/api/chat/route.ts`）发起请求。然后消息会显示在聊天 UI 中。

### Claude 4 模型版本

Claude 4 提供两个版本，每个版本针对不同用例进行了优化：

- **Claude Sonnet 4**：性能均衡，适用于大多数企业应用，相比 Sonnet 3.7 有显著改进。
- **Claude Opus 4**：Anthropic 最强大的模型，也是目前最好的编码模型。擅长持续处理需要专注力和数千步骤的长时任务，能够连续工作数小时。
