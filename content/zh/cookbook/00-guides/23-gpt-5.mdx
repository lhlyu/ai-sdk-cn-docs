# OpenAI GPT-5 入门指南

随着 [OpenAI GPT-5 模型的发布](https://openai.com/index/introducing-gpt-5)，现在是构建具备高级功能（如详细程度控制、网络搜索和原生多模态理解）的 AI 应用的最佳时机。

[AI SDK](/) 是一个强大的 TypeScript 工具包，用于结合 OpenAI GPT-5 等大型语言模型 (LLM) 以及 React、Next.js、Vue、Svelte、Node.js 等流行框架来构建 AI 应用。

## OpenAI GPT-5

OpenAI 的 GPT-5 代表了其在语言模型领域的最新进展，提供了强大的新功能，包括用于定制响应长度的详细程度控制、集成的网络搜索功能、用于透明度的推理摘要，以及对文本、图像、音频和 PDF 的原生支持。该模型提供三种变体：`gpt-5`、`gpt-5-mini`（用于更快、更具成本效益的处理）和 `gpt-5-nano`（用于超高效操作）。

### GPT-5 的提示词工程

以下是有效提示的关键策略：

#### 核心原则

1.  **精确且无歧义**：避免矛盾或模糊的指令。GPT-5 在清晰、明确的指导下表现最佳。
2.  **使用结构化提示词**：利用类似 XML 的标签来组织指令的不同部分，以获得更好的清晰度。
3.  **自然语言效果最佳**：在保持精确的同时，像向熟练的同事解释一样编写提示词。

#### 提示词技巧

**1. 智能体工作流控制**

-   调整 `reasoningEffort` 参数以校准模型自主性
-   设置明确的停止条件并定义显式的工具调用预算
-   提供关于探索深度和持久性的指导

```ts
// 带有推理努力控制的示例
const result = await generateText({
  model: openai('gpt-5'),
  prompt: '分析这个复杂数据集并提供见解。',
  providerOptions: {
    openai: {
      reasoningEffort: 'high', // 增加自主探索
    },
  },
});
```

**2. 结构化提示词格式**
使用类似 XML 的标签来组织你的提示词：

```
<context_gathering>
目标：从报告中提取关键性能指标
方法：关注定量数据和同比比较
提前停止标准：找到 5 个关键指标后停止
</context_gathering>

<task>
分析所附的财务报告并识别最重要的指标。
</task>
```

**3. 工具调用最佳实践**

-   使用工具前言提供清晰的前期计划
-   为不同工具定义安全与不安全操作
-   创建关于工具调用进度的结构化更新

**4. 详细程度控制**

-   使用 `textVerbosity` 参数以编程方式控制响应长度
-   在特定上下文中需要时，使用自然语言覆盖
-   在简洁性和完整性之间取得平衡

**5. 优化工作流**

-   从一个清晰、简单的提示词开始
-   测试并识别模糊或混淆的区域
-   通过消除矛盾进行迭代优化
-   考虑对复杂提示词使用 OpenAI 的 Prompt Optimizer 工具
-   记录成功的模式以便复用

## AI SDK 入门

AI SDK 是一个 TypeScript 工具包，旨在帮助开发者使用 React、Next.js、Vue、Svelte、Node.js 等构建 AI 驱动的应用。将 LLM 集成到应用中很复杂，并且高度依赖于你使用的特定模型提供商。

AI SDK 抽象了不同模型提供商之间的差异，消除了构建聊天机器人的样板代码，并允许你超越文本输出，生成丰富的交互式组件。

AI SDK 的核心是 [AI SDK Core](/docs/ai-sdk-core/overview)，它提供了一个统一的 API 来调用任何 LLM。以下代码片段是使用 AI SDK 调用 OpenAI GPT-5 所需的全部内容：

```ts
import { generateText } from 'ai';
import { openai } from '@ai-sdk/openai';

const { text } = await generateText({
  model: openai('gpt-5'),
  prompt: '解释量子纠缠的概念。',
});
```

### 生成结构化数据

虽然文本生成很有用，但你可能希望生成结构化的 JSON 数据。例如，你可能希望从文本中提取信息、对数据进行分类或生成合成数据。AI SDK Core 提供了带有 `Output` 的 [`generateText`](/docs/reference/ai-sdk-core/generate-text) 和 [`streamText`](/docs/reference/ai-sdk-core/stream-text) 来生成结构化数据，允许你将模型输出约束到特定的模式。

```ts
import { generateText, Output } from 'ai';
import { openai } from '@ai-sdk/openai';
import { z } from 'zod';

const { output } = await generateText({
  model: openai('gpt-5'),
  output: Output.object({
    schema: z.object({
      recipe: z.object({
        name: z.string(),
        ingredients: z.array(
          z.object({ name: z.string(), amount: z.string() }),
        ),
        steps: z.array(z.string()),
      }),
    }),
  }),
  prompt: '生成一个千层面食谱。',
});
```

此代码片段将生成一个符合指定 zod 模式的类型安全食谱。

### 详细程度控制

GPT-5 的新功能之一是详细程度控制，允许你调整响应长度而无需修改提示词：

```ts
import { generateText } from 'ai';
import { openai } from '@ai-sdk/openai';

// 简洁响应
const { text: conciseText } = await generateText({
  model: openai('gpt-5'),
  prompt: '解释量子计算。',
  providerOptions: {
    openai: {
      textVerbosity: 'low', // 产生简短、最少的响应
    },
  },
});

// 详细响应
const { text: detailedText } = await generateText({
  model: openai('gpt-5'),
  prompt: '解释量子计算。',
  providerOptions: {
    openai: {
      textVerbosity: 'high', // 产生全面、详细的响应
    },
  },
});
```

### 网络搜索

GPT-5 可以通过集成的网络搜索工具访问实时信息：

```ts
import { generateText } from 'ai';
import { openai } from '@ai-sdk/openai';

const result = await generateText({
  model: openai('gpt-5'),
  prompt: '本周 AI 领域的最新发展是什么？',
  tools: {
    web_search: openai.tools.webSearch({
      searchContextSize: 'high',
    }),
  },
});

// 访问 URL 来源
const sources = result.sources;
```

### 推理摘要

为了透明地了解 GPT-5 的思考过程，可以启用推理摘要：

```ts
import { openai } from '@ai-sdk/openai';
import { streamText } from 'ai';

const result = streamText({
  model: openai('gpt-5'),
  prompt:
    '解决这个逻辑谜题：如果所有的玫瑰都是花，并且有些花凋谢得很快，那么所有的玫瑰都凋谢得快吗？',
  providerOptions: {
    openai: {
      reasoningSummary: 'detailed', // 'auto' 表示简洁，'detailed' 表示全面
    },
  },
});

// 分别流式传输推理和文本
for await (const part of result.stream) {
  if (part.type === 'reasoning') {
    console.log(part.textDelta);
  } else if (part.type === 'text-delta') {
    process.stdout.write(part.textDelta);
  }
}
```

### 在 AI SDK 中使用工具

GPT-5 开箱即用地支持工具调用，允许它与外部系统交互并执行离散任务。以下是在 AI SDK 中使用工具调用的示例：

```ts
import { generateText, tool } from 'ai';
import { openai } from '@ai-sdk/openai';
import { z } from 'zod';

const { toolResults } = await generateText({
  model: openai('gpt-5'),
  prompt: '今天旧金山的天气怎么样？',
  tools: {
    getWeather: tool({
      description: '获取某个位置的天气',
      inputSchema: z.object({
        location: z.string().describe('要获取天气的位置'),
      }),
      execute: async ({ location }) => ({
        location,
        temperature: 72 + Math.floor(Math.random() * 21) - 10,
      }),
    }),
  },
});
```

### 构建交互式界面

AI SDK Core 可以与 [AI SDK UI](/docs/ai-sdk-ui/overview) 配对使用，后者是 AI SDK 的另一个强大组件，可以简化使用 Next.js、Nuxt 和 SvelteKit 等流行框架构建聊天、补全和助手界面的过程。

AI SDK UI 提供了强大的抽象，简化了在前端管理聊天流和 UI 更新的复杂任务，使你能够更高效地开发动态的 AI 驱动界面。

通过四个主要的 Hook — [`useChat`](/docs/reference/ai-sdk-ui/use-chat)、[`useCompletion`](/docs/reference/ai-sdk-ui/use-completion) 和 [`useObject`](/docs/reference/ai-sdk-ui/use-object) — 你可以将实时聊天功能、文本补全、流式 JSON 和交互式助手功能集成到你的应用中。

让我们探索如何使用 [Next.js](https://nextjs.org)、AI SDK 和 OpenAI GPT-5 构建一个聊天机器人：

在一个新的 Next.js 应用中，首先安装 AI SDK 和 OpenAI 提供商：

<Snippet text="pnpm install ai @ai-sdk/openai @ai-sdk/react" />

然后，为聊天端点创建一个路由处理器：

```tsx filename="app/api/chat/route.ts"
import { openai } from '@ai-sdk/openai';
import {
  convertToModelMessages,
  createUIMessageStreamResponse,
  streamText,
  toUIMessageStream,
  UIMessage,
} from 'ai';

// 允许最长 30 秒的响应时间
export const maxDuration = 30;

export async function POST(req: Request) {
  const { messages }: { messages: UIMessage[] } = await req.json();

  const result = streamText({
    model: openai('gpt-5'),
    messages: await convertToModelMessages(messages),
  });

  return createUIMessageStreamResponse({
    stream: toUIMessageStream({ stream: result.stream }),
  });
}
```

最后，更新根页面 (`app/page.tsx`) 以使用 `useChat` Hook：

```tsx filename="app/page.tsx"
'use client';

import { useChat } from '@ai-sdk/react';
import { useState } from 'react';

export default function Page() {
  const [input, setInput] = useState('');
  const { messages, sendMessage } = useChat({});

  return (
    <>
      {messages.map(message => (
        <div key={message.id}>
          {message.role === 'user' ? '用户: ' : 'AI: '}
          {message.parts.map((part, index) => {
            if (part.type === 'text') {
              return <span key={index}>{part.text}</span>;
            }
            return null;
          })}
        </div>
      ))}
      <form
        onSubmit={e => {
          e.preventDefault();
          if (input.trim()) {
            sendMessage({ text: input });
            setInput('');
          }
        }}
      >
        <input
          name="prompt"
          value={input}
          onChange={e => setInput(e.target.value)}
        />
        <button type="submit">提交</button>
      </form>
    </>
  );
}
```

当用户提交消息时，根页面 (`app/page.tsx`) 上的 useChat Hook 将向你的 AI 提供商端点 (`app/api/chat/route.ts`) 发起请求。然后，消息会显示在聊天 UI 中。
