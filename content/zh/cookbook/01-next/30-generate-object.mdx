# 生成对象

你可以使用 `generateText` 配合 `Output` 来生成 JSON 等结构化数据。通过提供描述所需对象结构的 schema，SDK 将验证生成的输出，并确保其符合指定的结构。

`Output.object` 函数要求你使用 [zod](https://zod.dev) 提供 schema，zod 是一个用于定义 JavaScript 对象 schema 的库。

## 客户端

让我们创建一个简单的 React 组件，当按钮被点击时，它会向 `/api/completion` 端点发送 POST 请求。该端点将根据输入的提示词返回生成的对象，我们将展示它。

```tsx filename='app/page.tsx'
'use client';

import { useState } from 'react';

export default function Page() {
  const [generation, setGeneration] = useState();
  const [isLoading, setIsLoading] = useState(false);

  return (
    <div>
      <div
        onClick={async () => {
          setIsLoading(true);

          await fetch('/api/completion', {
            method: 'POST',
            body: JSON.stringify({
              prompt: '期末考试周期间的消息。',
            }),
          }).then(response => {
            response.json().then(json => {
              setGeneration(json.notifications);
              setIsLoading(false);
            });
          });
        }}
      >
        生成
      </div>

      {isLoading ? (
        '加载中...'
      ) : (
        <pre>{JSON.stringify(generation, null, 2)}</pre>
      )}
    </div>
  );
}
```

## 服务端

让我们为 `/api/completion` 创建一个路由处理器，它将根据输入的提示词生成一个对象。该路由将调用 `ai` 模块中的 `generateText` 函数并配合 `Output.object`，然后根据输入的提示词生成一个对象并返回它。

```typescript filename='app/api/completion/route.ts'
import { generateText, Output } from 'ai';
import { z } from 'zod';

export async function POST(req: Request) {
  const { prompt }: { prompt: string } = await req.json();

  const result = await generateText({
    model: 'openai/gpt-4o',
    instructions: '你为一个消息应用生成三条通知。',
    prompt,
    output: Output.object({
      schema: z.object({
        notifications: z.array(
          z.object({
            name: z.string().describe('虚构人物的姓名。'),
            message: z.string().describe('不要使用表情符号或链接。'),
            minutesAgo: z.number(),
          }),
        ),
      }),
    }),
  });

  return Response.json(result.output);
}
```
