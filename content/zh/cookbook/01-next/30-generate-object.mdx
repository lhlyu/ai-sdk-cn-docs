# 生成对象

你可以使用 `generateText` 配合 `Output` 来生成 JSON 等结构化数据。通过提供描述所需对象结构的 schema，SDK 将验证生成的输出，并确保其符合指定的结构。

`Output.object` 函数要求你使用 [zod](https://zod.dev) 提供 schema，这是一个用于定义 JavaScript 对象 schema 的库。

## 客户端

让我们创建一个简单的 React 组件，当点击按钮时，它会向 `/api/completion` 端点发送 POST 请求。该端点将根据输入提示词返回生成的对象，我们将显示它。

```tsx filename='app/page.tsx'
'use client';

import { useState } from 'react';

export default function Page() {
  const [generation, setGeneration] = useState();
  const [isLoading, setIsLoading] = useState(false);

  return (
    <div>
      <div
        onClick={async () => {
          setIsLoading(true);

          await fetch('/api/completion', {
            method: 'POST',
            body: JSON.stringify({
              prompt: 'Messages during finals week.',
            }),
          }).then(response => {
            response.json().then(json => {
              setGeneration(json.notifications);
              setIsLoading(false);
            });
          });
        }}
      >
        Generate
      </div>

      {isLoading ? (
        'Loading...'
      ) : (
        <pre>{JSON.stringify(generation, null, 2)}</pre>
      )}
    </div>
  );
}
```

## 服务端

让我们为 `/api/completion` 创建一个路由处理程序，它将根据输入提示词生成一个对象。该路由将调用 `generateText` 函数，并使用 `ai` 模块中的 `Output.object`，然后根据输入提示词生成一个对象并返回。

```typescript filename='app/api/completion/route.ts'
import { generateText, Output } from 'ai';
import { z } from 'zod';

export async function POST(req: Request) {
  const { prompt }: { prompt: string } = await req.json();

  const result = await generateText({
    model: 'openai/gpt-4o',
    system: 'You generate three notifications for a messages app.',
    prompt,
    output: Output.object({
      schema: z.object({
        notifications: z.array(
          z.object({
            name: z.string().describe('Name of a fictional person.'),
            message: z.string().describe('Do not use emojis or links.'),
            minutesAgo: z.number(),
          }),
        ),
      }),
    }),
  });

  return Response.json(result.output);
}
```
