# 跟踪智能体 Token 用量

<Note>
  关于构建智能体的更多信息，请参阅 [ToolLoopAgent
  文档](/docs/reference/ai-sdk-core/tool-loop-agent)。
</Note>

在智能体应用中跟踪 Token 消耗有助于监控成本并实施上下文管理策略。
本指南将展示如何跨步骤跟踪用量，并在智能体的整个生命周期中使其可用。

## 从基础智能体开始

首先，使用工具设置一个基础的 `ToolLoopAgent`。使用 `InferAgentUIMessage` 定义 `AgentUIMessage` 类型，以便在前端获得类型安全的消息，包括类型化的工具调用和结果。

```typescript filename='ai/agent.ts'
import { type InferAgentUIMessage, ToolLoopAgent, tool } from 'ai';
import { z } from 'zod';

export const agent = new ToolLoopAgent({
  model: 'anthropic/claude-haiku-4.5',
  tools: {
    greet: tool({
      description: '按姓名向某人打招呼。',
      inputSchema: z.object({ name: z.string() }),
      execute: async ({ name }) => `向 ${name} 打了招呼`,
    }),
  },
});

export type AgentUIMessage = InferAgentUIMessage<typeof agent>;
```

创建一个路由处理程序，用于流式传输智能体的响应。使用 `AgentUIMessage` 对来自客户端的消息进行类型化。

```tsx filename='app/api/chat/route.ts'
import {
  convertToModelMessages,
  createUIMessageStreamResponse,
  toUIMessageStream,
} from 'ai';
import { type AgentUIMessage, agent } from '@/ai/agent';

export async function POST(req: Request) {
  const { messages }: { messages: AgentUIMessage[] } = await req.json();

  const result = await agent.stream({
    messages: await convertToModelMessages(messages),
  });

  return createUIMessageStreamResponse({
    stream: toUIMessageStream({ stream: result.stream }),
  });
}
```

以及一个使用 `useChat` 的基础聊天界面。将 `AgentUIMessage` 作为泛型传入，以获得类型安全的消息访问，包括类型化的工具调用和结果。

```tsx filename='app/page.tsx'
'use client';

import { type AgentUIMessage } from '@/ai/agent';
import { useChat } from '@ai-sdk/react';
import { useState } from 'react';

export default function Chat() {
  const [input, setInput] = useState('');
  const { messages, sendMessage } = useChat<AgentUIMessage>();

  return (
    <div>
      {messages.map(m => (
        <div key={m.id}>
          <strong>{m.role}:</strong>
          {m.parts.map(
            (p, i) => p.type === 'text' && <span key={i}>{p.text}</span>,
          )}
        </div>
      ))}
      <form
        onSubmit={e => {
          e.preventDefault();
          sendMessage({ text: input });
          setInput('');
        }}
      >
        <input value={input} onChange={e => setInput(e.target.value)} />
      </form>
    </div>
  );
}
```

## 通过消息元数据访问步骤间的用量

要跟踪 Token 用量，请使用 `messageMetadata` 回调将其附加到每条消息。首先，定义一个元数据类型，并将其作为第二个泛型参数传递给 `InferAgentUIMessage`。

```typescript filename='ai/agent.ts' highlight="1,15-16"
import {
  type InferAgentUIMessage,
  type LanguageModelUsage,
  ToolLoopAgent,
  tool,
} from 'ai';
import { z } from 'zod';

export const agent = new ToolLoopAgent({
  model: 'anthropic/claude-haiku-4.5',
  tools: {
    greet: tool({
      description: '按姓名向某人打招呼。',
      inputSchema: z.object({ name: z.string() }),
      execute: async ({ name }) => `向 ${name} 打了招呼`,
    }),
  },
});

type AgentMetadata = { usage: LanguageModelUsage };
export type AgentUIMessage = InferAgentUIMessage<typeof agent, AgentMetadata>;
```

现在，将 `messageMetadata` 回调添加到路由处理程序。将 `AgentUIMessage` 作为消息泛型传递给 `toUIMessageStream`，以对回调进行类型化。当一个步骤完成时，`finish-step` 部分包含用量数据，你可以将其包含在消息元数据中。

```tsx filename='app/api/chat/route.ts' highlight="16-25"
import {
  convertToModelMessages,
  createUIMessageStreamResponse,
  toUIMessageStream,
  type ToolSet,
} from 'ai';
import { type AgentUIMessage, agent } from '@/ai/agent';

export async function POST(req: Request) {
  const { messages }: { messages: AgentUIMessage[] } = await req.json();

  const result = await agent.stream({
    messages: await convertToModelMessages(messages),
  });

  return createUIMessageStreamResponse({
    stream: toUIMessageStream<ToolSet, AgentUIMessage>({
      stream: result.stream,
      messageMetadata: ({ part }) => {
        if (part.type === 'finish-step') {
          return { usage: part.usage };
        }
      },
    }),
  });
}
```

现在，你可以在客户端访问元数据。`AgentUIMessage` 类型已包含元数据形状，使你能够类型安全地访问 `m.metadata.usage`。

```typescript filename='app/page.tsx' highlight="17-19"
'use client';

import { type AgentUIMessage } from '@/ai/agent';
import { useChat } from '@ai-sdk/react';
import { useState } from 'react';

export default function Chat() {
  const [input, setInput] = useState('');
  const { messages, sendMessage } = useChat<AgentUIMessage>();

  return (
    <div>
      {messages.map((m) => (
        <div key={m.id}>
          <strong>{m.role}:</strong>
          {m.parts.map((p, i) => p.type === 'text' && <span key={i}>{p.text}</span>)}
          {m.metadata?.usage && (
            <div>输入 Token：{m.metadata.usage.inputTokens}</div>
          )}
        </div>
      ))}
      <form onSubmit={(e) => {
        e.preventDefault();
        sendMessage({ text: input });
        setInput('');
      }}>
        <input value={input} onChange={(e) => setInput(e.target.value)} />
      </form>
    </div>
  );
}
```

## 通过调用选项将用量传回智能体

现在，你已在 UI 中显示了用量数据。但如果你想对这些数据采取行动呢？例如，你可能希望在接近 Token 限制时实现上下文压缩。

要操作消息或应用上下文管理策略，你可以使用 `prepareStep` 回调。然而，`prepareStep` 只能访问当前运行中的步骤。在新请求的第一步中，`steps` 为空，导致你无法了解对话在之前的请求中累积了多少 Token。

为了解决这个问题，将之前消息的用量传回智能体。使用 `callOptionsSchema` 定义数据形状，并使用 `prepareCall` 使其在 `context` 上可用，这样 `prepareStep` 就可以访问它。

```typescript filename='ai/agent.ts' highlight="11-13,21-26"
import {
  type InferAgentUIMessage,
  type LanguageModelUsage,
  ToolLoopAgent,
  tool,
} from 'ai';
import { z } from 'zod';

export const agent = new ToolLoopAgent({
  model: 'anthropic/claude-haiku-4.5',
  callOptionsSchema: z.object({
    lastInputTokens: z.number(),
  }),
  tools: {
    greet: tool({
      description: '按姓名向某人打招呼。',
      inputSchema: z.object({ name: z.string() }),
      execute: async ({ name }) => `向 ${name} 打了招呼`,
    }),
  },
  prepareCall: ({ options, ...settings }) => {
    return {
      ...settings,
      context: { lastInputTokens: options.lastInputTokens },
    };
  },
});

type AgentMetadata = { usage: LanguageModelUsage };
export type AgentUIMessage = InferAgentUIMessage<typeof agent, AgentMetadata>;
```

从之前的消息中提取最后一个输入 Token 计数，并将其传递给智能体。

```tsx filename='app/api/chat/route.ts' highlight="12-14,18-20"
import {
  convertToModelMessages,
  createUIMessageStreamResponse,
  toUIMessageStream,
  type ToolSet,
} from 'ai';
import { type AgentUIMessage, agent } from '@/ai/agent';

export async function POST(req: Request) {
  const { messages }: { messages: AgentUIMessage[] } = await req.json();

  const lastInputTokens =
    messages.filter(m => m.role === 'assistant').at(-1)?.metadata?.usage
      ?.inputTokens ?? 0;

  const result = await agent.stream({
    messages: await convertToModelMessages(messages),
    options: {
      lastInputTokens,
    },
  });

  return createUIMessageStreamResponse({
    stream: toUIMessageStream<ToolSet, AgentUIMessage>({
      stream: result.stream,
      messageMetadata: ({ part }) => {
        if (part.type === 'finish-step') {
          return { usage: part.usage };
        }
      },
    }),
  });
}
```

## 在 prepareStep 和工具中访问用量

通过将用量放在 `context` 上，你可以在 `prepareStep` 中访问它，以做出关于上下文管理的决策，或者将其传递给工具。

```typescript filename='ai/agent.ts' highlight="9-11,31-40"
import {
  type InferAgentUIMessage,
  type LanguageModelUsage,
  ToolLoopAgent,
  tool,
} from 'ai';
import { z } from 'zod';

type TContext = {
  lastInputTokens: number;
};

export const agent = new ToolLoopAgent({
  model: 'anthropic/claude-haiku-4.5',
  callOptionsSchema: z.object({
    lastInputTokens: z.number(),
  }),
  tools: {
    greet: tool({
      description: '按姓名向某人打招呼。',
      inputSchema: z.object({ name: z.string() }),
      execute: async ({ name }) => `向 ${name} 打了招呼`,
    }),
  },
  prepareCall: ({ options, ...settings }) => {
    return {
      ...settings,
      context: { lastInputTokens: options.lastInputTokens },
    };
  },
  prepareStep: ({ steps, context }) => {
    const lastStep = steps.at(-1);
    const lastStepUsage =
      lastStep?.usage?.inputTokens ??
      (context as TContext)?.lastInputTokens ??
      0;
    console.log('上一步输入 Token：', lastStepUsage);
    // 你可以使用此信息来实现上下文压缩策略
    return {
      context: {
        ...context,
        lastStepUsage,
      },
    };
  },
});

type AgentMetadata = { usage: LanguageModelUsage };
export type AgentUIMessage = InferAgentUIMessage<typeof agent, AgentMetadata>;
```

`prepareStep` 回调在每个步骤之前运行，使你能够访问：

- `steps`：所有之前的步骤及其用量数据
- `context`：由 `prepareCall` 设置的上下文（来自上一个请求的用量）

这使你能够跟踪整个对话生命周期中的 Token 消耗，并在接近 Token 限制时实施上下文压缩等策略。
