# 使用 Next.js 实现人在回路

在构建智能体系统时，添加人在回路（HITL）功能非常重要，以确保用户可以在系统执行操作之前批准这些操作。AI SDK 通过工具上的 `needsApproval` 属性为工具执行审批提供了内置支持。

本教程演示如何使用 AI SDK 的原生工具执行审批功能，为 Next.js 聊天机器人添加人工审批步骤。

## 背景

为了理解如何实现此功能，让我们看看在 Next.js 聊天机器人应用中，工具调用是如何与 AI SDK 配合工作的。

在前端，使用 `useChat` Hook 来管理消息状态和用户交互。

```tsx filename="app/page.tsx"
'use client';

import { useChat } from '@ai-sdk/react';
import { DefaultChatTransport } from 'ai';
import { useState } from 'react';

export default function Chat() {
  const { messages, sendMessage } = useChat({
    transport: new DefaultChatTransport({
      api: '/api/chat',
    }),
  });
  const [input, setInput] = useState('');

  return (
    <div>
      <div>
        {messages?.map(m => (
          <div key={m.id}>
            <strong>{`${m.role}: `}</strong>
            {m.parts?.map((part, i) => {
              switch (part.type) {
                case 'text':
                  return <div key={i}>{part.text}</div>;
              }
            })}
            <br />
          </div>
        ))}
      </div>

      <form
        onSubmit={e => {
          e.preventDefault();
          if (input.trim()) {
            sendMessage({ text: input });
            setInput('');
          }
        }}
      >
        <input
          value={input}
          placeholder="说点什么..."
          onChange={e => setInput(e.target.value)}
        />
      </form>
    </div>
  );
}
```

在后端，创建一个使用 `streamText` 并返回 `UIMessageStreamResponse` 的路由处理器。该工具具有一个 `execute` 函数，当模型调用它时会自动运行。

```ts filename="app/api/chat/route.ts"
import {
  streamText,
  tool,
  createUIMessageStreamResponse,
  toUIMessageStream,
} from 'ai';
import { openai } from '@ai-sdk/openai';
import { z } from 'zod';

export async function POST(req: Request) {
  const { messages } = await req.json();

  const result = streamText({
    model: openai('gpt-4o'),
    messages,
    tools: {
      getWeatherInformation: tool({
        description: '向用户展示指定城市的天气',
        inputSchema: z.object({ city: z.string() }),
        execute: async ({ city }) => {
          const weatherOptions = ['晴天', '多云', '下雨', '下雪'];
          return weatherOptions[
            Math.floor(Math.random() * weatherOptions.length)
          ];
        },
      }),
    },
  });

  return createUIMessageStreamResponse({
    stream: toUIMessageStream({ stream: result.stream }),
  });
}
```

当用户向 LLM 询问纽约的天气时，模型会生成带有城市参数的调用。AI SDK 随后自动运行 `execute` 函数并返回结果。

要添加 HITL 步骤，您可以使用 `needsApproval` 在工具调用和工具执行之间添加审批门控。

## 添加工具执行审批

### 服务器端设置

在工具定义中添加 `needsApproval: true`。该工具保留其 `execute` 函数，但 SDK 会暂停执行，直到用户批准。

```ts filename="app/api/chat/route.ts" highlight="20"
import {
  streamText,
  tool,
  createUIMessageStreamResponse,
  toUIMessageStream,
} from 'ai';
import { openai } from '@ai-sdk/openai';
import { z } from 'zod';

export async function POST(req: Request) {
  const { messages } = await req.json();

  const result = streamText({
    model: openai('gpt-4o'),
    messages,
    tools: {
      getWeatherInformation: tool({
        description: '向用户展示指定城市的天气',
        inputSchema: z.object({ city: z.string() }),
        needsApproval: true,
        execute: async ({ city }) => {
          const weatherOptions = ['晴天', '多云', '下雨', '下雪'];
          return weatherOptions[
            Math.floor(Math.random() * weatherOptions.length)
          ];
        },
      }),
    },
  });

  return createUIMessageStreamResponse({
    stream: toUIMessageStream({ stream: result.stream }),
  });
}
```

当模型调用此工具时，SDK 不会运行 `execute` 函数，而是向客户端发送一个处于 `approval-requested` 状态的工具部分。只有在用户响应后，该工具才会执行。

### 客户端审批界面

在前端，检查 `approval-requested` 状态并渲染批准/拒绝按钮。使用 `useChat` Hook 中的 `addToolApprovalResponse` 来发送用户的决定。

```tsx filename="app/page.tsx"
'use client';

import { useChat } from '@ai-sdk/react';
import {
  DefaultChatTransport,
  lastAssistantMessageIsCompleteWithApprovalResponses,
} from 'ai';
import { useState } from 'react';

export default function Chat() {
  const { messages, sendMessage, addToolApprovalResponse } = useChat({
    transport: new DefaultChatTransport({
      api: '/api/chat',
    }),
    sendAutomaticallyWhen: lastAssistantMessageIsCompleteWithApprovalResponses,
  });
  const [input, setInput] = useState('');

  return (
    <div>
      <div>
        {messages?.map(m => (
          <div key={m.id}>
            <strong>{`${m.role}: `}</strong>
            {m.parts?.map((part, i) => {
              if (part.type === 'text') {
                return <div key={i}>{part.text}</div>;
              }
              if (part.type === 'tool-getWeatherInformation') {
                switch (part.state) {
                  case 'approval-requested':
                    return (
                      <div key={part.toolCallId}>
                        获取 {part.input.city} 的天气信息？
                        <div>
                          <button
                            onClick={() =>
                              addToolApprovalResponse({
                                id: part.approval.id,
                                approved: true,
                              })
                            }
                          >
                            批准
                          </button>
                          <button
                            onClick={() =>
                              addToolApprovalResponse({
                                id: part.approval.id,
                                approved: false,
                              })
                            }
                          >
                            拒绝
                          </button>
                        </div>
                      </div>
                    );
                  case 'output-available':
                    return (
                      <div key={part.toolCallId}>
                        {part.input.city} 的天气：{part.output}
                      </div>
                    );
                  case 'output-denied':
                    return (
                      <div key={part.toolCallId}>
                        {part.input.city} 的天气请求已被拒绝。
                      </div>
                    );
                }
              }
            })}
            <br />
          </div>
        ))}
      </div>

      <form
        onSubmit={e => {
          e.preventDefault();
          if (input.trim()) {
            sendMessage({ text: input });
            setInput('');
          }
        }}
      >
        <input
          value={input}
          placeholder="说点什么..."
          onChange={e => setInput(e.target.value)}
        />
      </form>
    </div>
  );
}
```

以下是审批流程的工作原理：

1. 模型调用 `getWeatherInformation` 并传入城市
2. 工具部分进入 `approval-requested` 状态，并带有 `approval.id`
3. UI 渲染批准/拒绝按钮
4. 当用户点击按钮时，`addToolApprovalResponse` 记录决定
5. `sendAutomaticallyWhen` 检测到所有审批都已响应并发送消息
6. 在服务器端，如果批准，`execute` 函数运行并返回结果。如果拒绝，模型会收到拒绝通知并相应回应。

### 审批后自动提交

`sendAutomaticallyWhen` 选项配合 `lastAssistantMessageIsCompleteWithApprovalResponses` 会在最后一步中的所有工具审批都已响应后自动发送消息。如果没有此选项，您需要在每次审批后手动调用 `sendMessage()`。

```tsx
import { useChat } from '@ai-sdk/react';
import { lastAssistantMessageIsCompleteWithApprovalResponses } from 'ai';

const { messages, addToolApprovalResponse } = useChat({
  sendAutomaticallyWhen: lastAssistantMessageIsCompleteWithApprovalResponses,
});
```

<Note>
  如果您在批准工具执行后没有任何反应，请确保您手动调用了
  `sendMessage` 或在 `useChat` Hook 上配置了 `sendAutomaticallyWhen`。
</Note>

### 动态审批

您可以通过向 `needsApproval` 提供异步函数，根据工具的输入来条件化审批：

```ts filename="app/api/chat/route.ts" highlight="23"
import {
  streamText,
  tool,
  createUIMessageStreamResponse,
  toUIMessageStream,
} from 'ai';
import { openai } from '@ai-sdk/openai';
import { z } from 'zod';

export async function POST(req: Request) {
  const { messages } = await req.json();

  const result = streamText({
    model: openai('gpt-4o'),
    messages,
    tools: {
      processPayment: tool({
        description: '处理付款',
        inputSchema: z.object({
          amount: z.number(),
          recipient: z.string(),
        }),
        needsApproval: async ({ amount }) => amount > 1000,
        execute: async ({ amount, recipient }) => {
          return `已向 ${recipient} 处理 $${amount} 的付款。`;
        },
      }),
    },
  });

  return createUIMessageStreamResponse({
    stream: toUIMessageStream({ stream: result.stream }),
  });
}
```

在此示例中，只有超过 $1000 的付款需要审批。较小金额会自动执行。

### 处理拒绝

当用户拒绝工具执行时，模型会收到拒绝通知并可以相应回应。为了防止模型重试相同的工具调用，请添加一条指令：

```ts highlight="5-6"
const result = streamText({
  model: openai('gpt-4o'),
  messages,
  instructions:
    '当工具执行未被用户批准时，不要重试。' +
    '告知用户该操作未被执行。',
  tools: {
    // ...
  },
});
```
