# 流式文本

文本生成有时需要较长时间才能完成，尤其是在生成多段文本时。在这种情况下，将文本生成过程实时流式传输到客户端会非常有用。这样，客户端可以在生成过程中逐步显示生成的文本，而不是让用户等待全部生成完成后再显示结果。

## 客户端

让我们创建一个简单的 React 组件，从 `@ai-sdk/react` 模块导入 `useCompletion` Hook。当按钮被点击时，`useCompletion` Hook 将调用 `/api/completion` 端点。该端点将根据输入的提示词生成文本，并将其流式传输到客户端。

```tsx filename="app/page.tsx"
'use client';

import { useCompletion } from '@ai-sdk/react';

export default function Page() {
  const { completion, complete } = useCompletion({
    api: '/api/completion',
  });

  return (
    <div>
      <div
        onClick={async () => {
          await complete('为什么天空是蓝色的？');
        }}
      >
        生成
      </div>

      {completion}
    </div>
  );
}
```

## 服务端

让我们为 `/api/completion` 创建一个路由处理器，它将根据输入的提示词生成文本。该路由将调用 `ai` 模块中的 `streamText` 函数，该函数将根据输入的提示词生成文本，并将其流式传输到客户端。

```typescript filename='app/api/completion/route.ts'
import {
  createUIMessageStreamResponse,
  streamText,
  toUIMessageStream,
} from 'ai';

export async function POST(req: Request) {
  const { prompt }: { prompt: string } = await req.json();

  const result = streamText({
    model: 'openai/gpt-4o',
    instructions: '你是一个乐于助人的助手。',
    prompt,
  });

  return createUIMessageStreamResponse({
    stream: toUIMessageStream({ stream: result.stream }),
  });
}
```
