# 流式传输文本

文本生成有时可能需要很长时间才能完成，尤其是当你生成几段文字时。在这种情况下，将文本生成过程实时流式传输到客户端会很有用。这允许客户端在文本生成时即时显示生成的文本，而不必让用户等待生成完成后再显示结果。

## 客户端

让我们创建一个简单的 React 组件，从 `@ai-sdk/react` 模块导入 `useCompletion` Hook。当点击按钮时，`useCompletion` Hook 将调用 `/api/completion` 端点。该端点将根据输入提示词生成文本，并将其流式传输到客户端。

```tsx filename="app/page.tsx"
'use client';

import { useCompletion } from '@ai-sdk/react';

export default function Page() {
  const { completion, complete } = useCompletion({
    api: '/api/completion',
  });

  return (
    <div>
      <div
        onClick={async () => {
          await complete('Why is the sky blue?');
        }}
      >
        Generate
      </div>

      {completion}
    </div>
  );
}
```

## 服务端

让我们为 `/api/completion` 创建一个路由处理器，它将根据输入提示词生成文本。该路由将调用 `ai` 模块中的 `streamText` 函数，然后根据输入提示词生成文本并将其流式传输到客户端。

```typescript filename='app/api/completion/route.ts'
import {
  createUIMessageStreamResponse,
  streamText,
  toUIMessageStream,
} from 'ai';

export async function POST(req: Request) {
  const { prompt }: { prompt: string } = await req.json();

  const result = streamText({
    model: 'openai/gpt-6-astra',
    instructions: 'You are a helpful assistant.',
    prompt,
  });

  return createUIMessageStreamResponse({
    stream: toUIMessageStream({ stream: result.stream }),
  });
}
```
