# 带记忆化的 Markdown 聊天机器人

在使用 Next.js 和 AI SDK 构建聊天机器人时，您可能希望使用 `react-markdown` 之类的库以 Markdown 格式渲染模型的响应。然而，这可能会对性能产生负面影响，因为每次从流式响应中接收到新的 token 时，Markdown 都会被重新渲染。

随着对话变得越来越长、越来越复杂，这种性能影响会呈指数级恶化，因为每次收到新的 token 时，整个对话历史都会被重新渲染。

本食谱使用记忆化——一种性能优化技术，将昂贵函数调用的结果缓存并复用，以避免不必要的重新计算。在这种情况下，解析后的 Markdown 块会被记忆化，以防止它们在每次 token 更新时被重新解析和重新渲染，这意味着一旦一个块被完全解析，它就会被缓存并复用，而不是重新生成。这种方法通过消除冗余的解析和渲染操作，显著提高了长对话的渲染性能。

## 安装

首先，安装 Markdown 渲染和解析所需的依赖：

```bash
npm install react-markdown marked
```

## 服务端

在服务端，您使用一个简单的路由处理器，从语言模型流式传输响应。

```tsx filename='app/api/chat/route.ts'
import {
  convertToModelMessages,
  createUIMessageStreamResponse,
  streamText,
  toUIMessageStream,
  type UIMessage,
} from 'ai';

export async function POST(req: Request) {
  const { messages }: { messages: UIMessage[] } = await req.json();

  const result = streamText({
    instructions:
      'You are a helpful assistant. Respond to the user in Markdown format.',
    model: 'openai/gpt-4o',
    messages: await convertToModelMessages(messages),
  });

  return createUIMessageStreamResponse({
    stream: toUIMessageStream({ stream: result.stream }),
  });
}
```

## 记忆化 Markdown 组件

接下来，创建一个记忆化的 markdown 组件，该组件将原始 Markdown 文本拆分为块，并且仅在内容实际发生变化时更新。该组件使用 `marked` 库将 Markdown 内容拆分为块，以识别离散的 Markdown 元素，然后使用 React 的记忆化功能来优化重新渲染，仅更新实际发生变化的块。

```tsx filename='components/memoized-markdown.tsx'
import { marked } from 'marked';
import { memo, useMemo } from 'react';
import ReactMarkdown from 'react-markdown';

function parseMarkdownIntoBlocks(markdown: string): string[] {
  const tokens = marked.lexer(markdown);
  return tokens.map(token => token.raw);
}

const MemoizedMarkdownBlock = memo(
  ({ content }: { content: string }) => {
    return <ReactMarkdown>{content}</ReactMarkdown>;
  },
  (prevProps, nextProps) => {
    if (prevProps.content !== nextProps.content) return false;
    return true;
  },
);

MemoizedMarkdownBlock.displayName = 'MemoizedMarkdownBlock';

export const MemoizedMarkdown = memo(
  ({ content, id }: { content: string; id: string }) => {
    const blocks = useMemo(() => parseMarkdownIntoBlocks(content), [content]);

    return blocks.map((block, index) => (
      <MemoizedMarkdownBlock content={block} key={`${id}-block_${index}`} />
    ));
  },
);

MemoizedMarkdown.displayName = 'MemoizedMarkdown';
```

## 客户端

最后，在客户端，使用 `useChat` Hook 来管理聊天状态并渲染聊天界面。您可以使用 `MemoizedMarkdown` 组件以 Markdown 格式渲染消息内容，而不会影响性能。此外，您可以将表单渲染在单独的组件中，以避免触发聊天消息的不必要重新渲染。您还可以使用 `throttle` 选项，该选项会将数据更新限制在指定的时间间隔内，有助于管理渲染性能。

```typescript filename='app/page.tsx'
"use client";

import { Chat, useChat } from "@ai-sdk/react";
import { DefaultChatTransport } from "ai";
import { useState } from "react";
import { MemoizedMarkdown } from "@/components/memoized-markdown";

const chat = new Chat({
  transport: new DefaultChatTransport({
    api: "/api/chat",
  }),
});

export default function Page() {
  const { messages } = useChat({ chat, throttle: 50 });

  return (
    <div className="flex flex-col w-full max-w-xl py-24 mx-auto stretch">
      <div className="space-y-8 mb-4">
        {messages.map((message) => (
          <div key={message.id}>
            <div className="font-bold mb-2">
              {message.role === "user" ? "You" : "Assistant"}
            </div>
            <div className="prose space-y-2">
              {message.parts.map((part) => {
                if (part.type === "text") {
                  return (
                    <MemoizedMarkdown
                      key={`${message.id}-text`}
                      id={message.id}
                      content={part.text}
                    />
                  );
                }
              })}
            </div>
          </div>
        ))}
      </div>

      <MessageInput />
    </div>
  );
}

const MessageInput = () => {
  const [input, setInput] = useState("");
  const { sendMessage } = useChat({ chat });

  return (
    <form
      onSubmit={(event) => {
        event.preventDefault();
        sendMessage({
          text: input,
        });
        setInput("");
      }}
    >
      <input
        className="fixed bottom-0 w-full max-w-xl p-2 mb-8 dark:bg-zinc-900 border border-zinc-300 dark:border-zinc-800 rounded shadow-xl"
        placeholder="Say something..."
        value={input}
        onChange={(event) => {
          setInput(event.target.value);
        }}
      />
    </form>
  );
};
```

<Note>
  通过使用相同的 `Chat` 实例，两个组件之间共享聊天状态。这允许您将表单和聊天消息拆分为独立的组件，同时保持状态同步。
</Note>
