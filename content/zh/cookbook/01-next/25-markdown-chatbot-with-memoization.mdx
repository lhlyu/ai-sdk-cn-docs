# 使用 Streamdown 的 Markdown 聊天机器人

[Streamdown](https://streamdown.ai) 可以在语言模型流式输出时渲染 Markdown。它能够处理不完整的 Markdown 语法，并[对 Markdown 块进行记忆化](https://streamdown.ai/docs/memoization)，使未更改的块可以跳过重新渲染。Streamdown 在其默认的流式传输模式下提供此行为。

从 [Stream Text with Chat Prompt](/cookbook/next/stream-text-with-chat-prompt) 配方开始，搭建 `/api/chat` 路由。然后使用 Streamdown 在客户端渲染文本部分。

## 安装

在你的 Next.js 应用中安装 Streamdown：

```bash
npm install streamdown
```

对于 Tailwind CSS v4，将 Streamdown 添加到全局样式表的 sources 中：

```css filename='app/globals.css'
@import 'tailwindcss';
@source '../node_modules/streamdown/dist/*.js';
```

`@source` 路径相对于样式表。如果你使用 `src/app` 目录或 monorepo，请相应调整。有关 Tailwind CSS v3 配置，请参阅 [Streamdown 安装指南](https://streamdown.ai/docs/getting-started)。

## 客户端

将每个文本部分传递给 `Streamdown`。当该部分正在流式传输时设置 `isAnimating`，以便 Streamdown 在文本完成之前禁用交互控件。

```tsx filename='app/page.tsx'
'use client';

import { useChat } from '@ai-sdk/react';
import { DefaultChatTransport } from 'ai';
import { useState } from 'react';
import { Streamdown } from 'streamdown';

export default function Page() {
  const [input, setInput] = useState('');
  const { messages, sendMessage } = useChat({
    transport: new DefaultChatTransport({ api: '/api/chat' }),
  });

  return (
    <div>
      {messages.map(message => (
        <div key={message.id}>
          <div>{message.role === 'user' ? 'You' : 'Assistant'}</div>
          {message.parts.map((part, index) =>
            part.type === 'text' ? (
              <Streamdown
                key={`${message.id}-${index}`}
                isAnimating={part.state === 'streaming'}
              >
                {part.text}
              </Streamdown>
            ) : null,
          )}
        </div>
      ))}

      <form
        onSubmit={event => {
          event.preventDefault();
          sendMessage({ text: input });
          setInput('');
        }}
      >
        <input
          value={input}
          onChange={event => setInput(event.target.value)}
          placeholder="Say something..."
        />
        <button type="submit">Send</button>
      </form>
    </div>
  );
}
```

有关语法高亮、数学公式或 Mermaid 图表，请参阅 [Streamdown 的插件](https://streamdown.ai/docs/plugins)。
