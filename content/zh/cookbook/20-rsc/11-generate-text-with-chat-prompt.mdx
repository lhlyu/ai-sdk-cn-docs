# 使用聊天提示词生成文本

之前，我们可以使用单条消息提示词、系统提示词或两者的组合来生成文本和对象。然而，有时您可能希望基于一系列消息来生成文本。

聊天补全允许您基于一系列消息生成文本。这一系列消息可以是任意数量的系统之间的任意交互序列，但最流行且最贴近实际应用的场景是代表用户与模型之间对话的一系列消息。

## 客户端

让我们创建一个用户与模型之间的简单对话，并放置一个按钮来调用 `continueConversation`。

```tsx filename='app/page.tsx'
'use client';

import { useState } from 'react';
import { Message, continueConversation } from './actions';

// Allow streaming responses up to 30 seconds
export const maxDuration = 30;

export default function Home() {
  const [conversation, setConversation] = useState<Message[]>([]);
  const [input, setInput] = useState<string>('');

  return (
    <div>
      <div>
        {conversation.map((message, index) => (
          <div key={index}>
            {message.role}: {message.content}
          </div>
        ))}
      </div>

      <div>
        <input
          type="text"
          value={input}
          onChange={event => {
            setInput(event.target.value);
          }}
        />
        <button
          onClick={async () => {
            const { messages } = await continueConversation([
              ...conversation,
              { role: 'user', content: input },
            ]);

            setConversation(messages);
          }}
        >
          Send Message
        </button>
      </div>
    </div>
  );
}
```

## 服务器

现在，让我们实现 `continueConversation` 函数，该函数将用户的消息插入对话中并生成响应。

```typescript filename='app/actions.ts'
'use server';

import { generateText } from 'ai';

export interface Message {
  role: 'user' | 'assistant';
  content: string;
}

export async function continueConversation(history: Message[]) {
  'use server';

  const { text } = await generateText({
    model: 'openai/gpt-5.4',
    instructions: 'You are a friendly assistant!',
    messages: history,
  });

  return {
    messages: [
      ...history,
      {
        role: 'assistant' as const,
        content: text,
      },
    ],
  };
}
```
