# 使用聊天提示词生成文本

之前，我们能够通过单条消息提示词、系统提示词或两者结合来生成文本和对象。但有时你可能希望基于一系列消息来生成文本。

聊天补全功能允许你基于一系列消息生成文本。这一系列消息可以是任意数量系统之间的任意交互序列，但最流行且最易理解的用例是代表用户与模型之间对话的消息序列。

<Browser>
  <ChatGeneration
    history={[
      { role: '用户', content: '最近怎么样？' },
      { role: '助手', content: '一切都好，有什么可以帮你的吗？' },
    ]}
    inputMessage={{ role: '用户', content: '为什么天空是蓝色的？' }}
    outputMessage={{
      role: '助手',
      content: '天空是蓝色的，这是因为瑞利散射。',
    }}
  />
</Browser>

## 客户端

让我们创建一个用户与模型之间的简单对话，并放置一个按钮来调用 `continueConversation`。

```tsx filename='app/page.tsx'
'use client';

import { useState } from 'react';
import { Message, continueConversation } from './actions';

// 允许流式响应最长 30 秒
export const maxDuration = 30;

export default function Home() {
  const [conversation, setConversation] = useState<Message[]>([]);
  const [input, setInput] = useState<string>('');

  return (
    <div>
      <div>
        {conversation.map((message, index) => (
          <div key={index}>
            {message.role}: {message.content}
          </div>
        ))}
      </div>

      <div>
        <input
          type="text"
          value={input}
          onChange={event => {
            setInput(event.target.value);
          }}
        />
        <button
          onClick={async () => {
            const { messages } = await continueConversation([
              ...conversation,
              { role: 'user', content: input },
            ]);

            setConversation(messages);
          }}
        >
          发送消息
        </button>
      </div>
    </div>
  );
}
```

## 服务端

现在，让我们实现 `continueConversation` 函数，该函数会将用户消息插入对话并生成响应。

```typescript filename='app/actions.ts'
'use server';

import { generateText } from 'ai';

export interface Message {
  role: 'user' | 'assistant';
  content: string;
}

export async function continueConversation(history: Message[]) {
  'use server';

  const { text } = await generateText({
    model: 'openai/gpt-5.4',
    system: '你是一个友好的助手！',
    messages: history,
  });

  return {
    messages: [
      ...history,
      {
        role: 'assistant' as const,
        content: text,
      },
    ],
  };
}
```
