# 生成对象

<Note>
  此示例使用 React Server Components (RSC)。如果你希望使用客户端渲染和 Hook，请查看[使用
  useState 的“生成对象”示例](/examples/next-pages/basics/generating-object)。
</Note>

你可以将 `generateText` 与 `Output` 搭配使用来生成 JSON 等结构化数据。通过提供一个描述目标对象结构的 schema，SDK 将验证生成的输出并确保其符合指定的结构。

`Output.object` 函数要求你使用 [zod](https://zod.dev) 提供 schema，这是一个用于定义 JavaScript 对象 schema 的库。

## 客户端

让我们创建一个简单的 React 组件，当点击按钮时它会调用 `getNotifications` 函数。该函数将按照 schema 中描述的内容生成一个通知列表。

```tsx filename='app/page.tsx'
'use client';

import { useState } from 'react';
import { getNotifications } from './actions';

// Allow streaming responses up to 30 seconds
export const maxDuration = 30;

export default function Home() {
  const [generation, setGeneration] = useState<string>('');

  return (
    <div>
      <button
        onClick={async () => {
          const { notifications } = await getNotifications(
            'Messages during finals week.',
          );

          setGeneration(JSON.stringify(notifications, null, 2));
        }}
      >
        View Notifications
      </button>

      <pre>{generation}</pre>
    </div>
  );
}
```

## 服务端

现在让我们实现 `getNotifications` 函数。我们将使用 `generateText` 函数搭配 `Output.object`，根据前面定义的 schema 生成通知列表。

```typescript filename='app/actions.ts'
'use server';

import { generateText, Output } from 'ai';
import { z } from 'zod';

export async function getNotifications(input: string) {
  'use server';

  const { output: notifications } = await generateText({
    model: 'openai/gpt-6-astra',
    instructions: 'You generate three notifications for a messages app.',
    prompt: input,
    output: Output.object({
      schema: z.object({
        notifications: z.array(
          z.object({
            name: z.string().describe('Name of a fictional person.'),
            message: z.string().describe('Do not use emojis or links.'),
            minutesAgo: z.number(),
          }),
        ),
      }),
    }),
  });

  return { notifications };
}
```
