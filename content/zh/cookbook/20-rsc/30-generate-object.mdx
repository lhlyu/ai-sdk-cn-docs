# 生成对象

<Note>
  此示例使用 React 服务器组件（RSC）。如果您希望使用客户端渲染和 Hook，请查看[“生成对象”示例（使用 useState）](/examples/next-pages/basics/generating-object)。
</Note>

您可以将 `generateText` 与 `Output` 结合使用，以生成 JSON 等结构化数据。通过提供描述所需对象结构的模式，SDK 将验证生成的输出，并确保其符合指定的结构。

`Output.object` 函数要求您使用 [zod](https://zod.dev) 提供模式，zod 是一个用于定义 JavaScript 对象模式的库。

## 客户端

让我们创建一个简单的 React 组件，在点击按钮时调用 `getNotifications` 函数。该函数将根据模式生成通知列表。

```tsx filename='app/page.tsx'
'use client';

import { useState } from 'react';
import { getNotifications } from './actions';

// 允许流式响应最长 30 秒
export const maxDuration = 30;

export default function Home() {
  const [generation, setGeneration] = useState<string>('');

  return (
    <div>
      <button
        onClick={async () => {
          const { notifications } = await getNotifications(
            '期末考试周的消息。',
          );

          setGeneration(JSON.stringify(notifications, null, 2));
        }}
      >
        查看通知
      </button>

      <pre>{generation}</pre>
    </div>
  );
}
```

## 服务器

现在让我们实现 `getNotifications` 函数。我们将使用 `generateText` 函数和 `Output.object`，根据我们之前定义的模式生成通知列表。

```typescript filename='app/actions.ts'
'use server';

import { generateText, Output } from 'ai';
import { z } from 'zod';

export async function getNotifications(input: string) {
  'use server';

  const { output: notifications } = await generateText({
    model: 'openai/gpt-5.4',
    instructions: '您为消息应用生成三条通知。',
    prompt: input,
    output: Output.object({
      schema: z.object({
        notifications: z.array(
          z.object({
            name: z.string().describe('虚构人物的姓名。'),
            message: z.string().describe('请勿使用表情符号或链接。'),
            minutesAgo: z.number(),
          }),
        ),
      }),
    }),
  });

  return { notifications };
}
```
