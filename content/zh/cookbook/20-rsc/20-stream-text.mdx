# 流式文本生成

<Note>
  本示例使用 React 服务端组件 (RSC)。如果你希望使用客户端渲染和 Hook，请查看 [使用 useCompletion 的"流式文本生成"示例](/examples/next-pages/basics/streaming-text-generation)。
</Note>

文本生成有时需要较长时间才能完成，尤其是在生成多个段落时。在这种情况下，将文本生成过程实时流式传输到客户端会非常有用。这样客户端可以在生成过程中逐步显示文本，而无需等待全部生成完毕再展示结果。

## 客户端

让我们创建一个简单的 React 组件，当点击按钮时调用 `generate` 函数。`generate` 函数会调用 `streamText` 函数，该函数根据输入提示词生成文本。为了在客户端消费文本流，我们将使用 `@ai-sdk/rsc` 模块中的 `readStreamableValue` 函数。

```tsx filename="app/page.tsx"
'use client';

import { useState } from 'react';
import { generate } from './actions';
import { readStreamableValue } from '@ai-sdk/rsc';

// 允许流式响应最长持续 30 秒
export const maxDuration = 30;

export default function Home() {
  const [generation, setGeneration] = useState<string>('');

  return (
    <div>
      <button
        onClick={async () => {
          const { output } = await generate('为什么天空是蓝色的？');

          for await (const delta of readStreamableValue(output)) {
            setGeneration(currentGeneration => `${currentGeneration}${delta}`);
          }
        }}
      >
        提问
      </button>

      <div>{generation}</div>
    </div>
  );
}
```

## 服务端

在服务端，我们需要实现 `generate` 函数，该函数会调用 `streamText` 函数。`streamText` 函数根据输入提示词生成文本。为了将文本生成过程流式传输到客户端，我们将使用 `createStreamableValue` 来包装任何可变化的值，并将其流式传输到客户端。

通过 DevTools，我们可以实时看到文本生成被流式传输到客户端的过程。

```typescript filename='app/actions.ts'
'use server';

import { streamText } from 'ai';
import { createStreamableValue } from '@ai-sdk/rsc';

export async function generate(input: string) {
  const stream = createStreamableValue('');

  (async () => {
    const { textStream } = streamText({
      model: 'openai/gpt-5.4',
      prompt: input,
    });

    for await (const delta of textStream) {
      stream.update(delta);
    }

    stream.done();
  })();

  return { output: stream.value };
}
```
