# 流式传输文本

<Note>
  此示例使用 React Server Components（RSC）。如果你想要客户端渲染和 Hook，请查看[使用
  useCompletion 的“流式传输文本”示例](/examples/next-pages/basics/streaming-text-generation)。
</Note>

文本生成有时可能需要很长时间才能完成，尤其是在生成几段文字时。在这种情况下，将文本生成过程实时流式传输到客户端会很有用。这允许客户端在文本生成时显示生成的文本，而不是让用户等待生成完成后再显示结果。

## 客户端

让我们创建一个简单的 React 组件，当按钮被点击时调用 `generate` 函数。`generate` 函数将调用 `streamText` 函数，该函数将根据输入提示词生成文本。为了在客户端消费文本流，我们将使用来自 `@ai-sdk/rsc` 模块的 `readStreamableValue` 函数。

```tsx filename="app/page.tsx"
'use client';

import { useState } from 'react';
import { generate } from './actions';
import { readStreamableValue } from '@ai-sdk/rsc';

// Allow streaming responses up to 30 seconds
export const maxDuration = 30;

export default function Home() {
  const [generation, setGeneration] = useState<string>('');

  return (
    <div>
      <button
        onClick={async () => {
          const { output } = await generate('Why is the sky blue?');

          for await (const delta of readStreamableValue(output)) {
            setGeneration(currentGeneration => `${currentGeneration}${delta}`);
          }
        }}
      >
        Ask
      </button>

      <div>{generation}</div>
    </div>
  );
}
```

## 服务端

在服务端，我们需要实现 `generate` 函数，它将调用 `streamText` 函数。`streamText` 函数将根据输入提示词生成文本。为了将文本生成流式传输到客户端，我们将使用 `createStreamableValue`，它可以包装任何可变值并将其流式传输到客户端。

使用 DevTools，我们可以看到文本生成正在实时流式传输到客户端。

```typescript filename='app/actions.ts'
'use server';

import { streamText } from 'ai';
import { createStreamableValue } from '@ai-sdk/rsc';

export async function generate(input: string) {
  const stream = createStreamableValue('');

  (async () => {
    const { textStream } = streamText({
      model: 'openai/gpt-6-astra',
      prompt: input,
    });

    for await (const delta of textStream) {
      stream.update(delta);
    }

    stream.done();
  })();

  return { output: stream.value };
}
```
