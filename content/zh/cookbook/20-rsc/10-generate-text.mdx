# 生成文本

<Note>
  此示例使用 React Server Components (RSC)。如果你需要客户端渲染和 Hook，请查看[使用 useState 的"生成文本"示例](/examples/next-pages/basics/generating-text)。
</Note>

在某些场景下，你可能需要根据提示词生成文本。例如，你可能需要生成问题的回答或总结一段文本。`generateText` 函数可用于根据输入提示词生成文本。

## 客户端

让我们创建一个简单的 React 组件，当点击按钮时调用 `getAnswer` 函数。`getAnswer` 函数将调用 `ai` 模块中的 `generateText` 函数，该函数会根据输入提示词生成文本。

```tsx filename="app/page.tsx"
'use client';

import { useState } from 'react';
import { getAnswer } from './actions';

// 允许流式响应最长 30 秒
export const maxDuration = 30;

export default function Home() {
  const [generation, setGeneration] = useState<string>('');

  return (
    <div>
      <button
        onClick={async () => {
          const { text } = await getAnswer('为什么天空是蓝色的？');
          setGeneration(text);
        }}
      >
        回答
      </button>
      <div>{generation}</div>
    </div>
  );
}
```

## 服务端

在服务端，我们需要实现 `getAnswer` 函数，该函数将调用 `ai` 模块中的 `generateText` 函数。`generateText` 函数会根据输入提示词生成文本。

```typescript filename='app/actions.ts'
'use server';

import { generateText } from 'ai';

export async function getAnswer(question: string) {
  const { text, finishReason, usage } = await generateText({
    model: 'openai/gpt-5.4',
    prompt: question,
  });

  return { text, finishReason, usage };
}
```
