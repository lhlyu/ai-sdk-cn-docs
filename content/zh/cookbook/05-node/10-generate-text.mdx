# 生成文本

最基本的 LLM 用例是根据提示词生成文本。
例如，你可能希望生成对某个问题的回答，或对一段文本进行摘要。
`generateText` 函数可用于根据输入提示词生成文本。

```ts file='index.ts'
import { generateText } from 'ai';

const result = await generateText({
  model: 'openai/gpt-6-astra',
  prompt: 'Why is the sky blue?',
});

console.log(result);
```
