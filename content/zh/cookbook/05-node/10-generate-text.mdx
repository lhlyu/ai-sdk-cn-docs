# 生成文本

最基础的 LLM 用例是基于提示词生成文本。
例如，你可能需要生成对某个问题的回答，或总结一段文本。
`generateText` 函数可用于根据输入的提示词生成文本。

```ts file='index.ts'
import { generateText } from 'ai';

const result = await generateText({
  model: 'openai/gpt-4o',
  prompt: 'Why is the sky blue?',
});

console.log(result);
```
