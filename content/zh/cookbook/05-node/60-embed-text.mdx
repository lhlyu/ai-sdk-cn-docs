# 嵌入文本

文本嵌入是文本的数值表示，能够捕捉语义含义，使机器能够以数学方式理解和处理语言。这些向量表示对于许多 AI 应用至关重要，因为它们能够实现语义搜索、文档相似度比较和内容推荐等任务。

本示例演示如何使用文本嵌入模型将文本转换为嵌入。生成的嵌入是一个高维向量，代表输入文本的语义含义。有关嵌入的更实际应用，请查看我们的 [RAG 示例](/cookbook/node/retrieval-augmented-generation)，该示例展示了如何将嵌入用于文档检索。

```ts
import { embed } from 'ai';
import 'dotenv/config';

async function main() {
  const { embedding, usage } = await embed({
    model: 'openai/text-embedding-3-small',
    value: 'sunny day at the beach',
  });

  console.log(embedding);
  console.log(usage);
}

main().catch(console.error);
```
