# Web 搜索智能体

使用 AI SDK 构建 Web 搜索智能体有两种方式：

1. 使用具备原生 Web 搜索能力的模型
2. 使用工具访问网络并返回搜索结果。

提供商原生搜索运行在提供商的基础设施上，并在生成响应时一并返回来源。可用的搜索控制项和定价因提供商而异；搜索可能会产生额外的工具费用。

相反，通过使用工具，你可以获得更大的灵活性，并对搜索查询拥有更强的控制力。它允许你自定义搜索策略、指定搜索参数，并且可以与任何支持工具调用的 LLM 配合使用。这种方式会为你使用的搜索 API 带来额外费用，但让你能够完全掌控搜索体验。

## 使用原生 Web 搜索

有多个模型提供原生 Web 搜索能力（Perplexity、OpenAI、Gemini）。让我们看看如何跨提供商构建一个 Web 搜索智能体。

### OpenAI Responses API

OpenAI 的 Responses API 内置了一个 Web 搜索工具，可用于搜索网络并返回搜索结果。该工具名为 `web_search`，通过 `openai` 提供商访问。

```ts
import { openai } from '@ai-sdk/openai';
import { generateText } from 'ai';

const { text, sources } = await generateText({
  model: 'openai/gpt-6-luna',
  prompt: 'What happened in San Francisco last week?',
  tools: {
    web_search: openai.tools.webSearch({}),
  },
});

console.log(text);
console.log(sources);
```

你也可以使用 `ToolLoopAgent` 来构建一个基于 OpenAI 的 Web 搜索智能体。以下示例展示了如何从工具调用中提取查询和来源：

```ts
import { openai } from '@ai-sdk/openai';
import { ToolLoopAgent } from 'ai';

const agent = new ToolLoopAgent({
  model: 'openai/gpt-6-luna',
  tools: {
    web_search: openai.tools.webSearch({
      searchContextSize: 'low',
    }),
  },
});

const { text, sources, toolResults } = await agent.generate({
  prompt: 'What happened in San Francisco last week?',
});

// Access sources directly
console.log('Sources:', sources);

// Or extract query and sources from tool results
for (const toolResult of toolResults) {
  if (toolResult.toolName === 'web_search') {
    const { action, sources } = toolResult.output;
    console.log('Search query:', action.query);
    console.log('Sources:', sources);
  }
}
```

### Perplexity

Perplexity 的 Agent API 提供了预设，将模型与 Web 搜索等原生工具结合在一起。`fast` 预设可以搜索网络，并通过 `sources` 属性返回引用。

安装 `@ai-sdk/perplexity` 并在环境中设置 `PERPLEXITY_API_KEY`，即可直接使用该提供商：

<InstallPackages packages="@ai-sdk/perplexity" />

```ts
import { perplexity } from '@ai-sdk/perplexity';
import { generateText } from 'ai';

const { text, sources } = await generateText({
  model: perplexity('fast'),
  prompt: 'What are the latest developments in quantum computing?',
});

console.log(text);
console.log(sources);
```

有关原生工具、搜索过滤器和 Agent API 选项，请参阅 [Perplexity 提供商文档](/providers/ai-sdk-providers/perplexity#agent-tools)。

### Gemini

对于兼容的 Gemini 模型，你可以启用搜索接地（search grounding），让模型能够使用 Google 搜索获取最新信息。

```ts
import { google } from '@ai-sdk/google';
import { generateText } from 'ai';

const { text, sources, providerMetadata } = await generateText({
  model: 'google/gemini-3.8-flash',
  tools: {
    google_search: google.tools.googleSearch({}),
  },
  prompt:
    'List the top 5 San Francisco news from the past week.' +
    'You must include the date of each article.',
});

console.log(text);
console.log(sources);

// access the grounding metadata.
const metadata = providerMetadata?.google;
const groundingMetadata = metadata?.groundingMetadata;
const safetyRatings = metadata?.safetyRatings;
```

## 使用工具

在使用工具进行 Web 搜索时，你有两种选择：使用与 AI SDK 直接集成的现成工具，或者构建适合你特定需求的自定义工具。

与原生 Web 搜索示例中搜索内置于模型不同，使用 Web 搜索工具需要多个步骤。语言模型会进行两次生成——第一次调用相关的 Web 搜索工具（从上下文中提取搜索查询），第二次处理结果并生成响应。当你将 `stopWhen: isStepCount(n)` 设置为大于 1 的值时，这个多步骤过程会自动处理。

<Note>
  通过使用 `stopWhen`，你可以自动将工具结果连同原始问题一起发送回语言模型，使模型能够根据搜索结果回应用户查询的相关信息。这创造了一种无缝体验，智能体可以搜索网络并将这些发现融入其响应中。
</Note>

### 使用现成工具

如果你希望使用开箱即用的 Web 搜索工具，而不必从头构建，有多个选项可以直接与 AI SDK 集成。

#### Exa

<Note>
  从 [Exa Dashboard](https://dashboard.exa.ai/api-keys) 获取你的 API 密钥。
</Note>

首先，安装 Exa `webSearch` 工具：

```bash
pnpm install @exalabs/ai-sdk
```

然后，你可以导入它并传入 `generateText`、`streamText` 或你的智能体：

```ts
import { generateText, isStepCount } from 'ai';
__PROVIDER_IMPORT__;
import { webSearch } from '@exalabs/ai-sdk';

const { text } = await generateText({
  model: __MODEL__,
  prompt: 'Tell me the latest developments in AI',
  tools: {
    webSearch: webSearch(),
  },
  stopWhen: isStepCount(3),
});

console.log(text);
```

有关更多配置选项和自定义，请参阅 [Exa AI SDK 文档](https://docs.exa.ai/reference/vercel)。

#### Parallel Web

<Note>从 [Parallel Platform](https://parallel.ai) 获取你的 API 密钥。</Note>

首先，安装 Parallel Web AI SDK 工具：

```bash
pnpm install @parallel-web/ai-sdk-tools
```

然后，你可以导入这些工具并传入 `generateText`、`streamText` 或你的智能体。Parallel Web 提供两个工具：用于 Web 搜索的 `searchTool` 和用于提取网页内容的 `extractTool`：

```ts
import { generateText, isStepCount } from 'ai';
__PROVIDER_IMPORT__;
import { searchTool, extractTool } from '@parallel-web/ai-sdk-tools';

const { text } = await generateText({
  model: __MODEL__,
  prompt: 'When was Vercel Ship AI?',
  tools: {
    webSearch: searchTool,
    webExtract: extractTool,
  },
  stopWhen: isStepCount(3),
});

console.log(text);
```

#### Perplexity Search

<Note>
  从 [Perplexity API Keys 页面](https://www.perplexity.ai/account/api/keys)获取你的 API 密钥。
</Note>

首先，安装 Perplexity Search 工具：

```bash
pnpm install @perplexity-ai/ai-sdk
```

然后，你可以导入它并传入 `generateText`、`streamText` 或你的智能体。Perplexity Search 提供实时 Web 搜索，并带有高级过滤选项，包括域名、语言、日期范围和时效性过滤器：

```ts
import { generateText, isStepCount } from 'ai';
__PROVIDER_IMPORT__;
import { perplexitySearch } from '@perplexity-ai/ai-sdk';

const { text } = await generateText({
  model: __MODEL__,
  prompt:
    'What are the latest AI developments? Use search to find current information.',
  tools: {
    search: perplexitySearch(),
  },
  stopWhen: isStepCount(3),
});

console.log(text);
```

有关更多配置选项和自定义，请参阅 [Perplexity Search API 文档](https://docs.perplexity.ai/guides/search-quickstart)。

#### You.com

<Note>
  从 [You.com API Keys 页面](https://you.com/platform/api-keys)获取你的 API 密钥。
</Note>

首先，安装 You.com AI SDK 插件：

```bash
pnpm install @youdotcom-oss/ai-sdk-plugin
```

然后，你可以导入这些工具并传入 `generateText`、`streamText` 或你的智能体。You.com 提供三个工具：`youSearch` 用于带高级过滤的实时 Web 搜索，`youResearch` 用于带引用来源和可配置力度（从 lite 到 exhaustive）的深度研究，`youContents` 用于以 markdown 或 HTML 提取网页内容：

```ts
import { generateText, isStepCount } from 'ai';
__PROVIDER_IMPORT__;
import {
  youSearch,
  youResearch,
  youContents,
} from '@youdotcom-oss/ai-sdk-plugin';

const { text } = await generateText({
  model: __MODEL__,
  prompt: 'Research the latest developments in quantum computing',
  tools: {
    search: youSearch(),
    research: youResearch(),
    extract: youContents(),
  },
  stopWhen: isStepCount(5),
});

console.log(text);
```

有关更多配置选项和自定义，请参阅 [You.com AI SDK 插件文档](https://github.com/youdotcom-oss/dx-toolkit/tree/main/packages/ai-sdk-plugin#readme)。

### 构建并使用自定义工具

为了更好地控制你的 Web 搜索功能，你可以使用网页抓取和爬取 API 构建自定义工具。这种方式允许你自定义搜索参数、处理特定数据格式，并与专门的搜索服务集成。

#### Exa

让我们看看如何使用 Exa 实现一个搜索工具：

```bash
pnpm install exa-js
```

```ts
import { generateText, tool, isStepCount } from 'ai';
__PROVIDER_IMPORT__;
import { z } from 'zod';
import Exa from 'exa-js';

export const exa = new Exa(process.env.EXA_API_KEY);

export const webSearch = tool({
  description: 'Search the web for up-to-date information',
  inputSchema: z.object({
    query: z.string().min(1).max(100).describe('The search query'),
  }),
  execute: async ({ query }) => {
    const { results } = await exa.searchAndContents(query, {
      livecrawl: 'always',
      numResults: 3,
    });
    return results.map(result => ({
      title: result.title,
      url: result.url,
      content: result.text.slice(0, 1000), // take just the first 1000 characters
      publishedDate: result.publishedDate,
    }));
  },
});

const { text } = await generateText({
  model: __MODEL__, // can be any model that supports tools
  prompt: 'What happened in San Francisco last week?',
  tools: {
    webSearch,
  },
  stopWhen: isStepCount(5),
});
```

#### Firecrawl

[Firecrawl](https://firecrawl.dev) 提供了一个用于网页抓取和爬取的 API。让我们看看如何使用 Firecrawl 构建一个自定义抓取工具：

```bash
pnpm install @mendable/firecrawl-js
```

```ts
import { generateText, tool, isStepCount } from 'ai';
__PROVIDER_IMPORT__;
import { z } from 'zod';
import FirecrawlApp from '@mendable/firecrawl-js';
import 'dotenv/config';

const app = new FirecrawlApp({ apiKey: process.env.FIRECRAWL_API_KEY });

export const webSearch = tool({
  description: 'Search the web for up-to-date information',
  inputSchema: z.object({
    urlToCrawl: z
      .string()
      .url()
      .min(1)
      .max(100)
      .describe('The URL to crawl (including http:// or https://)'),
  }),
  execute: async ({ urlToCrawl }) => {
    const crawlResponse = await app.crawlUrl(urlToCrawl, {
      limit: 1,
      scrapeOptions: {
        formats: ['markdown', 'html'],
      },
    });
    if (!crawlResponse.success) {
      throw new Error(`Failed to crawl: ${crawlResponse.error}`);
    }
    return crawlResponse.data;
  },
});

const main = async () => {
  const { text } = await generateText({
    model: __MODEL__, // can be any model that supports tools
    prompt: 'Get the latest blog post from vercel.com/blog',
    tools: {
      webSearch,
    },
    stopWhen: isStepCount(5),
  });
  console.log(text);
};

main();
```
