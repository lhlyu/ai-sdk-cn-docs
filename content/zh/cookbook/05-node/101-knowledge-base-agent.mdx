在本教程中，你将学习如何使用 [Upstash Search](https://upstash.com/docs/search) 构建一个能与知识库交互的 AI 智能体。该智能体能够从知识库中检索信息，也能向其中添加新资源，并充分利用 AI SDK 的工具功能。

Upstash Search 提供输入增强、重排序、语义搜索和全文搜索功能，可获取高精度结果。它还内置了嵌入服务，无需单独使用嵌入提供商，非常适合构建和管理简单的知识库。

本示例使用[以下文章](https://raw.githubusercontent.com/run-llama/llama_index/main/docs/docs/examples/data/paul_graham/paul_graham_essay.txt)作为输入数据（`essay.txt`）。

如需更深入的指南，请查看 [RAG 智能体指南](/cookbook/guides/rag-chatbot)，其中展示了如何使用 [Next.js](https://nextjs.org)、[Drizzle ORM](https://orm.drizzle.team/) 和 [Postgres](https://postgresql.org) 构建 RAG 智能体。

## 开始使用

在 [Upstash 控制台](https://console.upstash.com/search) 创建一个 Upstash Search 数据库。创建完成后，你将获得一个 REST URL 和一个令牌。将它们设置为环境变量：

```bash
UPSTASH_SEARCH_REST_URL="***"
UPSTASH_SEARCH_REST_TOKEN="***"
```

## 项目设置

为你的项目创建一个新的空目录，并初始化 pnpm：

```bash
mkdir knowledge-base-agent
cd knowledge-base-agent
pnpm init
```

安装 AI SDK、OpenAI 提供商、Upstash Search 包，并将 tsx 作为开发依赖项：

```bash
pnpm i ai zod @ai-sdk/openai @upstash/search
pnpm i -D tsx
```

最后，下载并保存输入文章：

```bash
curl -o essay.txt https://raw.githubusercontent.com/run-llama/llama_index/main/docs/docs/examples/data/paul_graham/paul_graham_essay.txt
```

## 设置知识库

接下来，通过读取文件并将其内容上传到 Upstash Search 来设置初始知识库。创建一个名为 `setup.ts` 的脚本：

```ts filename="setup.ts"
import fs from 'fs';
import path from 'path';
import 'dotenv/config';
import { Search } from '@upstash/search';

type KnowledgeContent = {
  text: string;
  section: string;
  title?: string;
};

// 初始化 Upstash Search 客户端
const search = new Search({
  url: process.env.UPSTASH_SEARCH_REST_URL!,
  token: process.env.UPSTASH_SEARCH_REST_TOKEN!,
});

const index = search.index<KnowledgeContent>('knowledge-base');

async function setupKnowledgeBase() {
  // 读取并处理源文件
  const content = fs.readFileSync(path.join(__dirname, 'essay.txt'), 'utf8');

  // 将内容分割成有意义的块
  const chunks = content
    .split(/\n\s*\n/) // 按双换行符（段落）分割
    .map(chunk => chunk.trim())
    .filter(chunk => chunk.length > 50); // 只保留有实质内容的块

  // 以每批 100 个块的方式上传到 Upstash Search
  const batchSize = 100;
  for (let i = 0; i < chunks.length; i += batchSize) {
    const batch = chunks.slice(i, i + batchSize).map((chunk, j) => ({
      id: `chunk-${i + j}`,
      content: {
        text: chunk,
        section: `section-${Math.floor((i + j) / 10)}`,
        title: chunk.split('\n')[0] || `Chunk ${i + j + 1}`,
      },
    }));
    await index.upsert(batch);
    console.log(
      `已上传 ${Math.min(i + batch.length, chunks.length)} 个块，共 ${chunks.length} 个块`,
    );
  }
}

// 运行设置
setupKnowledgeBase().catch(console.error);
```

运行设置脚本以填充你的知识库：

```bash
pnpm tsx setup.ts
```

导航到 Upstash 控制台，查看 Search 数据库的数据浏览器。你应该会看到文章已被索引。

## 构建知识库智能体

现在，让我们创建一个能与该知识库交互的智能体。创建一个名为 `agent.ts` 的新文件：

```ts filename="agent.ts"
import { tool, isStepCount, generateText, generateId } from 'ai';
import { z } from 'zod';
import { Search } from '@upstash/search';

import 'dotenv/config';

const search = new Search({
  url: process.env.UPSTASH_SEARCH_REST_URL!,
  token: process.env.UPSTASH_SEARCH_REST_TOKEN!,
});

type KnowledgeContent = {
  text: string;
  section: string;
  title?: string;
};

const index = search.index<KnowledgeContent>('knowledge-base');

async function main(prompt: string) {
  const { text } = await generateText({
    model: 'openai/gpt-4o',
    prompt,
    stopWhen: isStepCount(5),
    tools: {
      addResource: tool({
        description:
          '向知识库添加新资源或信息片段',
        inputSchema: z.object({
          resource: z
            .string()
            .describe('要添加到知识库的内容或资源'),
          title: z
            .string()
            .optional()
            .describe('资源的可选标题'),
        }),
        execute: async ({ resource, title }) => {
          const id = generateId();
          await index.upsert({
            id,
            content: {
              text: resource,
              section: 'user-added',
              title: title || `Resource ${id.slice(0, 8)}`,
            },
          });
          return `已成功将资源 "${title || '未命名'}" 添加到知识库，ID 为：${id}`;
        },
      }),
      searchKnowledge: tool({
        description:
          '搜索知识库以查找回答问题的相关信息',
        inputSchema: z.object({
          query: z
            .string()
            .describe('用于查找相关信息的搜索查询'),
          limit: z
            .number()
            .optional()
            .describe('返回的最大结果数（默认：3）'),
        }),
        execute: async ({ query, limit = 3 }) => {
          const results = await index.search({
            query,
            limit,
            reranking: true,
          });

          if (results.length === 0) {
            return '在知识库中未找到相关信息。';
          }

          return results.map((hit, i) => ({
            resourceId: hit.id,
            rank: i + 1,
            title: hit.content.title || '未命名',
            content: hit.content.text || '',
            section: hit.content.section || '未知',
            score: hit.score,
          }));
        },
      }),
      deleteResource: tool({
        description: '从知识库中删除资源',
        inputSchema: z.object({
          resourceId: z.string().describe('要删除的资源的 ID'),
        }),
        execute: async ({ resourceId }) => {
          try {
            await index.delete({ ids: [resourceId] });
            return `已成功删除 ID 为 ${resourceId} 的资源`;
          } catch (error) {
            return `删除资源失败：${error instanceof Error ? error.message : '未知错误'}`;
          }
        },
      }),
    },
    // 记录中间步骤
    onStepEnd: ({ toolResults }) => {
      if (toolResults.length > 0) {
        console.log('工具结果：');
        console.dir(toolResults, { depth: null });
      }
    },
  });

  return text;
}

const question =
  '我在上大学前主要做了哪两件事？（利用知识库）';

main(question).then(console.log).catch(console.error);
```

## 运行智能体

现在，让我们运行智能体：

```bash
pnpm tsx agent.ts
```

智能体将利用知识库回答问题、添加新资源，并根据需要删除现有资源。你可以修改 `question` 变量来测试不同的查询以及与知识库的交互。
