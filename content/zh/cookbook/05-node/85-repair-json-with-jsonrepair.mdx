# 使用 jsonrepair 修复损坏的 JSON

在生成结构化输出时，语言模型有时会产生格式错误的 JSON。这可能是由于以下原因造成的：

- 响应被截断（达到 token 限制）
- 语法错误，例如使用单引号代替双引号
- 缺少闭合的括号或花括号
- 尾随逗号

使用 AI SDK v6，一个实用的模式是生成文本、修复文本，然后解析并验证文本。结合 [`jsonrepair`](https://github.com/josdejong/jsonrepair) 库，你可以自动修复许多常见的 JSON 问题。

## 安装

首先，安装 `jsonrepair` 库：

```bash
pnpm add jsonrepair
```

## 与 generateText 一起使用

以下是如何将 `jsonrepair` 与 `generateText` 一起使用：

```ts
import { generateText, Output } from 'ai';
import { safeParseJSON } from '@ai-sdk/provider-utils';
__PROVIDER_IMPORT__;
import { jsonrepair } from 'jsonrepair';
import { z } from 'zod';

const recipeSchema = z.object({
  recipe: z.object({
    name: z.string(),
    ingredients: z.array(
      z.object({
        name: z.string(),
        amount: z.string(),
      }),
    ),
    steps: z.array(z.string()),
  }),
});

const result = await generateText({
  model: __MODEL__,
  output: Output.text(),
  prompt: '生成一份千层面食谱。',
});

const repairedText = jsonrepair(result.text);
const parseResult = safeParseJSON({ text: repairedText });

if (!parseResult.success) {
  throw parseResult.error;
}

const output = recipeSchema.parse(parseResult.value);
console.log(output.recipe);
```

## 工作原理

这个流程包含三个步骤：

1. 从模型生成纯文本（`Output.text()`）。
2. 使用 `jsonrepair` 修复损坏的 JSON。
3. 安全解析并使用你的 schema 进行验证。

## jsonrepair 可以修复什么

`jsonrepair` 库可以自动修复许多常见问题：

- 缺少闭合括号：`{"name": "test"` -> `{"name": "test"}`
- 单引号：`{'name': 'test'}` -> `{"name": "test"}`
- 键缺少引号：`{name: "test"}` -> `{"name": "test"}`
- 尾随逗号：`{"items": [1, 2, 3,]}` -> `{"items": [1, 2, 3]}`
- JSON 中的注释
- 未转义的特殊字符

## 注意事项

1. **修复是尽力而为的** - 虽然 `jsonrepair` 能处理许多情况，但它无法修复所有格式错误的 JSON（例如，语义上不正确但恰好是有效 JSON 的数据）
2. **Schema 验证** - 即使修复后，对象仍然必须匹配你的 schema。如果模型产生了结构错误的数据，修复也无济于事
3. **截断的内容** - 对于严重截断的响应，考虑增加 `maxOutputTokens` 或简化你的 schema
