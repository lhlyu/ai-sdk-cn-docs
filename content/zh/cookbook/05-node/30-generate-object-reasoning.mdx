# 使用推理模型生成对象

推理模型，例如 [DeepSeek](/providers/ai-sdk-providers/deepseek) 的 R1，因其理解和生成复杂查询响应的能力优于非推理模型而日益流行。您可能希望使用这些模型来生成结构化数据。然而，大多数模型（如 R1 和 [OpenAI](/providers/ai-sdk-providers/openai) 的 o1）并不支持工具调用或结构化输出。

一种解决方案是将推理模型的输出传递给一个能够输出结构化数据的较小模型（如 gpt-4o-mini）。这些轻量级模型能够高效地提取结构化数据，同时在速度和成本方面增加的开销非常小。

```ts
import { generateText, Output } from 'ai';
import 'dotenv/config';
import { z } from 'zod';

async function main() {
  const { text: rawOutput } = await generateText({
    model: 'deepseek/deepseek-r1',
    prompt:
      '预测2050年最大的3个城市。对于每个城市，返回名称、国家、上榜原因以及预估人口（单位：百万）。',
  });

  const { output } = await generateText({
    model: 'openai/gpt-4o-mini',
    prompt: '从以下文本中提取所需信息：\n' + rawOutput,
    output: Output.array({
      element: z.object({
        name: z.string().describe('城市名称'),
        country: z.string().describe('国家名称'),
        reason: z
          .string()
          .describe(
            '该城市成为2050年最大城市之一的原因',
          ),
        estimatedPopulation: z.number(),
      }),
    }),
  });

  console.log(output);
}

main().catch(console.error);
```
