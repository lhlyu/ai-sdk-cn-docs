# 调用工具

部分模型允许开发者提供一组可在生成过程中随时调用的工具。
这有助于扩展语言模型的能力，使其能够利用逻辑或数据与模型外部的系统进行交互。

```ts
import { generateText, tool } from 'ai';
import { z } from 'zod';

const result = await generateText({
  model: 'openai/gpt-4.1',
  tools: {
    weather: tool({
      description: '获取某个位置的天气',
      inputSchema: z.object({
        location: z.string().describe('要获取天气的位置'),
      }),
      execute: async ({ location }) => ({
        location,
        temperature: 72 + Math.floor(Math.random() * 21) - 10,
      }),
    }),
    cityAttractions: tool({
      inputSchema: z.object({ city: z.string() }),
    }),
  },
  prompt:
    '旧金山的天气如何？我应该参观哪些景点？',
});
```

## 访问工具调用与工具结果

如果模型决定调用工具，它将生成一个工具调用。你可以通过检查结果的 `toolCalls` 属性来访问该工具调用。

```ts highlight="31-44"
import { generateText, tool } from 'ai';
import dotenv from 'dotenv';
import { z } from 'zod';

dotenv.config();

async function main() {
  const result = await generateText({
    model: 'openai/gpt-4o',
    maxOutputTokens: 512,
    tools: {
      weather: tool({
        description: '获取某个位置的天气',
        inputSchema: z.object({
          location: z.string().describe('要获取天气的位置'),
        }),
        execute: async ({ location }) => ({
          location,
          temperature: 72 + Math.floor(Math.random() * 21) - 10,
        }),
      }),
      cityAttractions: tool({
        inputSchema: z.object({ city: z.string() }),
      }),
    },
    prompt:
      '旧金山的天气如何？我应该参观哪些景点？',
  });

  // 类型化的工具调用：
  for (const toolCall of result.toolCalls) {
    if (toolCall.dynamic) {
      continue;
    }

    switch (toolCall.toolName) {
      case 'cityAttractions': {
        toolCall.input.city; // string
        break;
      }

      case 'weather': {
        toolCall.input.location; // string
        break;
      }
    }
  }

  console.log(JSON.stringify(result, null, 2));
}

main().catch(console.error);
```

## 访问工具结果

你可以通过检查结果的 `toolResults` 属性来访问工具调用的结果。

```ts highlight="31-41"
import { generateText, tool } from 'ai';
import dotenv from 'dotenv';
import { z } from 'zod';

dotenv.config();

async function main() {
  const result = await generateText({
    model: 'openai/gpt-4o',
    maxOutputTokens: 512,
    tools: {
      weather: tool({
        description: '获取某个位置的天气',
        inputSchema: z.object({
          location: z.string().describe('要获取天气的位置'),
        }),
        execute: async ({ location }) => ({
          location,
          temperature: 72 + Math.floor(Math.random() * 21) - 10,
        }),
      }),
      cityAttractions: tool({
        inputSchema: z.object({ city: z.string() }),
      }),
    },
    prompt:
      '旧金山的天气如何？我应该参观哪些景点？',
  });

  // 针对包含 execute 方法的工具的类型化工具结果：
  for (const toolResult of result.toolResults) {
    if (toolResult.dynamic) {
      continue;
    }

    switch (toolResult.toolName) {
      case 'weather': {
        toolResult.input.location; // string
        toolResult.output.location; // string
        toolResult.output.temperature; // number
        break;
      }
    }
  }

  console.log(JSON.stringify(result, null, 2));
}

main().catch(console.error);
```

<Note>
  `toolResults` 仅在工具包含 `execute` 函数时可用。
</Note>

## 模型响应

使用工具时，需要注意模型默认不会返回工具调用的结果。
这是因为模型在技术上已经生成了对提示词的响应：即工具调用本身。
许多用例需要模型在原始提示词的上下文中自动总结工具调用的结果。
你可以通过[使用 `stopWhen`](/cookbook/node/call-tools-multiple-steps) 来实现这一点，
它会自动将 toolResults 发送给模型以触发新一轮生成。
