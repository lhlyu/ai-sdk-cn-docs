# 批量文本嵌入

在处理大型数据集或多段文本时，逐个处理嵌入可能效率低下。批量嵌入允许您同时将多个文本输入转换为嵌入向量，从而显著提升性能并减少 API 调用。这在处理文档、聊天消息或任何需要向量化的文本集合时尤为有用。

本示例演示如何使用 AI SDK 在单次操作中嵌入多个文本输入。如需了解单文本嵌入，请参阅我们的[嵌入文本](/cookbook/node/embed-text)示例；如需查看实际应用，请查阅我们的[RAG 示例](/cookbook/node/retrieval-augmented-generation)，该示例展示了如何在文档检索系统中使用批量嵌入。

```ts
import { embedMany } from 'ai';
import 'dotenv/config';

async function main() {
  const { embeddings, usage } = await embedMany({
    model: 'openai/text-embedding-3-small',
    values: [
      'sunny day at the beach',
      'rainy afternoon in the city',
      'snowy night in the mountains',
    ],
  });

  console.log(embeddings);
  console.log(usage);
}

main().catch(console.error);
```
