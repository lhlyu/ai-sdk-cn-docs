# 提示词工程

## 什么是大语言模型（LLM）？

大语言模型本质上是一个预测引擎，它接收一个单词序列作为输入，并旨在预测接下来最可能出现的序列。它通过为可能的后续序列分配概率，然后选择一个序列来实现这一点。模型会持续生成序列，直到满足指定的停止条件。

这些模型通过在大量文本语料库上进行训练来学习，这意味着它们会更适合某些用例。例如，在 GitHub 数据上训练的模型会特别擅长理解源代码中序列的概率。然而，至关重要的是要理解，生成的序列虽然看起来似乎合理，但有时可能是随机的，并且不基于现实。随着这些模型变得更加准确，许多令人惊讶的能力和应用也随之涌现。

## 什么是提示词？

提示词是 LLM 的起点。它们是触发模型生成文本的输入。提示词工程的范围不仅包括精心设计这些提示词，还包括理解相关概念，例如隐藏提示词、令牌、令牌限制以及提示词攻击的可能性，其中包括越狱和泄露等现象。

## 为什么需要提示词工程？

目前，提示词工程在塑造 LLM 的响应方面起着关键作用。它允许我们调整模型，使其更有效地响应更广泛的查询。这包括使用语义搜索、命令语法和 ReActive 模型架构等技术。LLM 的性能、上下文窗口和成本因模型和模型提供商而异，这进一步增加了约束条件。例如，GPT-4 模型比 GPT-3.5-turbo 更昂贵且明显更慢，但在某些任务上也可能更有效。因此，就像软件工程中的许多事情一样，在成本和性能之间存在权衡。

为了帮助比较和调整 LLM，我们构建了一个 AI 游乐场，允许您在线并排比较不同模型的性能。当您准备好后，您甚至可以使用 AI SDK 生成代码，以快速将您的提示词和所选模型集成到您自己的应用程序中。

## 示例：构建一个标语生成器

### 从指令开始

想象一下，您想为营销活动构建一个标语生成器。创建朗朗上口的标语并不总是那么简单！

首先，您需要一个能清楚表达您需求的提示词。让我们从一个指令开始。提交此提示词以生成您的第一个补全。

<InlinePrompt initialInput="为一家咖啡店创建一个标语。" />

不错！现在，尝试让您的指令更具体。

<InlinePrompt initialInput="为一家有机咖啡店创建一个标语。" />

在提示词中引入一个描述性术语会影响补全。本质上，精心设计提示词是您“指导”或“编程”模型的方式。

### 包含示例

清晰的指令是获得高质量结果的关键，但这可能并不总是足够的。让我们尝试进一步增强您的指令。

<InlinePrompt initialInput="为一家有现场音乐的咖啡店创建三个标语。" />

这些标语还不错，但还可以更好。模型似乎忽略了提示词中的“现场”部分。让我们稍微修改一下，以生成更合适的建议。

通常，向模型演示并告知您的要求是有益的。在提示词中加入示例有助于传达模式或细微差别。测试这个包含几个示例的提示词。

<InlinePrompt
  initialInput={`为具有独特特色的企业创建三个标语。

企业：有猫的书店
标语："完美书页"、"书籍与胡须"、"小说与依偎"
企业：有攀岩的健身房
标语："巅峰表现"、"达到新高度"、"攀向健康"
企业：有现场音乐的咖啡店
标语：`}
/>

太好了！在提示词中加入针对特定输入的预期输出示例，促使模型生成了我们想要的那种名称。

### 调整您的设置

除了设计提示词之外，您还可以通过调整模型设置来影响补全。一个关键的设置是**温度**。

您可能已经注意到，重复相同的提示词会产生相同或几乎相同的补全。当您的温度设置为 0 时，就会发生这种情况。

尝试将温度设置为 1，并多次重新提交相同的提示词。

<InlinePrompt
  initialInput={`为具有独特特色的企业创建三个标语。

企业：有猫的书店
标语："完美书页"、"书籍与胡须"、"小说与依偎"
企业：有攀岩的健身房
标语："巅峰表现"、"达到新高度"、"攀向健康"
企业：有现场音乐的咖啡店
标语：`}
showTemp={true}
initialTemperature={1}
/>

注意到区别了吗？当温度高于 0 时，相同的提示词每次都会产生不同的补全。

请记住，模型会预测最可能跟随前面文本的文本。温度是一个从 0 到 1 的值，它本质上控制着模型在进行这些预测时的置信水平。较低的温度意味着较低的风险，从而产生更精确和确定性的补全。较高的温度会产生更广泛的补全范围。

对于您的标语生成器，您可能需要大量的名称建议。0.6 的适中温度应该效果不错。
