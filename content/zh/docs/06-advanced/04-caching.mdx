# 缓存响应

根据你正在构建的应用程序类型，你可能希望缓存从 AI 提供商收到的响应，至少是临时缓存。

## 使用语言模型中间件（推荐）

缓存响应的推荐方法是使用[语言模型中间件](/docs/ai-sdk-core/middleware)和 [`simulateReadableStream`](/docs/reference/ai-sdk-core/simulate-readable-stream) 函数。

语言模型中间件是一种通过拦截和修改对语言模型的调用来增强语言模型行为的方式。
让我们看看如何使用语言模型中间件来缓存响应。

```ts filename="ai/middleware.ts"
import { Redis } from '@upstash/redis';
import {
  type LanguageModelV4,
  type LanguageModelV4Middleware,
  type LanguageModelV4StreamPart,
  simulateReadableStream,
} from 'ai';

const redis = new Redis({
  url: process.env.KV_URL,
  token: process.env.KV_TOKEN,
});

export const cacheMiddleware: LanguageModelV4Middleware = {
  wrapGenerate: async ({ doGenerate, params }) => {
    const cacheKey = JSON.stringify(params);

    const cached = (await redis.get(cacheKey)) as Awaited<
      ReturnType<LanguageModelV4['doGenerate']>
    > | null;

    if (cached !== null) {
      return {
        ...cached,
        response: {
          ...cached.response,
          timestamp: cached?.response?.timestamp
            ? new Date(cached?.response?.timestamp)
            : undefined,
        },
      };
    }

    const result = await doGenerate();

    redis.set(cacheKey, result);

    return result;
  },
  wrapStream: async ({ doStream, params }) => {
    const cacheKey = JSON.stringify(params);

    // Check if the result is in the cache
    const cached = await redis.get(cacheKey);

    // If cached, return a simulated ReadableStream that yields the cached result
    if (cached !== null) {
      // Format the timestamps in the cached response
      const formattedChunks = (cached as LanguageModelV4StreamPart[]).map(p => {
        if (p.type === 'response-metadata' && p.timestamp) {
          return { ...p, timestamp: new Date(p.timestamp) };
        } else return p;
      });
      return {
        stream: simulateReadableStream({
          initialDelayInMs: 0,
          chunkDelayInMs: 10,
          chunks: formattedChunks,
        }),
      };
    }

    // If not cached, proceed with streaming
    const { stream, ...rest } = await doStream();

    const fullResponse: LanguageModelV4StreamPart[] = [];

    const transformStream = new TransformStream<
      LanguageModelV4StreamPart,
      LanguageModelV4StreamPart
    >({
      transform(chunk, controller) {
        fullResponse.push(chunk);
        controller.enqueue(chunk);
      },
      flush() {
        // Store the full response in the cache after streaming is complete
        redis.set(cacheKey, fullResponse);
      },
    });

    return {
      stream: stream.pipeThrough(transformStream),
      ...rest,
    };
  },
};
```

<Note>
  此示例使用 `@upstash/redis` 来存储和检索助手的响应，但你可以使用任何你喜欢的 KV 存储提供商。
</Note>

<Note>
  此中间件在 AI SDK 验证结构化输出之前缓存原始模型响应。使用结构化输出时，只缓存已通过你的 schema 验证的响应；否则，无效响应可能会在后续请求中从缓存中重放。
</Note>

`LanguageModelV4Middleware` 有两个方法：`wrapGenerate` 和 `wrapStream`。使用 [`generateText`](/docs/reference/ai-sdk-core/generate-text) 时会调用 `wrapGenerate`，而使用 [`streamText`](/docs/reference/ai-sdk-core/stream-text) 时会调用 `wrapStream`。

对于 `wrapGenerate`，你可以直接缓存响应。而对于 `wrapStream`，你缓存一个流部分的数组，然后可以将其与 [`simulateReadableStream`](/docs/ai-sdk-core/testing#simulate-ui-message-stream-responses) 函数一起使用，创建一个模拟的 `ReadableStream` 来返回缓存的响应。通过这种方式，缓存的响应会像由模型生成一样逐块返回。你可以通过调整 `simulateReadableStream` 的 `initialDelayInMs` 和 `chunkDelayInMs` 参数来控制初始延迟和块之间的延迟。

你可以在我们的[缓存中间件配方](/cookbook/next/caching-middleware)中查看在 Next.js 应用程序中使用 Redis 进行缓存的完整示例。

## 使用生命周期回调

或者，每个 AI SDK Core 函数都有你可以使用的特殊生命周期回调。你可能感兴趣的是 `onEnd`，它在生成完成时被调用。你可以在这里缓存完整的响应。

以下是一个示例，展示如何使用 [Upstash Redis](https://upstash.com/redis) 和 Next.js 将 OpenAI 响应缓存 1 小时：

```tsx filename="app/api/chat/route.ts"
import {
  convertToModelMessages,
  createUIMessageStreamResponse,
  streamText,
  toUIMessageStream,
  UIMessage,
} from 'ai';
__PROVIDER_IMPORT__;
import { Redis } from '@upstash/redis';

// Allow streaming responses up to 30 seconds
export const maxDuration = 30;

const redis = new Redis({
  url: process.env.KV_URL,
  token: process.env.KV_TOKEN,
});

export async function POST(req: Request) {
  const { messages }: { messages: UIMessage[] } = await req.json();

  // come up with a key based on the request:
  const key = JSON.stringify(messages);

  // Check if we have a cached response
  const cached = (await redis.get(key)) as string | null;
  if (cached != null) {
    return new Response(cached, {
      status: 200,
      headers: { 'Content-Type': 'text/plain' },
    });
  }

  // Call the language model:
  const result = streamText({
    model: __MODEL__,
    messages: await convertToModelMessages(messages),
    async onEnd({ text }) {
      // Cache the response text:
      await redis.set(key, text);
      await redis.expire(key, 60 * 60);
    },
  });

  // Respond with the stream
  return createUIMessageStreamResponse({
    stream: toUIMessageStream({ stream: result.stream }),
  });
}
```
