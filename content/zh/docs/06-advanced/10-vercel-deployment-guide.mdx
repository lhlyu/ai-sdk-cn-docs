# Vercel 部署指南

在本指南中，你将使用 [Next.js](https://nextjs.org)（App Router）将 AI 应用部署到 [Vercel](https://vercel.com)。

Vercel 是一个面向开发者的平台，提供构建和部署 Web 应用所需的工具、工作流和基础设施，无需额外配置。

Vercel 支持在每次分支推送和合并到 GitHub、GitLab 和 Bitbucket 项目的生产分支时自动部署。它是部署 AI 应用的绝佳选择。

## 开始之前

要跟随本指南操作，你需要：

- 一个 Vercel 账户
- 一个 Git 提供商账户（本教程将使用 [Github](https://github.com)）
- 一个 OpenAI API 密钥

本指南将教你如何将在 Next.js（App Router）快速入门教程中构建的应用部署到 Vercel。如果你尚未完成快速入门指南，可以从[此仓库](https://github.com/vercel-labs/ai-sdk-deployment-guide)开始。

## 提交更改

Vercel 提供强大的基于 Git 的工作流，每次推送到仓库主分支时，都会自动将应用部署到生产环境。

在提交本地更改之前，请确保你有一个 `.gitignore` 文件。在 `.gitignore` 中，确保排除了环境变量（`.env`）和 node 模块（`node_modules`）。

如果你有任何本地更改，可以通过运行以下命令提交：

```bash
git add .
git commit -m "init"
```

## 创建 Git 仓库

你可以在终端内或 [github.com](https://github.com/) 上创建 GitHub 仓库。本教程将使用 GitHub CLI（[更多信息](https://cli.github.com/)）。

要创建你的 GitHub 仓库：

1. 导航到 [github.com](https://github.com/)
2. 在右上角，点击“加号”图标并选择“New repository”
3. 为你的仓库选择一个名称（可以是任意名称）
4. 点击“Create repository”

创建仓库后，GitHub 将重定向到你的新仓库。

1. 向下滚动页面，复制标题为“...or push an existing repository from the command line”下的命令
2. 返回终端，粘贴并运行这些命令

注意：如果遇到错误“error: remote origin already exists.”，这是因为你的本地仓库仍链接到克隆的仓库。要“取消链接”，可以运行以下命令：

```bash
rm -rf .git
git init
git add .
git commit -m "init"
```

重新运行上一步的代码片段。

## 在 Vercel 中导入项目

在[新建项目](https://vercel.com/new)页面，在 **Import Git Repository** 部分，选择要导入项目的 Git 提供商。按照提示登录你的 GitHub 账户。

登录后，你应该会在“Import Git Repository”部分看到上一步新创建的仓库。点击该项目旁边的“Import”按钮。

### 添加环境变量

你的应用在本地开发时使用 `.env.local` 文件存储 OpenAI API 密钥等环境机密。要将此 API 密钥添加到生产部署中，展开“Environment Variables”部分并粘贴你的 `.env.local` 文件。Vercel 会自动解析你的变量并以适当的 `key:value` 格式输入。

### 部署

点击 **Deploy** 按钮。Vercel 将创建项目并根据所选配置进行部署。

### 享受庆祝时刻！

要查看你的部署，在仪表板中选择项目，然后选择 **Domain**。现在，任何拥有该 URL 的人都可以看到此页面。

## 注意事项

部署 AI 应用时，需要注意一些与基础设施相关的问题。

### 函数持续时间

大多数情况下，你会在服务器上调用大语言模型（LLM）。默认情况下，Hobby 套餐的 Vercel 无服务器函数最大持续时间为 10 秒。根据你的提示词，LLM 完成响应可能需要超过此限制的时间。如果响应在此限制内未解析，服务器将抛出错误。

你可以使用[路由段配置](https://nextjs.org/docs/app/api-reference/file-conventions/route-segment-config)指定 Vercel 函数的最大持续时间。要更新最大持续时间，请在路由处理程序或调用服务器操作的页面顶部添加以下路由段配置。

```ts
export const maxDuration = 30;
```

在 Hobby 套餐中，你可以将最大持续时间增加到 60 秒。对于其他套餐，请参阅[文档](https://vercel.com/docs/functions/runtimes#max-duration)了解限制。

## 安全注意事项

鉴于调用 LLM 的成本较高，采取措施保护应用免受滥用非常重要。

### 速率限制

速率限制是一种通过定义客户端在给定时间范围内可以向服务器发送的最大请求数来调节网络流量的方法。

请遵循[此指南](https://vercel.com/guides/securing-ai-app-rate-limiting)为你的应用添加速率限制。

### 防火墙

防火墙有助于保护你的应用和网站免受 DDoS 攻击和未经授权的访问。

[Vercel Firewall](https://vercel.com/docs/security/vercel-firewall) 是一组专门为安全考虑而创建的工具和基础设施。它自动缓解 DDoS 攻击，企业团队可以进一步自定义其站点，包括专用支持和用于 IP 阻止的自定义规则。
