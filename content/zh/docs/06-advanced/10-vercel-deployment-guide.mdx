# Vercel 部署指南

在本指南中，你将使用 [Next.js](https://nextjs.org)（App Router）将 AI 应用部署到 [Vercel](https://vercel.com)。

Vercel 是一个面向开发者的平台，提供构建和部署 Web 应用所需的工具、工作流和基础设施，让你能够更快地完成部署，而无需额外配置。

Vercel 支持在每次分支推送以及合并到 GitHub、GitLab 和 Bitbucket 项目的生产分支时自动部署。它是部署 AI 应用的绝佳选择。

## 开始之前

要跟随本指南操作，你需要：

- 一个 Vercel 账户
- 一个 Git 提供商账户（本教程将使用 [GitHub](https://github.com)）
- 一个 OpenAI API 密钥

本指南将教你如何将你在 Next.js（App Router）快速入门教程中构建的应用部署到 Vercel。如果你尚未完成快速入门指南，可以从[此仓库](https://github.com/vercel-labs/ai-sdk-deployment-guide)开始。

## 提交更改

Vercel 提供了一套强大的以 Git 为中心的工作流，每次你推送到仓库的主分支时，它都会自动将你的应用部署到生产环境。

在提交本地更改之前，请确保你有一个 `.gitignore` 文件。在 `.gitignore` 中，确保排除你的环境变量（`.env`）和 node modules（`node_modules`）。

如果你有任何本地更改，可以通过运行以下命令提交它们：

```bash
git add .
git commit -m "init"
```

## 创建 Git 仓库

你可以在终端中或通过 [github.com](https://github.com/) 创建 GitHub 仓库。本教程将使用 GitHub CLI（[更多信息见此](https://cli.github.com/)）。

要创建 GitHub 仓库：

1. 导航到 [github.com](https://github.com/)
2. 在右上角，点击“加号”图标并选择“New repository”
3. 为你的仓库选择一个名称（可以是任意名称）
4. 点击“Create repository”

创建仓库后，GitHub 会将你重定向到新仓库。

1. 向下滚动页面，复制标题为“...or push an existing repository from the command line”下方的命令
2. 返回终端，粘贴并运行这些命令

注意：如果你遇到错误“error: remote origin already exists.”，这是因为你的本地仓库仍然链接到你克隆的仓库。要“取消链接”，可以运行以下命令：

```bash
rm -rf .git
git init
git add .
git commit -m "init"
```

重新运行上一步中的代码片段。

## 在 Vercel 中导入项目

在 [New Project](https://vercel.com/new) 页面中，在 **Import Git Repository** 部分下，选择你想要从中导入项目的 Git 提供商。按照提示登录你的 GitHub 账户。

登录后，你应该能在“Import Git Repository”部分看到上一步中新创建的仓库。点击该项目旁边的“Import”按钮。

### 添加环境变量

你的应用使用环境密钥来存储 OpenAI API 密钥，在本地开发时通过 `.env.local` 文件实现。要将此 API 密钥添加到生产部署中，请展开“Environment Variables”部分并粘贴你的 `.env.local` 文件。Vercel 会自动解析你的变量，并以适当的 `key:value` 格式填入。

### 部署

点击 **Deploy** 按钮。Vercel 将根据所选配置创建项目并部署它。

### 享受彩带吧！

要查看你的部署，请在仪表板中选择该项目，然后选择 **Domain**。现在任何拥有该 URL 的人都可以访问此页面。

## 注意事项

部署 AI 应用时，有一些与基础设施相关的注意事项需要了解。

### 函数持续时间

在大多数情况下，你会在服务器上调用大型语言模型（LLM）。默认情况下，Vercel 无服务器函数在 Hobby 套餐上的最大持续时间为 10 秒。根据你的提示词，LLM 可能需要超过此限制的时间才能完成响应。如果响应未在此限制内完成，服务器将抛出错误。

你可以使用[路由段配置](https://nextjs.org/docs/app/api-reference/file-conventions/route-segment-config)来指定 Vercel 函数的最大持续时间。要更新最大持续时间，请将以下路由段配置添加到你的路由处理程序或调用服务器操作的页面顶部。

```ts
export const maxDuration = 30;
```

在 Hobby 套餐上，你可以将最大持续时间增加到 60 秒。对于其他套餐，[请参阅文档](https://vercel.com/docs/functions/runtimes#max-duration)了解限制。

### 请求取消

AI SDK UI 辅助函数（如 `useChat` 和 `useCompletion`）在你调用 `stop()` 时会中止客户端请求。要将该取消操作传播到 Vercel Function 及其模型请求，你必须：

1. 使用 Node.js 运行时，这是 Next.js 路由处理程序的默认运行时。
2. 在 `vercel.json` 中为该路由启用 [`supportsCancellation`](https://vercel.com/docs/functions/functions-api-reference#cancel-requests)。
3. 将路由的 `req.signal` 作为 `abortSignal` 转发给 `streamText` 或 `generateText`。

例如，为你的聊天路由启用取消：

```json filename="vercel.json"
{
  "functions": {
    "app/api/chat/route.ts": {
      "supportsCancellation": true
    }
  }
}
```

然后将请求信号转发给 AI SDK：

```ts filename="app/api/chat/route.ts" highlight="10"
import { convertToModelMessages, streamText, type UIMessage } from 'ai';
__PROVIDER_IMPORT__;

export async function POST(req: Request) {
  const { messages }: { messages: UIMessage[] } = await req.json();

  const result = streamText({
    model: __MODEL__,
    messages: convertToModelMessages(messages),
    abortSignal: req.signal,
  });

  return result.toUIMessageStreamResponse();
}
```

如果没有 `supportsCancellation`，调用 `stop()` 会关闭客户端流，但不会取消 Vercel Function 或模型请求。请参阅[停止流](/docs/advanced/stopping-streams)了解完整的客户端和服务器设置。

## 安全注意事项

鉴于调用 LLM 的高昂成本，采取措施保护你的应用免受滥用非常重要。

### 速率限制

速率限制是一种通过定义客户端在给定时间范围内可以向服务器发送的最大请求数来调节网络流量的方法。

按照[本指南](https://vercel.com/guides/securing-ai-app-rate-limiting)为你的应用添加速率限制。

### 防火墙

防火墙有助于保护你的应用和网站免受 DDoS 攻击和未经授权的访问。

[Vercel Firewall](https://vercel.com/docs/security/vercel-firewall) 是一套专为安全而设计的工具和基础设施。它会自动缓解 DDoS 攻击，企业团队还可以为其站点获得进一步的自定义配置，包括专属支持和用于 IP 阻止的自定义规则。
