# 速率限制

速率限制有助于保护您的 API 免受滥用。它涉及设置客户端在指定时间范围内可以发出的请求数量的最大阈值。这一简单技术充当守门员，防止过度使用导致服务性能下降并产生不必要的成本。

## 使用 Upstash Redis 和 Upstash Ratelimit 进行速率限制

在此示例中，您将使用 [Upstash Redis](https://upstash.com/redis) 和 [Upstash Ratelimit](https://github.com/upstash/ratelimit) 保护一个 API 端点。

```tsx filename='app/api/generate/route.ts'
import {
  createUIMessageStreamResponse,
  streamText,
  toUIMessageStream,
} from 'ai';
__PROVIDER_IMPORT__;
import { Ratelimit } from '@upstash/ratelimit';
import { Redis } from '@upstash/redis';
import { NextRequest } from 'next/server';

// 允许流式响应最长 30 秒
export const maxDuration = 30;

// 创建速率限制
const ratelimit = new Ratelimit({
  redis: Redis.fromEnv(),
  limiter: Ratelimit.fixedWindow(5, '30s'),
});

export async function POST(req: NextRequest) {
  // 使用请求 IP 调用速率限制
  const ip = req.ip ?? 'ip';
  const { success, remaining } = await ratelimit.limit(ip);

  // 如果未成功则阻止请求
  if (!success) {
    return new Response('Ratelimited!', { status: 429 });
  }

  const { messages } = await req.json();

  const result = streamText({
    model: __MODEL__,
    messages,
  });

  return createUIMessageStreamResponse({
    stream: toUIMessageStream({ stream: result.stream }),
  });
}
```

## 简化 API 保护

借助 Upstash Redis 和 Upstash Ratelimit，您可以轻松保护 API 免受此类攻击。要了解更多关于 Ratelimit 的工作原理以及如何根据您的需求进行配置，请参阅 [Ratelimit 文档](https://upstash.com/docs/oss/sdks/ts/ratelimit/overview)。
