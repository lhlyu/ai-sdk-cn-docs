# 使用语言模型渲染用户界面

语言模型生成文本，因此最初你可能认为只需在应用中渲染文本即可。

```tsx highlight="16" filename="app/actions.tsx"
const text = generateText({
  model: __MODEL__,
  instructions: 'You are a friendly assistant',
  prompt: 'What is the weather in SF?',
  tools: {
    getWeather: {
      description: 'Get the weather for a location',
      inputSchema: z.object({
        city: z.string().describe('The city to get the weather for'),
        unit: z
          .enum(['C', 'F'])
          .describe('The unit to display the temperature in'),
      }),
      execute: async ({ city, unit }) => {
        const weather = getWeather({ city, unit });
        return `It is currently ${weather.value}°${unit} and ${weather.description} in ${city}!`;
      },
    },
  },
});
```

上面，语言模型被传入了一个名为 `getWeather` 的[工具](/docs/ai-sdk-core/tools-and-tool-calling)，该工具以文本形式返回天气信息。然而，与其返回文本，如果你返回一个表示天气信息的 JSON 对象，就可以用它来渲染一个 React 组件。

```tsx highlight="18-23" filename="app/action.ts"
const text = generateText({
  model: __MODEL__,
  instructions: 'You are a friendly assistant',
  prompt: 'What is the weather in SF?',
  tools: {
    getWeather: {
      description: 'Get the weather for a location',
      inputSchema: z.object({
        city: z.string().describe('The city to get the weather for'),
        unit: z
          .enum(['C', 'F'])
          .describe('The unit to display the temperature in'),
      }),
      execute: async ({ city, unit }) => {
        const weather = getWeather({ city, unit });
        const { temperature, unit, description, forecast } = weather;

        return {
          temperature,
          unit,
          description,
          forecast,
        };
      },
    },
  },
});
```

现在，你可以使用 `getWeather` 函数返回的对象，通过将该对象作为 props 传入，有条件地渲染一个显示天气信息的 React 组件 `<WeatherCard/>`。

```tsx filename="app/page.tsx"
return (
  <div>
    {messages.map(message => {
      // 检查助手消息部分以获取工具结果
      if (message.role === 'assistant') {
        return message.parts.map(part => {
          if (
            part.type === 'tool-weather' &&
            part.state === 'output-available'
          ) {
            const { temperature, unit, description, forecast } = part.output;

            return (
              <WeatherCard
                weather={{
                  temperature,
                  unit,
                  description,
                  forecast,
                }}
              />
            );
          }
        });
      }
    })}
  </div>
);
```

以下是可能效果的小预览。

<div className="not-prose flex flex-col">
  <CardPlayer
    type="weather"
    title="天气"
    description="一个在流式组件中渲染天气信息的助手示例。"
  />
</div>

将界面作为语言模型生成的一部分进行渲染，可以提升应用的用户体验，让人们能够超越文本与语言模型进行交互。

它们还使你更容易解释在多个步骤中发生的[顺序工具调用](/docs/ai-sdk-rsc/multistep-interfaces)，并帮助识别和调试模型推理错误的位置。

## 渲染多个用户界面

回顾一下，应用需要经过以下步骤才能将用户界面作为模型生成的一部分进行渲染：

1. 用户向语言模型发出提示词。
2. 语言模型生成包含工具调用的响应。
3. 工具调用返回一个表示用户界面的 JSON 对象。
4. 响应被发送到客户端。
5. 客户端接收响应并检查最新消息是否为工具调用。
6. 如果是工具调用，客户端根据工具调用返回的 JSON 对象渲染用户界面。

大多数应用都有多个由语言模型调用的工具，每个工具可以返回不同的用户界面。

例如，一个搜索课程的工具可以返回课程列表，而一个搜索人员的工具可以返回人员列表。随着列表的增长，应用的复杂性也会增加，管理这些用户界面会变得越来越困难。

```tsx filename='app/page.tsx'
{
  message.parts.map(part => {
    if (part.state !== 'output-available') return null;

    switch (part.type) {
      case 'tool-api-search-course':
        return <Courses courses={part.output} />;
      case 'tool-api-search-profile':
        return <People people={part.output} />;
      case 'tool-api-meetings':
        return <Meetings meetings={part.output} />;
      case 'tool-api-search-building':
        return <Buildings buildings={part.output} />;
      case 'tool-api-events':
        return <Events events={part.output} />;
      case 'tool-api-meals':
        return <Meals meals={part.output} />;
      case 'text':
        return <div>{part.text}</div>;
      default:
        return null;
    }
  });
}
```

## 在服务器上渲染用户界面

**AI SDK RSC (`@ai-sdk/rsc`)** 利用 RSC 解决了在客户端管理所有 React 组件的问题，允许你在服务器上渲染 React 组件并将其流式传输到客户端。

你无需根据语言模型返回的数据在客户端有条件地渲染用户界面，而是可以在模型生成期间直接从服务器流式传输它们。

```tsx highlight="3,22-31,38" filename="app/action.ts"
import { createStreamableUI } from '@ai-sdk/rsc'

const uiStream = createStreamableUI();

const text = generateText({
  model: __MODEL__,
  instructions: 'you are a friendly assistant'
  prompt: 'what is the weather in SF?'
  tools: {
    getWeather: {
      description: 'Get the weather for a location',
      inputSchema: z.object({
        city: z.string().describe('The city to get the weather for'),
        unit: z
          .enum(['C', 'F'])
          .describe('The unit to display the temperature in')
      }),
      execute: async ({ city, unit }) => {
        const weather = getWeather({ city, unit })
        const { temperature, unit, description, forecast } = weather

        uiStream.done(
          <WeatherCard
            weather={{
              temperature: 47,
              unit: 'F',
              description: 'sunny'
              forecast,
            }}
          />
        )
      }
    }
  }
})

return {
  display: uiStream.value
}
```

[`createStreamableUI`](/docs/reference/ai-sdk-rsc/create-streamable-ui) 函数属于 `@ai-sdk/rsc` 模块，它创建一个可以将 React 组件发送到客户端的流。

在服务器上，你使用传入的 props 渲染 `<WeatherCard/>` 组件，然后将其流式传输到客户端。在客户端，你只需要渲染从服务器流式传输的 UI。

```tsx filename="app/page.tsx" highlight="4"
return (
  <div>
    {messages.map(message => (
      <div>{message.display}</div>
    ))}
  </div>
);
```

现在涉及的步骤简化了：

1. 用户向语言模型发出提示词。
2. 语言模型生成包含工具调用的响应。
3. 工具调用渲染一个 React 组件以及表示用户界面的相关 props。
4. 响应被流式传输到客户端并直接渲染。

> **注意：** 你也可以在服务器上渲染文本，并使用 React Server Components 将其流式传输到客户端。这样，从语言模型生成到 UI 渲染的所有操作都可以在服务器上完成，而客户端只需渲染从服务器流式传输的 UI。

请查看此[示例](/examples/next-app/interface/stream-component-updates)，了解如何在 Next.js App Router 中使用 React Server Components 流式传输组件更新的完整说明。
