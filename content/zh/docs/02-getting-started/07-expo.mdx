# Expo 快速入门

在本快速入门教程中，你将使用 [Expo](https://expo.dev/) 构建一个带有流式聊天用户界面的简单智能体。在此过程中，你将学习在项目中使用 SDK 所需的关键概念和技术。

如果你不熟悉[提示词工程](/docs/advanced/prompt-engineering)和 [HTTP 流式传输](/docs/foundations/streaming)的概念，可以选择先阅读这些文档。

## 前提条件

要遵循本快速入门，你需要：

- 在本地开发机器上安装 Node.js 22+ 和 pnpm。
- 一个 [Vercel AI Gateway](https://vercel.com/ai-gateway) API 密钥。

如果你尚未获得 Vercel AI Gateway API 密钥，可以通过在 Vercel 网站上[注册](https://vercel.com/d?to=%2F%5Bteam%5D%2F%7E%2Fai&title=Go+to+AI+Gateway)来获取。

## 创建你的应用

首先创建一个新的 Expo 应用程序。此命令将创建一个名为 `my-ai-app` 的新目录，并在其中设置一个基本的 Expo 应用程序。

<Snippet text="pnpm create expo-app@latest my-ai-app" />

导航到新创建的目录：

<Snippet text="cd my-ai-app" />

<Note>本指南需要 Expo 52 或更高版本。</Note>

### 安装依赖项

安装 `ai` 和 `@ai-sdk/react`，即 AI 包和 AI SDK 的 React Hooks。AI SDK 的 [Vercel AI Gateway 提供商](/providers/ai-sdk-providers/ai-gateway) 随 `ai` 包一起提供。你还需要安装 `zod`，这是一个用于定义工具输入的模式验证库。

<Note>
  本指南使用 Vercel AI Gateway 提供商，因此你可以使用一个 API 密钥访问来自不同提供商的数百个模型，但你可以通过安装其包来切换到任何提供商或模型。查看可用的 [AI SDK 提供商](/providers/ai-sdk-providers) 以获取更多信息。
</Note>

## 创建 API 路由

创建一个路由处理程序 `app/api/chat+api.ts` 并添加以下代码：

```tsx filename="app/api/chat+api.ts"
import {
  streamText,
  UIMessage,
  convertToModelMessages,
  createUIMessageStreamResponse,
  toUIMessageStream,
} from 'ai';
__PROVIDER_IMPORT__;

export async function POST(req: Request) {
  const { messages }: { messages: UIMessage[] } = await req.json();

  const result = streamText({
    model: __MODEL__,
    messages: await convertToModelMessages(messages),
  });

  return createUIMessageStreamResponse({
    stream: toUIMessageStream({ stream: result.stream }),
    headers: {
      'Content-Type': 'application/octet-stream',
      'Content-Encoding': 'none',
    },
  });
}
```

让我们看看这段代码中发生了什么：

1. 定义一个异步的 `POST` 请求处理程序，并从请求体中提取 `messages`。`messages` 变量包含你和聊天机器人之间的对话历史，为聊天机器人提供进行下一次生成所需的上下文。
2. 调用从 `ai` 包导入的 [`streamText`](/docs/reference/ai-sdk-core/stream-text) 函数。此函数接受一个配置对象，其中包含一个 `model` 提供商（从 `ai` 导入）和 `messages`（在步骤 1 中定义）。你可以传递额外的[设置](/docs/ai-sdk-core/settings)来进一步自定义模型的行为。
3. `streamText` 函数返回一个 [`StreamTextResult`](/docs/reference/ai-sdk-core/stream-text#result-object)。将其 `stream` 传递给 `toUIMessageStream`，并使用 `createUIMessageStreamResponse` 返回它，以创建一个流式响应对象。
4. 最后，将结果返回给客户端以流式传输响应。

此 API 路由在 `/api/chat` 创建了一个 POST 请求端点。

## 选择提供商

AI SDK 通过[第一方](/providers/ai-sdk-providers)、[兼容 OpenAI](/providers/openai-compatible-providers) 和[社区](/providers/community-providers)包支持数十个模型提供商。

本快速入门使用 [Vercel AI Gateway](https://vercel.com/ai-gateway) 提供商，它是默认的[全局提供商](/docs/ai-sdk-core/provider-management#global-provider-configuration)。这意味着你可以使用模型配置中的简单字符串来访问模型：

```ts

```

你也可以通过另外两种等效方式显式导入和使用网关提供商：

```ts
// 选项 1：从 'ai' 包导入（默认包含）
import { gateway } from 'ai';

// 选项 2：安装并从 '@ai-sdk/gateway' 包导入
import { gateway } from '@ai-sdk/gateway';
model: gateway('anthropic/claude-sonnet-4.5');
```

## 连接 UI

现在你已经有了一个可以查询 LLM 的 API 路由，是时候设置你的前端了。AI SDK 的 [UI](/docs/ai-sdk-ui) 包将聊天界面的复杂性抽象为一个 Hook：[`useChat`](/docs/reference/ai-sdk-ui/use-chat)。

使用以下代码更新你的根页面（`app/(tabs)/index.tsx`），以显示聊天消息列表并提供用户消息输入：

```tsx filename="app/(tabs)/index.tsx"
import { generateAPIUrl } from '@/utils';
import { useChat } from '@ai-sdk/react';
import { DefaultChatTransport } from 'ai';
import { fetch as expoFetch } from 'expo/fetch';
import { useState } from 'react';
import { View, TextInput, ScrollView, Text, SafeAreaView } from 'react-native';

export default function App() {
  const [input, setInput] = useState('');
  const { messages, error, sendMessage } = useChat({
    transport: new DefaultChatTransport({
      fetch: expoFetch as unknown as typeof globalThis.fetch,
      api: generateAPIUrl('/api/chat'),
    }),
    onError: error => console.error(error, 'ERROR'),
  });

  if (error) return <Text>{error.message}</Text>;

  return (
    <SafeAreaView style={{ height: '100%' }}>
      <View
        style={{
          height: '95%',
          display: 'flex',
          flexDirection: 'column',
          paddingHorizontal: 8,
        }}
      >
        <ScrollView style={{ flex: 1 }}>
          {messages.map(m => (
            <View key={m.id} style={{ marginVertical: 8 }}>
              <View>
                <Text style={{ fontWeight: 700 }}>{m.role}</Text>
                {m.parts.map((part, i) => {
                  switch (part.type) {
                    case 'text':
                      return <Text key={`${m.id}-${i}`}>{part.text}</Text>;
                  }
                })}
              </View>
            </View>
          ))}
        </ScrollView>

        <View style={{ marginTop: 8 }}>
          <TextInput
            style={{ backgroundColor: 'white', padding: 8 }}
            placeholder="说点什么..."
            value={input}
            onChange={e => setInput(e.nativeEvent.text)}
            onSubmitEditing={e => {
              e.preventDefault();
              sendMessage({ text: input });
              setInput('');
            }}
            autoFocus={true}
          />
        </View>
      </View>
    </SafeAreaView>
  );
}
```

此页面使用了 `useChat` Hook，默认情况下，它将使用你之前创建的 `POST` API 路由（`/api/chat`）。该 Hook 提供了用于处理用户输入和表单提交的函数和状态。`useChat` Hook 提供了多个实用函数和状态变量：

- `messages` - 当前的聊天消息（包含 `id`、`role` 和 `parts` 属性的对象数组）。
- `sendMessage` - 向聊天 API 发送消息的函数。

该组件使用本地状态（`useState`）来管理输入字段的值，并通过调用 `sendMessage` 并传入输入文本，然后清除输入字段来处理表单提交。

LLM 的响应通过消息的 `parts` 数组访问。每条消息都包含一个有序的 `parts` 数组，表示模型在其响应中生成的所有内容。这些部分可以包括纯文本、推理令牌等，你将在后面看到。`parts` 数组保留了模型输出的顺序，允许你按生成顺序显示或处理每个组件。

<Note>
  你使用 expo/fetch 函数而不是原生的 node fetch 来启用聊天响应的流式传输。这需要 Expo 52 或更高版本。
</Note>

### 创建 API URL 生成器

因为你使用 expo/fetch 进行流式响应而不是原生的 fetch 函数，所以需要一个 API URL 生成器来确保根据客户端环境（例如 Web 或移动端）使用正确的基础 URL 和格式。在项目根目录创建一个名为 `utils.ts` 的新文件，并添加以下代码：

```ts filename="utils.ts"
import Constants from 'expo-constants';

export const generateAPIUrl = (relativePath: string) => {
  const origin = Constants.experienceUrl.replace('exp://', 'http://');

  const path = relativePath.startsWith('/') ? relativePath : `/${relativePath}`;

  if (process.env.NODE_ENV === 'development') {
    return origin.concat(path);
  }

  if (!process.env.EXPO_PUBLIC_API_BASE_URL) {
    throw new Error(
      'EXPO_PUBLIC_API_BASE_URL 环境变量未定义',
    );
  }

  return process.env.EXPO_PUBLIC_API_BASE_URL.concat(path);
};
```

此实用函数处理开发和生产环境的 URL 生成，确保你的 API 调用在不同设备和配置下都能正常工作。

<Note>
  在部署到生产环境之前，你必须在生产环境中设置 `EXPO_PUBLIC_API_BASE_URL` 环境变量。此变量应指向你的 API 服务器的基础 URL。
</Note>

## 使用工具增强你的聊天机器人

虽然大型语言模型（LLM）具有令人难以置信的生成能力，但它们在处理离散任务（例如数学）和与外部世界交互（例如获取天气）方面存在困难。这就是[工具](/docs/ai-sdk-core/tools-and-tool-calling)发挥作用的地方。

工具是 LLM 可以调用的操作。这些操作的结果可以报告回 LLM，以便在下一个响应中考虑。

例如，如果用户询问当前天气，没有工具，模型只能根据其训练数据提供一般信息。但是有了天气工具，它可以获取并提供最新的、特定于位置的天气信息。

让我们通过添加一个简单的天气工具来增强你的聊天机器人。

### 更新你的 API 路由

修改你的 `app/api/chat+api.ts` 文件以包含新的天气工具：

```tsx filename="app/api/chat+api.ts" highlight="9,18-32"
import {
  streamText,
  UIMessage,
  convertToModelMessages,
  tool,
  createUIMessageStreamResponse,
  toUIMessageStream,
} from 'ai';
__PROVIDER_IMPORT__;
import { z } from 'zod';

export async function POST(req: Request) {
  const { messages }: { messages: UIMessage[] } = await req.json();

  const result = streamText({
    model: __MODEL__,
    messages: await convertToModelMessages(messages),
    tools: {
      weather: tool({
        description: '获取某个位置的天气（华氏度）',
        inputSchema: z.object({
          location: z.string().describe('要获取天气的位置'),
        }),
        execute: async ({ location }) => {
          const temperature = Math.round(Math.random() * (90 - 32) + 32);
          return {
            location,
            temperature,
          };
        },
      }),
    },
  });

  return createUIMessageStreamResponse({
    stream: toUIMessageStream({ stream: result.stream }),
    headers: {
      'Content-Type': 'application/octet-stream',
      'Content-Encoding': 'none',
    },
  });
}
```

在此更新后的代码中：

1. 你从 `ai` 包中导入了 `tool` 函数，并从 `zod` 导入了 `z` 用于模式验证。
2. 你定义了一个包含 `weather` 工具的 `tools` 对象。此工具：
   - 有一个描述，帮助模型理解何时使用它。
   - 使用 Zod 模式定义了 `inputSchema`，指定执行此工具需要一个 `location` 字符串。模型将尝试从对话上下文中提取此输入。如果无法提取，它将向用户询问缺失的信息。
   - 定义了一个 `execute` 函数，模拟获取天气数据（在本例中，它返回一个随机温度）。这是一个在服务器上运行的异步函数，因此你可以从外部 API 获取真实数据。

现在，你的聊天机器人可以为用户询问的任何位置“获取”天气信息。当模型确定需要使用天气工具时，它将生成一个带有必要输入的工具调用。然后，`execute` 函数将自动运行，工具输出将作为 `tool` 消息添加到 `messages` 中。

<Note>
  你可能需要重新启动开发服务器才能使更改生效。
</Note>

尝试询问类似“纽约的天气怎么样？”这样的问题，看看模型如何使用新工具。

注意到 UI 中的空白响应了吗？这是因为模型没有生成文本响应，而是生成了一个工具调用。你可以通过 `message.parts` 数组中的 `tool-weather` 部分在客户端访问工具调用和随后的工具结果。

<Note>
  工具部分始终命名为 `tool-{toolName}`，其中 `{toolName}` 是你在定义工具时使用的键。在这种情况下，由于我们将工具定义为 `weather`，因此部分类型是 `tool-weather`。
</Note>

## 启用多步骤工具调用

你可能已经注意到，虽然工具结果在聊天界面中可见，但模型并未使用此信息来回答你的原始查询。这是因为一旦模型生成了工具调用，它在技术上就完成了生成。

为了解决这个问题，你可以使用 `stopWhen` 启用多步骤工具调用。默认情况下，`stopWhen` 设置为 `isStepCount(1)`，这意味着当存在工具结果时，生成在第一步后停止。通过更改此条件，你可以允许模型自动将工具结果发送回自身，以触发额外的生成，直到满足你指定的停止条件。在这种情况下，你希望模型继续生成，以便它可以使用天气工具结果来回答你的原始问题。

### 更新你的 API 路由

修改你的 `app/api/chat+api.ts` 文件以包含 `stopWhen` 条件：

```tsx filename="app/api/chat+api.ts" highlight="19"
import {
  streamText,
  UIMessage,
  convertToModelMessages,
  tool,
  isStepCount,
  createUIMessageStreamResponse,
  toUIMessageStream,
} from 'ai';
__PROVIDER_IMPORT__;
import { z } from 'zod';

export async function POST(req: Request) {
  const { messages }: { messages: UIMessage[] } = await req.json();

  const result = streamText({
    model: __MODEL__,
    messages: await convertToModelMessages(messages),
    stopWhen: isStepCount(5),
    tools: {
      weather: tool({
        description: '获取某个位置的天气（华氏度）',
        inputSchema: z.object({
          location: z.string().describe('要获取天气的位置'),
        }),
        execute: async ({ location }) => {
          const temperature = Math.round(Math.random() * (90 - 32) + 32);
          return {
            location,
            temperature,
          };
        },
      }),
    },
  });

  return createUIMessageStreamResponse({
    stream: toUIMessageStream({ stream: result.stream }),
    headers: {
      'Content-Type': 'application/octet-stream',
      'Content-Encoding': 'none',
    },
  });
}
```

<Note>
  你可能需要重新启动开发服务器才能使更改生效。
</Note>

返回 Expo 应用程序并询问某个位置的天气。你现在应该看到模型使用天气工具结果来回答你的问题。

通过设置 `stopWhen: isStepCount(5)`，你允许模型在任何给定的生成中使用最多 5 个“步骤”。这可以实现更复杂的交互，并允许模型在需要时通过多个步骤收集和处理信息。你可以通过添加另一个工具将温度从华氏度转换为摄氏度来看到这一点。

### 添加更多工具

更新你的 `app/api/chat+api.ts` 文件以添加一个新工具，将温度从华氏度转换为摄氏度：

```tsx filename="app/api/chat+api.ts" highlight="34-47"
import {
  streamText,
  UIMessage,
  convertToModelMessages,
  tool,
  isStepCount,
  createUIMessageStreamResponse,
  toUIMessageStream,
} from 'ai';
__PROVIDER_IMPORT__;
import { z } from 'zod';

export async function POST(req: Request) {
  const { messages }: { messages: UIMessage[] } = await req.json();

  const result = streamText({
    model: __MODEL__,
    messages: await convertToModelMessages(messages),
    stopWhen: isStepCount(5),
    tools: {
      weather: tool({
        description: '获取某个位置的天气（华氏度）',
        inputSchema: z.object({
          location: z.string().describe('要获取天气的位置'),
        }),
        execute: async ({ location }) => {
          const temperature = Math.round(Math.random() * (90 - 32) + 32);
          return {
            location,
            temperature,
          };
        },
      }),
      convertFahrenheitToCelsius: tool({
        description: '将华氏度温度转换为摄氏度',
        inputSchema: z.object({
          temperature: z
            .number()
            .describe('要转换的华氏度温度'),
        }),
        execute: async ({ temperature }) => {
          const celsius = Math.round((temperature - 32) * (5 / 9));
          return {
            celsius,
          };
        },
      }),
    },
  });

  return createUIMessageStreamResponse({
    stream: toUIMessageStream({ stream: result.stream }),
    headers: {
      'Content-Type': 'application/octet-stream',
      'Content-Encoding': 'none',
    },
  });
}
```

<Note>
  你可能需要重新启动开发服务器才能使更改生效。
</Note>

### 为新工具更新 UI

要在 UI 中显示温度转换工具调用，请更新你的 `app/(tabs)/index.tsx` 文件以处理新的工具部分：

```tsx filename="app/(tabs)/index.tsx" highlight="39-45"
import { generateAPIUrl } from '@/utils';
import { useChat } from '@ai-sdk/react';
import { DefaultChatTransport } from 'ai';
import { fetch as expoFetch } from 'expo/fetch';
import { useState } from 'react';
import { View, TextInput, ScrollView, Text, SafeAreaView } from 'react-native';

export default function App() {
  const [input, setInput] = useState('');
  const { messages, error, sendMessage } = useChat({
    transport: new DefaultChatTransport({
      fetch: expoFetch as unknown as typeof globalThis.fetch,
      api: generateAPIUrl('/api/chat'),
    }),
    onError: error => console.error(error, 'ERROR'),
  });

  if (error) return <Text>{error.message}</Text>;

  return (
    <SafeAreaView style={{ height: '100%' }}>
      <View
        style={{
          height: '95%',
          display: 'flex',
          flexDirection: 'column',
          paddingHorizontal: 8,
        }}
      >
        <ScrollView style={{ flex: 1 }}>
          {messages.map(m => (
            <View key={m.id} style={{ marginVertical: 8 }}>
              <View>
                <Text style={{ fontWeight: 700 }}>{m.role}</Text>
                {m.parts.map((part, i) => {
                  switch (part.type) {
                    case 'text':
                      return <Text key={`${m.id}-${i}`}>{part.text}</Text>;
                    case 'tool-weather':
                    case 'tool-convertFahrenheitToCelsius':
                      return (
                        <Text key={`${m.id}-${i}`}>
                          {JSON.stringify(part, null, 2)}
                        </Text>
                      );
                  }
                })}
              </View>
            </View>
          ))}
        </ScrollView>

        <View style={{ marginTop: 8 }}>
          <TextInput
            style={{ backgroundColor: 'white', padding: 8 }}
            placeholder="说点什么..."
            value={input}
            onChange={e => setInput(e.nativeEvent.text)}
            onSubmitEditing={e => {
              e.preventDefault();
              sendMessage({ text: input });
              setInput('');
            }}
            autoFocus={true}
          />
        </View>
      </View>
    </SafeAreaView>
  );
}
```

<Note>
  你可能需要重新启动开发服务器才能使更改生效。
</Note>

现在，当你询问“纽约的天气是多少摄氏度？”时，你应该会看到一个更完整的交互：

1. 模型将为纽约调用天气工具。
2. 你将看到显示的工具结果。
3. 然后它将调用温度转换工具，将温度从华氏度转换为摄氏度。
4. 模型将使用该信息提供关于纽约天气的自然语言响应。

这种多步骤方法允许模型收集信息并使用它来提供更准确和上下文相关的响应，使你的聊天机器人更加有用。

这个简单的例子演示了工具如何扩展模型的能力。你可以创建更复杂的工具来与真实的 API、数据库或任何其他外部系统集成，允许模型实时访问和处理现实世界的数据。工具弥合了模型知识截止日期和当前信息之间的差距。

## Polyfills

AI SDK 内部使用的几个函数可能在你的 Expo 运行时中不可用，具体取决于你的配置和目标平台。

首先，安装以下包：

<InstallPackages packages="@ungap/structured-clone @stardazed/streams-text-encoding" />

然后在项目根目录创建一个包含以下 polyfills 的新文件：

```ts filename="polyfills.js"
import { Platform } from 'react-native';
import structuredClone from '@ungap/structured-clone';

if (Platform.OS !== 'web') {
  const setupPolyfills = async () => {
    const { polyfillGlobal } =
      await import('react-native/Libraries/Utilities/PolyfillFunctions');

    const { TextEncoderStream, TextDecoderStream } =
      await import('@stardazed/streams-text-encoding');

    if (!('structuredClone' in global)) {
      polyfillGlobal('structuredClone', () => structuredClone);
    }

    polyfillGlobal('TextEncoderStream', () => TextEncoderStream);
    polyfillGlobal('TextDecoderStream', () => TextDecoderStream);
  };

  setupPolyfills();
}

export {};
```

最后，在你的根 `_layout.tsx` 中导入 polyfills：

```ts filename="_layout.tsx"
import '@/polyfills';
```
