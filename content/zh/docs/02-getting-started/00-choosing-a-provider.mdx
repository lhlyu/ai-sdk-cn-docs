# 选择提供商

AI SDK 通过[第一方](/providers/ai-sdk-providers)、[OpenAI 兼容](/providers/openai-compatible-providers)和[社区](/providers/community-providers)包支持数十种模型提供商。

```ts
import { generateText } from 'ai';
__PROVIDER_IMPORT__;

const { text } = await generateText({
  model: __MODEL__,
  prompt: 'What is love?',
});
```

## AI Gateway

[Vercel AI Gateway](/providers/ai-sdk-providers/ai-gateway) 是开始使用 AI SDK 的最快方式。访问来自 OpenAI、Anthropic、Google 和其他提供商的模型。使用 [OIDC](https://ai-sdk.dev/providers/ai-sdk-providers/ai-gateway#oidc-authentication-vercel-deployments) 或 AI Gateway API 密钥进行身份验证

将你的 API 密钥添加到环境中：

```env filename=".env.local"
AI_GATEWAY_API_KEY=your_api_key_here
```

AI Gateway 是默认的[全局提供商](/docs/ai-sdk-core/provider-management#global-provider-configuration)，因此你可以使用简单的字符串访问模型：

```ts
import { generateText } from 'ai';

const { text } = await generateText({
  model: 'anthropic/claude-sonnet-5',
  prompt: 'What is love?',
});
```

你也可以显式导入并使用 gateway 提供商：

```ts
// Option 1: Import from 'ai' package (included by default)
import { gateway } from 'ai';
model: gateway('anthropic/claude-sonnet-5');

// Option 2: Install and import from '@ai-sdk/gateway' package
import { gateway } from '@ai-sdk/gateway';
model: gateway('anthropic/claude-sonnet-5');
```

## 使用专用提供商

你也可以直接使用[第一方](/providers/ai-sdk-providers)、[OpenAI 兼容](/providers/openai-compatible-providers)和[社区](/providers/community-providers)提供商包。安装包并创建提供商实例。例如，要使用 Anthropic：

<InstallPackages packages="@ai-sdk/anthropic" />

```ts
import { anthropic } from '@ai-sdk/anthropic';

model: anthropic('claude-sonnet-5');
```

你可以更改默认的全局提供商，以便字符串模型引用在应用程序的任何位置都使用你首选的提供商。详细了解[提供商管理](/docs/ai-sdk-core/provider-management#global-provider-configuration)。

查看[可用提供商](/providers/ai-sdk-providers)以获取每个提供商的设置说明。

## 自定义提供商

你可以构建自己的提供商，将任何服务与 AI SDK 集成。AI SDK 提供了[语言模型规范](https://github.com/vercel/ai/tree/main/packages/provider/src/language-model/v3)，以确保跨提供商的兼容性。

```ts
import { generateText } from 'ai';
import { yourProvider } from 'your-custom-provider';

const { text } = await generateText({
  model: yourProvider('your-model-id'),
  prompt: 'What is love?',
});
```

查看[编写自定义提供商](/providers/community-providers/custom-providers)以获取完整指南。
