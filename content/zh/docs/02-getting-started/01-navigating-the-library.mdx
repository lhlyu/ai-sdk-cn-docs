# 浏览库

AI SDK 是一个用于构建 AI 应用程序的强大工具包。本页将帮助您根据需求选择合适的工具。

首先快速了解 AI SDK 的三大组成部分：

- **[AI SDK Core](/docs/ai-sdk-core/overview)：** 一个统一且与提供商无关的 API，用于通过大语言模型生成文本、结构化对象和工具调用。
- **[AI SDK UI](/docs/ai-sdk-ui/overview)：** 一组与框架无关的 Hook，用于构建聊天和生成式用户界面。
- **[AI SDK RSC](/docs/ai-sdk-rsc/overview)：** 使用 React Server Components (RSC) 流式传输生成式用户界面。目前开发阶段为实验性，建议使用 [AI SDK UI](/docs/ai-sdk-ui/overview)。

## 为您的环境选择合适的工具

在决定使用 AI SDK 的哪个部分时，首先应考虑您所处的环境和现有技术栈。SDK 的不同组件针对特定框架和环境进行了优化。

| 库                                       | 用途                                                                                                                                                                                                  | 环境兼容性                                                          |
| ---------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------- |
| [AI SDK Core](/docs/ai-sdk-core/overview) | 通过统一 API 调用任何大语言模型（例如 [generateText](/docs/reference/ai-sdk-core/generate-text) 和 [streamText](/docs/reference/ai-sdk-core/stream-text)）                                            | 任何 JS 环境（例如 Node.js、Deno、浏览器）                          |
| [AI SDK UI](/docs/ai-sdk-ui/overview)     | 构建流式聊天和生成式用户界面（例如 [useChat](/docs/reference/ai-sdk-ui/use-chat)）                                                                                                                    | React & Next.js、Vue & Nuxt、Svelte & SvelteKit                     |
| [AI SDK RSC](/docs/ai-sdk-rsc/overview)   | 从服务器向客户端流式传输生成式用户界面（例如 [streamUI](/docs/reference/ai-sdk-rsc/stream-ui)）。目前开发阶段为实验性，建议使用 [AI SDK UI](/docs/ai-sdk-ui/overview)。                               | 任何支持 React Server Components 的框架（例如 Next.js）             |

## 何时使用 AI SDK UI

AI SDK UI 提供了一组与框架无关的 Hook，用于快速构建**生产就绪的 AI 原生应用程序**。它提供：

- 对流式聊天和客户端生成式用户界面的全面支持
- 处理常见 AI 交互模式（如聊天、补全、助手）的实用工具
- 经过生产验证的可靠性和性能
- 跨流行框架的兼容性

## 何时使用 AI SDK RSC

<Note type="warning">
  AI SDK RSC 目前处于实验阶段。建议在生产环境中使用 [AI SDK
  UI](/docs/ai-sdk-ui/overview)。有关从 RSC 迁移到 UI 的指导，请参阅我们的[迁移指南](/docs/ai-sdk-rsc/migrating-to-ui)。
</Note>

[React Server Components](https://nextjs.org/docs/app/building-your-application/rendering/server-components)
(RSC) 提供了一种构建 React 应用程序的新方法，允许组件在服务器上渲染、直接获取数据，并将结果流式传输到客户端，从而减少包体积并提升性能。它们还引入了一种从应用程序任意位置调用服务器端函数的新方式，称为 [Server Actions](https://nextjs.org/docs/app/building-your-application/data-fetching/server-actions-and-mutations)。

AI SDK RSC 提供了多种实用工具，允许您将值和用户界面直接从服务器流式传输到客户端。然而，**了解当前限制非常重要**：

- **取消操作**：目前无法使用 Server Actions 中止流。这将在 React 和 Next.js 的未来版本中得到改进。
- **数据传输增加**：使用 [`createStreamableUI`](/docs/reference/ai-sdk-rsc/create-streamable-ui) 可能导致二次方数据传输（与生成文本长度成二次方关系）。您可以使用 [`createStreamableValue`](/docs/reference/ai-sdk-rsc/create-streamable-value) 来避免此问题，并在客户端渲染组件。
- **流式传输期间的重新挂载问题**：使用 `createStreamableUI` 时，组件会在 `.done()` 时重新挂载，导致[闪烁](https://github.com/vercel/ai/issues/2232)。

鉴于这些限制，**我们建议在生产应用程序中使用 [AI SDK UI](/docs/ai-sdk-ui/overview)**。
