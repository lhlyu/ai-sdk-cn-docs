# 终端 UI

`@ai-sdk/tui` 包让你可以在交互式终端界面中运行本地 `ToolLoopAgent`，或通过 `ChatTransport` 连接到远程智能体。
它适用于本地开发、演示以及内部工具，这些场景下终端体验已经足够，你无需构建自定义 UI。

终端 UI 处理提示词输入、流式传输的助手响应、markdown 渲染、工具卡片、推理部分、滚动以及工具审批提示。

## 安装

将 `@ai-sdk/tui` 与你使用的 `ai` 和提供商包一起安装：

<Snippet text={`pnpm add @ai-sdk/tui ai @ai-sdk/openai`} prompt={false} />

## 运行智能体

创建一个 `ToolLoopAgent` 并将其传递给 `runAgentTUI`：

```ts
import { openai } from '@ai-sdk/openai';
import { runAgentTUI } from '@ai-sdk/tui';
import { ToolLoopAgent, tool } from 'ai';
import { z } from 'zod';

const agent = new ToolLoopAgent({
  model: openai('gpt-6-astra'),
  instructions:
    'You are a helpful terminal assistant. Answer in markdown and use tools when they help.',
  tools: {
    weather: tool({
      description: 'Get the weather in a location',
      inputSchema: z.object({
        location: z.string().describe('The location to get the weather for'),
      }),
      execute: async ({ location }) => ({
        location,
        temperature: 72,
      }),
    }),
  },
});

await runAgentTUI({
  title: 'Weather Agent',
  agent,
});
```

`runAgentTUI` 会一直运行，直到用户通过 `Esc` 或 `Ctrl+C` 退出。

## 连接到远程智能体

传入 `ChatTransport` 而不是 `agent`，即可将终端 UI 连接到远程 AI SDK UI 消息端点：

```ts
import { runAgentTUI } from '@ai-sdk/tui';
import { DefaultChatTransport } from 'ai';

await runAgentTUI({
  title: 'Remote Agent',
  transport: new DefaultChatTransport({
    api: 'https://example.com/api/chat',
  }),
});
```

transport 控制端点、身份验证、请求体以及其他远程通信行为。终端 UI 会将其内部聊天 id 和消息历史保持为 transport 契约的私有内容。

## 沙箱

当你的智能体工具需要执行环境时，通过 `sandbox` 选项传入沙箱会话：

```ts
import { createJustBashSandbox } from '@ai-sdk/sandbox-just-bash';

const sandboxSession = await createJustBashSandbox({
  cwd: '/home/user',
}).createSession();

await runAgentTUI({
  title: 'Sandbox Agent',
  agent,
  sandbox: sandboxSession.restricted(),
});
```

终端 UI 会将沙箱作为 `experimental_sandbox` 转发给每次智能体调用。工具描述函数和工具 `execute` 函数可以从它们的选项中读取它，并将命令或文件操作委托给它。
如果模型需要了解工作目录、公共主机名或暴露端口等详细信息，请将沙箱描述添加到你的智能体指令中。

## 显示选项

你可以控制工具调用、推理和响应统计信息的显示方式：

```ts
await runAgentTUI({
  title: 'Weather Agent',
  agent,
  tools: 'auto-collapsed',
  reasoning: 'collapsed',
  responseStatistics: 'outputTokensPerSecond',
  contextSize: 200_000,
});
```

设置项：

- `tools`：控制工具调用的渲染方式。使用 `"full"` 显示工具输入和输出，使用 `"collapsed"` 仅显示工具卡片，使用 `"auto-collapsed"` 显示最新工具展开，直到出现另一个可见部分，或使用 `"hidden"` 省略工具调用。默认为 `"auto-collapsed"`。
- `reasoning`：控制推理的渲染方式。使用 `"full"` 显示推理，使用 `"collapsed"` 仅显示推理卡片，使用 `"auto-collapsed"` 显示最新推理展开，直到出现另一个可见部分，或使用 `"hidden"` 省略推理。默认为 `"auto-collapsed"`。
- `responseStatistics`：使用 `"outputTokensPerSecond"` 显示输出 token 吞吐量，或使用 `"outputTokenCount"` 显示输出 token 数量。默认为 `"outputTokensPerSecond"`。
- `contextSize`：提供后，终端 UI 会以模型上下文窗口的百分比显示总 token 使用量。

## 工具审批

`runAgentTUI` 支持 `ToolLoopAgent` 工具审批流程。当智能体发出手动审批请求时，终端 UI 会提示用户批准或拒绝该工具调用，然后智能体才会继续。

```ts
const agent = new ToolLoopAgent({
  model: openai('gpt-6-astra'),
  tools: { weather },
  toolApproval: {
    weather: ({ location }) =>
      location.toLowerCase().includes('san francisco')
        ? 'approved'
        : 'user-approval',
  },
});

await runAgentTUI({ title: 'Weather Agent', agent });
```

## 兼容性

使用 `agent` 选项时，智能体必须能够直接从终端用户输入运行。它不能要求每次调用提供选项，也不能使用结构化输出，因为终端 UI 无法从自由形式的提示词中推断这些值。对于需要自定义请求处理的远程智能体，请使用 `transport`。

对于需要固定提示词、调用选项、结构化输出、自定义结果检查或自定义流处理的示例或应用，请直接使用 `agent.generate()` 或 `agent.stream()`。

## 控制

- `Enter`：提交提示词
- `y` / `n`：批准或拒绝工具调用
- `Up` / `Down`：滚动对话记录
- `PageUp` / `PageDown`：按整页滚动对话记录
- `Ctrl+L`：重绘
- `Esc` / `Ctrl+C`：退出
