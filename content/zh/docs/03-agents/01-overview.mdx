# 智能体

智能体是**大语言模型 (LLM)**，通过**循环**使用**工具**来完成任务。

这些组件协同工作：

- **LLM** 处理输入并决定下一步操作
- **工具** 扩展了文本生成之外的能力（读取文件、调用 API、写入数据库）
- **循环** 通过以下方式编排执行：
  - **上下文管理** - 维护对话历史，并决定模型在每个步骤中看到的内容（输入）
  - **停止条件** - 确定循环（任务）何时完成

## 智能体状态与上下文

智能体通常需要服务端状态，这些状态不应直接放入提示词中，例如租户设置、请求 ID、功能开关、凭据或任务进度。

使用 `runtimeContext` 作为智能体的共享运行时状态。它流经智能体循环，在 `prepareStep` 和生命周期回调中可用，并且可以在步骤之间更新。使用 `toolsContext` 存储每个工具的值，例如 API 密钥或作用域权限；每个工具仅根据其 `contextSchema` 接收其自身的类型化 `context`。

在[运行时与工具上下文](/docs/ai-sdk-core/runtime-and-tool-context)中了解更多。

## ToolLoopAgent 类

ToolLoopAgent 类处理这三个组件。以下是一个在循环中使用多个工具来完成任务的智能体：

```ts
import { ToolLoopAgent, tool } from 'ai';
__PROVIDER_IMPORT__;
import { z } from 'zod';

const weatherAgent = new ToolLoopAgent({
  model: __MODEL__,
  tools: {
    weather: tool({
      description: '获取某个位置的天气（华氏度）',
      inputSchema: z.object({
        location: z.string().describe('要获取天气的位置'),
      }),
      execute: async ({ location }) => ({
        location,
        temperature: 72 + Math.floor(Math.random() * 21) - 10,
      }),
    }),
    convertFahrenheitToCelsius: tool({
      description: '将温度从华氏度转换为摄氏度',
      inputSchema: z.object({
        temperature: z.number().describe('华氏度温度'),
      }),
      execute: async ({ temperature }) => {
        const celsius = Math.round((temperature - 32) * (5 / 9));
        return { celsius };
      },
    }),
  },
});

const result = await weatherAgent.generate({
  prompt: '旧金山的天气是多少摄氏度？',
});

console.log(result.text); // 智能体的最终回答
console.log(result.steps); // 智能体执行的步骤
```

智能体会自动：

1. 调用 `weather` 工具获取华氏度温度
2. 调用 `convertFahrenheitToCelsius` 进行转换
3. 生成包含结果的最终文本响应

ToolLoopAgent 处理循环、上下文管理和停止条件。

## 为什么使用 ToolLoopAgent？

ToolLoopAgent 是使用 AI SDK 构建智能体的推荐方法，因为它：

- **减少样板代码** - 管理循环和消息数组
- **提高可重用性** - 定义一次，在整个应用程序中使用
- **简化维护** - 单一位置更新智能体配置

对于大多数用例，从 ToolLoopAgent 开始。当您需要对复杂结构化工作流的每个步骤进行显式控制时，请使用核心函数（`generateText`、`streamText`）。

## HarnessAgent 类

当您想要运行预配置的既定 harness（例如 Claude Code、Codex 或 Pi），而不是围绕语言模型自行构建循环时，请使用 `HarnessAgent`。Harness 是与提供商和模型不同的抽象层，但会流式传输到 AI SDK 兼容的结果和 UI 原语中。

在 [Harnesses](/docs/ai-sdk-harnesses) 和 [HarnessAgent](/docs/ai-sdk-harnesses/harness-agent) 中了解更多。

本节其余部分将重点介绍 `ToolLoopAgent`，它是用于构建您自己的模型和工具循环的 AI SDK 智能体类。

## 终端 UI

使用 `@ai-sdk/tui` 在交互式终端 UI 中运行 `ToolLoopAgent`。这对于本地智能体开发、演示和内部工具非常有用，在这些场景中，您希望无需构建自定义界面即可获得提示输入、流式响应、工具卡片、推理部分、滚动和工具批准提示。

```ts
import { runAgentTUI } from '@ai-sdk/tui';

await runAgentTUI({
  title: '天气智能体',
  agent: weatherAgent,
});
```

在[终端 UI](/docs/agents/terminal-ui) 中了解更多。

## 结构化工作流

智能体灵活且强大，但具有非确定性。当您需要具有显式控制流的可靠、可重复的结果时，请使用核心函数结合结构化工作流模式，包括：

- 用于显式分支的条件语句
- 用于可重用逻辑的标准函数
- 用于鲁棒性的错误处理
- 用于可预测性的显式控制流

[探索工作流模式](/docs/agents/workflows) 以了解有关构建结构化、可靠系统的更多信息。
