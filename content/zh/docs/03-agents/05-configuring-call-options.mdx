# 配置调用选项

调用选项允许你向智能体传递类型安全的结构化输入。使用它们可以根据特定请求动态修改任何智能体设置。

## 为什么使用调用选项？

当你需要智能体行为根据运行时输入变化时：

- **添加动态上下文** - 将检索到的文档、用户偏好或会话数据注入提示词
- **动态选择模型** - 根据请求复杂度选择更快或能力更强的模型
- **按请求配置工具** - 将用户位置传递给搜索工具或调整工具行为
- **自定义提供商选项** - 设置推理努力度、温度或其他提供商特定设置

没有调用选项，你需要创建多个智能体或在智能体外部处理配置逻辑。

## 工作原理

通过三个步骤定义调用选项：

1. **定义模式** - 使用 `callOptionsSchema` 指定你接受的输入
2. **使用 `prepareCall` 配置** - 利用这些输入修改智能体设置
3. **运行时传递选项** - 在调用 `generate()` 或 `stream()` 时提供选项

## 基本示例

在运行时向智能体的提示词添加用户上下文：

```ts
import { ToolLoopAgent } from 'ai';
__PROVIDER_IMPORT__;
import { z } from 'zod';

const supportAgent = new ToolLoopAgent({
  model: __MODEL__,
  callOptionsSchema: z.object({
    userId: z.string(),
    accountType: z.enum(['free', 'pro', 'enterprise']),
  }),
  instructions: '你是一位乐于助人的客户支持智能体。',
  prepareCall: ({ options, ...settings }) => ({
    ...settings,
    instructions:
      settings.instructions +
      `\n用户上下文：
- 账户类型：${options.accountType}
- 用户 ID：${options.userId}

根据用户的账户级别调整你的回复。`,
  }),
});

// 使用特定用户上下文调用智能体
const result = await supportAgent.generate({
  prompt: '如何升级我的账户？',
  options: {
    userId: 'user_123',
    accountType: 'free',
  },
});
```

现在 `options` 参数是必需的且经过类型检查。如果你不提供它或传递错误的类型，TypeScript 会报错。

## 修改智能体设置

使用 `prepareCall` 修改任何智能体设置。只返回你想要更改的设置。

### 动态模型选择

根据请求特征选择模型：

```ts
import { ToolLoopAgent } from 'ai';
__PROVIDER_IMPORT__;
import { z } from 'zod';

const agent = new ToolLoopAgent({
  model: __MODEL__, // 默认模型
  callOptionsSchema: z.object({
    complexity: z.enum(['simple', 'complex']),
  }),
  prepareCall: ({ options, ...settings }) => ({
    ...settings,
    model:
      options.complexity === 'simple' ? 'openai/gpt-4o-mini' : 'openai/o1-mini',
  }),
});

// 对简单查询使用更快的模型
await agent.generate({
  prompt: '2+2 等于多少？',
  options: { complexity: 'simple' },
});

// 对复杂推理使用能力更强的模型
await agent.generate({
  prompt: '解释量子纠缠',
  options: { complexity: 'complex' },
});
```

### 动态工具配置

根据运行时输入配置工具：

```ts
import { openai } from '@ai-sdk/openai';
import { ToolLoopAgent } from 'ai';
__PROVIDER_IMPORT__;
import { z } from 'zod';

const newsAgent = new ToolLoopAgent({
  model: __MODEL__,
  callOptionsSchema: z.object({
    userCity: z.string().optional(),
    userRegion: z.string().optional(),
  }),
  tools: {
    web_search: openai.tools.webSearch(),
  },
  prepareCall: ({ options, ...settings }) => ({
    ...settings,
    tools: {
      web_search: openai.tools.webSearch({
        searchContextSize: 'low',
        userLocation: {
          type: 'approximate',
          city: options.userCity,
          region: options.userRegion,
          country: 'US',
        },
      }),
    },
  }),
});

await newsAgent.generate({
  prompt: '有哪些本地头条新闻？',
  options: {
    userCity: '旧金山',
    userRegion: '加利福尼亚',
  },
});
```

### 提供商特定选项

动态配置提供商设置：

```ts
import { OpenAILanguageModelResponsesOptions } from '@ai-sdk/openai';
import { ToolLoopAgent } from 'ai';
import { z } from 'zod';

const agent = new ToolLoopAgent({
  model: 'openai/o3',
  callOptionsSchema: z.object({
    taskDifficulty: z.enum(['low', 'medium', 'high']),
  }),
  prepareCall: ({ options, ...settings }) => ({
    ...settings,
    providerOptions: {
      openai: {
        reasoningEffort: options.taskDifficulty,
      } satisfies OpenAILanguageModelResponsesOptions,
    },
  }),
});

await agent.generate({
  prompt: '分析这个复杂场景……',
  options: { taskDifficulty: 'high' },
});
```

## 高级模式

### 检索增强生成（RAG）

获取相关上下文并将其注入提示词：

```ts
import { ToolLoopAgent } from 'ai';
__PROVIDER_IMPORT__;
import { z } from 'zod';

const ragAgent = new ToolLoopAgent({
  model: __MODEL__,
  callOptionsSchema: z.object({
    query: z.string(),
  }),
  prepareCall: async ({ options, ...settings }) => {
    // 获取相关文档（这可以是异步的）
    const documents = await vectorSearch(options.query);

    return {
      ...settings,
      instructions: `使用以下上下文回答问题：

${documents.map(doc => doc.content).join('\n\n')}`,
    };
  },
});

await ragAgent.generate({
  prompt: '我们的退款政策是什么？',
  options: { query: '退款政策' },
});
```

`prepareCall` 函数可以是异步的，使你能够在配置智能体之前获取数据。

### 组合多个修改

一起修改多个设置：

```ts
import { ToolLoopAgent } from 'ai';
__PROVIDER_IMPORT__;
import { z } from 'zod';

const agent = new ToolLoopAgent({
  model: __MODEL__,
  callOptionsSchema: z.object({
    userRole: z.enum(['admin', 'user']),
    urgency: z.enum(['low', 'high']),
  }),
  tools: {
    readDatabase: readDatabaseTool,
    writeDatabase: writeDatabaseTool,
  },
  prepareCall: ({ options, ...settings }) => ({
    ...settings,
    // 对紧急请求升级模型
    model: options.urgency === 'high' ? __MODEL__ : settings.model,
    // 根据用户角色限制工具
    activeTools:
      options.userRole === 'admin'
        ? ['readDatabase', 'writeDatabase']
        : ['readDatabase'],
    // 调整指令
    instructions: `你是一位 ${options.userRole} 助手。
${options.userRole === 'admin' ? '你拥有完整的数据库访问权限。' : '你只有只读访问权限。'}`,
  }),
});

await agent.generate({
  prompt: '更新用户记录',
  options: {
    userRole: 'admin',
    urgency: 'high',
  },
});
```

## 与 createAgentUIStreamResponse 一起使用

通过 API 路由将调用选项传递给智能体：

```ts filename="app/api/chat/route.ts"
import { createAgentUIStreamResponse } from 'ai';
import { myAgent } from '@/ai/agents/my-agent';

export async function POST(request: Request) {
  const { messages, userId, accountType } = await request.json();

  return createAgentUIStreamResponse({
    agent: myAgent,
    messages,
    options: {
      userId,
      accountType,
    },
  });
}
```
