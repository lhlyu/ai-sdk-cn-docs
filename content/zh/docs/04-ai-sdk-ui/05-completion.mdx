# 完成

`useCompletion` Hook 允许你在应用中创建用户界面来处理文本补全。它支持从 AI 提供商流式传输文本补全，管理聊天输入的状态，并在收到新消息时自动更新 UI。

<Note>
  `useCompletion` Hook 现在是 `@ai-sdk/react` 包的一部分。
</Note>

在本指南中，你将学习如何在应用中使用 `useCompletion` Hook 来生成文本补全，并实时流式传输给用户。

## 示例

```tsx filename='app/page.tsx'
'use client';

import { useCompletion } from '@ai-sdk/react';

export default function Page() {
  const { completion, input, handleInputChange, handleSubmit } = useCompletion({
    api: '/api/completion',
  });

  return (
    <form onSubmit={handleSubmit}>
      <input
        name="prompt"
        value={input}
        onChange={handleInputChange}
        id="input"
      />
      <button type="submit">提交</button>
      <div>{completion}</div>
    </form>
  );
}
```

```ts filename='app/api/completion/route.ts'
import {
  createUIMessageStreamResponse,
  streamText,
  toUIMessageStream,
} from 'ai';
__PROVIDER_IMPORT__;

// 允许流式响应最长 30 秒
export const maxDuration = 30;

export async function POST(req: Request) {
  const { prompt }: { prompt: string } = await req.json();

  const result = streamText({
    model: __MODEL__,
    prompt,
  });

  return createUIMessageStreamResponse({
    stream: toUIMessageStream({ stream: result.stream }),
  });
}
```

在 `Page` 组件中，每当用户提交消息时，`useCompletion` Hook 都会向你的 AI 提供商端点发起请求。补全内容随后会实时流式返回并显示在 UI 中。

这实现了无缝的文本补全体验，用户无需等待整个响应接收完毕，即可立即看到 AI 的回复。

## 自定义 UI

`useCompletion` 还提供了通过代码管理提示词、显示加载和错误状态，以及在不依赖用户交互的情况下更新消息的方法。

### 加载和错误状态

要在聊天机器人处理用户消息时显示加载动画，你可以使用 `useCompletion` Hook 返回的 `isLoading` 状态：

```tsx
const { isLoading, ... } = useCompletion()

return(
  <>
    {isLoading ? <Spinner /> : null}
  </>
)
```

类似地，`error` 状态反映了 fetch 请求期间抛出的错误对象。它可以用来显示错误消息或弹出通知：

```tsx
const { error, ... } = useCompletion()

useEffect(() => {
  if (error) {
    toast.error(error.message)
  }
}, [error])

// 或者在 UI 中显示错误消息：
return (
  <>
    {error ? <div>{error.message}</div> : null}
  </>
)
```

### 受控输入

在最初的示例中，我们有 `handleSubmit` 和 `handleInputChange` 回调来管理输入变化和表单提交。这些对于常见用例非常方便，但你也可以使用非受控 API 来处理更高级的场景，例如表单验证或自定义组件。

以下示例演示了如何将 `setInput` 等更细粒度的 API 与自定义输入和提交按钮组件一起使用：

```tsx
const { input, setInput } = useCompletion();

return (
  <>
    <MyCustomInput value={input} onChange={value => setInput(value)} />
  </>
);
```

### 取消

在 AI 提供商仍在流式返回响应时中止响应消息也是一个常见的用例。你可以通过调用 `useCompletion` Hook 返回的 `stop` 函数来实现。

```tsx
const { stop, isLoading, ... } = useCompletion()

return (
  <>
    <button onClick={stop} disabled={!isLoading}>停止</button>
  </>
)
```

当用户点击“停止”按钮时，fetch 请求将被中止。这避免了不必要的资源消耗，并改善了应用的 UX。

### 节流 UI 更新

<Note>此功能目前仅适用于 React。</Note>

默认情况下，`useCompletion` Hook 会在每次收到新数据块时触发一次渲染。
你可以使用 `throttle` 选项来节流 UI 更新。

```tsx filename="page.tsx" highlight="2-3"
const { completion, ... } = useCompletion({
  // 将补全和数据更新节流到 50ms：
  throttle: 50
})
```

## 事件回调

`useCompletion` 还提供了可选的事件回调，你可以用来处理聊天机器人生命周期的不同阶段。这些回调可以用来触发额外的操作，例如日志记录、分析或自定义 UI 更新。

```tsx
const { ... } = useCompletion({
  onFinish: (prompt: string, completion: string) => {
    console.log('完成流式补全：', completion)
  },
  onError: (error: Error) => {
    console.error('发生错误：', error)
  },
})
```

## 配置请求选项

默认情况下，`useCompletion` Hook 会向 `/api/completion` 端点发送 HTTP POST 请求，并将提示词作为请求体的一部分。你可以通过向 `useCompletion` Hook 传递额外选项来自定义请求：

```tsx
const { messages, input, handleInputChange, handleSubmit } = useCompletion({
  api: '/api/custom-completion',
  headers: {
    Authorization: 'your_token',
  },
  body: {
    user_id: '123',
  },
  credentials: 'same-origin',
});
```

在此示例中，`useCompletion` Hook 会向 `/api/completion` 端点发送 POST 请求，并携带指定的 headers、额外的 body 字段以及该 fetch 请求的 credentials。在服务端，你可以利用这些额外信息来处理请求。

你可以为额外的 body 字段提供类型。该类型同时适用于 Hook 上配置的 body 和传递给 `complete` 的 body：

```tsx
type CompletionBody = {
  model: 'fast' | 'smart';
};

const { complete } = useCompletion<CompletionBody>({
  body: {
    model: 'fast',
  },
});

await complete('什么是补全？', {
  body: {
    model: 'smart',
  },
});
```
