# 聊天机器人

`useChat` Hook 让为你的聊天机器人应用创建对话式用户界面变得轻而易举。它能够从你的 AI 提供商流式传输聊天消息，管理聊天状态，并在新消息到达时自动更新 UI。

总而言之，`useChat` Hook 提供了以下特性：

- **消息流式传输**：来自 AI 提供商的所有消息都会实时流式传输到聊天 UI。
- **状态管理**：该 Hook 为你管理输入、消息、状态、错误等状态。
- **无缝集成**：只需极少的努力，即可将你的聊天 AI 轻松集成到任何设计或布局中。

在本指南中，你将学习如何使用 `useChat` Hook 创建一个具有实时消息流式传输功能的聊天机器人应用。
请查看我们的[带工具的聊天机器人指南](/docs/ai-sdk-ui/chatbot-tool-usage)，了解如何在你的聊天机器人中使用工具。
让我们先从下面的示例开始。

## 示例

```tsx filename='app/page.tsx'
'use client';

import { useChat } from '@ai-sdk/react';
import { DefaultChatTransport } from 'ai';
import { useState } from 'react';

export default function Page() {
  const { messages, sendMessage, status } = useChat({
    transport: new DefaultChatTransport({
      api: '/api/chat',
    }),
  });
  const [input, setInput] = useState('');

  return (
    <>
      {messages.map(message => (
        <div key={message.id}>
          {message.role === 'user' ? '用户: ' : 'AI: '}
          {message.parts.map((part, index) =>
            part.type === 'text' ? <span key={index}>{part.text}</span> : null,
          )}
        </div>
      ))}

      <form
        onSubmit={e => {
          e.preventDefault();
          if (input.trim()) {
            sendMessage({ text: input });
            setInput('');
          }
        }}
      >
        <input
          value={input}
          onChange={e => setInput(e.target.value)}
          disabled={status !== 'ready'}
          placeholder="说点什么..."
        />
        <button type="submit" disabled={status !== 'ready'}>
          提交
        </button>
      </form>
    </>
  );
}
```

```ts filename='app/api/chat/route.ts'
import {
  convertToModelMessages,
  createUIMessageStreamResponse,
  streamText,
  toUIMessageStream,
  UIMessage,
} from 'ai';
__PROVIDER_IMPORT__;

// 允许流式响应最长 30 秒
export const maxDuration = 30;

export async function POST(req: Request) {
  const { messages }: { messages: UIMessage[] } = await req.json();

  const result = streamText({
    model: __MODEL__,
    instructions: '你是一个乐于助人的助手。',
    messages: await convertToModelMessages(messages),
  });

  return createUIMessageStreamResponse({
    stream: toUIMessageStream({ stream: result.stream }),
  });
}
```

<Note>
  UI 消息有一个新的 `parts` 属性，包含消息的各个部分。
  我们建议使用 `parts` 属性而不是 `content` 属性来渲染消息。`parts` 属性支持不同的消息类型，
  包括文本、工具调用和工具结果，并允许构建更灵活和复杂的聊天 UI。
</Note>

在 `Page` 组件中，每当用户使用 `sendMessage` 发送消息时，`useChat` Hook 都会向你的 AI 提供商端点发起请求。
然后，消息会实时流式传输回来并显示在聊天 UI 中。

这实现了无缝的聊天体验，用户可以在 AI 响应可用时立即看到，而无需等待整个响应接收完毕。

## 自定义 UI

`useChat` 还提供了通过代码管理聊天消息状态、显示状态以及在不触发用户交互的情况下更新消息的方法。

### 状态

`useChat` Hook 返回一个 `status`。它具有以下可能的值：

- `submitted`：消息已发送到 API，我们正在等待响应流的开始。
- `streaming`：响应正在从 API 主动流式传输，接收数据块。
- `ready`：已收到并处理完完整响应；可以提交新的用户消息。
- `error`：API 请求期间发生错误，阻止了成功完成。

你可以将 `status` 用于例如以下目的：

- 在聊天机器人处理用户消息时显示加载旋转器。
- 显示“停止”按钮以中止当前消息。
- 禁用提交按钮。

```tsx filename='app/page.tsx' highlight="8,26-33,47,50"
'use client';

import { useChat } from '@ai-sdk/react';
import { DefaultChatTransport } from 'ai';
import { useState } from 'react';

export default function Page() {
  const { messages, sendMessage, status, stop } = useChat({
    transport: new DefaultChatTransport({
      api: '/api/chat',
    }),
  });
  const [input, setInput] = useState('');

  return (
    <>
      {messages.map(message => (
        <div key={message.id}>
          {message.role === 'user' ? '用户: ' : 'AI: '}
          {message.parts.map((part, index) =>
            part.type === 'text' ? <span key={index}>{part.text}</span> : null,
          )}
        </div>
      ))}

      {(status === 'submitted' || status === 'streaming') && (
        <div>
          {status === 'submitted' && <Spinner />}
          <button type="button" onClick={() => stop()}>
            停止
          </button>
        </div>
      )}

      <form
        onSubmit={e => {
          e.preventDefault();
          if (input.trim()) {
            sendMessage({ text: input });
            setInput('');
          }
        }}
      >
        <input
          value={input}
          onChange={e => setInput(e.target.value)}
          disabled={status !== 'ready'}
          placeholder="说点什么..."
        />
        <button type="submit" disabled={status !== 'ready'}>
          提交
        </button>
      </form>
    </>
  );
}
```

### 错误状态

类似地，`error` 状态反映了在 fetch 请求期间抛出的错误对象。
它可以用来显示错误消息、禁用提交按钮或显示重试按钮：

<Note>
  我们建议向用户显示通用错误消息，例如“出了点问题。”这是一种避免从服务器泄露信息的好做法。
</Note>

```tsx file="app/page.tsx" highlight="8,26-33,47"
'use client';

import { useChat } from '@ai-sdk/react';
import { DefaultChatTransport } from 'ai';
import { useState } from 'react';

export default function Chat() {
  const { messages, sendMessage, error, regenerate } = useChat({
    transport: new DefaultChatTransport({
      api: '/api/chat',
    }),
  });
  const [input, setInput] = useState('');

  return (
    <div>
      {messages.map(m => (
        <div key={m.id}>
          {m.role}:{' '}
          {m.parts.map((part, index) =>
            part.type === 'text' ? <span key={index}>{part.text}</span> : null,
          )}
        </div>
      ))}

      {error && (
        <>
          <div>发生了一个错误。</div>
          <button type="button" onClick={() => regenerate()}>
            重试
          </button>
        </>
      )}

      <form
        onSubmit={e => {
          e.preventDefault();
          if (input.trim()) {
            sendMessage({ text: input });
            setInput('');
          }
        }}
      >
        <input
          value={input}
          onChange={e => setInput(e.target.value)}
          disabled={error != null}
        />
      </form>
    </div>
  );
}
```

另请参阅[错误处理](/docs/ai-sdk-ui/error-handling)指南以获取更多信息。

### 修改消息

有时，你可能希望直接修改一些现有消息。例如，可以为每条消息添加一个删除按钮，以允许用户将其从聊天历史中移除。

`setMessages` 函数可以帮助你完成这些任务：

```tsx
const { messages, setMessages } = useChat()

const handleDelete = (id) => {
  setMessages(messages.filter(message => message.id !== id))
}

return <>
  {messages.map(message => (
    <div key={message.id}>
      {message.role === 'user' ? '用户: ' : 'AI: '}
      {message.parts.map((part, index) => (
        part.type === 'text' ? (
          <span key={index}>{part.text}</span>
        ) : null
      ))}
      <button onClick={() => handleDelete(message.id)}>删除</button>
    </div>
  ))}
  ...
```

你可以将 `messages` 和 `setMessages` 视为 React 中的一对 `state` 和 `setState`。

### 取消与重新生成

另一个常见的用例是在响应消息仍在从 AI 提供商流式传输时中止它。你可以通过调用 `useChat` Hook 返回的 `stop` 函数来实现这一点。

```tsx
const { stop, status } = useChat()

return <>
  <button onClick={stop} disabled={!(status === 'streaming' || status === 'submitted')}>停止</button>
  ...
```

当用户点击“停止”按钮时，fetch 请求将被中止。这可以避免消耗不必要的资源，并改善聊天机器人应用的用户体验。

类似地，你也可以通过调用 `useChat` Hook 返回的 `regenerate` 函数来请求 AI 提供商重新处理最后一条消息：

```tsx
const { regenerate, status } = useChat();

return (
  <>
    <button
      onClick={regenerate}
      disabled={!(status === 'ready' || status === 'error')}
    >
      重新生成
    </button>
    ...
  </>
);
```

当用户点击“重新生成”按钮时，AI 提供商将重新生成最后一条消息并相应地替换当前消息。

### 节流 UI 更新

<Note>此功能目前仅适用于 React。</Note>

默认情况下，`useChat` Hook 会在每次收到新数据块时触发一次渲染。
你可以使用 `throttle` 选项来节流 UI 更新。

```tsx filename="page.tsx" highlight="2-3"
const { messages, ... } = useChat({
  // 将消息和数据更新节流到 50 毫秒：
  throttle: 50
})
```

## 事件回调

`useChat` 提供了可选的事件回调，你可以使用它们来处理聊天机器人生命周期的不同阶段：

- `onFinish`：当助手响应完成时调用。该事件包括响应消息、所有消息以及关于中止、断开连接和错误的标志。
- `onError`：当 fetch 请求期间发生错误时调用。
- `onData`：每当接收到数据部分时调用。

这些回调可用于触发额外的操作，例如日志记录、分析或自定义 UI 更新。

```tsx
import { UIMessage } from 'ai';

const {
  /* ... */
} = useChat({
  onFinish: ({ message, messages, isAbort, isDisconnect, isError }) => {
    // 使用信息来例如更新其他 UI 状态
  },
  onError: error => {
    console.error('发生了一个错误:', error);
  },
  onData: data => {
    console.log('从服务器接收到的数据部分:', data);
  },
});
```

值得注意的是，你可以通过在 `onData` 回调中抛出错误来中止处理。这将触发 `onError` 回调并阻止消息被附加到聊天 UI。这对于处理来自 AI 提供商的意外响应非常有用。

## 请求配置

### 自定义头部、请求体和凭据

默认情况下，`useChat` Hook 会向 `/api/chat` 端点发送一个 HTTP POST 请求，并将消息列表作为请求体。你可以通过两种方式自定义请求：

#### Hook 级别配置（应用于所有请求）

你可以配置传输级别的选项，这些选项将应用于 Hook 发出的所有请求：

```tsx
import { useChat } from '@ai-sdk/react';
import { DefaultChatTransport } from 'ai';

const { messages, sendMessage } = useChat({
  transport: new DefaultChatTransport({
    api: '/api/custom-chat',
    headers: {
      Authorization: 'your_token',
    },
    body: {
      user_id: '123',
    },
    credentials: 'same-origin',
  }),
});
```

#### 动态 Hook 级别配置

你也可以提供返回配置值的函数。这对于需要刷新的身份验证令牌或依赖于运行时条件的配置非常有用：

```tsx
import { useChat } from '@ai-sdk/react';
import { DefaultChatTransport } from 'ai';

const { messages, sendMessage } = useChat({
  transport: new DefaultChatTransport({
    api: '/api/custom-chat',
    headers: () => ({
      Authorization: `Bearer ${getAuthToken()}`,
      'X-User-ID': getCurrentUserId(),
    }),
    body: () => ({
      sessionId: getCurrentSessionId(),
      preferences: getUserPreferences(),
    }),
    credentials: () => 'include',
  }),
});
```

<Note>
  对于随时间变化的组件状态，请使用 `useRef` 存储当前值，并在配置函数中引用 `ref.current`，或者为了更好的可靠性，优先使用请求级别选项（见下一节）。
</Note>

#### 请求级别配置（推荐）

<Note>
  **推荐**：使用请求级别选项以获得更好的灵活性和控制力。
  请求级别选项优先于 Hook 级别选项，并允许你单独自定义每个请求。
</Note>

```tsx
// 将选项作为 sendMessage 的第二个参数传递
sendMessage(
  { text: input },
  {
    headers: {
      Authorization: 'Bearer token123',
      'X-Custom-Header': 'custom-value',
    },
    body: {
      temperature: 0.7,
      max_tokens: 100,
      user_id: '123',
    },
    metadata: {
      userId: 'user123',
      sessionId: 'session456',
    },
  },
);
```

请求级别选项与 Hook 级别选项合并，请求级别选项优先。在你的服务器端，你可以使用这些附加信息来处理请求。

### 为每个请求设置自定义请求体字段

你可以使用 `sendMessage` 函数的第二个参数，在每个请求的基础上配置自定义的 `body` 字段。
如果你想向后端传递不属于消息列表的附加信息，这将非常有用。

```tsx filename="app/page.tsx" highlight="25-32"
'use client';

import { useChat } from '@ai-sdk/react';
import { useState } from 'react';

export default function Chat() {
  const { messages, sendMessage } = useChat();
  const [input, setInput] = useState('');

  return (
    <div>
      {messages.map(m => (
        <div key={m.id}>
          {m.role}:{' '}
          {m.parts.map((part, index) =>
            part.type === 'text' ? <span key={index}>{part.text}</span> : null,
          )}
        </div>
      ))}

      <form
        onSubmit={event => {
          event.preventDefault();
          if (input.trim()) {
            sendMessage(
              { text: input },
              {
                body: {
                  customKey: 'customValue',
                },
              },
            );
            setInput('');
          }
        }}
      >
        <input value={input} onChange={e => setInput(e.target.value)} />
      </form>
    </div>
  );
}
```

你可以在服务器端通过解构请求体来检索这些自定义字段：

```ts filename="app/api/chat/route.ts" highlight="3,4"
export async function POST(req: Request) {
  // 从请求体中提取附加信息 ("customKey")：
  const { messages, customKey }: { messages: UIMessage[]; customKey: string } =
    await req.json();
  //...
}
```

## 消息元数据

你可以将自定义元数据附加到消息上，用于跟踪时间戳、模型详情和令牌使用情况等信息。

```ts
// 服务器：发送关于消息的元数据
return createUIMessageStreamResponse({
  stream: toUIMessageStream({
    stream: result.stream,
    messageMetadata: ({ part }) => {
      if (part.type === 'start') {
        return {
          createdAt: Date.now(),
          model: 'gpt-5.1',
        };
      }

      if (part.type === 'finish') {
        return {
          totalTokens: part.totalUsage.totalTokens,
        };
      }
    },
  }),
});
```

```tsx
// 客户端：通过 message.metadata 访问元数据
{
  messages.map(message => (
    <div key={message.id}>
      {message.role}:{' '}
      {message.metadata?.createdAt &&
        new Date(message.metadata.createdAt).toLocaleTimeString()}

      {/* 如果可用则显示令牌计数 */}

}
```

## 传输配置

你可以使用 `transport` 选项配置自定义传输行为，以自定义消息发送到 API 的方式：

```tsx filename="app/page.tsx"
import { useChat } from '@ai-sdk/react';
import { DefaultChatTransport } from 'ai';

export default function Chat() {
  const { messages, sendMessage } = useChat({
    id: 'my-chat',
    transport: new DefaultChatTransport({
      prepareSendMessagesRequest: ({ id, messages }) => {
        return {
          body: {
            id,
            message: messages[messages.length - 1],
          },
        };
      },
    }),
  });

  // ... 组件的其余部分
}
```

相应的 API 路由接收自定义请求格式：

```ts filename="app/api/chat/route.ts"
export async function POST(req: Request) {
  const { id, message } = await req.json();

  // 加载现有消息并添加新消息
  const messages = await loadMessages(id);
  messages.push(message);

  const result = streamText({
    model: __MODEL__,
    messages: await convertToModelMessages(messages),
  });

  return createUIMessageStreamResponse({
    stream: toUIMessageStream({ stream: result.stream }),
  });
}
```

### 高级：基于触发器的路由

对于更复杂的场景，例如消息重新生成，你可以使用基于触发器的路由：

```tsx filename="app/page.tsx"
import { useChat } from '@ai-sdk/react';
import { DefaultChatTransport } from 'ai';

export default function Chat() {
  const { messages, sendMessage, regenerate } = useChat({
    id: 'my-chat',
    transport: new DefaultChatTransport({
      prepareSendMessagesRequest: ({ id, messages, trigger, messageId }) => {
        if (trigger === 'submit-user-message') {
          return {
            body: {
              trigger: 'submit-user-message',
              id,
              message: messages[messages.length - 1],
              messageId,
            },
          };
        } else if (trigger === 'regenerate-assistant-message') {
          return {
            body: {
              trigger: 'regenerate-assistant-message',
              id,
              messageId,
            },
          };
        }
        throw new Error(`不支持的触发器: ${trigger}`);
      },
    }),
  });

  // ... 组件的其余部分
}
```

相应的 API 路由将处理不同的触发器：

```ts filename="app/api/chat/route.ts"
export async function POST(req: Request) {
  const { trigger, id, message, messageId } = await req.json();

  const chat = await readChat(id);
  let messages = chat.messages;

  if (trigger === 'submit-user-message') {
    // 处理新的用户消息
    messages = [...messages, message];
  } else if (trigger === 'regenerate-assistant-message') {
    // 处理消息重新生成 - 移除 messageId 之后的消息
    const messageIndex = messages.findIndex(m => m.id === messageId);
    if (messageIndex !== -1) {
      messages = messages.slice(0, messageIndex);
    }
  }

  const result = streamText({
    model: __MODEL__,
    messages: await convertToModelMessages(messages),
  });

  return createUIMessageStreamResponse({
    stream: toUIMessageStream({ stream: result.stream }),
  });
}
```

要了解有关构建自定义传输的更多信息，请参阅[传输 API 文档](/docs/ai-sdk-ui/transport)。

### 直接智能体传输

对于希望直接与智能体通信而无需通过 HTTP 的场景，你可以使用 `DirectChatTransport`。这对于以下情况非常有用：

- 服务器端渲染场景
- 无需网络的测试
- 单进程应用

```tsx filename="app/page.tsx"
import { useChat } from '@ai-sdk/react';
import { DirectChatTransport, ToolLoopAgent } from 'ai';
__PROVIDER_IMPORT__;

const agent = new ToolLoopAgent({
  model: __MODEL__,
  instructions: '你是一个乐于助人的助手。',
});

export default function Chat() {
  const { messages, sendMessage, status } = useChat({
    transport: new DirectChatTransport({ agent }),
  });

  return (
    <>
      {messages.map(message => (
        <div key={message.id}>
          {message.role === 'user' ? '用户: ' : 'AI: '}
          {message.parts.map((part, index) =>
            part.type === 'text' ? <span key={index}>{part.text}</span> : null,
          )}
        </div>
      ))}

      <button
        onClick={() => sendMessage({ text: '你好！' })}
        disabled={status !== 'ready'}
      >
        发送
      </button>
    </>
  );
}
```

`DirectChatTransport` 直接调用智能体的 `stream()` 方法，将 UI 消息转换为模型消息，并将响应作为 UI 消息块流式传输回来。

有关更多详细信息，请参阅 [DirectChatTransport 参考](/docs/reference/ai-sdk-ui/direct-chat-transport)。

## 控制响应流

使用 `streamText`，你可以控制错误消息和使用信息如何发送回客户端。

### 错误消息

默认情况下，出于安全原因，错误消息会被屏蔽。
默认的错误消息是“发生了一个错误。”
你可以通过提供 `onError` 函数来转发错误消息或发送你自己的错误消息：

```ts filename="app/api/chat/route.ts" highlight="21-35"
import {
  convertToModelMessages,
  createUIMessageStreamResponse,
  streamText,
  toUIMessageStream,
  UIMessage,
} from 'ai';
__PROVIDER_IMPORT__;

export async function POST(req: Request) {
  const { messages }: { messages: UIMessage[] } = await req.json();

  const result = streamText({
    model: __MODEL__,
    messages: await convertToModelMessages(messages),
  });

  return createUIMessageStreamResponse({
    stream: toUIMessageStream({
      stream: result.stream,
      onError: error => {
        if (error == null) {
          return '未知错误';
        }

        if (typeof error === 'string') {
          return error;
        }

        if (error instanceof Error) {
          return error.message;
        }

        return JSON.stringify(error);
      },
    }),
  });
}
```

### 使用信息

使用[消息元数据](/docs/ai-sdk-ui/message-metadata)跟踪令牌消耗和资源使用情况：

1. 定义一个带有使用字段的自定义元数据类型（可选，用于类型安全）
2. 在响应中使用 `messageMetadata` 附加使用数据
3. 在你的 UI 组件中显示使用指标

使用数据作为元数据附加到消息上，并在模型完成响应生成后可用。

```ts
import { openai } from '@ai-sdk/openai';
import {
  convertToModelMessages,
  createUIMessageStreamResponse,
  streamText,
  toUIMessageStream,
  UIMessage,
  type LanguageModelUsage,
} from 'ai';
__PROVIDER_IMPORT__;

// 创建一个新的元数据类型（可选，用于类型安全）
type MyMetadata = {
  totalUsage: LanguageModelUsage;
};

// 使用你自己的元数据创建一个新的自定义消息类型
export type MyUIMessage = UIMessage<MyMetadata>;

export async function POST(req: Request) {
  const { messages }: { messages: MyUIMessage[] } = await req.json();

  const result = streamText({
    model: __MODEL__,
    messages: await convertToModelMessages(messages),
  });

  return createUIMessageStreamResponse({
    stream: toUIMessageStream({
      stream: result.stream,
      originalMessages: messages,
      messageMetadata: ({ part }) => {
        // 生成完成时发送总使用量
        if (part.type === 'finish') {
          return { totalUsage: part.totalUsage };
        }
      },
    }),
  });
}
```

然后，在客户端，你可以访问消息级别的元数据。

```tsx
'use client';

import { useChat } from '@ai-sdk/react';
import type { MyUIMessage } from './api/chat/route';
import { DefaultChatTransport } from 'ai';

export default function Chat() {
  // 使用在服务器上定义的自定义消息类型（可选，用于类型安全）
  const { messages } = useChat<MyUIMessage>({
    transport: new DefaultChatTransport({
      api: '/api/chat',
    }),
  });

  return (
    <div className="flex flex-col w-full max-w-md py-24 mx-auto stretch">
      {messages.map(m => (
        <div key={m.id} className="whitespace-pre-wrap">
          {m.role === 'user' ? '用户: ' : 'AI: '}
          {m.parts.map(part => {
            if (part.type === 'text') {
              return part.text;
            }
          })}
          {/* 通过元数据渲染使用情况 */}
          {m.metadata?.totalUsage && (
            <div>总使用量: {m.metadata?.totalUsage.totalTokens} 个令牌</div>
          )}
        </div>
      ))}
    </div>
  );
}
```

你也可以从 `useChat` 的 `onFinish` 回调中访问你的元数据：

```tsx
'use client';

import { useChat } from '@ai-sdk/react';
import type { MyUIMessage } from './api/chat/route';
import { DefaultChatTransport } from 'ai';

export default function Chat() {
  // 使用在服务器上定义的自定义消息类型（可选，用于类型安全）

      api: '/api/chat',
    }),
    onFinish: ({ message }) => {
      // 通过 onFinish 回调访问消息元数据
      console.log(message.metadata?.totalUsage);
    },
  });
}
```

## 推理

某些模型，例如 DeepSeek `deepseek-r1`
和 Anthropic `claude-sonnet-4-5-20250929`，支持推理令牌。
这些令牌通常在消息内容之前发送。
你可以使用 `sendReasoning` 选项将它们转发给客户端：

```ts filename="app/api/chat/route.ts" highlight="20"
import {
  convertToModelMessages,
  createUIMessageStreamResponse,
  streamText,
  toUIMessageStream,
  UIMessage,
} from 'ai';

export async function POST(req: Request) {
  const { messages }: { messages: UIMessage[] } = await req.json();

  const result = streamText({
    model: 'deepseek/deepseek-r1',
    messages: await convertToModelMessages(messages),
  });

  return createUIMessageStreamResponse({
    stream: toUIMessageStream({
      stream: result.stream,
      sendReasoning: true,
    }),
  });
}
```

在客户端，你可以访问消息对象的推理部分。

推理部分有一个 `text` 属性，包含推理内容。

```tsx filename="app/page.tsx"
messages.map(message => (
  <div key={message.id}>
    {message.role === 'user' ? '用户: ' : 'AI: '}
    {message.parts.map((part, index) => {
      // 文本部分：
      if (part.type === 'text') {
        return <div key={index}>{part.text}</div>;
      }

      // 推理部分：
      if (part.type === 'reasoning') {
        return <pre key={index}>{part.text}</pre>;
      }
    })}
  </div>
));
```

某些模型也可能在推理过程中生成文件（例如图像）。
这些文件作为 `reasoning-file` 部分（`ReasoningFileUIPart`）提供，具有
`mediaType` 和 `url` 属性，类似于常规的文件部分。

## 来源

某些提供商，例如 [Perplexity](/providers/ai-sdk-providers/perplexity#sources) 和
[Google](/providers/ai-sdk-providers/google#sources)，会在响应中包含来源。

目前，来源仅限于为响应提供依据的网页。
你可以使用 `sendSources` 选项将它们转发给客户端：

```ts filename="app/api/chat/route.ts" highlight="20"
import {
  convertToModelMessages,
  createUIMessageStreamResponse,
  streamText,
  toUIMessageStream,
  UIMessage,
} from 'ai';

export async function POST(req: Request) {
  const { messages }: { messages: UIMessage[] } = await req.json();

  const result = streamText({
    model: 'perplexity/sonar-pro',
    messages: await convertToModelMessages(messages),
  });

  return createUIMessageStreamResponse({
    stream: toUIMessageStream({
      stream: result.stream,
      sendSources: true,
    }),
  });
}
```

在客户端，你可以访问消息对象的来源部分。
有两种类型的来源：`source-url` 用于网页，`source-document` 用于文档。
以下是一个渲染两种类型来源的示例：

```tsx filename="app/page.tsx"
messages.map(message => (
  <div key={message.id}>
    {message.role === 'user' ? '用户: ' : 'AI: '}

    {/* 渲染 URL 来源 */}
    {message.parts
      .filter(part => part.type === 'source-url')
      .map(part => (
        <span key={`source-${part.id}`}>
          [
          <a href={part.url} target="_blank">
            {part.title ?? new URL(part.url).hostname}
          </a>
          ]
        </span>
      ))}

    {/* 渲染文档来源 */}
    {message.parts
      .filter(part => part.type === 'source-document')
      .map(part => (
        <span key={`source-${part.id}`}>
          [<span>{part.title ?? `文档 ${part.id}`}</span>]
        </span>
      ))}
  </div>
));
```

## 附件

`useChat` Hook 支持随消息发送文件附件，并在客户端渲染它们。这对于构建涉及向 AI 提供商发送图像、文件或其他媒体内容的应用非常有用。

有两种方式随消息发送文件：使用来自文件输入的 `FileList` 对象，或使用文件对象数组。

### FileList

通过使用 `FileList`，你可以使用文件输入元素随消息发送多个文件作为附件。`useChat` Hook 会自动将它们转换为数据 URL 并发送给 AI 提供商。

<Note>
  目前，只有 `image/*` 和 `text/*` 内容类型会自动转换为[多模态内容
  部分](/docs/foundations/prompts#file-parts)。你需要手动处理其他内容类型。
</Note>

```tsx filename="app/page.tsx"
'use client';

import { useChat } from '@ai-sdk/react';
import { useRef, useState } from 'react';

export default function Page() {
  const { messages, sendMessage, status } = useChat();

  const [input, setInput] = useState('');
  const [files, setFiles] = useState<FileList | undefined>(undefined);
  const fileInputRef = useRef<HTMLInputElement>(null);

  return (
    <div>
      <div>
        {messages.map(message => (
          <div key={message.id}>
            <div>{`${message.role}: `}</div>

            <div>
              {message.parts.map((part, index) => {
                if (part.type === 'text') {
                  return <span key={index}>{part.text}</span>;
                }

                if (
                  part.type === 'file' &&
                  part.mediaType?.startsWith('image/')
                ) {
                  return <img key={index} src={part.url} alt={part.filename} />;
                }

                return null;
              })}
            </div>
          </div>
        ))}
      </div>

      <form
        onSubmit={event => {
          event.preventDefault();
          if (input.trim()) {
            sendMessage({
              text: input,
              files,
            });
            setInput('');
            setFiles(undefined);

            if (fileInputRef.current) {
              fileInputRef.current.value = '';
            }
          }
        }}
      >
        <input
          type="file"
          onChange={event => {
            if (event.target.files) {
              setFiles(event.target.files);
            }
          }}
          multiple
          ref={fileInputRef}
        />
        <input
          value={input}
          placeholder="发送消息..."
          onChange={e => setInput(e.target.value)}
          disabled={status !== 'ready'}
        />
      </form>
    </div>
  );
}
```

## 工具的类型推断

在 TypeScript 中使用工具时，AI SDK UI 提供了类型推断辅助工具，以确保工具输入和输出的类型安全。

### InferUITool

`InferUITool` 类型辅助工具推断单个工具的输入和输出类型，以便在 UI 消息中使用：

```tsx
import { InferUITool } from 'ai';
import { z } from 'zod';

const weatherTool = {
  description: '获取当前天气',
  inputSchema: z.object({
    location: z.string().describe('城市和州'),
  }),
  execute: async ({ location }) => {
    return `${location} 的天气是晴天。`;
  },
};

// 从工具推断类型
type WeatherUITool = InferUITool<typeof weatherTool>;
// 这将创建一个具有以下结构的类型：
// {
//   input: { location: string };
//   output: string;
// }
```

### InferUITools

`InferUITools` 类型辅助工具推断一个 `ToolSet` 的输入和输出类型：

```tsx
import { InferUITools, ToolSet } from 'ai';
import { z } from 'zod';

const tools = {
  weather: {
    description: '获取当前天气',
    inputSchema: z.object({
      location: z.string().describe('城市和州'),
    }),
    execute: async ({ location }) => {
      return `${location} 的天气是晴天。`;
    },
  },
  calculator: {
    description: '执行基本算术运算',
    inputSchema: z.object({
      operation: z.enum(['add', 'subtract', 'multiply', 'divide']),
      a: z.number(),
      b: z.number(),
    }),
    execute: async ({ operation, a, b }) => {
      switch (operation) {
        case 'add':
          return a + b;
        case 'subtract':
          return a - b;
        case 'multiply':
          return a * b;
        case 'divide':
          return a / b;
      }
    },
  },
} satisfies ToolSet;

// 从工具集推断类型
type MyUITools = InferUITools<typeof tools>;
// 这将创建一个具有以下结构的类型：
// {
//   weather: { input: { location: string }; output: string };
//   calculator: { input: { operation: 'add' | 'subtract' | 'multiply' | 'divide'; a: number; b: number }; output: number };
// }
```

### 使用推断类型

你可以使用这些推断类型来创建自定义的 UIMessage 类型，并将其传递给各种 AI SDK UI 函数：

```tsx
import { InferUITools, UIMessage, UIDataTypes } from 'ai';

type MyUITools = InferUITools<typeof tools>;
type MyUIMessage = UIMessage<never, UIDataTypes, MyUITools>;
```

将自定义类型传递给 `useChat` 或 `createUIMessageStream`：

```tsx
import { useChat } from '@ai-sdk/react';
import { createUIMessageStream } from 'ai';
import type { MyUIMessage } from './types';

// 使用 useChat
const { messages } = useChat<MyUIMessage>();

// 使用 createUIMessageStream
const stream = createUIMessageStream<MyUIMessage>(/* ... */);
```

这为客户端和服务器的工具输入和输出提供了完整的类型安全。
