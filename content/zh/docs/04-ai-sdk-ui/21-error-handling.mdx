# 错误处理与警告

## 警告

AI SDK 会在某些情况可能不如预期工作时显示警告。这些警告帮助您在问题引发错误之前修复它们。

### 警告出现时机

警告会在浏览器控制台中显示，当出现以下情况时：

- **不支持的功能**：您使用了 AI 模型不支持的功能或设置（例如某些选项或参数）。
- **兼容性警告**：某个功能以兼容模式使用，可能运行方式不同或效果不如预期。
- **其他警告**：AI 模型报告了其他类型的问题，例如一般性问题或建议性消息。

### 警告消息

所有警告都以“AI SDK Warning:”开头，方便您快速定位。例如：

```
AI SDK Warning: The feature "temperature" is not supported by this model
```

### 关闭警告

默认情况下，警告会在控制台中显示。您可以控制此行为：

#### 关闭所有警告

设置一个全局变量以完全关闭警告：

```ts
globalThis.AI_SDK_LOG_WARNINGS = false;
```

#### 自定义警告处理函数

您也可以提供自己的函数来处理警告。该函数会接收提供商 ID、模型 ID 以及警告列表。

```ts
globalThis.AI_SDK_LOG_WARNINGS = ({ warnings, provider, model }) => {
  // 以您自己的方式处理警告
};
```

## 错误处理

### 错误辅助对象

每个 AI SDK UI Hook 也会返回一个 [error](/docs/reference/ai-sdk-ui/use-chat#error) 对象，您可以使用它在 UI 中渲染错误信息。您可以使用该错误对象来显示错误消息、禁用提交按钮或显示重试按钮。

<Note>
  我们建议向用户显示通用的错误消息，例如“出了点问题”。这是一种避免从服务器泄露信息的好做法。
</Note>

```tsx file="app/page.tsx" highlight="8,28-35,41"
'use client';

import { useChat } from '@ai-sdk/react';
import { useState } from 'react';

export default function Chat() {
  const [input, setInput] = useState('');
  const { messages, sendMessage, error, regenerate } = useChat();

  const handleSubmit = (e: React.FormEvent) => {
    e.preventDefault();
    sendMessage({ text: input });
    setInput('');
  };

  return (
    <div>
      {messages.map(m => (
        <div key={m.id}>
          {m.role}:{' '}
          {m.parts
            .filter(part => part.type === 'text')
            .map(part => part.text)
            .join('')}
        </div>
      ))}

      {error && (
        <>
          <div>An error occurred.</div>
          <button type="button" onClick={() => regenerate()}>
            Retry
          </button>
        </>
      )}

      <form onSubmit={handleSubmit}>
        <input
          value={input}
          onChange={e => setInput(e.target.value)}
          disabled={error != null}
        />
      </form>
    </div>
  );
}
```

#### 替代方案：替换失败的消息

或者，您可以编写一个自定义提交处理程序，用新的输入替换失败的用户消息。如果助手响应在错误发生前已经开始流式传输，则同时移除部分助手响应及其对应的用户消息。

```tsx file="app/page.tsx" highlight="13-19,21-22,39"
'use client';

import { useChat } from '@ai-sdk/react';
import { useState } from 'react';

export default function Chat() {
  const [input, setInput] = useState('');
  const { sendMessage, error, messages, setMessages } = useChat();

  function customSubmit(event: React.FormEvent<HTMLFormElement>) {
    event.preventDefault();

    if (error != null) {
      setMessages(messages =>
        messages.at(-1)?.role === 'assistant'
          ? messages.slice(0, -2)
          : messages.slice(0, -1),
      );
    }

    sendMessage({ text: input });
    setInput('');
  }

  return (
    <div>
      {messages.map(m => (
        <div key={m.id}>
          {m.role}:{' '}
          {m.parts
            .filter(part => part.type === 'text')
            .map(part => part.text)
            .join('')}
        </div>
      ))}

      {error && <div>An error occurred.</div>}

      <form onSubmit={customSubmit}>
        <input value={input} onChange={e => setInput(e.target.value)} />
      </form>
    </div>
  );
}
```

### 错误处理回调

可以通过将 [`onError`](/docs/reference/ai-sdk-ui/use-chat#on-error) 回调函数作为选项传递给 [`useChat`](/docs/reference/ai-sdk-ui/use-chat) 或 [`useCompletion`](/docs/reference/ai-sdk-ui/use-completion) Hook 来处理错误。该回调函数接收一个错误对象作为参数。

```tsx file="app/page.tsx" highlight="6-9"
import { useChat } from '@ai-sdk/react';

export default function Page() {
  const {
    /* ... */
  } = useChat({
    // 处理错误：
    onError: error => {
      console.error(error);
    },
  });
}
```

### 注入错误以进行测试

您可能希望创建错误用于测试。只需在路由处理程序中抛出错误即可轻松实现：

```ts file="app/api/chat/route.ts"
export async function POST(req: Request) {
  throw new Error('This is a test error');
}
```
