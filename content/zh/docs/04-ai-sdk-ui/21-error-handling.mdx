# 错误处理与警告

## 警告

当某些功能可能无法按预期工作时，AI SDK 会显示警告。
这些警告可帮助你在问题引发错误之前将其修复。

### 警告出现时机

在以下情况下，警告会显示在浏览器控制台中：

- **不支持的功能**：你使用了 AI 模型不支持的功能或设置（例如某些选项或参数）。
- **兼容性警告**：某功能在兼容模式下使用，其工作方式可能与预期不同或不够理想。
- **其他警告**：AI 模型报告了其他类型的问题，例如一般性问题或提示信息。

### 警告消息

所有警告都以 "AI SDK Warning:" 开头，方便你轻松找到它们。例如：

```
AI SDK Warning: The feature "temperature" is not supported by this model
```

### 关闭警告

默认情况下，警告会显示在控制台中。你可以控制此行为：

#### 关闭所有警告

设置一个全局变量即可完全关闭警告：

```ts
globalThis.AI_SDK_LOG_WARNINGS = false;
```

#### 自定义警告处理器

你也可以提供自己的函数来处理警告。
它会接收提供商 id、模型 id 以及警告列表。

```ts
globalThis.AI_SDK_LOG_WARNINGS = ({ warnings, provider, model }) => {
  // Handle warnings your own way
};
```

## 错误处理

### 错误辅助对象

每个 AI SDK UI Hook 还会返回一个 [error](/docs/reference/ai-sdk-ui/use-chat#error) 对象，你可以用它来在 UI 中渲染错误。
你可以使用该 error 对象来显示错误消息、禁用提交按钮或显示重试按钮。

<Note>
  我们建议向用户显示通用的错误消息，例如 "Something
  went wrong."。这是避免泄露服务器信息的好做法。
</Note>

```tsx file="app/page.tsx" highlight="8,28-35,41"
'use client';

import { useChat } from '@ai-sdk/react';
import { useState } from 'react';

export default function Chat() {
  const [input, setInput] = useState('');
  const { messages, sendMessage, error, regenerate } = useChat();

  const handleSubmit = (e: React.FormEvent) => {
    e.preventDefault();
    sendMessage({ text: input });
    setInput('');
  };

  return (
    <div>
      {messages.map(m => (
        <div key={m.id}>
          {m.role}:{' '}
          {m.parts
            .filter(part => part.type === 'text')
            .map(part => part.text)
            .join('')}
        </div>
      ))}

      {error && (
        <>
          <div>An error occurred.</div>
          <button type="button" onClick={() => regenerate()}>
            Retry
          </button>
        </>
      )}

      <form onSubmit={handleSubmit}>
        <input
          value={input}
          onChange={e => setInput(e.target.value)}
          disabled={error != null}
        />
      </form>
    </div>
  );
}
```

#### 替代方案：替换失败的消息

或者，你可以编写一个自定义提交处理器，用新的输入替换失败的用户消息。如果助手响应在错误发生前已开始流式传输，则同时移除部分助手响应及其用户消息。

```tsx file="app/page.tsx" highlight="13-19,21-22,39"
'use client';

import { useChat } from '@ai-sdk/react';
import { useState } from 'react';

export default function Chat() {
  const [input, setInput] = useState('');
  const { sendMessage, error, messages, setMessages } = useChat();

  function customSubmit(event: React.FormEvent<HTMLFormElement>) {
    event.preventDefault();

    if (error != null) {
      setMessages(messages =>
        messages.at(-1)?.role === 'assistant'
          ? messages.slice(0, -2)
          : messages.slice(0, -1),
      );
    }

    sendMessage({ text: input });
    setInput('');
  }

  return (
    <div>
      {messages.map(m => (
        <div key={m.id}>
          {m.role}:{' '}
          {m.parts
            .filter(part => part.type === 'text')
            .map(part => part.text)
            .join('')}
        </div>
      ))}

      {error && <div>An error occurred.</div>}

      <form onSubmit={customSubmit}>
        <input value={input} onChange={e => setInput(e.target.value)} />
      </form>
    </div>
  );
}
```

### 错误处理回调

可以通过向 [`useChat`](/docs/reference/ai-sdk-ui/use-chat) 或 [`useCompletion`](/docs/reference/ai-sdk-ui/use-completion) Hook 传入 [`onError`](/docs/reference/ai-sdk-ui/use-chat#on-error) 回调函数作为选项来处理错误。
该回调函数会接收一个 error 对象作为参数。

AI SDK 创建的客户端错误使用导出的错误类，并带有基于标记的
`.isInstance()` 守卫：

| 错误类                                                                                              | AI SDK UI 故障                                                                             |
| --------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| [`APICallError`](/docs/reference/ai-sdk-errors/ai-api-call-error)                                   | 聊天传输或补全请求返回了非成功的 HTTP 响应。                                               |
| [`EmptyResponseBodyError`](/docs/reference/ai-sdk-errors/ai-empty-response-body-error)              | 成功的聊天传输或补全响应没有响应体。                                                       |
| [`UIMessageStreamError`](/docs/reference/ai-sdk-errors/ai-ui-message-stream-error)                  | 补全数据流报告了错误，或 UI 消息流包含无效的数据块。                                       |
| [`InvalidArgumentError`](/docs/reference/ai-sdk-errors/ai-invalid-argument-error)                   | 使用了无效的流协议或消息 ID。                                                              |
| [`UnsupportedFunctionalityError`](/docs/reference/ai-sdk-errors/ai-unsupported-functionality-error) | 在不支持 `FileList` 的环境中使用了 `FileList`。                                            |

由自定义 fetch 实现、回调和流解析器抛出的错误会继续原样传播。

```tsx file="app/page.tsx" highlight="2,9-15"
import { useChat } from '@ai-sdk/react';
import { APICallError, EmptyResponseBodyError } from 'ai';

export default function Page() {
  const {
    /* ... */
  } = useChat({
    // handle error:
    onError: error => {
      if (APICallError.isInstance(error)) {
        console.error('Request failed with status:', error.statusCode);
      } else if (EmptyResponseBodyError.isInstance(error)) {
        console.error('The server returned no response body.');
      } else {
        console.error(error);
      }
    },
  });
}
```

对于 AI SDK UI 请求，`APICallError.requestBodyValues` 为 `undefined`，因此
提示词和消息不会被复制到面向客户端的错误对象中。响应文本仍可通过
`message` 和 `responseBody` 获取；请向用户显示通用消息，以避免泄露服务器信息。

### 为测试注入错误

你可能想要为测试创建错误。
你只需在路由处理器中抛出一个错误即可轻松实现：

```ts file="app/api/chat/route.ts"
export async function POST(req: Request) {
  throw new Error('This is a test error');
}
```
