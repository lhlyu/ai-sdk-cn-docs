# 聊天机器人工具使用

通过 [`useChat`](/docs/reference/ai-sdk-ui/use-chat) 和 [`streamText`](/docs/reference/ai-sdk-core/stream-text)，您可以在聊天机器人应用中使用工具。
AI SDK 在此场景下支持三种工具执行模式：

1. 自动执行的服务器端工具
2. 自动执行的客户端工具
3. 需要用户交互的工具，例如确认对话框

流程如下：

1. 用户在聊天界面中输入消息。
1. 消息被发送到 API 路由。
1. 在您的服务器端路由中，语言模型在 `streamText` 调用期间生成工具调用。
1. 所有工具调用都被转发到客户端。
1. 服务器端工具使用其 `execute` 方法执行，其结果被转发到客户端。
1. 应自动执行的客户端工具通过 `onToolCall` 回调处理。
   您必须调用 `addToolOutput` 来提供工具结果。
1. 需要用户交互的客户端工具可以在界面中显示。
   工具调用和结果可作为最后一条助手消息的 `parts` 属性中的工具调用部分使用。
1. 当用户交互完成时，可以使用 `addToolOutput` 将工具结果添加到聊天中。
1. 聊天可以配置为在所有工具结果可用时使用 `sendAutomaticallyWhen` 自动提交。
   这会触发此流程的另一次迭代。

工具调用和工具执行作为类型化工具部分集成到助手消息中。
工具部分首先是一个工具调用，然后在工具执行后变为工具结果。
工具结果包含有关工具调用的所有信息以及工具执行的结果。

<Note>
  工具结果提交可以使用 `sendAutomaticallyWhen` 选项进行配置。您可以使用
  `lastAssistantMessageIsCompleteWithToolCalls` 辅助函数在所有工具结果可用时
  自动提交。这简化了客户端代码，同时在需要时仍允许完全控制。
</Note>

## 示例

在此示例中，我们将使用三个工具：

- `getWeatherInformation`：一个自动执行的服务器端工具，返回指定城市的天气。
- `askForConfirmation`：一个用户交互客户端工具，向用户请求确认。
- `getLocation`：一个自动执行的客户端工具，返回一个随机城市。

### API 路由

```tsx filename='app/api/chat/route.ts'
import {
  convertToModelMessages,
  createUIMessageStreamResponse,
  streamText,
  toUIMessageStream,
  UIMessage,
} from 'ai';
__PROVIDER_IMPORT__;
import { z } from 'zod';

// 允许流式响应最长 30 秒
export const maxDuration = 30;

export async function POST(req: Request) {
  const { messages }: { messages: UIMessage[] } = await req.json();

  const result = streamText({
    model: __MODEL__,
    messages: await convertToModelMessages(messages),
    tools: {
      // 带有 execute 函数的服务器端工具：
      getWeatherInformation: {
        description: '向用户显示指定城市的天气',
        inputSchema: z.object({ city: z.string() }),
        execute: async ({}: { city: string }) => {
          const weatherOptions = ['sunny', 'cloudy', 'rainy', 'snowy', 'windy'];
          return weatherOptions[
            Math.floor(Math.random() * weatherOptions.length)
          ];
        },
      },
      // 启动用户交互的客户端工具：
      askForConfirmation: {
        description: '向用户请求确认。',
        inputSchema: z.object({
          message: z.string().describe('请求确认的消息。'),
        }),
      },
      // 在客户端自动执行的客户端工具：
      getLocation: {
        description:
          '获取用户位置。使用此工具前务必请求确认。',
        inputSchema: z.object({}),
      },
    },
  });

  return createUIMessageStreamResponse({
    stream: toUIMessageStream({ stream: result.stream }),
  });
}
```

### 客户端页面

客户端页面使用 `useChat` Hook 创建具有实时消息流式传输的聊天机器人应用。
工具调用作为类型化工具部分显示在聊天界面中。
请确保使用消息的 `parts` 属性来渲染消息。

有三点值得注意：

1. [`onToolCall`](/docs/reference/ai-sdk-ui/use-chat#on-tool-call) 回调用于处理应自动执行的客户端工具。
   在此示例中，`getLocation` 工具是一个返回随机城市的客户端工具。
   您调用 `addToolOutput` 来提供结果（不使用 `await` 以避免潜在的死锁）。

   <Note>
     始终先在 `onToolCall` 处理器中检查 `if (toolCall.dynamic)`。
     如果不进行此检查，当您尝试在 `addToolOutput` 中使用
     `toolCall.toolName` 时，TypeScript 将抛出类似
     `Type 'string' is not assignable to type '"toolName1" | "toolName2"'` 的错误。
   </Note>

2. [`sendAutomaticallyWhen`](/docs/reference/ai-sdk-ui/use-chat#send-automatically-when) 选项与 `lastAssistantMessageIsCompleteWithToolCalls` 辅助函数配合使用，可在所有工具结果可用时自动提交。

3. 助手消息的 `parts` 数组包含类型化名称的工具部分，如 `tool-askForConfirmation`。
   客户端工具 `askForConfirmation` 显示在界面中。
   它向用户请求确认，并在用户确认或拒绝执行后显示结果。
   结果通过 `addToolOutput` 并使用 `tool` 参数添加到聊天中，以确保类型安全。

类型化工具部分还包括 `approval-requested`、`approval-responded`
和 `output-denied` 状态。在处理 `part.state` 时请包含这些状态，
即使工具不需要审批。请参阅
[工具执行审批](#工具执行审批) 以获取完整的审批界面。

```tsx filename='app/page.tsx' highlight="6,11,16,19-23,25-26,28-33,51,66-70,77-81"
'use client';

import { useChat } from '@ai-sdk/react';
import {
  DefaultChatTransport,
  lastAssistantMessageIsCompleteWithToolCalls,
} from 'ai';
import { useState } from 'react';

export default function Chat() {
  const { messages, sendMessage, addToolOutput } = useChat({
    transport: new DefaultChatTransport({
      api: '/api/chat',
    }),

    sendAutomaticallyWhen: lastAssistantMessageIsCompleteWithToolCalls,

    // 运行自动执行的客户端工具：
    async onToolCall({ toolCall }) {
      // 首先检查是否为动态工具，以进行正确的类型收窄
      if (toolCall.dynamic) {
        return;
      }

      if (toolCall.toolName === 'getLocation') {
        const cities = ['New York', 'Los Angeles', 'Chicago', 'San Francisco'];

        // 不使用 await - 避免潜在的死锁
        addToolOutput({
          tool: 'getLocation',
          toolCallId: toolCall.toolCallId,
          output: cities[Math.floor(Math.random() * cities.length)],
        });
      }
    },
  });
  const [input, setInput] = useState('');

  return (
    <>
      {messages?.map(message => (
        <div key={message.id}>
          <strong>{`${message.role}: `}</strong>
          {message.parts.map(part => {
            switch (part.type) {
              // 将文本部分渲染为简单文本：
              case 'text':
                return part.text;

              // 对于工具部分，使用类型化工具部分名称：
              case 'tool-askForConfirmation': {
                const callId = part.toolCallId;

                switch (part.state) {
                  case 'input-streaming':
                    return (
                      <div key={callId}>正在加载确认请求...</div>
                    );
                  case 'input-available':
                    return (
                      <div key={callId}>
                        {part.input.message}
                        <div>
                          <button
                            onClick={() =>
                              addToolOutput({
                                tool: 'askForConfirmation',
                                toolCallId: callId,
                                output: '是，已确认。',
                              })
                            }
                          >
                            是
                          </button>
                          <button
                            onClick={() =>
                              addToolOutput({
                                tool: 'askForConfirmation',
                                toolCallId: callId,
                                output: '否，已拒绝',
                              })
                            }
                          >
                            否
                          </button>
                        </div>
                      </div>
                    );
                  case 'approval-requested':
                    return <div key={callId}>已请求审批。</div>;
                  case 'approval-responded':
                    return <div key={callId}>已收到审批响应。</div>;
                  case 'output-available':
                    return (
                      <div key={callId}>
                        位置访问已允许：{part.output}
                      </div>
                    );
                  case 'output-error':
                    return <div key={callId}>错误：{part.errorText}</div>;
                  case 'output-denied':
                    return <div key={callId}>工具调用已被拒绝。</div>;
                }
                break;
              }

              case 'tool-getLocation': {
                const callId = part.toolCallId;

                switch (part.state) {
                  case 'input-streaming':
                    return (
                      <div key={callId}>正在准备位置请求...</div>
                    );
                  case 'input-available':
                    return <div key={callId}>正在获取位置...</div>;
                  case 'approval-requested':
                    return <div key={callId}>已请求审批。</div>;
                  case 'approval-responded':
                    return <div key={callId}>已收到审批响应。</div>;
                  case 'output-available':
                    return <div key={callId}>位置：{part.output}</div>;
                  case 'output-error':
                    return (
                      <div key={callId}>
                        获取位置时出错：{part.errorText}
                      </div>
                    );
                  case 'output-denied':
                    return <div key={callId}>位置请求已被拒绝。</div>;
                }
                break;
              }

              case 'tool-getWeatherInformation': {
                const callId = part.toolCallId;

                switch (part.state) {
                  // 预渲染流式工具输入的示例：
                  case 'input-streaming':
                    return (
                      <pre key={callId}>{JSON.stringify(part, null, 2)}</pre>
                    );
                  case 'input-available':
                    return (
                      <div key={callId}>
                        正在获取 {part.input.city} 的天气信息...
                      </div>
                    );
                  case 'approval-requested':
                    return <div key={callId}>已请求审批。</div>;
                  case 'approval-responded':
                    return <div key={callId}>已收到审批响应。</div>;
                  case 'output-available':
                    return (
                      <div key={callId}>
                        {part.input.city} 的天气：{part.output}
                      </div>
                    );
                  case 'output-error':
                    return (
                      <div key={callId}>
                        获取 {part.input.city} 的天气时出错：{' '}
                        {part.errorText}
                      </div>
                    );
                  case 'output-denied':
                    return <div key={callId}>天气请求已被拒绝。</div>;
                }
                break;
              }
            }
          })}
          <br />
        </div>
      ))}

      <form
        onSubmit={e => {
          e.preventDefault();
          if (input.trim()) {
            sendMessage({ text: input });
            setInput('');
          }
        }}
      >
        <input value={input} onChange={e => setInput(e.target.value)} />
      </form>
    </>
  );
}
```

### 错误处理

有时客户端工具执行过程中可能会发生错误。使用 `addToolOutput` 方法，并传入 `state` 为 `output-error` 和 `errorText` 值，而不是 `output` 来记录错误。

```tsx filename='app/page.tsx' highlight="19,36-41"
'use client';

import { useChat } from '@ai-sdk/react';
import {
  DefaultChatTransport,
  lastAssistantMessageIsCompleteWithToolCalls,
} from 'ai';
import { useState } from 'react';

export default function Chat() {
  const { messages, sendMessage, addToolOutput } = useChat({
    transport: new DefaultChatTransport({
      api: '/api/chat',
    }),

    sendAutomaticallyWhen: lastAssistantMessageIsCompleteWithToolCalls,

    // 运行自动执行的客户端工具：
    async onToolCall({ toolCall }) {
      // 首先检查是否为动态工具，以进行正确的类型收窄
      if (toolCall.dynamic) {
        return;
      }

      if (toolCall.toolName === 'getWeatherInformation') {
        try {
          const weather = await getWeatherInformation(toolCall.input);

          // 不使用 await - 避免潜在的死锁
          addToolOutput({
            tool: 'getWeatherInformation',
            toolCallId: toolCall.toolCallId,
            output: weather,
          });
        } catch (err) {
          addToolOutput({
            tool: 'getWeatherInformation',
            toolCallId: toolCall.toolCallId,
            state: 'output-error',
            errorText: '无法获取天气信息',
          });
        }
      }
    },
  });
}
```

## 工具执行审批

工具执行审批允许您在服务器端工具运行之前要求用户确认。与在浏览器中执行的[客户端工具](#示例)不同，需要审批的工具仍然在服务器上执行——但仅在用户批准之后。

在以下情况下使用工具执行审批：

- 确认敏感操作（支付、删除、外部 API 调用）
- 让用户在工具执行前审查工具输入
- 为自动化工作流增加人工监督

对于需要在浏览器中运行的工具（更新界面状态、访问浏览器 API），请改用客户端工具。

### 服务器设置

在 `streamText` 上使用 `toolApproval` 启用审批。工具上较旧的
`needsApproval` 属性已弃用。请参阅 [工具执行审批](/docs/ai-sdk-core/tools-and-tool-calling#tool-execution-approval) 了解配置选项，包括基于输入的动态审批。

```tsx filename='app/api/chat/route.ts'
import {
  createUIMessageStreamResponse,
  streamText,
  tool,
  toUIMessageStream,
} from 'ai';
__PROVIDER_IMPORT__;
import { z } from 'zod';

export async function POST(req: Request) {
  const { messages } = await req.json();

  const result = streamText({
    model: __MODEL__,
    messages,
    tools: {
      getWeather: tool({
        description: '获取某个位置的天气',
        inputSchema: z.object({
          city: z.string(),
        }),
        execute: async ({ city }) => {
          const weather = await fetchWeather(city);
          return weather;
        },
      }),
    },
    toolApproval: {
      getWeather: 'user-approval',
    },
  });

  return createUIMessageStreamResponse({
    stream: toUIMessageStream({ stream: result.stream }),
  });
}
```

### 客户端审批界面

当工具需要手动审批时，工具部分的状态为
`approval-requested`。自动批准和拒绝也会流经相同的
审批状态，但它们会设置 `part.approval.isAutomatic === true`，因此您
可以在不调用 `addToolApprovalResponse` 的情况下渲染状态。自动
审批决定还可以包含 `part.approval.reason`。

```tsx filename='app/page.tsx'
'use client';

import { useChat } from '@ai-sdk/react';

export default function Chat() {
  const { messages, addToolApprovalResponse } = useChat();

  return (
    <>
      {messages.map(message => (
        <div key={message.id}>
          {message.parts.map(part => {
            if (part.type === 'tool-getWeather') {
              switch (part.state) {
                case 'approval-requested': {
                  if (part.approval.isAutomatic) {
                    return (
                      <div key={part.toolCallId}>
                        正在检查 {part.input.city} 的审批...
                      </div>
                    );
                  }

                  return (
                    <div key={part.toolCallId}>
                      <p>获取 {part.input.city} 的天气？</p>
                      {part.approval.requestReason && (
                        <p>{part.approval.requestReason}</p>
                      )}
                      <button
                        onClick={() =>
                          addToolApprovalResponse({
                            id: part.approval.id,
                            approved: true,
                          })
                        }
                      >
                        批准
                      </button>
                      <button
                        onClick={() =>
                          addToolApprovalResponse({
                            id: part.approval.id,
                            approved: false,
                          })
                        }
                      >
                        拒绝
                      </button>
                    </div>
                  );
                }
                case 'approval-responded':
                  return (
                    <div key={part.toolCallId}>
                      {part.input.city} 的天气请求已
                      {part.approval.isAutomatic ? ' 自动' : ''}{' '}
                      {part.approval.approved ? '批准' : '拒绝'}。
                      {part.approval.reason
                        ? ` 原因：${part.approval.reason}`
                        : ''}
                    </div>
                  );
                case 'output-available':
                  return (
                    <div key={part.toolCallId}>
                      {part.input.city} 的天气：{part.output}
                    </div>
                  );
                case 'output-denied':
                  return (
                    <div key={part.toolCallId}>
                      {part.input.city} 的天气请求已被拒绝。
                      {part.approval.reason
                        ? ` 原因：${part.approval.reason}`
                        : ''}
                    </div>
                  );
              }
            }
            // 处理其他部分类型...
          })}
        </div>
      ))}
    </>
  );
}
```

仅对手动审批调用 `addToolApprovalResponse`。自动审批
决定已经以 `approval-requested` 和
`approval-responded` 状态到达界面流中，被拒绝的执行会继续到 `output-denied`。
如果您从自动批准或拒绝中返回 `reason`，它可作为
`part.approval.reason` 使用。
对于手动审批请求，需要审批的原因可作为
`part.approval.requestReason` 使用。它与提供给
`addToolApprovalResponse` 的可选响应原因保持分离。

### 保护敏感工具的审批安全

在 `useChat` 模式中，客户端每轮都会将完整的消息历史发送到服务器。如果没有额外的保护，被修改的客户端可能会伪造审批响应。对于执行敏感操作的工具，请在 `streamText` 调用中添加 `experimental_toolApprovalSecret`，以便服务器以加密方式验证审批确实由其签发：

```tsx filename='app/api/chat/route.ts' highlight="6"
const result = streamText({
  model: __MODEL__,
  messages,
  tools: { deleteFile },
  toolApproval: { deleteFile: 'user-approval' },
  experimental_toolApprovalSecret: process.env.TOOL_APPROVAL_SECRET,
});
```

有关设置详情，请参阅 [安全注意事项](/docs/agents/tool-approvals#security-considerations)。

### 审批后自动提交

<Note>
  如果在您批准工具执行后没有任何反应，请确保您
  手动调用 `sendMessage` 或在 `useChat` Hook 上配置
  `sendAutomaticallyWhen`。
</Note>

使用 `lastAssistantMessageIsCompleteWithApprovalResponses` 在审批后自动继续对话：

```tsx
import { useChat } from '@ai-sdk/react';
import { lastAssistantMessageIsCompleteWithApprovalResponses } from 'ai';

const { messages, addToolApprovalResponse } = useChat({
  sendAutomaticallyWhen: lastAssistantMessageIsCompleteWithApprovalResponses,
});
```

## 动态工具

当使用动态工具（编译时类型未知的工具）时，界面部分使用通用的 `dynamic-tool` 类型，而不是特定的工具类型：

```tsx filename='app/page.tsx'
{
  message.parts.map((part, index) => {
    switch (part.type) {
      // 具有特定（`tool-${toolName}`）类型的静态工具
      case 'tool-getWeatherInformation':
        return <WeatherDisplay part={part} />;

      // 动态工具使用通用的 `dynamic-tool` 类型
      case 'dynamic-tool':
        return (
          <div key={index}>
            <h4>工具：{part.toolName}</h4>
            {part.state === 'input-streaming' && (
              <pre>{JSON.stringify(part.input, null, 2)}</pre>
            )}
            {part.state === 'output-available' && (
              <pre>{JSON.stringify(part.output, null, 2)}</pre>
            )}
            {part.state === 'output-error' && (
              <div>错误：{part.errorText}</div>
            )}
          </div>
        );
    }
  });
}
```

动态工具在以下集成场景中非常有用：

- 没有 schema 的 MCP（模型上下文协议）工具
- 运行时加载的用户定义函数
- 外部工具提供商

## 工具调用流式传输

工具调用流式传输在 AI SDK 5.0 中**默认启用**，允许您在工具调用生成时进行流式传输。这通过实时显示生成的工具输入提供了更好的用户体验。

```tsx filename='app/api/chat/route.ts'
export async function POST(req: Request) {
  const { messages }: { messages: UIMessage[] } = await req.json();

  const result = streamText({
    model: __MODEL__,
    messages: await convertToModelMessages(messages),
    // toolCallStreaming 在 v5 中默认启用
    // ...
  });

  return createUIMessageStreamResponse({
    stream: toUIMessageStream({ stream: result.stream }),
  });
}
```

启用工具调用流式传输后，部分工具调用会作为数据流的一部分进行流式传输。
它们可通过 `useChat` Hook 使用。
助手消息的类型化工具部分也将包含部分工具调用。
您可以使用工具部分的 `state` 属性来渲染正确的界面。

```tsx filename='app/page.tsx' highlight="9,10"
export default function Chat() {
  // ...
  return (
    <>
      {messages?.map(message => (
        <div key={message.id}>
          {message.parts.map(part => {
            switch (part.type) {
              case 'tool-askForConfirmation':
              case 'tool-getLocation':
              case 'tool-getWeatherInformation':
                switch (part.state) {
                  case 'input-streaming':
                    return <pre>{JSON.stringify(part.input, null, 2)}</pre>;
                  case 'input-available':
                    return <pre>{JSON.stringify(part.input, null, 2)}</pre>;
                  case 'approval-requested':
                    return <div>已请求审批。</div>;
                  case 'approval-responded':
                    return <div>已收到审批响应。</div>;
                  case 'output-available':
                    return <pre>{JSON.stringify(part.output, null, 2)}</pre>;
                  case 'output-error':
                    return <div>错误：{part.errorText}</div>;
                  case 'output-denied':
                    return <div>工具调用已被拒绝。</div>;
                }
            }
          })}
        </div>
      ))}
    </>
  );
}
```

当您使用多步骤工具调用时，AI SDK 会向助手消息添加步骤开始部分。
如果您想显示工具调用之间的边界，可以按如下方式使用 `step-start` 部分：

```tsx filename='app/page.tsx'
// ...
// 在您渲染消息部分的位置：
message.parts.map((part, index) => {
  switch (part.type) {
    case 'step-start':

          <hr className="my-2 border-gray-300" />
        </div>
      ) : null;
    case 'text':
    // ...
    case 'tool-askForConfirmation':
    case 'tool-getLocation':
    case 'tool-getWeatherInformation':
    // ...
  }
});
// ...
```

## 服务器端多步骤调用

您也可以在服务器端使用 `streamText` 进行多步骤调用。
当所有被调用的工具在服务器端都有 `execute` 函数时，此功能有效。

```tsx filename='app/api/chat/route.ts' highlight="22-28,31"
import {
  convertToModelMessages,
  createUIMessageStreamResponse,
  isStepCount,
  streamText,
  toUIMessageStream,
  UIMessage,
} from 'ai';
__PROVIDER_IMPORT__;
import { z } from 'zod';

export async function POST(req: Request) {
  const { messages }: { messages: UIMessage[] } = await req.json();

  const result = streamText({
    model: __MODEL__,
    messages: await convertToModelMessages(messages),
    tools: {
      getWeatherInformation: {
        description: '向用户显示指定城市的天气',
        inputSchema: z.object({ city: z.string() }),
        // 工具具有 execute 函数：
        execute: async ({}: { city: string }) => {
          const weatherOptions = ['sunny', 'cloudy', 'rainy', 'snowy', 'windy'];
          return weatherOptions[
            Math.floor(Math.random() * weatherOptions.length)
          ];
        },
      },
    },
    stopWhen: isStepCount(5),
  });

  return createUIMessageStreamResponse({
    stream: toUIMessageStream({ stream: result.stream }),
  });
}
```

## 错误

语言模型在调用工具时可能会出错。
默认情况下，出于安全原因，这些错误会被屏蔽，并在界面中显示为“发生错误”。

要显示错误，您可以在调用 `toUIMessageResponse` 时使用 `onError` 函数。

```tsx
export function errorHandler(error: unknown) {
  if (error == null) {
    return '未知错误';
  }

  if (typeof error === 'string') {
    return error;
  }

  if (error instanceof Error) {
    return error.message;
  }

  return JSON.stringify(error);
}
```

```tsx
const result = streamText({
  // ...
});

return createUIMessageStreamResponse({
  stream: toUIMessageStream({
    stream: result.stream,
    onError: errorHandler,
  }),
});
```

如果您使用 `createUIMessageResponse`，可以在调用 `toUIMessageResponse` 时使用 `onError` 函数：

```tsx
const response = createUIMessageResponse({
  // ...
  async execute(dataStream) {
    // ...
  },
  onError: error => `自定义错误：${error.message}`,
});
```
