# 对象生成

<Note>
  `useObject` 是一项实验性功能，仅在 React、Svelte 和 Vue 中可用。
</Note>

[`useObject`](/docs/reference/ai-sdk-ui/use-object) Hook 允许你创建表示正在流式传输的结构化 JSON 对象的界面。

在本指南中，你将学习如何在应用程序中使用 `useObject` Hook，以动态生成结构化数据的 UI。

## 示例

该示例展示了一个小型通知演示应用，该应用实时生成虚假通知。

### 模式

最好将模式放在一个单独的文件中，并在客户端和服务器端都导入该文件。

```ts filename='app/api/notifications/schema.ts'
import { z } from 'zod';

// 定义通知的模式
export const notificationSchema = z.object({
  notifications: z.array(
    z.object({
      name: z.string().describe('虚构人物的姓名。'),
      message: z.string().describe('消息。不要使用表情符号或链接。'),
    }),
  ),
});
```

### 客户端

客户端使用 [`useObject`](/docs/reference/ai-sdk-ui/use-object) 来流式传输对象生成过程。

结果是部分结果，并在收到时立即显示。
请注意 JSX 中处理 `undefined` 值的代码。

```tsx filename='app/page.tsx'
'use client';

import { experimental_useObject as useObject } from '@ai-sdk/react';
import { notificationSchema } from './api/notifications/schema';

export default function Page() {
  const { object, submit } = useObject({
    api: '/api/notifications',
    schema: notificationSchema,
  });

  return (
    <>
      <button onClick={() => submit('期末考试周的消息。')}>
        生成通知
      </button>

      {object?.notifications?.map((notification, index) => (
        <div key={index}>
          <p>{notification?.name}</p>
          <p>{notification?.message}</p>
        </div>
      ))}
    </>
  );
}
```

### 服务器端

在服务器端，我们使用 [`streamText`](/docs/reference/ai-sdk-core/stream-text) 配合 [`Output.object()`](/docs/reference/ai-sdk-core/output#output-object) 来流式传输对象生成过程。

```typescript filename='app/api/notifications/route.ts'
import { createTextStreamResponse, Output, streamText, toTextStream } from 'ai';
__PROVIDER_IMPORT__;
import { notificationSchema } from './schema';

// 允许流式响应最长 30 秒
export const maxDuration = 30;

export async function POST(req: Request) {
  const context = await req.json();

  const result = streamText({
    model: __MODEL__,
    output: Output.object({ schema: notificationSchema }),
    prompt:
      `在此上下文中为消息应用生成 3 条通知：` + context,
  });

  return createTextStreamResponse({
    stream: toTextStream({ stream: result.stream }),
  });
}
```

## 枚举输出模式

当你需要将输入分类或归类到预定义选项时，可以将 `enum` 输出模式与 `useObject` 一起使用。这需要一个特定的模式结构，其中对象以 `enum` 作为键，并使用 `z.enum` 包含你的可能值。

### 示例：文本分类

此示例展示了如何构建一个简单的文本分类器，将陈述分类为真或假。

#### 客户端

当将 `useObject` 与枚举输出模式一起使用时，你的模式必须是一个以 `enum` 为键的对象：

```tsx filename='app/classify/page.tsx'
'use client';

import { experimental_useObject as useObject } from '@ai-sdk/react';
import { z } from 'zod';

export default function ClassifyPage() {
  const { object, submit, isLoading } = useObject({
    api: '/api/classify',
    schema: z.object({ enum: z.enum(['true', 'false']) }),
  });

  return (
    <>
      <button onClick={() => submit('地球是平的')} disabled={isLoading}>
        分类陈述
      </button>

      {object && <div>分类结果：{object.enum}</div>}
    </>
  );
}
```

#### 服务器端

在服务器端，使用 `streamText` 配合 `Output.choice()` 来流式传输分类结果：

```typescript filename='app/api/classify/route.ts'
import { createTextStreamResponse, Output, streamText, toTextStream } from 'ai';
__PROVIDER_IMPORT__;

export async function POST(req: Request) {
  const context = await req.json();

  const result = streamText({
    model: __MODEL__,
    output: Output.choice({ options: ['true', 'false'] }),
    prompt: `将此陈述分类为真或假：${context}`,
  });

  return createTextStreamResponse({
    stream: toTextStream({ stream: result.stream }),
  });
}
```

## 自定义 UI

`useObject` 还提供了显示加载和错误状态的方法：

### 加载状态

`useObject` Hook 返回的 `isLoading` 状态可用于多种目的：

- 在生成对象时显示加载旋转器。
- 禁用提交按钮。

```tsx filename='app/page.tsx' highlight="6,13-20,24"
'use client';

import { experimental_useObject as useObject } from '@ai-sdk/react';

export default function Page() {
  const { isLoading, object, submit } = useObject({
    api: '/api/notifications',
    schema: notificationSchema,
  });

  return (
    <>
      {isLoading && <Spinner />}

      <button
        onClick={() => submit('期末考试周的消息。')}
        disabled={isLoading}
      >
        生成通知
      </button>

      {object?.notifications?.map((notification, index) => (
        <div key={index}>
          <p>{notification?.name}</p>
          <p>{notification?.message}</p>
        </div>
      ))}
    </>
  );
}
```

### 停止处理程序

`stop` 函数可用于停止对象生成过程。如果用户想要取消请求，或者服务器响应时间过长，这会很有用。

```tsx filename='app/page.tsx' highlight="6,14-16"
'use client';

import { experimental_useObject as useObject } from '@ai-sdk/react';

export default function Page() {
  const { isLoading, stop, object, submit } = useObject({
    api: '/api/notifications',
    schema: notificationSchema,
  });

  return (
    <>
      {isLoading && (
        <button type="button" onClick={() => stop()}>
          停止
        </button>
      )}

      <button onClick={() => submit('期末考试周的消息。')}>
        生成通知
      </button>

      {object?.notifications?.map((notification, index) => (
        <div key={index}>
          <p>{notification?.name}</p>
          <p>{notification?.message}</p>
        </div>
      ))}
    </>
  );
}
```

### 错误状态

类似地，`error` 状态反映了在 fetch 请求期间抛出的错误对象。
它可以用来显示错误消息，或禁用提交按钮：

<Note>
  我们建议向用户显示通用错误消息，例如“出了点问题。”这是一种避免从服务器泄露信息的好做法。
</Note>

```tsx file="app/page.tsx" highlight="6,13"
'use client';

import { experimental_useObject as useObject } from '@ai-sdk/react';

export default function Page() {
  const { error, object, submit } = useObject({
    api: '/api/notifications',
    schema: notificationSchema,
  });

  return (
    <>
      {error && <div>发生了一个错误。</div>}

      <button onClick={() => submit('期末考试周的消息。')}>
        生成通知
      </button>

      {object?.notifications?.map((notification, index) => (
        <div key={index}>
          <p>{notification?.name}</p>
          <p>{notification?.message}</p>
        </div>
      ))}
    </>
  );
}
```

## 事件回调

`useObject` 提供了可选的事件回调，你可以使用它们来处理生命周期事件。

- `onFinish`：在对象生成完成时调用。
- `onError`：在 fetch 请求期间发生错误时调用。

这些回调可用于触发额外的操作，例如日志记录、分析或自定义 UI 更新。

```tsx filename='app/page.tsx' highlight="10-20"
'use client';

import { experimental_useObject as useObject } from '@ai-sdk/react';
import { notificationSchema } from './api/notifications/schema';

export default function Page() {
  const { object, submit } = useObject({
    api: '/api/notifications',
    schema: notificationSchema,
    onFinish({ object, error }) {
      // 类型化的对象，如果模式验证失败则为 undefined：
      console.log('对象生成完成：', object);

      // 错误，如果模式验证成功则为 undefined：
      console.log('模式验证错误：', error);
    },
    onError(error) {
      // fetch 请求期间的错误：
      console.error('发生了一个错误：', error);
    },
  });

  return (
    <div>
      <button onClick={() => submit('期末考试周的消息。')}>
        生成通知
      </button>

      {object?.notifications?.map((notification, index) => (
        <div key={index}>
          <p>{notification?.name}</p>
          <p>{notification?.message}</p>
        </div>
      ))}
    </div>
  );
}
```

## 配置请求选项

你可以使用 `api`、`headers` 和 `credentials` 设置来配置 API 端点、可选的请求头和凭据。

```tsx highlight="2-5"
const { submit, object } = useObject({
  api: '/api/use-object',
  headers: {
    'X-Custom-Header': 'CustomValue',
  },
  credentials: 'include',
  schema: yourSchema,
});
```
