# AI SDK UI

AI SDK UI 旨在帮助你轻松构建交互式聊天、补全和助手应用。它是一个**框架无关的工具包**，可简化将高级 AI 功能集成到你的应用中的过程。

AI SDK UI 提供了强大的抽象，简化了在前端管理聊天流和 UI 更新等复杂任务，使你能够更高效地开发动态的 AI 驱动界面。通过三个主要的 Hook —— **`useChat`**、**`useCompletion`** 和 **`useObject`** —— 你可以将实时聊天能力、文本补全、流式 JSON 和交互式助手功能集成到你的应用中。

- **[`useChat`](/docs/ai-sdk-ui/chatbot)** 提供聊天消息的实时流式传输，并管理消息、加载和错误状态。在你的组件中管理输入状态，以便无缝集成到任何 UI 设计中。
- **[`useCompletion`](/docs/ai-sdk-ui/completion)** 使你能够在应用中处理文本补全，管理提示词输入，并在新的补全内容流式传输时自动更新 UI。
- **[`useObject`](/docs/ai-sdk-ui/object-generation)** 是一个 Hook，允许你消费流式 JSON 对象，提供了一种简单的方式来处理和显示应用中的结构化数据。

这些 Hook 旨在降低实现 AI 交互所需的复杂度和时间，让你能够专注于打造卓越的用户体验。

## UI 框架支持

AI SDK UI 支持以下框架：[React](https://react.dev/)、[Svelte](https://svelte.dev/)、[Vue.js](https://vuejs.org/)、
[Angular](https://angular.dev/) 和 [SolidJS](https://www.solidjs.com/)。

以下是这些框架所支持功能的对比：
