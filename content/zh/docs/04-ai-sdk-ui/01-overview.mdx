# AI SDK UI

AI SDK UI 旨在帮助你轻松构建交互式聊天、补全和智能体应用。它是一个**框架无关的工具包**，可简化将高级 AI 功能集成到应用程序中的过程。

AI SDK UI 提供了强大的抽象层，简化了在前端管理聊天流和 UI 更新的复杂任务，使你能够更高效地开发动态的 AI 驱动界面。通过三个主要的 Hook——**`useChat`**、**`useCompletion`** 和 **`useObject`**——你可以将实时聊天功能、文本补全、流式 JSON 以及交互式智能体特性集成到你的应用中。

- **[`useChat`](/docs/ai-sdk-ui/chatbot)** 提供聊天消息的实时流式传输，抽象了输入、消息、加载状态和错误的状态管理，可无缝集成到任何 UI 设计中。
- **[`useCompletion`](/docs/ai-sdk-ui/completion)** 使你能够在应用中处理文本补全，管理提示词输入，并在新补全内容流式传输时自动更新 UI。
- **[`useObject`](/docs/ai-sdk-ui/object-generation)** 是一个 Hook，允许你消费流式 JSON 对象，为在应用中处理和显示结构化数据提供了一种简单的方式。

这些 Hook 旨在减少实现 AI 交互的复杂性和时间，让你专注于打造卓越的用户体验。

## UI 框架支持

AI SDK UI 支持以下框架：[React](https://react.dev/)、[Svelte](https://svelte.dev/)、[Vue.js](https://vuejs.org/)、[Angular](https://angular.dev/) 和 [SolidJS](https://www.solidjs.com/)。
