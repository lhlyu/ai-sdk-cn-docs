# 版本管理

每个版本号遵循以下格式：`主版本号.次版本号.补丁号`

- **主版本号**：需要修改代码的重大 API 更新。
- **次版本号**：汇总新功能和改进的博客文章，以公开版本形式发布并突出其优势。
- **补丁号**：新功能和错误修复。

## API 稳定性

我们通过以下方式说明 API 的稳定性：

### 稳定 API

所有不带特殊前缀的 API 均视为稳定版本，可用于生产环境。我们保持稳定功能的向后兼容性，仅在主版本中引入破坏性更改。

### 实验性 API

带有 `experimental_` 或 `Experimental_` 前缀的 API（例如 `experimental_generateImage()`）仍在开发中，可能在任何版本中发生变化。安全使用实验性 API 的方法：

1. 先在开发环境中测试，而非生产环境
2. 升级前查看版本说明
3. 为可能的代码更新做好准备

<Note type="warning">
  如果使用实验性 API，请确保精确锁定 AI SDK 版本号（避免使用 ^ 或 ~ 版本范围），以防止意外的破坏性更改。
</Note>

### 已弃用 API

标记为 `deprecated` 的 API 将在未来的主版本中移除。您可以等到主版本发布时再更新代码。处理弃用问题的方法：

1. 切换到推荐的替代 API
2. 遵循迁移指南（与主版本一同发布）

<Note>
  对于主版本，我们会在可能的情况下提供自动化的代码迁移工具，帮助您将代码迁移到新版本。
</Note>
