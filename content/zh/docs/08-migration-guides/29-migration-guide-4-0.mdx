# 从 AI SDK 3.4 迁移到 4.0

<Note>
  有关该版本的更多信息，请查看 [AI SDK 4.0 发布博客文章](https://vercel.com/blog/ai-sdk-4-0)。
</Note>

## 推荐的迁移流程

1. 备份你的项目。如果你使用版本控制系统，请确保所有之前的版本都已提交。
1. [迁移到 AI SDK 3.4](/docs/migration-guides/migration-guide-3-4)。
1. 升级到 AI SDK 4.0。
1. 使用 [codemod](#codemods) 自动迁移你的代码。
   > 如果你不想使用 codemod，我们建议在升级到 AI SDK 4.0 之前解决所有弃用警告。
1. 遵循下面的破坏性变更指南。
1. 验证你的项目按预期工作。
1. 提交你的更改。

## AI SDK 4.0 包版本

你需要在 `package.json` 文件中将以下包更新到以下版本：

- `ai` 包：`4.0.*`
- `ai-sdk@provider-utils` 包：`2.0.*`
- `ai-sdk/*` 包：`1.0.*`（其他 `@ai-sdk` 包）

## Codemod

AI SDK 提供了 Codemod 转换，以帮助你在某个功能被弃用、移除或以其他方式更改时升级你的代码库。

Codemod 是以编程方式在你的代码库上运行的转换。它们允许你轻松地应用许多更改，而无需手动检查每个文件。

<Note>
  Codemod 旨在作为帮助你完成升级过程的工具。它们可能无法涵盖你需要进行的所有更改。你可能需要手动进行其他更改。
</Note>

你可以通过从项目根目录运行以下命令来运行作为 4.0 升级过程一部分提供的所有 codemod：

```sh
npx @ai-sdk/codemod upgrade
```

仅运行 v4 codemod：

```sh
npx @ai-sdk/codemod v4
```

可以通过指定 codemod 的名称来运行单个 codemod：

```sh
npx @ai-sdk/codemod <codemod-name> <path>
```

例如，要运行特定的 v4 codemod：

```sh
npx @ai-sdk/codemod v4/replace-baseurl src/
```

另请参阅 [codemod 表格](#codemod-table)。此外，最新的 codemod 集可以在 [`@ai-sdk/codemod`](https://github.com/vercel/ai/tree/main/packages/codemod/src/codemods) 仓库中找到。

## 提供商变更

### 移除了 `baseUrl` 选项

`baseUrl` 选项已从所有提供商中移除。请改用 `baseURL` 选项。

```ts filename="AI SDK 3.4"
const perplexity = createOpenAI({
  // ...
  baseUrl: 'https://api.perplexity.ai/',
});
```

```ts filename="AI SDK 4.0"
const perplexity = createOpenAI({
  // ...
  baseURL: 'https://api.perplexity.ai/',
});
```

### Anthropic 提供商

#### 移除了 `Anthropic` 外观

`Anthropic` 外观已从 Anthropic 提供商中移除。请改用 `anthropic` 对象或 `createAnthropic` 函数。

```ts filename="AI SDK 3.4"
const anthropic = new Anthropic({
  // ...
});
```

```ts filename="AI SDK 4.0"
const anthropic = createAnthropic({
  // ...
});
```

#### 移除了 `topK` 设置

<Note type="warning">
  此更改没有可用的 codemod。请手动检查和更新你的代码。
</Note>

模型特定的 `topK` 设置已从 Anthropic 提供商中移除。你可以改用标准的 `topK` 设置。

```ts filename="AI SDK 3.4"
const result = await generateText({
  model: anthropic('claude-3-5-sonnet-latest', {
    topK: 0.5,
  }),
});
```

```ts filename="AI SDK 4.0"
const result = await generateText({
  model: anthropic('claude-3-5-sonnet-latest'),
  topK: 0.5,
});
```

## AI SDK Core 变更

### `streamText` 立即返回

`streamText` 函数现在立即返回，而不是返回一个 Promise。不需要 `await` `streamText` 的结果。

```ts filename="AI SDK 3.4"
const result = await streamText({
  // ...
});
```

```ts filename="AI SDK 4.0"
const result = streamText({
  // ...
});
```

### `streamObject` 立即返回

`streamObject` 函数现在立即返回，而不是返回一个 Promise。不需要 `await` `streamObject` 的结果。

```ts filename="AI SDK 3.4"
const result = await streamObject({
  // ...
});
```

```ts filename="AI SDK 4.0"
const result = streamObject({
  // ...
});
```

### 移除轮次

`maxToolRoundtrips` 和 `maxAutomaticRoundtrips` 选项已从 `generateText` 和 `streamText` 函数中移除。请改用 `maxSteps` 选项。

`roundtrips` 属性已从 `GenerateTextResult` 类型中移除。请改用 `steps` 属性。

```ts filename="AI SDK 3.4"
const { text, roundtrips } = await generateText({
  maxToolRoundtrips: 1, // 或 maxAutomaticRoundtrips
  // ...
});
```

```ts filename="AI SDK 4.0"
const { text, steps } = await generateText({
  maxSteps: 2,
  // ...
});
```

### 移除了 `nanoid` 导出

`nanoid` 导出已被移除。请改用 [`generateId`](/docs/reference/ai-sdk-core/generate-id)。

```ts filename="AI SDK 3.4"
import { nanoid } from 'ai';
```

```ts filename="AI SDK 4.0"
import { generateId } from 'ai';
```

### 增加了生成 ID 的默认大小

<Note type="warning">
  此更改没有可用的 codemod。请手动检查和更新你的代码。
</Note>

[`generateId`](/docs/reference/ai-sdk-core/generate-id) 函数现在生成 16 个字符的 ID。之前的默认值是 7 个字符。

例如，如果你限制了 ID 的长度，这可能需要更新你的数据库模式。

```ts filename="AI SDK 4.0"
import { generateId } from 'ai';

const id = generateId(); // 现在为 16 个字符
```

以下类型已被移除：

- `ExperimentalMessage`（改用 `ModelMessage`）
- `ExperimentalUserMessage`（改用 `CoreUserMessage`）
- `ExperimentalAssistantMessage`（改用 `CoreAssistantMessage`）
- `ExperimentalToolMessage`（改用 `CoreToolMessage`）

```ts filename="AI SDK 3.4"
import {
  ExperimentalMessage,
  ExperimentalUserMessage,
  ExperimentalAssistantMessage,
  ExperimentalToolMessage,
} from 'ai';
```

```ts filename="AI SDK 4.0"
import {
  ModelMessage,
  CoreUserMessage,
  CoreAssistantMessage,
  CoreToolMessage,
} from 'ai';
```

`ExperimentalTool` 类型已被移除。请改用 `CoreTool` 类型。

```ts filename="AI SDK 3.4"
import { ExperimentalTool } from 'ai';
```

```ts filename="AI SDK 4.0"
import { CoreTool } from 'ai';
```

以下导出已被移除：

- `experimental_generateText`（改用 `generateText`）
- `experimental_streamText`（改用 `streamText`）

### 从 `streamText` 移除了与 AI 流相关的方法

以下方法已从 `streamText` 结果中移除：

- `toAIStream`
- `pipeAIStreamToResponse`
- `toAIStreamResponse`

请改用 `toDataStream`、`pipeDataStreamToResponse` 和 `toDataStreamResponse` 函数。

```ts filename="AI SDK 3.4"
const result = await streamText({
  // ...

result.toAIStream();
result.pipeAIStreamToResponse(response);
result.toAIStreamResponse();
```

```ts filename="AI SDK 4.0"
const result = streamText({
  // ...

result.toDataStream();
result.pipeDataStreamToResponse(response);

```


### 移除了弃用的遥测数据

<Note type="warning">
  此更改没有可用的 codemod。请手动检查和更新你的代码。
</Note>

以下遥测数据值已被移除：

- `ai.finishReason`（现在位于 `ai.response.finishReason`）
- `ai.result.object`（现在位于 `ai.response.object`）
- `ai.result.text`（现在位于 `ai.response.text`）
- `ai.result.toolCalls`（现在位于 `ai.response.toolCalls`）

此更改将影响可观测性提供商以及你用于处理遥测数据的任何脚本或自动化。

## AI SDK 2.x 旧版变更

<Note type="warning">
  本节中的更改没有可用的 codemod。请手动检查和更新你的代码。
</Note>

### 移除了 2.x 旧版提供商

来自 AI SDK 2.x 的旧版提供商已被移除。请改用新的 [AI SDK 提供商架构](/docs/foundations/providers-and-models)。

#### 移除了 2.x 旧版函数和工具调用

`useChat` 和 `Message` 中的旧版 `function_call` 和 `tools` 选项已被移除。`Message` 类型中的 `name` 属性已被移除。请改用 [AI SDK Core 工具调用](/docs/ai-sdk-core/tools-and-tool-calling)。

### 移除了 2.x 提示词辅助函数

使用 AI SDK 提供商架构不再需要用于构建消息提示词的辅助函数，它们已被移除。

### 移除了 2.x `AIStream`

`AIStream` 函数及相关导出已被移除。请改用 [`streamText`](/docs/reference/ai-sdk-core/stream-text) 函数及其 `toDataStream()` 方法。

### 移除了 2.x `StreamingTextResponse`

`StreamingTextResponse` 函数已被移除。请改用 [`streamText`](/docs/reference/ai-sdk-core/stream-text) 函数及其 `toDataStreamResponse()` 方法。

### 移除了 2.x `streamToResponse`

`streamToResponse` 函数已被移除。请改用 [`streamText`](/docs/reference/ai-sdk-core/stream-text) 函数及其 `pipeDataStreamToResponse()` 方法。

### 移除了 2.x RSC `Tokens` 流式传输

来自 2.x 的旧版 `Tokens` RSC 流式传输已被移除。`Tokens` 是在 AI SDK RSC 之前实现的，不再需要。
