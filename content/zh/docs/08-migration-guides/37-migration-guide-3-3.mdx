# 将 AI SDK 3.2 迁移到 3.3

<Note>
  查看 [AI SDK 3.3 发布博客文章](https://vercel.com/blog/vercel-ai-sdk-3-3) 以了解有关此版本的更多信息。
</Note>

此版本中没有破坏性变更。

以下变更日志涵盖了 3.2.x 系列中所做的所有更改，在 AI SDK 及其相关库中引入了重大改进和新功能：

## 新功能

### OpenTelemetry 支持

- 为所有 [AI SDK Core 函数](/docs/ai-sdk-core/overview#ai-sdk-core-functions) 添加了实验性的 [OpenTelemetry 支持](/docs/ai-sdk-core/telemetry)，从而实现更好的可观测性和追踪能力。

### AI SDK UI 改进

- 引入了实验性的 **`useObject`** Hook（用于 React），可与后端的 **`streamObject`** 配合使用，实现结构化数据的无缝流式传输。
- 增强了 **`useChat`**，实验性支持附件和流式工具调用，提供更通用的聊天功能。
- 修补了 **`useChat`** 以防止空提交，通过确保只处理预期的输入来提高用户交互质量。
- 修复了 **`useChat`** 的 **`reload`** 函数，现在可以正确发送 data、body 和 headers。
- 为 **`useAssistant`** 实现了 **`setThreadId`** 辅助函数，简化了线程管理。
- 为 **`useChat`** 和 **`useCompletion`** 编写了流数据协议文档，允许开发者将这些函数与任何后端一起使用。流数据协议还支持将自定义前端与 **`streamText`** 一起使用。
- 添加了对自定义 fetch 函数和请求体自定义的支持，提供对 API 交互的更大控制。
- 为 **`useChat`** Hook 添加了 **`onFinish`**，用于访问 token 使用量和完成原因。

### 核心增强

- 实现了对发送自定义请求头的支持，从而实现更定制化的 API 请求。
- 在现有 Zod 支持的基础上添加了原始 JSON schema 支持，为 schema 和数据验证提供更多选项。
- 为 **`embed`** 和 **`embedMany`** 函数引入了使用信息，提供对 token 使用量的洞察。
- 添加了对其他设置的支持，包括 **`stopSequences`** 和 **`topK`**，允许对文本生成进行更精细的控制。
- 提供了对 **`generateText`** 所有步骤信息的访问，从而可以访问中间工具调用和结果。

### 新提供商

- [AWS Bedrock 提供商](/providers/ai-sdk-providers/amazon-bedrock)。

### 提供商改进

- 增强了现有提供商，包括 Anthropic、Google、Azure 和 OpenAI，进行了各种改进和错误修复。
- 升级了 LangChain 适配器，支持 StreamEvent v2，并引入了 **`toDataStreamResponse`** 函数，可将 LangChain 输出流转换为数据流响应。
- 为 OpenAI 提供商添加了旧版工具调用支持。
- 更新了 Mistral AI 提供商，修复并改进了工具调用支持。

### UI 框架支持扩展

- SolidJS：更新了 **`useChat`** 和 **`useCompletion`**，以实现与 React 实现的功能对等。
- Vue.js：引入了 **`useAssistant`** Hook。
- Vue.js / Nuxt：[更新了示例](https://github.com/vercel/ai/tree/main/examples/nuxt-openai)，以展示最新功能和最佳实践。
- Svelte：为 **`useChat`** 添加了工具调用支持。

## 修复和改进

- 解决了 SDK 不同组件中的各种问题，包括竞态条件、错误处理和状态管理。
