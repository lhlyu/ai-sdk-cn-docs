# 将 AI SDK 3.2 迁移至 3.3

<Note>
  有关该版本的更多信息，请查看 [AI SDK 3.3 发布博客文章](https://vercel.com/blog/vercel-ai-sdk-3-3)。
</Note>

此版本无破坏性变更。

以下变更日志涵盖了 3.2.x 系列中的所有更改，为 AI SDK 及其相关库引入了重大改进和新功能：

## 新功能

### OpenTelemetry 支持

- 为所有 [AI SDK Core 函数](/docs/ai-sdk-core/telemetry#telemetry) 添加了实验性 [OpenTelemetry 支持](/docs/ai-sdk-core/overview#ai-sdk-core-functions)，从而提供更好的可观测性和追踪能力。

### AI SDK UI 改进

- 引入了实验性 **`useObject`** Hook（适用于 React），可与后端的 **`streamObject`** 结合使用，实现结构化数据的无缝流式传输。
- 增强了 **`useChat`**，实验性支持附件和流式工具调用，提供更通用的聊天功能。
- 修补了 **`useChat`**，防止空提交，确保仅处理预期输入，从而提升用户交互质量。
- 修复了 **`useChat`** 的 **`reload`** 函数，现在能正确发送数据、请求体和请求头。
- 为 **`useAssistant`** 实现了 **`setThreadId`** 辅助函数，简化线程管理。
- 记录了 **`useChat`** 和 **`useCompletion`** 的流数据协议，允许开发者将这两个函数与任何后端配合使用。流数据协议还支持将自定义前端与 **`streamText`** 结合使用。
- 添加了对自定义 fetch 函数和请求体定制的支持，提供对 API 交互的更大控制。
- 为 **`useChat`** Hook 添加了 **`onFinish`**，用于获取令牌使用情况和完成原因。

### 核心增强

- 实现了对发送自定义请求头的支持，使 API 请求更具定制性。
- 在现有 Zod 支持基础上，添加了原始 JSON Schema 支持，为模式和数据验证提供更多选择。
- 为 **`embed`** 和 **`embedMany`** 函数引入了使用信息，提供令牌使用情况的洞察。
- 添加了对其他设置的支持，包括 **`stopSequences`** 和 **`topK`**，允许对文本生成进行更精细的控制。
- 提供了对 **`generateText`** 所有步骤信息的访问，包括中间工具调用和结果。

### 新提供商

- [AWS Bedrock 提供商](/providers/ai-sdk-providers/amazon-bedrock)。

### 提供商改进

- 增强了现有提供商，包括 Anthropic、Google、Azure 和 OpenAI，进行了各种改进和错误修复。
- 升级了 LangChain 适配器，支持 StreamEvent v2，并引入了 **`toDataStreamResponse`** 函数，可将 LangChain 输出流转换为数据流响应。
- 为 OpenAI 提供商添加了旧版函数调用支持。
- 更新了 Mistral AI 提供商，修复并改进了工具调用支持。

### UI 框架支持扩展

- SolidJS：更新了 **`useChat`** 和 **`useCompletion`**，实现与 React 实现的功能对等。
- Vue.js：引入了 **`useAssistant`** Hook。
- Vue.js / Nuxt：[更新了示例](https://github.com/vercel/ai/tree/main/examples/nuxt-openai)，展示最新功能和最佳实践。
- Svelte：为 **`useChat`** 添加了工具调用支持。

## 修复和改进

- 解决了 SDK 不同组件中的各种问题，包括竞态条件、错误处理和状态管理。
