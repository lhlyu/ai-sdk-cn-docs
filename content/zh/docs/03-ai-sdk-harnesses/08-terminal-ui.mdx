# 终端 UI 的 Harnesses

`@ai-sdk/tui` 可以在终端中渲染 harness 流、工具调用、推理部分和审批提示。由于 `HarnessAgent` 每次调用都需要一个会话，因此可以将其包装在一个小的 `AgentTUIAgent` 适配器中，该适配器在终端 UI 的整个生命周期内注入一个会话。

## 安装

<InstallPackages packages="@ai-sdk/tui @ai-sdk/harness @ai-sdk/harness-codex @ai-sdk/sandbox-vercel" />

## 示例

```ts filename='tui.ts'
import { HarnessAgent, type HarnessAgentSession } from '@ai-sdk/harness/agent';
import { codex } from '@ai-sdk/harness-codex';
import { createVercelSandbox } from '@ai-sdk/sandbox-vercel';
import { runAgentTUI, type AgentTUIAgent } from '@ai-sdk/tui';

const agent = new HarnessAgent({
  harness: codex,
  sandbox: createVercelSandbox({
    runtime: 'node24',
    ports: [4000],
  }),
});

function createTUIAgent({
  agent,
  session,
}: {
  agent: HarnessAgent<any, any, any>;
  session: HarnessAgentSession;
}): AgentTUIAgent {
  return {
    version: 'agent-v1',
    id: agent.id,
    tools: agent.tools,
    generate(request) {
      return agent.generate({
        ...request,
        session,
      } as Parameters<typeof agent.generate>[0]);
    },
    stream(request) {
      return agent.stream({
        ...request,
        session,
      } as Parameters<typeof agent.stream>[0]);
    },
  } as AgentTUIAgent;
}

const session = await agent.createSession();

try {
  await runAgentTUI({
    title: 'Codex',
    agent: createTUIAgent({ agent, session }),
    tools: 'auto-collapsed',
    reasoning: 'collapsed',
  });
} finally {
  await session.destroy();
}
```

终端 UI 会一直运行，直到用户按下 `Esc` 或 `Ctrl+C` 退出。

每次终端运行使用一个会话。对于长期运行的终端工具，如果需要稍后恢复，请持久化 `session.detach()` 或 `session.stop()` 中的状态。
