# 工具集技能

[技能](https://agentskills.io/) 是可复用的指令包，适用于项目约定、工作流指南、领域特定流程，或任何其他应能被底层工具集运行时发现的指令。您可以为 `HarnessAgent` 配置技能，或在完成的回合之间替换它们。

## 定义技能

通过 `skills` 设置将技能传递给 `HarnessAgent`：

```ts
const agent = new HarnessAgent({
  harness: claudeCode,
  sandbox: createVercelSandbox({
    runtime: 'node24',
    ports: [4000],
  }),
  skills: [
    {
      name: 'careful-refactors',
      description: 'Make small, low-risk code changes.',
      content:
        'Prefer minimal diffs. Preserve public APIs. Before editing, read references/checklist.md and follow it.',
      files: [
        {
          path: 'references/checklist.md',
          content:
            '# Refactor checklist\n\n- Identify the smallest useful change.\n- Preserve public APIs.\n- Run the narrowest relevant test.',
        },
      ],
    },
  ],
});
```

每个技能包含：

- `name`：技能的稳定标识符。
- `description`：面向模型的简短摘要。
- `content`：完整的指令内容。
- `files`：可选的附加文本文件，与技能捆绑在一起。

附加文件使用技能相对 POSIX 路径，例如 `reference.md`、`references/codes.md` 或 `templates/config.json`。当智能体需要读取这些文件时，请在 `content` 中引用这些路径。

## 何时使用技能

对于应按需提供的可复用指令，请使用技能，而不是像常规 `instructions` 那样始终加载到智能体的上下文中。

使用 `instructions` 来定义广泛的智能体行为和当前会话的优先级。

可以使用 `callOptionsSchema` 和 `prepareCall` 在完成的回合之间更改技能。有关详细信息，请参阅[在回合之间更改设置](/docs/ai-sdk-harnesses/harness-agent#change-settings-between-turns)。
