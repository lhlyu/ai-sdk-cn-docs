# Harness Skills

[Skills](https://agentskills.io/) 是可复用的指令包，可用于项目约定、工作流指导、领域特定流程，或任何其他应能被底层 harness 运行时发现的指令。你可以为 `HarnessAgent` 配置 skills，也可以在已完成的轮次之间替换它们。

## 定义 Skills

通过 `skills` 设置将 skills 传递给 `HarnessAgent`：

```ts
const agent = new HarnessAgent({
  harness: claudeCode,
  skills: [
    {
      name: 'careful-refactors',
      description: 'Make small, low-risk code changes.',
      content:
        'Prefer minimal diffs. Preserve public APIs. Before editing, read references/checklist.md and follow it.',
      files: [
        {
          path: 'references/checklist.md',
          content:
            '# Refactor checklist\n\n- Identify the smallest useful change.\n- Preserve public APIs.\n- Run the narrowest relevant test.',
        },
      ],
    },
  ],
});
```

每个 skill 包含：

- `name`：skill 的稳定标识符。
- `description`：面向模型的简短摘要。
- `content`：完整的指令内容。
- `files`：可选的、随 skill 一起打包的额外文本文件。

额外文件使用相对于 skill 的 POSIX 路径，例如
`reference.md`、`references/codes.md` 或 `templates/config.json`。当智能体应读取这些文件时，请在 `content` 中引用这些路径。

## 何时使用 Skills

对于应按需提供的可复用指令，请使用 skills，而不是像常规 `instructions` 那样始终加载到智能体的上下文中。

使用 `instructions` 来定义宽泛的智能体行为和当前会话的优先事项。

可以使用 `callOptionsSchema` 和 `prepareCall` 在已完成的轮次之间更改 skills。详情请参阅[在轮次之间更改设置](/docs/ai-sdk-harnesses/harness-agent#change-settings-between-turns)。
