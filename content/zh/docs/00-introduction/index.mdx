# AI SDK

AI SDK 是一个 TypeScript 工具包，旨在帮助开发者使用 React、Next.js、Vue、Svelte、Node.js 等构建 AI 驱动的应用和智能体。

## 为什么使用 AI SDK？

将大型语言模型（LLM）集成到应用中既复杂，又在很大程度上取决于你所使用的具体模型提供商。

AI SDK 标准化了在[受支持的提供商](/docs/foundations/providers-and-models)之间集成人工智能（AI）模型的方式。这使开发者能够专注于构建出色的 AI 应用，而不必在技术细节上浪费时间。

AI SDK 还包含一个[harness 抽象](/docs/ai-sdk-harnesses)，用于通过
`HarnessAgent` 使用诸如 Claude Code、Codex 和 Pi 等成熟的智能体 harness。Harness 与模型提供商解耦，但使用兼容的
流和响应原语，因此 AI SDK UI 和智能体接口可以以相同的方式使用它们。

AI SDK 包含以下主要接口：

- **[AI SDK Core](/docs/ai-sdk-core)：** 一个统一的 API，用于生成文本、结构化对象、工具调用，以及使用 LLM 构建智能体。
- **[AI SDK UI](/docs/ai-sdk-ui)：** 一组与框架无关的 Hook，用于快速构建聊天和生成式用户界面。
- **[AI SDK Harnesses](/docs/ai-sdk-harnesses)：** 一个统一的 API，用于通过 `HarnessAgent` 运行成熟的智能体 harness。

## `llms.txt`（适用于 Cursor、Windsurf、Copilot、Claude 等）

你可以在 [ai-sdk.dev/llms.txt](/llms.txt) 以 Markdown 格式访问完整的 AI SDK 文档。这可用于让任何 LLM（假设其上下文窗口足够大）基于最新的文档回答有关 AI SDK 的问题。

### 使用示例

例如，要向 LLM 提出有关 AI SDK 的问题：

1. 从 [ai-sdk.dev/llms.txt](/llms.txt) 复制文档内容
2. 使用以下提示词格式：

```text
Documentation:
{paste documentation here}
---
Based on the above documentation, answer the following:
{your question}
```
