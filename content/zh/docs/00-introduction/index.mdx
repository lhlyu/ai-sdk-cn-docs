# AI SDK

AI SDK 是一个 TypeScript 工具包，帮助开发者使用 React、Next.js、Vue、Svelte、Node.js 等技术构建 AI 应用和智能体。

## 为什么使用 AI SDK？

把大语言模型集成到应用里并不简单，而且会强依赖具体的模型提供商。

AI SDK 对不同 [模型提供商](/docs/foundations/providers-and-models) 的集成方式做了标准化。这样开发者可以把精力放在应用本身，而不是反复处理每个模型接口的细节。

AI SDK 也包含一个 [harness 抽象](/docs/ai-sdk-harnesses)，可通过 `HarnessAgent` 使用 Claude Code、Codex、Pi 等成熟智能体运行环境。

<PreviewSwitchProviders />

AI SDK 主要包含这些能力：

- **[AI SDK Core](/docs/ai-sdk-core)：** 用统一 API 生成文本、结构化对象、工具调用，并基于大语言模型构建智能体。
- **[AI SDK UI](/docs/ai-sdk-ui)：** 一组框架无关的 Hook，用于快速构建聊天和生成式 UI。
- **[AI SDK Harnesses](/docs/ai-sdk-harnesses)：** 使用 `HarnessAgent` 以统一 API 运行成熟智能体 harness。
