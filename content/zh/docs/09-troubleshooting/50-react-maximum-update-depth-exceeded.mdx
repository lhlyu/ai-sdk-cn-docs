# React 错误 "Maximum update depth exceeded"

## 问题

我在 React 项目中使用 AI SDK 的 `useChat` 或 `useCompletion` Hook，
当 AI 响应流式传输进来时，我遇到了以下错误：`Maximum update depth exceeded`。

## 背景

默认情况下，每到达一个数据块，UI 都会重新渲染。
这可能会导致渲染过载，尤其是在较慢的设备上，或者当复杂组件
需要更新时（例如 Markdown）。节流可以缓解这个问题。

## 解决方案

使用 `throttle` 选项来节流 UI 更新：

### `useChat`

```tsx filename="page.tsx" highlight="2-3"
const { messages } = useChat({
  // Throttle the messages and data updates to 50ms:
  throttle: 50,
});
```

### `useCompletion`

```tsx filename="page.tsx" highlight="2-3"
const { completion } = useCompletion({
  // Throttle the completion and data updates to 50ms:
  throttle: 50,
});
```
