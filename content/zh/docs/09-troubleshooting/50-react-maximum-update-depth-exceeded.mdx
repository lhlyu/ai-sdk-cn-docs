# React 错误“超出最大更新深度”

## 问题

我在 React 项目中使用 AI SDK 的 `useChat` 或 `useCompletion` Hook，
当 AI 响应流式传输时，出现以下错误：`超出最大更新深度`。

## 背景

默认情况下，UI 会在每个到达的数据块上重新渲染。
这可能会使渲染过载，尤其是在较慢的设备上或需要更新复杂组件（例如 Markdown）时。
节流可以缓解此问题。

## 解决方案

使用 `throttle` 选项来节流 UI 更新：

### `useChat`

```tsx filename="page.tsx" highlight="2-3"
const { messages, ... } = useChat({
  // 将消息和数据更新节流到 50ms：
  throttle: 50
})
```

### `useCompletion`

```tsx filename="page.tsx" highlight="2-3"
const { completion, ... } = useCompletion({
  // 将完成和数据更新节流到 50ms：
  throttle: 50
})
```
