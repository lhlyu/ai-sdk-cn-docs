# 工具调用缺少结果错误

## 问题

使用 `generateText()` 或 `streamText()` 时，如果调用了没有 `execute` 函数的工具，可能会遇到 "ToolInvocation must have a result" 错误。

## 原因

当您定义了一个没有 `execute` 函数的工具，并且没有通过其他方式（如 `useChat` 的 `onToolCall` 或 `addToolOutput` 函数）提供结果时，就会发生此错误。

每次调用工具时，模型都期望在继续对话前收到结果。如果没有结果，模型无法判断工具调用是成功还是失败，对话状态将变得无效。

## 解决方案

您有两种处理工具结果的方式：

1. 使用带 `execute` 函数的工具在服务端执行：

```tsx
const tools = {
  weather: tool({
    description: '获取某个地点的天气',
    inputSchema: z.object({
      location: z
        .string()
        .describe('城市和州，例如 "San Francisco, CA"'),
    }),
    execute: async ({ location }) => {
      // 获取并返回天气数据
      return { temperature: 72, conditions: 'sunny', location };
    },
  }),
};
```

2. 使用 `useChat` 在客户端执行（省略 `execute` 函数），您必须通过 `addToolOutput` 提供结果：

```tsx
import { useChat } from '@ai-sdk/react';
import {
  DefaultChatTransport,
  lastAssistantMessageIsCompleteWithToolCalls,
} from 'ai';

const { messages, sendMessage, addToolOutput } = useChat({
  // 当所有工具结果可用时自动提交
  sendAutomaticallyWhen: lastAssistantMessageIsCompleteWithToolCalls,

  // 在 onToolCall 中处理工具调用
  onToolCall: async ({ toolCall }) => {
    if (toolCall.toolName === 'getLocation') {
      try {
        const result = await getLocationData();

        // 重要：不要在 onToolCall 内部使用 await，以避免死锁
        addToolOutput({
          tool: 'getLocation',
          toolCallId: toolCall.toolCallId,
          output: result,
        });
      } catch (err) {
        // 重要：不要在 onToolCall 内部使用 await，以避免死锁
        addToolOutput({
          tool: 'getLocation',
          toolCallId: toolCall.toolCallId,
          state: 'output-error',
          errorText: '获取位置失败',
        });
      }
    }
  },
});
```

```tsx
// 对于交互式 UI 元素：
const { messages, sendMessage, addToolOutput } = useChat({
  transport: new DefaultChatTransport({ api: '/api/chat' }),
  sendAutomaticallyWhen: lastAssistantMessageIsCompleteWithToolCalls,
});

// 在您的 JSX 中，渲染工具调用时：
<button
  onClick={() =>
    addToolOutput({
      tool: 'myTool',
      toolCallId, // 必须提供工具调用 ID
      output: {
        /* 您的工具结果 */
      },
    })
  }
>
  确认
</button>;
```

<Note type="warning">
  无论是在服务端还是客户端处理工具，每个工具调用在对话继续之前都必须有对应的结果。
</Note>
