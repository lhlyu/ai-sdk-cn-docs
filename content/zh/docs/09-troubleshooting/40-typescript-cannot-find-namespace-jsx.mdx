# TypeScript 错误 "Cannot find namespace 'JSX'"

## 问题

我在没有 React 的项目中使用 AI SDK，例如 Hono 服务器，并遇到以下错误：
`error TS2503: Cannot find namespace 'JSX'.`

## 背景

AI SDK 依赖于 `@types/react`，该包定义了 `JSX` 命名空间。
该依赖将在 AI SDK 的下一个主要版本中移除。

## 解决方案

你可以安装 `@types/react` 包作为依赖项来解决此错误。

```bash
npm install @types/react
```
