# 模型无法赋值给类型 "LanguageModelV1"

## 问题

我已更新 AI SDK，现在遇到以下错误：`Type 'SomeModel' is not assignable to type 'LanguageModelV1'.`

<Note>`EmbeddingModelV4` 也可能出现类似错误。</Note>

## 背景

有时模型规范会新增功能。这可能导致与旧版提供商版本不兼容。

## 解决方案

将您的提供商包和 AI SDK 更新至最新版本。
