# `streamText` 无法工作

## 问题

我使用了 [`streamText`](/docs/reference/ai-sdk-core/stream-text) 函数，但它无法正常工作。
它没有抛出任何错误，且流中只包含错误部分。

## 背景

`streamText` 会立即开始流式传输，以便无需等待模型即可发送数据。
错误会成为流的一部分，而不会被抛出，以防止服务器崩溃等情况。

## 解决方案

要记录错误，你可以提供一个 `onError` 回调函数，该函数在发生错误时被触发。

```tsx highlight="7-9"
import { streamText } from 'ai';
__PROVIDER_IMPORT__;

const result = streamText({
  model: __MODEL__,
  prompt: '发明一个新节日并描述其传统。',
  onError({ error }) {
    console.error(error); // 在此处编写你的错误记录逻辑
  },
});
```
