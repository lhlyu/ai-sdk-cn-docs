# 结合结构化输出的工具调用

## 问题

你可能希望将工具调用与结构化输出生成结合使用。

## 背景

如需在工具调用中使用结构化输出，请使用 `generateText` 或 `streamText` 并指定 `output` 选项。

**重要提示**：在工具调用中使用 `output` 时，结构化输出生成会作为执行流程中的一个额外步骤。

## 解决方案

在工具调用中使用 `output` 时，请调整 `stopWhen` 条件，以计入结构化输出生成所需的额外步骤：

```tsx
const result = await generateText({
  model: __MODEL__,
  output: Output.object({
    schema: z.object({
      summary: z.string(),
      sentiment: z.enum(['positive', 'neutral', 'negative']),
    }),
  }),
  tools: {
    analyze: tool({
      description: 'Analyze data',
      inputSchema: z.object({
        data: z.string(),
      }),
      execute: async ({ data }) => {
        return { result: 'analyzed' };
      }),
    },
  },
  // 在预期步骤数基础上至少加 1，以计入结构化输出
  stopWhen: isStepCount(3), // 现在计入：工具调用 + 工具结果 + 结构化输出
  prompt: 'Analyze the data and provide a summary',
});
```

有关在 `generateText` 和 `streamText` 中使用结构化输出的更多信息，请参阅[生成结构化数据](/docs/ai-sdk-core/generating-structured-data#generating-structured-outputs)。
