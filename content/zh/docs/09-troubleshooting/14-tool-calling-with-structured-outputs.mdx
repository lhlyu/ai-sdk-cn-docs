# 结合结构化输出的工具调用

## 问题

你可能希望将工具调用与结构化输出生成结合使用。

## 背景

要使用结构化输出进行工具调用，请使用带有 `output` 选项的 `generateText` 或 `streamText`。

**重要**：当在工具调用中使用 `output` 时，结构化输出生成会在执行流程中计为一个额外的步骤。

## 解决方案

当在工具调用中使用 `output` 时，请调整你的 `stopWhen` 条件，以计入结构化输出生成所需的额外步骤：

```tsx
const result = await generateText({
  model: __MODEL__,
  output: Output.object({
    schema: z.object({
      summary: z.string(),
      sentiment: z.enum(['positive', 'neutral', 'negative']),
    }),
  }),
  tools: {
    analyze: tool({
      description: '分析数据',
      inputSchema: z.object({
        data: z.string(),
      }),
      execute: async ({ data }) => {
        return { result: 'analyzed' };
      }),
    },
  },
  // 在你预期的步骤数上至少加 1，以计入结构化输出
  stopWhen: isStepCount(3), // 现在计入：工具调用 + 工具结果 + 结构化输出
  prompt: '分析数据并提供摘要',
});
```

有关在 `generateText` 和 `streamText` 中使用结构化输出的更多信息，请参阅[生成结构化数据](/docs/ai-sdk-core/generating-structured-data#structured-outputs-with-generatetext-and-streamtext)。
