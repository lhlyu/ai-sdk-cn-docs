# useChat 中的请求体数据陈旧问题

## 问题

使用 `useChat` 并通过 Hook 级别的 `body` 参数传递动态信息时，数据会保持陈旧状态，仅反映组件初始渲染时的值。这是因为 body 配置在 Hook 初始化时被捕获一次，后续组件重新渲染时不会更新。

```tsx
// 问题代码 - body 数据将保持陈旧
export default function Chat() {
  const [temperature, setTemperature] = useState(0.7);
  const [userId, setUserId] = useState('user123');

  // 此 body 配置仅捕获一次，不会更新
  const { messages, sendMessage } = useChat({
    transport: new DefaultChatTransport({
      api: '/api/chat',
      body: {
        temperature, // 始终为初始值 (0.7)
        userId, // 始终为初始值 ('user123')
      },
    }),
  });

  // 即使 temperature 或 userId 发生变化，请求中的 body 仍使用初始值
  return (
    <div>
      <input
        type="range"
        value={temperature}
        onChange={e => setTemperature(parseFloat(e.target.value))}
      />
      {/* 聊天界面 */}
    </div>
  );
}
```

## 背景

Hook 级别的 body 配置在初始渲染时被评估一次，当组件状态发生变化时不会重新评估。

## 解决方案

将动态变量通过 `sendMessage` 函数的第二个参数传递，而不是在 Hook 级别传递。请求级别的选项会在每次调用时评估，并优先于 Hook 级别的选项。

```tsx
export default function Chat() {
  const [temperature, setTemperature] = useState(0.7);
  const [userId, setUserId] = useState('user123');
  const [input, setInput] = useState('');

  const { messages, sendMessage } = useChat({
    // 仅静态配置
    transport: new DefaultChatTransport({
      api: '/api/chat',
    }),
  });

  return (
    <div>
      <input
        type="range"
        value={temperature}
        onChange={e => setTemperature(parseFloat(e.target.value))}
      />

      <form
        onSubmit={event => {
          event.preventDefault();
          if (input.trim()) {
            // 将动态值作为请求级别选项传递
            sendMessage(
              { text: input },
              {
                body: {
                  temperature, // 请求时的当前值
                  userId, // 请求时的当前值
                },
              },
            );
            setInput('');
          }
        }}
      >
        <input value={input} onChange={e => setInput(e.target.value)} />
      </form>
    </div>
  );
}
```

### 替代方案：动态 Hook 级别配置

如果你需要响应变化的 Hook 级别配置，可以使用返回配置值的函数。但对于组件状态，你需要使用 `useRef` 来访问当前值：

```tsx
export default function Chat() {
  const temperatureRef = useRef(0.7);

  const { messages, sendMessage } = useChat({
    transport: new DefaultChatTransport({
      api: '/api/chat',
      body: () => ({
        temperature: temperatureRef.current, // 通过 ref.current 访问
        sessionId: getCurrentSessionId(), // 函数调用可直接工作
      }),
    }),
  });

  // ...
}
```

**建议：** 对于组件状态，请求级别配置更简单且更可靠。当你需要传递在组件生命周期内变化的动态值时，请使用此方式。

### 服务端处理

在服务端，通过解构请求体来获取自定义字段：

```tsx
// app/api/chat/route.ts
export async function POST(req: Request) {
  const { messages, temperature, userId } = await req.json();

  const result = streamText({
    model: 'openai/gpt-5-mini',
    messages: await convertToModelMessages(messages),
    temperature, // 使用来自请求的动态 temperature
    // ... 其他配置
  });

  return createUIMessageStreamResponse({
    stream: toUIMessageStream({ stream: result.stream }),
  });
}
```
