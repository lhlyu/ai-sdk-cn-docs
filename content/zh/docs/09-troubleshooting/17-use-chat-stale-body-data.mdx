# useChat 中的 body 值过期

## 问题

在使用 `useChat` 并在 Hook 层级通过 `body` 参数传递动态信息时，数据会保持过期状态，仅反映组件初始渲染时的值。这是因为 body 配置在 Hook 初始化时被捕获一次，之后组件重新渲染时不会更新。

```tsx
// 有问题的代码 - body 数据会过期
export default function Chat() {
  const [temperature, setTemperature] = useState(0.7);
  const [userId, setUserId] = useState('user123');

  // 此 body 配置只被捕获一次，不会更新
  const { messages, sendMessage } = useChat({
    transport: new DefaultChatTransport({
      api: '/api/chat',
      body: {
        temperature, // 始终是初始值 (0.7)
        userId, // 始终是初始值 ('user123')
      },
    }),
  });

  // 即使 temperature 或 userId 发生变化，请求中的 body 仍会使用初始值
  return (
    <div>
      <input
        type="range"
        value={temperature}
        onChange={e => setTemperature(parseFloat(e.target.value))}
      />
      {/* Chat UI */}
    </div>
  );
}
```

## 背景

Hook 层级的 body 配置在初始渲染时被求值一次，当组件状态变化时不会重新求值。

## 解决方案

通过 `sendMessage` 函数的第二个参数传递动态变量，而不是在 Hook 层级传递。请求级别的选项在每次调用时都会求值，并且优先于 Hook 级别的选项。

```tsx
export default function Chat() {
  const [temperature, setTemperature] = useState(0.7);
  const [userId, setUserId] = useState('user123');
  const [input, setInput] = useState('');

  const { messages, sendMessage } = useChat({
    // 仅静态配置
    transport: new DefaultChatTransport({
      api: '/api/chat',
    }),
  });

  return (
    <div>
      <input
        type="range"
        value={temperature}
        onChange={e => setTemperature(parseFloat(e.target.value))}
      />

      <form
        onSubmit={event => {
          event.preventDefault();
          if (input.trim()) {
            // 将动态值作为请求级别的选项传递
            sendMessage(
              { text: input },
              {
                body: {
                  temperature, // 请求时的当前值
                  userId, // 请求时的当前值
                },
              },
            );
            setInput('');
          }
        }}
      >
        <input value={input} onChange={e => setInput(e.target.value)} />
      </form>
    </div>
  );
}
```

### 替代方案：动态 Hook 层级配置

如果你需要能够响应变化的 Hook 层级配置，可以使用返回配置值的函数。不过，对于组件状态，你需要使用 `useRef` 来访问当前值：

```tsx
export default function Chat() {
  const temperatureRef = useRef(0.7);

  const { messages, sendMessage } = useChat({
    transport: new DefaultChatTransport({
      api: '/api/chat',
      body: () => ({
        temperature: temperatureRef.current, // 通过 ref.current 访问
        sessionId: getCurrentSessionId(), // 函数调用可直接使用
      }),
    }),
  });

  // ...
}
```

**建议：** 对于组件状态，请求级别的配置更简单也更可靠。当你需要传递在组件生命周期内发生变化的动态值时，请使用它。

### 服务端处理

在服务端，通过解构请求 body 来获取自定义字段：

```tsx
// app/api/chat/route.ts
export async function POST(req: Request) {
  const { messages, temperature, userId } = await req.json();

  const result = streamText({
    model: 'openai/gpt-4.1-mini', // 支持动态 temperature 设置
    messages: await convertToModelMessages(messages),
    temperature, // 使用请求中的动态 temperature
    // ... 其他配置
  });

  return createUIMessageStreamResponse({
    stream: toUIMessageStream({ stream: result.stream }),
  });
}
```

更多信息，请参阅[聊天机器人请求配置文档](/docs/ai-sdk-ui/chatbot#request-configuration)。
