# 客户端组件中的服务端操作

你可以在客户端组件中使用服务端操作，但有时可能会遇到以下问题。

## 问题

不允许在客户端组件中定义内联的 `"use server"` 注释服务端操作。

## 解决方案

要在客户端组件中使用服务端操作，你可以：

- 从单独的文件中导出，并在文件顶部添加 `"use server"`。
- 通过服务端组件的 props 向下传递。
- 结合使用 [`createAI`](/docs/reference/ai-sdk-rsc/create-ai) 和 [`useActions`](/docs/reference/ai-sdk-rsc/use-actions) Hook 来访问它们。

了解更多关于[服务端操作和变更](https://nextjs.org/docs/app/api-reference/functions/server-actions#with-client-components)的信息。

```ts file='actions.ts'
'use server';

import { generateText } from 'ai';
__PROVIDER_IMPORT__;

export async function getAnswer(question: string) {
  'use server';

  const { text } = await generateText({
    model: __MODEL__,
    prompt: question,
  });

  return { answer: text };
}
```
