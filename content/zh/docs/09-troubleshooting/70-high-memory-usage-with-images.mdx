# 处理大量图片时内存占用过高

## 问题

在使用 `generateText` 或 `streamText` 处理大量图片时（例如在循环或批处理中），你可能会注意到：

- 内存占用持续增长且不会下降
- 应用最终耗尽内存
- 即使经过垃圾回收，内存也不会被释放

当使用 `experimental_download` 处理来自 URL 的图片，或在提示词中发送 base64 编码的图片时，这个问题尤为明显。

## 背景

当通过 `include` 选项启用时，AI SDK 会在步骤结果中包含完整的请求消息以及请求和响应体。在处理图片时，请求消息和请求体可能包含 base64 编码的图片数据，这些数据可能非常大（单张图片经 base64 编码后可能达到 1MB 以上）。如果你处理大量图片并保留对结果的引用，这些数据就会在内存中不断累积。

例如，处理 100 张每张 500KB 的图片，会在内存中包含约 50MB 以上的请求体数据。

## 解决方案

使用 `include` 选项禁用对请求消息和/或请求与响应体的包含：

```ts
import { generateText } from 'ai';
import { openai } from '@ai-sdk/openai';

const result = await generateText({
  model: openai('gpt-6-astra'),
  messages: [
    {
      role: 'user',
      content: [
        { type: 'text', text: 'Describe this image' },
        { type: 'file', mediaType: 'image', data: imageUrl },
      ],
    },
  ],
  // Request and response bodies are excluded by default.
  include: {
    requestBody: false,
    responseBody: false,
  },
});
```

### 选项

`include` 选项接受以下参数：

- `requestBody`：设置为 `true` 以在步骤结果中包含请求体。请求体通常是存储 base64 编码图片的地方。默认值：`false`。在 `generateText` 和 `streamText` 中均可用。
- `requestMessages`：设置为 `true` 以在步骤结果中包含请求消息。请求消息可能包含图片和文件等较大的消息内容。默认值：`false`。在 `generateText` 和 `streamText` 中均可用。
- `rawChunks`：设置为 `true` 以在流中包含提供商的原始数据块。默认值：`false`。仅在 `streamText` 中可用。
- `responseBody`：设置为 `true` 以在步骤结果中包含响应体。默认值：`false`。仅在 `generateText` 中可用。

### 何时使用

- **批量处理图片**：在循环中处理大量图片时
- **长时间运行的智能体**：当智能体在其生命周期内可能处理大量图片时
- **内存受限的环境**：在内存有限的环境中运行时

### 权衡

当你禁用请求体包含时：

- 你将无法访问 `result.request.body` 或 `result.response.body`
- 除非启用 `requestMessages`，否则你将无法访问 `result.request.messages`
- 调试可能会更困难，因为你无法检查原始请求/响应
- 如果你需要请求体用于日志记录或调试，请考虑在下一次迭代之前提取所需的数据

## 示例：处理多张图片

```ts
import { generateText } from 'ai';
import { openai } from '@ai-sdk/openai';

const imageUrls = [
  /* array of image URLs */
];
const results = [];

for (const imageUrl of imageUrls) {
  const result = await generateText({
    model: openai('gpt-6-astra'),
    messages: [
      {
        role: 'user',
        content: [
          { type: 'text', text: 'Describe this image' },
          { type: 'file', mediaType: 'image', data: imageUrl },
        ],
      },
    ],
    include: {
      requestBody: false,
    },
  });

  // Only store the text result, not the full result object
  results.push(result.text);
}
```
