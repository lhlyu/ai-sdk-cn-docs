# 代理环境下流式传输失效

## 问题

在本地开发环境或某些代理环境中，AI SDK 的流式传输功能无法正常工作。  
不会进行流式传输，而是等待一段时间后直接返回完整响应。

## 原因

该问题由代理中间件引起。

如果中间件配置了响应压缩，将导致流式传输失败。

## 解决方案

可尝试以下方法，该方案仅影响流式传输 API：

- 添加 `'Content-Encoding': 'none'` 请求头

  ```tsx
  return createUIMessageStreamResponse({
    stream: toUIMessageStream({ stream: result.stream }),
    headers: {
      'Content-Encoding': 'none',
    },
  });
  ```
