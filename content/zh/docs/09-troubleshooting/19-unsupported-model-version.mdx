# 不支持的模型版本错误

## 问题

迁移至 AI SDK 5 时，可能会遇到模型使用不受支持版本的错误：

```
AI_UnsupportedModelVersionError: 提供商 "ollama.chat" 和模型 "gamma3:4b" 使用了不支持的模型版本 v1。
AI SDK 5 仅支持实现规范版本 "v2" 的模型。
```

此错误的原因是您使用的提供商包版本实现了较旧的（v1）模型规范。

## 背景

AI SDK 5 要求所有提供商包实现规范版本 "v2"。当您升级到 AI SDK 5 但未将提供商包更新到兼容版本时，它们会继续使用旧的 "v1" 规范，从而导致此错误。

## 解决方案

### 将提供商包更新至 AI SDK 5 兼容版本

将所有 `@ai-sdk/*` 提供商包更新至兼容版本 `2.0.0` 或更高版本。这些版本实现了 AI SDK 5 所需的 v2 规范。

```bash
pnpm install ai@latest @ai-sdk/openai@latest @ai-sdk/anthropic@latest
```

对于 AI SDK 5 兼容性，您需要：

- `ai` 包：`5.0.0` 或更高版本
- `@ai-sdk/*` 包：`2.0.0` 或更高版本（例如 `@ai-sdk/openai`、`@ai-sdk/anthropic`、`@ai-sdk/google`）
- `@ai-sdk/provider` 包：`2.0.0` 或更高版本
- `zod` 包：`4.1.8` 或更高版本

### 检查提供商兼容性

如果您使用的是第三方或自定义提供商，请确认其已更新以支持 AI SDK 5。并非所有提供商都已提供 v2 兼容版本。

要检查提供商是否支持 AI SDK 5：

1. 检查提供商的 package.json 中 `@ai-sdk/provider` 的 peer 依赖版本是否为 `2.0.0` 或更高版本
2. 查看提供商的更新日志或迁移指南
3. 检查提供商的仓库是否支持 AI SDK 5

有关迁移至 AI SDK 5 的更多信息，请参阅 [AI SDK 5.0 迁移指南](/docs/migration-guides/migration-guide-5-0)。
