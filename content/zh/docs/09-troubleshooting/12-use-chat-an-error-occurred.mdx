# `useChat` "发生错误"

## 问题

我正在使用 [`useChat`](/docs/reference/ai-sdk-ui/use-chat)，但遇到了"发生错误"的错误提示。

## 背景

出于安全考虑（默认安全），使用 `toUIMessageStream` 时，`streamText` 的错误消息默认会被屏蔽。这可以防止敏感信息泄露到客户端。

## 解决方案

如需将错误详情转发到客户端或记录错误，可在调用 `toUIMessageStream` 时使用 `onError` 函数。

```tsx
export function errorHandler(error: unknown) {
  if (error == null) {
    return 'unknown error';
  }

  if (typeof error === 'string') {
    return error;
  }

  if (error instanceof Error) {
    return error.message;
  }

  return JSON.stringify(error);
}
```

```tsx
const result = streamText({
  // ...
});

return createUIMessageStreamResponse({
  stream: toUIMessageStream({
    stream: result.stream,
    onError: errorHandler,
  }),
});
```

如果你使用的是 `createDataStreamResponse`，可以在调用 `toDataStreamResponse` 时使用 `onError` 函数：

```tsx
const response = createDataStreamResponse({
  // ...
  async execute(dataStream) {
    // ...
  },
  onError: errorHandler,
});
```
