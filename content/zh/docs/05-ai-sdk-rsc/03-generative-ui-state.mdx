# 管理生成式 UI 状态

<Note type="warning">
  AI SDK RSC 目前处于实验阶段。我们建议在生产环境中使用 [AI SDK
  UI](/docs/ai-sdk-ui/overview)。如需从 RSC 迁移到 UI 的指导，请参阅我们的[迁移指南](/docs/ai-sdk-rsc/migrating-to-ui)。
</Note>

状态是任何应用程序的重要组成部分。状态在 AI 应用程序中尤为重要，因为它在每次请求时都会被传递给大语言模型（LLM），以确保它们拥有生成优质内容所需的必要上下文。传统聊天机器人基于文本，其结构与任何聊天应用程序类似。

例如，在聊天机器人中，状态是一个 `messages` 数组，其中每条 `message` 包含：

- `id`：唯一标识符
- `role`：消息发送者（user/assistant/system/tool）
- `content`：消息内容

此状态可以在 UI 中渲染，并无需任何修改即可发送给模型。

借助生成式 UI，模型现在可以返回一个 React 组件，而不是纯文本消息。客户端可以正常渲染该组件，但该状态无法发送回模型，因为 React 组件不可序列化。那么，你该怎么办？

**解决方案是将状态一分为二，其中一个（AI 状态）成为另一个（UI 状态）的代理**。

理解这个概念的一种方式是通过乐高类比。想象一个由 10,000 块积木组成的乐高模型，一旦搭建完成，由于它很脆弱，就无法轻易运输。通过将模型拆解，它可以轻松运输，然后按照说明书小册子中列出的步骤重新搭建。这样，说明书小册子就是物理结构的代理。类似地，AI 状态提供了 UI 的可序列化（JSON）表示，可以来回传递给模型。

## 什么是 AI 状态和 UI 状态？

RSC API 简化了 AI 状态和 UI 状态的管理方式，提供了一种健壮的方法来保持它们在数据库、服务器和客户端之间的同步。

### AI 状态

AI 状态是指应用程序以可序列化格式存在的状态，它将在服务器上使用，并可以与语言模型共享。

对于聊天应用，AI 状态是用户与助手之间的对话历史（消息）。模型生成的组件将以 JSON 格式表示为工具，并附带任何必要的 props。AI 状态还可以用于存储其他值和元信息，例如每条消息的 `createdAt` 和每个对话的 `chatId`。LLM 读取此历史记录，以便生成下一条消息。此状态作为当前应用程序状态的唯一真实来源。

<Note>
  **注意**：AI 状态可以从服务器和客户端两端访问/修改。
</Note>

### UI 状态

UI 状态是指应用程序在客户端渲染的状态。它是一个完全客户端侧的状态（类似于 `useState`），可以存储从 JavaScript 值到 React 元素的任何内容。UI 状态是在客户端渲染的实际 UI 元素列表。

<Note>**注意**：UI 状态只能在客户端访问。</Note>

## 使用 AI / UI 状态

### 创建 AI 上下文

AI SDK RSC 通过提供多个 Hook 简化了应用程序中 AI 状态和 UI 状态的管理。这些 Hook 底层由 [React context](https://react.dev/reference/react/hooks#context-hooks) 提供支持。

值得注意的是，这意味着你不必为每个请求显式地将消息历史传递给服务器。你还可以在上下文提供者的任何子组件中访问和更新应用程序状态。当你开始构建[多步骤生成式界面](/docs/ai-sdk-rsc/multistep-interfaces)时，这将特别有用。

要在应用程序中使用 `@ai-sdk/rsc` 管理 AI 状态和 UI 状态，你可以使用 [`createAI`](/docs/reference/ai-sdk-rsc/create-ai) 创建一个 React 上下文：

```tsx filename='app/actions.tsx'
// Define the AI state and UI state types
export type ServerMessage = {
  role: 'user' | 'assistant';
  content: string;
};

export type ClientMessage = {
  id: string;
  role: 'user' | 'assistant';
  display: ReactNode;
};

export const sendMessage = async (input: string): Promise<ClientMessage> => {
  "use server"
  ...
}
```

```tsx filename='app/ai.ts'
import { createAI } from '@ai-sdk/rsc';
import { ClientMessage, ServerMessage, sendMessage } from './actions';

export type AIState = ServerMessage[];
export type UIState = ClientMessage[];

// Create the AI provider with the initial states and allowed actions
export const AI = createAI<AIState, UIState>({
  initialAIState: [],
  initialUIState: [],
  actions: {
    sendMessage,
  },
});
```

<Note>你必须将 Server Actions 传递给 `actions` 对象。</Note>

在此示例中，你分别定义了 AI 状态和 UI 状态的类型。

接下来，用你新创建的上下文包裹你的应用程序。这样，你就可以在整个应用程序中获取和设置 AI 状态和 UI 状态。

```tsx filename='app/layout.tsx'
import { type ReactNode } from 'react';
import { AI } from './ai';

export default function RootLayout({
  children,
}: Readonly<{ children: ReactNode }>) {
  return (
    <AI>
      <html lang="en">
        <body>{children}</body>
      </html>
    </AI>
  );
}
```

## 在客户端读取 UI 状态

UI 状态可以在客户端组件中使用 RSC API 提供的 [`useUIState`](/docs/reference/ai-sdk-rsc/use-ui-state) Hook 访问。该 Hook 返回当前 UI 状态以及一个更新 UI 状态的函数，类似于 React 的 `useState`。

```tsx filename='app/page.tsx'
'use client';

import { useUIState } from '@ai-sdk/rsc';

export default function Page() {
  const [messages, setMessages] = useUIState();

  return (
    <ul>
      {messages.map(message => (
        <li key={message.id}>{message.display}</li>
      ))}
    </ul>
  );
}
```

## 在客户端读取 AI 状态

AI 状态可以在客户端组件中使用 RSC API 提供的 [`useAIState`](/docs/reference/ai-sdk-rsc/use-ai-state) Hook 访问。该 Hook 返回当前 AI 状态。

```tsx filename='app/page.tsx'
'use client';

import { useAIState } from '@ai-sdk/rsc';

export default function Page() {
  const [messages, setMessages] = useAIState();

  return (
    <ul>
      {messages.map(message => (
        <li key={message.id}>{message.content}</li>
      ))}
    </ul>
  );
}
```

## 在服务器上读取 AI 状态

AI 状态可以在传递给 `createAI` 上下文的任何 Server Action 中，使用 [`getAIState`](/docs/reference/ai-sdk-rsc/get-ai-state) 函数访问。它以只读值的形式返回当前 AI 状态：

```tsx filename='app/actions.ts'
import { getAIState } from '@ai-sdk/rsc';

export async function sendMessage(message: string) {
  'use server';

  const history = getAIState();

  const response = await generateText({
    model: __MODEL__,
    messages: [...history, { role: 'user', content: message }],
  });

  return response;
}
```

<Note>
  请记住，你只能在已通过 `actions` 键传递给 `createAI` 上下文的 action 中访问状态。
</Note>

## 在服务器上更新 AI 状态

AI 状态也可以在 Server Action 中使用 [`getMutableAIState`](/docs/reference/ai-sdk-rsc/get-mutable-ai-state) 函数进行更新。此函数与 `getAIState` 类似，但它返回的状态带有读取和更新它的方法：

```tsx filename='app/actions.ts'
import { getMutableAIState } from '@ai-sdk/rsc';

export async function sendMessage(message: string) {
  'use server';

  const history = getMutableAIState();

  // Update the AI state with the new user message.
  history.update([...history.get(), { role: 'user', content: message }]);

  const response = await generateText({
    model: __MODEL__,
    messages: history.get(),
  });

  // Update the AI state again with the response from the model.
  history.done([...history.get(), { role: 'assistant', content: response }]);

  return response;
}
```

<Note>
  重要的是，要使用 `.update()` 和 `.done()` 以新响应更新 AI 状态，以保持对话历史同步。
</Note>

## 从客户端调用 Server Actions

要从客户端调用 `sendMessage` action，你可以使用 [`useActions`](/docs/reference/ai-sdk-rsc/use-actions) Hook。该 Hook 返回提供给 `createAI` 的所有可用 Actions：

```tsx filename='app/page.tsx'
'use client';

import { useActions, useUIState } from '@ai-sdk/rsc';
import { AI } from './ai';

export default function Page() {
  const { sendMessage } = useActions<typeof AI>();
  const [messages, setMessages] = useUIState();

  const handleSubmit = async event => {
    event.preventDefault();

    setMessages(currentMessages => [
      ...currentMessages,
      {
        id: Date.now().toString(),
        role: 'user',
        display: event.target.message.value,
      },
    ]);

    const response = await sendMessage(event.target.message.value);

    setMessages(currentMessages => [...currentMessages, response]);
  };

  return (
    <>
      <ul>
        {messages.map(message => (
          <li key={message.id}>{message.display}</li>
        ))}
      </ul>
      <form onSubmit={handleSubmit}>
        <input type="text" name="message" />
        <button type="submit">Send</button>
      </form>
    </>
  );
}
```

当用户提交消息时，会使用消息内容调用 `sendMessage` action。然后，action 的响应会被添加到 UI 状态中，从而更新显示的消息。

<Note>
  重要！调用 Server Action 后不要忘记更新 UI 状态，否则流式传输的组件将不会显示在 UI 中。
</Note>
