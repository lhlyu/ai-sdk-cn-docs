# AI SDK RSC

<Note type="warning">
  AI SDK RSC 目前处于实验阶段。我们建议在生产环境中使用 [AI SDK
  UI](/docs/ai-sdk-ui/overview)。如需从 RSC 迁移到 UI 的指导，请参阅我们的[迁移指南](/docs/ai-sdk-rsc/migrating-to-ui)。
</Note>

<Note>
  `@ai-sdk/rsc` 包与支持 React Server Components 的框架兼容。
</Note>

[React Server Components](https://nextjs.org/docs/app/building-your-application/rendering/server-components) (RSC) 允许你编写可在服务器端渲染并流式传输到客户端的 UI。RSC 支持 [Server Actions](https://nextjs.org/docs/app/building-your-application/data-fetching/server-actions-and-mutations#with-client-components)，这是一种从客户端直接调用服务器端代码的新方式，就像调用任何其他函数一样，并具有端到端的类型安全性。这种结合为构建 AI 应用开辟了新途径，使大语言模型 (LLM) 能够直接从服务器生成并流式传输 UI 到客户端。

## AI SDK RSC 函数

AI SDK RSC 提供了多种函数，旨在帮助你使用 React Server Components 构建 AI 原生应用。这些函数：

1. 提供了构建生成式 UI 应用的抽象。
   - [`streamUI`](/docs/reference/ai-sdk-rsc/stream-ui)：调用模型并允许其使用 React Server Components 进行响应。
   - [`useUIState`](/docs/reference/ai-sdk-rsc/use-ui-state)：返回当前 UI 状态以及更新 UI 状态的函数（类似于 React 的 `useState`）。UI 状态是 AI 状态的视觉表示。
   - [`useAIState`](/docs/reference/ai-sdk-rsc/use-ai-state)：返回当前 AI 状态以及更新 AI 状态的函数（类似于 React 的 `useState`）。AI 状态旨在包含与 AI 模型共享的上下文和信息，例如系统消息、函数响应以及其他相关数据。
   - [`useActions`](/docs/reference/ai-sdk-rsc/use-actions)：提供从客户端访问 Server Actions 的能力。这对于构建需要用户与服务器交互的界面特别有用。
   - [`createAI`](/docs/reference/ai-sdk-rsc/create-ai)：创建一个客户端-服务器上下文提供者，可用于包裹应用树的部分区域，以便轻松管理应用的 UI 和 AI 状态。
2. 简化了在服务器和客户端之间处理可流式传输值的工作。
   - [`createStreamableValue`](/docs/reference/ai-sdk-rsc/create-streamable-value)：创建一个从服务器向客户端发送值的流。该值可以是任何可序列化的数据。
   - [`readStreamableValue`](/docs/reference/ai-sdk-rsc/read-streamable-value)：从客户端读取最初使用 `createStreamableValue` 创建的可流式传输值。
   - [`createStreamableUI`](/docs/reference/ai-sdk-rsc/create-streamable-ui)：创建一个从服务器向客户端发送 UI 的流。
   - [`useStreamableValue`](/docs/reference/ai-sdk-rsc/use-streamable-value)：接受使用 `createStreamableValue` 创建的可流式传输值，并返回当前值、错误和待处理状态。
