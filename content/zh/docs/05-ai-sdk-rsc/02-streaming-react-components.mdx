# 流式传输 React 组件

<Note type="warning">
  AI SDK RSC 目前处于实验阶段。我们建议在生产环境中使用 [AI SDK
  UI](/docs/ai-sdk-ui/overview)。有关从 RSC 迁移到 UI 的指导，请参阅我们的[迁移指南](/docs/ai-sdk-rsc/migrating-to-ui)。
</Note>

RSC API 允许你使用 [`streamUI`](/docs/reference/ai-sdk-rsc/stream-ui) 函数将 React 组件从服务器流式传输到客户端。当你希望超越纯文本，实时将组件流式传输到客户端时，这非常有用。

与 [AI SDK Core](/docs/ai-sdk-core/overview) API（如 [`streamText`](/docs/reference/ai-sdk-core/stream-text)）类似，`streamUI` 提供了一个单一函数来调用模型，并允许其以 React Server Components 的形式响应。
它支持与 AI SDK Core API 相同的模型接口。

### 概念

为了让模型能够以 React 组件响应用户的提示词，你可以利用[工具](/docs/ai-sdk-core/tools-and-tool-calling)。

<Note>
  请记住，工具就像你可以提供给模型的程序，模型可以根据对话的上下文决定何时使用它们。
</Note>

使用 `streamUI` 函数，**你提供的工具需要返回 React 组件**。凭借流式传输组件的能力，模型就像一个动态路由器，能够理解用户的意图并显示相关的 UI。

在高层面上，`streamUI` 的工作方式与其他 AI SDK Core 函数类似：你可以为模型提供提示词或一些对话历史，以及可选的工具。如果模型根据对话上下文决定调用某个工具，它将生成一个工具调用。然后，`streamUI` 函数将运行相应的工具，返回一个 React 组件。如果模型没有相关的工具可用，它将返回文本生成结果，该结果将传递给 `text` 函数，由你处理（渲染并作为 React 组件返回）。

<Note>请记住，`streamUI` 函数必须返回一个 React 组件。</Note>

```tsx
const result = await streamUI({
  model: openai('gpt-4o'),
  prompt: 'Get the weather for San Francisco',
  text: ({ content }) => <div>{content}</div>,
  tools: {},
});
```

此示例使用 OpenAI 的 `gpt-4o` 模型调用 `streamUI` 函数，传递一个提示词，指定模型纯文本响应（`content`）的渲染方式，然后为工具提供一个空对象。尽管此示例没有定义任何工具，但它会将模型的响应作为 `div` 流式传输，而不是纯文本。

### 添加工具

在 `streamUI` 中使用工具与在 `generateText` 和 `streamText` 中使用工具类似。
一个工具是一个对象，包含：

- `description`：一个字符串，告诉模型该工具的功能以及何时使用它
- `inputSchema`：一个 Zod 模式，描述工具运行所需的内容
- `generate`：一个异步函数，如果模型调用该工具，则会运行该函数。它必须返回一个 React 组件

让我们扩展前面的示例来添加一个工具。

```tsx highlight="6-14"
const result = await streamUI({
  model: openai('gpt-4o'),
  prompt: 'Get the weather for San Francisco',
  text: ({ content }) => <div>{content}</div>,
  tools: {
    getWeather: {
      description: 'Get the weather for a location',
      inputSchema: z.object({ location: z.string() }),
      generate: async function* ({ location }) {
        yield <LoadingComponent />;
        const weather = await getWeather(location);
        return <WeatherComponent weather={weather} location={location} />;
      },
    },
  },
});
```

如果用户询问某个位置的天气，此工具将被运行。如果用户未指定位置，模型会在调用工具之前询问。当模型调用该工具时，`generate` 函数将首先返回一个加载组件。该组件将一直显示，直到对 `getWeather` 的等待调用被解析，此时模型会将 `<WeatherComponent />` 流式传输给用户。

<Note>
  注意：此示例使用了[生成器函数](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/function*)
  （`function*`），它允许你暂停执行并返回一个值，然后在下次调用时从暂停处恢复。这对于处理数据流非常有用，因为你可以从异步源（如 API）获取并返回数据，然后在需要时恢复函数以获取下一个数据块。通过一次只生成一个值，生成器函数能够高效处理流式数据，而不会阻塞主线程。
</Note>

## 在 Next.js 中使用 `streamUI`

让我们看看如何在 Next.js 应用程序中使用上面的示例。

要在 Next.js 应用程序中使用 `streamUI`，你需要两样东西：

1. 一个 Server Action（你将在其中调用 `streamUI`）
2. 一个页面来调用 Server Action 并渲染生成的组件

### 步骤 1：创建 Server Action

<Note>
  Server Action 是可以在前端直接调用的服务器端函数。有关更多信息，请参阅[文档](https://nextjs.org/docs/app/building-your-application/data-fetching/server-actions-and-mutations#with-client-components)。
</Note>

在 `app/actions.tsx` 中创建一个 Server Action，并添加以下代码：

```tsx filename="app/actions.tsx"
'use server';

import { streamUI } from '@ai-sdk/rsc';
import { openai } from '@ai-sdk/openai';
import { z } from 'zod';

const LoadingComponent = () => (
  <div className="animate-pulse p-4">getting weather...</div>
);

const getWeather = async (location: string) => {
  await new Promise(resolve => setTimeout(resolve, 2000));
  return '82°F️ ☀️';
};

interface WeatherProps {
  location: string;
  weather: string;
}

const WeatherComponent = (props: WeatherProps) => (
  <div className="border border-neutral-200 p-4 rounded-lg max-w-fit">
    The weather in {props.location} is {props.weather}
  </div>
);

export async function streamComponent() {
  const result = await streamUI({
    model: openai('gpt-4o'),
    prompt: 'Get the weather for San Francisco',
    text: ({ content }) => <div>{content}</div>,
    tools: {
      getWeather: {
        description: 'Get the weather for a location',
        inputSchema: z.object({
          location: z.string(),
        }),
        generate: async function* ({ location }) {
          yield <LoadingComponent />;
          const weather = await getWeather(location);
          return <WeatherComponent weather={weather} location={location} />;
        },
      },
    },
  });

  return result.value;
}
```

`getWeather` 工具应该看起来很熟悉，因为它与上一节中的示例完全相同。为了使此工具正常工作：

1. 首先定义一个 `LoadingComponent`，它渲染一个带有脉冲动画的 `div`，显示一些加载文本。
2. 接下来，定义一个 `getWeather` 函数，该函数将超时 2 秒（模拟从外部获取天气），然后返回某个 `location` 的“天气”。注意：你可以在此处运行任何异步 TypeScript 代码。
3. 最后，定义一个 `WeatherComponent`，它接受 `location` 和 `weather` 作为 props，然后在 `div` 中渲染它们。

你的 Server Action 是一个名为 `streamComponent` 的异步函数，它不接受任何输入，并返回一个 `ReactNode`。在 action 内部，你调用 `streamUI` 函数，指定模型（`gpt-4o`）、提示词、如果模型选择返回文本时应渲染的组件，以及你的 `getWeather` 工具。最后但同样重要的是，你使用 `result.value` 返回模型生成的组件。

要调用此 Server Action 并显示生成的 React 组件，你需要一个页面。

### 步骤 2：创建页面

使用以下代码创建或更新你的根页面（`app/page.tsx`）：

```tsx filename="app/page.tsx"
'use client';

import { useState } from 'react';
import { Button } from '@/components/ui/button';
import { streamComponent } from './actions';

export default function Page() {
  const [component, setComponent] = useState<React.ReactNode>();

  return (
    <div>
      <form
        onSubmit={async e => {
          e.preventDefault();
          setComponent(await streamComponent());
        }}
      >
        <Button>Stream Component</Button>
      </form>
      <div>{component}</div>
    </div>
  );
}
```

此页面首先通过 `"use client";` 指令标记为客户端组件，因为它将使用 Hook 和交互性。在页面上，你渲染一个表单。当该表单提交时，你调用上一步创建的 `streamComponent` action（就像调用任何其他函数一样）。`streamComponent` action 返回一个 `ReactNode`，你可以使用 React 状态（`setComponent`）在页面上渲染它。

## 超越单一提示词

现在，你可以让模型以 React 组件响应用户的提示词。但是，此示例仅限于在 Server Action 中设置的静态提示词。你可以通过将其转换为聊天机器人来使此示例具有交互性。
