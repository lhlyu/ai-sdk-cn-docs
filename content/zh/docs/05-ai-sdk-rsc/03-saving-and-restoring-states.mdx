# 保存与恢复状态

<Note type="warning">
  AI SDK RSC 目前处于实验阶段。生产环境建议使用 [AI SDK
  UI](/docs/ai-sdk-ui/overview)。关于从 RSC 迁移到 UI 的指导，请参阅我们的[迁移指南](/docs/ai-sdk-rsc/migrating-to-ui)。
</Note>

AI SDK RSC 提供了便捷的方法来保存与恢复 AI 和 UI 状态。这对于在每次模型生成后保存应用程序状态，并在用户重新访问生成内容时恢复状态非常有用。

## AI 状态

### 保存 AI 状态

AI 状态可以通过 [`onSetAIState`](/docs/reference/ai-sdk-rsc/create-ai#on-set-ai-state) 回调来保存，该回调在 AI 状态更新时被调用。在以下示例中，当生成标记为完成时，你将聊天历史保存到数据库。

```tsx filename='app/ai.ts'
export const AI = createAI<ServerMessage[], ClientMessage[]>({
  actions: {
    continueConversation,
  },
  onSetAIState: async ({ state, done }) => {
    'use server';

    if (done) {
      saveChatToDB(state);
    }
  },
});
```

### 恢复 AI 状态

AI 状态可以通过传递给由 [`createAI`](/docs/reference/ai-sdk-rsc/create-ai) 函数创建的上下文提供者的 [`initialAIState`](/docs/reference/ai-sdk-rsc/create-ai#initial-ai-state) 属性来恢复。在以下示例中，当组件挂载时，你从数据库恢复聊天历史。

```tsx file='app/layout.tsx'
import { ReactNode } from 'react';
import { AI } from './ai';

export default async function RootLayout({
  children,
}: Readonly<{ children: ReactNode }>) {
  const chat = await loadChatFromDB();

  return (
    <html lang="en">
      <body>
        <AI initialAIState={chat}>{children}</AI>
      </body>
    </html>
  );
}
```

## UI 状态

### 保存 UI 状态

UI 状态无法直接保存，因为其内容尚不可序列化。相反，你可以使用 AI 状态作为代理来存储 UI 状态的详细信息，并在需要时用于恢复 UI 状态。

### 恢复 UI 状态

UI 状态可以通过 AI 状态作为代理来恢复。在以下示例中，当组件挂载时，你从 AI 状态恢复聊天历史。你使用 [`onGetUIState`](/docs/reference/ai-sdk-rsc/create-ai#on-get-ui-state) 回调来监听 SSR 事件并恢复 UI 状态。

```tsx filename='app/ai.ts'
export const AI = createAI<ServerMessage[], ClientMessage[]>({
  actions: {
    continueConversation,
  },
  onGetUIState: async () => {
    'use server';

    const historyFromDB: ServerMessage[] = await loadChatFromDB();
    const historyFromApp: ServerMessage[] = getAIState();

    // 如果数据库中的历史记录与应用程序中的
    // 历史记录不同，则它们不同步，因此返回基于
    // 数据库历史记录的 UIState

    if (historyFromDB.length !== historyFromApp.length) {
      return historyFromDB.map(({ role, content }) => ({
        id: generateId(),
        role,
        display:
          role === 'function' ? (
            <Component {...JSON.parse(content)} />
          ) : (
            content
          ),
      }));
    }
  },
});
```

要了解更多信息，请查看这个[示例](/examples/next-app/state-management/save-and-restore-states)，它演示了如何在 Next.js 应用程序中持久化和恢复状态。
