# 设计多步骤界面

<Note type="warning">
  AI SDK RSC 目前处于实验阶段。我们建议在生产环境中使用 [AI SDK
  UI](/docs/ai-sdk-ui/overview)。如需从 RSC 迁移到 UI 的指导，请参阅我们的[迁移指南](/docs/ai-sdk-rsc/migrating-to-ui)。
</Note>

多步骤界面是指需要按顺序执行多个独立步骤才能完成特定任务的用户界面。

例如，如果你想构建一个能够预订航班的生成式 UI 聊天机器人，它可能包含三个步骤：

- 搜索所有航班
- 选择航班
- 检查可用性

要构建此类应用，你将利用两个概念：**工具组合**和**应用上下文**。

**工具组合**是将多个[工具](/docs/ai-sdk-core/tools-and-tool-calling)组合以创建新工具的过程。这是一个强大的概念，允许你将复杂任务分解为更小、更易管理的步骤。在上述示例中，"搜索所有航班"、"选择航班"和"检查可用性"共同构成了一个完整的"预订航班"工具。

**应用上下文**指应用在任何给定时间点的状态，包括用户输入、语言模型输出以及其他相关信息。在上述示例中，"选择航班"中选定的航班将作为完成"检查可用性"任务所需的上下文。

## 概述

要使用 `@ai-sdk/rsc` 构建多步骤界面，你需要以下内容：

- 一个调用并返回 `streamUI` 函数结果的服务器操作
- 工具（完成整体任务所需的子任务）
- 调用工具时应渲染的 React 组件
- 用于渲染聊天机器人的页面

你将遵循的通用流程是：

- 用户发送消息（使用 `useActions` 调用服务器操作，将消息作为输入传入）
- 消息被追加到 AI 状态，然后与多个工具一起传递给模型
- 模型可以决定调用某个工具，这将渲染 `<SomeTool />` 组件
- 在该组件内，你可以通过使用 `useActions` 调用服务器操作以及 `useUIState` 将模型的响应（`<SomeOtherTool />`）追加到 UI 状态来添加交互性
- 以此类推……

## 实现

逐轮实现是最简单的多步骤界面形式。在这种实现中，用户和模型在对话中轮流进行。每次用户输入后，模型生成响应，对话以这种逐轮方式继续。

在以下示例中，你指定了两个工具（`searchFlights` 和 `lookupFlight`），模型可以使用它们搜索航班并查找特定航班的详细信息。

```tsx filename="app/actions.tsx"
import { streamUI } from '@ai-sdk/rsc';
import { openai } from '@ai-sdk/openai';
import { z } from 'zod';

const searchFlights = async (
  source: string,
  destination: string,
  date: string,
) => {
  return [
    {
      id: '1',
      flightNumber: 'AA123',
    },
    {
      id: '2',
      flightNumber: 'AA456',
    },
  ];
};

const lookupFlight = async (flightNumber: string) => {
  return {
    flightNumber: flightNumber,
    departureTime: '10:00 AM',
    arrivalTime: '12:00 PM',
  };
};

export async function submitUserMessage(input: string) {
  'use server';

  const ui = await streamUI({
    model: openai('gpt-4o'),
    instructions: '你是一个航班预订助手',
    prompt: input,
    text: async ({ content }) => <div>{content}</div>,
    tools: {
      searchFlights: {
        description: '搜索航班',
        inputSchema: z.object({
          source: z.string().describe('航班出发地'),
          destination: z.string().describe('航班目的地'),
          date: z.string().describe('航班日期'),
        }),
        generate: async function* ({ source, destination, date }) {
          yield `正在搜索从 ${source} 到 ${destination} 在 ${date} 的航班……`;
          const results = await searchFlights(source, destination, date);

          return (
            <div>
              {results.map(result => (
                <div key={result.id}>
                  <div>{result.flightNumber}</div>
                </div>
              ))}
            </div>
          );
        },
      },
      lookupFlight: {
        description: '查找航班详情',
        inputSchema: z.object({
          flightNumber: z.string().describe('航班号'),
        }),
        generate: async function* ({ flightNumber }) {
          yield `正在查找航班 ${flightNumber} 的详情……`;
          const details = await lookupFlight(flightNumber);

          return (
            <div>
              <div>航班号：{details.flightNumber}</div>
              <div>起飞时间：{details.departureTime}</div>
              <div>到达时间：{details.arrivalTime}</div>
            </div>
          );
        },
      },
    },
  });

  return ui.value;
}
```

接下来，创建一个将持有 UI 状态和 AI 状态的 AI 上下文。

```ts filename='app/ai.ts'
import { createAI } from '@ai-sdk/rsc';
import { submitUserMessage } from './actions';

export const AI = createAI<any[], React.ReactNode[]>({
  initialUIState: [],
  initialAIState: [],
  actions: {
    submitUserMessage,
  },
});
```

然后，用新创建的上下文包裹你的应用。

```tsx filename='app/layout.tsx'
import { type ReactNode } from 'react';
import { AI } from './ai';

export default function RootLayout({
  children,
}: Readonly<{ children: ReactNode }>) {
  return (
    <AI>
      <html lang="en">
        <body>{children}</body>
      </html>
    </AI>
  );
}
```

要调用你的服务器操作，请用以下内容更新根页面：

```tsx filename="app/page.tsx"
'use client';

import { useState } from 'react';
import { AI } from './ai';
import { useActions, useUIState } from '@ai-sdk/rsc';

export default function Page() {
  const [input, setInput] = useState<string>('');
  const [conversation, setConversation] = useUIState<typeof AI>();
  const { submitUserMessage } = useActions();

  const handleSubmit = async (e: React.FormEvent<HTMLFormElement>) => {
    e.preventDefault();
    setInput('');
    setConversation(currentConversation => [
      ...currentConversation,
      <div>{input}</div>,
    ]);
    const message = await submitUserMessage(input);
    setConversation(currentConversation => [...currentConversation, message]);
  };

  return (
    <div>
      <div>
        {conversation.map((message, i) => (
          <div key={i}>{message}</div>
        ))}
      </div>
      <div>
        <form onSubmit={handleSubmit}>
          <input
            type="text"
            value={input}
            onChange={e => setInput(e.target.value)}
          />
          <button>发送消息</button>
        </form>
      </div>
    </div>
  );
}
```

此页面使用 `useUIState` Hook 获取当前 UI 状态，然后遍历并渲染到 UI 中。要访问服务器操作，你使用 `useActions` Hook，它将返回在 `actions.tsx` 文件中传递给 `createAI` 函数的 `actions` 键的所有操作。最后，你像调用其他 TypeScript 函数一样调用 `submitUserMessage` 函数。该函数返回一个 React 组件（`message`），然后通过 `setConversation` 更新 UI 状态，将其渲染到 UI 中。

在此示例中，要调用下一个工具，用户必须用纯文本响应。**由于你正在流式传输一个 React 组件，你可以添加一个按钮来触发对话的下一步**。

要添加用户交互，你需要将组件转换为客户端组件，并使用 `useAction` Hook 触发对话的下一步。

```tsx filename="components/flights.tsx"
'use client';

import { useActions, useUIState } from '@ai-sdk/rsc';
import { ReactNode } from 'react';

interface FlightsProps {
  flights: { id: string; flightNumber: string }[];
}

export const Flights = ({ flights }: FlightsProps) => {
  const { submitUserMessage } = useActions();
  const [_, setMessages] = useUIState();

  return (
    <div>
      {flights.map(result => (
        <div key={result.id}>
          <div
            onClick={async () => {
              const display = await submitUserMessage(
                `lookupFlight ${result.flightNumber}`,
              );

              setMessages((messages: ReactNode[]) => [...messages, display]);
            }}
          >
            {result.flightNumber}
          </div>
        </div>
      ))}
    </div>
  );
};
```

现在，更新你的 `searchFlights` 工具以渲染新的 `<Flights />` 组件。

```tsx filename="actions.tsx"
...
searchFlights: {
  description: '搜索航班',
  inputSchema: z.object({
    source: z.string().describe('航班出发地'),
    destination: z.string().describe('航班目的地'),
    date: z.string().describe('航班日期'),
  }),
  generate: async function* ({ source, destination, date }) {
    yield `正在搜索从 ${source} 到 ${destination} 在 ${date} 的航班……`;
    const results = await searchFlights(source, destination, date);
    return (<Flights flights={results} />);
  },
}
...
```

在上述示例中，`Flights` 组件用于显示搜索结果。当用户点击航班号时，`lookupFlight` 工具被调用，并将航班号作为参数传入。然后调用 `submitUserMessage` 操作来触发对话的下一步。
