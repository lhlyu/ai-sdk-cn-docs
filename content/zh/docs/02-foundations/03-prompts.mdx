# 提示词

提示词是你提供给[大语言模型（LLM）](/docs/foundations/overview#large-language-models)的指令，用来告诉它该做什么。
这就像你向别人问路一样；你的问题越清晰，得到的指引就越好。

许多 LLM 提供商提供了用于指定提示词的复杂接口。它们涉及不同的角色和消息类型。
虽然这些接口功能强大，但可能难以使用和理解。

为了简化提示词编写，AI SDK 支持文本提示词、消息提示词和系统提示词。

## 文本提示词

文本提示词是字符串。
它们非常适合简单的生成用例，
例如为同一提示词文本的多个变体重复生成内容。

你可以使用 AI SDK 函数（如 [`streamText`](/docs/reference/ai-sdk-core/stream-text) 或 [`generateText`](/docs/reference/ai-sdk-core/generate-text)）提供的 `prompt` 属性来设置文本提示词。
你可以以任何方式组织文本并注入变量，例如使用模板字面量。

```ts highlight="3"
const result = await generateText({
  model: __MODEL__,
  prompt: 'Invent a new holiday and describe its traditions.',
});
```

你也可以使用模板字面量为提示词提供动态数据。

```ts highlight="3-5"
const result = await generateText({
  model: __MODEL__,
  prompt:
    `I am planning a trip to ${destination} for ${lengthOfStay} days. ` +
    `Please suggest the best tourist activities for me to do.`,
});
```

## 系统提示词

系统提示词是提供给模型的初始指令集，用于帮助引导和约束模型的行为与响应。
你可以使用 `instructions` 属性来设置系统提示词。
系统提示词可与 `prompt` 和 `messages` 属性一起使用。
默认情况下，`prompt` 或 `messages` 中的系统消息会被拒绝；请使用 `instructions` 属性来设置系统指令，或者当你需要发送包含系统消息的现有消息历史时，设置 `allowSystemInMessages: true`。

<Note type="warning">
  通过 `allowSystemInMessages` 选择启用可能会带来提示词注入风险，
  用户可以通过注入系统消息来覆盖或设置系统提示词。在大多数情况下，
  只有受信任的服务端代码才应通过 `instructions` 属性设置系统指令。
</Note>

```ts highlight="3-6"
const result = await generateText({
  model: __MODEL__,
  instructions:
    `You help planning travel itineraries. ` +
    `Respond to the users' request with a list ` +
    `of the best stops to make in their destination.`,
  prompt:
    `I am planning a trip to ${destination} for ${lengthOfStay} days. ` +
    `Please suggest the best tourist activities for me to do.`,
});
```

## 消息提示词

消息提示词是用户、助手和工具消息组成的数组。
它们非常适合聊天界面以及更复杂的多模态提示词。
你可以使用 `messages` 属性来设置消息提示词。

每条消息都有一个 `role` 和一个 `content` 属性。content 可以是文本（用于用户和助手消息），也可以是该消息类型相关部分（数据）组成的数组。

```ts highlight="3-7"
const result = await generateText({
  model: __MODEL__,
  messages: [
    { role: 'user', content: 'Hi!' },
    { role: 'assistant', content: 'Hello, how can I help?' },
    { role: 'user', content: 'Where can I buy the best Currywurst in Berlin?' },
  ],
});
```

除了在 `content` 属性中发送文本之外，你还可以发送一个包含文本和其他内容部分混合的数组。

<Note type="warning">
  并非所有语言模型都支持所有消息和内容类型。例如，
  某些模型可能无法处理多模态输入或工具消息。
  [了解特定模型的能力](./providers-and-models#model-capabilities)。
</Note>

### 提供商选项

你可以传递额外的提供商特定元数据，以在 3 个层级启用提供商特定功能。

#### 函数调用层级

[`streamText`](/docs/reference/ai-sdk-core/stream-text#provider-options) 或 [`generateText`](/docs/reference/ai-sdk-core/generate-text#provider-options) 等函数接受 `providerOptions` 属性。

当你不需要对提供商选项的应用位置进行细粒度控制时，应在函数调用层级添加提供商选项。

```ts
const { text } = await generateText({
  model: azure('your-deployment-name'),
  providerOptions: {
    openai: {
      reasoningEffort: 'low',
    },
  },
});
```

#### 消息层级

要对提供商选项在消息层级的应用进行细粒度控制，你可以将 `providerOptions` 传递给消息对象：

```ts
const result = await generateText({
  model: __MODEL__,
  instructions: {
    role: 'system',
    content: 'Cached system message',
    providerOptions: {
      // Sets a cache control breakpoint on the system message
      anthropic: { cacheControl: { type: 'ephemeral' } },
    },
  },
  prompt: 'Invent a new holiday and describe its traditions.',
});
```

#### 消息部分层级

某些提供商特定选项需要在消息部分层级进行配置：

```ts
import { ModelMessage } from 'ai';

const messages: ModelMessage[] = [
  {
    role: 'user',
    content: [
      {
        type: 'text',
        text: 'Describe the image in detail.',
        providerOptions: {
          openai: { imageDetail: 'low' },
        },
      },
      {
        type: 'file',
        mediaType: 'image',
        data: 'https://github.com/vercel/ai/blob/main/examples/ai-functions/data/comic-cat.png?raw=true',
        // Sets image detail configuration for image part:
        providerOptions: {
          openai: { imageDetail: 'low' },
        },
      },
    ],
  },
];
```

<Note type="warning">
  [`useChat`](/docs/reference/ai-sdk-ui/use-chat) 等 AI SDK UI Hook 会返回
  `UIMessage` 对象数组，它们不支持提供商选项。我们
  建议使用
  [`convertToModelMessages`](/docs/reference/ai-sdk-ui/convert-to-model-messages)
  函数将 `UIMessage` 对象转换为
  [`ModelMessage`](/docs/reference/ai-sdk-core/model-message) 对象，然后再
  应用或附加带有 `providerOptions` 的消息或消息部分。
</Note>

### 用户消息

#### 文本部分

文本内容是最常见的内容类型。它是传递给模型的字符串。

如果你只需要在消息中发送文本内容，`content` 属性可以是一个字符串，
但你也可以使用它来发送多个内容部分。

```ts highlight="7-10"
const result = await generateText({
  model: __MODEL__,
  messages: [
    {
      role: 'user',
      content: [
        {
          type: 'text',
          text: 'Where can I buy the best Currywurst in Berlin?',
        },
      ],
    },
  ],
});
```

#### 图像部分

用户消息可以包含图像部分。图像可以是以下之一：

- base64 编码图像：
  - 包含 base-64 编码内容的 `string`
  - data URL `string`，例如 `data:image/png;base64,...`
- 二进制图像：
  - `ArrayBuffer`
  - `Uint8Array`
  - `Buffer`
- URL：
  - http(s) URL `string`，例如 `https://example.com/image.png`
  - `URL` 对象，例如 `new URL('https://example.com/image.png')`

##### 示例：二进制图像（Buffer）

```ts highlight="8-11"
const result = await generateText({
  model,
  messages: [
    {
      role: 'user',
      content: [
        { type: 'text', text: 'Describe the image in detail.' },
        {
          type: 'file',
          mediaType: 'image',
          data: fs.readFileSync('./data/comic-cat.png'),
        },
      ],
    },
  ],
});
```

##### 示例：Base-64 编码图像（字符串）

```ts highlight="8-11"
const result = await generateText({
  model: __MODEL__,
  messages: [
    {
      role: 'user',
      content: [
        { type: 'text', text: 'Describe the image in detail.' },
        {
          type: 'file',
          mediaType: 'image',
          data: fs.readFileSync('./data/comic-cat.png').toString('base64'),
        },
      ],
    },
  ],
});
```

##### 示例：图像 URL（字符串）

```ts highlight="8-12"
const result = await generateText({
  model: __MODEL__,
  messages: [
    {
      role: 'user',
      content: [
        { type: 'text', text: 'Describe the image in detail.' },
        {
          type: 'file',
          mediaType: 'image',
          data: 'https://github.com/vercel/ai/blob/main/examples/ai-functions/data/comic-cat.png?raw=true',
        },
      ],
    },
  ],
});
```

#### 文件部分

<Note type="warning">
  目前只有少数提供商和模型支持文件部分：[Google
  Generative AI](/providers/ai-sdk-providers/google)、[Google Vertex
  AI](/providers/ai-sdk-providers/google-vertex)、
  [OpenAI](/providers/ai-sdk-providers/openai)（用于 `wav` 和 `mp3` 音频，配合
  `gpt-4o-audio-preview`）、[Anthropic](/providers/ai-sdk-providers/anthropic)、
  [OpenAI](/providers/ai-sdk-providers/openai)（用于 `pdf`）。
</Note>

用户消息可以包含文件部分。文件可以是以下之一：

- base64 编码文件：
  - 包含 base-64 编码内容的 `string`
  - data URL `string`，例如 `data:image/png;base64,...`
- 二进制数据：
  - `ArrayBuffer`
  - `Uint8Array`
  - `Buffer`
- URL：
  - http(s) URL `string`，例如 `https://example.com/some.pdf`
  - `URL` 对象，例如 `new URL('https://example.com/some.pdf')`

你需要指定所发送文件的 MIME 类型。

##### 示例：来自 Buffer 的 PDF 文件

```ts highlight="12-15"
import { google } from '@ai-sdk/google';
import { generateText } from 'ai';

const result = await generateText({
  model: google('gemini-3.8-flash'),
  messages: [
    {
      role: 'user',
      content: [
        { type: 'text', text: 'What is the file about?' },
        {
          type: 'file',
          mediaType: 'application/pdf',
          data: fs.readFileSync('./data/example.pdf'),
          filename: 'example.pdf', // optional, not used by all providers
        },
      ],
    },
  ],
});
```

##### 示例：来自 Buffer 的 mp3 音频文件

```ts highlight="12-14"
import { openai } from '@ai-sdk/openai';
import { generateText } from 'ai';

const result = await generateText({
  model: openai('gpt-4o-audio-preview'),
  messages: [
    {
      role: 'user',
      content: [
        { type: 'text', text: 'What is the audio saying?' },
        {
          type: 'file',
          mediaType: 'audio/mpeg',
          data: fs.readFileSync('./data/galileo.mp3'),
        },
      ],
    },
  ],
});
```

#### 自定义下载函数（实验性）

你可以使用自定义下载函数来实现限流、重试、身份验证、缓存等功能。

当模型不支持文件时，默认下载实现会自动并行下载文件。

自定义下载函数可以通过 `experimental_download` 属性传入：

```ts
const result = await generateText({
  model: __MODEL__,
  experimental_download: async (
    requestedDownloads: Array<{
      url: URL;
      isUrlSupportedByModel: boolean;
    }>,
  ): PromiseLike<
    Array<{
      data: Uint8Array;
      mediaType: string | undefined;
    } | null>
  > => {
    // ... download the files and return an array with similar order
  },
  messages: [
    {
      role: 'user',
      content: [
        {
          type: 'file',
          data: new URL('https://api.company.com/private/document.pdf'),
          mediaType: 'application/pdf',
        },
      ],
    },
  ],
});
```

<Note>
  `experimental_download` 选项是实验性的，可能会在未来版本中发生变化。
</Note>

### 助手消息

助手消息是角色为 `assistant` 的消息。
它们通常是助手之前的响应，
可以包含文本、推理和工具调用部分。

#### 示例：包含文本内容的助手消息

```ts highlight="5"
const result = await generateText({
  model: __MODEL__,
  messages: [
    { role: 'user', content: 'Hi!' },
    { role: 'assistant', content: 'Hello, how can I help?' },
  ],
});
```

#### 示例：包含数组形式文本内容的助手消息

```ts highlight="7"
const result = await generateText({
  model: __MODEL__,
  messages: [
    { role: 'user', content: 'Hi!' },
    {
      role: 'assistant',
      content: [{ type: 'text', text: 'Hello, how can I help?' }],
    },
  ],
});
```

#### 示例：包含工具调用内容的助手消息

```ts highlight="7-14"
const result = await generateText({
  model: __MODEL__,
  messages: [
    { role: 'user', content: 'How many calories are in this block of cheese?' },
    {
      role: 'assistant',
      content: [
        {
          type: 'tool-call',
          toolCallId: '12345',
          toolName: 'get-nutrition-data',
          input: { cheese: 'Roquefort' },
        },
      ],
    },
  ],
});
```

#### 示例：包含文件内容的助手消息

<Note>
  此内容部分用于模型生成的文件。只有少数模型支持
  此功能，且仅限它们能够生成的文件类型。
</Note>

```ts highlight="9-11"
const result = await generateText({
  model: __MODEL__,
  messages: [
    { role: 'user', content: 'Generate an image of a roquefort cheese!' },
    {
      role: 'assistant',
      content: [
        {
          type: 'file',
          mediaType: 'image/png',
          data: fs.readFileSync('./data/roquefort.jpg'),
        },
      ],
    },
  ],
});
```

### 工具消息

<Note>
  [工具](/docs/foundations/tools)（也称为函数调用）是你可以提供给 LLM
  以扩展其内置功能的程序。这可以是任何内容，从调用外部 API 到调用
  UI 内的函数。在[下一节](/docs/foundations/tools)中了解更多关于工具的信息。
</Note>

对于支持[工具](/docs/foundations/tools)调用的模型，助手消息可以包含工具调用部分，工具消息可以包含工具输出部分。
单条助手消息可以调用多个工具，单条工具消息可以包含多个工具结果。

```ts highlight="14-42"
const result = await generateText({
  model: __MODEL__,
  messages: [
    {
      role: 'user',
      content: [
        {
          type: 'text',
          text: 'How many calories are in this block of cheese?',
        },
        {
          type: 'file',
          mediaType: 'image',
          data: fs.readFileSync('./data/roquefort.jpg'),
        },
      ],
    },
    {
      role: 'assistant',
      content: [
        {
          type: 'tool-call',
          toolCallId: '12345',
          toolName: 'get-nutrition-data',
          input: { cheese: 'Roquefort' },
        },
        // there could be more tool calls here (parallel calling)
      ],
    },
    {
      role: 'tool',
      content: [
        {
          type: 'tool-result',
          toolCallId: '12345', // needs to match the tool call id
          toolName: 'get-nutrition-data',
          output: {
            type: 'json',
            value: {
              name: 'Cheese, roquefort',
              calories: 369,
              fat: 31,
              protein: 22,
            },
          },
        },
        // there could be more tool results here (parallel calling)
      ],
    },
  ],
});
```

#### 多模态工具结果

工具结果可以是多部分和多模态的，例如文本和图像。
你可以使用 `output: { type: 'content', value: [...] }` 来指定多部分工具结果。

```ts highlight="14-27"
const result = await generateText({
  model: __MODEL__,
  messages: [
    // ...
    {
      role: 'tool',
      content: [
        {
          type: 'tool-result',
          toolCallId: '12345', // needs to match the tool call id
          toolName: 'get-nutrition-data',
          // for models that do not support multi-part tool results,
          // you can include a regular output part:
          output: {
            type: 'json',
            value: {
              name: 'Cheese, roquefort',
              calories: 369,
              fat: 31,
              protein: 22,
            },
          },
        },
        {
          type: 'tool-result',
          toolCallId: '12345', // needs to match the tool call id
          toolName: 'get-nutrition-data',
          // for models that support multi-part tool results,
          // you can include a multi-part content part:
          output: {
            type: 'content',
            value: [
              {
                type: 'text',
                text: 'Here is the nutrition data for the cheese:',
              },
              {
                type: 'file-data',
                data: fs
                  .readFileSync('./data/roquefort-nutrition-data.png')
                  .toString('base64'),
                mediaType: 'image/png',
              },
            ],
          },
        },
      ],
    },
  ],
});
```

### 系统消息

系统消息是在用户消息之前发送给模型的消息，用于引导助手的行为。
在 `messages` 中发送系统消息需要 `allowSystemInMessages: true`。
你也可以改用 `instructions` 属性。

```ts highlight="3,5"
const result = await generateText({
  model: __MODEL__,
  allowSystemInMessages: true,
  messages: [
    { role: 'system', content: 'You help planning travel itineraries.' },
    {
      role: 'user',
      content:
        'I am planning a trip to Berlin for 3 days. Please suggest the best tourist activities for me to do.',
    },
  ],
});
```
