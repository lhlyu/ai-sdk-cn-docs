# 概述

AI SDK 标准化了跨[支持的提供商](/docs/foundations/providers-and-models)集成人工智能（AI）模型的方式。这使得开发者能够专注于构建出色的 AI 应用，而无需在技术细节上浪费时间。

要有效利用 AI SDK，熟悉以下概念会有所帮助：

## 生成式人工智能

**生成式人工智能**指的是基于统计可能性预测并生成各种类型输出（如文本、图像或音频）的模型，这些模型从训练数据中学习到的模式中提取信息。例如：

- 给定一张照片，生成式模型可以生成描述文字。
- 给定一个音频文件，生成式模型可以生成转录文本。
- 给定一段文字描述，生成式模型可以生成图像。

## 大型语言模型

**大型语言模型（LLM）**是生成式模型的一个子集，主要专注于**文本**。LLM 以单词序列作为输入，旨在预测最可能出现的后续序列。它会为可能的后续序列分配概率，然后选择其中一个。模型会持续生成序列，直到满足指定的停止条件。

LLM 通过在海量书面文本上进行训练来学习，这意味着它们在某些用例上会比在其他用例上表现更好。例如，在 GitHub 数据上训练的模型会特别擅长理解源代码中序列的概率。

然而，理解 LLM 的局限性至关重要。当被问及鲜为人知或不存在的信息（如个人亲属的生日）时，LLM 可能会“幻觉”或编造信息。因此，考虑所需信息在模型中的代表性至关重要。

## 嵌入模型

**嵌入模型**用于将复杂数据（如单词或图像）转换为密集向量（数字列表）表示，称为嵌入。与生成式模型不同，嵌入模型不会生成新的文本或数据。相反，它们提供实体之间语义和句法关系的表示，这些表示可用作其他模型或其他自然语言处理任务的输入。
