为了有效利用 AI SDK，熟悉以下概念会有所帮助：

## 生成式人工智能

**生成式人工智能**是指基于统计上最可能的结果，从训练数据中学到的模式中提取信息，来预测并生成各种类型输出（如文本、图像或音频）的模型。例如：

- 给定一张照片，生成式模型可以生成一段说明文字。
- 给定一个音频文件，生成式模型可以生成一份转录文本。
- 给定一段文字描述，生成式模型可以生成一张图像。

## 大语言模型

**大语言模型（LLM）**是生成式模型的一个子集，主要专注于**文本**。LLM 接收一个词序列作为输入，旨在预测最可能跟随其后的序列。它为潜在的后续序列分配概率，然后选择其中一个。模型会持续生成序列，直到满足指定的停止条件。

LLM 通过在海量书面文本集合上进行训练来学习，这意味着它们对某些用例的适用性会优于其他用例。例如，在 GitHub 数据上训练的模型会特别擅长理解源代码中序列的概率。

然而，理解 LLM 的局限性至关重要。当被问及较少见或不存在的信息时，比如某位个人亲属的生日，LLM 可能会“幻觉”或编造信息。务必考虑你所需的信息在模型中的代表性如何。

## 嵌入模型

**嵌入模型**用于将复杂数据（如词语或图像）转换为稠密向量（一组数字）表示，称为嵌入。与生成式模型不同，嵌入模型不会生成新的文本或数据。相反，它们提供实体之间语义和句法关系的表示，这些表示可作为其他模型或其他自然语言处理任务的输入。
