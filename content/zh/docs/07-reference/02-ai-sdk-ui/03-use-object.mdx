# `useObject()`

<Note>`useObject` 仅在 React、Svelte 和 Vue 中可用。</Note>

允许你消费表示 JSON 对象的文本流，并根据模式将其解析为完整的对象。
你可以将其与后端的 [`streamText`](/docs/reference/ai-sdk-core/stream-text) 和 [`Output.object()`](/docs/reference/ai-sdk-core/output#output-object) 结合使用。

```tsx
'use client';

import { useObject } from '@ai-sdk/react';

export default function Page() {
  const { object, submit } = useObject({
    api: '/api/use-object',
    schema: z.object({ content: z.string() }),
  });

  return (
    <div>
      <button onClick={() => submit('example input')}>生成</button>
      {object?.content && <p>{object.content}</p>}
    </div>
  );
}
```
