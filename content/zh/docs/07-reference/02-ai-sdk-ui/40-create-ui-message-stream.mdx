# `createUIMessageStream`

`createUIMessageStream` 函数允许你创建一个用于 UI 消息的可读流，并具备消息合并、错误处理和完成回调等高级功能。

## 导入

<Snippet text={`import { createUIMessageStream } from "ai"`} prompt={false} />

## 示例

```tsx
const existingMessages: UIMessage[] = [
  /* ... */
];

const stream = createUIMessageStream({
  async execute({ writer }) {
    // 开始一条文本消息
    // 注意：text-start、text-delta 和 text-end 步骤的 id 必须一致
    // 这允许系统正确识别它们属于同一个文本块
    writer.write({
      type: 'text-start',
      id: 'example-text',
    });

    // 写入一条消息块
    writer.write({
      type: 'text-delta',
      id: 'example-text',
      delta: 'Hello',
    });

    // 结束文本消息
    writer.write({
      type: 'text-end',
      id: 'example-text',
    });

    // 合并来自 streamText 的另一个流
    const result = streamText({
      model: __MODEL__,
      prompt: '写一首关于 AI 的俳句',
    });

    writer.merge(toUIMessageStream({ stream: result.stream }));
  },
  onError: error => `自定义错误: ${error.message}`,
  originalMessages: existingMessages,
  onEnd: ({ messages, isContinuation, responseMessage }) => {
    console.log('流结束，消息为：', messages);
  },
});
```

### 返回值

`ReadableStream<UIMessageChunk>`

一个发出 UI 消息块的可读流。该流会自动处理错误传播、多个流的合并以及所有操作完成后的正确清理。
