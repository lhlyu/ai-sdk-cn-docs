# `DirectChatTransport`

一种传输方式，直接与进程内的[智能体](/docs/reference/ai-sdk-core/agent)通信，无需经过 HTTP。适用于以下场景：

- 服务端渲染场景
- 无需网络的测试
- 单进程应用

与通过 HTTP 请求发送到 API 端点的 `DefaultChatTransport` 不同，`DirectChatTransport` 直接调用智能体的 `stream()` 方法，并将结果转换为 UI 消息流。

```tsx
import { useChat } from '@ai-sdk/react';
import { DirectChatTransport, ToolLoopAgent } from 'ai';
__PROVIDER_IMPORT__;

const agent = new ToolLoopAgent({
  model: __MODEL__,
  instructions: '你是一个乐于助人的助手。',
});

export default function Chat() {
  const { messages, sendMessage, status } = useChat({
    transport: new DirectChatTransport({ agent }),
  });

  // ... 渲染聊天 UI
}
```

## 方法

### `sendMessages()`

向智能体发送消息并返回流式响应。此方法验证并将 UI 消息转换为模型消息，调用智能体的 `stream()` 方法，并将结果作为 UI 消息流返回。

```ts
const stream = await transport.sendMessages({
  chatId: 'chat-123',
  trigger: 'submit-message',
  messages: [...],
  abortSignal: controller.signal,
});
```

#### 返回值

返回一个 `Promise<ReadableStream<UIMessageChunk>>` - 一个 UI 消息块流，可由聊天 UI 处理。

### `reconnectToStream()`

直接传输不支持重新连接，因为没有持久的服务端流可以重新连接。

#### 返回值

始终返回 `Promise<null>`。

## 示例

### 基本用法

```tsx
import { useChat } from '@ai-sdk/react';
import { DirectChatTransport, ToolLoopAgent } from 'ai';
import { openai } from '@ai-sdk/openai';

const agent = new ToolLoopAgent({
  model: openai('gpt-4o'),
  instructions: '你是一个乐于助人的助手。',
});

export default function Chat() {
  const { messages, sendMessage, status } = useChat({
    transport: new DirectChatTransport({ agent }),
  });

  return (
    <div>
      {messages.map(message => (
        <div key={message.id}>
          {message.role === 'user' ? '用户: ' : 'AI: '}
          {message.parts.map((part, index) =>
            part.type === 'text' ? <span key={index}>{part.text}</span> : null,
          )}
        </div>
      ))}
      <button onClick={() => sendMessage({ text: '你好！' })}>发送</button>
    </div>
  );
}
```

### 使用智能体工具

```tsx
import { useChat } from '@ai-sdk/react';
import { DirectChatTransport, ToolLoopAgent, tool } from 'ai';
import { openai } from '@ai-sdk/openai';
import { z } from 'zod';

const weatherTool = tool({
  description: '获取当前天气',
  parameters: z.object({
    location: z.string().describe('城市和州'),
  }),
  execute: async ({ location }) => {
    return `${location} 的天气晴朗，72°F。`;
  },
});

const agent = new ToolLoopAgent({
  model: openai('gpt-4o'),
  instructions: '你是一个可以访问天气数据的乐于助人的助手。',
  tools: { weather: weatherTool },
});

export default function Chat() {
  const { messages, sendMessage } = useChat({
    transport: new DirectChatTransport({ agent }),
  });

  // ... 渲染带有工具结果的聊天 UI
}
```

### 使用自定义智能体选项

```tsx
import { useChat } from '@ai-sdk/react';
import { DirectChatTransport, ToolLoopAgent } from 'ai';
import { openai } from '@ai-sdk/openai';

const agent = new ToolLoopAgent<{ userId: string }>({
  model: openai('gpt-4o'),
  prepareCall: ({ options, ...rest }) => ({
    ...rest,
    providerOptions: {
      openai: { user: options.userId },
    },
  }),
});

export default function Chat({ userId }: { userId: string }) {
  const { messages, sendMessage } = useChat({
    transport: new DirectChatTransport({
      agent,
      options: { userId },
    }),
  });

  // ... 渲染聊天 UI
}
```

### 使用推理

```tsx
import { useChat } from '@ai-sdk/react';
import { DirectChatTransport, ToolLoopAgent } from 'ai';
import { openai } from '@ai-sdk/openai';

const agent = new ToolLoopAgent({
  model: openai('o1-preview'),
});

export default function Chat() {
  const { messages, sendMessage } = useChat({
    transport: new DirectChatTransport({
      agent,
      sendReasoning: true,
    }),
  });

  return (
    <div>
      {messages.map(message => (
        <div key={message.id}>
          {message.parts.map((part, index) => {
            if (part.type === 'text') {
              return <p key={index}>{part.text}</p>;
            }
            if (part.type === 'reasoning') {
              return (
                <pre key={index} style={{ opacity: 0.6 }}>
                  {part.text}
                </pre>
              );
            }
            return null;
          })}
        </div>
      ))}
    </div>
  );
}
```
