# `pipeUIMessageStreamToResponse`

`pipeUIMessageStreamToResponse` 函数将流式数据管道传输到 Node.js ServerResponse 对象（参见[流式数据](/docs/ai-sdk-ui/streaming-data)）。

## 导入

<Snippet
  text={`import { pipeUIMessageStreamToResponse } from "ai"`}
  prompt={false}
/>

## 示例

```tsx
await pipeUIMessageStreamToResponse({
  response: serverResponse,
  status: 200,
  statusText: 'OK',
  headers: {
    'Custom-Header': 'value',
  },
  stream: myUIMessageStream,
  consumeSseStream: ({ stream }) => {
    // 可选：独立消费 SSE 流
    console.log('正在消费 SSE 流:', stream);
  },
});
```

### 返回值

一个 `Promise<void>`，当流已写入响应时解析，当读取或写入流失败时拒绝。
