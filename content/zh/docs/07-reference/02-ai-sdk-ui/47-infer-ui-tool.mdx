# InferUITool

推断工具（tool）的输入和输出类型。

此类型辅助工具适用于处理单个工具，以确保在 `UIMessage` 中工具输入和输出的类型安全。

## 导入

```tsx
import { InferUITool } from 'ai';
```

## API 签名

### 类型参数

<PropertiesTable
  content={[
    {
      name: 'TOOL',
      type: 'Tool',
      description: '要推断类型的工具。',
    },
  ]}
/>

### 返回值

一个包含工具推断出的输入和输出类型的类型。

结果类型的形状如下：

```typescript
{
  input: InferToolInput<TOOL>;
  output: InferToolOutput<TOOL>;
}
```

## 示例

### 基本用法

```tsx
import { InferUITool } from 'ai';
import { z } from 'zod';

const weatherTool = {
  description: '获取当前天气',
  inputSchema: z.object({
    location: z.string().describe('城市和州'),
  }),
  execute: async ({ location }) => {
    return `{location} 的天气是晴天。`;
  },
};

// 从工具推断类型
type WeatherUITool = InferUITool<typeof weatherTool>;
// 这会创建一个包含以下内容的类型：
// {
//   input: { location: string };
//   output: string;
// }
```
