# readUIMessageStream

将 `UIMessageChunk` 流转换为 `UIMessage` 的 `AsyncIterableStream`。

UI 消息流在聊天场景之外也很有用，例如终端 UI、客户端自定义流消费或 RSC（React 服务器组件）。

## 导入

```tsx
import { readUIMessageStream } from 'ai';
```

### 返回值

`UIMessage` 的 `AsyncIterableStream`。每个流部分代表同一消息在完成过程中的不同状态。

有关全面的示例和使用场景，请参阅[读取 UI 消息流](/docs/ai-sdk-ui/reading-ui-message-streams)。
