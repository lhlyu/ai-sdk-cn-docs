# `experimental_useRealtime()`

<Note type="warning">
  `experimental_useRealtime` 是一个实验性功能。
</Note>

创建一个浏览器端实时会话，用于与实时提供商模型进行双向音频和文本对话。

该 Hook 使用来自设置端点的短期令牌连接到实时 WebSocket，以 `UIMessage[]` 形式返回消息，并提供音频捕获、播放、文本输入和工具输出的控制。

```tsx
import { openai } from '@ai-sdk/openai';
import { experimental_useRealtime } from '@ai-sdk/react';

const realtime = experimental_useRealtime({
  model: openai.experimental_realtime('gpt-realtime'),
  api: {
    token: '/api/realtime/setup',
  },
});
```

对于 AI Gateway，将 `gateway.experimental_realtime(...)` 作为模型传入，并将 `api.token` 指向一个调用 `gateway.experimental_realtime.getToken()` 的服务端设置端点。

## 工具调用

实时工具执行由客户端驱动。使用 `onToolCall` 处理工具调用并返回工具输出：

```tsx
const realtime = experimental_useRealtime({
  model: openai.experimental_realtime('gpt-realtime'),
  api: {
    token: '/api/realtime/setup',
  },
  onToolCall: async ({ toolCall }) => {
    if (toolCall.toolName === 'getWeather') {
      const response = await fetch('/api/weather', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify(toolCall.args),
      });

      return response.json();
    }
  },
});
```

对于需要用户交互的工具，从 `onToolCall` 返回 `undefined`，并在稍后调用 `addToolOutput`。

有关包含服务端应用特定工具端点的完整示例，请参阅 [Realtime](/docs/ai-sdk-core/realtime#tool-calling)。
