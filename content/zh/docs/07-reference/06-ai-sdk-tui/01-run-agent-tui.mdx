# `runAgentTUI()`

在交互式终端 UI 中运行本地智能体或聊天传输。该终端 UI 读取用户提示词、流式传输助手响应、渲染 markdown、显示工具和推理部分，并处理手动工具审批。

`runAgentTUI` 会一直运行，直到用户通过 `Esc` 或 `Ctrl+C` 退出。

```ts
import { openai } from '@ai-sdk/openai';
import { runAgentTUI } from '@ai-sdk/tui';
import { ToolLoopAgent } from 'ai';

const agent = new ToolLoopAgent({
  model: openai('gpt-6-astra'),
  instructions: 'You are a helpful terminal assistant.',
});

await runAgentTUI({
  title: 'Assistant',
  agent,
});
```

## Types

### `AgentTUIAgent`

与终端 UI 兼容的智能体：

```ts
type AgentTUIAgent = Agent<undefined, any, any, never>;
```

这意味着该智能体没有每次调用的选项，也没有结构化输出。

### `TerminalPartDisplayMode`

控制终端各部分的显示方式：

```ts
type TerminalPartDisplayMode =
  | 'full'
  | 'collapsed'
  | 'auto-collapsed'
  | 'hidden';
```

- `"full"`：显示部分标题和完整内容。
- `"collapsed"`：仅显示部分标题。
- `"auto-collapsed"`：最新部分保持展开，直到出现另一个可见部分，然后将其折叠。
- `"hidden"`：完全省略该部分。

### `ResponseStatisticsMode`

控制显示哪项响应统计信息：

```ts
type ResponseStatisticsMode = 'outputTokenCount' | 'outputTokensPerSecond';
```

- `"outputTokenCount"`：显示响应中的输出 token 数量。
- `"outputTokensPerSecond"`：显示响应的输出 token 吞吐量。

## Example with Tool Display Options

```ts
await runAgentTUI({
  title: 'Assistant',
  agent,
  tools: 'auto-collapsed',
  reasoning: 'collapsed',
  responseStatistics: 'outputTokenCount',
  contextSize: 200_000,
});
```

## Example with a Chat Transport

```ts
import { DefaultChatTransport } from 'ai';

await runAgentTUI({
  title: 'Remote Assistant',
  transport: new DefaultChatTransport({
    api: 'https://example.com/api/chat',
  }),
});
```

## Example with Sandbox

```ts
import { createJustBashSandbox } from '@ai-sdk/sandbox-just-bash';

const sandboxSession = await createJustBashSandbox({
  cwd: '/home/user',
}).createSession();

await runAgentTUI({
  title: 'Sandbox Assistant',
  agent,
  sandbox: sandboxSession.restricted(),
});
```

沙箱会在每次 `agent.stream()` 调用时作为 `experimental_sandbox` 转发，使其可用于工具描述函数和工具 `execute` 函数。当模型需要了解沙箱特定细节（例如工作目录或暴露的端口）时，请在智能体指令中包含沙箱描述。

## Compatibility

对于可以直接从自由形式的用户输入运行的智能体，请使用 `agent` 选项。使用 `transport` 选项与远程智能体通信。当你需要固定提示词、每次调用的选项、结构化输出、自定义结果检查或自定义流处理时，请直接使用 `agent.generate()` 或 `agent.stream()`。
