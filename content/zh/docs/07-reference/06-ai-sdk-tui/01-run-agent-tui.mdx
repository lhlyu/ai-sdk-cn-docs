# `runAgentTUI()`

在交互式终端 UI 中运行 `ToolLoopAgent`。该终端 UI 读取用户提示词，流式传输智能体响应，渲染 Markdown，显示工具和推理部分，并处理手动工具审批。

`runAgentTUI` 会持续运行，直到用户按下 `Esc` 或 `Ctrl+C` 退出。

```ts
import { openai } from '@ai-sdk/openai';
import { runAgentTUI } from '@ai-sdk/tui';
import { ToolLoopAgent } from 'ai';

const agent = new ToolLoopAgent({
  model: openai('gpt-5'),
  instructions: '你是一个有用的终端助手。',
});

await runAgentTUI({
  title: '助手',
  agent,
});
```

## 类型

### `AgentTUIAgent`

与终端 UI 兼容的智能体：

```ts
type AgentTUIAgent = Agent<undefined, any, any, never>;
```

这意味着该智能体没有每次调用的选项，也没有结构化输出。

### `TerminalPartDisplayMode`

控制终端部分的显示方式：

```ts
type TerminalPartDisplayMode =
  | 'full'
  | 'collapsed'
  | 'auto-collapsed'
  | 'hidden';
```

- `"full"`：显示部分标题和完整内容。
- `"collapsed"`：仅显示部分标题。
- `"auto-collapsed"`：显示最新的部分为展开状态，直到出现另一个可见部分，然后将其折叠。
- `"hidden"`：完全省略该部分。

### `ResponseStatisticsMode`

控制显示的响应统计信息：

```ts
type ResponseStatisticsMode = 'outputTokenCount' | 'outputTokensPerSecond';
```

- `"outputTokenCount"`：显示响应中的输出 token 数量。
- `"outputTokensPerSecond"`：显示响应的输出 token 吞吐量。

## 带工具显示选项的示例

```ts
await runAgentTUI({
  title: '助手',
  agent,
  tools: 'auto-collapsed',
  reasoning: 'collapsed',
  responseStatistics: 'outputTokenCount',
  contextSize: 200_000,
});
```

## 带沙箱的示例

```ts
import { createJustBashSandbox } from '@ai-sdk/sandbox-just-bash';

const sandboxSession = await createJustBashSandbox({
  cwd: '/home/user',
}).createSession();

await runAgentTUI({
  title: '沙箱助手',
  agent,
  sandbox: sandboxSession.restricted(),
});
```

沙箱会作为 `experimental_sandbox` 转发到每次 `agent.stream()` 调用，使其可用于工具描述函数和工具 `execute` 函数。当模型需要了解沙箱特定细节（如工作目录或暴露的端口）时，请在智能体指令中包含沙箱描述。

## 兼容性

对于可以直接从自由格式用户输入运行的智能体，使用 `runAgentTUI`。当需要固定提示词、每次调用的选项、结构化输出、自定义结果检查或自定义流处理时，直接使用 `agent.generate()` 或 `agent.stream()`。
