# `useStreamableValue`

<Note type="warning">
  AI SDK RSC 目前处于实验阶段。生产环境建议使用 [AI SDK
  UI](/docs/ai-sdk-ui/overview)。如需从 RSC 迁移到 UI，请参阅我们的[迁移指南](/docs/ai-sdk-rsc/migrating-to-ui)。
</Note>

这是一个 React Hook，它接收通过 [`createStreamableValue`](/docs/reference/ai-sdk-rsc/create-streamable-value) 创建的流式值，并返回当前值、错误和挂起状态。

## 导入

<Snippet
  text={`import { useStreamableValue } from "@ai-sdk/rsc"`}
  prompt={false}
/>

## 示例

这对于消费从组件 props 接收的流式值非常有用。

```tsx
function MyComponent({ streamableValue }) {
  const [data, error, pending] = useStreamableValue(streamableValue);

  if (pending) return <div>加载中...</div>;
  if (error) return <div>错误：{error.message}</div>;

  return <div>数据：{data}</div>;
}
```

## API 签名

### 参数

它接收一个通过 `createStreamableValue` 创建的流式值。

### 返回值

它是一个数组，其中第一个元素包含数据，第二个元素包含流过程中任何时刻抛出的错误，第三个元素是一个布尔值，表示值是否处于挂起状态。
