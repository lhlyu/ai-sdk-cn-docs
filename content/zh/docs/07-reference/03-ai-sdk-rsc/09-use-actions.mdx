# `useActions`

<Note type="warning">
  AI SDK RSC 目前处于实验阶段。我们建议在生产环境中使用 [AI SDK
  UI](/docs/ai-sdk-ui/overview)。如需从 RSC 迁移到 UI 的指导，请参阅我们的[迁移指南](/docs/ai-sdk-rsc/migrating-to-ui)。
</Note>

这是一个 Hook，用于帮助你在客户端访问 Server Actions。这对于构建需要用户与服务器交互的界面特别有用。

必须通过此 Hook 访问这些服务器操作，因为它们在通过上下文传递时已被修补。直接访问它们可能会导致[找不到客户端组件错误](/docs/troubleshooting/server-actions-in-client-components)。

## 导入

<Snippet text={`import { useActions } from "@ai-sdk/rsc"`} prompt={false} />

## API 签名

### 返回值

`Record<string, Action>`，一个服务器操作的字典。
