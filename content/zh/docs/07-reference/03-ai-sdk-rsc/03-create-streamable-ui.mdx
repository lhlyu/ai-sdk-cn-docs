# `createStreamableUI`

<Note type="warning">
  AI SDK RSC 目前处于实验阶段。生产环境建议使用 [AI SDK
  UI](/docs/ai-sdk-ui/overview)。如需从 RSC 迁移到 UI，请参阅我们的[迁移指南](/docs/ai-sdk-rsc/migrating-to-ui)。
</Note>

创建一个流，用于将 UI 从服务器发送到客户端。在客户端，它可以作为普通的 React 节点进行渲染。

## 导入

<Snippet
  text={`import { createStreamableUI } from "@ai-sdk/rsc"`}
  prompt={false}
/>
