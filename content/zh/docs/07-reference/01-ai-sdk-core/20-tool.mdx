# `tool()`

Tool 是一个辅助函数，用于推断其 `execute` 方法和生命周期回调中的工具输入和上下文。

它没有任何运行时行为，但能帮助 TypeScript 推断工具回调的类型。

如果没有这个辅助函数，TypeScript 无法将 `inputSchema` 和 `contextSchema` 属性连接到工具回调，并且回调参数类型也无法被推断。

关于 `runtimeContext`、`toolsContext`、工具 `context` 以及敏感上下文过滤的完整模型，请参阅[运行时与工具上下文](/docs/ai-sdk-core/runtime-and-tool-context)。

`Tool` 类型是四种工具类型的联合：

- `FunctionTool`：用户定义的函数式工具，具有已知的输入和输出类型。
- `DynamicTool`：在运行时定义的函数式工具，输入和输出类型为 `unknown`。
- `ProviderDefinedTool`：提供商定义的工具，由你的代码执行。
- `ProviderExecutedTool`：提供商定义的工具，由提供商执行。

```ts highlight={"1,4,9,10"}
import { tool } from 'ai';
import { z } from 'zod';

export const weatherTool = tool({
  description: '获取某个地点的天气',
  inputSchema: z.object({
    location: z.string().describe('要获取天气的地点'),
  }),
  // 下面的 location 被推断为字符串类型：
  execute: async ({ location }) => ({
    location,
    temperature: 72 + Math.floor(Math.random() * 21) - 10,
  }),
});
```
