# `customProvider()`

使用自定义提供商，你可以将 id 映射到任意模型。
这允许你设置自定义模型配置、别名等。
自定义提供商还支持回退提供商，这对于包装现有提供商并添加额外功能非常有用。自定义
提供商可以暴露语言、嵌入、图像、转录、语音、
重排序、视频、文件和技能能力。

### 示例：自定义模型设置

你可以使用 `customProvider` 创建自定义提供商。

```ts
import { openai } from '@ai-sdk/openai';
import { customProvider } from 'ai';

// custom provider with different model settings:
export const myOpenAI = customProvider({
  languageModels: {
    // replacement model with custom settings:
    'gpt-6-astra': wrapLanguageModel({
      model: openai('gpt-6-astra'),
      middleware: defaultSettingsMiddleware({
        settings: {
          providerOptions: {
            openai: {
              reasoningEffort: 'high',
            },
          },
        },
      }),
    }),
    // alias model with custom settings:
    'gpt-6-astra-reasoning-high': wrapLanguageModel({
      model: openai('gpt-6-astra'),
      middleware: defaultSettingsMiddleware({
        settings: {
          providerOptions: {
            openai: {
              reasoningEffort: 'high',
            },
          },
        },
      }),
    }),
  },
  fallbackProvider: openai,
});
```

## Experimental decision models

传入 `decisionModels: Record<string, Experimental_DecisionModel>` 来为决策模型实例或字符串 ID 定义
别名。返回的提供商添加了
`decisionModel(alias): Experimental_DecisionModelV4`。字符串别名默认通过 Gateway 解析，
或者通过显式配置的、带有
`decisionModel` 方法的默认提供商解析。未知别名在可用时会使用回退提供商的决策
工厂；模型失败和不支持的问题不会触发
替换。

不可用的决策能力或模型会抛出 `NoSuchModelError`，并带有
`modelType: 'decisionModel'`；未知的注册表提供商会抛出
`NoSuchProviderError`。这些能力是结构性扩展，并未
添加到稳定的 `ProviderV4` 契约中。当未配置默认提供商时，直接的决策字符串 ID 默认
使用 Gateway。
有关可运行的用法模式，请参阅 [Decisions](/docs/ai-sdk-core/decisions#model-aliases-and-registries)。
