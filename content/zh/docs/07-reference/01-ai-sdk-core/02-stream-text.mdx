# `streamText()`

从语言模型流式传输文本生成。

你可以将 streamText 函数用于交互式场景，例如聊天机器人和其它实时应用。你也可以使用工具生成 UI 组件。

```ts
import { streamText } from 'ai';
__PROVIDER_IMPORT__;

const { textStream } = streamText({
  model: __MODEL__,
  prompt: 'Invent a new holiday and describe its traditions.',
});

for await (const textPart of textStream) {
  process.stdout.write(textPart);
}
```

关于 `runtimeContext`、`toolsContext`、工具 `context` 和敏感上下文过滤的指导，请参阅 [运行时和工具上下文](/docs/ai-sdk-core/runtime-and-tool-context)。

要查看 `streamText` 的实际应用，请查看 [这些示例](#examples)。

## 类型

### `ActiveTools`

```ts
type ActiveTools<TOOLS extends ToolSet> =
  | ReadonlyArray<keyof TOOLS & string>
  | undefined;
```

将生成步骤限制为列出的工具名称。`undefined` 表示不应用工具限制。
