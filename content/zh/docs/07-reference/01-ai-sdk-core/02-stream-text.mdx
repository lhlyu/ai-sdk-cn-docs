# `streamText()`

从语言模型流式传输文本生成。

你可以使用 `streamText` 函数处理交互式用例，例如聊天机器人和其它实时应用。你还可以使用工具生成 UI 组件。

```ts
import { streamText } from 'ai';
__PROVIDER_IMPORT__;

const { textStream } = streamText({
  model: __MODEL__,
  prompt: '发明一个新节日并描述其传统。',
});

for await (const textPart of textStream) {
  process.stdout.write(textPart);
}
```

关于 `runtimeContext`、`toolsContext`、工具 `context` 以及敏感上下文过滤的指导，请参阅[运行时和工具上下文](/docs/ai-sdk-core/runtime-and-tool-context)。

要查看 `streamText` 的实际应用，请查看[这些示例](#examples)。
