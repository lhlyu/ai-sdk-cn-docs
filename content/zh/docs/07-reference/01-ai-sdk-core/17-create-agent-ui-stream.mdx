# `createAgentUIStream`

`createAgentUIStream` 函数执行一个[智能体](/docs/reference/ai-sdk-core/agent)，消费一组 UI 消息，并通过异步可迭代对象将智能体的输出作为 UI 消息块进行流式传输。这可以在您自己的运行时中实现 AI 助手输出的实时、增量渲染，并完全支持工具使用、中间推理和交互式 UI 功能——非常适合构建由智能体驱动的聊天 API、仪表盘或机器人。

## 导入

<Snippet text={`import { createAgentUIStream } from "ai"`} prompt={false} />

## 用法

```ts
import { ToolLoopAgent, createAgentUIStream } from 'ai';
__PROVIDER_IMPORT__;

const agent = new ToolLoopAgent({
  model: __MODEL__,
  instructions: '你是一个乐于助人的助手。',
  tools: { weather: weatherTool, calculator: calculatorTool },
});

export async function* streamAgent(
  uiMessages: unknown[],
  abortSignal?: AbortSignal,
) {
  const stream = await createAgentUIStream({
    agent,
    uiMessages,
    abortSignal,
    // experimental_sandbox, // 可选：将实验性沙盒传递给工具执行
    // ...其他选项（见下文）
  });

  for await (const chunk of stream) {
    yield chunk; // 每个块都是智能体输出的 UI 消息。
  }
}
```

## 返回值

一个 `Promise<AsyncIterableStream<UIMessageChunk>>`，其中每个生成的块都是智能体输出的 UI 消息（请参阅 [`UIMessage`](/docs/reference/ai-sdk-core/ui-message)）。可以使用任何异步迭代器循环消费，或通过管道传输到流式 HTTP 响应、套接字或任何其他接收器。

## 示例

```ts
import { createAgentUIStream } from 'ai';

const controller = new AbortController();

const stream = await createAgentUIStream({
  agent,
  uiMessages: [{ role: 'user', content: '今天旧金山的天气怎么样？' }],
  abortSignal: controller.signal,
  // experimental_sandbox, // 可选
  sendStart: true,
  // ...其他 UIMessageStreamOptions
});

for await (const chunk of stream) {
  // 每个块都是一个 UI 消息更新——将其流式传输到您的客户端、仪表盘、日志等。
  console.log(chunk);
}

// 调用 controller.abort() 以提前取消智能体操作。
```

## 工作原理

1. **UI 消息验证：** 使用智能体的 `tools` 定义对输入的 `uiMessages` 数组进行验证和规范化。任何无效消息都会导致错误。
2. **转换为模型消息：** 验证后的 UI 消息将转换为模型特定的消息格式，这是智能体所要求的。
3. **智能体流式传输：** 使用转换后的模型消息、可选的调用选项、abortSignal、experimental_sandbox 以及任何实验性转换来调用智能体的 `.stream({ prompt, ... })` 方法。
4. **UI 消息流构建：** 结果流被转换并作为 UI 消息块的流式异步可迭代对象暴露出来，供您消费。

## 注意事项

- 智能体**必须**实现 `.stream({ prompt, ... })` 方法并定义其支持的 `tools` 属性。
- 此工具返回一个异步可迭代对象，以实现最大的流式传输灵活性。对于 HTTP 响应，请参阅 [`createAgentUIStreamResponse`](/docs/reference/ai-sdk-core/create-agent-ui-stream-response)（Web）或 [`pipeAgentUIStreamToResponse`](/docs/reference/ai-sdk-core/pipe-agent-ui-stream-to-response)（Node.js）。
- `uiMessages` 参数名为 `uiMessages`，**不是** `messages`。
- 您可以通过 `UIMessageStreamOptions` 提供高级选项（例如，包含来源或使用数据）。
- 要取消流，请通过 `abortSignal` 参数传递一个 [`AbortSignal`](https://developer.mozilla.org/en-US/docs/Web/API/AbortSignal)。
- 当您的智能体工具在执行期间需要实验性沙盒环境时，请传递 `experimental_sandbox`。
