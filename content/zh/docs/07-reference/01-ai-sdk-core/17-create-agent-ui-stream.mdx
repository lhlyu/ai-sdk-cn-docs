# `createAgentUIStream`

`createAgentUIStream` 函数会执行一个 [Agent](/docs/reference/ai-sdk-core/agent)，消费一个 UI 消息数组，并通过异步可迭代对象将智能体的输出以 UI 消息块的形式流式传输。这使你能够在自己的运行时中实时、增量地渲染 AI 助手的输出，并完全访问工具使用、中间推理和交互式 UI 功能——非常适合构建由智能体驱动的聊天 API、仪表盘或机器人。

## 导入

<Snippet text={`import { createAgentUIStream } from "ai"`} prompt={false} />

## 用法

```ts
import { ToolLoopAgent, createAgentUIStream } from 'ai';
__PROVIDER_IMPORT__;

const agent = new ToolLoopAgent({
  model: __MODEL__,
  instructions: 'You are a helpful assistant.',
  tools: { weather: weatherTool, calculator: calculatorTool },
});

export async function* streamAgent(
  uiMessages: unknown[],
  abortSignal?: AbortSignal,
) {
  const stream = await createAgentUIStream({
    agent,
    uiMessages,
    abortSignal,
    // experimental_sandbox, // optional: pass an experimental sandbox through to tool execution
    // ...other options (see below)
  });

  for await (const chunk of stream) {
    yield chunk; // Each chunk is a UI message output from the agent.
  }
}
```

## 返回值

一个 `Promise<AsyncIterableStream<UIMessageChunk>>`，其中每个产出的块都是智能体输出的 UI 消息（参见 [`UIMessage`](/docs/reference/ai-sdk-core/ui-message)）。可以使用任何异步迭代器循环来消费它，或将其管道传输到流式 HTTP 响应、套接字或任何其他接收端。

## 示例

```ts
import { createAgentUIStream } from 'ai';

const controller = new AbortController();

const stream = await createAgentUIStream({
  agent,
  uiMessages: [{ role: 'user', content: 'What is the weather in SF today?' }],
  abortSignal: controller.signal,
  // experimental_sandbox, // optional
  sendStart: true,
  // ...other UIMessageStreamOptions
});

for await (const chunk of stream) {
  // Each chunk is a UI message update — stream it to your client, dashboard, logs, etc.
  console.log(chunk);
}

// Call controller.abort() to cancel the agent operation early.
```

## 工作原理

1. **UI 消息验证：** 输入的 `uiMessages` 数组会使用智能体的 `tools` 定义进行验证和规范化。任何无效消息都会导致错误。
2. **转换为模型消息：** 验证后的 UI 消息会按照智能体的要求转换为模型特定的消息格式。
3. **智能体流式传输：** 使用转换后的模型消息、可选的调用选项、中止信号、experimental_sandbox 以及任何实验性转换来调用智能体的 `.stream({ prompt, ... })` 方法。
4. **UI 消息流构建：** 结果流会被转换并作为 UI 消息块的流式异步可迭代对象暴露出来，供你消费。

## 注意事项

- 智能体**必须**实现 `.stream({ prompt, ... })` 方法，并定义其支持的 `tools` 属性。
- 此工具返回一个异步可迭代对象，以实现最大的流式传输灵活性。对于 HTTP 响应，请参阅 [`createAgentUIStreamResponse`](/docs/reference/ai-sdk-core/create-agent-ui-stream-response)（Web）或 [`pipeAgentUIStreamToResponse`](/docs/reference/ai-sdk-core/pipe-agent-ui-stream-to-response)（Node.js）。
- `uiMessages` 参数命名为 `uiMessages`，**而不是**简单的 `messages`。
- 你可以通过 `UIMessageStreamOptions` 提供高级选项（例如，包含来源或使用情况）。
- 要取消流，请通过 `abortSignal` 参数传入一个 [`AbortSignal`](https://developer.mozilla.org/en-US/docs/Web/API/AbortSignal)。
- 当你的智能体工具在执行期间需要实验性沙箱环境时，请传入 `experimental_sandbox`。
