# `experimental_streamTranslate()`

<Note type="warning">
  `experimental_streamTranslate` 是一个实验性功能。
</Note>

从实时原始音频流式传输语音到语音的翻译。模型将实时源音频翻译为目标语言的音频和文本。

`experimental_streamTranslate` 基于语音翻译模型规范（`Experimental_SpeechTranslationModelV4`）构建。该规范的提供商实现单独发布——请参阅您的提供商的文档以了解可用的翻译模型。

```ts
import { experimental_streamTranslate as streamTranslate } from 'ai';

const result = streamTranslate({
  // 任何实现了实验性语音翻译模型规范（Experimental_SpeechTranslationModelV4）的提供商模型实例：
  model: translationModel,
  audio: audioStream, // ReadableStream<Uint8Array | string>
  inputAudioFormat: { type: 'audio/pcm', rate: 24000 },
  targetLanguage: 'es',
});

for await (const part of result.fullStream) {
  if (part.type === 'output-text-delta') {
    process.stdout.write(part.delta);
  }
}

console.log(await result.translationText);
```
