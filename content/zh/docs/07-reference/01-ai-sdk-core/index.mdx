# AI SDK Core

[AI SDK Core](/docs/ai-sdk-core) 是一组函数，允许你与语言模型和其他 AI 模型进行交互。
这些函数设计得易于使用且灵活，使你能够从语言模型和其他 AI 模型生成文本、结构化数据和嵌入。
