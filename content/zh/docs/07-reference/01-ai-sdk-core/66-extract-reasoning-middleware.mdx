# `extractReasoningMiddleware()`

`extractReasoningMiddleware` 是一个中间件函数，用于从生成文本中提取被分隔符包裹的推理部分，并将其与主文本内容分开暴露。当你希望将 AI 模型的推理过程与其最终输出分离时，这尤其有用。

```ts
import { extractReasoningMiddleware } from 'ai';

const middleware = extractReasoningMiddleware({
  tagName: 'reasoning',
  separator: '\n',
});
```

对于使用非 XML 分隔符的模型，请传入字面量形式的 `opening` 和 `closing` 字符串。例如，Gemma 4 的原始思维通道输出在其起始分隔符中使用了换行符：

```ts
const middleware = extractReasoningMiddleware({
  tagName: { opening: '<|channel>thought\n', closing: '<channel|>' },
});
```

自定义分隔符必须非空。它们按字面量进行匹配，包括 `|` 等字符，并且可以跨越多个流式传输分块。空的推理块也会从答案文本中移除。当服务器在文本中返回这些标记时，请使用此中间件；已经单独返回推理内容的提供商则不需要它。

### Returns

返回一个中间件对象，它会：

- 同时处理流式传输和非流式传输响应
- 将指定分隔符之间的内容提取为推理内容
- 从主文本中移除分隔符和推理内容
- 将推理内容部分与文本内容部分分开输出
- 使用指定的分隔符在文本部分之间保持正确的分隔

### Type Parameters

该中间件适用于流式传输响应的 `LanguageModelV4StreamPart` 类型。
