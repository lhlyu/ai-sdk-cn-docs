# MCP Apps

`@ai-sdk/mcp` 中的 MCP Apps 辅助工具帮助 MCP 主机宣传 UI 支持、保持模型可见和应用程序可见的工具分离，并读取用于渲染的 `ui://` HTML 资源。

## 导入

<Snippet
  text={`import {
  MCP_APP_MIME_TYPE,
  mcpAppClientCapabilities,
  readMCPAppResource,
  splitMCPAppTools,
} from "@ai-sdk/mcp"`}
  prompt={false}
/>

## `MCP_APP_MIME_TYPE`

应渲染为 MCP Apps 的 HTML 资源的 MIME 类型。

```ts
const MCP_APP_MIME_TYPE = 'text/html;profile=mcp-app';
```

## `mcpAppClientCapabilities`

当你的主机支持 MCP Apps 时，传递给 [`createMCPClient`](/docs/reference/ai-sdk-core/create-mcp-client) 的客户端能力。

```ts
import { createMCPClient, mcpAppClientCapabilities } from '@ai-sdk/mcp';

const client = await createMCPClient({
  transport: {
    type: 'http',
    url: 'https://example.com/mcp',
  },
  capabilities: mcpAppClientCapabilities,
});
```

宣传的能力是：

```json
{
  "extensions": {
    "io.modelcontextprotocol/ui": {
      "mimeTypes": ["text/html;profile=mcp-app"]
    }
  }
}
```

## `splitMCPAppTools()`

将 MCP 工具定义拆分为模型可见的工具和应用程序可见的工具。

没有 MCP Apps 可见性元数据的工具保持模型可见。`_meta.ui.visibility` 包含 `"app"` 的工具在 `appVisible` 中返回。

```ts
const definitions = await client.listTools();
const { modelVisible, appVisible } = splitMCPAppTools(definitions);

const tools = client.toolsFromDefinitions(modelVisible);
```

## `readMCPAppResource()`

从 MCP 服务器读取 `ui://` 资源，并将其规范化为 HTML 及渲染元数据。

```ts
const resource = await readMCPAppResource({
  client,
  uri: 'ui://example/dashboard',
});
```

该辅助工具验证 URI 以 `ui://` 开头，要求 `text/html;profile=mcp-app` MIME 类型，并支持以文本或 base64 blob 数据形式返回的资源内容。
