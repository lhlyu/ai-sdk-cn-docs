# `isLoopFinished()`

创建一个永不触发的停止条件，让智能体循环一直运行，直到自然结束（即模型停止进行工具调用）。

默认情况下，`ToolLoopAgent` 使用 `isStepCount(20)` 作为安全措施，以防止失控循环导致过多的 API 调用和费用。如果你确信智能体会自然终止，或者不太关心成本，`isLoopFinished()` 可以移除该限制，让智能体一直运行到模型真正完成。

```ts
import { ToolLoopAgent, isLoopFinished } from 'ai';
__PROVIDER_IMPORT__;

const agent = new ToolLoopAgent({
  model: __MODEL__,
  tools: {
    // 你的工具
  },
  stopWhen: isLoopFinished(),
});

const result = await agent.generate({
  prompt: '分析此数据集并创建摘要报告',
});
```

## API 签名

### 参数

此函数不接受任何参数。

### 返回值

一个始终返回 `false` 的 `StopCondition` 函数，意味着它永远不会触发停止条件。智能体循环只会通过其自然终止条件停止：

- 模型停止进行工具调用，或
- 调用了没有 `execute` 函数的工具，或
- 工具调用需要审批

## 示例

### 基本用法

让智能体一直运行直到完成：

```ts
import { ToolLoopAgent, isLoopFinished } from 'ai';

const agent = new ToolLoopAgent({
  model: yourModel,
  tools: yourTools,
  stopWhen: isLoopFinished(),
});
```

### 与其他条件结合使用

你可以将 `isLoopFinished()` 与其他条件结合使用。由于 `isLoopFinished()` 永不触发，其他条件仍然有效：

```ts
import { ToolLoopAgent, isLoopFinished, hasToolCall } from 'ai';

const agent = new ToolLoopAgent({
  model: yourModel,
  tools: yourTools,
  stopWhen: [isLoopFinished(), hasToolCall('finalAnswer')],
});
```

实际上，在这种情况下这样做意义不大，因为你完全可以省略 `isLoopFinished()`。
