# `experimental_getRealtimeToolDefinitions()`

<Note type="warning">
  `experimental_getRealtimeToolDefinitions` 是实验性实时 API 的一部分。
</Note>

将 AI SDK 的 `ToolSet` 转换为与提供商无关的实时工具定义，这些定义可传递给实时会话设置请求。

在服务端设置端点中使用它，该端点用于创建短期有效的实时提供商令牌。

```ts
import { openai } from '@ai-sdk/openai';
import { experimental_getRealtimeToolDefinitions, tool } from 'ai';
import { z } from 'zod';

const tools = {
  getWeather: tool({
    description: '获取指定城市的当前天气',
    inputSchema: z.object({
      city: z.string(),
    }),
  }),
};

const toolDefinitions = await experimental_getRealtimeToolDefinitions({
  tools,
});

const token = await openai.experimental_realtime.getToken({
  model: 'gpt-realtime',
  sessionConfig: {
    tools: toolDefinitions,
  },
});
```

## 注意事项

- 工具执行不由 `experimental_getRealtimeToolDefinitions` 处理。请使用
  [`experimental_useRealtime`](/docs/reference/ai-sdk-ui/use-realtime)
  的 `onToolCall` 和 `addToolOutput` 来执行工具并返回结果。
- 提供商工具会被跳过，因为实时提供商期望在会话配置中使用常规函数定义。
- 动态工具描述会在返回定义之前，使用 `toolsContext` 中的匹配值进行解析。
