# `createIdGenerator()`

创建一个可自定义的 ID 生成器函数。你可以配置生成 ID 的字母表、前缀、分隔符和默认大小。

```ts
import { createIdGenerator } from 'ai';

const generateCustomId = createIdGenerator({
  prefix: 'user',
  separator: '_',
});

const id = generateCustomId(); // 示例: "user_1a2b3c4d5e6f7g8h"
```

### 返回值

返回一个基于配置选项生成 ID 的函数。

### 说明

- 生成器使用非安全随机生成，不应用于安全关键场景。
- 分隔符字符不能是字母表的一部分，以确保可靠的前缀检查。

## 示例

```ts
// 为用户 ID 创建自定义 ID 生成器
const generateUserId = createIdGenerator({
  prefix: 'user',
  separator: '_',
  size: 8,
});

// 生成 ID
const id1 = generateUserId(); // 例如: "user_1a2b3c4d"
```
