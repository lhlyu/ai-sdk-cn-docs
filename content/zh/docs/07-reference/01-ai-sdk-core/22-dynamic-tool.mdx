# `dynamicTool()`

`dynamicTool` 函数用于创建在编译时输入和输出类型未知的工具。这在以下场景中非常有用：

- 无模式的 MCP（模型上下文协议）工具
- 运行时加载的用户定义函数
- 从外部来源或数据库加载的工具
- 基于用户输入动态生成工具

与常规的 `tool` 函数不同，`dynamicTool` 接受并返回 `unknown` 类型，允许你处理具有运行时确定模式的工具。

```ts highlight={"1,4,9,11"}
import { dynamicTool } from 'ai';
import { z } from 'zod';

export const customTool = dynamicTool({
  description: '执行自定义用户定义函数',
  inputSchema: z.object({}),
  // input 的类型为 'unknown'
  execute: async input => {
    const { action, parameters } = input as any;

    // 执行你的动态逻辑
    return {
      result: `已执行 ${action}，参数为 ${JSON.stringify(parameters)}`,
    };
  },
});
```

### 返回值

一个 `Tool<unknown, unknown>`，其 `type: 'dynamic'`，可与 `generateText`、`streamText` 以及其他 AI SDK 函数一起使用。

## 类型安全用法

当动态工具与静态工具一起使用时，你需要检查 `dynamic` 标志以进行正确的类型收窄：

```ts
const result = await generateText({
  model: __MODEL__,
  tools: {
    // 具有已知类型的静态工具
    weather: weatherTool,
    // 具有未知类型的动态工具
    custom: dynamicTool({
      /* ... */
    }),
  },
  onStepEnd: ({ toolCalls, toolResults }) => {
    for (const toolCall of toolCalls) {
      if (toolCall.dynamic) {
        // 动态工具：输入/输出为 'unknown'
        console.log('动态工具:', toolCall.toolName);
        console.log('输入:', toolCall.input);
        continue;
      }

      // 静态工具具有完整的类型推断
      switch (toolCall.toolName) {
        case 'weather':
          // TypeScript 知道确切的类型
          console.log(toolCall.input.location); // string
          break;
      }
    }
  },
});
```

## 与 `useChat` 一起使用

当与 useChat（`UIMessage` 格式）一起使用时，动态工具显示为 `dynamic-tool` 部分：

```tsx
{
  message.parts.map(part => {
    switch (part.type) {
      case 'dynamic-tool':
        return (
          <div>
            <h4>工具: {part.toolName}</h4>
            <pre>{JSON.stringify(part.input, null, 2)}</pre>
          </div>
        );
      // ... 处理其他部分类型
    }
  });
}
```
