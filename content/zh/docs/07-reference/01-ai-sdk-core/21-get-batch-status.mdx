# `experimental_getBatchStatus()`

<Note type="warning">
  批处理支持为实验性功能，API 可能会在补丁版本中发生变化。
</Note>

检索异步批处理的最新状态。有关批处理生命周期的完整指南，请参阅 [Batch](/docs/ai-sdk-core/batch)。

```ts
import { anthropic } from '@ai-sdk/anthropic';
import { experimental_getBatchStatus as getBatchStatus } from 'ai';

const status = await getBatchStatus({
  provider: anthropic,
  batch,
});

console.log(status.status, status.requestCounts);
```
