# `experimental_getBatchResults()`

<Note type="warning">
  批处理支持为实验性功能，API 可能会在补丁版本中发生变化。
</Note>

返回异步批处理中请求的最终结果的异步可迭代对象。有关批处理生命周期的完整指南，请参阅
[批处理](/docs/ai-sdk-core/batch)。

```ts
import { anthropic } from '@ai-sdk/anthropic';
import { experimental_getBatchResults as getBatchResults } from 'ai';

for await (const item of getBatchResults({ provider: anthropic, batch })) {
  if (item.status === 'succeeded') {
    console.log(item.id, item.text);
  } else {
    console.error(item.id, item.error);
  }
}
```

### 返回值

一个 `AsyncIterableStream<Experimental_BatchItemResult>`，包含成功、
失败、已取消或已过期请求的结果。你可以将该流作为异步可迭代对象或
`ReadableStream` 来消费。

成功的项包含 `id`、`status: 'succeeded'`、`text`、规范化后的
`content`（包括文本、推理、来源、文件、工具调用和工具
结果）、
`finishReason`、`usage`，以及可选的响应和提供商元数据。`text` 是
文本部分的拼接，当结果不包含文本部分时可能为空字符串。
失败、已取消和已过期的项包含请求 `id`、其最终
状态，以及可选的错误详情。
