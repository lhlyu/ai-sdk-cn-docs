# `generateText()`

根据给定的提示词，使用语言模型生成文本并调用工具。

它非常适合非交互式用例，例如需要编写文本（如起草电子邮件或总结网页）的自动化任务，以及使用工具的智能体。

```ts
import { generateText } from 'ai';
__PROVIDER_IMPORT__;

const { text } = await generateText({
  model: __MODEL__,
  prompt: '发明一个新的节日并描述其传统。',
});

console.log(text);
```

关于 `runtimeContext`、`toolsContext`、工具 `context` 以及敏感上下文过滤的指导，请参阅[运行时和工具上下文](/docs/ai-sdk-core/runtime-and-tool-context)。

要查看 `generateText` 的实际应用，请查看[这些示例](#examples)。
