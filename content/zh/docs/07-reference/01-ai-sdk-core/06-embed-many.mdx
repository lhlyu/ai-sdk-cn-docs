# `embedMany()`

使用嵌入模型嵌入多个值。

当模型对单次调用可处理的嵌入数量或 UTF-8 输入字节数有限制时，`embedMany` 会自动将大型请求拆分为较小的块。提供商可以使用保守的字节预算，在无需向 AI SDK 核心包添加分词器的情况下，将请求保持在聚合令牌限制以下。大于字节预算的单个值会单独发送调用，因为拆分它会改变最终的嵌入结果。

```ts
import { embedMany } from 'ai';

const { embeddings } = await embedMany({
  model: 'openai/text-embedding-3-small',
  values: [
    'sunny day at the beach',
    'rainy afternoon in the city',
    'snowy night in the mountains',
  ],
});
```
