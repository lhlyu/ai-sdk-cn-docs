# `defaultSettingsMiddleware()`

`defaultSettingsMiddleware` 是一个中间件函数，用于为语言模型调用应用默认设置。当您希望在多次模型调用中建立一致的默认参数时，此功能非常有用。

```ts
import { defaultSettingsMiddleware } from 'ai';

const middleware = defaultSettingsMiddleware({
  settings: {
    temperature: 0.7,
    maxOutputTokens: 1000,
    // 其他设置...
  },
});
```

## API 签名

### 参数

该中间件接受一个配置对象，包含以下属性：

- `settings`：一个对象，包含要应用于语言模型调用的默认参数值。这些参数可以包括任何有效的 `LanguageModelV4CallOptions` 属性和可选的提供商元数据。

### 返回值

返回一个中间件对象，该对象：

- 将默认设置与每次模型调用中提供的参数合并
- 确保显式提供的参数优先于默认值
- 合并提供商元数据对象

### 使用示例

```ts
import { streamText, wrapLanguageModel, defaultSettingsMiddleware } from 'ai';

// 创建具有默认设置的模型
const modelWithDefaults = wrapLanguageModel({
  model: gateway('anthropic/claude-sonnet-4.5'),
  middleware: defaultSettingsMiddleware({
    settings: {
      providerOptions: {
        openai: {
          reasoningEffort: 'high',
        },
      },
    },
  }),
});

// 使用模型 - 将应用默认设置
const result = await streamText({
  model: modelWithDefaults,
  prompt: '您的提示词',
  // 这些参数将覆盖默认值
  temperature: 0.8,
});
```

## 工作原理

该中间件：

1. 将一组默认设置作为配置
2. 将这些默认值与每次模型调用中提供的参数合并
3. 确保显式提供的参数优先于默认值
4. 合并两个来源的提供商元数据对象
