# `experimental_streamTranscribe()`

<Note type="warning">
  `experimental_streamTranscribe` 是一个实验性功能。
</Note>

使用支持流式传输的转录模型，从实时原始音频中流式传输转录文本。

```ts
import { experimental_streamTranscribe as streamTranscribe } from 'ai';
import { openai } from '@ai-sdk/openai';

const result = streamTranscribe({
  model: openai.transcription('gpt-realtime-whisper'),
  audio: audioStream, // ReadableStream<Uint8Array | string>
  inputAudioFormat: { type: 'audio/pcm', rate: 24000 },
});

for await (const part of result.fullStream) {
  if (part.type === 'transcript-delta') {
    process.stdout.write(part.delta);
  }
}

console.log(await result.text);
```

  结果 Promise 会在流被消费时逐步解决。如果你提前停止消费 `fullStream`（例如通过 `break` 退出循环），底层提供商连接将被关闭，待处理的 Promise 将拒绝。
</Note>

## 线路格式（实验性）

通过 WebSocket 的流式转录使用 `@ai-sdk/provider-utils` 中定义的实验性转录流信封进行序列化（`experimental_parseTranscriptionStreamClientFrame`、`experimental_serializeTranscriptionStreamPart`、`experimental_parseTranscriptionStreamPart`）：客户端发送一个 `transcription-stream.start` TEXT 帧，音频作为 BINARY 帧，以及一个 `transcription-stream.audio-done` TEXT 帧；每个服务器 TEXT 帧是一个 JSON 序列化的转录流部分。AI Gateway 实现了此信封的服务器端。
