# `cosineSimilarity()`

当需要比较嵌入的相似度时，通常使用标准向量相似度指标，如余弦相似度。

`cosineSimilarity` 计算两个向量之间的余弦相似度。
高值（接近 1）表示向量非常相似，而低值（接近 -1）表示它们不同。

```ts
import { cosineSimilarity, embedMany } from 'ai';

const { embeddings } = await embedMany({
  model: 'openai/text-embedding-3-small',
  values: ['阳光明媚的海滩日', '城市里的阴雨午后'],
});

console.log(
  `余弦相似度: ${cosineSimilarity(embeddings[0], embeddings[1])}`,
);
```
