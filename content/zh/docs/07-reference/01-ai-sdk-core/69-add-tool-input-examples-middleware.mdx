# `addToolInputExamplesMiddleware`

`addToolInputExamplesMiddleware` 是一个中间件函数，用于将输入示例追加到工具描述中。这对于**本身不支持 `inputExamples` 属性**的语言模型提供商特别有用——该中间件会将示例序列化并注入到工具的 `description` 中，以便模型能够从中学习。

## 导入

<Snippet
  text={`import { addToolInputExamplesMiddleware } from "ai"`}
  prompt={false}
/>

## API

### 签名

```ts
function addToolInputExamplesMiddleware(options?: {
  prefix?: string;
  format?: (example: { input: JSONObject }, index: number) => string;
  remove?: boolean;
}): LanguageModelMiddleware;
```

      type: 'boolean',
      isOptional: true,

        '是否在将示例添加到描述后从工具中移除 `inputExamples` 属性。默认值：true。',
    },
  ]}
/>

### 返回值

一个 [LanguageModelMiddleware](/docs/ai-sdk-core/middleware)，它会：

- 定位具有 `inputExamples` 属性的函数工具。
- 序列化每个输入示例（默认使用 JSON，或使用自定义格式化函数）。
- 在工具描述末尾添加一个包含所有格式化示例的部分，并以 `prefix` 作为前缀。
- 从工具中移除 `inputExamples` 属性（除非设置 `remove: false`）。
- 其他所有工具（包括没有示例的工具）保持不变。

## 使用示例

```ts
import {
  generateText,
  tool,
  wrapLanguageModel,
  addToolInputExamplesMiddleware,
} from 'ai';
import { openai } from '@ai-sdk/openai';
import { z } from 'zod';

const model = wrapLanguageModel({
  model: __MODEL__,
  middleware: addToolInputExamplesMiddleware({
    prefix: 'Input Examples:',
    format: (example, index) =>
      `${index + 1}. ${JSON.stringify(example.input)}`,
  }),
});

const result = await generateText({
  model,
  tools: {
    weather: tool({
      description: '获取某个位置的天气',
      inputSchema: z.object({ location: z.string() }),
      inputExamples: [
        { input: { location: '旧金山' } },
        { input: { location: '伦敦' } },
      ],
    }),
  },
  prompt: '东京的天气怎么样？',
});
```

## 工作原理

1. 对于每个定义了 `inputExamples` 的函数工具，中间件会：
   - 使用 `format` 函数格式化每个示例（默认：JSON.stringify）。
   - 构建一个类似以下内容的部分：

     ```
     Input Examples:
     {"location":"旧金山"}
     {"location":"伦敦"}
     ```

   - 将此部分追加到工具的 `description` 末尾。

2. 默认情况下，它会在追加后移除 `inputExamples` 属性，以防止重复（可以通过 `remove: false` 禁用）。
3. 没有输入示例的工具或非函数工具保持不变。

> **提示：** 此中间件对于 OpenAI 或 Anthropic 等提供商特别有用，因为它们本身不支持 `inputExamples`。

## 示例效果

如果你的原始工具定义如下：

```ts
{
  type: 'function',
  name: 'weather',
  description: '获取某个位置的天气',
  inputSchema: { ... },
  inputExamples: [
    { input: { location: '旧金山' } },
    { input: { location: '伦敦' } }
  ]
}
```

应用中间件后（使用默认设置），传递给模型的工具将如下所示：

```ts
{
  type: 'function',
  name: 'weather',
  description: `获取某个位置的天气

Input Examples:
{"location":"旧金山"}
{"location":"伦敦"}`,
  inputSchema: { ... }
  // inputExamples 默认被移除
}
```
