# `addToolInputExamplesMiddleware`

`addToolInputExamplesMiddleware` 是一个中间件函数，用于将输入示例追加到工具描述中。这对于**原生不支持 `inputExamples` 属性**的语言模型提供商尤其有用——该中间件会将示例序列化并注入到工具的 `description` 中，以便模型可以从中学习。

## 导入

<Snippet
  text={`import { addToolInputExamplesMiddleware } from "ai"`}
  prompt={false}
/>

## API

### 签名

```ts
function addToolInputExamplesMiddleware(options?: {
  prefix?: string;
  format?: (example: { input: JSONObject }, index: number) => string;
  remove?: boolean;
}): LanguageModelMiddleware;
```

### 返回值

一个 [LanguageModelMiddleware](/docs/ai-sdk-core/middleware)，它会：

- 定位带有 `inputExamples` 属性的函数工具。
- 序列化每个输入示例（默认使用 JSON，或使用你的自定义格式化函数）。
- 在工具描述末尾追加一个包含所有格式化示例的部分，并以 `prefix` 作为前缀。
- 从工具中移除 `inputExamples` 属性（除非设置 `remove: false`）。
- 原样传递所有其他工具（包括没有示例的工具）。

## 使用示例

```ts
import {
  generateText,
  tool,
  wrapLanguageModel,
  addToolInputExamplesMiddleware,
} from 'ai';
import { openai } from '@ai-sdk/openai';
import { z } from 'zod';

const model = wrapLanguageModel({
  model: __MODEL__,
  middleware: addToolInputExamplesMiddleware({
    prefix: 'Input Examples:',
    format: (example, index) =>
      `${index + 1}. ${JSON.stringify(example.input)}`,
  }),
});

const result = await generateText({
  model,
  tools: {
    weather: tool({
      description: 'Get the weather in a location',
      inputSchema: z.object({ location: z.string() }),
      inputExamples: [
        { input: { location: 'San Francisco' } },
        { input: { location: 'London' } },
      ],
    }),
  },
  prompt: 'What is the weather in Tokyo?',
});
```

## 工作原理

1. 对于每个定义了 `inputExamples` 的函数工具，该中间件会：
   - 使用 `format` 函数格式化每个示例（默认：JSON.stringify）。
   - 构建如下所示的部分：

     ```
     Input Examples:
     {"location":"San Francisco"}
     {"location":"London"}
     ```

   - 将此部分追加到工具 `description` 的末尾。

2. 默认情况下，它会在追加后移除 `inputExamples` 属性以防止重复（可以通过 `remove: false` 禁用）。
3. 没有输入示例的工具或非函数工具保持不变。

> **提示：** 该中间件在 OpenAI 或 Anthropic 等提供商中尤其有用，因为这些提供商不原生支持 `inputExamples`。

## 示例效果

如果你的原始工具定义是：

```ts
{
  type: 'function',
  name: 'weather',
  description: 'Get the weather in a location',
  inputSchema: { ... },
  inputExamples: [
    { input: { location: 'San Francisco' } },
    { input: { location: 'London' } }
  ]
}
```

应用中间件后（使用默认设置），传递给模型的工具将如下所示：

```ts
{
  type: 'function',
  name: 'weather',
  description: `Get the weather in a location

Input Examples:
{"location":"San Francisco"}
{"location":"London"}`,
  inputSchema: { ... }
  // inputExamples is removed by default
}
```
