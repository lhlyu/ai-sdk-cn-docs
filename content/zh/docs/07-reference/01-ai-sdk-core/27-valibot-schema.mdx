# `valibotSchema()`

`valibotSchema` 是一个辅助函数，用于将 Valibot 模式转换为与 AI SDK 兼容的 JSON 模式对象。
它接收一个 Valibot 模式作为输入，并返回一个类型化的模式。

你可以使用它来[生成结构化数据](/docs/ai-sdk-core/generating-structured-data)以及
在[工具](/docs/ai-sdk-core/tools-and-tool-calling)中使用。

## 示例

```ts
import { valibotSchema } from '@ai-sdk/valibot';
import { object, string, array } from 'valibot';

const recipeSchema = valibotSchema(
  object({
    name: string(),
    ingredients: array(
      object({
        name: string(),
        amount: string(),
      }),
    ),
    steps: array(string()),
  }),
);
```
