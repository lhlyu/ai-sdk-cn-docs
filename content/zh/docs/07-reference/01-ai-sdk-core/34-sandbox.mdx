# `Experimental_SandboxSession`

`Experimental_SandboxSession` 接口描述了一个执行环境，工具可在此环境中运行命令。使用 `generateText`、`streamText`、`ToolLoopAgent.generate`、`ToolLoopAgent.stream` 或 agent UI 流式传输辅助函数中的 `experimental_sandbox` 选项传入实验性沙箱，使其可用于工具描述函数和工具执行。

<Note type="warning">
  此 API 为实验性，可能在补丁版本中发生变更。传入实验性沙箱并不会对工具本身进行沙箱化。除非工具明确将工作委托给实验性沙箱，否则工具代码仍会在你的应用程序进程中运行。
</Note>

```ts
type Experimental_SandboxSession = {
  readonly description: string;
  readonly run: (options: {
    command: string;

    env?: Record<string, string>;
    abortSignal?: AbortSignal;
  }) => PromiseLike<{
    exitCode: number;
    stdout: string;
    stderr: string;
  }>;
};
```

## 示例

```ts
const result = await generateText({
  model: __MODEL__,
  tools: { shell },
  experimental_sandbox,
  prompt: '运行测试套件。',
});
```

在工具内部，从第二个 `execute` 参数读取实验性沙箱：

```ts
const shell = tool({
  inputSchema: z.object({
    command: z.string(),
    workingDirectory: z.string().optional(),
  }),
  execute: async (
    { command, workingDirectory },
    { abortSignal, experimental_sandbox },
  ) => {
    if (!experimental_sandbox) {
      throw new Error('实验性沙箱不可用');
    }

    return experimental_sandbox.run({
      command,
      workingDirectory,
      abortSignal,
    });
  },
});
```
