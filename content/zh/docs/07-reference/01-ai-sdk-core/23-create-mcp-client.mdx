# `createMCPClient()`

创建一个轻量级的 Model Context Protocol (MCP) 客户端，用于连接 MCP 服务器。该客户端提供：

- **工具**：在 MCP 工具与 AI SDK 工具之间自动转换
- **资源**：用于列出、读取和发现 MCP 服务器资源模板的方法
- **提示词**：用于列出可用提示词并获取提示词消息的方法
- **补全**：用于为提示词参数和资源模板变量请求自动补全建议的方法
- **引导请求**：支持在工具执行期间处理服务器对额外输入的请求
- **实验性事件**：通过 `client.experimental_events` 发现事件并管理 webhook 订阅

它目前不支持来自 MCP 服务器的带内通知。有关实验性 webhook 投递，请参阅 [MCP 事件指南](/docs/ai-sdk-core/mcp-events)、
[事件方法参考](/docs/reference/ai-sdk-core/mcp-events) 以及
[webhook 处理器参考](/docs/reference/ai-sdk-core/mcp-events#webhook-handler)。

## Example

```typescript
import { createMCPClient } from '@ai-sdk/mcp';
import { generateText } from 'ai';
import { Experimental_StdioMCPTransport } from '@ai-sdk/mcp/mcp-stdio';

let client;

try {
  client = await createMCPClient({
    transport: new Experimental_StdioMCPTransport({
      command: 'node server.js',
    }),
  });

  const tools = await client.tools();

  const response = await generateText({
    model: __MODEL__,
    tools,
    messages: [{ role: 'user', content: 'Query the data' }],
  });

  console.log(response);
} catch (error) {
  console.error('Error:', error);
} finally {
  // ensure the client is closed even if an error occurs
  if (client) {
    await client.close();
  }
}
```

## Error Handling

客户端在以下情况会抛出 `MCPClientError`：

- 客户端初始化失败
- 协议版本不匹配
- 缺少服务器能力
- 连接失败

从 `@ai-sdk/mcp` 导入 `MCPClientError`，并使用其 `isInstance` 方法
安全地收窄未知错误：

```typescript
import { createMCPClient, MCPClientError } from '@ai-sdk/mcp';

try {
  await createMCPClient({
    transport: {
      type: 'http',
      url: 'https://your-server.com/mcp',
    },
  });
} catch (error) {
  if (MCPClientError.isInstance(error)) {
    if (error.statusCode === 401 || error.statusCode === 403) {
      // Authentication or authorization must be fixed before retrying.
      throw error;
    }

    // Inspect error.code and error.statusCode according to your application's policy.
  }

  throw error;
}
```

该错误暴露可选的 `code`、`statusCode`、`url` 和 `responseBody`
属性。`code` 是 JSON-RPC 应用错误码。`statusCode`、`url`
和 `responseBody` 在可用时包含 HTTP 传输上下文。对于没有 HTTP 响应的失败，例如网络错误、
超时、中止的请求和 stdio 传输失败，它们为 `undefined`。

`MCPClientError` 也代表配置和协议错误，因此仅凭其
类型或缺少 `statusCode` 并不能表明失败可重试。
OAuth 失败可能会改为抛出单独导出的 `UnauthorizedError`
或 `MCPClientOAuthError`。

避免在未脱敏敏感端点、
查询参数或服务器响应数据的情况下记录 `url` 或 `responseBody`。

对于工具执行，错误会作为 `CallToolError` 错误传播。

对于未知错误，客户端暴露一个 `onUncaughtError` 回调，可用于手动记录或处理已知错误类型未覆盖的错误。
