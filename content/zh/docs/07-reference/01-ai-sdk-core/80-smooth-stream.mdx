# `smoothStream()`

`smoothStream` 是一个工具函数，用于为 `streamText` 的 `transform` 选项创建 `TransformStream`，
通过缓冲并以可配置的延迟释放完整块来平滑文本和推理输出。
这为流式传输文本和推理响应时创造了更自然的阅读体验。

```ts highlight={"6-9"}
import { smoothStream, streamText } from 'ai';

const result = streamText({
  model,
  prompt,
  experimental_transform: smoothStream({
    delayInMs: 20, // 可选：默认为 10ms
    chunking: 'line', // 可选：默认为 'word'
  }),
});
```

#### 非拉丁语言的词分块注意事项

基于词的分块**不适用于**以下不使用空格分隔词的语言：

- 中文
- 日语
- 韩语
- 越南语
- 泰语

#### 使用 Intl.Segmenter（推荐）

对于这些语言，我们推荐使用 `Intl.Segmenter` 进行正确的区域感知词分割。
这是首选方法，因为它为中日韩等语言提供了准确的词边界。

<Note>
  `Intl.Segmenter` 在 Node.js 16+ 和所有现代浏览器（Chrome
  87+、Firefox 125+、Safari 14.1+）中可用。
</Note>

```tsx filename="使用 Intl.Segmenter 的日语示例"
import { smoothStream, streamText } from 'ai';
__PROVIDER_IMPORT__;

const segmenter = new Intl.Segmenter('ja', { granularity: 'word' });

const result = streamText({
  model: __MODEL__,
  prompt: 'Your prompt here',
  experimental_transform: smoothStream({
    chunking: segmenter,
  }),
});
```

```tsx filename="使用 Intl.Segmenter 的中文示例"
import { smoothStream, streamText } from 'ai';
__PROVIDER_IMPORT__;

const segmenter = new Intl.Segmenter('zh', { granularity: 'word' });

const result = streamText({
  model: __MODEL__,
  prompt: 'Your prompt here',
  experimental_transform: smoothStream({
    chunking: segmenter,
  }),
});
```

#### 基于正则表达式的分块

要使用基于正则表达式的分块，请将 `RegExp` 传递给 `chunking` 选项。支持全局和粘性表达式。表达式不得匹配空字符串。

```ts
// 以下划线分割：
smoothStream({
  chunking: /_+/,
});

// 也可以这样写，行为相同
smoothStream({
  chunking: /[^_]*_/,
});
```

#### 自定义回调分块

要使用自定义回调进行分块，请将函数传递给 `chunking` 选项。

```ts
smoothStream({
  chunking: text => {
    const findString = 'some string';
    const index = text.indexOf(findString);

    if (index === -1) {
      return null;
    }

    return text.slice(0, index) + findString;
  },
});
```

### 返回值

返回一个 `TransformStream`，其功能如下：

- 缓冲传入的文本和推理块
- 在遇到分块模式时释放内容
- 在块之间添加可配置的延迟以实现平滑输出
- 立即传递非文本/推理块（如工具调用、步骤完成事件）
