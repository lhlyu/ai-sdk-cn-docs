# `smoothStream()`

`smoothStream` 是一个实用函数，用于为 `streamText` 的 `experimental_transform` 选项创建 TransformStream，
通过缓冲并以可配置的延迟释放完整块来平滑文本和推理的流式传输。
这在流式传输文本和推理响应时能带来更自然的阅读体验。

```ts highlight={"6-9"}
import { smoothStream, streamText } from 'ai';

const result = streamText({
  model,
  prompt,
  experimental_transform: smoothStream({
    delayInMs: 20, // optional: defaults to 10ms
    chunking: 'line', // optional: defaults to 'word'
  }),
});
```

#### 非拉丁语言下按词分块的注意事项

基于词的分块**无法很好地处理**以下不使用空格分隔单词的语言：

- 中文
- 日文
- 韩文
- 越南语
- 泰语

#### 使用 Intl.Segmenter（推荐）

对于这些语言，我们推荐使用 `Intl.Segmenter` 进行正确的区域感知分词。
这是首选方案，因为它能为 CJK 及其他语言提供准确的词边界。

<Note>
  `Intl.Segmenter` 在 Node.js 16+ 及所有现代浏览器（Chrome 87+、Firefox
  125+、Safari 14.1+）中可用。
</Note>

```tsx filename="Japanese example with Intl.Segmenter"
import { smoothStream, streamText } from 'ai';
__PROVIDER_IMPORT__;

const segmenter = new Intl.Segmenter('ja', { granularity: 'word' });

const result = streamText({
  model: __MODEL__,
  prompt: 'Your prompt here',
  experimental_transform: smoothStream({
    chunking: segmenter,
  }),
});
```

```tsx filename="Chinese example with Intl.Segmenter"
import { smoothStream, streamText } from 'ai';
__PROVIDER_IMPORT__;

const segmenter = new Intl.Segmenter('zh', { granularity: 'word' });

const result = streamText({
  model: __MODEL__,
  prompt: 'Your prompt here',
  experimental_transform: smoothStream({
    chunking: segmenter,
  }),
});
```

#### 基于正则的分块

要使用基于正则的分块，请向 `chunking` 选项传入一个 `RegExp`。支持全局
和粘性表达式。该表达式不能匹配空字符串。

```ts
// To split on underscores:
smoothStream({
  chunking: /_+/,
});

// Also can do it like this, same behavior
smoothStream({
  chunking: /[^_]*_/,
});
```

#### 自定义回调分块

要使用自定义回调进行分块，请向 `chunking` 选项传入一个函数。

```ts
smoothStream({
  chunking: text => {
    const findString = 'some string';
    const index = text.indexOf(findString);

    if (index === -1) {
      return null;
    }

    return text.slice(0, index) + findString;
  },
});
```

### 返回值

返回一个 `TransformStream`，它会：

- 缓冲传入的文本和推理块
- 在遇到分块模式时释放内容
- 在块之间添加可配置的延迟以实现平滑输出
- 立即透传非文本/推理块（如工具调用、步骤完成事件）
