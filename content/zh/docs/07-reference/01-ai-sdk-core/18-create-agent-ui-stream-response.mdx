# `createAgentUIStreamResponse`

`createAgentUIStreamResponse` 函数执行一个[智能体](/docs/reference/ai-sdk-core/agent)，将其流式输出作为 UI 消息流运行，并返回一个 HTTP [Response](https://developer.mozilla.org/en-US/docs/Web/API/Response) 对象，其主体是实时的流式 UI 消息输出。此函数专为提供实时智能体结果的 API 路由设计，例如聊天端点或流式工具调用操作。

## 导入

<Snippet
  text={`import { createAgentUIStreamResponse } from "ai"`}
  prompt={false}
/>

## 用法

```ts
import { ToolLoopAgent, createAgentUIStreamResponse } from 'ai';
__PROVIDER_IMPORT__;

const agent = new ToolLoopAgent({
  model: __MODEL__,
  instructions: '你是一个乐于助人的助手。',
  tools: { weather: weatherTool, calculator: calculatorTool },
});

export async function POST(request: Request) {
  const { messages } = await request.json();

  // 可选：支持取消（在断开连接时中止等）
  const abortController = new AbortController();

  return createAgentUIStreamResponse({
    agent,
    uiMessages: messages,
    abortSignal: abortController.signal, // 可选
    // experimental_sandbox, // 可选：传递给工具执行
    // ...其他 UIMessageStreamOptions，如 sendSources、experimental_transform 等
  });
}
```

## 返回值

一个 `Promise<Response>`，其 `body` 是来自智能体的流式 UI 消息输出。在 serverless、Next.js、Express、Hono 或边缘运行时环境中，将其用作 API/服务器处理程序的返回值。

## 示例：Next.js API 路由处理程序

```ts
import { createAgentUIStreamResponse } from 'ai';
import { MyCustomAgent } from '@/agent/my-custom-agent';

export async function POST(request: Request) {
  const { messages } = await request.json();

  return createAgentUIStreamResponse({
    agent: MyCustomAgent,
    uiMessages: messages,
    // experimental_sandbox, // 可选
    sendSources: true, // (可选)
    // headers、status、abortSignal 和其他 UIMessageStreamOptions 也支持
  });
}
```

## 工作原理

- 1. **UI 消息验证：** 根据智能体指定的工具和要求验证传入的 `uiMessages` 数组。
- 2. **模型消息转换：** 将验证后的 UI 消息转换为智能体的内部模型消息格式。
- 3. **流式智能体输出：** 调用智能体的 `.stream({ prompt, ... })` 以获取数据块流（步骤/UI 消息），并传递诸如 `experimental_sandbox` 等选项。
- 4. **创建 HTTP 响应：** 将输出流包装为可读的 HTTP `Response` 对象，将 UI 消息块流式传输到客户端。

## 注意事项

- 你的智能体**必须**实现 `.stream({ prompt, ... })` 并定义 `tools` 属性（即使只是 `{}`）才能与此函数一起使用。
- **仅限服务端：** 此 API 仅应在后端/服务端上下文中调用（API 路由、边缘/serverless/服务端路由处理程序等）。不适用于浏览器。
- 当你的智能体工具在执行期间需要实验性沙箱环境时，请传递 `experimental_sandbox`。
- 其他选项（`headers`、`status`、UI 流选项、转换等）可用于高级场景。
- 这利用了 [ReadableStream](https://developer.mozilla.org/en-US/docs/Web/API/ReadableStream)，因此你的平台/客户端必须支持 HTTP 流式消费。
