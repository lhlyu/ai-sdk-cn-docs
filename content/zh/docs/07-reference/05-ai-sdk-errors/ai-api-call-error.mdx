# AI_APICallError

当 API 调用失败时，会发生此错误。

## 属性

- `url`：失败的 API 请求的 URL
- `requestBodyValues`：发送到 API 的请求体值
- `statusCode`：API 返回的 HTTP 状态码（可选）
- `responseHeaders`：API 返回的响应头（可选）
- `responseBody`：API 返回的响应体（可选）
- `isRetryable`：根据状态码判断该请求是否可以重试
- `data`：与该错误关联的任何附加数据（可选）
- `cause`：导致 API 调用失败的根本错误（可选）

当为 AI SDK UI 聊天传输或补全请求创建此错误时，`requestBodyValues` 为 `undefined`，因此提示词和消息不会被复制到面向客户端的错误对象中。

## 检查此错误

你可以使用以下方法检查某个错误是否为 `AI_APICallError` 的实例：

```typescript
import { APICallError } from 'ai';

if (APICallError.isInstance(error)) {
  // Handle the error
}
```
