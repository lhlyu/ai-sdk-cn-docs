# AI_InvalidToolInputError

当提供了无效的工具输入时，会触发此错误。

## 属性

- `toolName`：具有无效输入的工具名称
- `toolInput`：无效的工具输入
- `message`：错误消息
- `cause`：错误原因

## 检查此错误

你可以使用以下方法检查某个错误是否为 `AI_InvalidToolInputError` 的实例：

```typescript
import { InvalidToolInputError } from 'ai';

if (InvalidToolInputError.isInstance(error)) {
  // 处理错误
}
```
