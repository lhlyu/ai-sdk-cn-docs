# AI_JSONParseError

当 JSON 解析失败时，会触发此错误。

## 属性

- `text`：无法解析的文本值
- `cause`：底层解析错误（构造函数中必需）

## 检查此错误

你可以使用以下方法检查错误是否为 `AI_JSONParseError` 的实例：

```typescript
import { JSONParseError } from 'ai';

if (JSONParseError.isInstance(error)) {
  // 处理错误
}
```
