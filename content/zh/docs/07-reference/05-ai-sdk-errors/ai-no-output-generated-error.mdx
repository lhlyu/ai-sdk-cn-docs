# AI_NoOutputGeneratedError

当没有生成 LLM 输出时（例如由于错误），会抛出此错误。

对于 `generateText`，当结果不包含输出时，访问 `result.output` 会抛出此错误。这可能发生在最后一步未以 `stop` 原因结束时，例如以 `tool-calls` 结束时。`output` 属性是一个 getter，因此解构它也会触发此访问。

## 属性

- `message`：错误消息（可选，默认为 `'No output generated.'`）
- `cause`：导致未生成输出的底层错误（可选）

## 检查此错误

您可以使用以下方法检查错误是否为 `AI_NoOutputGeneratedError` 的实例：

```typescript
import { NoOutputGeneratedError } from 'ai';

if (NoOutputGeneratedError.isInstance(error)) {
  // 处理错误
}
```
