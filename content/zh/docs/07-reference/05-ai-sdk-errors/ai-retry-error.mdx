# AI_RetryError

当重试操作失败时，会引发此错误。

## 属性

- `reason`：重试失败的原因
- `lastError`：重试期间发生的最新错误
- `errors`：重试尝试期间发生的所有错误数组
- `message`：错误消息

## 检查此错误

你可以使用以下方法检查错误是否为 `AI_RetryError` 的实例：

```typescript
import { RetryError } from 'ai';

if (RetryError.isInstance(error)) {
  // 处理错误
}
```
