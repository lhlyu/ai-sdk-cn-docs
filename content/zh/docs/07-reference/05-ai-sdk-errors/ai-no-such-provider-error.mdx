# AI_NoSuchProviderError

当找不到某个提供商 ID 时，会发生此错误。

## 属性

- `providerId`：未找到的提供商的 ID
- `availableProviders`：可用提供商 ID 的数组
- `modelId`：模型的 ID
- `modelType`：模型的类型
- `message`：错误消息

## 检查此错误

你可以使用以下方式检查某个错误是否为 `AI_NoSuchProviderError` 的实例：

```typescript
import { NoSuchProviderError } from 'ai';

if (NoSuchProviderError.isInstance(error)) {
  // Handle the error
}
```

实验性决策解析使用 `modelType: 'decisionModel'`。这包括不可用的决策能力以及未知的决策模型或提供商 ID。请参阅[决策](/docs/ai-sdk-core/decisions#default-provider-strings)。
