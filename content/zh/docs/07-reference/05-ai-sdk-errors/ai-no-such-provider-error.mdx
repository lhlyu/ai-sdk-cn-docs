# AI_NoSuchProviderError

当未找到提供商 ID 时，会触发此错误。

## 属性

- `providerId`：未找到的提供商 ID
- `availableProviders`：可用提供商 ID 的数组
- `modelId`：模型 ID
- `modelType`：模型类型
- `message`：错误消息

## 检查此错误

你可以使用以下方法检查某个错误是否为 `AI_NoSuchProviderError` 的实例：

```typescript
import { NoSuchProviderError } from 'ai';

if (NoSuchProviderError.isInstance(error)) {
  // 处理错误
}
```
