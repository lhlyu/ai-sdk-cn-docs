# AI_LoadSettingError

当设置未能成功加载时，会触发此错误。

## 属性

- `message`：错误消息

## 检查此错误

你可以使用以下方法检查错误是否为 `AI_LoadSettingError` 的实例：

```typescript
import { LoadSettingError } from 'ai';

if (LoadSettingError.isInstance(error)) {
  // 处理错误
}
```
