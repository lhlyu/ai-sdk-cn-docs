# AI_NoTranscriptGeneratedError

当无法从输入生成转录时，会触发此错误。

## 属性

- `responses`：转录模型响应元数据数组（构造函数中必需）

## 检查此错误

您可以使用以下方法检查错误是否为 `AI_NoTranscriptGeneratedError` 的实例：

```typescript
import { NoTranscriptGeneratedError } from 'ai';

if (NoTranscriptGeneratedError.isInstance(error)) {
  // 处理错误
}
```
