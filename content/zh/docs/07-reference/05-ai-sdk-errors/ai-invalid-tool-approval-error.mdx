# AI_InvalidToolApprovalError

当工具审批响应引用了未知的 `approvalId` 时，会触发此错误。在消息历史中未找到匹配的 `tool-approval-request`。

## 属性

- `approvalId`：未找到的审批 ID

## 检查此错误

你可以使用以下方法检查某个错误是否为 `AI_InvalidToolApprovalError` 的实例：

```typescript
import { InvalidToolApprovalError } from 'ai';

if (InvalidToolApprovalError.isInstance(error)) {
  // 处理错误
}
```
