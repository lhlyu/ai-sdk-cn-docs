# AI_NoSuchModelError

当找不到模型 ID 时，会发生此错误。

## 属性

- `modelId`：未找到的模型的 ID
- `modelType`：模型类型（`'languageModel'`、`'embeddingModel'`、`'imageModel'`、`'transcriptionModel'`、`'speechModel'` 或 `'rerankingModel'`）
- `message`：错误消息（可选，根据 `modelId` 和 `modelType` 自动生成）

## 检查此错误

你可以使用以下代码检查某个错误是否为 `AI_NoSuchModelError` 的实例：

```typescript
import { NoSuchModelError } from 'ai';

if (NoSuchModelError.isInstance(error)) {
  // Handle the error
}
```

实验性决策解析使用 `modelType: 'decisionModel'`。这包括不可用的决策能力以及未知的决策模型或提供商 ID。请参阅[决策](/docs/ai-sdk-core/decisions#default-provider-strings)。
