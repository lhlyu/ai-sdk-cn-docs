# AI_NoSuchToolError

当模型尝试调用不可用的工具时，会触发此错误。

## 属性

- `toolName`：未找到的工具名称
- `availableTools`：可用工具名称数组（可选）
- `message`：错误消息（可选，根据 `toolName` 和 `availableTools` 自动生成）

## 检查此错误

您可以使用以下方法检查错误是否为 `AI_NoSuchToolError` 的实例：

```typescript
import { NoSuchToolError } from 'ai';

if (NoSuchToolError.isInstance(error)) {
  // 处理错误
}
```
