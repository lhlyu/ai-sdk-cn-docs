# AI_UIMessageStreamError

当 UI 消息流报告错误，或包含无效或顺序错误的 chunk 时，会出现此错误。

常见原因：

- 在 completion 数据流中收到 `error` chunk
- 收到 `text-delta` chunk 但没有前置的 `text-start` chunk
- 收到 `text-end` chunk 但没有前置的 `text-start` chunk
- 收到 `reasoning-delta` chunk 但没有前置的 `reasoning-start` chunk
- 收到 `reasoning-end` chunk 但没有前置的 `reasoning-start` chunk
- 收到 `tool-input-delta` chunk 但没有前置的 `tool-input-start` chunk
- 尝试访问不存在的工具调用

当上游请求在**任何 token 被流式传输之前**失败，并且自定义传输层试图在没有正确 start chunk 的情况下将内联错误消息写入 UI 流时，此错误经常会出现。

## 属性

- `chunkType`：导致错误的 chunk 类型（例如 `text-delta`、`reasoning-end`、`tool-input-delta`）
- `chunkId`：与失败 chunk 关联的 ID（part ID 或 toolCallId）。
  对于没有 ID 的 chunk（例如 completion `error` chunk），此值为空字符串。
- `message`：包含出错详情的错误消息

## 检查此错误

你可以使用以下方式检查某个错误是否为 `AI_UIMessageStreamError` 的实例：

```typescript
import { UIMessageStreamError } from 'ai';

if (UIMessageStreamError.isInstance(error)) {
  console.log('Chunk type:', error.chunkType);
  console.log('Chunk ID:', error.chunkId);
  // Handle the error
}
```

## 常见解决方案

1. **确保正确的 chunk 顺序**：对于同一个 ID，始终在任何 `*-delta` 或 `*-end` chunk 之前发送 `*-start` chunk：

   ```typescript
   // Correct order
   writer.write({ type: 'text-start', id: 'my-text' });
   writer.write({ type: 'text-delta', id: 'my-text', delta: 'Hello' });
   writer.write({ type: 'text-end', id: 'my-text' });
   ```

2. **验证 ID 匹配**：确保 `*-delta` 和 `*-end` chunk 中使用的 `id` 与对应的 `*-start` chunk 中使用的 `id` 匹配。

3. **正确处理错误路径**：在自定义传输层中写入错误消息时，确保发出完整的 start/delta/end 序列：

   ```typescript
   // When handling errors in custom transports
   writer.write({ type: 'text-start', id: errorId });
   writer.write({
     type: 'text-delta',
     id: errorId,
     delta: 'Request failed...',
   });
   writer.write({ type: 'text-end', id: errorId });
   ```

4. **检查流生产者逻辑**：审查你的流式传输实现，确保 chunk 按正确顺序发送，尤其是在处理并发操作或合并流时。
