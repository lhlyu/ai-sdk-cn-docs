# AI_InvalidArgumentError

当提供了无效参数时，会发生此错误。

例如，当 `getTextFromDataUrl` 的 `dataUrl` 参数格式错误或无法解码时，它会抛出此错误。供更高级别 API 使用的实用工具校验也会使用此错误，因此你可以用一个稳定的错误守卫来处理无效参数。

## 属性

- `parameter`：无效参数的名称
- `value`：无效的值
- `message`：错误消息

## 检查此错误

你可以使用以下方式检查某个错误是否为 `AI_InvalidArgumentError` 的实例：

```typescript
import { InvalidArgumentError } from 'ai';

if (InvalidArgumentError.isInstance(error)) {
  console.error(`Invalid ${error.parameter}:`, error.message);
}
```
