# AI_InvalidArgumentError

当提供了无效参数时，会触发此错误。

## 属性

- `parameter`：无效参数的名称
- `value`：无效的值
- `message`：错误消息

## 检查此错误

你可以使用以下方法检查错误是否为 `AI_InvalidArgumentError` 的实例：

```typescript
import { InvalidArgumentError } from 'ai';

if (InvalidArgumentError.isInstance(error)) {
  // 处理错误
}
```
