# AI_LoadAPIKeyError

当 API 密钥未能成功加载时，会触发此错误。

## 属性

- `message`：错误消息

## 检查此错误

你可以使用以下方法检查错误是否为 `AI_LoadAPIKeyError` 的实例：

```typescript
import { LoadAPIKeyError } from 'ai';

if (LoadAPIKeyError.isInstance(error)) {
  // 处理错误
}
```
