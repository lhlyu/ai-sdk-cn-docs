# AI SDK 错误

AI SDK 提供类型化错误，使应用程序无需匹配错误消息字符串即可处理预期的失败模式。

## 导入错误

应用程序包名为 `ai`，而非 `@ai-sdk/ai`。它重新导出了来自 `@ai-sdk/provider` 的常见提供商级错误，以及由 AI SDK Core 抛出的更高级别错误：

```typescript
import { APICallError, NoObjectGeneratedError } from 'ai';
```

直接依赖 `@ai-sdk/provider` 的提供商实现可以从该包导入其提供商级错误：

```typescript
import { APICallError, InvalidResponseDataError } from '@ai-sdk/provider';
```

## 迁移到类型化错误处理

将消息匹配或无条件的通用 `catch` 块替换为最具体的静态 `isInstance` 守卫。当需要为任何 AI SDK 错误提供回退时，最后检查 `AISDKError`：

```typescript
import { AISDKError, APICallError, generateText } from 'ai';

try {
  await generateText({
    model,
    prompt: 'Write a vegetarian lasagna recipe for 4 people.',
  });
} catch (error) {
  if (APICallError.isInstance(error)) {
    console.error('Provider request failed:', error.statusCode);
    return;
  }

  if (AISDKError.isInstance(error)) {
    console.error('AI SDK error:', error.name);
    return;
  }

  throw error;
}
```

当类提供 `ErrorClass.isInstance(error)` 时，优先使用它而非 `error instanceof ErrorClass`。静态守卫在加载多个 AI SDK 包版本时同样有效。

## 常见失败模式

| 失败模式                                                                               | 需要检查的错误                                                                                                                                                                                                                                                                              |
| -------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 提供商请求因网络错误或非成功响应而失败                                                 | [`APICallError`](/docs/reference/ai-sdk-errors/ai-api-call-error)                                                                                                                                                                                                                           |
| 自动重试已耗尽                                                                         | [`RetryError`](/docs/reference/ai-sdk-errors/ai-retry-error)                                                                                                                                                                                                                                |
| 提供商在响应流开始后报告错误                                                           | [`StreamProviderError`](/docs/reference/ai-sdk-errors/ai-stream-provider-error)                                                                                                                                                                                                             |
| 结构化输出无法解析或验证                                                               | [`NoObjectGeneratedError`](/docs/reference/ai-sdk-errors/ai-no-object-generated-error)；检查其 `cause` 以获取 [`JSONParseError`](/docs/reference/ai-sdk-errors/ai-json-parse-error) 或 [`TypeValidationError`](/docs/reference/ai-sdk-errors/ai-type-validation-error)                    |
| 生成调用未返回可用输出                                                                 | [`NoOutputGeneratedError`](/docs/reference/ai-sdk-errors/ai-no-output-generated-error) 或特定模态的 `No*GeneratedError`                                                                                                                                                                     |
| 模型调用了不存在的工具或提供了无效的工具输入                                           | [`NoSuchToolError`](/docs/reference/ai-sdk-errors/ai-no-such-tool-error) 或 [`InvalidToolInputError`](/docs/reference/ai-sdk-errors/ai-invalid-tool-input-error)                                                                                                                            |
| 工具调用修复失败                                                                       | [`ToolCallRepairError`](/docs/reference/ai-sdk-errors/ai-tool-call-repair-error)                                                                                                                                                                                                            |
| 响应违反了强制执行的 `toolChoice`                                                      | [`ToolChoiceViolationError`](/docs/reference/ai-sdk-errors/ai-tool-choice-violation-error)                                                                                                                                                                                                  |
| 消息历史包含未解析的工具调用或无效的审批                                                 | [`MissingToolResultsError`](/docs/troubleshooting/missing-tool-results-error)、[`InvalidToolApprovalError`](/docs/reference/ai-sdk-errors/ai-invalid-tool-approval-error) 或 [`InvalidToolApprovalSignatureError`](/docs/reference/ai-sdk-errors/ai-invalid-tool-approval-signature-error) |
| 无法解析提供商或模型                                                                   | [`NoSuchProviderError`](/docs/reference/ai-sdk-errors/ai-no-such-provider-error)、[`NoSuchModelError`](/docs/reference/ai-sdk-errors/ai-no-such-model-error) 或 [`NoSuchProviderReferenceError`](/docs/reference/ai-sdk-errors/ai-no-such-provider-reference-error)                        |
| 提供商响应为空、格式错误或无效                                                         | [`EmptyResponseBodyError`](/docs/reference/ai-sdk-errors/ai-empty-response-body-error)、[`JSONParseError`](/docs/reference/ai-sdk-errors/ai-json-parse-error) 或 [`InvalidResponseDataError`](/docs/reference/ai-sdk-errors/ai-invalid-response-data-error)                                |
| 请求的模型或提供商不支持某项功能或规范版本                                             | [`UnsupportedFunctionalityError`](/docs/reference/ai-sdk-errors/ai-unsupported-functionality-error) 或 [`UnsupportedModelVersionError`](/docs/troubleshooting/unsupported-model-version)                                                                                                    |
| UI 消息无法转换或 UI 消息流无效                                                        | [`MessageConversionError`](/docs/reference/ai-sdk-errors/ai-message-conversion-error) 或 [`UIMessageStreamError`](/docs/reference/ai-sdk-errors/ai-ui-message-stream-error)                                                                                                                 |
