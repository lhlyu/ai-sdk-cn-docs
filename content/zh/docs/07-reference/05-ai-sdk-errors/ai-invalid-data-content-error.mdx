# AI_InvalidDataContentError

当多模态消息部分中提供的数据内容无效时，会触发此错误。请查看[多模态消息的提示词示例](/docs/foundations/prompts#message-prompts)。

## 属性

- `content`：无效的内容值
- `cause`：导致此错误的底层错误（可选）
- `message`：描述预期和实际接收内容类型的错误消息（可选，自动生成）

## 检查此错误

你可以使用以下方法检查某个错误是否为 `AI_InvalidDataContentError` 的实例：

```typescript
import { InvalidDataContentError } from 'ai';

if (InvalidDataContentError.isInstance(error)) {
  // 处理错误
}
```
