# AI_InvalidToolApprovalSignatureError

当配置了 `experimental_toolApprovalSecret`，且从消息历史中重放的工具审批缺少或包含无效的 HMAC 签名时，会触发此错误。服务器会在工具执行前拒绝该审批。

常见原因：

- 审批由客户端伪造（缺少签名）
- 工具参数在审批签名后被修改
- 服务器密钥在签发与验证之间发生变更（例如，密钥轮换时未设置重叠期）

## 属性

- `approvalId`：验证失败的审批 ID
- `toolCallId`：该审批对应的工具调用 ID

## 检查此错误

你可以使用以下方法检查错误是否为 `AI_InvalidToolApprovalSignatureError` 的实例：

```typescript
import { InvalidToolApprovalSignatureError } from 'ai';

if (InvalidToolApprovalSignatureError.isInstance(error)) {
  // 处理错误
}
```
