# AI_InvalidResponseDataError

当服务器返回包含无效数据内容的响应时，会触发此错误。

## 属性

- `data`：无效的响应数据值
- `message`：错误消息

## 检查此错误

你可以使用以下方法检查错误是否为 `AI_InvalidResponseDataError` 的实例：

```typescript
import { InvalidResponseDataError } from 'ai';

if (InvalidResponseDataError.isInstance(error)) {
  // 处理错误
}
```
