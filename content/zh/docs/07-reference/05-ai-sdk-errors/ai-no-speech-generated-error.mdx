# AI_NoSpeechGeneratedError

当无法从输入生成音频时，会触发此错误。

## 属性

- `responses`：语音模型响应元数据数组（构造函数中必需）

## 检查此错误

你可以使用以下方法检查错误是否为 `AI_NoSpeechGeneratedError` 的实例：

```typescript
import { NoSpeechGeneratedError } from 'ai';

if (NoSpeechGeneratedError.isInstance(error)) {
  // 处理错误
}
```
