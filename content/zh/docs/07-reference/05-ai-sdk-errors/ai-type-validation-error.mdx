# AI_TypeValidationError

当类型验证失败时，会触发此错误。

## 属性

- `value`：验证失败的值
- `cause`：底层的验证错误（构造函数中必需）

## 检查此错误

你可以使用以下方法检查错误是否为 `AI_TypeValidationError` 的实例：

```typescript
import { TypeValidationError } from 'ai';

if (TypeValidationError.isInstance(error)) {
  // 处理错误
}
```
