# AI_NoTranslationGeneratedError

当无法从输入音频生成翻译时，会出现此错误：
没有发出 `audio` 部分，且最终输出文本为空，或者流在没有结束事件的情况下终止。

## 属性

- `response`：语音翻译模型响应元数据（构造函数中必填）

## 检查此错误

你可以使用以下方法检查错误是否为 `AI_NoTranslationGeneratedError` 的实例：

```typescript
import { NoTranslationGeneratedError } from 'ai';

if (NoTranslationGeneratedError.isInstance(error)) {
  // 处理错误
}
```
