# AI SDK 工作流

[`@ai-sdk/workflow`](/docs/agents/workflow-agent) 提供了 `WorkflowAgent` 类，用于构建在工作流中运行的持久、可恢复的 AI 智能体。它处理工具模式序列化、工作流步骤边界以及内置的工具审批流程。
