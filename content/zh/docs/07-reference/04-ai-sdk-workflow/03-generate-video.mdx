# `generateVideo()`

在工作流内部持久地生成视频。该辅助函数会使用 Workflow webhook URL 启动一个异步视频生成任务，暂停工作流直到提供商发送终止通知，然后通过一次状态请求获取完成的结果。

与 `ai` 中的 [`experimental_generateVideo`](/docs/reference/ai-sdk-core/generate-video) 不同，此辅助函数不会下载提供商托管的视频。URL 结果保持为 URL，以便你的工作流可以决定是否在另一个步骤中持久化、复制或处理它们，而无需将视频字节序列化穿过工作流步骤边界。

```ts
import { experimental_generateVideo as generateVideo } from '@ai-sdk/workflow/video';

export async function videoWorkflow(prompt: string) {
  'use workflow';

  // 视频渲染期间工作流会挂起，不消耗计算资源。
  const result = await generateVideo({
    model: 'klingai/kling-v3.0-t2v',
    prompt,
  });

  return result.videos;
}
```

所选模型必须支持异步启动和状态操作以及提供商 webhook。该辅助函数必须从 Workflow SDK 工作流中调用。

## 返回值

返回提供商的完成状态结果。`videos` 包含按 `type` 区分的原始提供商视频数据：

- `url`：提供商托管的 URL 和媒体类型
- `base64`：Base64 编码的视频数据和媒体类型
- `binary`：`Uint8Array` 和媒体类型

托管的 URL 可能会过期。请在单独的工作流步骤中处理你需要保留的任何视频。
