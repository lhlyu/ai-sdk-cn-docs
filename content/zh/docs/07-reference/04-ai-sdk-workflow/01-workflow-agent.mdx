# `WorkflowAgent`

创建一个持久、可恢复的 AI 智能体，用于工作流内部。`WorkflowAgent` 处理智能体循环、跨工作流步骤边界的工具 schema 序列化，以及内置的工具审批流程。

与 `ai` 包中的 [`ToolLoopAgent`](/docs/reference/ai-sdk-core/tool-loop-agent) 不同，`WorkflowAgent` 设计用于在进程重启后存活、暂停等待人工审批，并与 Workflow DevKit 的步骤机制集成。

`WorkflowAgent` 支持 `runtimeContext` 用于共享智能体状态，以及 `toolsContext` 用于每个工具的上下文。由于这些值可以跨越工作流和步骤边界，请保持它们为可序列化的持久数据。与 `ToolLoopAgent` 不同，不要在上下文中放置函数、类实例、符号、数据库客户端或 SDK 客户端；请传递标识符或配置，并在步骤函数内部重新创建不可序列化的资源。

```ts
import { WorkflowAgent } from '@ai-sdk/workflow';
import { tool } from 'ai';
import { z } from 'zod';

const agent = new WorkflowAgent({
  model: 'anthropic/claude-sonnet-4-6',
  instructions: 'You are a helpful assistant.',
  tools: {
    weather: tool({
      description: 'Get the weather in a location',
      inputSchema: z.object({
        location: z.string(),
      }),
      execute: async ({ location }) => ({
        location,
        temperature: 72,
      }),
    }),
  },
});

const result = await agent.stream({
  messages: [
    {
      role: 'user',
      content: [{ type: 'text', text: 'What is the weather in NYC?' }],
    },
  ],
});

console.log(result.messages);
```

要查看 `WorkflowAgent` 的实际应用，请查看[这些示例](#examples)。

### `stream()`

运行智能体循环，流式传输响应并根据需要执行工具调用。返回一个解析为 `WorkflowAgentStreamResult` 的 Promise。

```ts
const result = await agent.stream({
  messages: [{ role: 'user', content: [{ type: 'text', text: 'Hello' }] }],
});
```

## 工具函数

### `createModelCallToUIChunkTransform(options?)`

创建一个 `TransformStream`，将原始 `ModelCallStreamPart` 块（智能体写入 `writable` 流的）转换为适合客户端消费的 `UIMessageChunk` 对象。

```ts
import { createModelCallToUIChunkTransform } from '@ai-sdk/workflow';

return createUIMessageStreamResponse({
  stream: run.readable.pipeThrough(createModelCallToUIChunkTransform()),
});
```

使用 `WorkflowChatTransport` 游标恢复时，从索引 `0` 重放原始工作流流，并将非负的 UI 块索引传递给转换器：

```ts
const readable = run
  .getReadable({ startIndex: 0 })
  .pipeThrough(createModelCallToUIChunkTransform({ uiStartIndex: startIndex }));
```

`uiStartIndex` 必须是非负安全整数。原始模型流部分和 UI 消息块不是一一对应的，因此不要将 UI 块索引传递给 `getReadable`。负尾部索引需要已经存储 `UIMessageChunk` 对象的持久流。

### `toUIMessageChunk()`

将单个 `ModelCallStreamPart` 转换为 `UIMessageChunk`。对于不映射到 UI 块的部分返回 `undefined`。

```ts
import { toUIMessageChunk } from '@ai-sdk/workflow';

const uiChunk = toUIMessageChunk(modelCallPart);
```

## 类型

### `ActiveTools`

```ts
type ActiveTools<TTools extends ToolSet> =
  | ReadonlyArray<keyof TTools & string>
  | undefined;
```

将工作流智能体调用限制为列出的工具名称。`undefined` 表示不应用工具限制。

### `InferWorkflowAgentUIMessage`

推断 `WorkflowAgent` 实例的 UI 消息类型。可选地接受第二个类型参数用于自定义消息元数据。

```ts
import { WorkflowAgent, InferWorkflowAgentUIMessage } from '@ai-sdk/workflow';

const agent = new WorkflowAgent({
  model: 'anthropic/claude-sonnet-4-6',
  tools: { weather: weatherTool },
});

type MyAgentUIMessage = InferWorkflowAgentUIMessage<typeof agent>;
```

### `InferWorkflowAgentTools`

推断 `WorkflowAgent` 实例的工具集类型。

```ts
import { WorkflowAgent, InferWorkflowAgentTools } from '@ai-sdk/workflow';

type MyTools = InferWorkflowAgentTools<typeof myAgent>;
```

### 工作流中使用持久工具的智能体

```ts filename="workflow/agent-chat.ts"
import { WorkflowAgent, type ModelCallStreamPart } from '@ai-sdk/workflow';
import { convertToModelMessages, tool, type UIMessage } from 'ai';
import { getWritable } from 'workflow';
import { z } from 'zod';

// 标记为 'use step' 的工具 execute 函数成为持久工作流步骤，
// 具有自动重试和持久化能力
async function searchFlightsStep(input: {
  origin: string;
  destination: string;
}) {
  'use step';
  const response = await fetch(`https://api.flights.example/search?...`);
  return response.json();
}

export async function chat(messages: UIMessage[]) {
  'use workflow';

  const modelMessages = await convertToModelMessages(messages);

  const agent = new WorkflowAgent({
    model: 'anthropic/claude-sonnet-4-6',
    instructions: 'You are a flight booking assistant.',
    tools: {
      searchFlights: tool({
        description: 'Search for available flights',
        inputSchema: z.object({
          origin: z.string(),
          destination: z.string(),
        }),
        execute: searchFlightsStep,
      }),
    },
  });

  const result = await agent.stream({
    messages: modelMessages,
    writable: getWritable<ModelCallStreamPart>(),
  });

  return { messages: result.messages };
}
```

```ts filename="app/api/chat/route.ts"
import { createModelCallToUIChunkTransform } from '@ai-sdk/workflow';
import { createUIMessageStreamResponse, type UIMessage } from 'ai';
import { start } from 'workflow/api';
import { chat } from '@/workflow/agent-chat';

export async function POST(request: Request) {
  const { messages }: { messages: UIMessage[] } = await request.json();

  const run = await start(chat, [messages]);

  return createUIMessageStreamResponse({
    stream: run.readable.pipeThrough(createModelCallToUIChunkTransform()),
  });
}
```

### 带工具审批的智能体

对于 `WorkflowAgent`，工具审批在工具定义上使用 `needsApproval` 配置。对于 `generateText`、`streamText` 和 `ToolLoopAgent`，请改用 `toolApproval`。

```ts
import { WorkflowAgent } from '@ai-sdk/workflow';
import { tool } from 'ai';
import { z } from 'zod';

const agent = new WorkflowAgent({
  model: 'anthropic/claude-sonnet-4-6',
  experimental_toolApprovalSecret: {
    environmentVariable: 'TOOL_APPROVAL_SECRET',
  },
  tools: {
    bookFlight: tool({
      description: 'Book a flight',
      inputSchema: z.object({
        flightId: z.string(),
        passengerName: z.string(),
      }),
      needsApproval: true, // 暂停智能体直到用户批准
      execute: bookFlightStep,
    }),
  },
});
```

当配置了 `experimental_toolApprovalSecret` 时，每个审批请求都会在其审批 ID、工具调用 ID、工具名称和已验证输入上进行签名。缺少或签名无效的重放审批不会执行工具。签名保留在持久流和 UI 消息历史中，而只有环境变量名称会跨越工作流边界。签名和验证步骤从其本地环境读取原始密钥，并且不会序列化它。流级引用会覆盖构造函数值。

### 带生命周期回调的智能体

```ts
import { WorkflowAgent } from '@ai-sdk/workflow';

const agent = new WorkflowAgent({
  model: 'anthropic/claude-sonnet-4-6',
  tools: { weather: weatherTool },

  // 智能体级回调
  onStepEnd({ usage }) {
    console.log('Tokens used:', usage.totalTokens);
  },
});

const result = await agent.stream({
  messages,

  // 每次调用回调（两者都会触发）
  onStepEnd({ usage }) {
    await trackUsage(usage);
  },

  onEnd({ steps, totalUsage }) {
    console.log(
      `Done in ${steps.length} steps, ${totalUsage.totalTokens} tokens`,
    );
  },
});
```
