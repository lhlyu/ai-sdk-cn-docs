# `WorkflowChatTransport`

一个用于 [`useChat`](/docs/reference/ai-sdk-ui/use-chat) 的 [`ChatTransport`](/docs/ai-sdk-ui/transport) 实现，可为基于工作流的聊天应用启用自动流重连。它向聊天端点发送消息，提取 `x-workflow-run-id` 响应头，并在发生中断（网络故障、页面刷新、函数超时）时重新连接到 `/{runId}/stream` 端点。

与假设完整响应通过单个 HTTP 请求到达的 [`DefaultChatTransport`](/docs/ai-sdk-ui/transport) 不同，`WorkflowChatTransport` 专为 [Workflow SDK](https://vercel.com/docs/workflow) 设计，在该 SDK 中，初始响应流可能因函数超时而中断。该传输层会自动检测缺失的 `finish` 事件并重新连接，以从流中断处恢复。

```tsx
'use client';

import { useChat } from '@ai-sdk/react';
import { WorkflowChatTransport } from '@ai-sdk/workflow';

export default function Chat() {
  const { messages, sendMessage } = useChat({
    transport: new WorkflowChatTransport({
      api: '/api/chat',
      maxConsecutiveErrors: 5,
      initialStartIndex: -50,
    }),
  });

  // ... 渲染聊天 UI
}
```

## 方法

### `sendMessages()`

通过 POST 向聊天端点发送消息并返回流式响应。如果流被中断（未收到 `finish` 事件），传输层会自动通过 GET 请求重新连接到 `{api}/{runId}/stream?startIndex={chunkIndex}`，以从中断处恢复。

POST 请求将消息作为 JSON 发送，并期望响应包含标识工作流运行的 `x-workflow-run-id` 头。

```ts
const stream = await transport.sendMessages({
  chatId: 'chat-123',
  trigger: 'submit-message',
  messages: [...],
  abortSignal: controller.signal,
});
```

#### 返回值

返回一个 `Promise<ReadableStream<UIMessageChunk>>`，包含来自初始 POST 响应和任何自动重连的块。

### `reconnectToStream()`

重新连接到之前中断的现有聊天流。适用于页面刷新后恢复，或客户端需要重新建立连接时。

```ts
const stream = await transport.reconnectToStream({
  chatId: 'chat-123',
  startIndex: -50, // 可选：获取最后 50 个块
});
```

## 重连机制

传输层遵循以下流程：

1. **POST** 到 `{api}` 并携带消息。响应必须包含 `x-workflow-run-id` 头。
2. **流式传输** SSE 响应，计数到达的块。
3. **检测中断**：如果流在没有 `finish` 事件的情况下关闭（例如，函数超时、网络错误），传输层会知道响应不完整。
4. **重连**：通过 GET 请求到 `{api}/{runId}/stream?startIndex={chunkIndex}`，从最后接收的块恢复。
5. **重试**：如果重连流也中断，最多重试 `maxConsecutiveErrors` 次。
6. **完成**：一旦收到 `finish` 事件，调用 `onChatEnd` 并关闭流。

### 负起始索引

当 `initialStartIndex` 为负值时（例如，`-50`），传输层会原样发送到第一个重连请求。服务器应将其解析为绝对位置，并返回 `x-workflow-stream-tail-index` 响应头，以便传输层为后续重试计算正确位置。

如果该头缺失或无效，传输层会回退到从头开始重放（`startIndex=0`）。

## 服务器要求

要使 `WorkflowChatTransport` 正常工作，您的服务器必须提供两个端点：

### POST `{api}`（例如，`/api/chat`）

- 接受 JSON 格式的消息体
- 返回 `UIMessageChunk` 事件的 SSE 流
- 包含 `x-workflow-run-id` 响应头

### GET `{api}/{runId}/stream`（例如，`/api/chat/{runId}/stream`）

- 接受 `startIndex` 查询参数
- 返回从给定块索引开始的 SSE 流
- 对于负的 `startIndex`，解析为尾部并包含 `x-workflow-stream-tail-index` 响应头

有关完整的端点示例，请参阅 [WorkflowAgent 指南](/docs/agents/workflow-agent)。

## 示例

### 与 useChat 的基本用法

```tsx
'use client';

import { useChat } from '@ai-sdk/react';
import { WorkflowChatTransport } from '@ai-sdk/workflow';
import { useMemo } from 'react';

export default function Chat() {
  const transport = useMemo(
    () => new WorkflowChatTransport({ api: '/api/chat' }),
    [],
  );

  const { messages, sendMessage, status } = useChat({ transport });

  return (
    <div>
      {messages.map(message => (
        <div key={message.id}>
          {message.role === 'user' ? '用户: ' : 'AI: '}
          {message.parts.map((part, index) =>
            part.type === 'text' ? <span key={index}>{part.text}</span> : null,
          )}
        </div>
      ))}
      <button onClick={() => sendMessage({ text: '你好！' })}>发送</button>
    </div>
  );
}
```

### 带回调与页面刷新恢复

```tsx
'use client';

import { useChat } from '@ai-sdk/react';
import { WorkflowChatTransport } from '@ai-sdk/workflow';
import { useMemo } from 'react';

export default function Chat() {
  const transport = useMemo(
    () =>
      new WorkflowChatTransport({
        api: '/api/chat',
        maxConsecutiveErrors: 5,
        initialStartIndex: -50, // 页面刷新后从最后 50 个块恢复
        onChatSendMessage: response => {
          const runId = response.headers.get('x-workflow-run-id');
          console.log('工作流运行已启动:', runId);
        },
        onChatEnd: ({ chatId, chunkIndex }) => {
          console.log(`聊天 ${chatId} 完成，共 ${chunkIndex} 个块`);
        },
      }),
    [],
  );

  const { messages, sendMessage } = useChat({ transport });

  // ... 渲染聊天 UI
}
```

### 服务端端点 (Next.js)

```ts filename="app/api/chat/route.ts"
import { createModelCallToUIChunkTransform } from '@ai-sdk/workflow';
import { createUIMessageStreamResponse, type UIMessage } from 'ai';
import { start } from 'workflow/api';
import { chat } from '@/workflow/agent-chat';

export async function POST(request: Request) {
  const { messages }: { messages: UIMessage[] } = await request.json();
  const run = await start(chat, [messages]);

  return createUIMessageStreamResponse({
    stream: run.readable.pipeThrough(createModelCallToUIChunkTransform()),
    headers: {
      'x-workflow-run-id': run.runId,
    },
  });
}
```

```ts filename="app/api/chat/[runId]/stream/route.ts"
import { createModelCallToUIChunkTransform } from '@ai-sdk/workflow';
import type { NextRequest } from 'next/server';
import { getRun } from 'workflow/api';

export async function GET(
  request: NextRequest,
  { params }: { params: Promise<{ runId: string }> },
) {
  const { runId } = await params;
  const startIndex = Number(
    new URL(request.url).searchParams.get('startIndex') ?? '0',
  );

  const run = await getRun(runId);
  const readable = run
    .getReadable({ startIndex })
    .pipeThrough(createModelCallToUIChunkTransform());

  return new Response(readable, {
    headers: {
      'Content-Type': 'text/event-stream',
      'Cache-Control': 'no-cache',
      Connection: 'keep-alive',
      'x-workflow-run-id': runId,
    },
  });
}
```
