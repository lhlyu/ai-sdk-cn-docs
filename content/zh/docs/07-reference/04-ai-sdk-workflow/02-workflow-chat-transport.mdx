# `WorkflowChatTransport`

一个用于 [`useChat`](/docs/reference/ai-sdk-ui/use-chat) 的 [`ChatTransport`](/docs/ai-sdk-ui/transport) 实现，可为基于工作流的聊天应用启用自动流重连。它将消息发送到聊天端点，提取 `x-workflow-run-id` 响应头，并在中断（网络故障、页面刷新、函数超时）时重新连接到 `/{runId}/stream` 端点。

与假设完整响应在单个 HTTP 请求中到达的 [`DefaultChatTransport`](/docs/ai-sdk-ui/transport) 不同，`WorkflowChatTransport` 专为 [Workflow SDK](https://vercel.com/docs/workflow) 设计，在该 SDK 中，初始响应流可能会因函数超时而中断。该传输层会自动检测缺失的 `finish` 事件，并重新连接以从流中断处恢复。

```tsx
'use client';

import { useChat } from '@ai-sdk/react';
import { WorkflowChatTransport } from '@ai-sdk/workflow';

export default function Chat() {
  const { messages, sendMessage } = useChat({
    transport: new WorkflowChatTransport({
      api: '/api/chat',
      maxConsecutiveErrors: 5,
    }),
  });

  // ... 渲染聊天 UI
}
```

## 方法

### `sendMessages()`

通过 POST 将消息发送到聊天端点并返回流式响应。如果流被中断（未收到 `finish` 事件），传输层会自动通过 GET 重新连接到 `{api}/{runId}/stream?startIndex={chunkIndex}`，以从上次中断处恢复。

POST 请求将消息作为 JSON 包含在内，并期望响应包含标识工作流运行的 `x-workflow-run-id` 头。

```ts
const stream = await transport.sendMessages({
  chatId: 'chat-123',
  trigger: 'submit-message',
  messages: [...],
  abortSignal: controller.signal,
});
```

## 重连工作原理

传输层遵循以下流程：

1. **POST** 到 `{api}` 并携带消息。响应必须包含 `x-workflow-run-id` 头。
2. **流式传输** SSE 响应，在块到达时计数。
3. **检测中断**：如果流在没有 `finish` 事件的情况下关闭（例如，函数超时、网络错误），传输层会知道响应不完整。
4. **重连** 通过 GET 到 `{api}/{runId}/stream?startIndex={chunkIndex}`，从最后接收的块恢复。
5. **重试**：如果重连流也中断，则重试最多 `maxConsecutiveErrors` 次。
6. **完成**：一旦收到 `finish` 事件，调用 `onChatEnd` 并关闭流。

### 负起始索引

当 `initialStartIndex` 为负值（例如，`-50`）时，传输层会在第一次重连请求中按原样发送。服务器应将其解析为绝对位置，并返回 `x-workflow-stream-tail-index` 响应头，以便传输层为后续重试计算正确的位置。

如果该头缺失或无效，传输层会回退到从头重放（`startIndex=0`）。

负索引需要持久化的服务器流，其存储的对象已经是 `UIMessageChunk` 对象。下面显示的原始 `WorkflowAgent` 转换仅支持非负索引。

## 服务器要求

要使 `WorkflowChatTransport` 正常工作，您的服务器必须提供两个端点：

### POST `{api}`（例如，`/api/chat`）

- 接受 JSON 格式的消息体
- 返回 `UIMessageChunk` 事件的 SSE 流
- 包含 `x-workflow-run-id` 响应头

### GET `{api}/{runId}/stream`（例如，`/api/chat/{runId}/stream`）

- 接受 `startIndex` 查询参数
- 返回从给定块索引开始的 SSE 流
- 对于负 `startIndex`，解析到尾部并包含 `x-workflow-stream-tail-index` 响应头

有关完整的端点示例，请参阅 [WorkflowAgent 指南](/docs/agents/workflow-agent)。

## 示例

### 与 useChat 的基本用法

```tsx
'use client';

import { useChat } from '@ai-sdk/react';
import { WorkflowChatTransport } from '@ai-sdk/workflow';
import { useMemo } from 'react';

export default function Chat() {
  const transport = useMemo(
    () => new WorkflowChatTransport({ api: '/api/chat' }),
    [],
  );

  const { messages, sendMessage, status } = useChat({ transport });

  return (
    <div>
      {messages.map(message => (
        <div key={message.id}>
          {message.role === 'user' ? '用户：' : 'AI：'}
          {message.parts.map((part, index) =>
            part.type === 'text' ? <span key={index}>{part.text}</span> : null,
          )}
        </div>
      ))}
      <button onClick={() => sendMessage({ text: '你好！' })}>发送</button>
    </div>
  );
}
```

```tsx
'use client';

import { useChat } from '@ai-sdk/react';
import { WorkflowChatTransport } from '@ai-sdk/workflow';
import { useMemo } from 'react';

export default function Chat() {
  const transport = useMemo(
    () =>
      new WorkflowChatTransport({
        api: '/api/chat',
        maxConsecutiveErrors: 5,
        onChatSendMessage: response => {
          const runId = response.headers.get('x-workflow-run-id');
          console.log('工作流运行已开始：', runId);
        },
        onChatEnd: ({ chatId, chunkIndex }) => {
          console.log(`聊天 ${chatId} 已完成，共 ${chunkIndex} 个块`);
        },
      }),
    [],
  );

  const { messages, sendMessage } = useChat({ transport });

  // ... 渲染聊天 UI
}
```

### 服务器端端点（Next.js）

```ts filename="app/api/chat/route.ts"
import { createModelCallToUIChunkTransform } from '@ai-sdk/workflow';
import { createUIMessageStreamResponse, type UIMessage } from 'ai';
import { start } from 'workflow/api';
import { chat } from '@/workflow/agent-chat';

export async function POST(request: Request) {
  const { messages }: { messages: UIMessage[] } = await request.json();
  const run = await start(chat, [messages]);

  return createUIMessageStreamResponse({
    stream: run.readable.pipeThrough(createModelCallToUIChunkTransform()),
    headers: {
      'x-workflow-run-id': run.runId,
    },
  });
}
```

```ts filename="app/api/chat/[runId]/stream/route.ts"
import { createModelCallToUIChunkTransform } from '@ai-sdk/workflow';
import { createUIMessageStreamResponse } from 'ai';
import type { NextRequest } from 'next/server';
import { getRun } from 'workflow/api';

export async function GET(
  request: NextRequest,
  { params }: { params: Promise<{ runId: string }> },
) {
  const { runId } = await params;
  const startIndex = Number(
    new URL(request.url).searchParams.get('startIndex') ?? '0',
  );
  if (!Number.isSafeInteger(startIndex) || startIndex < 0) {
    return Response.json(
      { error: 'startIndex 必须是非负安全整数' },
      { status: 400 },
    );
  }

  const run = await getRun(runId);
  const readable = run
    .getReadable({ startIndex: 0 })
    .pipeThrough(
      createModelCallToUIChunkTransform({ uiStartIndex: startIndex }),
    );

  return createUIMessageStreamResponse({
    stream: readable,
    headers: {
      'x-workflow-run-id': runId,
    },
  });
}
```

此 `WorkflowAgent` 端点从索引 `0` 开始重放原始 `ModelCallStreamPart` 对象，然后在将它们转换为 `UIMessageChunk` 对象后应用传输层的非负游标。负起始索引需要持久化的流，其存储的对象已经是 `UIMessageChunk` 对象。
