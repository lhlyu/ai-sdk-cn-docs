# 推理

许多语言模型在生成响应之前支持一个内部的“推理”阶段（有时也称为“思考”）。AI SDK 在 [`generateText`](/docs/reference/ai-sdk-core/generate-text) 和 [`streamText`](/docs/reference/ai-sdk-core/stream-text) 上提供了一个顶层 `reasoning` 参数，通过一个单一且可移植的设置，在各大提供商之间控制这一行为。

## 基本用法

```ts
import { generateText } from 'ai';

const { text, reasoning, reasoningText } = await generateText({
  model: 'anthropic/claude-sonnet-5.5',
  reasoning: 'medium',
  prompt: 'How many people will live in the world in 2040?',
});
```

`reasoning` 参数接受以下值：

| 值                   | 行为                                                             |
| -------------------- | -------------------------------------------------------------------- |
| `'provider-default'` | 使用提供商的默认推理行为（省略时的默认值） |
| `'none'`             | 禁用推理                                                    |
| `'minimal'`          | 最低限度的推理                                               |
| `'low'`              | 快速、简洁的推理                                              |
| `'medium'`           | 均衡的推理                                                   |
| `'high'`             | 详尽的推理                                                   |
| `'xhigh'`            | 最大程度的推理                                                    |

## 流式传输

`reasoning` 参数在 `streamText` 中的工作方式相同：

```ts
import { streamText } from 'ai';

const result = streamText({
  model: 'google/gemini-3.8-flash',
  reasoning: 'high',
  prompt: 'Explain the Riemann hypothesis in simple terms.',
});

for await (const part of result.stream) {
  if (part.type === 'reasoning') {
    process.stdout.write(part.textDelta);
  } else if (part.type === 'text-delta') {
    process.stdout.write(part.textDelta);
  }
}
```

## 优先级规则

顶层 `reasoning` 参数与提供商特定的 `providerOptions` **永远不会合并**。如果你在 `providerOptions` 中设置了与推理相关的选项，它们将完全优先，顶层 `reasoning` 参数会被忽略。

```ts
import { generateText } from 'ai';
import { openai } from '@ai-sdk/openai';

const { text } = await generateText({
  model: openai.responses('gpt-6-astra'),
  reasoning: 'low', // ignored because providerOptions.openai.reasoningEffort is set
  providerOptions: {
    openai: {
      reasoningEffort: 'high', // this wins
    },
  },
  prompt: 'Explain quantum entanglement.',
});
```

这种设计让你默认使用可移植的 `reasoning` 参数，仅在需要提供商特定功能（例如精确的 token 预算）时才回退到 `providerOptions`。

## 提供商支持

以下提供商支持 `reasoning` 参数：OpenAI、Anthropic、Google、xAI、Groq、DeepSeek、Fireworks、Amazon Bedrock 和 Perplexity。每个提供商都会将该值转换为其原生的推理 API。有些提供商原生支持全部六个级别，而其他提供商会强制转换为更少的级别（发生强制转换时会发出警告）。有些提供商使用数字 token 预算而非枚举来控制推理；在这些情况下，顶层 `reasoning` 值会被映射为按模型最大输出 token 数百分比计算的预算。

不支持推理的提供商（例如 Mistral 和 Cohere）会发出 `unsupported` 警告并忽略该参数。

## 从 `providerOptions` 迁移

如果你目前通过 `providerOptions` 控制推理，可以迁移到顶层 `reasoning` 参数，以实现跨提供商的可移植性。

### 之前（Anthropic）

```ts
const { text } = await generateText({
  model: anthropic('claude-opus-5-5'),
  providerOptions: {
    anthropic: {
      thinking: { type: 'adaptive' },
      effort: 'high',
    },
  },
  prompt: 'How many people will live in the world in 2040?',
});
```

### 之后（Anthropic）

```ts
const { text } = await generateText({
  model: anthropic('claude-opus-5-5'),
  reasoning: 'high',
  prompt: 'How many people will live in the world in 2040?',
});
```

### 之前（使用较旧模型的 Anthropic）

```ts
const { text } = await generateText({
  model: anthropic('claude-sonnet-4-20250514'),
  providerOptions: {
    anthropic: {
      thinking: { type: 'enabled', budgetTokens: 12000 },
    },
  },
  prompt: 'How many people will live in the world in 2040?',
});
```

### 之后（使用较旧模型的 Anthropic）

```ts
const { text } = await generateText({
  model: anthropic('claude-sonnet-4-20250514'),
  reasoning: 'medium',
  prompt: 'How many people will live in the world in 2040?',
});
```

如果你需要强制使用精确的 token 预算（例如恰好 12000 个 token），请继续使用 `providerOptions` 而非顶层 `reasoning` 参数。

### 之前（使用 `includeThoughts` 的 Google）

```ts
const { text } = await generateText({
  model: google('gemini-3.8-flash'),
  providerOptions: {
    google: {
      thinkingConfig: { thinkingLevel: 'high', includeThoughts: true },
    },
  },
  prompt: 'Explain the Riemann hypothesis in simple terms.',
});
```

### 之后（使用 `includeThoughts` 的 Google）

```ts
const { text } = await generateText({
  model: google('gemini-3.8-flash'),
  reasoning: 'high',
  providerOptions: {
    google: { thinkingConfig: { includeThoughts: true } },
  },
  prompt: 'Explain the Riemann hypothesis in simple terms.',
});
```

### 之前（使用 `reasoningSummary` 的 OpenAI）

```ts
const { text } = await generateText({
  model: openai.responses('gpt-6-astra'),
  providerOptions: {
    openai: { reasoningEffort: 'high', reasoningSummary: 'auto' },
  },
  prompt: 'Explain quantum entanglement.',
});
```

### 之后（使用 `reasoningSummary` 的 OpenAI）

```ts
const { text } = await generateText({
  model: openai.responses('gpt-6-astra'),
  reasoning: 'high',
  providerOptions: {
    openai: { reasoningSummary: 'auto' },
  },
  prompt: 'Explain quantum entanglement.',
});
```

请注意，`providerOptions` 仍可与 `reasoning` 一起使用，以支持与推理强度无关的提供商特定功能。但是，如果 `providerOptions` 包含推理强度/预算设置（例如 `reasoningEffort`、`thinking`、`thinkingConfig.thinkingBudget`），这些设置将完全优先，顶层 `reasoning` 参数会被忽略。
