# 转录

AI SDK 提供了 [`transcribe`](/docs/reference/ai-sdk-core/transcribe)
函数，用于使用转录模型转录音频。

```ts
import { transcribe } from 'ai';
import { openai } from '@ai-sdk/openai';
import { readFile } from 'fs/promises';

const transcript = await transcribe({
  model: openai.transcription('whisper-1'),
  audio: await readFile('audio.mp3'),
});
```

`audio` 属性可以是 `Uint8Array`、`ArrayBuffer`、`Buffer`、`string`（base64 编码的音频数据）或 `URL`。

要访问生成的转录文本：

```ts
const text = transcript.text; // 转录文本，例如 "Hello, world!"
const segments = transcript.segments; // 包含开始和结束时间的片段数组（如果可用）
const language = transcript.language; // 转录的语言，例如 "en"（如果可用）
const durationInSeconds = transcript.durationInSeconds; // 转录的时长（秒）（如果可用）
```

## 流式转录

<Note type="warning">流式转录是一项实验性功能。</Note>

当您拥有实时原始音频并需要在完整音频流完成之前获取转录更新时，请使用 `experimental_streamTranscribe`。该函数使用支持流式的转录模型；提供商选项用于配置特定提供商的行为，但流式操作由函数本身选择。

```ts
import { openai } from '@ai-sdk/openai';
import { experimental_streamTranscribe as streamTranscribe } from 'ai';

const result = streamTranscribe({
  model: openai.transcription('gpt-realtime-whisper'),
  audio: audioStream, // ReadableStream<Uint8Array | string>
  inputAudioFormat: { type: 'audio/pcm', rate: 24000 },
  providerOptions: {
    openai: {
      language: 'en',
      streaming: {
        delay: 'low',
      },
    },
  },
});

for await (const part of result.fullStream) {
  if (part.type === 'transcript-delta') {
    process.stdout.write(part.delta);
  }

  if (part.type === 'transcript-partial') {
    console.log('partial:', part.text);
  }

  if (part.type === 'transcript-final') {
    console.log('final:', part.text);
  }
}

console.log(await result.text);
```

`fullStream` 是一个单消费者实时流，只能访问一次。
当您同时需要流部分和最终结果时，请先访问 `fullStream`，并在消费它期间或之后等待结果 Promise。先访问结果 Promise 会在内部消费流，因此 `fullStream` 将不再可用。这避免了为实时音频保留无界重放缓冲区。

要访问最终转录元数据：

```ts
const text = await result.text; // 最终转录文本
const segments = await result.segments; // 包含时间信息的最终片段（如果可用）
const language = await result.language; // 转录的语言（如果可用）
const durationInSeconds = await result.durationInSeconds; // 时长（秒）（如果可用）
```

`audio` 流必须包含原始音频块。`Uint8Array` 块是原始字节；`string` 块是 base64 编码的原始字节。始终设置 `inputAudioFormat` 以匹配您发送的块。

<Note>
  字符串模型 ID 通过全局提供商（默认为 AI Gateway）解析。AI Gateway 支持受支持模型的流式转录（例如 `openai/gpt-realtime-whisper`、`elevenlabs/eleven-scribe-2-realtime`、`xai/grok-stt`），因此字符串 ID 可以正常工作：
  `experimental_streamTranscribe({ model: 'openai/gpt-realtime-whisper', ...
  })`。您也可以传递提供商模型实例（例如
  `openai.transcription('gpt-realtime-whisper')`）以直接针对提供商进行流式传输。
</Note>

OpenAI 流式转录使用 `openai.transcription('gpt-realtime-whisper')`。
Cartesia 使用 `cartesia.transcription('ink-2')` 进行仅流式的 Ink 2
转录。ElevenLabs 使用
`elevenLabs.transcription('scribe_v2_realtime')` 进行 Scribe v2 Realtime。xAI
对请求/响应和流式转录使用相同的 `xai.transcription()` 模型；`experimental_streamTranscribe` 选择提供商的 WebSocket STT 传输。

```ts
import { xai } from '@ai-sdk/xai';
import { experimental_streamTranscribe as streamTranscribe } from 'ai';

const result = streamTranscribe({
  model: xai.transcription(),
  audio: audioStream,
  inputAudioFormat: { type: 'audio/pcm', rate: 16000 },
  providerOptions: {
    xai: {
      language: 'en',
      keyterm: ['AI SDK', 'Grok'],
      streaming: {
        interimResults: true,
        endpointing: 500,
      },
    },
  },
});
```

某些提供商在直接流式 STT 时需要 WebSocket 头。在这些运行时中，创建提供商时请传递特定于提供商的 `webSocket` 实现。

## 设置

### 提供商特定设置

转录模型通常具有提供商或模型特定的设置，您可以使用 `providerOptions` 参数进行设置。

```ts highlight="8-12"
import { transcribe } from 'ai';
import { openai } from '@ai-sdk/openai';
import { readFile } from 'fs/promises';

const transcript = await transcribe({
  model: openai.transcription('whisper-1'),
  audio: await readFile('audio.mp3'),
  providerOptions: {
    openai: {
      timestampGranularities: ['word'],
    },
  },
});
```

### 下载大小限制

当 `audio` 是 URL 时，SDK 会以默认 **2 GiB** 大小限制下载文件。
您可以使用 `createDownload` 自定义此限制：

```ts highlight="1,7"
import { transcribe, createDownload } from 'ai';
import { openai } from '@ai-sdk/openai';

const transcript = await transcribe({
  model: openai.transcription('whisper-1'),
  audio: new URL('https://example.com/audio.mp3'),
  download: createDownload({ maxBytes: 50 * 1024 * 1024 }), // 50 MB 限制
});
```

您还可以提供完全自定义的下载函数：

```ts highlight="7-13"
import { transcribe } from 'ai';
import { openai } from '@ai-sdk/openai';

const transcript = await transcribe({
  model: openai.transcription('whisper-1'),
  audio: new URL('https://example.com/audio.mp3'),
  download: async ({ url }) => {
    const res = await myAuthenticatedFetch(url);
    return {
      data: new Uint8Array(await res.arrayBuffer()),
      mediaType: res.headers.get('content-type') ?? undefined,
    };
  },
});
```

如果下载超过大小限制，将抛出 `DownloadError`：

```ts
import { transcribe, DownloadError } from 'ai';
import { openai } from '@ai-sdk/openai';

try {
  await transcribe({
    model: openai.transcription('whisper-1'),
    audio: new URL('https://example.com/audio.mp3'),
  });
} catch (error) {
  if (DownloadError.isInstance(error)) {
    console.log('下载失败：', error.message);
  }
}
```

### 中止信号与超时

`transcribe` 接受可选的 `abortSignal` 参数，类型为
[`AbortSignal`](https://developer.mozilla.org/en-US/docs/Web/API/AbortSignal)，
您可以使用它来中止转录过程或设置超时。

当与 URL 下载结合使用时，这尤其有用，可以防止长时间运行的请求：

```ts highlight="7"
import { openai } from '@ai-sdk/openai';
import { transcribe } from 'ai';

const transcript = await transcribe({
  model: openai.transcription('whisper-1'),
  audio: new URL('https://example.com/audio.mp3'),
  abortSignal: AbortSignal.timeout(5000), // 5 秒后中止
});
```

### 自定义请求头

`transcribe` 接受可选的 `headers` 参数，类型为 `Record<string, string>`，
您可以使用它向转录请求添加自定义请求头。

```ts highlight="8"
import { openai } from '@ai-sdk/openai';
import { transcribe } from 'ai';
import { readFile } from 'fs/promises';

const transcript = await transcribe({
  model: openai.transcription('whisper-1'),
  audio: await readFile('audio.mp3'),
  headers: { 'X-Custom-Header': 'custom-value' },
});
```

### 警告

警告（例如不支持的参数）可在 `warnings` 属性上获取。

```ts
import { openai } from '@ai-sdk/openai';
import { transcribe } from 'ai';
import { readFile } from 'fs/promises';

const transcript = await transcribe({
  model: openai.transcription('whisper-1'),
  audio: await readFile('audio.mp3'),
});

const warnings = transcript.warnings;
```

### 错误处理

当 `transcribe` 无法生成有效的转录文本时，它会抛出 [`AI_NoTranscriptGeneratedError`](/docs/reference/ai-sdk-errors/ai-no-transcript-generated-error)。

此错误可能由以下任一原因引起：

- 模型未能生成响应
- 模型生成的响应无法解析

该错误保留以下信息以帮助您记录问题：

- `responses`：关于转录模型响应的元数据，包括时间戳、模型和请求头。
- `cause`：错误的原因。您可以使用它进行更详细的错误处理。

```ts
import { transcribe, NoTranscriptGeneratedError } from 'ai';
import { openai } from '@ai-sdk/openai';
import { readFile } from 'fs/promises';

try {
  await transcribe({
    model: openai.transcription('whisper-1'),
    audio: await readFile('audio.mp3'),
  });
} catch (error) {
  if (NoTranscriptGeneratedError.isInstance(error)) {
    console.log('NoTranscriptGeneratedError');
    console.log('原因：', error.cause);
    console.log('响应：', error.responses);
  }
}
```
