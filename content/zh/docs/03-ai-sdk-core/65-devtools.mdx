# DevTools

<Note type="warning">
  AI SDK DevTools 仅用于本地开发。请勿在生产环境中使用。
</Note>

AI SDK DevTools 让您能够全面了解通过 [`generateText`](/docs/reference/ai-sdk-core/generate-text)、[`streamText`](/docs/reference/ai-sdk-core/stream-text) 和 [`ToolLoopAgent`](/docs/reference/ai-sdk-core/tool-loop-agent) 进行的 AI SDK 调用。它通过基于 Web 的 UI 帮助您调试和检查 LLM 请求、响应、工具调用以及多步骤交互。

DevTools 由两部分组成：

1. **遥测集成**：通过[遥测](/docs/ai-sdk-core/telemetry)系统捕获 AI SDK 调用的运行和步骤
2. **查看器**：用于检查捕获数据的 Web UI

## 安装

安装 DevTools 包：

```bash
pnpm add @ai-sdk/devtools
```

## 要求

- AI SDK v7 (`ai@latest`)
- 兼容 Node.js 的运行时

## 使用 DevTools

### 注册集成

全局注册 `DevToolsTelemetry`，以便捕获所有 AI SDK 调用：

```ts
import { registerTelemetry } from 'ai';
import { DevToolsTelemetry } from '@ai-sdk/devtools';

registerTelemetry(DevToolsTelemetry());
```

注册集成后，遥测功能会自动启用——无需对每个调用进行配置：

```ts
import { generateText } from 'ai';

const result = await generateText({
  model: openai('gpt-4o'),
  prompt: '美国有哪些城市？',
});
```

您也可以将集成传递给单个调用，而不是全局注册：

```ts highlight="7-9"
import { streamText } from 'ai';
import { DevToolsTelemetry } from '@ai-sdk/devtools';

const result = streamText({
  model: openai('gpt-4o'),
  prompt: '你好！',
  telemetry: {
    integrations: [DevToolsTelemetry()],
  },
});
```

### 启动查看器

启动 DevTools 查看器：

```bash
npx @ai-sdk/devtools
```

打开 [http://localhost:4983](http://localhost:4983) 查看您的 AI SDK 交互。

### 在单体仓库中使用

如果您使用单体仓库（例如 Turborepo、Nx），请从运行 AI SDK 代码的同一工作区启动 DevTools。

例如，如果您的 API 位于 `apps/api` 中，请运行：

```bash
cd apps/api
npx @ai-sdk/devtools
```

## 捕获的数据

DevTools 从您的 AI SDK 调用中捕获以下信息：

- **输入参数和提示词**：查看发送给 LLM 的完整输入
- **输出内容和工具调用**：检查生成的文本和工具调用
- **Token 使用情况和时间**：监控资源消耗和性能
- **原始提供商数据**：访问完整的请求和响应负载

### 运行和步骤

DevTools 将捕获的数据组织为运行和步骤：

- **运行**：一次完整的多步骤 AI 交互，按初始提示词分组
- **步骤**：运行中的单个 LLM 调用（例如，一次 `generateText` 或 `streamText` 调用）

多步骤交互（例如由工具调用或智能体循环创建的交互）会被分组为包含多个步骤的单个运行。嵌套的子智能体调用会链接到其父运行，从而轻松追踪完整的执行树。

## 工作原理

`DevToolsTelemetry` 集成会挂接到 AI SDK [遥测](/docs/ai-sdk-core/telemetry)生命周期，以捕获所有 `generateText`、`streamText`、`generateObject` 和 `streamObject` 调用。捕获的数据会本地存储在 JSON 文件（`.devtools/generations.json`）中，并通过基于 Hono 和 React 构建的 Web UI 提供服务。

<Note type="warning">
  该集成会自动将 `.devtools` 添加到您的 `.gitignore` 文件中。请验证 `.devtools` 是否在您的 `.gitignore` 中，以确保您不会将敏感的 AI 交互数据提交到仓库。
</Note>

## 安全注意事项

DevTools 会将所有 AI 交互以纯文本文件形式存储在本地，包括：

- 用户提示词和消息
- LLM 响应
- 工具调用参数和结果
- API 请求和响应数据

**仅在本地开发环境中使用 DevTools。** 请勿在生产环境或处理敏感数据时启用 DevTools。
