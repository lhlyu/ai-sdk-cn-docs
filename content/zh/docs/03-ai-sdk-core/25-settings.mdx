# 设置

大型语言模型（LLM）通常提供设置来增强其输出。

所有 AI SDK 函数除了模型、[提示词](/docs/foundations/prompts)和特定于提供商的设置外，还支持以下通用设置：

```ts highlight="3-6"
const result = await generateText({
  model: __MODEL__,
  maxOutputTokens: 512,
  temperature: 0.3,
  maxRetries: 5,
  timeout: 10000,
  prompt: 'Invent a new holiday and describe its traditions.',
});
```

<Note>
  某些提供商不支持所有通用设置。如果你对不支持的提供商使用了某个设置，将会生成警告。你可以检查结果对象中的 `warnings` 属性，查看是否生成了任何警告。
</Note>

## 语言模型调用选项

语言模型调用选项（`LanguageModelCallOptions`）是影响语言模型如何生成其响应的设置——包括令牌限制、采样行为、惩罚、停止序列、种子和推理。它们会被转发到底层模型。

### `maxOutputTokens`

要生成的最大令牌数。

### `temperature`

温度设置。

该值会传递给提供商。取值范围取决于提供商和模型。
对于大多数提供商，`0` 表示几乎确定性的结果，而更高的值表示更多的随机性。

建议设置 `temperature` 或 `topP` 中的一个，但不要同时设置两者。

<Note>在 AI SDK 5.0 中，温度不再默认设置为 `0`。</Note>

### `topP`

核采样（Nucleus sampling）。

该值会传递给提供商。取值范围取决于提供商和模型。
对于大多数提供商，核采样是一个介于 0 和 1 之间的数字。
例如，0.1 意味着只考虑概率质量最高的前 10% 的令牌。

建议设置 `temperature` 或 `topP` 中的一个，但不要同时设置两者。

### `topK`

仅从每个后续令牌的前 K 个选项中采样。

用于移除“长尾”低概率响应。
仅推荐用于高级用例。通常你只需要使用 `temperature`。

### `presencePenalty`

存在惩罚会影响模型重复提示词中已有信息的可能性。

该值会传递给提供商。取值范围取决于提供商和模型。
对于大多数提供商，`0` 表示没有惩罚。

### `frequencyPenalty`

频率惩罚会影响模型重复使用相同单词或短语的可能性。

该值会传递给提供商。取值范围取决于提供商和模型。
对于大多数提供商，`0` 表示没有惩罚。

### `stopSequences`

用于停止文本生成的停止序列。

如果设置，当生成其中一个停止序列时，模型将停止生成文本。
提供商可能对停止序列的数量有限制。

### `seed`

用于随机采样的种子（整数）。
如果设置且模型支持，调用将生成确定性的结果。

### `reasoning`

控制模型在生成响应之前执行多少推理。

| 值                    | 行为                                                             |
| -------------------- | -------------------------------------------------------------------- |
| `'provider-default'` | 使用提供商的默认推理行为（省略时的默认值） |
| `'none'`             | 禁用推理                                                    |
| `'minimal'`          | 最低限度的推理                                               |
| `'low'`              | 快速、简洁的推理                                              |
| `'medium'`           | 平衡的推理                                                   |
| `'high'`             | 彻底的推理                                                   |
| `'xhigh'`            | 最大推理                                                    |

如果你还在 `providerOptions` 中设置了与推理相关的选项（例如 `openai.reasoningEffort` 或 `anthropic.thinking`），则提供商特定选项优先，顶层的 `reasoning` 参数将被忽略。

有关每个提供商的映射以及从 `providerOptions` 迁移的详细信息，请参阅[推理指南](/docs/ai-sdk-core/reasoning)。

## 请求选项

请求选项（`RequestOptions`）是影响传输、重试、取消和超时的设置——而不是模型生成行为。它们控制 SDK 如何与提供商的 API 通信。

### `maxRetries`

最大重试次数。设置为 0 可禁用重试。默认值：`2`。

### `abortSignal`

一个可选的终止信号，可用于取消调用。

终止信号可以例如从用户界面转发以取消调用，
或使用 `AbortSignal.timeout` 定义超时。

#### 示例：AbortSignal.timeout

```ts
const result = await generateText({
  model: __MODEL__,
  prompt: 'Invent a new holiday and describe its traditions.',
  abortSignal: AbortSignal.timeout(5000), // 5 秒
});
```

### `timeout`

一个可选的超时时间（毫秒）。如果调用时间超过指定时长，将被中止。

这是一个便捷参数，内部会创建一个终止信号。它可以与 `abortSignal` 一起使用——如果两者都提供，则当任一条件满足时调用将中止。

你可以将超时指定为数字（毫秒）或具有以下属性的对象：

- `totalMs`：整个调用（包括所有步骤）的总超时时间。
- `stepMs`：每个单独步骤（LLM 调用）的超时时间。这对于多步骤生成非常有用，你可以独立限制每个步骤的时间。
- `chunkMs`：流块之间的超时时间（仅限流式传输）。如果在此时间内未收到新块，调用将中止。这对于检测停滞的流非常有用。
- `toolMs`：所有工具执行的默认超时时间。如果某个工具执行时间过长，它将中止并返回工具错误，以便模型可以响应或重试。
- `tools`：使用 `{toolName}Ms` 键（例如 `weatherMs`、`slowApiMs`）的每个工具超时覆盖。优先级高于 `toolMs`。工具名称会进行类型检查以支持自动补全。

#### 示例：5 秒超时（数字格式）

```ts
const result = await generateText({
  model: __MODEL__,
  prompt: 'Invent a new holiday and describe its traditions.',
  timeout: 5000, // 5 秒
});
```

#### 示例：5 秒总超时（对象格式）

```ts
const result = await generateText({
  model: __MODEL__,
  prompt: 'Invent a new holiday and describe its traditions.',
  timeout: { totalMs: 5000 }, // 5 秒
});
```

#### 示例：10 秒步骤超时

```ts
const result = await generateText({
  model: __MODEL__,
  prompt: 'Invent a new holiday and describe its traditions.',
  timeout: { stepMs: 10000 }, // 每步 10 秒
});
```

#### 示例：组合总超时和步骤超时

```ts
const result = await generateText({
  model: __MODEL__,
  prompt: 'Invent a new holiday and describe its traditions.',
  timeout: {
    totalMs: 60000, // 总共 60 秒
    stepMs: 10000, // 每步 10 秒
  },
});
```

#### 示例：流式传输的每块超时（仅限 streamText）

```ts
const result = streamText({
  model: __MODEL__,
  prompt: 'Invent a new holiday and describe its traditions.',
  timeout: { chunkMs: 5000 }, // 如果 5 秒内未收到块则中止
});
```

#### 示例：工具执行超时

```ts
const result = await generateText({
  model: __MODEL__,
  tools: { weather: weatherTool, slowApi: slowApiTool },
  timeout: {
    toolMs: 5000, // 所有工具默认 5 秒
  },
  prompt: 'What is the weather in San Francisco?',
});
```

#### 示例：每个工具的超时覆盖

```ts
const result = await generateText({
  model: __MODEL__,
  tools: { weather: weatherTool, slowApi: slowApiTool },
  timeout: {
    toolMs: 5000, // 所有工具默认
    tools: {
      weatherMs: 3000, // 天气工具 3 秒
      slowApiMs: 10000, // 慢速 API 工具 10 秒
    },
  },
  prompt: 'What is the weather in San Francisco?',
});
```

### `headers`

随请求发送的额外 HTTP 标头。仅适用于基于 HTTP 的提供商。

你可以使用请求标头向提供商提供额外信息，
具体取决于提供商支持的内容。例如，某些可观测性提供商支持
诸如 `Prompt-Id` 之类的标头。

```ts
import { generateText } from 'ai';
__PROVIDER_IMPORT__;

const result = await generateText({
  model: __MODEL__,
  prompt: 'Invent a new holiday and describe its traditions.',
  headers: {
    'Prompt-Id': 'my-prompt-id',
  },
});
```

<Note>
  `headers` 设置用于请求特定的标头。你也可以在提供商配置中设置
  `headers`。这些标头将随提供商发出的每个请求一起发送。
</Note>
