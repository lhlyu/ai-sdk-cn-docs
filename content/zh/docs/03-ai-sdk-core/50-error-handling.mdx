# 错误处理

## 处理常规错误

常规错误会被抛出，可以使用 `try/catch` 块进行处理。

```ts highlight="4,9-11"
import { generateText } from 'ai';
__PROVIDER_IMPORT__;

try {
  const { text } = await generateText({
    model: __MODEL__,
    prompt: '为4人份编写一份素食千层面食谱。',
  });
} catch (error) {
  // 处理错误
}
```

有关可能抛出的不同错误类型的更多信息，请参阅[错误类型](/docs/reference/ai-sdk-errors)。

## 处理流式错误（简单流）

当在不支持错误块的流中发生错误时，错误会作为常规错误抛出。你可以使用 `try/catch` 块来处理这些错误。

```ts highlight="4,13-15"
import { streamText } from 'ai';
__PROVIDER_IMPORT__;

try {
  const { textStream } = streamText({
    model: __MODEL__,
    prompt: '为4人份编写一份素食千层面食谱。',
  });

  for await (const textPart of textStream) {
    process.stdout.write(textPart);
  }
} catch (error) {
  // 处理错误
}
```

## 处理流式错误（支持 `error` 的流式传输）

`stream` 结果支持错误部分。你可以像处理其他部分一样处理这些部分。建议同时添加 try-catch 块来处理流式传输之外发生的错误。

```ts highlight="14-22"
import { streamText } from 'ai';
__PROVIDER_IMPORT__;

try {
  const { stream } = streamText({
    model: __MODEL__,
    prompt: '为4人份编写一份素食千层面食谱。',
  });

  for await (const part of stream) {
    switch (part.type) {
      // ... 处理其他部分类型

      case 'error': {
        const error = part.error;
        // 处理错误
        break;
      }

      case 'abort': {
        // 处理流中止
        break;
      }

      case 'tool-error': {
        const error = part.error;
        // 处理错误
        break;
      }
    }
  }
} catch (error) {
  // 处理错误
}
```

## 处理流中止

当流被中止时（例如，通过聊天停止按钮），你可能希望执行清理操作，比如更新 UI 中存储的消息。使用 `onAbort` 回调来处理这些情况。

当流通过 `AbortSignal` 中止时，会调用 `onAbort` 回调，但不会调用 `onEnd`。这确保你仍然可以适当地更新 UI 状态。

```ts highlight="6-10"
import { streamText } from 'ai';
__PROVIDER_IMPORT__;

const { textStream } = streamText({
  model: __MODEL__,
  prompt: '为4人份编写一份素食千层面食谱。',
  onAbort: ({ steps }) => {
    // 更新存储的消息或执行清理
    console.log('流在', steps.length, '个步骤后被中止');
  },
  onEnd: ({ steps, totalUsage }) => {
    // 正常完成时调用此函数
    console.log('流正常完成');
  },
});

for await (const textPart of textStream) {
  process.stdout.write(textPart);
}
```

`onAbort` 回调接收：

- `steps`：中止前所有已完成步骤的数组

你也可以直接在流中处理中止事件：

```ts highlight="11-14"
import { streamText } from 'ai';
__PROVIDER_IMPORT__;

const { stream } = streamText({
  model: __MODEL__,
  prompt: '为4人份编写一份素食千层面食谱。',
});

for await (const chunk of stream) {
  switch (chunk.type) {
    case 'abort': {
      // 直接在流中处理中止
      console.log('流已被中止');
      break;
    }
    // ... 处理其他部分类型
  }
}
```
