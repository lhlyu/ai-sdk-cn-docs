# 图像生成

AI SDK 提供了 [`generateImage`](/docs/reference/ai-sdk-core/generate-image) 函数，用于根据给定的提示词使用图像模型生成图像。

```tsx
import { generateImage } from 'ai';
__PROVIDER_IMPORT__;

const { image } = await generateImage({
  model: __IMAGE_MODEL__,
  prompt: 'Santa Claus driving a Cadillac',
});
```

你可以使用 `base64` 或 `uint8Array` 属性访问图像数据：

```tsx
const base64 = image.base64; // base64 图像数据
const uint8Array = image.uint8Array; // Uint8Array 图像数据
```

## 设置

### 尺寸与宽高比

根据模型的不同，你可以指定尺寸或宽高比。

##### 尺寸

尺寸以 `{宽度}x{高度}` 格式的字符串指定。模型仅支持少数几种尺寸，且不同模型和提供商支持的尺寸各不相同。

```tsx highlight={"7"}
import { generateImage } from 'ai';
__PROVIDER_IMPORT__;

const { image } = await generateImage({
  model: __IMAGE_MODEL__,
  prompt: 'Santa Claus driving a Cadillac',
  size: '1024x1024',
});
```

##### 宽高比

宽高比以 `{宽度}:{高度}` 格式的字符串指定。模型仅支持少数几种宽高比，且不同模型和提供商支持的宽高比各不相同。

```tsx highlight={"7"}
import { generateImage } from 'ai';
__PROVIDER_IMPORT__;

const { image } = await generateImage({
  model: __IMAGE_MODEL__,
  prompt: 'Santa Claus driving a Cadillac',
  aspectRatio: '16:9',
});
```

### 生成多张图像

`generateImage` 也支持一次生成多张图像：

```tsx highlight={"7"}
import { generateImage } from 'ai';
__PROVIDER_IMPORT__;

const { images } = await generateImage({
  model: __IMAGE_MODEL__,
  prompt: 'Santa Claus driving a Cadillac',
  n: 4, // 要生成的图像数量
});
```

<Note>
  `generateImage` 会根据需要自动（并行）调用模型，以生成所请求数量的图像。
</Note>

每个图像模型在单次 API 调用中都有一个内部限制，限制其能生成的图像数量。AI SDK 通过在你使用 `n` 参数请求多张图像时，适当地对请求进行批处理，来自动管理此限制。默认情况下，SDK 使用提供商文档中说明的限制（例如，DALL-E 3 每次调用只能生成 1 张图像，而 DALL-E 2 支持最多 10 张）。

如果需要，你可以在生成图像时使用 `maxImagesPerCall` 设置覆盖此行为。当使用默认批处理大小可能不是最优的新模型或自定义模型时，这尤其有用：

```tsx
const { images } = await generateImage({
  model: __IMAGE_MODEL__,
  prompt: 'Santa Claus driving a Cadillac',
  maxImagesPerCall: 5, // 覆盖默认批处理大小
  n: 10, // 将进行 2 次调用，每次生成 5 张图像
});
```

### 提供种子

你可以向 `generateImage` 函数提供种子，以控制图像生成过程的输出。如果模型支持，相同的种子将始终生成相同的图像。

```tsx highlight={"7"}
import { generateImage } from 'ai';
__PROVIDER_IMPORT__;

const { image } = await generateImage({
  model: __IMAGE_MODEL__,
  prompt: 'Santa Claus driving a Cadillac',
  seed: 1234567890,
});
```

### 提供商特定设置

图像模型通常具有提供商甚至模型特定的设置。你可以使用 `providerOptions` 参数将这些设置传递给 `generateImage` 函数。提供商的选项（如下例中的 `openai`）将成为请求体的属性。

```tsx highlight={"8-13"}
import { generateImage } from 'ai';
import { openai, type OpenAIImageModelGenerationOptions } from '@ai-sdk/openai';

const { image } = await generateImage({
  model: openai.image('dall-e-3'),
  prompt: 'Santa Claus driving a Cadillac',
  size: '1024x1024',
  providerOptions: {
    openai: {
      style: 'vivid',
      quality: 'hd',
    } satisfies OpenAIImageModelGenerationOptions,
  },
});
```

### 中止信号与超时

`generateImage` 接受一个可选的 `abortSignal` 参数，类型为 [`AbortSignal`](https://developer.mozilla.org/en-US/docs/Web/API/AbortSignal)，你可以用它来中止图像生成过程或设置超时。

```ts highlight={"7"}
import { generateImage } from 'ai';
__PROVIDER_IMPORT__;

const { image } = await generateImage({
  model: __IMAGE_MODEL__,
  prompt: 'Santa Claus driving a Cadillac',
  abortSignal: AbortSignal.timeout(1000), // 1 秒后中止
});
```

### 自定义请求头

`generateImage` 接受一个可选的 `headers` 参数，类型为 `Record<string, string>`，你可以用它向图像生成请求添加自定义请求头。

```ts highlight={"7"}
import { generateImage } from 'ai';
__PROVIDER_IMPORT__;

const { image } = await generateImage({
  model: __IMAGE_MODEL__,
  prompt: 'Santa Claus driving a Cadillac',
  headers: { 'X-Custom-Header': 'custom-value' },
});
```

### 警告

如果模型返回警告（例如，针对不支持的参数），这些警告将在响应的 `warnings` 属性中提供。

```tsx
const { image, warnings } = await generateImage({
  model: __IMAGE_MODEL__,
  prompt: 'Santa Claus driving a Cadillac',
});
```

### 额外的提供商特定元数据

一些提供商为整体结果或每张图像公开额外的元数据。

```tsx
const prompt = 'Santa Claus driving a Cadillac';

const { image, providerMetadata } = await generateImage({
  model: openai.image('dall-e-3'),
  prompt,
});

const revisedPrompt = providerMetadata.openai.images[0]?.revisedPrompt;

console.log({
  prompt,
  revisedPrompt,
});
```

返回的 `providerMetadata` 的外部键是提供商名称。内部值是元数据。元数据中始终存在一个 `images` 键，它是一个数组，长度与顶层 `images` 键相同。

### 错误处理

当 `generateImage` 无法生成有效图像时，它会抛出一个 [`AI_NoImageGeneratedError`](/docs/reference/ai-sdk-errors/ai-no-image-generated-error) 错误。

当 AI 提供商未能生成图像时，会发生此错误。可能由以下原因引起：

- 模型未能生成响应
- 模型生成了无法解析的响应

该错误保留了以下信息以帮助你记录问题：

- `responses`：关于图像模型响应的元数据，包括时间戳、模型和请求头。
- `cause`：错误的原因。你可以用它来进行更详细的错误处理。

```ts
import { generateImage, NoImageGeneratedError } from 'ai';

try {
  await generateImage({ model, prompt });
} catch (error) {
  if (NoImageGeneratedError.isInstance(error)) {
    console.log('NoImageGeneratedError');
    console.log('Cause:', error.cause);
    console.log('Responses:', error.responses);
  }
}
```

## 图像中间件

你可以使用 `wrapImageModel` 和 `ImageModelV4Middleware` 来增强图像模型，例如设置默认值或实现日志记录。

以下是一个在未提供尺寸时设置默认尺寸的示例：

```ts
import { generateImage, wrapImageModel } from 'ai';
__PROVIDER_IMPORT__;

const model = wrapImageModel({
  model: __IMAGE_MODEL__,
  middleware: {
    specificationVersion: 'v3',
    transformParams: async ({ params }) => ({
      ...params,
      size: params.size ?? '1024x1024',
    }),
  },
});

const { image } = await generateImage({
  model,
  prompt: 'Santa Claus driving a Cadillac',
});
```

## 使用语言模型生成图像

某些语言模型（例如 Google 的 `gemini-2.5-flash-image`）支持包括图像在内的多模态输出。使用此类模型，你可以通过响应的 `files` 属性访问生成的图像。

```ts
import { google } from '@ai-sdk/google';
import { generateText } from 'ai';

const result = await generateText({
  model: google('gemini-2.5-flash-image'),
  prompt: 'Generate an image of a comic cat',
});

for (const file of result.files) {
  if (file.mediaType.startsWith('image/')) {
    // file 对象提供多种数据格式：
    // 以 base64 字符串、Uint8Array 二进制数据访问图像，或检查类型
    // - file.base64: string (data URL 格式)
    // - file.uint8Array: Uint8Array (二进制数据)
    // - file.mediaType: string (例如 "image/png")
  }
}
```
