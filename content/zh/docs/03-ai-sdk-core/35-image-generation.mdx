# 图像生成

AI SDK 提供了 [`generateImage`](/docs/reference/ai-sdk-core/generate-image)
函数，用于使用图像模型根据给定的提示词生成图像。

```tsx
import { generateImage } from 'ai';
__PROVIDER_IMPORT__;

const { image } = await generateImage({
  model: __IMAGE_MODEL__,
  prompt: 'Santa Claus driving a Cadillac',
});
```

您可以使用 `base64` 或 `uint8Array` 属性访问图像数据：

```tsx
const base64 = image.base64; // base64 图像数据
const uint8Array = image.uint8Array; // Uint8Array 图像数据
```

## 设置

### 尺寸和宽高比

根据模型的不同，您可以指定尺寸或宽高比。

##### 尺寸

尺寸以 `{宽度}x{高度}` 格式的字符串指定。
模型仅支持少数几种尺寸，且不同模型和提供商支持的尺寸各不相同。

```tsx highlight={"7"}
import { generateImage } from 'ai';
__PROVIDER_IMPORT__;

const { image } = await generateImage({
  model: __IMAGE_MODEL__,
  prompt: 'Santa Claus driving a Cadillac',
  size: '1024x1024',
});
```

##### 宽高比

宽高比以 `{宽度}:{高度}` 格式的字符串指定。
模型仅支持少数几种宽高比，且不同模型和提供商支持的宽高比各不相同。

```tsx highlight={"7"}
import { generateImage } from 'ai';
__PROVIDER_IMPORT__;

const { image } = await generateImage({
  model: __IMAGE_MODEL__,
  prompt: 'Santa Claus driving a Cadillac',
  aspectRatio: '16:9',
});
```

### 生成多张图像

`generateImage` 还支持一次生成多张图像：

```tsx highlight={"7"}
import { generateImage } from 'ai';
__PROVIDER_IMPORT__;

const { images } = await generateImage({
  model: __IMAGE_MODEL__,
  prompt: 'Santa Claus driving a Cadillac',
  n: 4, // 要生成的图像数量
});
```

<Note>
  `generateImage` 将根据需要自动（并行）调用模型多次，以生成所请求数量的图像。
</Note>

每个图像模型在单次 API 调用中都有一个内部限制，限制其可以生成的图像数量。AI SDK 通过在使用 `n` 参数请求多张图像时适当批量处理请求来自动管理此限制。默认情况下，SDK 使用提供商文档中记录的限制（例如，DALL-E 3 每次调用只能生成 1 张图像，而 DALL-E 2 支持最多 10 张）。

如有需要，您可以在生成图像时使用 `maxImagesPerCall` 设置覆盖此行为。这在处理新模型或自定义模型时特别有用，因为默认的批量大小可能不是最优的：

```tsx
const { images } = await generateImage({
  model: __IMAGE_MODEL__,
  prompt: 'Santa Claus driving a Cadillac',
  maxImagesPerCall: 5, // 覆盖默认批量大小
  n: 10, // 将进行 2 次调用，每次生成 5 张图像
});
```

### 提供种子值

您可以向 `generateImage` 函数提供种子值来控制图像生成过程的输出。
如果模型支持，相同的种子值将始终生成相同的图像。

```tsx highlight={"7"}
import { generateImage } from 'ai';
__PROVIDER_IMPORT__;

const { image } = await generateImage({
  model: __IMAGE_MODEL__,
  prompt: 'Santa Claus driving a Cadillac',
  seed: 1234567890,
});
```

### 提供商特定设置

图像模型通常具有提供商甚至模型特定的设置。
您可以使用 `providerOptions` 参数将这些设置传递给 `generateImage` 函数。
提供商的选项（如下例中的 `openai`）将成为请求体属性。

```tsx highlight={"8-13"}
import { generateImage } from 'ai';
import { openai, type OpenAIImageModelGenerationOptions } from '@ai-sdk/openai';

const { image } = await generateImage({
  model: openai.image('dall-e-3'),
  prompt: 'Santa Claus driving a Cadillac',
  size: '1024x1024',
  providerOptions: {
    openai: {
      style: 'vivid',
      quality: 'hd',
    } satisfies OpenAIImageModelGenerationOptions,
  },
});
```

### 中止信号和超时

`generateImage` 接受一个可选的 `abortSignal` 参数，类型为
[`AbortSignal`](https://developer.mozilla.org/en-US/docs/Web/API/AbortSignal)，
您可以使用它来中止图像生成过程或设置超时。

```ts highlight={"7"}
import { generateImage } from 'ai';
__PROVIDER_IMPORT__;

const { image } = await generateImage({
  model: __IMAGE_MODEL__,
  prompt: 'Santa Claus driving a Cadillac',
  abortSignal: AbortSignal.timeout(1000), // 1 秒后中止
});
```

### 自定义请求头

`generateImage` 接受一个可选的 `headers` 参数，类型为 `Record<string, string>`，
您可以使用它向图像生成请求添加自定义请求头。

```ts highlight={"7"}
import { generateImage } from 'ai';
__PROVIDER_IMPORT__;

const { image } = await generateImage({
  model: __IMAGE_MODEL__,
  prompt: 'Santa Claus driving a Cadillac',
  headers: { 'X-Custom-Header': 'custom-value' },
});
```

### 警告

如果模型返回警告（例如针对不支持的参数），这些警告将出现在响应的 `warnings` 属性中。

```tsx
const { image, warnings } = await generateImage({
  model: __IMAGE_MODEL__,
  prompt: 'Santa Claus driving a Cadillac',
});
```

### 提供商元数据

某些提供商会公开单个图像的元数据。这些元数据可直接在生成的图像上获取：

```tsx
const prompt = 'Santa Claus driving a Cadillac';

const { image } = await generateImage({
  model: openai.image('dall-e-3'),
  prompt,
});

const revisedPrompt = image.providerMetadata?.openai?.revisedPrompt;

console.log({
  prompt,
  revisedPrompt,
});
```

`image.providerMetadata` 的外层键是提供商名称。内层值是该图像的元数据。

### 底层调用

当请求被拆分为多个提供商调用时，`calls` 会保留每次调用的图像、提供商元数据、响应元数据、警告和使用量。`images` 和 `usage` 仍然分别提供便捷的扁平化视图和聚合视图。

```ts
const { calls } = await generateImage({
  model,
  prompt: 'Santa Claus driving a Cadillac',
  n: 4,
  maxImagesPerCall: 1,
});

for (const call of calls) {
  console.log(call.providerMetadata, call.usage);
}
```

### 错误处理

当 `generateImage` 无法生成有效图像时，它会抛出 [`AI_NoImageGeneratedError`](/docs/reference/ai-sdk-errors/ai-no-image-generated-error) 错误。

当 AI 提供商无法生成图像时会发生此错误。可能由以下原因引起：

- 模型未能生成响应
- 模型生成的响应无法解析

该错误保留了以下信息以帮助您记录问题：

- `calls`：底层图像模型调用的结果，包括生成的图像、提供商元数据、响应元数据、警告和使用量。
- `responses`：图像模型响应的元数据，包括时间戳、模型和请求头。
- `cause`：错误的原因。您可以使用它进行更详细的错误处理。

```ts
import { generateImage, NoImageGeneratedError } from 'ai';

try {
  await generateImage({ model, prompt });
} catch (error) {
  if (NoImageGeneratedError.isInstance(error)) {
    console.log('NoImageGeneratedError');
    console.log('Cause:', error.cause);
    console.log('Responses:', error.responses);

    for (const call of error.calls ?? []) {
      console.log('Provider metadata:', call.providerMetadata);
      console.log('Warnings:', call.warnings);
      console.log('Usage:', call.usage);
    }
  }
}
```

## 图像中间件

您可以使用 `wrapImageModel` 和 `ImageModelV4Middleware` 来增强图像模型，例如设置默认值或实现日志记录。

以下是一个在未提供尺寸时设置默认尺寸的示例：

```ts
import { generateImage, wrapImageModel } from 'ai';
__PROVIDER_IMPORT__;

const model = wrapImageModel({
  model: __IMAGE_MODEL__,
  middleware: {
    specificationVersion: 'v3',
    transformParams: async ({ params }) => ({
      ...params,
      size: params.size ?? '1024x1024',
    }),
  },
});

const { image } = await generateImage({
  model,
  prompt: 'Santa Claus driving a Cadillac',
});
```

## 使用语言模型生成图像

某些语言模型（如 Google `gemini-2.5-flash-image`）支持包括图像在内的多模态输出。
使用此类模型时，您可以通过响应的 `files` 属性访问生成的图像。

```ts
import { google } from '@ai-sdk/google';
import { generateText } from 'ai';

const result = await generateText({
  model: google('gemini-2.5-flash-image'),
  prompt: 'Generate an image of a comic cat',
});

for (const file of result.files) {
  if (file.mediaType.startsWith('image/')) {
    // 文件对象提供多种数据格式：
    // 以 base64 字符串、Uint8Array 二进制数据访问图像，或检查类型
    // - file.base64: string (data URL 格式)
    // - file.uint8Array: Uint8Array (二进制数据)
    // - file.mediaType: string (例如 "image/png")
  }
}
```
