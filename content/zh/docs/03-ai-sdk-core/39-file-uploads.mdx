# 文件上传

AI SDK 提供了 [`uploadFile`](/docs/reference/ai-sdk-core/upload-file)
函数，用于将文件上传到提供商，并返回一个可在后续 API 调用中使用的 `ProviderReference`。

在 AI SDK 中，上传的文件通过 `ProviderReference` 标识——这是一个
`Record<string, string>` 类型，将提供商名称映射到提供商特定的标识符。
此概念也用于其他提供商特定的资产引用，例如上传的技能。

```ts
import { uploadFile, generateText } from 'ai';
import { openai } from '@ai-sdk/openai';
import fs from 'node:fs';

const { providerReference } = await uploadFile({
  api: openai.files(),
  data: fs.readFileSync('./photo.png'),
  filename: 'photo.png',
});

const { text } = await generateText({
  model: openai.responses('gpt-4o-mini'),
  messages: [
    {
      role: 'user',
      content: [
        { type: 'text', text: '描述你在这张图片中看到的内容。' },
        { type: 'file', mediaType: 'image', data: providerReference },
      ],
    },
  ],
});
```

作为简写，你可以直接将提供商实例传递给 `api`，而无需显式调用 `.files()`——SDK 会自动为你调用 `.files()`：

```ts highlight="3"
const { providerReference } = await uploadFile({
  api: openai, // 简写形式，等同于 openai.files()
  data: fs.readFileSync('./photo.png'),
  filename: 'photo.png',
});
```

## 支持的文件类型

你可以上传图片、PDF、文本文件以及其他文档，具体取决于提供商。
当未显式指定媒体类型时，系统会根据文件字节自动检测：

```ts highlight="4"
const { providerReference } = await uploadFile({
  api: anthropic.files(),
  data: fs.readFileSync('./document.pdf'),
  mediaType: 'application/pdf', // 可选，省略时自动检测
  filename: 'document.pdf',
});
```

在文件内容部分中使用 `providerReference` 及其媒体类型：

```ts
{
  role: 'user',
  content: [
    { type: 'text', text: '总结这份文档。' },
    { type: 'file', data: providerReference, mediaType: 'application/pdf' },
  ],
}
```

## 提供商特定选项

某些提供商通过 `providerOptions` 接受额外选项。
例如，OpenAI 需要 `purpose` 字段：

```ts highlight="5-9"
import { openai, type OpenAIFilesOptions } from '@ai-sdk/openai';

const { providerReference } = await uploadFile({
  api: openai.files(),
  data: fs.readFileSync('./photo.png'),
  providerOptions: {
    openai: {
      purpose: 'assistants',
    } satisfies OpenAIFilesOptions,
  },
});
```

## 提供商引用

`ProviderReference` 是一个 `Record<string, string>` 类型，将提供商名称映射到
提供商特定的文件标识符：

```ts
// 示例 ProviderReference
{
  openai: 'file-abc123',
}
```

当你将 `ProviderReference` 作为消息内容部分的 `data` 或 `image` 字段传递时，
提供商会从引用中查找自己的文件 ID。如果引用中不包含当前提供商的条目，
则会抛出错误。

## 多提供商使用

如果你在对话中切换提供商（例如，使用 Anthropic 继续由 OpenAI 开始的聊天），
则需要将文件上传到两个提供商并合并引用：

```ts
const openaiResult = await uploadFile({
  api: openai.files(),
  data: imageBytes,
  filename: 'photo.png',
});

const anthropicResult = await uploadFile({
  api: anthropic.files(),
  data: imageBytes,
  filename: 'photo.png',
});

const mergedReference = {
  ...openaiResult.providerReference,
  ...anthropicResult.providerReference,
};

// mergedReference: { openai: 'file-abc123', anthropic: 'file-xyz789' }
```

合并后的引用随后可以在消息中使用，无论哪个提供商处理请求——每个提供商都会找到自己的文件 ID。

## 支持的提供商

以下提供商支持 `files()` 和文件上传：

| 提供商    | 工厂方法              |
| --------- | ------------------- |
| Anthropic | `anthropic.files()` |
| Google    | `google.files()`    |
| OpenAI    | `openai.files()`    |
| xAI       | `xai.files()`       |

不支持文件上传的提供商在遇到消息中的提供商引用时，会抛出 `UnsupportedFunctionalityError` 错误。
