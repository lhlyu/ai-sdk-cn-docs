# 语音合成

AI SDK 提供了 [`generateSpeech`](/docs/reference/ai-sdk-core/generate-speech)
函数，用于使用语音模型从文本生成语音。

```ts
import { generateSpeech } from 'ai';
import { openai } from '@ai-sdk/openai';

const audio = await generateSpeech({
  model: openai.speech('tts-1'),
  text: 'Hello, world!',
  voice: 'alloy',
});
```

### 语言设置

您可以指定语音生成的语言（提供商支持情况有所不同）：

```ts
import { generateSpeech } from 'ai';
import { lmnt } from '@ai-sdk/lmnt';

const audio = await generateSpeech({
  model: lmnt.speech('aurora'),
  text: 'Hola, mundo!',
  language: 'es', // 西班牙语
});
```

要访问生成的音频：

```ts
const audioData = result.audio.uint8Array; // 音频数据，类型为 Uint8Array
// 或者
const audioBase64 = result.audio.base64; // 音频数据，类型为 base64 字符串
```

## 设置

### 提供商特定设置

您可以使用 `providerOptions` 参数设置模型特定的设置。

```ts highlight="7-11"
import { generateSpeech } from 'ai';
import { openai } from '@ai-sdk/openai';

const audio = await generateSpeech({
  model: openai.speech('tts-1'),
  text: 'Hello, world!',
  providerOptions: {
    openai: {
      // ...
    },
  },
});
```

### 中止信号与超时

`generateSpeech` 接受一个可选的 `abortSignal` 参数，类型为
[`AbortSignal`](https://developer.mozilla.org/en-US/docs/Web/API/AbortSignal)，
您可以使用它来中止语音生成过程或设置超时。

```ts highlight="7"
import { openai } from '@ai-sdk/openai';
import { generateSpeech } from 'ai';

const audio = await generateSpeech({
  model: openai.speech('tts-1'),
  text: 'Hello, world!',
  abortSignal: AbortSignal.timeout(1000), // 1 秒后中止
});
```

### 自定义请求头

`generateSpeech` 接受一个可选的 `headers` 参数，类型为 `Record<string, string>`，
您可以使用它为语音生成请求添加自定义请求头。

```ts highlight="7"
import { openai } from '@ai-sdk/openai';
import { generateSpeech } from 'ai';

const audio = await generateSpeech({
  model: openai.speech('tts-1'),
  text: 'Hello, world!',
  headers: { 'X-Custom-Header': 'custom-value' },
});
```

### 警告

警告（例如不支持的参数）可在 `warnings` 属性上获取。

```ts
import { openai } from '@ai-sdk/openai';
import { generateSpeech } from 'ai';

const audio = await generateSpeech({
  model: openai.speech('tts-1'),
  text: 'Hello, world!',
});

const warnings = audio.warnings;
```

### 错误处理

当 `generateSpeech` 无法生成有效的音频时，它会抛出 [`AI_NoSpeechGeneratedError`](/docs/reference/ai-sdk-errors/ai-no-speech-generated-error)。

此错误可能由以下任一原因引起：

- 模型未能生成响应
- 模型生成的响应无法解析

该错误保留了以下信息，以帮助您记录问题：

- `responses`：语音模型响应的元数据，包括时间戳、模型和请求头。
- `cause`：错误的原因。您可以使用它进行更详细的错误处理。

```ts
import { generateSpeech, NoSpeechGeneratedError } from 'ai';
import { openai } from '@ai-sdk/openai';

try {
  await generateSpeech({
    model: openai.speech('tts-1'),
    text: 'Hello, world!',
  });
} catch (error) {
  if (NoSpeechGeneratedError.isInstance(error)) {
    console.log('AI_NoSpeechGeneratedError');
    console.log('原因:', error.cause);
    console.log('响应:', error.responses);
  }
}
```
