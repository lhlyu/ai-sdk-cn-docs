# 生成结构化数据

虽然文本生成很有用，但你的用例很可能需要生成结构化数据。例如，你可能需要从文本中提取信息、对数据进行分类，或生成合成数据。

许多语言模型能够生成结构化数据，通常通过“JSON 模式”或“工具”来实现。然而，你需要手动提供模式并验证生成的数据，因为大语言模型可能会产生不正确或不完整的结构化数据。

AI SDK 通过 `generateText` 和 `streamText` 上的 `output` 属性，标准化了跨模型提供商的结构化对象生成。你可以使用 [Zod 模式](/docs/reference/ai-sdk-core/zod-schema)、[Valibot](/docs/reference/ai-sdk-core/valibot-schema) 或 [JSON 模式](/docs/reference/ai-sdk-core/json-schema) 来指定所需数据的形状，AI 模型将生成符合该结构的数据。

<Note>
  结构化输出生成是 `generateText` 和 `streamText` 流程的一部分。这意味着你可以在同一请求中将其与工具调用结合使用。
</Note>

## 生成结构化输出

使用带有 `Output.object()` 的 `generateText` 从提示词生成结构化数据。该模式还用于验证生成的数据，确保类型安全和正确性。

```ts
import { generateText, Output } from 'ai';
__PROVIDER_IMPORT__;
import { z } from 'zod';

const { output } = await generateText({
  model: __MODEL__,
  output: Output.object({
    schema: z.object({
      recipe: z.object({
        name: z.string(),
        ingredients: z.array(
          z.object({ name: z.string(), amount: z.string() }),
        ),
        steps: z.array(z.string()),
      }),
    }),
  }),
  prompt: 'Generate a lasagna recipe.',
});
```

<Note>
  在 AI SDK 的多轮执行模型中（每次模型调用或工具执行为一步），结构化输出生成计为一步。当与工具结合使用时，请在 `stopWhen` 配置中考虑这一点。
</Note>

### 访问响应头与响应体

有时你需要访问模型提供商的完整响应，例如获取某些提供商特定的头信息或响应体内容。

你可以使用 `response` 属性访问原始响应头和响应体：

```ts
import { generateText, Output } from 'ai';

const result = await generateText({
  // ...
  output: Output.object({ schema }),
});

console.log(JSON.stringify(result.response.headers, null, 2));
console.log(JSON.stringify(result.response.body, null, 2));
```

## 流式传输结构化输出

由于返回结构化数据增加了复杂性，模型响应时间可能对你的交互式用例来说不可接受。通过 `streamText` 和 `output`，你可以在生成过程中流式传输模型的结构化响应。

```ts
import { streamText, Output } from 'ai';
__PROVIDER_IMPORT__;
import { z } from 'zod';

const { partialOutputStream } = streamText({
  model: __MODEL__,
  output: Output.object({
    schema: z.object({
      recipe: z.object({
        name: z.string(),
        ingredients: z.array(
          z.object({ name: z.string(), amount: z.string() }),
        ),
        steps: z.array(z.string()),
      }),
    }),
  }),
  prompt: 'Generate a lasagna recipe.',
});

// 将 partialOutputStream 用作异步可迭代对象
for await (const partialObject of partialOutputStream) {
  console.log(partialObject);
}
```

你可以在客户端使用 [`useObject`](/docs/reference/ai-sdk-ui/use-object) Hook 消费结构化输出。

### 流中的错误处理

`streamText` 会立即开始流式传输。当流式传输过程中发生错误时，它们会成为流的一部分，而不是抛出异常（以防止流崩溃）。

要处理错误，请提供 `onError` 回调：

```tsx highlight="5-7"
import { streamText, Output } from 'ai';

const result = streamText({
  // ...
  output: Output.object({ schema }),
  onError({ error }) {
    console.error(error); // 记录到你的错误跟踪服务
  },
});
```

关于 `generateText` 的非流式错误处理，请参见下面的[错误处理](#错误处理)部分。

## 输出类型

AI SDK 支持通过 `Output` 对象以多种方式指定生成数据的预期结构。你可以从不同的结构化/文本生成和验证策略中进行选择。

### `Output.text()`

使用 `Output.text()` 从模型生成纯文本。此选项不对结果强制任何模式：你只需接收模型返回的字符串文本。当未指定 `output` 时，这是默认行为。

```ts
import { generateText, Output } from 'ai';

const { output } = await generateText({
  // ...
  output: Output.text(),
  prompt: 'Tell me a joke.',
});
// output 将是一个字符串（笑话）
```

### `Output.object()`

使用 `Output.object({ schema })` 基于模式（例如 Zod 模式）生成结构化对象。输出会经过类型验证，以确保返回的结果符合模式。

```ts
import { generateText, Output } from 'ai';
import { z } from 'zod';

const { output } = await generateText({
  // ...
  output: Output.object({
    schema: z.object({
      name: z.string(),
      age: z.number().nullable(),
      labels: z.array(z.string()),
    }),
  }),
  prompt: 'Generate information for a test user.',
});
// output 将是一个符合上述模式的对象
```

<Note>
  通过 `streamText` 流式传输的部分输出无法根据你提供的模式进行验证，因为不完整的数据可能尚未符合预期结构。
</Note>

### `Output.array()`

使用 `Output.array({ element })` 指定你期望从模型获得一个类型化对象数组，其中每个元素应符合 `element` 属性中定义的模式。

```ts
import { generateText, Output } from 'ai';
import { z } from 'zod';

const { output } = await generateText({
  // ...
  output: Output.array({
    element: z.object({
      location: z.string(),
      temperature: z.number(),
      condition: z.string(),
    }),
  }),
  prompt: 'List the weather for San Francisco and Paris.',
});
// output 将是一个对象数组，例如：
// [
//   { location: 'San Francisco', temperature: 70, condition: 'Sunny' },
//   { location: 'Paris', temperature: 65, condition: 'Cloudy' },
// ]
```

当使用 `streamText` 流式传输数组时，你可以使用 `elementStream` 在生成每个完整元素时接收它：

```ts
import { streamText, Output } from 'ai';
import { z } from 'zod';

const { elementStream } = streamText({
  // ...
  output: Output.array({
    element: z.object({
      name: z.string(),
      class: z.string(),
      description: z.string(),
    }),
  }),
  prompt: 'Generate 3 hero descriptions for a fantasy role playing game.',
});

for await (const hero of elementStream) {
  console.log(hero); // 每个英雄都是完整且经过验证的
}
```

<Note>
  `elementStream` 发出的每个元素都是完整的，并已根据你的元素模式进行验证。这与 `partialOutputStream` 不同，后者流式传输整个部分数组，包括不完整的元素。
</Note>

### `Output.choice()`

当你期望模型从一组特定的字符串选项中进行选择时，例如用于分类或固定枚举答案，请使用 `Output.choice({ options })`。

```ts
import { generateText, Output } from 'ai';

const { output } = await generateText({
  // ...
  output: Output.choice({
    options: ['sunny', 'rainy', 'snowy'],
  }),
  prompt: 'Is the weather sunny, rainy, or snowy today?',
});
// output 将是以下之一：'sunny'、'rainy' 或 'snowy'
```

你可以提供任何字符串选项集合，输出将始终是一个与指定选项之一匹配的字符串值。AI SDK 会验证结果是否匹配你的某个选项，如果模型返回无效内容，则会抛出错误。

这对于进行分类式生成或为 API 兼容性强制有效值特别有用。

### `Output.json()`

当你希望从模型生成并解析非结构化的 JSON 值，而不强制使用特定模式时，请使用 `Output.json()`。如果你希望捕获任意对象、灵活结构，或希望依赖模型的自然输出而非严格验证，这非常有用。

```ts
import { generateText, Output } from 'ai';

const { output } = await generateText({
  // ...
  output: Output.json(),
  prompt:
    'For each city, return the current temperature and weather condition as a JSON object.',
});

// output 可以是任何有效的 JSON，例如：
// {
//   "San Francisco": { "temperature": 70, "condition": "Sunny" },
//   "Paris": { "temperature": 65, "condition": "Cloudy" }
// }
```

使用 `Output.json` 时，AI SDK 仅检查响应是否为有效的 JSON；它不会验证值的结构或类型。如果需要模式验证，请改用 `.object` 或 `.array` 输出。

有关更高级的验证或不同结构，请参见 [Output API 参考](/docs/reference/ai-sdk-core/output)。

## 使用工具生成结构化输出

将结构化输出与 `generateText` 和 `streamText` 结合使用的关键优势之一是能够与工具调用结合。

```ts
import { generateText, Output, tool, isStepCount } from 'ai';
__PROVIDER_IMPORT__;
import { z } from 'zod';

const { output } = await generateText({
  model: __MODEL__,
  tools: {
    weather: tool({
      description: 'Get the weather for a location',
      inputSchema: z.object({ location: z.string() }),
      execute: async ({ location }) => {
        // 获取天气数据
        return { temperature: 72, condition: 'sunny' };
      },
    }),
  },
  output: Output.object({
    schema: z.object({
      summary: z.string(),
      recommendation: z.string(),
    }),
  }),
  stopWhen: isStepCount(5),
  prompt: 'What should I wear in San Francisco today?',
});
```

<Note>
  当将工具与结构化输出一起使用时，请记住生成结构化输出计为一步。配置 `stopWhen` 以允许足够的步骤用于工具执行和输出生成。
</Note>

## 属性描述

你可以向单个模式属性添加 `.describe("...")`，以向模型提示每个属性的用途。这有助于提高生成结构化数据的质量和准确性：

```ts highlight="5,9"
import { generateText, Output } from 'ai';
__PROVIDER_IMPORT__;
import { z } from 'zod';

const { output } = await generateText({
  model: __MODEL__,
  output: Output.object({
    schema: z.object({
      name: z.string().describe('The name of the recipe'),
      ingredients: z
        .array(
          z.object({
            name: z.string(),
            amount: z
              .string()
              .describe('The amount of the ingredient (grams or ml)'),
          }),
        )
        .describe('List of ingredients with amounts'),
      steps: z.array(z.string()).describe('Step-by-step cooking instructions'),
    }),
  }),
  prompt: 'Generate a lasagna recipe.',
});
```

属性描述在以下情况下特别有用：

- 澄清模糊的属性名称
- 指定预期格式或约定
- 为复杂的嵌套结构提供上下文

## 输出名称与描述

你可以选择为输出指定 `name` 和 `description`。某些提供商使用这些信息进行额外的 LLM 指导，例如通过工具或模式名称。

```ts highlight="6-7"
import { generateText, Output } from 'ai';
__PROVIDER_IMPORT__;
import { z } from 'zod';

const { output } = await generateText({
  model: __MODEL__,
  output: Output.object({
    name: 'Recipe',
    description: 'A recipe for a dish.',
    schema: z.object({
      name: z.string(),
      ingredients: z.array(z.object({ name: z.string(), amount: z.string() })),
      steps: z.array(z.string()),
    }),
  }),
  prompt: 'Generate a lasagna recipe.',
});
```

这适用于所有支持结构化生成的输出类型：

- `Output.object({ name, description, schema })`
- `Output.array({ name, description, element })`
- `Output.choice({ name, description, options })`
- `Output.json({ name, description })`

## 访问推理过程

你可以通过结果上的 `reasoning` 属性访问语言模型用于生成对象的推理过程。如果可用，此属性包含一个字符串，表示模型的思考过程。

```ts
import { generateText, Output } from 'ai';
__PROVIDER_IMPORT__;
import { z } from 'zod';

const result = await generateText({
  model: __MODEL__, // 必须是推理模型
  output: Output.object({
    schema: z.object({
      recipe: z.object({
        name: z.string(),
        ingredients: z.array(
          z.object({
            name: z.string(),
            amount: z.string(),
          }),
        ),
        steps: z.array(z.string()),
      }),
    }),
  }),
  prompt: 'Generate a lasagna recipe.',
});

console.log(result.reasoningText);
```

## 错误处理

当带有结构化输出的 `generateText` 无法生成有效对象时，它会抛出一个 [`AI_NoObjectGeneratedError`](/docs/reference/ai-sdk-errors/ai-no-object-generated-error)。

当 AI 提供商未能生成符合模式的可解析对象时，会发生此错误。可能由以下原因引起：

- 模型未能生成响应。
- 模型生成的响应无法解析。
- 模型生成的响应无法根据模式进行验证。

该错误保留了以下信息以帮助你记录问题：

- `text`：模型生成的文本。根据对象生成模式，这可以是原始文本或工具调用文本。
- `response`：语言模型响应的元数据，包括响应 ID、时间戳和模型。
- `usage`：请求的令牌使用情况。
- `cause`：错误的原因（例如 JSON 解析错误）。你可以使用它进行更详细的错误处理。

```ts
import { generateText, Output, NoObjectGeneratedError } from 'ai';

try {
  await generateText({
    model,
    output: Output.object({ schema }),
    prompt,
  });
} catch (error) {
  if (NoObjectGeneratedError.isInstance(error)) {
    console.log('NoObjectGeneratedError');
    console.log('Cause:', error.cause);
    console.log('Text:', error.text);
    console.log('Response:', error.response);
    console.log('Usage:', error.usage);
  }
}
```
