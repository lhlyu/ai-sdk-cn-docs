# AI SDK Core

大型语言模型（LLMs）是先进的程序，能够大规模理解、生成和参与人类语言对话。
它们通过海量书面材料训练，学习识别语言模式并预测给定文本中接下来可能出现的内容。

AI SDK Core **通过提供标准化的方式将 LLMs 集成到你的应用中，简化了与 LLMs 的协作**——让你专注于为用户构建出色的 AI 应用，而不是在技术细节上浪费时间。

## AI SDK Core 函数

AI SDK Core 提供了多种函数，专为[文本生成](./generating-text)、[结构化数据生成](./generating-structured-data)和[工具使用](./tools-and-tool-calling)而设计。
这些函数采用标准化方法来设置[提示词](/docs/foundations/prompts)和[设置](./settings)，使与不同模型的协作更加便捷。

- [`generateText`](/docs/ai-sdk-core/generating-text)：生成文本和[工具调用](./tools-and-tool-calling)。
  此函数适用于非交互式用例，例如需要编写文本的自动化任务（如起草邮件或总结网页），以及使用工具的智能体。
- [`streamText`](/docs/ai-sdk-core/generating-text)：流式传输文本和工具调用。
  你可以将 `streamText` 函数用于交互式用例，例如[聊天机器人](/docs/ai-sdk-ui/chatbot)和[内容流式传输](/docs/ai-sdk-ui/completion)。

`generateText` 和 `streamText` 都通过 `output` 属性（例如 `Output.object()`、`Output.array()`）支持[结构化输出](/docs/ai-sdk-core/generating-structured-data)，允许你生成类型化、经过模式验证的数据，用于信息提取、合成数据生成、分类任务以及[流式生成 UI](/docs/ai-sdk-ui/object-generation)。
