# Scorecard

[Scorecard](https://www.scorecard.io/) 是一个用于监控和评估 LLM 应用的可观测性平台。
与 AI SDK 集成后，您可以使用 Scorecard 追踪、监控和分析您的 LLM 提供商、提示词以及应用流程。

## 设置

Scorecard 支持 [AI SDK 遥测数据](/docs/ai-sdk-core/telemetry)。
您需要在 https://app.scorecard.io 注册，并从[设置页面](https://app.scorecard.io/settings)获取 API 密钥。

### Next.js

要使用 AI SDK 向 Scorecard 发送遥测数据，首先在项目中设置以下环境变量：

```bash
OTEL_EXPORTER_OTLP_ENDPOINT=https://tracing.scorecard.io/otel/v1/traces
OTEL_EXPORTER_OTLP_HEADERS="Authorization=Bearer <您的 Scorecard API 密钥>"
```

接下来，安装 `@ai-sdk/otel` 并在项目根目录创建 `instrumentation.ts` 文件，以初始化 OpenTelemetry 并注册 AI SDK 遥测集成：

```typescript filename="instrumentation.ts"
import { registerTelemetry } from 'ai';
import { LegacyOpenTelemetry } from '@ai-sdk/otel';
import { registerOTel } from '@vercel/otel';

registerTelemetry(new LegacyOpenTelemetry());

export function register() {
  registerOTel({
    serviceName: 'my-service-name',
  });
}
```

集成注册后，所有 AI SDK 调用的遥测数据将自动捕获：

```typescript
import { generateText } from 'ai';
import { openai } from '@ai-sdk/openai';

const result = await generateText({
  model: openai('gpt-4o-mini'),
  prompt: '给我讲个笑话',
});
```

## 在 Scorecard 中查看的内容

集成后，您可以在 Scorecard 仪表板中查看：

- **LLM 调用追踪**：每次 AI SDK 调用的详细信息
- **性能指标**：延迟、令牌使用量和成本追踪
- **模型信息**：使用了哪些模型和提供商
- **自定义上下文**：通过 `context` 选项提供的任何额外上下文
- **错误追踪**：失败的请求和调试信息
- **使用分析**：LLM 使用模式与趋势
