# Weave 可观测性

[Weave](https://wandb.ai/site/weave) 是由 [Weights & Biases](https://wandb.ai/site/) 构建的工具包，用于跟踪、实验、评估、部署和改进基于 LLM 的应用。

与 AI SDK 集成后，您可以使用 Weave 查看 AI SDK 应用的追踪信息并与之交互，包括提示词、响应、流程、成本等。

## 设置

要将 Weave 设置为 [OpenTelemetry](https://opentelemetry.io/docs/) 后端，您需要将追踪路由到 Weave 的 OpenTelemetry 端点，设置 API 密钥，并指定团队和项目。为了将追踪记录到 Weave，您必须拥有 [Weights & Biases 账户](https://wandb.ai/site/weave)。

### 身份验证

首先，前往 [wandb.ai/authorize](https://wandb.ai/authorize)，复制您的 API 密钥，并通过运行以下命令生成 base64 编码的授权字符串：

```bash
echo -n "api:<YOUR_API_KEY>" | base64
```

记下输出结果。您将在环境配置中使用它。

### 项目配置

您的 W&B 项目 ID 标识了遥测数据的记录位置。
其格式为 `<YOUR_TEAM_NAME>/<YOUR_PROJECT_NAME>`。

1. 导航至 [Weights & Biases 仪表盘](https://wandb.ai/home)。
2. 在 **团队** 部分，选择或创建一个团队。
3. 选择一个现有项目或创建一个新项目。
4. 记下 `<YOUR_TEAM_NAME>/<YOUR_PROJECT_NAME>` 以供下一步使用。

### Next.js

在您的 Next.js 应用的 `.env` 文件中，设置 OTEL 环境变量。将 `<BASE64_AUTH_STRING>` 和 `<YOUR_TEAM_NAME>/<YOUR_PROJECT_NAME>` 替换为前几步中的值：

```bash
OTEL_EXPORTER_OTLP_ENDPOINT="https://trace.wandb.ai/otel/v1/traces"
OTEL_EXPORTER_OTLP_HEADERS="Authorization=Basic <BASE64_AUTH_STRING>,project_id=<YOUR_TEAM_NAME>/<YOUR_PROJECT_NAME>"
```

安装 `@ai-sdk/otel` 并在您的 `instrumentation.ts` 文件中注册 `LegacyOpenTelemetry`：

```typescript filename="instrumentation.ts"
import { registerTelemetry } from 'ai';
import { LegacyOpenTelemetry } from '@ai-sdk/otel';

registerTelemetry(new LegacyOpenTelemetry());
```

然后，您可以使用 `telemetry` 选项在支持的 AI SDK 函数调用上启用遥测：

```typescript
import { generateText } from 'ai';
import { openai } from '@ai-sdk/openai';

const result = await generateText({
  model: openai('gpt-4o-mini'),
  prompt: '2 + 2 等于多少？',
  telemetry: {
    metadata: {
      query: 'math',
      difficulty: 'easy',
    },
  },
});
```
