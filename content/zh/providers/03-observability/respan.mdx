# Respan 可观测性

[Respan](https://www.respan.ai/)（前身为 Keywords AI）是一个用于可观测性、评估和网关路由的 LLM 工程平台。Respan 与 AI SDK 集成，提供：

- 每次 AI SDK 调用的追踪（输入、输出、token 用量、成本、延迟）
- 工具调用和结构化输出捕获
- 可选的网关路由，通过单一端点访问 250+ 模型

## 设置

AI SDK 支持通过 OpenTelemetry 进行追踪。使用来自 `@respan/instrumentation-vercel` 的 `VercelAIInstrumentor`，追踪数据会自动导出到 Respan。

### 安装

```bash
npm install ai @ai-sdk/openai @respan/respan @respan/instrumentation-vercel
```

### 配置环境变量

```bash filename=".env"
RESPAN_API_KEY="your-respan-api-key"
```

从 [platform.respan.ai](https://platform.respan.ai/platform/api/api-keys) 获取你的 API 密钥。

### 初始化 Respan

<Tabs items={["Next.js", "Serverless / Node"]}>

<Tab>

在你的 Next.js 项目根目录创建 `instrumentation.ts`：

```ts filename="instrumentation.ts"
import { Respan } from '@respan/respan';
import { VercelAIInstrumentor } from '@respan/instrumentation-vercel';

export async function register() {
  const respan = new Respan({
    apiKey: process.env.RESPAN_API_KEY,
    instrumentations: [new VercelAIInstrumentor()],
  });
  await respan.initialize();
}
```

然后在 `next.config.ts` 中将 SDK 包标记为服务端外部包：

```ts filename="next.config.ts"
import type { NextConfig } from 'next';

const nextConfig: NextConfig = {
  serverExternalPackages: ['@respan/respan', '@respan/instrumentation-vercel'],
};

export default nextConfig;
```

</Tab>

<Tab>

在你的处理程序或入口点顶部初始化 Respan：

```ts
import { Respan } from '@respan/respan';
import { VercelAIInstrumentor } from '@respan/instrumentation-vercel';

const respan = new Respan({
  apiKey: process.env.RESPAN_API_KEY,
  instrumentations: [new VercelAIInstrumentor()],
});
await respan.initialize();
```

### 启用遥测生成文本

```ts
import { openai } from '@ai-sdk/openai';
import { generateText } from 'ai';

const result = await generateText({
  model: openai('gpt-6-luna'),
  prompt: 'Tell me a joke about AI',
  experimental_telemetry: { isEnabled: true },
});
```

Span 会出现在 [Respan 追踪页面](https://platform.respan.ai/platform/traces)中，包含输入、输出、token 用量和成本。

## 网关路由（可选）

要将 Respan 用作跨提供商的统一网关，请使用你的 `RESPAN_API_KEY` 将 AI SDK 提供商指向 Respan 网关。对于 OpenAI 提供商，使用 `https://api.respan.ai/api` 作为基础 URL。提供商密钥在 Respan 中管理；运行时只需要 Respan 密钥。

```ts
import { createOpenAI } from '@ai-sdk/openai';
import { generateText } from 'ai';

const provider = createOpenAI({
  apiKey: process.env.RESPAN_API_KEY!,
  baseURL: 'https://api.respan.ai/api',
});

const result = await generateText({
  model: provider('gpt-5.4-nano'),
  prompt: 'Tell me a joke about AI',
  experimental_telemetry: { isEnabled: true },
});
```

同一个网关端点在与各自的 AI SDK 提供商（`createAnthropic`、`createGoogleGenerativeAI`）以及匹配的基础路径（`/api/anthropic`、`/api/google/gemini`）一起使用时，也接受 Anthropic 和 Google 模型。
