# Axiom 可观测性

**Axiom** 是一个数据平台，具备针对 **AI 工程工作流** 的专门功能，帮助您自信地构建复杂的 AI 系统。

Axiom 与 AI SDK 的集成使用模型包装器来自动捕获每次 LLM 调用的详细追踪信息，让您立即了解应用程序的性能、成本和运行情况。

## 设置

### 1. 配置 Axiom

首先，您需要一个 Axiom 组织、一个用于发送追踪数据的数据集以及一个 API 令牌。

- [创建一个 Axiom 组织](https://app.axiom.co/register)。
- [创建一个新数据集](https://app.axiom.co/datasets)（例如，`my-ai-app`）。
- [创建一个 API 令牌](https://app.axiom.co/settings/api-tokens)，并为其授予数据集的摄取权限。

### 3. 设置环境变量

在 `.env` 文件中配置您的环境变量。这将使用标准的 OpenTelemetry 配置将追踪数据直接发送到您的 Axiom 数据集。

```bash filename=".env"
# Axiom 配置
AXIOM_TOKEN="YOUR_AXIOM_API_TOKEN"
AXIOM_DATASET="your-axiom-dataset-name"

# Vercel 和 OpenTelemetry 配置
OTEL_SERVICE_NAME="my-ai-app"
OTEL_EXPORTER_OTLP_ENDPOINT="https://api.axiom.co/v1/traces"
OTEL_EXPORTER_OTLP_HEADERS="Authorization=Bearer YOUR_AXIOM_API_TOKEN,X-Axiom-Dataset=your-axiom-dataset-name"

# 您的 AI 提供商密钥
OPENAI_API_KEY="YOUR_OPENAI_API_KEY"
```

将占位符值替换为您实际的 Axiom 令牌和数据集名称。

2. 创建检测文件：

```typescript filename="src/instrumentation.ts"
import { trace } from '@opentelemetry/api';
import { OTLPTraceExporter } from '@opentelemetry/exporter-trace-otlp-http';
import type { Resource } from '@opentelemetry/resources';
import { resourceFromAttributes } from '@opentelemetry/resources';
import { NodeSDK } from '@opentelemetry/sdk-node';
import { SimpleSpanProcessor } from '@opentelemetry/sdk-trace-node';
import { ATTR_SERVICE_NAME } from '@opentelemetry/semantic-conventions';
import { initAxiomAI, RedactionPolicy } from 'axiom/ai';

const tracer = trace.getTracer('my-tracer');

const sdk = new NodeSDK({
  resource: resourceFromAttributes({
    [ATTR_SERVICE_NAME]: 'my-ai-app',
  }) as Resource,
  spanProcessor: new SimpleSpanProcessor(
    new OTLPTraceExporter({
      url: `https://api.axiom.co/v1/traces`,
      headers: {
        Authorization: `Bearer ${process.env.AXIOM_TOKEN}`,
        'X-Axiom-Dataset': process.env.AXIOM_DATASET,
      },
    }),
  ),
});

sdk.start();

initAxiomAI({ tracer, redactionPolicy: RedactionPolicy.AxiomDefault });
```

### 5. 包装并使用 AI 模型

在您的应用程序代码中，从 Axiom 导入 `wrapAISDKModel`，并使用它来包装您现有的 AI SDK 模型客户端。

```typescript
import { createOpenAI } from '@ai-sdk/openai';
import { generateText } from 'ai';
import { wrapAISDKModel } from 'axiom/ai';

// 1. 创建您的标准 AI 模型提供商
const openaiProvider = createOpenAI({
  apiKey: process.env.OPENAI_API_KEY,
});

// 2. 包装模型以启用自动追踪
const tracedGpt4o = wrapAISDKModel(openaiProvider('gpt-4o'));

// 3. 像平常一样使用包装后的模型
const { text } = await generateText({
  model: tracedGpt4o,
  prompt: 'What is the capital of Spain?',
});

console.log(text);
```

使用 `tracedGpt4o` 模型进行的任何调用现在都会自动将详细的追踪信息发送到您的 Axiom 数据集。

## 在 Axiom 中您将看到的内容

集成后，您的 Axiom 数据集将包含：

- **AI 追踪瀑布图：** 一个专用视图，用于可视化单步和多步 LLM 工作流。
- **Gen AI 仪表板：** 一个预构建的仪表板，用于监控成本、延迟、令牌使用率和错误率。
- **详细跨度：** 每次调用的丰富遥测数据，包括完整的提示词和完成内容、令牌计数以及模型信息。

## 高级用法

Axiom 的 AI SDK 提供更高级的检测功能，以实现更深入的可见性：

- **业务上下文：** 使用 `withSpan` 函数将 LLM 调用分组到特定的业务能力下（例如，`customer_support_agent`）。
- **工具追踪：** 使用 `wrapTool` 辅助函数自动追踪 AI 模型调用的工具执行情况。

要了解有关这些功能的更多信息，请参阅 [Axiom AI SDK 检测指南](https://axiom.co/docs/ai-engineering/observe/axiom-ai-sdk-instrumentation)。
