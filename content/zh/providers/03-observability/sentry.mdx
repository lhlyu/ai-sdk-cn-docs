# Sentry 可观测性

[Sentry](https://sentry.io/) 可帮助您监控 AI 应用中的错误、追踪、延迟和令牌使用情况。Sentry 的 Next.js 和 Node.js SDK 通过原生 Node.js 遥测通道对 AI SDK v7 进行插桩，因此您无需使用 `@ai-sdk/otel` 或 `registerTelemetry` 即可将 AI SDK 追踪发送到 Sentry。

Sentry 会捕获 `generateText`、`streamText`、模型调用、工具调用、嵌入、重排序、令牌使用情况和错误的跨度。使用 AI SDK 的 `telemetry` 选项添加 `functionId`，可使追踪更易于在 Sentry 中查找和分组。

<Note>
  AI SDK v7 支持需要 `@sentry/node`、`@sentry/nextjs` 或其他 Sentry 服务器 SDK 版本 `10.62.0` 或更高版本。原生遥测通道在 Node.js 运行时中可用；请使用 Node.js 路由或服务器进程来处理这些追踪。
</Note>

## 设置

如果您的应用中已配置 Sentry，请跳至[用法](#usage)。否则，请在运行 AI SDK 调用之前，为您的运行时安装并初始化 Sentry SDK。

### Next.js

Sentry 向导可以为您创建完整的 Next.js 设置。以下代码片段展示了与 AI SDK 追踪相关的服务器端部分：

```bash
pnpm add @sentry/nextjs
```

创建或更新您的 Sentry 服务器配置，并使用 `tracesSampleRate` 或 `tracesSampler` 启用追踪：

```ts filename="sentry.server.config.ts"
import * as Sentry from '@sentry/nextjs';

Sentry.init({
  dsn: process.env.NEXT_PUBLIC_SENTRY_DSN,
  tracesSampleRate: 1.0,
});
```

如果您在 Next.js 中手动设置 Sentry，请确保您的 `instrumentation.ts` 为 Node.js 运行时加载服务器配置：

```ts filename="instrumentation.ts"
export async function register() {
  if (process.env.NEXT_RUNTIME === 'nodejs') {
    await import('./sentry.server.config');
  }
}
```

### Node.js

```bash
pnpm add @sentry/node
```

在服务器入口点开始时初始化 Sentry，并使用 `tracesSampleRate` 或 `tracesSampler` 启用追踪：

```ts filename="instrumentation.ts"
import * as Sentry from '@sentry/node';

Sentry.init({
  dsn: process.env.SENTRY_DSN,
  tracesSampleRate: 1.0,
});
```

Vercel AI 集成在 Sentry 服务器 SDK 中默认启用。如果您已禁用默认集成，请显式添加回来：

```ts
Sentry.init({
  dsn: process.env.SENTRY_DSN,
  tracesSampleRate: 1.0,
  integrations: [Sentry.vercelAIIntegration()],
});
```

## 用法

正常使用 AI SDK。Sentry 不需要 `registerTelemetry(new OpenTelemetry())` 调用或 `telemetry.isEnabled: true` 标志。

```ts filename="app/api/generate/route.ts"
import { anthropic } from '@ai-sdk/anthropic';
import { generateText } from 'ai';

export const runtime = 'nodejs';

export async function POST() {
  const result = await generateText({
    model: anthropic('claude-sonnet-4-5'),
    prompt: 'What is the weather in Tokyo?',
    telemetry: {
      functionId: 'anthropic-weather-demo',
    },
  });

  return Response.json({ text: result.text });
}
```

对于独立的 Node.js 脚本，将 AI SDK 调用包装在 Sentry 跨度中，以便 AI 跨度具有父级追踪，然后在进程退出前刷新：

```ts filename="index.ts"
import './instrumentation';
import * as Sentry from '@sentry/node';
import { openai } from '@ai-sdk/openai';
import { generateText } from 'ai';

await Sentry.startSpan({ name: 'ai-sdk-demo' }, async () => {
  const result = await generateText({
    model: openai('gpt-5-mini'),
    prompt: 'Write a haiku about observability.',
    telemetry: {
      functionId: 'haiku-demo',
    },
  });

  console.log(result.text);
});

await Sentry.flush(2000);
```

请求运行后，打开 Sentry 并在追踪中查找 `gen_ai.invoke_agent`、`gen_ai.generate_content` 和 `gen_ai.execute_tool` 跨度。

## 记录提示词和响应

默认情况下，Sentry 会记录元数据，例如模型、提供商、延迟、令牌使用情况和错误。提示词和响应内容仅在您选择加入时才会发送。

使用 Sentry 的 `dataCollection.genAI` 选项全局启用内容捕获：

```ts
Sentry.init({
  dsn: process.env.SENTRY_DSN,
  tracesSampleRate: 1.0,
  dataCollection: {
    genAI: {
      inputs: true,
      outputs: true,
    },
  },
});
```

或者使用 `telemetry` 选项为单个 AI SDK 调用启用它：

```ts
const result = await generateText({
  model: openai('gpt-5-mini'),
  prompt: 'Summarize this support ticket.',
  telemetry: {
    functionId: 'support-summary',
    recordInputs: true,
    recordOutputs: true,
  },
});
```

要为敏感调用选择退出 Sentry AI 遥测，请将 `telemetry.isEnabled` 设置为 `false`。
