# Laminar 可观测性

[Laminar](https://laminar.sh) 是一个[开源](https://github.com/lmnr-ai/lmnr)的、原生支持 Otel 的可观测性平台，专为 AI 智能体打造。

Laminar 的功能包括：

- [兼容 AI SDK 及更多框架的追踪](https://laminar.sh/docs/tracing/introduction)，
- [关于智能体行为的信号与告警](https://laminar.sh/docs/signals/introduction)，
- [评估](https://laminar.sh/docs/evaluations/introduction)，
- [智能体调试器](https://laminar.sh/docs/debugger/introduction)

<Note>
  本指南的另一个版本可在 [Laminar
  文档](https://laminar.sh/docs/tracing/integrations/vercel-ai-sdk)中找到。
</Note>

## 设置

你可以使用你的编码智能体来安装 Laminar，也可以手动安装。

### 使用编码智能体设置

复制下面的提示词并粘贴给你的编码智能体，让它全自动完成集成。

```markdown
1. 在项目根目录运行 `npx lmnr-cli setup` 开始使用 Laminar。该命令将对用户进行身份验证，将新的项目 API 密钥保存到 .env，并安装 Laminar skill。
2. 使用已安装的 skill 或文档，为本项目接入 Laminar：
   https://laminar.sh/docs/tracing/integrations/vercel-ai-sdk
3. 在你的应用中运行一条被追踪的路径。
4. 验证接入：
   `lmnr-cli sql query "SELECT * FROM traces ORDER BY start_time DESC LIMIT 1" --json`
```

### 手动设置

要手动设置 Laminar，首先安装 `@lmnr-ai/lmnr` 包。

<InstallPackages packages="@lmnr-ai/lmnr" />

### 获取项目 API 密钥并设置到环境中

然后，在 [Laminar](https://laminar.sh) 上注册，或自托管一个实例（[github](https://github.com/lmnr-ai/lmnr)），并创建一个新项目。

使用 `npx lmnr-cli@latest setup`。这将：

- 使用 Laminar 对你的设备进行身份验证，
- 创建一个新的项目 API 密钥并将其作为 `LMNR_PROJECT_API_KEY` 保存到你的 .env 中，
- 安装 Laminar skill，你的编码智能体将使用它来通过 Laminar SDK 为你的智能体接入。

## Next.js

### 初始化追踪

在 Next.js 中，Laminar 初始化和 AI SDK 遥测集成都应在 `instrumentation.{ts,js}` 中完成：

```javascript
export async function register() {
  // prevent this from running in the edge runtime
  if (process.env.NEXT_RUNTIME === 'nodejs') {
    const { registerTelemetry } = await import('ai');
    const { LaminarAiSdkTelemetry } = await import('@lmnr-ai/lmnr');

    registerTelemetry(new LaminarAiSdkTelemetry());
  }
}
```

### 将 @lmnr-ai/lmnr 添加到你的 next.config

在你的 `next.config.js`（`.ts` / `.mjs`）中，添加以下行：

```javascript
const nextConfig = {
  serverExternalPackages: ['@lmnr-ai/lmnr'],
};

export default nextConfig;
```

这是因为 Laminar 依赖 OpenTelemetry，而 OpenTelemetry 使用了一些 Node.js 特有的功能，我们需要告知 Next.js 这一点。在 [Next.js 文档](https://nextjs.org/docs/app/api-reference/config/next-config-js/serverExternalPackages)中了解更多。

### 追踪 AI SDK 调用

一旦集成注册完成，每次 AI SDK 调用都会自动捕获遥测数据：

```javascript
import { openai } from '@ai-sdk/openai';
import { generateText } from 'ai';

const { text } = await generateText({
  model: openai('gpt-6-luna'),
  prompt: 'What is Laminar flow?',
});
```

这将为 `ai.generateText` 创建 span。Laminar 收集并显示以下信息：

- LLM 调用的输入和输出
- 开始和结束时间
- 持续时间 / 延迟
- 使用的提供商和模型
- 输入和输出 token
- 输入和输出价格
- 附加元数据和 span 属性

### 旧版本的 Next.js

如果你使用的是 13.4 ≤ Next.js < 15，你还需要启用实验性的 instrumentation hook。将以下内容放入你的 `next.config.js`：

```javascript
module.exports = {
  experimental: {
    instrumentationHook: true,
  },
};
```

更多信息，请参阅 Laminar 的 [AI SDK 集成指南](https://laminar.sh/docs/tracing/integrations/vercel-ai-sdk)和 Next.js [instrumentation 文档](https://nextjs.org/docs/app/api-reference/file-conventions/instrumentation)。你也可以在文档中了解如何为 Next.js 启用所有追踪。

### 与 `@vercel/otel` 一起使用

Laminar 可以与 `@vercel/otel` 共存并追踪 AI SDK 调用。默认的 Laminar 设置将确保

- 常规的 Next.js 追踪通过 `@vercel/otel` 发送到你在 Vercel 配置的遥测后端，
- AI SDK 及其他 LLM 或浏览器智能体追踪通过 Laminar 发送。

```javascript
import { registerOTel } from '@vercel/otel';

export async function register() {
  if (process.env.NEXT_RUNTIME === 'nodejs') {
    const { registerTelemetry } = await import('ai');
    const { initializeLaminarInstrumentations, LaminarAiSdkTelemetry } =
      await import('@lmnr-ai/lmnr');

    // Next.js telemetry
    registerOTel({
      serviceName: 'my-service',
      instrumentations: initializeLaminarInstrumentations(),
    });

    // Laminar AI SDK telemetry
    registerTelemetry(new LaminarAiSdkTelemetry());
  }
}
```

关于允许你通过 Laminar 追踪所有 Next.js 追踪的高级配置，请参阅示例[仓库](https://github.com/lmnr-ai/lmnr-ts/tree/main/examples/nextjs)。

### 与 `@sentry/node` 一起使用

Laminar 可以与 `@sentry/node` 共存并追踪 AI SDK 调用。请确保在 `Sentry.init` **之后**初始化 Laminar。

这将确保

- 由 Sentry 接入的任何内容都发送到你的 Sentry 后端，
- AI SDK 及其他 LLM 或浏览器智能体追踪通过 Laminar 发送。

```javascript
export async function register() {
  if (process.env.NEXT_RUNTIME === 'nodejs') {
    const { registerTelemetry } = await import('ai');
    const Sentry = await import('@sentry/node');
    const { LaminarAiSdkTelemetry } = await import('@lmnr-ai/lmnr');

    Sentry.init({
      dsn: process.env.SENTRY_DSN,
    });

    // Make sure to initialize Laminar **after** `Sentry.init`
    registerTelemetry(new LaminarAiSdkTelemetry());
  }
}
```

## Node.js

### 初始化追踪

然后，在你的应用中初始化追踪：

```javascript
import { registerTelemetry } from 'ai';
import { LaminarAiSdkTelemetry } from '@lmnr-ai/lmnr';

registerTelemetry(new LaminarAiSdkTelemetry());
```

这必须在你的应用中执行一次，且尽可能早，但要在其他追踪库（例如 `@sentry/node`）初始化_之后_。

在 Laminar [文档](https://laminar.sh/docs/tracing/introduction)中了解更多。

### 追踪 AI SDK 调用

一旦集成注册完成，每次 AI SDK 调用都会自动捕获遥测数据：

```javascript
import { openai } from '@ai-sdk/openai';
import { generateText } from 'ai';

const { text } = await generateText({
  model: openai('gpt-6-luna'),
  prompt: 'What is Laminar flow?',
});
```

这将为 `ai.generateText` 创建 span。Laminar 收集并显示以下信息：

- LLM 调用的输入和输出
- 开始和结束时间
- 持续时间 / 延迟
- 使用的提供商和模型
- 输入和输出 token
- 输入和输出价格
- 附加元数据和 span 属性

### 与 `@sentry/node` 一起使用

Laminar 可以与 `@sentry/node` 一起工作以追踪 AI SDK 调用。请确保在 `Sentry.init` **之后**初始化 Laminar：

```javascript
const { LaminarAiSdkTelemetry } = await import('@lmnr-ai/lmnr');
const Sentry = await import('@sentry/node');
const { registerTelemetry } = await import('ai');

Sentry.init({
  dsn: process.env.SENTRY_DSN,
});

registerTelemetry(new LaminarAiSdkTelemetry());
```

这将确保

- 由 Sentry 接入的任何内容都发送到你的 Sentry 后端，
- AI SDK 及其他 LLM 或浏览器智能体追踪通过 Laminar 发送。

这两个库允许进行额外的进阶配置，但推荐使用上面的默认设置。

## 附加配置

### Laminar 选项

`LaminarAiSdkTelemetry` 可以将选项传递给 Laminar.initialize()。对于自托管用户，

```javascript
import { registerTelemetry } from 'ai';
import { LaminarAiSdkTelemetry } from '@lmnr-ai/lmnr';

registerTelemetry(new LaminarAiSdkTelemetry({
  laminarOptions: {
    projectApiKey: process.env.LMNR_PROJECT_API_KEY,
    baseUrl: "http://localhost",
    httpPort: 8000,
    grpcPort: 8001,
  },
})));
```

### 不记录输入或输出

默认情况下，Laminar 集成会记录所有输入和输出，但你可以在构造函数选项中禁用它们。

```javascript
import { registerTelemetry } from 'ai';
import { LaminarAiSdkTelemetry } from '@lmnr-ai/lmnr';

registerTelemetry(new LaminarAiSdkTelemetry({
  recordInputs: false, // default true
  recordOutputs: false, // default true
})));
```

### 为每个智能体步骤添加 span

AI SDK 遥测集成会为每个智能体步骤发出步骤 span。默认情况下，Laminar 会忽略这些 span。你可以在构造函数选项中配置此项。

```javascript
import { registerTelemetry } from 'ai';
import { LaminarAiSdkTelemetry } from '@lmnr-ai/lmnr';

registerTelemetry(new LaminarAiSdkTelemetry({
  createStepSpan: true, // default false
})));
```

### Span 名称

如果你想覆盖默认的 span 名称，可以在 `telemetry` 选项中设置 `functionId`。

```javascript
const { text } = await generateText({
  model: openai('gpt-6-luna'),
  prompt: `Write a poem about Laminar flow.`,
  telemetry: {
    functionId: 'poem-writer',
  },
});
```

### 嵌套 span

如果你想不仅追踪 AI SDK 调用，还追踪应用中的其他函数，可以使用 Laminar 的 `observe` 包装器。

```javascript highlight="3"
import { observe } from '@lmnr-ai/lmnr';

const result = await observe({ name: 'my-function' }, async () => {
  // ... some work
  await generateText({
    //...
  });
  // ... some work
});
```

这将创建一个名为 "my-function" 的 span 并追踪该函数调用。在其中，你将看到嵌套的 `ai.generateText` span。

要追踪你用 `observe` 包装的函数的输入参数，请将它们作为附加参数传递给包装器。函数的返回值将从包装器返回，并作为 span 的输出被追踪。

```javascript
const result = await observe(
  { name: 'poem writer' },
  async (topic: string, mood: string) => {
    const { text } = await generateText({
      model: openai('gpt-6-luna'),
      prompt: `Write a poem about ${topic} in ${mood} mood.`,
    });
    return text;
  },
  'Laminar flow',
  'happy',
);
```

### 元数据

在 Laminar 中，元数据设置在 trace 级别。元数据包含键值对，可用于过滤 trace。

```javascript
const { text } = await generateText({
  model: openai('gpt-6-luna'),
  prompt: `Write a poem about Laminar flow.`,
  telemetry: {
    metadata: {
      'my-key': 'my-value',
      'another-key': 'another-value',
    },
  },
});
```

这会被转换为 Laminar 的[元数据](https://laminar.sh/docs/tracing/structure/metadata)并存储在 trace 中。

### 标签

保留的元数据键之一是 `tags`。它可用于向 span 添加[标签](https://laminar.sh/docs/tracing/structure/tags)。

标签随后可用于在 Laminar 中过滤 trace。

```javascript
const { text } = await generateText({
  model: openai('gpt-6-luna'),
  prompt: `Write a poem about Laminar flow.`,
  telemetry: {
    metadata: {
      tags: ['fallback-model', 'api-handler'],
    },
  },
});
```

### 会话 ID 和用户 ID

Laminar 中的 trace 可以分组到[会话](https://laminar.sh/docs/tracing/structure/sessions)中或按[用户 ID](https://laminar.sh/docs/tracing/structure/user-id)分组。这些也是保留的元数据键。

```javascript
const { text } = await generateText({
  model: openai('gpt-6-luna'),
  prompt: `Write a poem about Laminar flow.`,
  telemetry: {
    metadata: {
      sessionId: 'session-123',
      userId: 'user-123',
    },
  },
});
```
