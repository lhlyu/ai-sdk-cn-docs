# Laminar 可观测性

[Laminar](https://laminar.sh) 是一个[开源](https://github.com/lmnr-ai/lmnr)、基于 OpenTelemetry 的可观测性平台，专为 AI 智能体构建。

Laminar 特性：

- [与 AI SDK 等兼容的追踪](https://laminar.sh/docs/tracing/introduction)
- [关于智能体行为的信号和告警](https://laminar.sh/docs/signals/introduction)
- [评估](https://laminar.sh/docs/evaluations/introduction)
- [智能体调试器](https://laminar.sh/docs/debugger/introduction)

<Note>
  本指南的一个版本可在 [Laminar 文档](https://laminar.sh/docs/tracing/integrations/vercel-ai-sdk) 中找到。
</Note>

## 设置

您可以使用编码智能体安装 Laminar，或手动安装。

### 使用编码智能体设置

将以下提示复制并粘贴到您的编码智能体中，以便其完全自动集成。

```markdown
1. 在项目根目录运行 `npx lmnr-cli setup` 以开始使用 Laminar。此命令将验证用户身份，将新的项目 API 密钥保存到 .env，并安装 Laminar 技能。
2. 使用已安装的技能或文档，用 Laminar 检测此项目：
   https://laminar.sh/docs/tracing/integrations/vercel-ai-sdk
3. 在应用程序中运行一个追踪路径。
4. 验证检测：
   `lmnr-cli sql query "SELECT * FROM traces ORDER BY start_time DESC LIMIT 1" --json`
```

### 手动设置

要手动设置 Laminar，首先安装 `@lmnr-ai/lmnr` 包。

<InstallPackages packages="@lmnr-ai/lmnr" />

### 获取项目 API 密钥并设置环境变量

然后，在 [Laminar](https://laminar.sh) 上注册或自行托管实例（[github](https://github.com/lmnr-ai/lmnr)），并创建一个新项目。

使用 `npx lmnr-cli@latest setup`。这将：

- 使用 Laminar 验证您的设备，
- 创建一个新的项目 API 密钥并将其保存到您的 .env 文件中，作为 `LMNR_PROJECT_API_KEY`，
- 安装 Laminar 技能，您的编码智能体将使用该技能通过 Laminar SDK 检测您的智能体。

## Next.js

### 初始化追踪

在 Next.js 中，Laminar 初始化和 AI SDK 遥测集成都应在 `instrumentation.{ts,js}` 中完成：

```javascript
export async function register() {
  // 防止在边缘运行时中执行
  if (process.env.NEXT_RUNTIME === 'nodejs') {
    const { registerTelemetry } = await import('ai');
    const { LaminarAiSdkTelemetry } = await import('@lmnr-ai/lmnr');

    registerTelemetry(new LaminarAiSdkTelemetry());
  }
}
```

### 将 @lmnr-ai/lmnr 添加到 next.config

在您的 `next.config.js`（`.ts` / `.mjs`）中，添加以下行：

```javascript
const nextConfig = {
  serverExternalPackages: ['@lmnr-ai/lmnr'],
};

export default nextConfig;
```

这是因为 Laminar 依赖于 OpenTelemetry，而 OpenTelemetry 使用了一些 Node.js 特定的功能，我们需要告知 Next.js。了解更多信息，请参阅 [Next.js 文档](https://nextjs.org/docs/app/api-reference/config/next-config-js/serverExternalPackages)。

### 追踪 AI SDK 调用

一旦集成注册完成，每次 AI SDK 调用都会自动捕获遥测数据：

```javascript
import { openai } from '@ai-sdk/openai';
import { generateText } from 'ai';

const { text } = await generateText({
  model: openai('gpt-5.4-mini'),
  prompt: '什么是层流？',
});
```

这将为 `ai.generateText` 创建 spans。Laminar 收集并显示以下信息：

- LLM 调用的输入和输出
- 开始和结束时间
- 持续时间/延迟
- 使用的提供商和模型
- 输入和输出令牌数
- 输入和输出价格
- 额外的元数据和 span 属性

### 旧版 Next.js

如果您使用的是 13.4 ≤ Next.js < 15，您还需要启用实验性 instrumentation hook。在您的 `next.config.js` 中添加以下内容：

```javascript
module.exports = {
  experimental: {
    instrumentationHook: true,
  },
};
```

更多信息，请参阅 Laminar 的 [AI SDK 集成指南](https://laminar.sh/docs/tracing/integrations/vercel-ai-sdk) 和 Next.js [instrumentation 文档](https://nextjs.org/docs/app/api-reference/file-conventions/instrumentation)。您还可以在文档中了解如何启用 Next.js 的所有追踪。

### 与 `@vercel/otel` 一起使用

Laminar 可以与 `@vercel/otel` 共存，并追踪 AI SDK 调用。默认的 Laminar 设置将确保：

- 常规的 Next.js 追踪通过 `@vercel/otel` 发送到您使用 Vercel 配置的遥测后端，
- AI SDK 和其他 LLM 或浏览器智能体的追踪通过 Laminar 发送。

```javascript
import { registerOTel } from '@vercel/otel';

export async function register() {
  if (process.env.NEXT_RUNTIME === 'nodejs') {
    const { registerTelemetry } = await import('ai');
    const { initializeLaminarInstrumentations, LaminarAiSdkTelemetry } =
      await import('@lmnr-ai/lmnr');

    // Next.js 遥测
    registerOTel({
      serviceName: 'my-service',
      instrumentations: initializeLaminarInstrumentations(),
    });

    // Laminar AI SDK 遥测
    registerTelemetry(new LaminarAiSdkTelemetry());
  }
}
```

有关允许您通过 Laminar 追踪所有 Next.js 追踪的高级配置，请参阅示例 [仓库](https://github.com/lmnr-ai/lmnr-ts/tree/main/examples/nextjs)。

### 与 `@sentry/node` 一起使用

Laminar 可以与 `@sentry/node` 共存，并追踪 AI SDK 调用。确保在 `Sentry.init` **之后**初始化 Laminar。

这将确保：

- Sentry 检测的任何内容都发送到您的 Sentry 后端，
- AI SDK 和其他 LLM 或浏览器智能体的追踪通过 Laminar 发送。

```javascript
export async function register() {
  if (process.env.NEXT_RUNTIME === 'nodejs') {
    const { registerTelemetry } = await import('ai');
    const Sentry = await import('@sentry/node');
    const { LaminarAiSdkTelemetry } = await import('@lmnr-ai/lmnr');

    Sentry.init({
      dsn: process.env.SENTRY_DSN,
    });

    // 确保在 `Sentry.init` **之后**初始化 Laminar
    registerTelemetry(new LaminarAiSdkTelemetry());
  }
}
```

## Node.js

### 初始化追踪

然后，在您的应用程序中初始化追踪：

```javascript
import { registerTelemetry } from 'ai';
import { LaminarAiSdkTelemetry } from '@lmnr-ai/lmnr';

registerTelemetry(new LaminarAiSdkTelemetry());
```

这必须在您的应用程序中尽早执行一次，但要在其他追踪库（例如 `@sentry/node`）初始化**之后**。

在 Laminar [文档](https://laminar.sh/docs/tracing/introduction) 中了解更多信息。

### 追踪 AI SDK 调用

一旦集成注册完成，每次 AI SDK 调用都会自动捕获遥测数据：

```javascript
import { openai } from '@ai-sdk/openai';
import { generateText } from 'ai';

const { text } = await generateText({
  model: openai('gpt-5.4-mini'),
  prompt: '什么是层流？',
});
```

这将为 `ai.generateText` 创建 spans。Laminar 收集并显示以下信息：

- LLM 调用的输入和输出
- 开始和结束时间
- 持续时间/延迟
- 使用的提供商和模型
- 输入和输出令牌数
- 输入和输出价格
- 额外的元数据和 span 属性

### 与 `@sentry/node` 一起使用

Laminar 可以与 `@sentry/node` 一起工作，以追踪 AI SDK 调用。确保在 `Sentry.init` **之后**初始化 Laminar：

```javascript
const { LaminarAiSdkTelemetry } = await import('@lmnr-ai/lmnr');
const Sentry = await import('@sentry/node');
const { registerTelemetry } = await import('ai');

Sentry.init({
  dsn: process.env.SENTRY_DSN,
});

registerTelemetry(new LaminarAiSdkTelemetry());
```

这将确保：

- Sentry 检测的任何内容都发送到您的 Sentry 后端，
- AI SDK 和其他 LLM 或浏览器智能体的追踪通过 Laminar 发送。

这两个库允许额外的高级配置，但建议使用上述默认设置。

## 额外配置

### Laminar 选项

`LaminarAiSdkTelemetry` 可以向 `Laminar.initialize()` 传递选项。对于自托管用户：

```javascript
import { registerTelemetry } from 'ai';
import { LaminarAiSdkTelemetry } from '@lmnr-ai/lmnr';

registerTelemetry(new LaminarAiSdkTelemetry({
  laminarOptions: {
    projectApiKey: process.env.LMNR_PROJECT_API_KEY,
    baseUrl: "http://localhost",
    httpPort: 8000,
    grpcPort: 8001,
  },
})));
```

### 不记录输入或输出

默认情况下，Laminar 集成会记录所有输入和输出，但您可以在构造函数选项中禁用它们。

```javascript
import { registerTelemetry } from 'ai';
import { LaminarAiSdkTelemetry } from '@lmnr-ai/lmnr';

registerTelemetry(new LaminarAiSdkTelemetry({
  recordInputs: false, // 默认为 true
  recordOutputs: false, // 默认为 true
})));
```

### 为每个智能体步骤添加 span

AI SDK 遥测集成会为每个智能体步骤发出步骤 spans。默认情况下，Laminar 会忽略这些 spans。您可以在构造函数选项中配置此行为。

```javascript
import { registerTelemetry } from 'ai';
import { LaminarAiSdkTelemetry } from '@lmnr-ai/lmnr';

registerTelemetry(new LaminarAiSdkTelemetry({
  createStepSpan: true, // 默认为 false
})));
```

### Span 名称

如果您想覆盖默认的 span 名称，可以在 `telemetry` 选项中设置 `functionId`。

```javascript
const { text } = await generateText({
  model: openai('gpt-5.4-mini'),
  prompt: `写一首关于层流的诗。`,
  telemetry: {
    functionId: 'poem-writer',
  },
});
```

### 嵌套 spans

如果您不仅想追踪 AI SDK 调用，还想追踪应用程序中的其他函数，可以使用 Laminar 的 `observe` 包装器。

```javascript highlight="3"
import { observe } from '@lmnr-ai/lmnr';

const result = await observe({ name: 'my-function' }, async () => {
  // ... 一些工作
  await generateText({
    //...
  });
  // ... 一些工作
});
```

这将创建一个名为 "my-function" 的 span 并追踪函数调用。在其中，您将看到嵌套的 `ai.generateText` spans。

要追踪您包装在 `observe` 中的函数的输入参数，请将它们作为额外参数传递给包装器。函数的返回值将从包装器返回并作为 span 的输出进行追踪。

```javascript
const result = await observe(
  { name: 'poem writer' },
  async (topic: string, mood: string) => {
    const { text } = await generateText({
      model: openai('gpt-5.4-mini'),
      prompt: `写一首关于 ${topic} 的 ${mood} 情绪的诗。`,
    });
    return text;
  },
  'Laminar flow',
  'happy',
);
```

### 元数据

在 Laminar 中，元数据设置在追踪级别。元数据包含键值对，可用于过滤追踪。

```javascript
const { text } = await generateText({
  model: openai('gpt-5.4-mini'),
  prompt: `写一首关于层流的诗。`,
  telemetry: {
    metadata: {
      'my-key': 'my-value',
      'another-key': 'another-value',
    },
  },
});
```

这将被转换为 Laminar 的[元数据](https://laminar.sh/docs/tracing/structure/metadata)并存储在追踪中。

### 标签

其中一个保留的元数据键是 `tags`。它可以用于向 span 添加[标签](https://laminar.sh/docs/tracing/structure/tags)。

随后可以使用标签在 Laminar 中过滤追踪。

```javascript
const { text } = await generateText({
  model: openai('gpt-5.4-mini'),
  prompt: `写一首关于层流的诗。`,
  telemetry: {
    metadata: {
      tags: ['fallback-model', 'api-handler'],
    },
  },
});
```

### 会话 ID 和用户 ID

Laminar 中的追踪可以按[会话](https://laminar.sh/docs/tracing/structure/sessions)或[用户 ID](https://laminar.sh/docs/tracing/structure/user-id) 分组。这些也是保留的元数据键。

```javascript
const { text } = await generateText({
  model: openai('gpt-5.4-mini'),
  prompt: `写一首关于层流的诗。`,
  telemetry: {
    metadata: {
      sessionId: 'session-123',
      userId: 'user-123',
    },
  },
});
```
