# LangWatch 可观测性

[LangWatch](https://langwatch.ai/) ([GitHub](https://github.com/langwatch/langwatch)) 是一个 LLM Ops 平台，用于监控、实验、测量和改进 LLM 管道，采用公平代码分发模型。

## 设置

从 [LangWatch 仪表盘](https://app.langwatch.com/) 获取您的 `LANGWATCH_API_KEY`。

<InstallPackages packages="langwatch" />

确保设置了 `LANGWATCH_API_KEY`：

<Tabs items={["环境变量", "客户端参数"]} >

<Tab title="环境变量">

```bash filename=".env"
LANGWATCH_API_KEY='your_api_key_here'
```

</Tab>

<Tab title="客户端参数">

```typescript
import { LangWatch } from 'langwatch';

const langwatch = new LangWatch({
  apiKey: 'your_api_key_here',
});
```

## 基本概念

- 触发整个 LLM 管道的每条消息都会通过 [Trace](https://docs.langwatch.ai/concepts#traces) 捕获。
- 一个 [Trace](https://docs.langwatch.ai/concepts#traces) 包含多个 [Span](https://docs.langwatch.ai/concepts#spans)，这些是管道内的步骤。
  - 一个 span 可以是 LLM 调用、用于 RAG 检索的数据库查询，或简单的函数转换。
  - 不同类型的 [Span](https://docs.langwatch.ai/concepts#spans) 捕获不同的参数。
  - [Span](https://docs.langwatch.ai/concepts#spans) 可以嵌套以捕获管道结构。
- [Trace](https://docs.langwatch.ai/concepts#traces) 可以通过在其元数据中设置相同的 [`thread_id`](https://docs.langwatch.ai/concepts#threads) 在 LangWatch 仪表盘上分组，使单个消息成为对话的一部分。
  - 还建议提供 [`user_id`](https://docs.langwatch.ai/concepts#user-id) 元数据以跟踪用户分析。

## 配置

AI SDK 支持通过 Next.js OpenTelemetry 集成进行跟踪。通过使用 `LangWatchExporter`，您可以自动将这些跟踪收集到 LangWatch。

首先，您需要安装必要的依赖项：

```bash
npm install @vercel/otel langwatch @opentelemetry/api-logs @opentelemetry/instrumentation @opentelemetry/sdk-logs @ai-sdk/otel
```

然后，为您的应用程序设置 OpenTelemetry，根据您使用的是 AI SDK 与 Next.js 还是 Node.js，选择以下选项卡之一：

<Tabs items={['Next.js', 'Node.js']}>
<Tab title="Next.js">

如果尚未启用，您需要在 `next.config.js` 文件中启用 `instrumentationHook`：

```javascript
/** @type {import('next').NextConfig} */
const nextConfig = {
  experimental: {
    instrumentationHook: true,
  },
};

module.exports = nextConfig;
```

接下来，您需要在项目的**根目录**（或使用 `src` 文件夹时在其中）创建一个名为 `instrumentation.ts`（或 `.js`）的文件，并将 `LangWatchExporter` 作为 traceExporter：

```typescript
import { registerTelemetry } from 'ai';
import { LegacyOpenTelemetry } from '@ai-sdk/otel';
import { registerOTel } from '@vercel/otel';
import { LangWatchExporter } from 'langwatch';

registerTelemetry(new LegacyOpenTelemetry());

export function register() {
  registerOTel({
    serviceName: 'next-app',
    traceExporter: new LangWatchExporter(),
  });
}
```

（有关 Next.js OpenTelemetry 配置的更多信息，请参阅[官方指南](https://nextjs.org/docs/app/building-your-application/optimizing/open-telemetry#manual-opentelemetry-configuration)）

最后，在您想要跟踪的 AI SDK 调用上启用 `telemetry` 跟踪：

```typescript
import { generateText } from 'ai';
import { openai } from '@ai-sdk/openai';

const result = await generateText({
  model: openai('gpt-4o-mini'),
  prompt:
    '解释为什么鸡会是一个糟糕的宇航员，要富有创意和幽默感。',
  telemetry: {
    // 可选元数据
    metadata: {
      userId: 'myuser-123',
      threadId: 'mythread-123',
    },
  },
});
```

</Tab>
<Tab title="Node.js">
对于 Node.js，首先按照官方 OpenTelemetry 指南进行操作：

- [OpenTelemetry Node.js 入门](https://opentelemetry.io/docs/languages/js/getting-started/nodejs/)

设置好 OpenTelemetry 后，您可以使用 `LangWatchExporter` 自动将跟踪发送到 LangWatch：

```typescript
import { LangWatchExporter } from 'langwatch';

const sdk = new NodeSDK({
  traceExporter: new LangWatchExporter({
    apiKey: process.env.LANGWATCH_API_KEY,
  }),
  // ...
});
```

</Tab>
</Tabs>

### 手动集成

以下文档适用于手动集成，如果您未使用 AI SDK OpenTelemetry 集成，可以手动启动一个 trace 来捕获您的消息：

```typescript
import { LangWatch } from 'langwatch';

const langwatch = new LangWatch();

const trace = langwatch.getTrace({
  metadata: { threadId: 'mythread-123', userId: 'myuser-123' },
});
```

然后，您可以在 trace 内启动一个 LLM span，并传入即将发送给 LLM 的输入。

```typescript
const span = trace.startLLMSpan({
  name: 'llm',
  model: model,
  input: {
    type: 'chat_messages',
    value: messages,
  },
});
```

这将捕获 LLM 输入并记录调用开始的时间。一旦 LLM 调用完成，结束 span 以记录完成时间戳，并捕获输出和 token 指标，这些将用于成本计算，例如：

```typescript
span.end({
  output: {
    type: 'chat_messages',
    value: [chatCompletion.choices[0]!.message],
  },
  metrics: {
    promptTokens: chatCompletion.usage?.prompt_tokens,
    completionTokens: chatCompletion.usage?.completion_tokens,
  },
});
```
