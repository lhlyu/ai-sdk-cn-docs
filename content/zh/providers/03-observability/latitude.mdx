# Latitude 可观测性

[Latitude](https://latitude.so)（[GitHub](https://github.com/latitude-dev/latitude-llm)）是一个开源、MIT 许可的平台，用于 AI 智能体可观测性，支持语义化追踪搜索和问题跟踪。它与 AI SDK 集成以捕获：

- 每次 `generateText`、`streamText` 和工具调用的追踪
- 每次调用的 token 用量和延迟
- 按重复出现的问题分组的错误和失败模式

## 设置

Latitude 的 SDK 会注册一个全局 OpenTelemetry tracer。一旦你注册了 AI SDK 的遥测集成，每次 AI SDK 调用都会自动发出 span。

安装这两个包：

<InstallPackages packages="@latitude-data/telemetry @ai-sdk/otel" />

在 [app.latitude.so](https://app.latitude.so) 登录，并从仪表盘获取你的 API key 和 project slug。将它们设置到你的环境中：

```bash filename=".env"
LATITUDE_API_KEY="..."
LATITUDE_PROJECT_SLUG="..."
```

在启动时初始化 Latitude 并注册遥测一次。之后，每次 AI SDK 调用都会自动发出追踪：

```ts
import { Latitude } from '@latitude-data/telemetry';
import { registerTelemetry, generateText } from 'ai';
import { OpenTelemetry } from '@ai-sdk/otel';
import { openai } from '@ai-sdk/openai';

const latitude = new Latitude({
  apiKey: process.env.LATITUDE_API_KEY!,
  project: process.env.LATITUDE_PROJECT_SLUG!,
});

registerTelemetry(new OpenTelemetry());

const { text } = await generateText({
  model: openai('gpt-6-astra'),
  prompt: 'Hello',
});

await latitude.shutdown();
```

对于命名追踪和每次调用的元数据（标签、用户 ID、会话 ID），将调用包装在 Latitude 的 `capture()` 辅助函数中：

```ts
import { capture } from '@latitude-data/telemetry';

await capture('generate-support-reply', async () => {
  const { text } = await generateText({
    model: openai('gpt-6-astra'),
    prompt: 'Hello',
  });
  return text;
});
```
