# Confident AI 可观测性

[Confident AI](https://confident-ai.com/) 是一个 LLM 可观测性与评估平台，面向在开发和生产环境中构建可靠 AI 应用的团队。

[`confident-trace`](https://github.com/confident-ai/confident-trace) 是 Confident AI 的 OpenTelemetry 原生追踪 SDK，无需更改你的调用即可追踪 AI SDK 应用——每次 `generateText` 和 `streamText` 调用都会在 [Observatory](https://www.confident-ai.com/docs/llm-tracing/introduction) 中显示为一条 trace，包含智能体、步骤、模型和工具 span，因此你可以看到应用选择了哪些工具、每次模型调用的成本，并对结果运行评估。

Confident AI 与 AI SDK 集成，提供：

- [Traces](https://www.confident-ai.com/docs/llm-tracing/introduction)，包含完整的智能体、步骤、模型和工具层级
- 每次模型调用的[Token 用量与成本](https://www.confident-ai.com/docs/llm-tracing/features/token-usage-cost)
- [Threads](https://www.confident-ai.com/docs/llm-tracing/features/threads)，将一次对话的多轮交互归为一个单元
- [在线评估](https://www.confident-ai.com/docs/llm-tracing/online-evals)，在 trace 被摄取时对其进行评分

## 设置

追踪需要 Node.js 22 或更高版本，以及 AI SDK `>=7.0.93 <8`。

### 1. 安装 confident-trace

```bash
npm install confident-trace @ai-sdk/otel
```

### 2. 设置你的 API Key

注册或登录 [Confident AI](https://app.confident-ai.com) 获取你的项目 API key，然后将其设置为环境变量：

```bash filename=".env"
CONFIDENT_API_KEY="YOUR-PROJECT-API-KEY"
```

<Note>
  对于欧盟地区的用户，请设置
  `CONFIDENT_OTEL_ENDPOINT="https://eu.otel.confident-ai.com/v1/traces"`
</Note>

### 3. 注册遥测集成

`createVercelAITracer()` 函数返回一个 tracer，将 AI SDK span 映射到
Confident AI 的 span 类型。将其传给 `OpenTelemetry`，并在应用启动时、任何 AI SDK 调用之前注册一次。`init()` 会设置将 span 发送到你的项目的 exporter：

```ts filename="instrumentation.ts"
import { registerTelemetry } from 'ai';
import { OpenTelemetry } from '@ai-sdk/otel';
import { init } from 'confident-trace';
import { createVercelAITracer } from 'confident-trace/vercel-ai';

export function register() {
  init();
  registerTelemetry(new OpenTelemetry({ tracer: createVercelAITracer() }));
}
```

在 Next.js 中，将此文件放在项目根目录的 `instrumentation.ts` 中——Next.js 会为你调用
`register()`。对于不使用 Next.js 的 Node.js 应用，在入口文件的顶层运行同样的两行代码：

```ts filename="index.ts"
import { generateText, registerTelemetry } from 'ai';
import { openai } from '@ai-sdk/openai';
import { OpenTelemetry } from '@ai-sdk/otel';
import { init } from 'confident-trace';
import { createVercelAITracer } from 'confident-trace/vercel-ai';

const runtime = init();
registerTelemetry(new OpenTelemetry({ tracer: createVercelAITracer() }));

try {
  const { text } = await generateText({
    model: openai('gpt-6-astra'),
    prompt: 'How do you make the best coffee?',
  });
  console.log(text);
} finally {
  await runtime.shutdown();
}
```

你的 AI SDK 调用保持原样不变。每个 span 都带有 `Vercel AI SDK` 集成标签，嵌套在调用发生时处于活动状态的 span 之下，并捕获：

- **智能体和步骤 span** —— 一个 span 对应整个 `generateText` 或 `streamText` 调用，多步骤运行中每个步骤再对应一个 span。
- **模型调用** —— [LLM span](https://www.confident-ai.com/docs/llm-tracing/features/span-types#llm-spans)，包含模型名称、[token 用量](https://www.confident-ai.com/docs/llm-tracing/features/token-usage-cost)、结束原因以及规范化后的输入/输出消息，包括模型请求的工具调用。
- **工具调用** —— [工具 span](https://www.confident-ai.com/docs/llm-tracing/features/span-types#tool-spans)，包含工具名称、其输入和结果，嵌套在运行它们的步骤之下。
- **内容** —— 提示词和响应文本，默认捕获且无大小限制（除非你配置了限制），并受[内容策略](https://www.confident-ai.com/docs/llm-tracing/features/masking)约束。

<Note>
  推理和二进制内容部分会被标记但不会导出，原始请求头、任意 SDK 元数据和异常消息也不会包含在内。
  嵌入、重排序以及图像和音频 API 不在此集成的范围内。
</Note>

<Note>
  初始化一次，关闭一次。在长时间运行的服务器中，在启动时调用 `init()`，并在优雅关闭期间、进行中的请求和流完成之后调用 `runtime.shutdown()`——绝不要按请求调用。在无服务器函数中，改为在处理程序末尾、任何流完成后调用 `runtime.flush()`，以便在函数冻结之前导出 span。
</Note>

## 高级功能

### 在线评估

你可以在 Confident AI 的[工作流页面](https://www.confident-ai.com/docs/llm-tracing/workflows)配置传入 trace 的处理方式。

![Confident AI 工作流页面](https://confident-docs.s3.us-east-1.amazonaws.com/confident-trace-workflows.png)

以下是你可以配置的工作流：

- **评估规则** —— 根据[指标集合](https://www.confident-ai.com/docs/metrics/metric-collections)评估传入的 trace。
- **分类器** —— 按问题、情感或你定义的任何维度为 trace 打标签，以便之后对其进行分组或筛选。
- **队列摄取** —— 将生产 trace 路由到标注队列，供内部审核团队手动标注。
- **数据集摄取** —— 将生产 trace 摄取到数据集中，作为测试用例复用，并迭代结果以持续改进。

你可以根据需要为不同的数据模型（如 trace、span 和 thread）分别创建自定义工作流。

要手动评估某个组件或 trace，请通过 `updateTrace` 传入指标集合——参见[在线评估](https://www.confident-ai.com/docs/llm-tracing/online-evals)。

### Trace 属性

使用 [trace 上下文](https://www.confident-ai.com/docs/llm-tracing/features/trace-context)附加你在调用开始前已知的属性。它不会创建额外的 span——由 `generateText()` 启动的 trace 会继承你传入的所有内容：

```ts
import { generateText } from 'ai';
import { openai } from '@ai-sdk/openai';
import { traceContext } from 'confident-trace';

const { text } = await traceContext(
  {
    tags: ['support'],
    metadata: { release: '2026-09' },
    userId: 'user-456',
    environment: 'production',
  },
  () =>
    generateText({
      model: openai('gpt-6-astra'),
      prompt: 'How do you make the best coffee?',
    }),
);
```

### 将 Trace 分组为 Thread

`confident-trace` 提供了 `turn()` 方法，你可以用它把两次连续的 AI SDK 调用归为一次 turn。在后续 turn 中复用相同的 thread ID，即可将它们归为一个 thread，你可以在 Confident AI 上查看和评估：

```ts
import { generateText } from 'ai';
import { openai } from '@ai-sdk/openai';
import { turn, updateTrace } from 'confident-trace';

async function chat(prompt: string, threadId: string) {
  return turn({ name: 'chat', threadId }, async () => {
    const { text } = await generateText({
      model: openai('gpt-6-astra'),
      prompt,
    });
    updateTrace({ input: prompt, output: text });
    return text;
  });
}
```

## 故障排查

- **完全没有 trace：** 确认 `registerTelemetry()` 在第一次 AI SDK 调用之前运行。在 Next.js 中，这意味着 `instrumentation.ts` 要放在项目根目录，而不是路由内部。不注册任何遥测集成会完全禁用 AI SDK 遥测。
- **Trace 在运行中途停止：** 进程在导出队列排空之前退出了。在退出时调用 `runtime.shutdown()`，或在无服务器处理程序末尾调用 `runtime.flush()`。
- **流式调用到达时不完整：** 在 flush 或关闭之前完成消费或中止流。
- **Trace 缺少内容：** 检查 AI SDK 的 `recordInputs` 和 `recordOutputs`，以及 `init()` 上的 `captureContent`。

其他问题请参阅 [Confident AI 的故障排查指南](https://www.confident-ai.com/docs/llm-tracing/troubleshooting)。
