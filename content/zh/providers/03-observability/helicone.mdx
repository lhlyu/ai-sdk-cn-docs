# Helicone 可观测性

[Helicone](https://helicone.ai) 是一个开源的 LLM 可观测性平台，帮助你监控、分析和优化你的 AI 应用。内置的可观测性会自动追踪每一个请求，无需额外的埋点即可提供关于性能、成本、用户行为和模型使用的全面洞察。

## 设置

Helicone 提供商位于 `@helicone/ai-sdk-provider` 包中。使用以下命令安装：

<InstallPackages packages="@helicone/ai-sdk-provider" />

设置 Helicone：

1. 在 [helicone.ai](https://helicone.ai) 创建一个 Helicone 账户
2. 从 [Helicone Dashboard](https://us.helicone.ai/settings/api-keys) 获取你的 API 密钥
3. 将你的 API 密钥设置为环境变量：
   ```bash filename=".env"
   HELICONE_API_KEY=your-helicone-api-key
   ```
4. 在你的应用中使用 Helicone：

   ```javascript
   import { createHelicone } from '@helicone/ai-sdk-provider';
   import { generateText } from 'ai';

   const helicone = createHelicone({
     apiKey: process.env.HELICONE_API_KEY,
   });

   // Use the provider with any supported model: https://helicone.ai/models
   const result = await generateText({
     model: helicone('claude-4.5-haiku'),
     prompt: 'Hello world',
   });

   console.log(result.text);
   ```

就是这样！你的请求现在正通过 Helicone 进行日志记录和监控，并具备自动可观测性。

[→ 了解更多关于 Helicone AI Gateway 的信息](https://docs.helicone.ai)

## 关键可观测性功能

Helicone 为你的 AI 应用提供全面的可观测性，且无需任何额外的埋点：

**自动请求追踪**

- 每个请求都会自动记录完整的请求/响应数据
- 实时追踪延迟、token、成本和模型性能
- 无需 OpenTelemetry 设置或额外配置

**分析仪表板**

- 查看所有 AI 请求的指标：成本、延迟、token 使用量和错误率
- 按用户、会话、模型或自定义属性进行筛选
- 识别性能瓶颈并优化模型选择

**用户与会话分析**

- 追踪单个用户的行为和使用模式
- 通过会话追踪监控对话流程
- 分析用户参与度和功能采用情况

**成本监控**

- 按请求、用户、功能或模型实时追踪成本
- 预算告警和成本优化洞察
- 比较不同模型和提供商之间的成本

**调试与故障排查**

- 为每次调用记录完整的请求/响应日志
- 带有详细上下文的错误追踪
- 搜索和筛选请求以快速定位问题

[→ 了解更多关于 Helicone 可观测性的信息](https://docs.helicone.ai)

## 可观测性配置

### 用户追踪

追踪单个用户的行为并分析整个应用中的使用模式。这有助于你了解哪些用户最活跃、识别重度用户，并监控每个用户的成本：

```javascript
import { createHelicone } from '@helicone/ai-sdk-provider';
import { generateText } from 'ai';

const helicone = createHelicone({
  apiKey: process.env.HELICONE_API_KEY,
});

const result = await generateText({
  model: helicone('gpt-6-luna', {
    extraBody: {
      helicone: {
        userId: 'user@example.com',
      },
    },
  }),
  prompt: 'Hello world',
});
```

**你可以追踪的内容：**

- 每个用户的总请求数
- 每个用户的成本
- 每个用户的平均延迟
- 按用户群体划分的最常见用例

[→ 了解更多关于用户指标的信息](https://docs.helicone.ai/features/advanced-usage/user-metrics)

### 自定义属性

添加结构化元数据，以便按功能、环境或任何自定义维度对请求进行细分和分析。这可以在你的分析仪表板中实现强大的筛选和洞察：

```javascript
import { createHelicone } from '@helicone/ai-sdk-provider';
import { generateText } from 'ai';

const helicone = createHelicone({
  apiKey: process.env.HELICONE_API_KEY,
});

const result = await generateText({
  model: helicone('gpt-6-luna', {
    extraBody: {
      helicone: {
        properties: {
          feature: 'translation',
          source: 'mobile-app',
          language: 'French',
          environment: 'production',
        },
      },
    },
  }),
  prompt: 'Translate this text to French',
});
```

**自定义属性的用例：**

- 比较不同功能或环境之间的性能
- 按产品领域或客户层级追踪成本
- 识别哪些功能推动了最多的 AI 使用量
- 通过标记实验对不同的提示词或模型进行 A/B 测试

[→ 了解更多关于自定义属性的信息](https://docs.helicone.ai/features/advanced-usage/custom-properties)

### 会话追踪

将相关请求分组到会话中，以分析对话流程和多轮交互。这对于理解用户旅程和调试复杂对话至关重要：

```javascript
import { createHelicone } from '@helicone/ai-sdk-provider';
import { generateText } from 'ai';

const helicone = createHelicone({
  apiKey: process.env.HELICONE_API_KEY,
});

const result = await generateText({
  model: helicone('gpt-6-luna', {
    extraBody: {
      helicone: {
        sessionId: 'convo-123',
        sessionName: 'Travel Planning',
        sessionPath: '/chats/travel',
      },
    },
  }),
  prompt: 'Tell me more about that',
});
```

**会话追踪的优势：**

- 在单一时间线中查看完整的对话历史
- 计算每个会话/对话的总成本
- 衡量会话时长和消息数量
- 识别用户在多轮对话中的流失点
- 通过回放整个对话流程来调试问题

[→ 了解更多关于会话的信息](https://docs.helicone.ai/features/sessions)

## 高级可观测性功能

### 标签与组织

添加标签以在你的分析仪表板中组织和筛选请求：

```javascript
import { createHelicone } from '@helicone/ai-sdk-provider';
import { generateText } from 'ai';

const helicone = createHelicone({
  apiKey: process.env.HELICONE_API_KEY,
});

const result = await generateText({
  model: helicone('gpt-6-luna', {
    extraBody: {
      helicone: {
        tags: ['customer-support', 'urgent'],
        properties: {
          ticketId: 'TICKET-789',
          priority: 'high',
          department: 'support',
        },
      },
    },
  }),
  prompt: 'Help resolve this customer issue',
});
```

**标签洞察：**

- 按标签筛选和分组请求
- 追踪不同类别的性能
- 识别带标签请求中的模式
- 围绕特定标签构建自定义仪表板

[→ 了解更多关于 Helicone 功能的信息](https://docs.helicone.ai)

### 流式响应追踪

以完整的可观测性监控流式响应，包括首 token 时间和总流式传输时长：

```javascript
import { createHelicone } from '@helicone/ai-sdk-provider';
import { streamText } from 'ai';

const helicone = createHelicone({
  apiKey: process.env.HELICONE_API_KEY,
});

const result = await streamText({
  model: helicone('gpt-6-luna', {
    extraBody: {
      helicone: {
        userId: 'user@example.com',
        sessionId: 'stream-session-123',
        tags: ['streaming', 'content-generation'],
      },
    },
  }),
  prompt: 'Write a short story about AI',
});

for await (const chunk of result.textStream) {
  process.stdout.write(chunk);
}
```

**追踪的流式传输指标：**

- 首 token 时间（TTFT）
- 总流式传输时长
- 每秒 token 数
- 即使是流式传输也记录完整的请求/响应日志
- 实时应用的用户体验指标
- 为流式响应追踪所有元数据（会话、用户、标签）
