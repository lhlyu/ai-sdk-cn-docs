[MLflow Tracing](https://mlflow.org/docs/latest/genai/tracing) 通过 OpenTelemetry 为使用 [Vercel AI SDK](https://ai-sdk.dev/)（`ai` 包）构建的应用提供自动追踪，为 TypeScript 和 JavaScript 应用带来可观测性。

启用后，MLflow 会记录：

- 提示词/消息及生成的响应
- 延迟和调用层级
- Token 用量（当提供商返回时）
- 异常

## 快速开始（NextJS）

如果你使用 NextJS，为 Vercel AI SDK 启用 MLflow 追踪相当简单。

<Note>
  手头没有应用？试试 Vercel 的演示聊天机器人：
  https://vercel.com/templates/next.js/ai-chatbot-telemetry
</Note>

### 1. 启动 MLflow Tracking Server

```bash
mlflow server --backend-store-uri sqlite:///mlruns.db --port 5000
```

你也可以使用 Docker Compose 启动服务器；请参阅 [MLflow 设置指南](https://mlflow.org/docs/latest/genai/getting-started/connect-environment/)。

### 2. 配置环境变量

将以下内容添加到 `.env.local`：

```bash filename=".env.local"
OTEL_EXPORTER_OTLP_ENDPOINT=<your-mlflow-tracking-server-endpoint>
OTEL_EXPORTER_OTLP_TRACES_HEADERS=x-mlflow-experiment-id=<your-experiment-id>
OTEL_EXPORTER_OTLP_TRACES_PROTOCOL=http/protobuf
```

本地测试时：`OTEL_EXPORTER_OTLP_ENDPOINT=http://localhost:5000`。

### 3. 启用 OpenTelemetry

安装 Vercel OpenTelemetry 集成：

```bash
pnpm i @opentelemetry/api @vercel/otel @ai-sdk/otel
```

在项目根目录创建 `instrumentation.ts`，并在设置 OTel 提供商的同时注册 `LegacyOpenTelemetry`：

```ts filename="instrumentation.ts"
import { registerTelemetry } from 'ai';
import { LegacyOpenTelemetry } from '@ai-sdk/otel';
import { registerOTel } from '@vercel/otel';

registerTelemetry(new LegacyOpenTelemetry());

export async function register() {
  registerOTel({ serviceName: 'next-app' });
}
```

注册集成后，你的 AI SDK 调用会自动发出遥测数据：

```ts filename="route.ts"
import { generateText } from 'ai';
import { openai } from '@ai-sdk/openai';

export async function POST(req: Request) {
  const { prompt } = await req.json();

  const { text } = await generateText({
    model: openai('gpt-6-astra'),
    prompt,
  });

  return new Response(JSON.stringify({ text }), {
    headers: { 'Content-Type': 'application/json' },
  });
}
```

有关上下文传播等高级选项，请参阅 [Vercel OpenTelemetry 文档](https://vercel.com/docs/tracing/instrumentation)。

### 4. 运行应用并查看追踪

启动你的 NextJS 应用，并在 tracking server 端点（例如 `http://localhost:5000`）打开 MLflow UI。AI SDK 调用的追踪会出现在配置的实验（experiment）中。

## 其他 Node.js 应用

对于其他 Node.js 框架，请手动接入 OpenTelemetry Node SDK 和 OTLP 导出器。

```ts filename="main.ts"
import { init } from 'mlflow-tracing';
import { registerTelemetry, generateText } from 'ai';
import { LegacyOpenTelemetry } from '@ai-sdk/otel';
import { openai } from '@ai-sdk/openai';
import { NodeSDK } from '@opentelemetry/sdk-node';
import { SimpleSpanProcessor } from '@opentelemetry/sdk-trace-node';
import { OTLPTraceExporter } from '@opentelemetry/exporter-trace-otlp-proto';

const sdk = new NodeSDK({
  spanProcessors: [
    new SimpleSpanProcessor(
      new OTLPTraceExporter({
        url: '<your-mlflow-tracking-server-endpoint>/v1/traces',
        headers: { 'x-mlflow-experiment-id': '<your-experiment-id>' },
      }),
    ),
  ],
});

sdk.start();
init();
registerTelemetry(new LegacyOpenTelemetry());

const result = await generateText({
  model: openai('gpt-6-astra'),
  prompt: 'What is MLflow?',
});

console.log(result.text);
sdk.shutdown();
```

```bash
npx tsx main.ts
```

## 流式传输

支持流式传输。与 `generateText` 一样，注册集成后会自动捕获追踪。

```ts
import { streamText } from 'ai';
import { openai } from '@ai-sdk/openai';

const stream = await streamText({
  model: openai('gpt-6-astra'),
  prompt: 'Explain vector databases in one paragraph.',
});

for await (const part of stream.textStream) {
  process.stdout.write(part);
}
```

## 禁用自动追踪

要禁用 Vercel AI SDK 的追踪，请在 AI SDK 调用上设置 `telemetry: { isEnabled: false }`。

## 了解更多

- 为 AI SDK 设置 MLflow Tracing 后，你可以使用更广泛的 MLflow GenAI 能力：
  - [评估](https://mlflow.org/docs/latest/genai/eval-monitor/)：使用内置的 LLM 评判器和数据集管理，系统性地衡量质量，并从开发到生产全程监控 GenAI 应用。
  - [提示词管理](https://mlflow.org/docs/latest/genai/prompt-registry/)：通过版本控制、别名、血缘和协作集中管理提示词模板，让团队可以安全地复用和比较提示词。
  - [MCP Server](https://mlflow.org/docs/latest/genai/mcp/)：将你的编码智能体与 MLflow MCP Server 连接，以编程方式与 MLflow 追踪交互，并改进你的 LLM 应用。
- 有关 AI SDK 中追踪的更多信息，请参阅[遥测文档](/docs/ai-sdk-core/telemetry)。
