# Claude Code 工具链

Claude Code 工具链适配器通过 `@anthropic-ai/claude-agent-sdk` 将 `HarnessAgent` 连接到 Claude Code。该适配器在沙箱内运行一个桥接器，并通过沙箱暴露的 WebSocket 将 Claude Code 事件流式传输回主机。

<Note>
  工具链包为**实验性**。随着这个早期 API 的进一步完善，版本之间可能会出现破坏性变更。
</Note>

## 设置

<InstallPackages packages="@ai-sdk/harness @ai-sdk/harness-claude-code @ai-sdk/sandbox-vercel" />

当第一个会话启动时，适配器会在沙箱内引导 Claude Code 桥接器依赖。

## 导入

```ts
import { claudeCode, createClaudeCode } from '@ai-sdk/harness-claude-code';
```

`claudeCode` 等同于使用默认配置的 `createClaudeCode()`。

## 基本用法

```ts
import { HarnessAgent } from '@ai-sdk/harness/agent';
import { claudeCode } from '@ai-sdk/harness-claude-code';
import { createVercelSandbox } from '@ai-sdk/sandbox-vercel';

const agent = new HarnessAgent({
  harness: claudeCode,
  model: 'claude-sonnet-4-6',
  sandbox: createVercelSandbox({
    runtime: 'node24',
    ports: [4000],
  }),
});

const session = await agent.createSession();

let exitCode = 0;
try {
  const result = await agent.stream({
    session,
    prompt: '检查测试失败并修复生产代码。',
  });

  for await (const part of result.stream) {
    if (part.type === 'text-delta') {
      process.stdout.write(part.text);
    }
  }
} catch (err) {
  exitCode = 1;
  console.error(err);
} finally {
  await session.destroy();
  process.exit(exitCode);
}
```

要使用此智能体，请确保环境变量包含用于 Vercel 沙箱的 `VERCEL_OIDC_TOKEN`，以及[身份验证](#authentication)下列出的用于 Claude Code 的变量之一。

## 适配器设置

使用 `createClaudeCode()` 配置运行时：

```ts
const harness = createClaudeCode({
  maxTurns: 10,
  env: {
    DEPLOYMENT_ENV: 'staging',
  },
  thinking: {
    type: 'adaptive',
    display: 'summarized',
  },
});
```

设置：

- `auth`：身份验证模式（`auto`、`direct` 或 `ai-gateway`）或隔离的身份验证环境。
- `credentialForwarding`：可选的同步或异步回调，在工具链适配器将每个凭据转发到沙箱进程之前立即自定义该凭据。它接收原本会被转发的凭据值（真实凭据或掩码值）以及用于暴露该凭据的环境变量名称。此回调仅控制转发到沙箱进程的值。它不限制工具链适配器在主机进程中可以发现、读取或以其他方式访问的凭据。
- `mcpServers`：以服务器名称作为键的 MCP 服务器定义。
- `maxTurns`：让出前的最大内部轮数。
- `env`：Claude Code 进程的环境变量。这些值会合并到沙箱桥接器进程环境中并优先使用。
- `thinking`：扩展思考配置。`type` 可以是 `enabled`、`disabled` 或 `adaptive`。对于启用或自适应思考，`display` 可以是 `summarized` 或 `omitted`。默认为 `{ type: 'adaptive', display: 'summarized' }`。
- `port`：桥接器端口覆盖。
- `startupTimeoutMs`：等待桥接器启动的最长时间。
- `mintBridgeToken`：同步函数，接收沙箱 ID 并返回桥接器身份验证令牌。默认情况下，适配器生成一个随机的 32 字节令牌。自定义实现必须返回一个足够机密的令牌。

## 结构化输出

Claude Code 支持基于模式的 [`HarnessAgent` 结构化输出](/docs/ai-sdk-harnesses/harness-agent#generate-structured-output)。适配器通过 Agent SDK 的原生 `outputFormat` 选项传递 JSON Schema，并将其 `structured_output` 值作为 JSON 文本返回。

## 身份验证

`auth` 设置选择如何从主机环境解析凭据：

- `auto`（默认）：优先使用 AI Gateway 凭据，然后回退到直接使用 Anthropic 凭据。
- `direct`：使用 Anthropic 凭据。
- `ai-gateway`：使用 AI Gateway 凭据。

当沙箱支持附加请求转换时，桥接器会接收占位符，适配器会将凭据注入到匹配的出站请求中。不具备该能力的沙箱则保留直接凭据转发。

支持的环境变量：

- `VERCEL_OIDC_TOKEN`
- `AI_GATEWAY_API_KEY`
- `AI_GATEWAY_BASE_URL`
- `ANTHROPIC_API_KEY`
- `ANTHROPIC_AUTH_TOKEN`
- `ANTHROPIC_BASE_URL`

当您不希望自动检测时，请选择特定的身份验证模式：

```ts
const directHarness = createClaudeCode({ auth: 'direct' });
const gatewayHarness = createClaudeCode({ auth: 'ai-gateway' });
```

传入身份验证环境以使用编程方式解析的凭据，而不读取 `process.env`：

```ts
const harness = createClaudeCode({
  auth: { ANTHROPIC_API_KEY: await resolveAnthropicToken() },
});
```

提供的记录将替换主机环境以进行身份验证发现。仅转发已识别的身份验证变量。

## 沙箱

Claude Code 需要一个至少暴露一个端口的网络沙箱，例如 `@ai-sdk/sandbox-vercel`：

```ts
const sandbox = createVercelSandbox({
  runtime: 'node24',
  ports: [4000],
});
```

## 内置工具

适配器通过 `agent.tools` 暴露以下常见的 Claude Code 内置工具：

- `read`
- `write`
- `edit`
- `bash`
- `glob`
- `grep`
- `webSearch`

当其他 Claude Code 内置工具不符合常见工具形态时，它们也可能出现在 `agent.tools` 中。

当 `permissionMode` 为 `allow-reads` 或 `allow-edits` 时，Claude Code 支持内置工具审批请求。
