# AI SDK Harnesses

AI SDK harness 适配器将 `HarnessAgent` 连接到成熟的智能体运行时。
它们与模型提供商分离，但暴露了兼容 AI SDK 的流式传输和响应原语。

## 用法

所有 harness 适配器都与 `HarnessAgent` 一起使用：

```ts
import { HarnessAgent } from '@ai-sdk/harness/agent';
import { codex } from '@ai-sdk/harness-codex';
import { createVercelSandbox } from '@ai-sdk/sandbox-vercel';

const agent = new HarnessAgent({
  harness: codex,
  sandbox: createVercelSandbox({
    runtime: 'node24',
    ports: [4000],
  }),
});
```

阅读 [Harnesses](/docs/ai-sdk-harnesses) 文档以了解会话、工具、UI 和终端用法。
