# AI SDK Harnesses

AI SDK harness 适配器将 `HarnessAgent` 连接到现有的智能体运行时。
它们与模型提供商相互独立，但会暴露 AI SDK 兼容的流式传输
和响应原语。

## 用法

所有 harness 适配器均与 `HarnessAgent` 搭配使用：

```ts
import { HarnessAgent } from '@ai-sdk/harness/agent';
import { codex } from '@ai-sdk/harness-codex';
import { createVercelSandbox } from '@ai-sdk/sandbox-vercel';

const agent = new HarnessAgent({
  harness: codex,
  model: 'gpt-5.6-luna',
  sandbox: createVercelSandbox({
    runtime: 'node24',
    ports: [4000],
  }),
});
```

阅读 [Harnesses](/docs/ai-sdk-harnesses) 文档，了解会话、
工具、UI 和终端用法。
