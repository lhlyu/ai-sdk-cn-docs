# AI SDK 工具集

AI SDK 工具集适配器将 `HarnessAgent` 与成熟的智能体运行时连接起来。它们与模型提供商相互独立，但会暴露兼容 AI SDK 的流和响应原语。

## 使用方法

所有工具集适配器均与 `HarnessAgent` 配合使用：

```ts
import { HarnessAgent } from '@ai-sdk/harness/agent';
import { codex } from '@ai-sdk/harness-codex';
import { createVercelSandbox } from '@ai-sdk/sandbox-vercel';

const agent = new HarnessAgent({
  harness: codex,
  sandbox: createVercelSandbox({
    runtime: 'node24',
    ports: [4000],
  }),
});
```

请阅读[工具集](/docs/ai-sdk-harnesses)文档，了解会话、工具、UI 和终端用法。
