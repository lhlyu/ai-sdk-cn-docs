# Deep Agents Harness

Deep Agents harness 适配器将 `HarnessAgent` 连接到
[Deep Agents](https://github.com/langchain-ai/deepagentsjs)，这是一个基于 LangGraph 的智能体
运行时。该适配器在沙箱内运行一个 Node 桥接程序，由它驱动
`deepagents` 包，并通过沙箱暴露的 WebSocket 将其 `streamEvents` 输出流式传输回主机。

<Note>
  Harness 包目前处于**实验阶段**。由于这一早期 API 仍在不断完善，
  各版本之间可能会出现破坏性变更。
</Note>

## 设置

<InstallPackages packages="@ai-sdk/harness @ai-sdk/harness-deepagents @ai-sdk/sandbox-vercel" />

适配器会在首个会话启动时，通过 `pnpm` 在沙箱内引导安装桥接程序的 Node 依赖
（`deepagents` 包和 LangChain）。

## 导入

```ts
import { deepAgents, createDeepAgents } from '@ai-sdk/harness-deepagents';
```

`deepAgents` 等同于使用默认配置的 `createDeepAgents()`。

## 基本用法

```ts
import { HarnessAgent } from '@ai-sdk/harness/agent';
import { deepAgents } from '@ai-sdk/harness-deepagents';
import { createVercelSandbox } from '@ai-sdk/sandbox-vercel';

const agent = new HarnessAgent({
  harness: deepAgents,
  model: 'anthropic/claude-sonnet-4-6',
  sandbox: createVercelSandbox({
    runtime: 'node24',
    ports: [4000],
  }),
});

const session = await agent.createSession();

let exitCode = 0;
try {
  const result = await agent.stream({
    session,
    prompt: 'Analyze this codebase and suggest improvements.',
  });

  for await (const part of result.stream) {
    if (part.type === 'text-delta') {
      process.stdout.write(part.text);
    }
  }
} catch (err) {
  exitCode = 1;
  console.error(err);
} finally {
  await session.destroy();
  process.exit(exitCode);
}
```

要使用此智能体，请确保环境变量中包含用于 Vercel Sandbox 的 `VERCEL_OIDC_TOKEN`，
以及[身份验证](#authentication)下列出的、用于模型提供商的变量之一。

## 适配器设置

使用 `createDeepAgents()` 配置运行时：

```ts
const harness = createDeepAgents({ recursionLimit: 100 });
```

设置项：

- `auth`：身份验证模式（`auto`、`anthropic` 或 `ai-gateway`），或一个
  隔离的身份验证环境。
- `credentialForwarding`：可选的同步或异步回调，用于在 harness 适配器将每个凭据
  转发到沙箱进程之前立即对其进行自定义。它会接收原本将被转发的凭据值
  （真实凭据或掩码值）以及用于暴露该凭据的环境变量名。此回调仅控制
  转发到沙箱进程中的值。它不会限制 harness 适配器在主机进程中
  可以发现、读取或以其他方式访问哪些凭据。
- `mcpServers`：以服务器名称为键的 MCP 服务器定义。
- `port`：桥接端口覆盖。
- `recursionLimit`：每轮 LangGraph 超级步骤的最大数量。省略时，
  将应用 Deep Agents 的默认值。
- `startupTimeoutMs`：等待桥接程序启动的最长时间。
- `reconnect`：已建立的桥接 WebSocket 连接断开后的重连时机。
  `maxElapsedMs` 控制总重试窗口，包括连接建立和退避延迟，默认值为 30 秒。
  `initialDelayMs` 默认值为 50 毫秒，`maxDelayMs` 默认值为
  2 秒。这些重试使用指数退避，与 `startupTimeoutMs` 相互独立。
  当沙箱、桥接进程或桥接端点永久不可用时，它们无法恢复。
- `mintBridgeToken`：同步函数，接收沙箱 id 并
  返回桥接身份验证令牌。默认情况下，适配器会生成一个
  随机的 32 字节令牌。自定义实现必须返回一个足够安全的
  令牌。

## 结构化输出

Deep Agents 支持基于 schema 的 [`HarnessAgent` 结构化输出](/docs/ai-sdk-harnesses/harness-agent#generate-structured-output)。
适配器会应用每轮 LangChain 工具策略，并将图经过验证的 `structuredResponse`
作为 JSON 文本返回。

## 身份验证

Deep Agents 始终驱动 Anthropic 客户端。非 Anthropic 模型通过
AI Gateway 的 Anthropic 兼容端点访问它，该端点可转换为任何
模型（Gemini、OpenAI 等），包括工具调用。

`auth` 设置用于选择如何从主机环境解析凭据：

- `auto`（默认）：在可用时使用 AI Gateway 凭据，然后回退
  到 Anthropic 凭据。
- `anthropic`：使用 Anthropic 凭据。
- `ai-gateway`：使用 AI Gateway 凭据。

当沙箱支持附加式请求转换时，桥接程序会接收占位符，适配器会将凭据注入到
匹配的出站请求中。不具备该能力的沙箱则保留直接凭据
转发。

支持的环境变量：

- `AI_GATEWAY_API_KEY`
- `VERCEL_OIDC_TOKEN`
- `AI_GATEWAY_BASE_URL`
- `ANTHROPIC_API_KEY`
- `ANTHROPIC_AUTH_TOKEN`
- `ANTHROPIC_BASE_URL`

要运行非 Anthropic 模型，请选择 `ai-gateway`：

```ts
const harness = createDeepAgents({ auth: 'ai-gateway' });
const agent = new HarnessAgent({
  harness,
  model: 'google/gemini-2.5-flash',
  sandbox,
});
```

传入身份验证环境，以使用以编程方式解析的凭据，而无需读取 `process.env`：

```ts
const harness = createDeepAgents({
  auth: { ANTHROPIC_API_KEY: await resolveAnthropicToken() },
});
```

所提供的记录会替换用于身份验证发现的主机环境。只有已识别的身份验证变量
会被转发。

## 沙箱

Deep Agents 需要一个至少暴露一个端口的网络沙箱，
例如 `@ai-sdk/sandbox-vercel`：

```ts
const sandbox = createVercelSandbox({
  runtime: 'node24',
  ports: [4000],
});
```

## 技能

传递给会话的技能会被具体化为原生 Deep Agents 技能文件夹
（`<name>/SKILL.md` 以及任何附加文件），位于沙箱中的 `$HOME/.agents/skills/`
下（在工作目录之外，因此不会与克隆的代码冲突），并通过 Deep Agents 的
`skills` 选项加载——因此智能体会按需加载它们，技能文件引用也能正确解析。
已存在于 `<workDir>/.agents/skills/` 下的技能
（例如在克隆的仓库中）也会被发现。

## 内置工具

适配器通过 `agent.tools` 暴露以下 Deep Agents 内置工具：

- `read`
- `write`
- `edit`
- `bash`
- `grep`
- `glob`
- `ls`
- `task`
- `write_todos`

## 已知限制

- **不支持恢复已停止会话的对话**——在
  `session.stop()` 之后，Deep Agents 的内存中对话状态（LangGraph
  `MemorySaver`）会丢失；只有沙箱工作区会通过其快照持久化。
  使用 `session.detach()` 进行跨进程交接，或使用 `session.suspendTurn()` 在保持
  实时桥接程序运行的同时继续轮次。
- **不支持手动压缩**。
