# Deep Agents 适配器

Deep Agents 适配器将 `HarnessAgent` 连接到
[Deep Agents](https://github.com/langchain-ai/deepagentsjs)，这是一个基于 LangGraph 的智能体
运行时。该适配器在沙箱内运行一个 Node 桥接器，驱动
`deepagents` 包，并通过沙箱暴露的 WebSocket 将其 `streamEvents` 输出流式传输回主机。

<Note>
  Harness 包是**实验性**的。随着这个早期 API 的进一步完善，不同版本之间可能会出现破坏性变更。
</Note>

## 设置

<InstallPackages packages="@ai-sdk/harness @ai-sdk/harness-deepagents @ai-sdk/sandbox-vercel" />

当第一个会话启动时，适配器会通过 `pnpm` 在沙箱内引导桥接器的 Node 依赖项（`deepagents` 包和 LangChain）。

## 导入

```ts
import { deepAgents, createDeepAgents } from '@ai-sdk/harness-deepagents';
```

`deepAgents` 等同于使用默认配置调用 `createDeepAgents()`。

## 基本用法

```ts
import { HarnessAgent } from '@ai-sdk/harness/agent';
import { deepAgents } from '@ai-sdk/harness-deepagents';
import { createVercelSandbox } from '@ai-sdk/sandbox-vercel';

const agent = new HarnessAgent({
  harness: deepAgents,
  sandbox: createVercelSandbox({
    runtime: 'node24',
    ports: [4000],
  }),
});

const session = await agent.createSession();

let exitCode = 0;
try {
  const result = await agent.stream({
    session,
    prompt: '分析此代码库并提出改进建议。',
  });

  for await (const part of result.stream) {
    if (part.type === 'text-delta') {
      process.stdout.write(part.text);
    }
  }
} catch (err) {
  exitCode = 1;
  console.error(err);
} finally {
  await session.destroy();
  process.exit(exitCode);
}
```

要使用此智能体，请确保环境变量包含用于 Vercel Sandbox 的 `VERCEL_OIDC_TOKEN`，以及[身份验证](#authentication)下列出的用于模型提供商的一个变量。

## 适配器设置

使用 `createDeepAgents()` 配置运行时：

```ts
const harness = createDeepAgents({
  model: 'claude-sonnet-4',
});
```

设置：

- `auth`：Anthropic 或 AI Gateway 身份验证设置。
- `model`：传递给 Deep Agents (LangChain) 运行时的模型 ID。通过 AI Gateway，使用 `creator/model` 标识符（例如 `anthropic/claude-sonnet-4-6`、`google/gemini-2.5-flash`、`openai/gpt-4.1-mini`）。
- `port`：桥接器端口覆盖。
- `recursionLimit`：每轮的最大 LangGraph 超级步骤数。省略时，应用 Deep Agents 默认值。
- `startupTimeoutMs`：等待桥接器启动的最长时间。

## 身份验证

Deep Agents 始终驱动 Anthropic 客户端。非 Anthropic 模型通过 AI Gateway 的 Anthropic 兼容端点访问，该端点可转换为任何模型（Gemini、OpenAI 等），包括工具调用。身份验证从主机环境解析并转发到沙箱桥接器：首先使用显式的 Anthropic 身份验证，然后是 AI Gateway 凭据，最后是环境中的 Anthropic 凭据。

支持的环境变量：

- `AI_GATEWAY_API_KEY`
- `VERCEL_OIDC_TOKEN`
- `AI_GATEWAY_BASE_URL`
- `ANTHROPIC_API_KEY`
- `ANTHROPIC_AUTH_TOKEN`
- `ANTHROPIC_BASE_URL`

您也可以传递显式的身份验证设置（`anthropic` 或 `gateway`）。要运行非 Anthropic 模型，请通过 AI Gateway 路由：

```ts
const harness = createDeepAgents({
  model: 'google/gemini-2.5-flash',
  auth: {
    gateway: {
      apiKey: process.env.AI_GATEWAY_API_KEY,
    },
  },
});
```

## 沙箱

Deep Agents 需要一个至少暴露一个端口的网络沙箱，例如 `@ai-sdk/sandbox-vercel`：

```ts
const sandbox = createVercelSandbox({
  runtime: 'node24',
  ports: [4000],
});
```

## 技能

传递给会话的技能会物化为原生的 Deep Agents 技能文件夹（`<name>/SKILL.md` 以及任何附加文件），位于沙箱中的 `$HOME/.agents/skills/` 下（在工作目录之外，因此不会与克隆的代码冲突），并通过 Deep Agents 的 `skills` 选项加载——因此智能体会按需加载它们，并且技能文件引用得以解析。已存在于 `<workDir>/.agents/skills/` 下的技能（例如在克隆的仓库中）也会被发现。

## 内置工具

适配器通过 `agent.tools` 暴露以下 Deep Agents 内置工具：

- `read`
- `write`
- `edit`
- `bash`
- `grep`
- `glob`
- `ls`
- `task`
- `write_todos`

## 已知限制

- **不支持恢复已停止会话的对话**——在 `session.stop()` 之后，Deep Agents 的内存对话状态（LangGraph `MemorySaver`）会丢失；只有沙箱工作区通过其快照持久存在。使用 `session.detach()` 进行跨进程交接，或使用 `session.suspendTurn()` 在保持实时桥接器运行的同时继续对话轮次。
- **不支持手动压缩**。
