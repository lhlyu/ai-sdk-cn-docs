# Codex 工具集成

Codex 工具集成适配器通过 `@openai/codex-sdk` 将 `HarnessAgent` 连接到 Codex。该适配器在沙箱内运行一个桥接服务，并通过沙箱暴露的 WebSocket 将 Codex 线程事件流式传输回主机。

<Note>
  工具集成包目前处于**实验性**阶段。随着这个早期 API 的进一步完善，不同版本之间可能会出现破坏性变更。
</Note>

当第一个会话启动时，适配器会在沙箱内引导 Codex 桥接依赖项。

## 导入

```ts
import { codex, createCodex } from '@ai-sdk/harness-codex';
```

`codex` 等同于使用默认配置的 `createCodex()`。

## 基本用法

```ts
import { HarnessAgent } from '@ai-sdk/harness/agent';
import { codex } from '@ai-sdk/harness-codex';
import { createVercelSandbox } from '@ai-sdk/sandbox-vercel';

const agent = new HarnessAgent({
  harness: codex,
  sandbox: createVercelSandbox({
    runtime: 'node24',
    ports: [4000],
  }),
});

const session = await agent.createSession();

let exitCode = 0;
try {
  const result = await agent.stream({
    session,
    prompt: '检查测试失败原因并修复生产代码。',
  });

  for await (const part of result.stream) {
    if (part.type === 'text-delta') {
      process.stdout.write(part.text);
    }
  }
} catch (err) {
  exitCode = 1;
  console.error(err);
} finally {
  await session.destroy();
  process.exit(exitCode);
}
```

要使用此智能体，请确保环境变量中包含用于 Vercel Sandbox 的 `VERCEL_OIDC_TOKEN`，以及 [身份验证](#身份验证) 部分列出的 Codex 相关变量之一。

## 适配器设置

使用 `createCodex()` 配置运行时：

```ts
const harness = createCodex({
  model: 'gpt-5.5',
  reasoningEffort: 'high',
  webSearch: true,
});
```

设置项：

- `auth`：OpenAI、兼容 OpenAI 或 AI Gateway 的身份验证设置。
- `model`：OpenAI 模型 ID。如果省略，适配器将使用其固定的默认值。
- `reasoningEffort`：`low`、`medium` 或 `high`。
- `webSearch`：允许实时网络搜索。
- `port`：桥接端口覆盖。
- `startupTimeoutMs`：等待桥接启动的最长时间。

## 身份验证

默认情况下，身份验证信息从主机环境解析并转发到沙箱桥接。适配器会检查 AI Gateway 和 OpenAI 凭据。

支持的环境变量：

- `VERCEL_OIDC_TOKEN`
- `AI_GATEWAY_API_KEY`
- `AI_GATEWAY_BASE_URL`
- `OPENAI_API_KEY`
- `CODEX_API_KEY`
- `OPENAI_BASE_URL`
- `OPENAI_ORGANIZATION`
- `OPENAI_PROJECT`

您也可以显式传递身份验证设置：

```ts
const harness = createCodex({
  auth: {
    openai: {
      apiKey: process.env.OPENAI_API_KEY,
    },
  },
});
```

对于兼容 OpenAI 的端点，请使用 `auth.openaiCompatible`。

## 沙箱

Codex 需要一个至少暴露一个端口的网络沙箱，例如 `@ai-sdk/sandbox-vercel`：

```ts
const sandbox = createVercelSandbox({
  runtime: 'node24',
  ports: [4000],
});
```

## 内置工具

适配器通过 `agent.tools` 暴露以下常见的 Codex 内置工具：

- `bash`
- `webSearch`

其他 Codex 内置工具也可能出现在 `agent.tools` 中，前提是它们不符合常见工具的形状。

Codex 文件更改也可能作为动态的 `fileChange` 工具部分出现，因为某些 Codex 文件变更并非源自可见的、可由模型调用的工具。

## 已知限制

Codex 目前不支持内置工具的审批请求。请在此适配器中使用 `permissionMode: 'allow-all'`。主机执行的 AI SDK 工具审批仍然有效。

Codex 目前不支持内置工具的过滤。您仍然可以使用 `activeTools` 和 `inactiveTools` 来过滤主机执行的工具，但过滤 Codex 内置工具（如 `bash` 或 `webSearch`）将会抛出错误。
