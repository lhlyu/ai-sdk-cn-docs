# Gemini CLI 提供商

[ai-sdk-provider-gemini-cli](https://github.com/ben-vargas/ai-sdk-provider-gemini-cli) 社区提供商支持通过 [@google/gemini-cli-core](https://www.npmjs.com/package/@google/gemini-cli-core) 库使用 Google 的 Gemini 模型。这对于希望使用现有 Gemini Code Assist 订阅或 API 密钥进行身份验证的开发者非常有用。

## 版本兼容性

| 提供商版本 | AI SDK 版本 | NPM 标签    | 状态     |
| ---------- | ----------- | ----------- | -------- |
| 2.x        | v6          | `latest`    | 稳定     |
| 1.x        | v5          | `ai-sdk-v5` | 维护中   |
| 0.x        | v4          | `ai-sdk-v4` | 旧版     |

```bash
# AI SDK v6（默认）
npm install ai-sdk-provider-gemini-cli ai

# AI SDK v5
npm install ai-sdk-provider-gemini-cli@ai-sdk-v5 ai@^5.0.0

# AI SDK v4
npm install ai-sdk-provider-gemini-cli@ai-sdk-v4 ai@^4.0.0
```

## 提供商实例

导入 `createGeminiProvider` 并根据身份验证设置创建提供商实例：

```ts
import { createGeminiProvider } from 'ai-sdk-provider-gemini-cli';

// OAuth 身份验证（省略 authType 时的默认值）
const gemini = createGeminiProvider({ authType: 'oauth-personal' });

// API 密钥身份验证
const gemini = createGeminiProvider({
  authType: 'api-key', // 或 'gemini-api-key'
  apiKey: process.env.GEMINI_API_KEY,
});

// Vertex AI 身份验证
const gemini = createGeminiProvider({
  authType: 'vertex-ai',
  vertexAI: {
    projectId: 'my-project',
    location: 'us-central1',
  },
});

// Google Auth Library
const gemini = createGeminiProvider({
  authType: 'google-auth-library',
  googleAuth: myGoogleAuthInstance,
});
```

身份验证选项：

- **authType** _'oauth' | 'oauth-personal' | 'api-key' | 'gemini-api-key' | 'vertex-ai' | 'google-auth-library'_ - 可选。默认为 `'oauth-personal'`。
- **apiKey** _string_ - 使用 `'api-key'` / `'gemini-api-key'` 时必填。
- **vertexAI** _\{ projectId, location \}_ - 使用 `'vertex-ai'` 时必填。
- **googleAuth** _GoogleAuth_ - 使用 `'google-auth-library'` 时必填。
- **cacheDir** _string_ - OAuth 凭据缓存的可选目录。
- **proxy** _string_ - HTTP/HTTPS 代理 URL。

## 语言模型

使用提供商实例创建通过 CLI 调用 Gemini 的模型：

```ts
const model = gemini('gemini-2.5-pro');
```

支持的模型：

- **gemini-3.1-pro-preview**：最新模型，增强推理能力（支持 `thinkingLevel`）
- **gemini-3-flash-preview**：快速 Gemini 3 模型（支持 `thinkingLevel`）
- **gemini-3.1-flash-lite-preview**：最新模型，增强推理能力（支持 `thinkingLevel`）
- **gemini-2.5-pro**：生产就绪模型，64K 输出令牌（支持 `thinkingBudget`）
- **gemini-2.5-flash**：快速高效模型，64K 输出令牌（支持 `thinkingBudget`）

### 示例

```ts
import { createGeminiProvider } from 'ai-sdk-provider-gemini-cli';
import { generateText } from 'ai';

const gemini = createGeminiProvider({
  authType: 'oauth-personal',
});

const { text } = await generateText({
  model: gemini('gemini-2.5-pro'),
  prompt: '写一份供4人食用的素食千层面食谱。',
});
```

### 模型设置

```ts
const model = gemini('gemini-3.1-pro-preview', {
  temperature: 0.7,
  topP: 0.95,
  topK: 40,
  maxOutputTokens: 8192,
  thinkingConfig: {
    thinkingLevel: 'medium', // 'low' | 'medium' | 'high' | 'minimal'
  },
  verbose: true, // 启用调试日志
  logger: customLogger, // 自定义日志记录器（或设为 false 以禁用）
});
```

## 身份验证

### OAuth 身份验证（推荐）

全局安装并验证 Gemini CLI：

```bash
npm install -g @google/gemini-cli
gemini  # 按照交互式身份验证设置进行操作
```

然后在代码中使用 `authType: 'oauth-personal'` 进行 OAuth 身份验证。

### API 密钥身份验证

1. 从 [Google AI Studio](https://aistudio.google.com/apikey) 生成 API 密钥。
2. 将其设置为环境变量：`export GEMINI_API_KEY="YOUR_API_KEY"`
3. 使用 `authType: 'api-key'` 和你的密钥。

## 要求

- Node.js 22 或更高版本
- 全局安装 Gemini CLI 以进行 OAuth 身份验证
- 有效的 Google 账户或 Gemini API 密钥

更多详情，请参阅[提供商文档](https://github.com/ben-vargas/ai-sdk-provider-gemini-cli)。
