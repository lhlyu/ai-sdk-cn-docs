# Sarvam 提供商

Sarvam AI 提供商是一个为集成 AI SDK 而开发的库。该库为您的应用程序带来了语音转文本（STT）功能，允许与音频和文本数据进行无缝交互。

## 设置

Sarvam 提供商在 `sarvam-ai-provider` 模块中可用。您可以通过以下方式安装：

<InstallPackages packages="sarvam-ai-provider" />

## 提供商实例

首先，从 [Sarvam 仪表盘](https://dashboard.sarvam.ai/auth/signin) 获取您的 **Sarvam API 密钥**。

然后在您的应用程序中初始化 `Sarvam`：

```ts
import { createSarvam } from 'sarvam-ai-provider';

const sarvam = createSarvam({
  headers: {
    'api-subscription-key': 'YOUR_API_KEY',
  },
});
```

<Note>
  `api-subscription-key` 需要在请求头中传递。出于安全考虑，建议使用环境变量来存储 `YOUR_API_KEY`。
</Note>

- 将语音转录为文本

```ts
import { transcribe } from 'ai';
import { readFile } from 'fs/promises';

await transcribe({
  model: sarvam.transcription('saarika:v2'),
  audio: await readFile('./src/transcript-test.mp3'),
  providerOptions: {
    sarvam: {
      language_code: 'en-IN',
    },
  },
});
```

## 功能

### 更改参数

- 更改 language_code

```ts
providerOptions: {
    sarvam: {
      language_code: 'en-IN',
    },
  },
```

<Note>
  `language_code` 指定输入音频的语言，对于准确转录是必需的。 • 对于 `saarika:v1` 模型是强制性的（此模型不支持 `unknown`）。 • 对于 `saarika:v2` 模型是可选的。 • 当语言未知时使用 `unknown`；在这种情况下，API 将自动检测。可用选项：`unknown`、`hi-IN`、`bn-IN`、`kn-IN`、`ml-IN`、`mr-IN`、`od-IN`、`pa-IN`、`ta-IN`、`te-IN`、`en-IN`、`gu-IN`。
</Note>

- with_timestamps？

```ts
providerOptions: {
  sarvam: {
    with_timestamps: true,
  },
},
```

<Note>
  `with_timestamps` 指定是否包含每个单词/标记的开始/结束时间戳。 • 类型：布尔值 • 当为 true 时，每个单词/标记将包含开始/结束时间戳。 • 默认值：false
</Note>

- with_diarization？

```ts
providerOptions: {
  sarvam: {
    with_diarization: true,
  },
},
```

<Note>
  `with_diarization` 启用说话人分离（Beta）。 • 类型：布尔值 • 当为 true 时，启用说话人分离。 • 默认值：false
</Note>

- num_speakers？

```ts
providerOptions: {
  sarvam: {
    with_diarization: true,
    num_speakers: 2,
  },
},
```

<Note>
  `num_speakers` 设置要检测的不同说话人数量（仅在 `with_diarization` 为 true 时有效）。 • 类型：number | null • 要检测的不同说话人数量。 • 默认值：null
</Note>
