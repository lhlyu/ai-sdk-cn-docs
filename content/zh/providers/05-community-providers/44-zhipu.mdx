# Zhipu AI (Z.AI) 提供商

[Zhipu AI Provider](https://github.com/Xiang-CH/zhipu-ai-provider) 是 [AI SDK](/) 的一个社区提供商。它支持与 [ZhipuAI](https://www.zhipuai.cn/) 在 [bigmodel.cn](https://bigmodel.cn/) 或 [z.ai](https://docs.z.ai/) 上提供的 **GLM** 和嵌入模型无缝集成。

在 `.env` 文件或环境中设置你的 API 密钥。

```bash
ZHIPU_API_KEY=<your-api-key>
```

## 提供商实例

你可以从 `zhipu-ai-provider` 导入默认的提供商实例 `zhipu`（它会自动从环境变量 `ZHIPU_API_KEY` 中读取 API 密钥）：

```ts
import { zhipu } from 'zhipu-ai-provider';
```

或者，你也可以使用 `createZhipu` 创建具有自定义配置的提供商实例（如果你想使用非中国的 [Z.AI](https://docs.z.ai/guides) 基础设施，请执行此操作）：

```ts
import { createZhipu } from 'zhipu-ai-provider';

const zhipu = createZhipu({
  baseURL: 'https://api.z.ai/api/paas/v4',
  apiKey: 'your-api-key',
});
```

你可以使用以下可选设置来自定义 Zhipu 提供商实例：

- **baseURL**: _string_
  - 为 API 调用使用不同的 URL 前缀，例如使用代理服务器。默认前缀是 `https://open.bigmodel.cn/api/paas/v4`。

- **apiKey**: _string_
  - 你的 Zhipu [BigModel 平台](https://bigmodel.cn/) API 密钥。如果未提供，提供商将尝试从环境变量 `ZHIPU_API_KEY` 中读取 API 密钥。

- **headers**: _Record\<string, string\>_
  - 要包含在请求中的自定义标头。

## 示例

```ts
import { zhipu } from 'zhipu-ai-provider';

const { text } = await generateText({
  model: zhipu('glm-4-plus'),
  prompt: '为什么天空是蓝色的？',
});

console.log(result);
```
