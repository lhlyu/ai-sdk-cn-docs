# SAP AI Core 提供商

[jerome-benoit/sap-ai-provider](https://github.com/jerome-benoit/sap-ai-provider) 是一个面向 SAP AI Core 的社区提供商，基于官方 **@sap-ai-sdk/orchestration** 和 **@sap-ai-sdk/foundation-models** 包构建。

该仓库发布两个 npm 包：

- `@jerome-benoit/sap-ai-provider` - 适用于 AI SDK 5.x 和 6.x 的语言模型 V4（推荐）
- `@jerome-benoit/sap-ai-provider-v2` - 适用于 AI SDK 5.x 的语言模型 V2

## 功能特性

两个提供商均提供：

- **双 API 支持**：可选择编排 API（支持数据脱敏、内容过滤、文档接地、翻译）或基础模型 API（支持 `logprobs`、`seed`、`dataSources`）
- **工具调用**和**多模态输入**（图像）
- **流式传输支持**，实现实时文本生成
- **文本嵌入**，用于 RAG 和语义搜索

## 提供商实例

你可以从 `@jerome-benoit/sap-ai-provider` 导入默认提供商实例 `sapai`：

```ts
import { sapai } from '@jerome-benoit/sap-ai-provider';
```

如果需要自定义设置，可以导入 `createSAPAIProvider` 并使用你的设置创建提供商实例：

```ts
import { createSAPAIProvider } from '@jerome-benoit/sap-ai-provider';

const sapai = createSAPAIProvider({
  resourceGroup: 'default',
  api: 'orchestration', // 或 'foundation-models'
});
```

你可以使用以下可选设置来自定义 SAP AI 提供商实例：

- **resourceGroup** _string_

  SAP AI Core 资源组。默认为 `'default'`。

- **deploymentId** _string_

  特定部署 ID。如果未提供，SDK 将自动解析部署。

- **api** _'orchestration' | 'foundation-models'_

  要使用的 API。默认为 `'orchestration'`。可通过 `providerOptions` 按模型或按调用覆盖。

- **name** _string_

  用作 `providerOptions` 中键的提供商名称。默认为 `'sap-ai'`。

- **defaultSettings** _object_

  默认模型设置，包括 `modelParams`、`masking`、`filtering`、`grounding` 和 `translation`。

## 语言模型

你可以使用提供商实例创建调用 SAP AI Core API 的模型。第一个参数是模型 ID。模型命名遵循 SAP AI Core 约定，带有供应商前缀：

```ts
const model = sapai('gpt-4.1');
const claudeModel = sapai('anthropic--claude-3.5-sonnet');
const geminiModel = sapai('gemini-2.0-flash');
```

<Note>
  模型可用性取决于你的 SAP AI Core 租户配置和区域。
</Note>

## 嵌入模型

你可以使用 `.embeddingModel()` 工厂方法创建调用 SAP AI Core 嵌入 API 的模型：

```ts
const model = sapai.embeddingModel('text-embedding-3-small');
```
