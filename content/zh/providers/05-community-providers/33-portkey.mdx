# Portkey 提供商

[Portkey](https://portkey.ai/?utm_source=vercel&utm_medium=docs&utm_campaign=integration) 原生集成 AI SDK，使您的应用达到生产就绪状态并具备可靠性。导入 Portkey 的 Vercel 包，并将其用作 Vercel AI 应用中的提供商，即可启用 Portkey 的所有功能：

- 所有请求的全栈**可观测性**和**追踪**
- 跨 **250+ 大语言模型**的互操作性
- 内置 **50+** 最先进的护栏
- 简单且语义化的**缓存**，节省成本和时间
- 带回退、负载均衡、自动重试等的条件请求路由
- 基于用户反馈的持续改进

了解更多信息，请访问 [Portkey 的 AI SDK 文档](https://docs.portkey.ai/docs/integrations/libraries/vercel)

## 设置

Portkey 提供商位于 `@portkey-ai/vercel-provider` 模块中。您可以通过以下命令安装：

<InstallPackages packages="@portkey-ai/vercel-provider" />

## 提供商实例

要创建 Portkey 提供商实例，请使用 `createPortkey` 函数：

```typescript
import { createPortkey } from '@portkey-ai/vercel-provider';

const portkeyConfig = {
  provider: 'openai', // 输入所选提供商
  api_key: 'OPENAI_API_KEY', // 输入相应提供商的 API 密钥
  override_params: {
    model: 'gpt-5', // 从 250+ 大语言模型中选择
  },
};

const portkey = createPortkey({
  apiKey: 'YOUR_PORTKEY_API_KEY',
  config: portkeyConfig,
});
```

您可以在 [Portkey 仪表盘](https://app.portkey.ai) 中找到您的 Portkey API 密钥。

## 语言模型

Portkey 支持聊天和补全模型。使用 `portkey.chatModel()` 处理聊天模型，使用 `portkey.completionModel()` 处理补全模型：

```typescript
const chatModel = portkey.chatModel('');
const completionModel = portkey.completionModel('');
```

注意：如果您已在 `portkeyConfig` 中定义了模型名称，则可以将模型名称留空字符串。

## 示例

您可以将 Portkey 语言模型与 `generateText` 或 `streamText` 函数一起使用：

### `generateText`

```javascript
import { createPortkey } from '@portkey-ai/vercel-provider';
import { generateText } from 'ai';

const portkey = createPortkey({
  apiKey: 'YOUR_PORTKEY_API_KEY',
  config: portkeyConfig,
});

const { text } = await generateText({
  model: portkey.chatModel(''),
  prompt: '什么是 Portkey？',
});

console.log(text);
```

### `streamText`

```javascript
import { createPortkey } from '@portkey-ai/vercel-provider';
import { streamText } from 'ai';

const portkey = createPortkey({
  apiKey: 'YOUR_PORTKEY_API_KEY',
  config: portkeyConfig,
});

const result = streamText({
  model: portkey.completionModel(''),
  prompt: '发明一个新的节日并描述其传统。',
});

for await (const chunk of result) {
  console.log(chunk);
}
```

注意：

- Portkey 支持与 AI SDK 一起使用 `Tool`
- 目前不支持通过 [`Output`](/docs/reference/ai-sdk-core/output) 的结构化输出。

## 高级功能

Portkey 提供多项高级功能来增强您的 AI 应用：

1. **互操作性**：通过更改配置中的提供商和模型名称，轻松在 250+ AI 模型之间切换。

2. **可观测性**：访问所有请求的全面分析和日志。

3. **可靠性**：实现缓存、回退、负载均衡和条件路由。

4. **护栏**：通过输入和输出检查实时强制执行大语言模型行为。

5. **安全与合规**：设置预算限制并实现细粒度的用户角色和权限。

有关这些功能和高级配置选项的详细信息，请参阅 [Portkey 文档](https://docs.portkey.ai/docs/integrations/libraries/vercel)。
