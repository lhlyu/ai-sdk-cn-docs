# MiniMax 提供商

[vercel-minimax-ai-provider](https://github.com/MiniMax-AI/vercel-minimax-ai-provider) 是一个社区提供商，可访问来自 [MiniMax](https://www.minimax.io/) 的最新 [MiniMax-M2 模型](https://platform.minimax.io/docs/guides/text-generation)。

API 密钥可以从 [MiniMax 平台](https://platform.minimax.io/user-center/basic-information/interface-key) 获取。

## 设置

MiniMax 提供商通过 `vercel-minimax-ai-provider` 模块提供。您可以使用以下命令安装：

<InstallPackages packages="vercel-minimax-ai-provider" />

## 提供商实例

MiniMax 提供商支持两种 API 兼容模式：

### Anthropic 兼容 API（默认）

您可以从 `vercel-minimax-ai-provider` 导入默认的提供商实例 `minimax`：

```ts
import { minimax } from 'vercel-minimax-ai-provider';
```

或者显式使用 Anthropic 兼容实例：

```ts
import { minimaxAnthropic } from 'vercel-minimax-ai-provider';
```

或者 OpenAI 兼容的 API 格式：

```ts
import { minimaxOpenAI } from 'vercel-minimax-ai-provider';
```

## 自定义配置

对于自定义配置，您可以使用 `createMinimax`（Anthropic 兼容）或 `createMinimaxOpenAI`（OpenAI 兼容）函数：

### Anthropic 兼容配置（默认）

```ts
import { createMinimax } from 'vercel-minimax-ai-provider';

const minimax = createMinimax({
  apiKey: process.env.MINIMAX_API_KEY,
});
```

### 配置选项

您可以使用以下可选设置来自定义 MiniMax 提供商实例：

- **baseURL** _string_

  为 API 调用使用不同的 URL 前缀。
  - Anthropic 兼容默认值：`https://api.minimax.io/anthropic/v1`
  - OpenAI 兼容默认值：`https://api.minimax.io/v1`

- **apiKey** _string_

  通过 `Authorization` 标头发送的 API 密钥。默认值为 `MINIMAX_API_KEY` 环境变量。

- **headers** _Record&lt;string,string&gt;_

  要包含在请求中的自定义标头。

- **fetch** _(input: RequestInfo, init?: RequestInit) => Promise&lt;Response&gt;_

  自定义 [fetch](https://developer.mozilla.org/en-US/docs/Web/API/fetch) 实现。

## API 兼容性

MiniMax 提供两种 API 格式。此包中包含了这两种格式。

主要区别在于 API 请求/响应格式：

- **Anthropic 格式**（默认）：使用 Anthropic Messages API 格式，带有 `anthropic-version` 标头
- **OpenAI 格式**：使用标准的 OpenAI 聊天补全格式

两种格式都访问相同的 MiniMax 模型，具有相同的功能。

## 使用示例

### 基本文本生成

```ts
import { minimax } from 'vercel-minimax-ai-provider';
import { generateText } from 'ai';

const result = await generateText({
  model: minimax('MiniMax-M2'),
  prompt: '用简单的术语解释量子计算。',
});

console.log(result.text);
```

### 流式传输

```ts
import { minimax } from 'vercel-minimax-ai-provider';
import { streamText } from 'ai';

const result = streamText({
  model: minimax('MiniMax-M2'),
  prompt: '写一个关于机器人学习绘画的短篇故事。',
});

for await (const chunk of result.textStream) {
  console.log(chunk);
}
```
