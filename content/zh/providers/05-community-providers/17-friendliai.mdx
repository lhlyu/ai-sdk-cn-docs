# FriendliAI 提供商

[FriendliAI](https://friendli.ai/) 提供商支持通过 [Friendli Serverless Endpoints](https://friendli.ai/products/serverless-endpoints) 使用开源 LLM，以及通过 [Dedicated Endpoints](https://friendli.ai/products/dedicated-endpoints) 使用自定义模型。

它创建的语言模型对象可用于 `generateText` 和 `streamText` 函数，并支持通过 [`Output`](/docs/reference/ai-sdk-core/output) 进行结构化数据生成。

## 设置

Friendli 提供商可通过 `@friendliai/ai-provider` 模块获取。
你可以通过以下命令安装：

<InstallPackages packages="@friendliai/ai-provider" />

### 凭据

模型使用所需的令牌可以从 [Friendli suite](https://suite.friendli.ai/) 获取。

要使用该提供商，你需要设置 `FRIENDLI_TOKEN` 环境变量，并填入你的个人访问令牌。

```bash
export FRIENDLI_TOKEN="YOUR_FRIENDLI_TOKEN"
```

更多信息请查看 [FriendliAI 文档](https://friendli.ai/docs/guides/personal_access_tokens)。

## 提供商实例

你可以从 `@friendliai/ai-provider` 导入默认的提供商实例 `friendliai`：

```ts
import { friendli } from '@friendliai/ai-provider';
```

## 语言模型

你可以使用提供商实例创建 [FriendliAI 模型](https://friendli.ai/docs/guides/serverless_endpoints/text_generation#model-supports)。
第一个参数是模型 ID，例如 `meta-llama-3.1-8b-instruct`。

```ts
const model = friendli('meta-llama-3.1-8b-instruct');
```

### 示例：生成文本

你可以使用 FriendliAI 语言模型通过 `generateText` 函数生成文本：

```ts
import { friendli } from '@friendliai/ai-provider';
import { generateText } from 'ai';

const { text } = await generateText({
  model: friendli('meta-llama-3.1-8b-instruct'),
  prompt: 'What is the meaning of life?',
});

console.log(text);
```

### 示例：推理

FriendliAI 在生成的文本中通过 `<think>` 标签暴露 `deepseek-r1` 的思考过程。
你可以使用 `extractReasoningMiddleware` 提取此推理过程，并将其作为结果的 `reasoning` 属性暴露：

```ts
import { friendli } from '@friendliai/ai-provider';
import { wrapLanguageModel, extractReasoningMiddleware } from 'ai';

const enhancedModel = wrapLanguageModel({
  model: friendli('deepseek-r1'),
  middleware: extractReasoningMiddleware({ tagName: 'think' }),
});

const { text, reasoning } = await generateText({
  model: enhancedModel,
  prompt: 'Explain quantum entanglement.',
});
```

### 示例：结构化输出（正则表达式）

正则表达式选项允许你通过指定模式来控制 LLM 输出的格式。这在以下场景中特别有用：

- 特定格式，如 CSV
- 将输出限制为特定字符，如韩文或日文

此功能可用于 `generateText` 和 `streamText` 函数。

要深入了解如何有效使用正则表达式模式与 LLM，请查看我们详细的指南，位于 [Structured Output LLM Agents](https://friendli.ai/blog/structured-output-llm-agents) 博客文章中。

```ts highlight="6"
import { friendli } from '@friendliai/ai-provider';
import { generateText } from 'ai';

const { text } = await generateText({
  model: friendli('meta-llama-3.1-8b-instruct', {
    regex: new RegExp('[\n ,.?!0-9\uac00-\ud7af]*'),
  }),
  prompt: 'Who is the first king of the Joseon Dynasty?',
});

console.log(text);
```

### 示例：结构化输出（JSON）

结构化输出是一种引导生成的形式。JSON 模式被用作语法，输出将始终符合该模式。

```ts
import { friendli } from '@friendliai/ai-provider';
import { generateText, Output } from 'ai';
import { z } from 'zod';

const { output } = await generateText({
  model: friendli('meta-llama-3.3-70b-instruct'),
  output: Output.object({
    schemaName: 'CalendarEvent',
    schema: z.object({
      name: z.string(),
      date: z.string(),
      participants: z.array(z.string()),
    }),
  }),
  system: 'Extract the event information.',
  prompt: 'Alice and Bob are going to a science fair on Friday.',
});

console.log(output);
```

### 示例：使用内置工具

<Note type="warning">内置工具目前处于测试阶段。</Note>

如果你使用 `@friendliai/ai-provider`，可以通过 `tools` 选项使用 [内置工具](https://friendli.ai/docs/guides/serverless_endpoints/tools/built_in_tools)。

内置工具允许模型使用工具生成更好的答案。例如，`web:search` 工具可以为当前问题提供最新的答案。

```ts highlight="1,5,6,7"
import { friendli } from '@friendliai/ai-provider';
import { streamText } from 'ai';

const result = streamText({
  model: friendli('meta-llama-3.3-70b-instruct', {
    tools: [{ type: 'web:search' }, { type: 'math:calculator' }],
  }),
  prompt:
    'Find the current USD to CAD exchange rate and calculate how much $5,000 USD would be in Canadian dollars.',
});

for await (const textPart of result.textStream) {
  console.log(textPart);
}
```

### 示例：使用专用端点生成文本

要通过专用端点使用自定义模型，你可以使用 `friendli` 实例并传入端点 ID，例如 `zbimjgovmlcb`

```ts
import { friendli } from '@friendliai/ai-provider';
import { generateText } from 'ai';

const { text } = await generateText({
  model: friendli('YOUR_ENDPOINT_ID'),
  prompt: 'What is the meaning of life?',
});

console.log(text);
```

你可以使用以下代码强制请求发送到专用端点。默认情况下，它们是自动检测的。

```ts highlight="5,6,7"
import { friendli } from '@friendliai/ai-provider';
import { generateText } from 'ai';

const { text } = await generateText({
  model: friendli("YOUR_ENDPOINT_ID", {
    endpoint: "dedicated",
  });
  prompt: 'What is the meaning of life?',
});

console.log(text);
```

FriendliAI 语言模型也可用于 `streamText` 函数，并支持通过 [`Output`](/docs/reference/ai-sdk-core/output) 进行结构化数据生成（请参阅 [AI SDK Core](/docs/ai-sdk-core)）。

### 模型能力

| 模型                           | 图像输入 | 对象生成 | 工具使用 | 工具流式传输 |
| ----------------------------- | ----------- | ----------------- | ---------- | -------------- |
| `deepseek-r1`                 | <Cross />   | <Check />         | <Cross />  | <Cross />      |
| `meta-llama-3.3-70b-instruct` | <Cross />   | <Check />         | <Check />  | <Check />      |
| `meta-llama-3.1-8b-instruct`  | <Cross />   | <Check />         | <Check />  | <Check />      |

<Note>
  要访问[更多模型](https://friendli.ai/models)，请访问 [Friendli Dedicated Endpoints 文档](https://friendli.ai/docs/guides/dedicated_endpoints/quickstart) 以部署你的自定义模型。
</Note>

### OpenAI 兼容性

你也可以使用 `@ai-sdk/openai`，因为其 API 与 OpenAI 兼容。

```ts
import { createOpenAI } from '@ai-sdk/openai';

const friendli = createOpenAI({
  baseURL: 'https://api.friendli.ai/serverless/v1',
  apiKey: process.env.FRIENDLI_TOKEN,
});
```

如果你使用专用端点：

```ts
import { createOpenAI } from '@ai-sdk/openai';

const friendli = createOpenAI({
  baseURL: 'https://api.friendli.ai/dedicated/v1',
  apiKey: process.env.FRIENDLI_TOKEN,
});
```
