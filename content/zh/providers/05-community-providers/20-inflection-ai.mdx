# AI SDK 的非官方社区提供商 - Inflection AI

<Note type="warning">
  此社区提供商尚不兼容 AI SDK 5。请等待提供商更新，或考虑使用 [AI SDK 5 兼容提供商](/providers/ai-sdk-providers)。
</Note>

[AI SDK](/docs) 的 **[非官方 Inflection AI 提供商](https://www.npmjs.com/package/inflection-ai-sdk-provider)** 包含对 [Inflection AI API](https://developers.inflection.ai/) 的语言模型支持。

## 安装

Inflection AI 提供商可在 npm 上的 [`inflection-ai-sdk-provider`](https://www.npmjs.com/package/inflection-ai-sdk-provider) 模块中找到。你可以通过以下命令安装：

```bash
npm i inflection-ai-sdk-provider
```

## 提供商实例

你可以从 `inflection-ai-sdk-provider` 导入默认提供商实例 `inflection`：

```ts
import { inflection } from 'inflection-ai-sdk-provider';
```

## 示例

```ts
import { inflection } from 'inflection-ai-sdk-provider';
import { generateText } from 'ai';

const { text } = await generateText({
  model: inflection('inflection_3_with_tools'),
  prompt: '如何快速制作鸡肉河粉？',
});
```

## 模型

支持以下模型：

- `inflection_3_pi` - "驱动我们 Pi 体验的模型，包括背景故事、情商、生产力和安全性。它在客户支持聊天机器人等场景中表现出色。"
- `inflection_3_productivity` - "针对遵循指令进行优化的模型。它更适合需要 JSON 输出或精确遵循给定指南的任务。"
- `inflection_3_with_tools` - 此模型似乎处于预览阶段，截至本 README 1.0.0 版本编写时，尚无官方描述。

| 模型                         | 文本生成 | 流式传输 | 图像输入 | 对象生成 | 工具使用 | 工具流式传输 |
| --------------------------- | --------------- | --------- | ----------- | ----------------- | ---------- | -------------- |
| `inflection_3_pi`           | ✓               | ✓         | ✗           | ✗                 | ✗          | ✗              |
| `inflection_3_productivity` | ✓               | ✓         | ✗           | ✗                 | ✗          | ✗              |
| `inflection_3_with_tools`   | ✓               | ✓         | ✗           | ✗                 | ✗          | ✗              |

目前，除文本生成和流式文本外，其他功能的 API 支持有限。如果情况发生变化，上表将更新，并且此非官方提供商将添加相应支持。
