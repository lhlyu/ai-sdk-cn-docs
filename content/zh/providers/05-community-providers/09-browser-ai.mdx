# Browser AI 模型提供商

[jakobhoeg/browser-ai](https://github.com/jakobhoeg/browser-ai) 是一个社区提供商，作为客户端浏览器内 AI 模型的 AI SDK 基础提供商。
它目前通过 JavaScript [Prompt API](https://github.com/webmachinelearning/prompt-api) 为 Chrome 和 Edge 的原生浏览器 AI 模型提供模型提供商，同时还为使用 [🤗 Transformers.js](https://github.com/huggingface/transformers.js) 和 [WebLLM](https://github.com/mlc-ai/web-llm) 的开源浏览器内模型提供模型提供商。

<Note>我们同时支持 AI SDK 的 v5 和 v6 版本。</Note>

### 安装

`@browser-ai/core`（原名 `@built-in-ai`）包是 Chrome 和 Edge 浏览器内置 AI 模型的 AI SDK 提供商。你可以通过以下命令安装：

<InstallPackages packages="@browser-ai/core" />

`@browser-ai/web-llm` 包是使用 WebLLM 推理引擎的流行开源模型的 AI SDK 提供商。你可以通过以下命令安装：

<InstallPackages packages="@browser-ai/web-llm" />

`@browser-ai/transformers-js` 包是使用 Transformers.js 的流行开源模型的 AI SDK 提供商。你可以通过以下命令安装：

<InstallPackages packages="@browser-ai/transformers-js" />

## 提供商实例

### `@browser-ai/core`

你可以从 `@browser-ai/core` 导入默认提供商实例 `browserAI`：

```ts
import { browserAI } from '@browser-ai/core';

const model = browserAI();
```

你可以使用以下可选设置来自定义模型：

- **temperature** _number_

  控制模型响应的随机性。对于大多数模型，`0` 表示几乎确定性的结果，值越高表示随机性越大。

- **topK** _number_

  通过限制下一个 token 的选择来控制生成文本的多样性和连贯性。

### `@browser-ai/web-llm`

你可以从 `@browser-ai/web-llm` 导入默认提供商实例 `webLLM`：

```ts
import { webLLM } from '@browser-ai/web-llm';

const model = webLLM();
```

### `@browser-ai/transformers-js`

你可以从 `@browser-ai/transformers-js` 导入默认提供商实例 `transformersJS`：

```ts
import { transformersJS } from '@browser-ai/transformers-js';

const model = transformersJS();
```

## 语言模型

### `@browser-ai/core`

该提供商将自动在所有支持 Prompt API 的浏览器中工作，因为浏览器负责模型编排。
例如，如果你的客户端使用 Edge，它将使用 [Phi4-mini](https://learn.microsoft.com/en-us/microsoft-edge/web-platform/prompt-api#the-phi-4-mini-model)；对于 Chrome，它将使用 [Gemini Nano](https://developer.chrome.com/docs/ai/prompt-api#model_download)。

### `@browser-ai/web-llm`

该提供商允许使用大量流行的开源模型，如 Llama3 和 Qwen3。要查看完整列表，请参考官方 [WebLLM 文档](https://github.com/mlc-ai/web-llm)。

### `@browser-ai/transformers-js`

该提供商允许使用 Transformers.js 库从 Huggingface 获取大量流行的开源模型。

### 使用示例

#### `@browser-ai/core`

```ts
import { streamText } from 'ai';
import { browserAI } from '@browser-ai/core';

const result = streamText({
  model: browserAI(), // 将默认使用特定浏览器模型
  prompt: 'Hello, how are you',
});

for await (const chunk of result.textStream) {
  console.log(chunk);
}
```

#### `@browser-ai/web-llm`

```ts
import { streamText } from 'ai';
import { webLLM } from '@browser-ai/web-llm';

const result = streamText({
  model: webLLM('Qwen3-0.6B-q0f16-MLC'),
  prompt: 'Hello, how are you',
});

for await (const chunk of result.textStream) {
  console.log(chunk);
}
```

#### `@browser-ai/transformers-js`

```ts
import { streamText } from 'ai';
import { transformersJS } from '@browser-ai/transformers-js';

const result = streamText({
  model: transformersJS('HuggingFaceTB/SmolLM2-360M-Instruct'),
  prompt: 'Hello, how are you',
});

for await (const chunk of result.textStream) {
  console.log(chunk);
}
```

更多示例和 API 参考，请查看[文档](https://www.browser-ai.dev/)。
