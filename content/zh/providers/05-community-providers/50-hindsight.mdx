# Hindsight

[Hindsight](https://hindsight.vectorize.io) 是一个面向 AI 智能体的持久记忆服务。[`@vectorize-io/hindsight-ai-sdk`](https://www.npmjs.com/package/@vectorize-io/hindsight-ai-sdk) 包提供了五个与 AI SDK 兼容的工具，让你的智能体能够在对话中拥有长期记忆。

功能包括：

- 五个记忆工具：`retain`、`recall`、`reflect`、`getMentalModel` 和 `getDocument`
- 与 `generateText`、`streamText` 和 `ToolLoopAgent` 兼容
- 在工具创建时配置基础设施选项（预算、标签、异步模式）——语义选择留给模型
- 通过 `bankId` 实现多用户记忆隔离
- 完整的 TypeScript 支持

## 设置

Hindsight 可以通过 Docker 在本地运行，也可以作为云服务使用。

### 自托管（Docker）

```bash
export OPENAI_API_KEY=your-key
docker run --rm -it -p 8888:8888 -p 9999:9999 \
  -e HINDSIGHT_API_LLM_API_KEY=$OPENAI_API_KEY \
  -v $HOME/.hindsight-docker:/home/hindsight/.pg0 \
  ghcr.io/vectorize-io/hindsight:latest
```

API 将在 `http://localhost:8888` 可用，UI 在 `http://localhost:9999` 可用。

### 云服务

从 [Hindsight 仪表盘](https://ui.hindsight.vectorize.io/signup) 注册并获取你的 API URL。

## 创建工具

初始化一个 `HindsightClient`，并将其与一个标识记忆存储的 `bankId`（通常是用户 ID）一起传递给 `createHindsightTools`：

```ts
import { HindsightClient } from '@vectorize-io/hindsight-client';
import { createHindsightTools } from '@vectorize-io/hindsight-ai-sdk';

const client = new HindsightClient({ baseUrl: process.env.HINDSIGHT_API_URL });

const tools = createHindsightTools({
  client,
  bankId: 'user-123',
});
```

## 基本用法

### generateText

```ts
import { HindsightClient } from '@vectorize-io/hindsight-client';
import { createHindsightTools } from '@vectorize-io/hindsight-ai-sdk';
import { generateText, isStepCount } from 'ai';
import { openai } from '@ai-sdk/openai';

const client = new HindsightClient({ baseUrl: process.env.HINDSIGHT_API_URL });
const tools = createHindsightTools({ client, bankId: 'user-123' });

const { text } = await generateText({
  model: openai('gpt-4o'),
  tools,
  stopWhen: isStepCount(5),
  system: '你是一个拥有长期记忆的得力助手。',
  prompt: '记住我偏好深色模式和大字体。',
});
```

### ToolLoopAgent

```ts
import { ToolLoopAgent } from 'ai';
import { openai } from '@ai-sdk/openai';
import { HindsightClient } from '@vectorize-io/hindsight-client';
import { createHindsightTools } from '@vectorize-io/hindsight-ai-sdk';

const client = new HindsightClient({ baseUrl: process.env.HINDSIGHT_API_URL });

const agent = new ToolLoopAgent({
  model: openai('gpt-4o'),
  tools: createHindsightTools({ client, bankId: 'user-123' }),
  instructions: '你是一个拥有长期记忆的得力助手。',
});

const result = await agent.generate({
  prompt: '记住我最喜欢的编辑器是 Neovim',
});
```

## 多用户记忆

在多用户应用中，在你的请求处理器内部创建工具，以便每个请求使用已认证用户的正确 `bankId`：

```ts
// app/api/chat/route.ts
import {
  createUIMessageStreamResponse,
  streamText,
  isStepCount,
  convertToModelMessages,
  toUIMessageStream,
} from 'ai';
import { openai } from '@ai-sdk/openai';
import { HindsightClient } from '@vectorize-io/hindsight-client';
import { createHindsightTools } from '@vectorize-io/hindsight-ai-sdk';

const hindsightClient = new HindsightClient({
  baseUrl: process.env.HINDSIGHT_API_URL,
});

export async function POST(req: Request) {
  const { messages, userId } = await req.json();

  const tools = createHindsightTools({
    client: hindsightClient,
    bankId: userId,
  });

  const result = streamText({
    model: openai('gpt-4o'),
    tools,
    stopWhen: isStepCount(5),
    system: '你是一个拥有长期记忆的得力助手。',
    messages: await convertToModelMessages(messages),
  });

  return createUIMessageStreamResponse({
    stream: toUIMessageStream({ stream: result.stream }),
  });
}
```

`HindsightClient` 实例是共享的（在模块级别创建一次），而 `createHindsightTools` 在每个请求中使用当前用户的 ID 调用。

## 配置

基础设施选项在工具创建时配置，让应用控制成本、标签和性能，同时将语义选择（记住什么、搜索什么）留给模型。

```ts
const tools = createHindsightTools({
  client,
  bankId: userId,
  retain: {
    async: true,
    tags: ['env:prod', 'app:support'],
    metadata: { version: '2.0' },
  },
  recall: {
    budget: 'high',
    types: ['experience', 'world'],
    maxTokens: 2048,
    includeEntities: true,
  },
  reflect: {
    budget: 'mid',
  },
});
```

### `retain` 选项

| 参数          | 类型                     | 默认值    | 描述                     |
| ------------- | ------------------------ | --------- | ------------------------ |
| `async`       | `boolean`                | `false`   | 即发即弃的摄取模式       |
| `tags`        | `string[]`               | —         | 应用于所有保留记忆的标签 |
| `metadata`    | `Record<string, string>` | —         | 应用于所有保留记忆的元数据 |
| `description` | `string`                 | 内置      | 覆盖默认工具描述         |

### `recall` 选项

| 参数               | 类型                                           | 默认值       | 描述                         |
| ------------------ | ---------------------------------------------- | ------------ | ---------------------------- |
| `budget`           | `'low' \| 'mid' \| 'high'`                     | `'mid'`      | 检索深度与延迟的权衡         |
| `types`            | `('world' \| 'experience' \| 'observation')[]` | 所有类型     | 将结果限制为指定的事实类型   |
| `maxTokens`        | `number`                                       | API 默认值   | 返回的最大总 token 数        |
| `includeEntities`  | `boolean`                                      | `false`      | 在结果中包含实体观察         |
| `includeChunks`    | `boolean`                                      | `false`      | 在结果中包含原始源块         |
| `description`      | `string`                                       | 内置         | 覆盖默认工具描述             |

### `reflect` 选项

| 参数          | 类型                       | 默认值       | 描述                         |
| ------------- | -------------------------- | ------------ | ---------------------------- |
| `budget`      | `'low' \| 'mid' \| 'high'` | `'mid'`      | 综合深度与延迟的权衡         |
| `maxTokens`   | `number`                   | API 默认值   | 最大响应 token 数            |
| `description` | `string`                   | 内置         | 覆盖默认工具描述             |

## 记忆工具

| 工具             | 描述                               |
| ---------------- | ---------------------------------- |
| `retain`         | 将信息存储在记忆库中               |
| `recall`         | 使用查询搜索记忆                   |
| `reflect`        | 从存储的记忆中综合洞察             |
| `getMentalModel` | 检索结构化的知识模型               |
| `getDocument`    | 通过标识符检索存储的文档           |
