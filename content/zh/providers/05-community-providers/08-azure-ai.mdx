# 适用于 AI SDK 的 Azure 自定义提供商

**[Quail-AI/azure-ai-provider](https://github.com/QuailAI/azure-ai-provider)** 支持与 Azure 托管的语言模型进行非官方集成，这些模型使用 Azure 原生 API 而非标准的 OpenAI API 格式。

## 语言模型

此提供商可与 Azure AI Foundry 中任何兼容 Azure-Rest AI-inference API 的模型配合使用。

### 已测试的模型：

- DeepSeek-R1
- Llama 3.3-70B Instruct
- Cohere-command-r-08-2024

## 设置

### 安装

通过 npm 安装此提供商：

```bash
npm i @quail-ai/azure-ai-provider
```

## 提供商实例

创建 Azure AI 资源并设置你的端点 URL 和 API 密钥。将以下内容添加到你的 `.env` 文件中：

```bash
AZURE_API_ENDPOINT=https://<your-resource>.services.ai.azure.com/models
AZURE_API_KEY=<your-api-key>
```

从包中导入 `createAzure` 以创建你的提供商实例：

```ts
import { createAzure } from '@quail-ai/azure-ai-provider';

const azure = createAzure({
  endpoint: process.env.AZURE_API_ENDPOINT,
  apiKey: process.env.AZURE_API_KEY,
});
```

## 基本用法

使用 Azure 自定义提供商生成文本：

```ts
import { generateText } from 'ai';

const { text } = await generateText({
  model: azure('your-deployment-name'),
  prompt: 'Write a story about a robot.',
});
```
