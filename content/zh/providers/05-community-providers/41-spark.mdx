# Spark 提供商

<Note type="warning">
  此社区提供商尚不兼容 AI SDK 5。请等待提供商更新，或考虑使用 [AI SDK 5 兼容提供商](/providers/ai-sdk-providers)。
</Note>

**[Spark 提供商](https://github.com/klren0312/spark-ai-provider)** 包含对 Spark API 的语言模型支持，使您能够访问 lite、generalv3、pro-128k、generalv3.5、max-32k 和 4.0Ultra 等模型。

## 安装

Spark 提供商位于 `spark-ai-provider` 模块中。您可以通过以下命令安装：

```bash
npm i spark-ai-provider
```

## 提供商实例

您可以从 `spark-ai-provider` 导入 `createSparkProvider` 来创建提供商实例：

```ts
import { createSparkProvider } from 'spark-ai-provider';
```

## 示例

```ts
import { createSparkProvider } from './index.mjs';
import { generateText } from 'ai';
const spark = createSparkProvider({
  apiKey: '',
});
const { text } = await generateText({
  model: spark('lite'),
  prompt: '为4人写一份素食千层面食谱。',
});
```
