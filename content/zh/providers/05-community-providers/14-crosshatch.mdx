# Crosshatch 提供商

<Note type="warning">
  该社区提供商尚未兼容 AI SDK 5。请等待提供商更新，或考虑使用[兼容 AI SDK 5 的提供商](/providers/ai-sdk-providers)。
</Note>

[Crosshatch](https://crosshatch.io) 提供商支持从热门语言模型进行安全推理，并对用户共享的数据进行权限化访问，从而提供结合完整用户上下文的个性化响应。

它创建的语言模型对象可用于 `generateText` 和 `streamText` 函数，并支持通过 [`Output`](/docs/reference/ai-sdk-core/output) 生成结构化数据。

## 设置

Crosshatch 提供商可通过 `@crosshatch/ai-provider` 模块获取。
你可以使用以下命令安装：

<InstallPackages packages="@crosshatch/ai-provider" />

[Crosshatch](https://crosshatch.io/) 提供商支持其所有可用模型，例如 OpenAI 的 GPT 和 Anthropic 的 Claude。该提供商还支持用于控制 Crosshatch 自定义数据集成行为的查询接口。该提供商封装了现有的底层提供商（[@ai-sdk/openai](/providers/ai-sdk-providers/openai)、[@ai-sdk/anthropic](/providers/ai-sdk-providers/openai)。

### 凭据

Crosshatch 提供商通过用户专属令牌进行身份验证，从而实现对个性化推理的权限化访问。

你可以从 [Crosshatch 开发者仪表盘](https://platform.crosshatch.io/)获取合成用户令牌和测试用户令牌。

生产用户令牌通过 [Link SDK](https://www.npmjs.com/package/@crosshatch/link) 使用你的 Crosshatch 开发者客户端 ID 进行配置和访问。

## 提供商实例

要创建 Crosshatch 提供商实例，请使用 `createCrosshatch` 函数：

```ts
import createCrosshatch from '@crosshatch/ai-provider';
```

## 语言模型

你可以使用提供商实例创建 [Crosshatch 模型](https://docs.crosshatch.io/endpoints/ai#supported-model-providers)。

```ts
import { createCrosshatch } from '@crosshatch/ai-provider';
const crosshatch = createCrosshatch();
```

要创建模型实例，请调用提供商实例，并在第一个参数中指定你想使用的模型。在第二个参数中，指定用户身份验证令牌、所需的上下文以及模型参数。
你可以使用 Crosshatch 基于权限化的用户上下文和你喜欢的语言模型来生成文本。

### 示例：结合上下文生成文本

此示例使用 `gpt-4o-mini` 生成文本。

```ts
import { generateText } from 'ai';
import createCrosshatch from '@crosshatch/ai-provider';
const crosshatch = createCrosshatch();

const { text } = await generateText({
  model: crosshatch.languageModel('gpt-4o-mini', {
    token: 'YOUR_ACCESS_TOKEN',
    replace: {
      restaurants: {
        select: ['entity_name', 'entity_city', 'entity_region'],
        from: 'personalTimeline',
        where: [
          { field: 'event', op: '=', value: 'confirmed' },
          { field: 'entity_subtype2', op: '=', value: 'RESTAURANTS' },
        ],
        groupby: ['entity_name', 'entity_city', 'entity_region'],
        orderby: 'count DESC',
        limit: 5,
      },
    },
  }),
  system: `The user recently ate at these restaurants: {restaurants}`,
  messages: [{ role: 'user', content: 'Where should I stay in Paris?' }],
});
```

### 示例：基于上下文推荐项目

使用 crosshatch 根据用户最近的购买记录对项目重新排序。

```ts
import { streamText, Output, jsonSchema } from 'ai';
import createCrosshatch from '@crosshatch/ai-provider';
const crosshatch = createCrosshatch();

const itemSummaries: { itemId: string }[] = [
  /* your items */
];
const ids = (itemSummaries?.map(({ itemId }) => itemId) ?? []) as string[];

const { elementStream } = streamText({
  output: Output.array({
    element: jsonSchema<{ id: string; reason: string }>({
      type: 'object',
      properties: {
        id: { type: 'string', enum: ids },
        reason: { type: 'string', description: 'Explain your ranking.' },
      },
    }),
  }),
  model: crosshatch.languageModel('gpt-4o-mini', {
    token: 'YOUR_ACCESS_TOKEN',
    replace: {
      orders: {
        select: [
          'originalTimestamp',
          'entity_name',
          'order_total',
          'order_summary',
        ],
        from: 'personalTimeline',
        where: [{ field: 'event', op: '=', value: 'purchased' }],
        orderBy: [{ field: 'originalTimestamp', dir: 'desc' }],
        limit: 5,
      },
    },
  }),
  system: `Rerank the following items based on alignment with users recent purchases {orders}`,
  messages: [
    {
      role: 'user',
      content: `Here's a list of items: ${JSON.stringify(itemSummaries)}`,
    },
  ],
});
```
