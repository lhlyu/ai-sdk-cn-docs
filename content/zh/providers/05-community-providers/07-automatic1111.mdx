# Automatic1111

[AUTOMATIC1111](https://github.com/AUTOMATIC1111/stable-diffusion-webui) 是一个流行的 Stable Diffusion 网页界面，提供全面的图像生成功能。用于 AI SDK 的 [Automatic1111 提供商](https://github.com/Ponesicek/automatic1111-provider) 能够与本地托管的 AUTOMATIC1111 实例无缝集成，并具有以下独特优势：

- **本地控制**：使用本地 Stable Diffusion 模型完全控制图像生成
- **无 API 费用**：无限生成图像，无需按请求付费
- **模型灵活性**：使用任何 Stable Diffusion 检查点
- **隐私保护**：所有生成过程均在本地硬件上完成
- **社区模型**：从 Civitai 和 HuggingFace 访问数千个社区创建的模型

在 [AUTOMATIC1111 文档](https://github.com/AUTOMATIC1111/stable-diffusion-webui) 中了解更多关于 AUTOMATIC1111 的功能。

## 设置

你需要运行已启用 `--api` 标志的 AUTOMATIC1111。使用以下命令启动你的 AUTOMATIC1111 实例：

```bash
# Windows
./webui.bat --api

# Linux/Mac
./webui.sh --api
```

Automatic1111 提供商位于 `automatic1111-provider` 模块中。你可以通过以下方式安装：

```bash
# pnpm
pnpm add automatic1111-provider

# npm
npm install automatic1111-provider

# yarn
npm install automatic1111-provider
```

## 提供商实例

要创建 Automatic1111 提供商实例，请使用 `createAutomatic1111` 函数：

```typescript
import { createAutomatic1111 } from 'automatic1111-provider';

const automatic1111 = createAutomatic1111({
  baseURL: 'http://127.0.0.1:7860', // 你的 AUTOMATIC1111 实例
});
```

## 图像模型

Automatic1111 提供商通过 `image()` 方法支持图像生成：

```typescript
// 基本图像生成
const imageModel = automatic1111.image('v1-5-pruned-emaonly');

// 使用自定义模型
const sdxlModel = automatic1111.image('sd_xl_base_1.0');
```

## 示例

### 基本图像生成

```typescript
import { automatic1111 } from 'automatic1111-provider';
import { generateImage } from 'ai';

const { images } = await generateImage({
  model: automatic1111.image('v1-5-pruned-emaonly'),
  prompt: 'A beautiful sunset over mountains',
  size: '512x512',
});
```

### 高级配置

```typescript
const { images } = await generateImage({
  model: automatic1111.image('realistic-vision-v4'),
  prompt: 'Portrait of a wise old wizard with a long beard',
  n: 2,
  seed: 12345,
  providerOptions: {
    automatic1111: {
      negative_prompt: 'blurry, ugly, deformed, low quality',
      steps: 40,
      cfg_scale: 8.5,
      sampler_name: 'DPM++ SDE Karras',
      styles: ['photorealistic', 'detailed'],
      check_model_exists: true,
    },
  },
});
```

## 提供商选项

Automatic1111 提供商支持以下选项来自定义图像生成：

### 可用选项

| 选项                   | 类型       | 默认值       | 描述                              |
| ---------------------- | ---------- | ------------ | --------------------------------- |
| `negative_prompt`      | `string`   | `undefined`  | 你不希望在图像中出现的内容        |
| `steps`                | `number`   | `20`         | 采样步数                          |
| `cfg_scale`            | `number`   | `7`          | CFG（无分类器引导）尺度           |
| `sampler_name`         | `string`   | `"Euler a"`  | 采样方法                          |
| `denoising_strength`   | `number`   | `undefined`  | img2img 的去噪强度（0.0-1.0）     |
| `styles`               | `string[]` | `undefined`  | 应用预定义样式                    |
| `check_model_exists`   | `boolean`  | `false`      | 在生成前验证模型是否存在          |

## 模型管理

提供商会自动检测你的 AUTOMATIC1111 实例中的可用模型。要使用模型：

1. 将你的 `.safetensors` 或 `.ckpt` 模型文件放入 `models/Stable-diffusion/` 文件夹
2. 重启 AUTOMATIC1111 或在网页界面中刷新模型列表
3. 在提供商中使用确切的模型名称（不带文件扩展名）
