# AnthropicVertex 提供商

<Note>
  Anthropic for Google Vertex 也受 [AI SDK Google Vertex 提供商](/providers/ai-sdk-providers/google-vertex) 支持。
</Note>

<Note type="warning">
  此社区提供商尚不兼容 AI SDK 5。请等待提供商更新，或考虑使用 [AI SDK 5 兼容的提供商](/providers/ai-sdk-providers)。
</Note>

[nalaso/anthropic-vertex-ai](https://github.com/nalaso/anthropic-vertex-ai) 是一个社区提供商，它通过 Vertex AI 使用 Anthropic 模型，为 AI SDK 提供语言模型支持。

## 设置

AnthropicVertex 提供商可在 `anthropic-vertex-ai` 模块中获得。您可以通过以下命令安装：

<InstallPackages packages="anthropic-vertex-ai" />

## 提供商实例

您可以从 `anthropic-vertex-ai` 导入默认提供商实例 `anthropicVertex`：

```ts
import { anthropicVertex } from 'anthropic-vertex-ai';
```

如果您需要自定义设置，可以从 `anthropic-vertex-ai` 导入 `createAnthropicVertex`，并使用您的设置创建提供商实例：

```ts
import { createAnthropicVertex } from 'anthropic-vertex-ai';

const anthropicVertex = createAnthropicVertex({
  region: 'us-central1',
  projectId: 'your-project-id',
  // 其他选项
});
```

您可以使用以下可选设置来自定义 AnthropicVertex 提供商实例：

- **region** _string_

  您的 Google Vertex 区域。默认为 `GOOGLE_VERTEX_REGION` 环境变量。

- **projectId** _string_

  您的 Google Vertex 项目 ID。默认为 `GOOGLE_VERTEX_PROJECT_ID` 环境变量。

- **googleAuth** _GoogleAuth_

  可选。由 google-auth-library 提供的身份验证选项。

- **baseURL** _string_

  为 API 调用使用不同的 URL 前缀，例如使用代理服务器。
  默认前缀为 `https://{region}-aiplatform.googleapis.com/v1`。

- **headers** _Record&lt;string,string&gt;_

  要包含在请求中的自定义标头。

- **fetch** _(input: RequestInfo, init?: RequestInit) => Promise&lt;Response&gt;_

  自定义 fetch 实现。您可以将其用作中间件来拦截请求，或提供自定义 fetch 实现，例如用于测试。

## 语言模型

您可以使用提供商实例创建通过 Vertex AI 调用 Anthropic API 的模型。
第一个参数是模型 ID，例如 `claude-3-sonnet@20240229`：

```ts
const model = anthropicVertex('claude-3-sonnet@20240229');
```

### 示例：生成文本

您可以使用 AnthropicVertex 语言模型通过 `generateText` 函数生成文本：

```ts
import { anthropicVertex } from 'anthropic-vertex-ai';
import { generateText } from 'ai';

const { text } = await generateText({
  model: anthropicVertex('claude-3-sonnet@20240229'),
  prompt: '写一份供 4 人食用的素食千层面食谱。',
});
```

AnthropicVertex 语言模型也可用于 `streamText` 函数，并支持通过 [`Output`](/docs/reference/ai-sdk-core/output) 生成结构化数据（有关更多信息，请参阅 [AI SDK Core](/docs/ai-sdk-core)）。

## 环境变量

要使用 AnthropicVertex 提供商，您需要设置以下环境变量：

- `GOOGLE_VERTEX_REGION`：您的 Google Vertex 区域（例如 'us-central1'）
- `GOOGLE_VERTEX_PROJECT_ID`：您的 Google Cloud 项目 ID

请确保在您的环境中或项目根目录的 `.env` 文件中设置这些变量。

## 身份验证

AnthropicVertex 提供商使用 Google Cloud 身份验证。请确保您已正确设置 Google Cloud 凭据。您可以使用服务账号密钥文件或默认应用凭据。

有关设置身份验证的更多信息，请参阅 [Google Cloud 身份验证指南](https://cloud.google.com/docs/authentication)。
