# Cloudflare Workers AI

[workers-ai-provider](https://github.com/cloudflare/ai/tree/main/packages/workers-ai-provider) 是一个社区提供商，允许你在 AI SDK 中使用 Cloudflare 的 [Workers AI](https://ai.cloudflare.com/) 模型。

## 设置

Cloudflare Workers AI 提供商位于 `workers-ai-provider` 模块中。你可以通过以下方式安装：

<Tabs items={['pnpm', 'npm', 'yarn', 'bun']}>
  <Tab>
    <Snippet text="pnpm add workers-ai-provider" />
  </Tab>
  <Tab>
    <Snippet text="npm install workers-ai-provider" />
  </Tab>
  <Tab>
    <Snippet text="yarn add workers-ai-provider" />
  </Tab>

  <Tab>
    <Snippet text="bun add workers-ai-provider" dark />
  </Tab>
</Tabs>

然后，在你的 Cloudflare Workers 项目 `wrangler.toml` 文件中设置 AI 绑定：

```bash filename="wrangler.toml"
[ai]
binding = "AI"
```

## 提供商实例

要创建 `workersai` 提供商实例，请使用 `createWorkersAI` 函数，并将 AI 绑定作为选项传入：

```typescript
import { createWorkersAI } from 'workers-ai-provider';

const workersai = createWorkersAI({ binding: env.AI });
```

## 语言模型

要创建模型实例，请调用提供商实例，并将要使用的模型指定为第一个参数。你还可以在第二个参数中传入其他设置：

```typescript highlight="4-7"
import { createWorkersAI } from 'workers-ai-provider';

const workersai = createWorkersAI({ binding: env.AI });
const model = workersai('@cf/meta/llama-3.1-8b-instruct', {
  // 其他设置
  safePrompt: true,
});
```

你可以使用以下可选设置进行自定义：

- **safePrompt** _布尔值_

  是否在所有对话前注入安全提示。默认为 `false`。

### 示例

你可以使用 Cloudflare Workers AI 语言模型通过 **`generateText`** 或 **`streamText`** 函数生成文本：

#### `generateText`

```typescript
import { createWorkersAI } from 'workers-ai-provider';
import { generateText } from 'ai';

type Env = {
  AI: Ai;
};

export default {
  async fetch(_: Request, env: Env) {
    const workersai = createWorkersAI({ binding: env.AI });
    const result = await generateText({
      model: workersai('@cf/meta/llama-2-7b-chat-int8'),
      prompt: '写一篇关于 hello world 的 50 字短文。',
    });

    return new Response(result.text);
  },
};
```

#### `streamText`

```typescript
import { createWorkersAI } from 'workers-ai-provider';
import { createTextStreamResponse, streamText, toTextStream } from 'ai';

type Env = {
  AI: Ai;
};

export default {
  async fetch(_: Request, env: Env) {
    const workersai = createWorkersAI({ binding: env.AI });
    const result = streamText({
      model: workersai('@cf/meta/llama-2-7b-chat-int8'),
      prompt: '写一篇关于 hello world 的 50 字短文。',
    });

    return createTextStreamResponse({
      stream: toTextStream({ stream: result.stream }),
      headers: {
        // 添加这些头部以确保响应被分块并流式传输
        'Content-Type': 'text/x-unknown',
        'content-encoding': 'identity',
        'transfer-encoding': 'chunked',
      },
    });
  },
};
```

#### 结构化输出

一些 Cloudflare Workers AI 语言模型还支持通过 [`Output`](/docs/reference/ai-sdk-core/output) 生成结构化数据：

```typescript
import { createWorkersAI } from 'workers-ai-provider';
import { generateText, Output } from 'ai';
import { z } from 'zod';

type Env = {
  AI: Ai;
};

export default {
  async fetch(_: Request, env: Env) {
    const workersai = createWorkersAI({ binding: env.AI });
    const result = await generateText({
      model: workersai('@cf/meta/llama-3.1-8b-instruct'),
      prompt: '生成一份千层面食谱',
      output: Output.object({
        schema: z.object({
          recipe: z.object({
            ingredients: z.array(z.string()),
            description: z.string(),
          }),
        }),
      }),
    });

    return Response.json(result.output);
  },
};
```
