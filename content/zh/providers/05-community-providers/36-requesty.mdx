# Requesty

[Requesty](https://requesty.ai/) 是一个统一的 LLM 网关，提供对来自 OpenAI、Anthropic、Google、Mistral、AWS 等领先提供商的 300 多个大语言模型的访问。AI SDK 的 Requesty 提供商能够与所有这些模型无缝集成，同时提供企业级优势：

- **通用模型访问**：一个 API 密钥即可访问来自多个提供商的 300+ 模型
- **99.99% 正常运行时间 SLA**：具有智能故障转移和负载均衡的企业级基础设施
- **成本优化**：即用即付定价，配合智能路由和提示词缓存，可降低高达 80% 的成本
- **高级安全性**：提示词注入检测、端到端加密和 GDPR 合规
- **实时可观测性**：内置监控、追踪和分析
- **智能路由**：自动故障转移和基于性能的路由
- **推理支持**：具有可配置努力级别的高级推理能力

在 [Requesty 文档](https://docs.requesty.ai) 中了解更多关于 Requesty 功能的信息。

## API 密钥设置

出于安全考虑，你应该将 API 密钥设置为名为 `REQUESTY_API_KEY` 的环境变量：

```bash
# Linux/Mac
export REQUESTY_API_KEY=your_api_key_here

# Windows Command Prompt
set REQUESTY_API_KEY=your_api_key_here

# Windows PowerShell
$env:REQUESTY_API_KEY="your_api_key_here"
```

你可以从 [Requesty 仪表板](https://app.requesty.ai/api-keys) 获取你的 Requesty API 密钥。

## 提供商实例

你可以从 `@requesty/ai-sdk` 导入默认的提供商实例 `requesty`：

```typescript
import { requesty } from '@requesty/ai-sdk';
```

或者，你可以使用 `createRequesty` 创建自定义提供商实例：

```typescript
import { createRequesty } from '@requesty/ai-sdk';

const customRequesty = createRequesty({
  apiKey: 'YOUR_REQUESTY_API_KEY',
});
```

## 语言模型

Requesty 通过简单统一的接口支持聊天和补全模型：

```typescript
// 使用默认提供商实例
const model = requesty('openai/gpt-4o');

// 使用自定义提供商实例
const customModel = customRequesty('anthropic/claude-3.5-sonnet');
```

你可以在 [Requesty 模型文档](https://requesty.ai/models) 中找到可用模型的完整列表。

## 示例

以下是使用 Requesty 与 AI SDK 的示例：

### `generateText`

```javascript
import { requesty } from '@requesty/ai-sdk';
import { generateText } from 'ai';

const { text } = await generateText({
  model: requesty('openai/gpt-4o'),
  prompt: '写一份供 4 人食用的素食千层面食谱。',
});

console.log(text);
```

### `streamText`

```javascript
import { requesty } from '@requesty/ai-sdk';
import { streamText } from 'ai';

const result = streamText({
  model: requesty('anthropic/claude-3.5-sonnet'),
  prompt: '写一个关于 AI 的短篇故事。',
});

for await (const chunk of result.textStream) {
  console.log(chunk);
}
```

### 结构化输出

```javascript
import { requesty } from '@requesty/ai-sdk';
import { generateText, Output } from 'ai';
import { z } from 'zod';

const { output } = await generateText({
  model: requesty('openai/gpt-4o'),
  output: Output.object({
    schema: z.object({
      recipe: z.object({
        name: z.string(),
        ingredients: z.array(z.string()),
        steps: z.array(z.string()),
      }),
    }),
  }),
  prompt: '生成一份巧克力曲奇饼干的食谱。',
});

console.log(output.recipe);
```

## 高级功能

### 推理支持

Requesty 为支持的模型提供具有可配置努力级别的高级推理能力：

```javascript
import { createRequesty } from '@requesty/ai-sdk';
import { generateText } from 'ai';

const requesty = createRequesty({ apiKey: process.env.REQUESTY_API_KEY });

// 使用推理努力
const { text, reasoning } = await generateText({
  model: requesty('openai/o3-mini', {
    reasoningEffort: 'medium',
  }),
  prompt: '逐步解决这个复杂问题...',
});

console.log('响应:', text);
console.log('推理:', reasoning);
```

#### 推理努力值

- `'low'` - 最低推理努力
- `'medium'` - 中等推理努力
- `'high'` - 高推理努力
- `'max'` - 最大推理努力（Requesty 特有）
- 预算字符串（例如 `"10000"`）- 推理的特定令牌预算

#### 支持的推理模型

- **OpenAI**：`openai/o3-mini`、`openai/o3`
- **Anthropic**：`anthropic/claude-sonnet-4-0`，其他 Claude 推理模型
- **Deepseek**：所有 Deepseek 推理模型（自动推理）

### 自定义配置

使用自定义设置配置 Requesty：

```javascript
import { createRequesty } from '@requesty/ai-sdk';

const requesty = createRequesty({
  apiKey: process.env.REQUESTY_API_KEY,
  baseURL: 'https://router.requesty.ai/v1',
  headers: {
    'Custom-Header': 'custom-value',
  },
  extraBody: {
    custom_field: 'value',
  },
});
```

### 传递额外请求体参数

有三种方式可以向 Requesty 传递额外请求体参数：

#### 1. 通过提供商选项

```javascript
await streamText({
  model: requesty('anthropic/claude-3.5-sonnet'),
  messages: [{ role: 'user', content: '你好' }],
  providerOptions: {
    requesty: {
      custom_field: 'value',
      reasoning_effort: 'high',
    },
  },
});
```

#### 2. 通过模型设置

```javascript
const model = requesty('anthropic/claude-3.5-sonnet', {
  extraBody: {
    custom_field: 'value',
  },
});
```

#### 3. 通过提供商工厂

```javascript
const requesty = createRequesty({
  apiKey: process.env.REQUESTY_API_KEY,
  extraBody: {
    custom_field: 'value',
  },
});
```

## 企业级功能

Requesty 提供多项企业级功能：

1. **99.99% 正常运行时间 SLA**：高级路由和故障转移机制确保你的 AI 应用在其他服务失败时仍能保持在线。

2. **智能负载均衡**：基于实时性能的路由自动选择性能最佳的提供商。

3. **成本优化**：智能路由可在保持响应质量的同时，将 API 成本降低高达 40%。

4. **高级安全性**：内置提示词注入检测、端到端加密和 GDPR 合规。

5. **实时可观测性**：对所有请求进行全面的监控、追踪和分析。

6. **地理限制**：通过可配置的地理控制遵守区域法规。

7. **模型访问控制**：对可访问的模型和提供商进行细粒度控制。
