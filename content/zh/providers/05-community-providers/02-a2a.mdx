# A2A

[dracoblue/a2a-ai-provider](https://github.com/dracoblue/a2a-ai-provider) 是一个社区提供商，支持将符合 [A2A 协议](https://a2aproject.github.io/A2A/specification/) 的智能体与 [AI SDK](https://ai-sdk.dev/) 结合使用。这使得开发者能够通过标准化的 JSON-RPC 接口在 HTTP 上流式传输、发送和接收文本、工具调用及工件。

<Note type="warning">
  `a2a-ai-provider` 包正在持续开发中。
</Note>

该提供商（通过使用官方 a2a-js SDK [@a2a-js/sdk](https://github.com/a2aproject/a2a-js)）支持：

- **流式文本响应**：通过 `sendSubscribe` 和 SSE 实现
- **文件与工件上传**：上传至 A2A 服务器
- **多模态消息**：支持文本和文件部分
- **完全符合 JSON-RPC 2.0 规范**：适用于兼容 A2A 的 LLM 智能体

了解更多关于 A2A 的信息，请访问 [A2A 项目网站](https://a2aproject.github.io/A2A/)。

## 安装

从 npm 安装 `a2a-ai-provider`：

<InstallPackages packages="a2a-ai-provider" />

## 提供商实例

为 A2A 服务器创建提供商实例：

```ts
import { a2a } from 'a2a-ai-provider';
```

## 示例

现在你可以像这样将提供商与 AI SDK 结合使用：

### `generateText`

```ts
import { a2a } from 'a2a-ai-provider';
import { generateText } from 'ai';

const result = await generateText({
  model: a2a('https://your-a2a-server.example.com'),
  prompt: '什么是爱？',
});

console.log(result.text);
```

### `streamText`

```ts
import { a2a } from 'a2a-ai-provider';
import { streamText } from 'ai';

const chatId = 'unique-chat-id'; // 每个对话使用唯一 ID，以便在 a2a 服务器中保持历史记录

const streamResult = streamText({
  model: a2a('https://your-a2a-server.example.com'),
  prompt: '什么是爱？',
  providerOptions: {
    a2a: {
      contextId: chatId,
    },
  },
});

await streamResult.consumeStream();

console.log(await streamResult.content);
```

## 功能特性

- **文本流式传输**：逐 token 流式输出 A2A 服务器的结果
- **文件上传**：在提示词中发送文件
- **工件处理**：在流式或最终结果中接收文件工件
