# Voyage AI 提供商

[patelvivekdev/voyage-ai-provider](https://github.com/patelvivekdev/voyageai-ai-provider) 是一个社区提供商，它使用 [Voyage AI](https://www.voyageai.com) 为 AI SDK 提供嵌入支持。

## 安装

Voyage 提供商位于 `voyage-ai-provider` 模块中。你可以通过以下方式安装它：

## 提供商实例

你可以从 `voyage-ai-provider` 导入默认的提供商实例 `voyage`：

```ts
import { voyage } from 'voyage-ai-provider';
```

如果你需要自定义设置，可以从 `voyage-ai-provider` 导入 `createVoyage`，并使用你的设置创建一个提供商实例：

```ts
import { createVoyage } from 'voyage-ai-provider';

const voyage = createVoyage({
  // 自定义设置
});
```

你可以使用以下可选设置来自定义 Voyage 提供商实例：

- **baseURL** _string_

  Voyage API 的基础 URL。
  默认前缀是 `https://api.voyageai.com/v1`。

- **apiKey** _string_

  通过 `Authorization` 标头发送的 API 密钥。
  默认为 `VOYAGE_API_KEY` 环境变量。

- **headers** _Record&lt;string,string&gt;_

  要包含在请求中的自定义标头。

- **fetch** _(input: RequestInfo, init?: RequestInit) => Promise&lt;Response&gt;_

  自定义 [fetch](https://developer.mozilla.org/en-US/docs/Web/API/fetch) 实现。
  默认为全局的 `fetch` 函数。
  你可以将其用作拦截请求的中间件，
  或为测试等场景提供自定义的 fetch 实现。

## 文本嵌入模型

你可以使用 `.embeddingModel()` 工厂方法创建调用 [Voyage 嵌入 API](https://docs.voyageai.com/reference/embeddings-api) 的模型。

```ts
import { voyage } from 'voyage-ai-provider';

const embeddingModel = voyage.embeddingModel('voyage-3.5-lite');
```

你可以使用 Voyage 嵌入模型通过 `embed` 或 `embedMany` 函数生成嵌入：

```ts
import { voyage } from 'voyage-ai-provider';
import { embed } from 'ai';

const { embedding } = await embed({
  model: voyage.embeddingModel('voyage-3.5-lite'),
  value: 'sunny day at the beach',
  providerOptions: {
    voyage: {
      inputType: 'document',
    },
  },
});
```

Voyage 嵌入模型支持通过 `providerOptions.voyage` 传递额外的提供商选项：

```ts
import { voyage } from 'voyage-ai-provider';
import { embed } from 'ai';

const { embedding } = await embed({
  model: voyage.embeddingModel('voyage-3.5-lite'),
  value: 'sunny day at the beach',
  providerOptions: {
    voyage: {
      inputType: 'query',
      outputDimension: 512,
    },
  },
});
```

以下 [提供商选项](https://docs.voyageai.com/reference/embeddings-api) 可用：

- **inputType** _'query' | 'document' | 'null'_

  指定传递给模型的输入类型。默认为 `'null'`。
  - `'null'`：当 `inputType` 为 `'null'` 时，嵌入模型直接将输入转换为数值向量。

  对于检索/搜索目的，建议使用 `'query'` 或 `'document'`。
  - `'query'`：输入是一个搜索查询，例如，“表示用于检索支持文档的查询：...”。
  - `'document'`：输入是要存储在向量数据库中的文档，例如，“表示用于检索的文档：...”。

- **outputDimension** _number_

  结果输出嵌入的维度数。默认为 `'null'`。
  - 例如，`voyage-code-3` 和 `voyage-3-large` 支持：2048、1024（默认）、512 和 256。
  - 请参阅 [模型文档](https://docs.voyageai.com/docs/embeddings) 了解支持的值。

- **outputDtype** _'float' | 'int8' | 'uint8' | 'binary' | 'ubinary'_

  输出嵌入的数据类型。默认为 `'float'`。
  - `'float'`：32 位浮点数（所有模型均支持）。
  - `'int8'`、`'uint8'`：8 位整数类型（`voyage-3-large`、`voyage-3.5`、`voyage-3.5-lite` 和 `voyage-code-3` 支持）。
  - `'binary'`、`'ubinary'`：位打包、量化的单比特嵌入值（`voyage-3-large`、`voyage-3.5`、`voyage-3.5-lite` 和 `voyage-code-3` 支持）。返回的列表长度是 `outputDimension` 的 1/8。`'binary'` 使用偏移二进制编码。

  有关更多详细信息，请参阅 [常见问题解答：输出数据类型](https://docs.voyageai.com/docs/faq#what-is-quantization-and-output-data-types)。

- **truncation** _boolean_

  是否截断输入文本以适合模型的上下文长度。如果未指定，默认为 true。

你可以在 [Voyage 库](https://docs.voyageai.com/docs/embeddings) 主页上找到更多模型。

## 图像嵌入

### 示例 1：将图像嵌入为单个嵌入

```ts
import { voyage, ImageEmbeddingInput } from 'voyage-ai-provider';
import { embedMany } from 'ai';

const imageModel = voyage.imageEmbeddingModel('voyage-multimodal-3');

const { embeddings } = await embedMany<ImageEmbeddingInput>({
  model: imageModel,
  values: [
    {
      image:
        'https://raw.githubusercontent.com/voyage-ai/voyage-multimodal-3/refs/heads/main/images/banana_200_x_200.jpg',
    },
    {
      image: 'data:image/jpeg;base64,/9j/4AAQSkZJRgABAQAA...',
    },
  ],
  // 或者你可以直接传递图像 URL 和 base64 字符串数组
  // values: [
  //   'https://raw.githubusercontent.com/voyage-ai/voyage-multimodal-3/refs/heads/main/images/banana_200_x_200.jpg',
  //   'data:image/jpeg;base64,/9j/4AAQSkZJRgABAQAA...',
  // ],
});
```

### 示例 2：将多张图像嵌入为单个嵌入

```ts
import { voyage, ImageEmbeddingInput } from 'voyage-ai-provider';
import { embedMany } from 'ai';

const imageModel = voyage.imageEmbeddingModel('voyage-multimodal-3');

const { embeddings } = await embedMany<ImageEmbeddingInput>({
  model: imageModel,
  values: [
    {
      image: [
        'https://raw.githubusercontent.com/voyage-ai/voyage-multimodal-3/refs/heads/main/images/banana_200_x_200.jpg',
        'data:image/jpeg;base64,/9j/4AAQSkZJRgABAQAA...',
      ],
    },
  ],
});
```

<Note>
  如果遇到图像 URL 未找到的错误，请将图像转换为 base64，并在图像数组中传递 base64 数据 URL。该值应为数据 URL 格式 `data:[mediatype];base64,<data>` 的 Base64 编码图像。支持的媒体类型：`image/png`、`image/jpeg`、`image/webp` 和 `image/gif`。
</Note>

## 多模态嵌入

### 示例 1：将多个文本和图像嵌入为单个嵌入

```ts
import { voyage, MultimodalEmbeddingInput } from 'voyage-ai-provider';
import { embedMany } from 'ai';

const multimodalModel = voyage.multimodalEmbeddingModel('voyage-multimodal-3');

const { embeddings } = await embedMany<MultimodalEmbeddingInput>({
  model: multimodalModel,
  values: [
    {
      text: ['Hello, world!', 'This is a banana'],
      image: [
        'https://raw.githubusercontent.com/voyage-ai/voyage-multimodal-3/refs/heads/main/images/banana_200_x_200.jpg',
      ],
    },
    {
      text: ['Hello, coders!', 'This is a coding test'],
      image: ['data:image/jpeg;base64,/9j/4AAQSkZJRgABAQAA...'],
    },
  ],
});
```

以下约束适用于 `values` 列表：

- 列表不能包含超过 1,000 个值。
- 每张图像的像素不能超过 1600 万，或大小不能超过 20 MB。
- 每 560 像素的图像计为一个 token，列表中的每个输入不得超过 32,000 个 token，所有输入的总 token 数不得超过 320,000。

Voyage 多模态嵌入模型支持通过 `providerOptions.voyage` 传递额外的提供商选项：

```ts
import { voyage, MultimodalEmbeddingInput } from 'voyage-ai-provider';
import { embedMany } from 'ai';

const multimodalModel = voyage.multimodalEmbeddingModel('voyage-multimodal-3');

const { embeddings } = await embedMany<MultimodalEmbeddingInput>({
  model: multimodalModel,
  values: [
    {
      text: ['Hello, world!'],
      image: ['data:image/jpeg;base64,/9j/4AAQSkZJRgABAQAA...'],
    },
  ],
  providerOptions: {
    voyage: {
      inputType: 'query',
      outputEncoding: 'base64',
      truncation: true,
    },
  },
});
```

以下提供商选项可用：

- **inputType** _'query' | 'document'_

  指定传递给模型的输入类型。默认为 `'query'`。

  当 `inputType` 指定为 `'query'` 或 `'document'` 时，Voyage 会在向量化之前自动在你的输入前添加提示，创建专为检索/搜索任务定制的向量：
  - `'query'`：添加前缀“表示用于检索支持文档的查询：”
  - `'document'`：添加前缀“表示用于检索的文档：”

- **outputEncoding** _'base64'_

  结果输出嵌入的数据编码。默认为 `null`（32 位浮点数列表）。
  - 如果为 `null`，嵌入以浮点数列表（float32）形式返回。
  - 如果为 `'base64'`，嵌入以 Base64 编码的 NumPy 数组（单精度浮点数）形式返回。

  有关更多详细信息，请参阅 [常见问题解答：输出数据类型](https://docs.voyageai.com/docs/faq#what-is-quantization-and-output-data-types)。

- **truncation** _boolean_

  是否截断输入以适合模型的上下文长度。如果未指定，默认为 `true`。

### 模型能力

| 模型                  | 上下文长度（token） | 嵌入维度 |
| --------------------- | ----------------------- | ------------------- |
| `voyage-multimodal-3` | 32,000                  | 1024                |
