# Ollama 提供商

AI SDK 通过两个社区提供商支持 [Ollama](https://ollama.com/)：

- [nordwestt/ollama-ai-provider-v2](https://github.com/nordwestt/ollama-ai-provider-v2) - 直接 HTTP API 集成
- [ai-sdk-ollama](https://github.com/jagreehal/ai-sdk-ollama) - 基于官方 Ollama JavaScript 客户端构建

两者都为 AI SDK 提供语言模型支持，但采用不同的方法和功能集。

## 选择您的提供商

AI SDK 生态系统提供多个 Ollama 提供商，每个都针对不同的用例进行了优化：

### 适用于简单文本生成

[nordwestt/ollama-ai-provider-v2](https://github.com/nordwestt/ollama-ai-provider-v2) 通过直接 HTTP API 调用提供对 Ollama 模型的直接访问，非常适合基本文本生成和快速入门。

### 适用于高级功能与工具可靠性

当您需要以下功能时，推荐使用 [`ai-sdk-ollama` by jagreehal](https://github.com/jagreehal/ai-sdk-ollama)：

- **可靠的工具调用**，保证完整响应（解决常见的空响应问题）
- **网络搜索能力**，使用 [Ollama 的新网络搜索 API](https://docs.ollama.com/web-search) 获取最新信息
- **跨环境支持**，自动检测 Node.js 和浏览器
- **高级 Ollama 功能**，如 `mirostat`、`repeat_penalty`、`num_ctx`，用于精细控制
- **增强的可靠性**，通过官方客户端内置错误处理和重试机制

关键技术优势：

- 基于官方 [`Ollama`](https://www.npmjs.com/package/ollama) JavaScript 客户端库构建
- 支持 CommonJS 和 ESM 模块格式
- 完整的 TypeScript 支持，提供类型安全的 Ollama 特定选项

两个提供商都实现了 AI SDK 规范，并提供出色的 TypeScript 支持。根据项目的复杂性和功能需求进行选择。

## 提供商实例

您可以从 `ollama-ai-provider-v2` 导入默认提供商实例 `ollama`：

```ts
import { ollama } from 'ollama-ai-provider-v2';
```

如果您需要自定义设置，可以从 `ollama-ai-provider-v2` 导入 `createOllama` 并使用您的设置创建提供商实例：

```ts
import { createOllama } from 'ollama-ai-provider-v2';

const ollama = createOllama({
  // 可选设置，例如
  baseURL: 'https://api.ollama.com',
});
```

您可以使用以下可选设置来自定义 Ollama 提供商实例：

- **baseURL** _string_

  为 API 调用使用不同的 URL 前缀，例如使用代理服务器。
  默认前缀是 `http://localhost:11434/api`。

- **headers** _Record&lt;string,string&gt;_

  要包含在请求中的自定义标头。

## 语言模型

您可以使用提供商实例创建调用 [Ollama 聊天补全 API](https://github.com/ollama/ollama/blob/main/docs/api.md#generate-a-chat-completion) 的模型。
第一个参数是模型 ID，例如 `phi3`。某些模型具有多模态能力。

```ts
const model = ollama('phi3');
```

您可以在 [Ollama 库](https://ollama.com/library) 主页上找到更多模型。

### 模型能力

此提供商能够使用混合推理模型（如 qwen3），允许在消息之间切换推理。

```ts
import { ollama } from 'ollama-ai-provider-v2';
import { generateText } from 'ai';

const { text } = await generateText({
  model: ollama('qwen3:4b'),
  providerOptions: { ollama: { think: true } },
  prompt:
    '写一份供 4 人食用的素食千层面食谱，但请认真思考一下',
});
```

## 嵌入模型

您可以使用 `.embeddingModel()` 工厂方法创建调用 [Ollama 嵌入 API](https://github.com/ollama/ollama/blob/main/docs/api.md#generate-embeddings) 的模型。

```ts
const model = ollama.embeddingModel('nomic-embed-text');

const { embeddings } = await embedMany({
  model: model,
  values: ['阳光明媚的海滩日', '城市中阴雨的午后'],
});

console.log(
  `余弦相似度：${cosineSimilarity(embeddings[0], embeddings[1])}`,
);
```
