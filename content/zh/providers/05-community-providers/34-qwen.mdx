# Qwen 提供商

<Note type="warning">
  此社区提供商尚不兼容 AI SDK 5。请等待提供商更新，或考虑使用 [兼容 AI SDK 5 的提供商](/providers/ai-sdk-providers)。
</Note>

[younis-ahmed/qwen-ai-provider](https://github.com/younis-ahmed/qwen-ai-provider) 是一个社区提供商，它使用 [Qwen](https://www.alibabacloud.com/en/solutions/generative-ai/qwen) 为 AI SDK 提供语言模型支持。

## 设置

Qwen 提供商可在 `qwen-ai-provider` 模块中获得。你可以通过以下方式安装它：

## 提供商实例

你可以从 `qwen-ai-provider` 导入默认的提供商实例 `qwen`：

```ts
import { qwen } from 'qwen-ai-provider';
```

如果你需要自定义设置，可以从 `qwen-ai-provider` 导入 `createQwen`，并使用你的设置创建提供商实例：

```ts
import { createQwen } from 'qwen-ai-provider';

const qwen = createQwen({
  // 可选设置，例如：
  // baseURL: 'https://qwen/api/v1',
});
```

你可以使用以下可选设置来自定义 Qwen 提供商实例：

- **baseURL** _string_

  为 API 调用使用不同的 URL 前缀，例如使用代理服务器。
  默认前缀为 `https://dashscope-intl.aliyuncs.com/compatible-mode/v1`。

- **apiKey** _string_

  通过 `Authorization` 标头发送的 API 密钥。
  默认为 `DASHSCOPE_API_KEY` 环境变量。

- **headers** _Record&lt;string,string&gt;_

  要包含在请求中的自定义标头。

- **fetch** _(input: RequestInfo, init?: RequestInit) => Promise&lt;Response&gt;_

  自定义 [fetch](https://developer.mozilla.org/en-US/docs/Web/API/fetch) 实现。
  默认为全局 `fetch` 函数。
  你可以将其用作中间件来拦截请求，
  或提供自定义 fetch 实现用于测试等场景。

## 语言模型

你可以使用提供商实例创建调用 [Qwen 聊天 API](https://www.alibabacloud.com/help/en/model-studio/developer-reference/use-qwen-by-calling-api) 的模型。
第一个参数是模型 ID，例如 `qwen-plus`。
某些 Qwen 聊天模型支持工具调用。

```ts
const model = qwen('qwen-plus');
```

### 示例

你可以使用 Qwen 语言模型通过 `generateText` 函数生成文本：

```ts
import { qwen } from 'qwen-ai-provider';
import { generateText } from 'ai';

const { text } = await generateText({
  model: qwen('qwen-plus'),
  prompt: '写一份供 4 人食用的素食千层面食谱。',
});
```

Qwen 语言模型也可用于 `streamText` 函数，并支持通过 [`Output`](/docs/reference/ai-sdk-core/output) 生成结构化数据（参见 [AI SDK Core](/docs/ai-sdk-core)）。

## 嵌入模型

你可以使用 `.embeddingModel()` 工厂方法创建调用 [Qwen 嵌入 API](https://www.alibabacloud.com/help/en/model-studio/getting-started/models#cff6607866tsg) 的模型。

```ts
const model = qwen.embeddingModel('text-embedding-v3');
```

### 模型能力

| 模型               | 默认维度 | 最大行数 | 每行最大 Token 数 |
| ------------------- | ------------------ | ---------------------- | ---------------------- |
| `text-embedding-v3` | 1024               | 6                      | 8,192                  |
