# MCP Sampling AI 提供商

[MCP Sampling AI 提供商](https://github.com/mcpc-tech/mcpc/tree/main/packages/mcp-sampling-ai-provider) 允许 MCP 服务器通过利用您现有的客户端订阅（如 VS Code Copilot）来使用 AI SDK 中的 AI 模型。这会将您的 MCP 服务器转变为一个能够推理和决策的智能体工具，而无需单独的 API 密钥或订阅。

该提供商通过 MCP 的 [sampling 功能](https://modelcontextprotocol.io/specification/2025-06-18/client/sampling) 将请求转发到 MCP 客户端，从而实现了 `LanguageModelV4`，具有以下独特优势：

- **服务端 AI 集成**：使 MCP 服务器能够通过 AI SDK 的标准接口直接调用语言模型
- **无需直接管理模型**：将 AI 请求转发给 MCP 客户端，无需管理多个 API 密钥
- **模型灵活性**：让 MCP 客户端根据偏好（成本、速度、智能）决定使用哪个模型
- **无缝 AI SDK 兼容性**：支持 `generateText`、`streamText`、使用 [`Output`](/docs/reference/ai-sdk-core/output) 的结构化输出以及实验性工具调用
- **客户端 Sampling 支持**：使用内置辅助函数为任何 MCP 客户端添加 sampling 能力
- **智能体工具**：将简单的 MCP 工具转变为能够推理和决策的智能体

在 [MCP 规范](https://modelcontextprotocol.io/specification/2025-06-18/client/sampling) 中了解更多关于 MCP Sampling 的信息。

## 前提条件

**警告：** 此提供商有特定要求：

1. **必须在 MCP 服务器内部运行** - 这不是一个独立的 AI SDK 提供商。它通过将请求转发到 MCP 客户端来工作。
2. **客户端必须支持 MCP Sampling** - 连接的 MCP 客户端必须实现 sampling 能力，或者您可以自行实现（请参阅下面的 [客户端 Sampling](#client-sampling-for-clients-without-native-support)）。

### 支持 Sampling 的客户端

- VS Code（含 GitHub Copilot）- 支持
- Claude Desktop - 跟踪中（[Issue #1785](https://github.com/anthropics/claude-code/issues/1785)）
- Cursor - 跟踪中（[Issue #3023](https://github.com/cursor/cursor/issues/3023)）

查看 [MCP 客户端完整列表](https://modelcontextprotocol.io/clients) 以获取更多选项。

**替代方案：** 使用 `setupClientSampling()` 为任何 MCP 客户端添加 sampling 功能（请参阅下面的示例）。

## 提供商实例

要创建 MCP Sampling 提供商实例，请使用 `createMCPSamplingProvider` 函数并传入您的 MCP 服务器实例：

```typescript
import { Server } from '@modelcontextprotocol/sdk/server/index.js';
import { createMCPSamplingProvider } from '@mcpc-tech/mcp-sampling-ai-provider';

// 创建一个具有 sampling 能力的 MCP 服务器
const server = new Server(
  { name: 'my-agent', version: '1.0.0' },
  { capabilities: { sampling: {}, tools: {} } },
);

const provider = createMCPSamplingProvider({ server });
```

### 配置

该提供商接受以下配置：

- **server** _MCP Server 实例_

  一个启用了 sampling 能力的 MCP 服务器实例。

## 语言模型

使用 `languageModel()` 方法创建语言模型实例：

```typescript
const model = provider.languageModel({
  modelPreferences: {
    hints: [{ name: 'gpt-5-mini' }],
    costPriority: 0.5,
    speedPriority: 0.8,
    intelligencePriority: 0.9,
  },
});
```

### 模型偏好

`languageModel()` 方法接受可选的模型偏好：

- **hints** _Array\<\{ name: string \}\>_

  模型名称提示数组（例如，`[{ name: "gpt-5-mini" }]`）。这些提示向 MCP 客户端建议首选模型。

- **costPriority** _number (0-1)_

  值越高越偏好成本更低的模型。默认值为 0。

- **speedPriority** _number (0-1)_

  值越高越偏好速度更快的模型。默认值为 0。

- **intelligencePriority** _number (0-1)_

  值越高越偏好能力更强的模型。默认值为 0。

有关更多详细信息，请参阅 [MCP 模型偏好](https://modelcontextprotocol.io/specification/2025-06-18/client/sampling#model-preferences)。

## 示例

### `generateText`

在 MCP 服务器工具中使用 MCP Sampling 提供商生成文本：

```typescript
import { Server } from '@modelcontextprotocol/sdk/server/index.js';
import { StdioServerTransport } from '@modelcontextprotocol/sdk/server/stdio.js';
import {
  CallToolRequestSchema,
  ListToolsRequestSchema,
} from '@modelcontextprotocol/sdk/types.js';
import { createMCPSamplingProvider } from '@mcpc-tech/mcp-sampling-ai-provider';
import { generateText } from 'ai';

// 创建具有 sampling 能力的 MCP 服务器
const server = new Server(
  { name: 'translator', version: '1.0.0' },
  { capabilities: { sampling: {}, tools: {} } },
);

// 列出可用工具
server.setRequestHandler(ListToolsRequestSchema, async () => {
  return {
    tools: [
      {
        name: 'translate',
        description: '使用 AI 将文本翻译成目标语言',
        inputSchema: {
          type: 'object',
          properties: {
            text: {
              type: 'string',
              description: '要翻译的文本',
            },
            target_lang: {
              type: 'string',
              description: '目标语言（例如 "西班牙语"、"法语"）',
            },
          },
          required: ['text', 'target_lang'],
        },
      },
    ],
  };
});

// 注册一个使用 AI 的翻译工具
server.setRequestHandler(CallToolRequestSchema, async request => {
  if (request.params.name === 'translate') {
    // 从服务器创建提供商
    const provider = createMCPSamplingProvider({ server });

    // 使用 AI SDK 翻译文本
    const { text } = await generateText({
      model: provider.languageModel({
        modelPreferences: { hints: [{ name: 'gpt-5-mini' }] },
      }),
      prompt: `翻译成 ${request.params.arguments?.target_lang}：${request.params.arguments?.text}`,
    });

    return { content: [{ type: 'text', text }] };
  }
});

// 连接并启动
const transport = new StdioServerTransport();
await server.connect(transport);
```

### `streamText`

使用 MCP Sampling 提供商流式传输文本响应：

```typescript
import { Server } from '@modelcontextprotocol/sdk/server/index.js';
import { StdioServerTransport } from '@modelcontextprotocol/sdk/server/stdio.js';
import {
  CallToolRequestSchema,
  ListToolsRequestSchema,
} from '@modelcontextprotocol/sdk/types.js';
import { createMCPSamplingProvider } from '@mcpc-tech/mcp-sampling-ai-provider';
import { streamText } from 'ai';

const server = new Server(
  { name: 'ai-assistant', version: '1.0.0' },
  { capabilities: { sampling: {}, tools: {} } },
);

server.setRequestHandler(ListToolsRequestSchema, async () => {
  return {
    tools: [
      {
        name: 'generate-story',
        description: '使用 AI 生成故事或诗歌',
        inputSchema: {
          type: 'object',
          properties: {},
        },
      },
    ],
  };
});

server.setRequestHandler(CallToolRequestSchema, async request => {
  if (request.params.name === 'generate-story') {
    const provider = createMCPSamplingProvider({ server });

    const result = streamText({
      model: provider.languageModel({
        modelPreferences: {
          hints: [{ name: 'gpt-5-mini' }],
          speedPriority: 0.9,
        },
      }),
      prompt: '写一首关于编程的短诗。',
    });

    const text = await result.text;

    return { content: [{ type: 'text', text }] };
  }
});

const transport = new StdioServerTransport();
await server.connect(transport);
```

### 结构化输出

使用 MCP Sampling 提供商生成结构化对象：

```typescript
import { Server } from '@modelcontextprotocol/sdk/server/index.js';
import { StdioServerTransport } from '@modelcontextprotocol/sdk/server/stdio.js';
import {
  CallToolRequestSchema,
  ListToolsRequestSchema,
} from '@modelcontextprotocol/sdk/types.js';
import { createMCPSamplingProvider } from '@mcpc-tech/mcp-sampling-ai-provider';
import { generateText, Output } from 'ai';
import { z } from 'zod';

const server = new Server(
  { name: 'recipe-generator', version: '1.0.0' },
  { capabilities: { sampling: {}, tools: {} } },
);

server.setRequestHandler(ListToolsRequestSchema, async () => {
  return {
    tools: [
      {
        name: 'generate-recipe',
        description: '使用 AI 生成食谱',
        inputSchema: {
          type: 'object',
          properties: {},
        },
      },
    ],
  };
});

server.setRequestHandler(CallToolRequestSchema, async request => {
  if (request.params.name === 'generate-recipe') {
    const provider = createMCPSamplingProvider({ server });

    const recipeSchema = z.object({
      recipe: z.object({
        name: z.string(),
        cuisine: z.string(),
        ingredients: z.array(z.string()),
        steps: z.array(z.string()),
      }),
    });

    const { output } = await generateText({
      model: provider.languageModel({
        modelPreferences: { hints: [{ name: 'gpt-5-mini' }] },
      }),
      output: Output.object({ schema: recipeSchema }),
      prompt: '生成一份美味的千层面食谱。',
    });

    return {
      content: [{ type: 'text', text: JSON.stringify(output, null, 2) }],
    };
  }
});

const transport = new StdioServerTransport();
await server.connect(transport);
```

### 工具调用（实验性）

将工具与 MCP Sampling 提供商一起使用。注意：这是通过系统提示实现的，可能不如原生工具支持可靠：

```typescript
import { Server } from '@modelcontextprotocol/sdk/server/index.js';
import { StdioServerTransport } from '@modelcontextprotocol/sdk/server/stdio.js';
import {
  CallToolRequestSchema,
  ListToolsRequestSchema,
} from '@modelcontextprotocol/sdk/types.js';
import { createMCPSamplingProvider } from '@mcpc-tech/mcp-sampling-ai-provider';
import { generateText, isStepCount } from 'ai';
import { z } from 'zod';

const server = new Server(
  { name: 'weather-agent', version: '1.0.0' },
  { capabilities: { sampling: {}, tools: {} } },
);

server.setRequestHandler(ListToolsRequestSchema, async () => {
  return {
    tools: [
      {
        name: 'ask-weather',
        description: '询问天气相关问题',
        inputSchema: {
          type: 'object',
          properties: {
            question: {
              type: 'string',
              description: '要询问的天气问题',
            },
          },
        },
      },
    ],
  };
});

server.setRequestHandler(CallToolRequestSchema, async request => {
  if (request.params.name === 'ask-weather') {
    const provider = createMCPSamplingProvider({ server });

    const result = await generateText({
      model: provider.languageModel({
        modelPreferences: { hints: [{ name: 'gpt-5-mini' }] },
      }),
      tools: {
        getWeather: {
          description: '获取某个地点的天气',
          parameters: z.object({
            city: z.string().describe('城市名称'),
          }),
          execute: async ({ city }) => {
            return `${city} 的天气是晴天，72°F`;
          },
        },
      },
      prompt:
        request.params.arguments?.question ||
        '旧金山的天气怎么样？',
      stopWhen: isStepCount(5),
    });

    return { content: [{ type: 'text', text: result.text }] };
  }
});

const transport = new StdioServerTransport();
await server.connect(transport);
```

## 客户端 Sampling（适用于没有原生支持的客户端）

如果您的 MCP 客户端不原生支持 sampling，您可以使用 `setupClientSampling` 并指定模型偏好来添加 sampling 能力：

```typescript
import { Client } from '@modelcontextprotocol/sdk/client/index.js';
import { StdioClientTransport } from '@modelcontextprotocol/sdk/client/stdio.js';
import {
  convertAISDKFinishReasonToMCP,
  selectModelFromPreferences,
  setupClientSampling,
} from '@mcpc-tech/mcp-sampling-ai-provider';
import { generateText } from 'ai';

const client = new Client(
  { name: 'my-client', version: '1.0.0' },
  { capabilities: { sampling: {} } },
);

setupClientSampling(client, {
  handler: async params => {
    const modelId = selectModelFromPreferences(params.modelPreferences, {
      hints: {
        'gpt-5': 'openai/gpt-5-mini',
        'gpt-mini': 'openai/gpt-5-mini',
      },
      priorities: {
        speed: 'openai/gpt-5-mini',
        intelligence: 'openai/gpt-5-mini',
      },
      default: 'openai/gpt-5-mini',
    });

    const result = await generateText({
      model: modelId,
      messages: params.messages,
    });

    return {
      model: modelId,
      role: 'assistant',
      content: { type: 'text', text: result.text },
      stopReason: convertAISDKFinishReasonToMCP(result.finishReason),
    };
  },
});

const transport = new StdioClientTransport({
  command: 'npx',
  args: ['-y', 'example_mcp_server.ts'],
});

await client.connect(transport);
```

查看 [完整示例](https://github.com/mcpc-tech/mcpc/blob/main/packages/mcp-sampling-ai-provider/examples/client-sampling-example.ts) 获取更多详细信息。

## 工作原理

请求流程非常简单：

1. AI SDK 调用语言模型
2. 提供商转换为 MCP `sampling/createMessage` 格式
3. MCP 客户端处理 sampling 请求
4. 提供商将响应转换回 AI SDK 格式

MCP 客户端（例如 VS Code、Claude Desktop）根据提供的 `modelPreferences` 决定使用哪个实际模型。

## 限制

- **无 token 计数**：MCP 不提供 token 使用信息（返回 0）
- **无原生流式传输**：MCP sampling 不支持流式传输——提供商先调用 `doGenerate`，然后将完整响应作为流事件发出
- **实验性工具/JSON 支持**：通过 systemPrompt 实现，因为 MCP sampling 不原生支持这些功能
