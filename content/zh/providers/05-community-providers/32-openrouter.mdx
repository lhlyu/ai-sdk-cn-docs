# OpenRouter

[OpenRouter](https://openrouter.ai/) 是一个统一的 API 网关，提供对 Anthropic、Google、Meta、Mistral 等领先提供商数百个 AI 模型的访问。AI SDK 的 OpenRouter 提供商能够无缝集成所有这些模型，同时提供独特优势：

- **通用模型访问**：一个 API 密钥即可访问来自多个提供商的数百个模型
- **经济高效**：按需付费定价，无月费或承诺
- **透明定价**：所有模型均按 token 明确计费
- **高可用性**：企业级基础设施，支持自动故障转移
- **简单集成**：所有模型使用标准化 API
- **最新模型**：新模型发布后即可立即访问

在 [OpenRouter 文档](https://openrouter.ai/docs) 中了解更多关于 OpenRouter 功能的信息。

## 提供商实例

要创建 OpenRouter 提供商实例，请使用 `createOpenRouter` 函数：

```typescript
import { createOpenRouter } from '@openrouter/ai-sdk-provider';

const openrouter = createOpenRouter({
  apiKey: 'YOUR_OPENROUTER_API_KEY',
});
```

您可以从 [OpenRouter 控制台](https://openrouter.ai/keys) 获取 OpenRouter API 密钥。

## 语言模型

OpenRouter 支持聊天模型和补全模型。使用 `openrouter.chat()` 处理聊天模型，使用 `openrouter.completion()` 处理补全模型：

```typescript
// 聊天模型（推荐）
const chatModel = openrouter.chat('anthropic/claude-3.5-sonnet');

// 补全模型
const completionModel = openrouter.completion(
  'meta-llama/llama-3.1-405b-instruct',
);
```

您可以在 [OpenRouter 模型文档](https://openrouter.ai/docs#models) 中查看可用模型的完整列表。

## 示例

以下是使用 OpenRouter 与 AI SDK 的示例：

### `generateText`

```javascript
import { createOpenRouter } from '@openrouter/ai-sdk-provider';
import { generateText } from 'ai';

const openrouter = createOpenRouter({
  apiKey: 'YOUR_OPENROUTER_API_KEY',
});

const { text } = await generateText({
  model: openrouter.chat('anthropic/claude-3.5-sonnet'),
  prompt: 'What is OpenRouter?',
});

console.log(text);
```

### `streamText`

```javascript
import { createOpenRouter } from '@openrouter/ai-sdk-provider';
import { streamText } from 'ai';

const openrouter = createOpenRouter({
  apiKey: 'YOUR_OPENROUTER_API_KEY',
});

const result = streamText({
  model: openrouter.chat('meta-llama/llama-3.1-405b-instruct'),
  prompt: 'Write a short story about AI.',
});

for await (const chunk of result.textStream) {
  console.log(chunk);
}
```

## 高级功能

OpenRouter 提供多项高级功能，以增强您的 AI 应用：

1. **模型灵活性**：无需更改代码或管理多个 API 密钥，即可在数百个模型之间切换。

2. **成本管理**：通过控制台实时跟踪每个模型的使用情况和成本。

3. **企业支持**：为高用量用户提供自定义 SLA 和专属支持。

4. **跨提供商兼容性**：在不同模型提供商之间使用相同的代码结构。

5. **定期更新**：新模型和功能可用时自动获得访问权限。

有关这些功能和高级配置选项的更多信息，请访问 [OpenRouter 文档](https://openrouter.ai/docs)。
