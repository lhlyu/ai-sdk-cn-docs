# Fireworks 提供商

[Fireworks](https://fireworks.ai/) 是一个通过其 [API](https://readme.fireworks.ai/) 运行和测试 LLM 的平台。

## 设置

Fireworks 提供商可通过 `@ai-sdk/fireworks` 模块获得。你可以使用以下命令安装它：

<InstallPackages packages="@ai-sdk/fireworks" />

## 提供商实例

你可以从 `@ai-sdk/fireworks` 导入默认的提供商实例 `fireworks`：

```ts
import { fireworks } from '@ai-sdk/fireworks';
```

如果你需要自定义设置，可以从 `@ai-sdk/fireworks` 导入 `createFireworks`，并使用你的设置创建一个提供商实例：

```ts
import { createFireworks } from '@ai-sdk/fireworks';

const fireworks = createFireworks({
  apiKey: process.env.FIREWORKS_API_KEY ?? '',
});
```

你可以使用以下可选设置来自定义 Fireworks 提供商实例：

- **baseURL** _string_

  为 API 调用使用不同的 URL 前缀，例如使用代理服务器。
  默认前缀是 `https://api.fireworks.ai/inference/v1`。

- **apiKey** _string_

  通过 `Authorization` 标头发送的 API 密钥。它默认为 `FIREWORKS_API_KEY` 环境变量。

- **headers** _Record&lt;string,string&gt;_

  要包含在请求中的自定义标头。

- **fetch** _(input: RequestInfo, init?: RequestInit) => Promise&lt;Response&gt;_

  自定义 [fetch](https://developer.mozilla.org/en-US/docs/Web/API/fetch) 实现。

## 语言模型

你可以使用提供商实例创建 [Fireworks 模型](https://fireworks.ai/models)。第一个参数是模型 ID，例如 `accounts/fireworks/models/firefunction-v1`：

```ts
const model = fireworks('accounts/fireworks/models/firefunction-v1');
```

### 推理模型

Fireworks 在生成的文本中使用 `<think>` 标签暴露 `deepseek-r1` 的思考过程。
你可以使用 `extractReasoningMiddleware` 来提取此推理过程，并将其作为结果上的 `reasoning` 属性暴露出来：

```ts
import { fireworks } from '@ai-sdk/fireworks';
import { wrapLanguageModel, extractReasoningMiddleware } from 'ai';

const enhancedModel = wrapLanguageModel({
  model: fireworks('accounts/fireworks/models/deepseek-r1'),
  middleware: extractReasoningMiddleware({ tagName: 'think' }),
});
```

然后，你可以在 `generateText` 和 `streamText` 等函数中使用这个增强模型。

### 示例

你可以使用 Fireworks 语言模型通过 `generateText` 函数生成文本：

```ts
import { fireworks } from '@ai-sdk/fireworks';
import { generateText } from 'ai';

const { text } = await generateText({
  model: fireworks('accounts/fireworks/models/firefunction-v1'),
  prompt: '写一份供 4 人食用的素食千层面食谱。',
});
```

Fireworks 语言模型也可以在 `streamText` 函数中使用（参见 [AI SDK Core](/docs/ai-sdk-core)）。

### 提供商选项

Fireworks 聊天模型支持额外的提供商选项，这些选项不属于[标准调用设置](/docs/ai-sdk-core/settings)。你可以在 `providerOptions` 参数中传递它们：

```ts
import {
  fireworks,
  type FireworksLanguageModelOptions,
} from '@ai-sdk/fireworks';
import { generateText } from 'ai';

const { text, reasoningText } = await generateText({
  model: fireworks('accounts/fireworks/models/kimi-k2p6'),
  providerOptions: {
    fireworks: {
      thinking: { type: 'enabled', budgetTokens: 4096 },
      reasoningHistory: 'interleaved',
    } satisfies FireworksLanguageModelOptions,
  },
  prompt: '单词 "strawberry" 中有多少个字母 "r"？',
});
```

Fireworks 聊天模型提供以下可选的提供商选项：

- **promptCacheKey** _string_

  一个稳定的、不透明的键，通过将具有共享提示词前缀的请求路由到同一个 Fireworks 副本，来提高提示词缓存命中率。在同一个对话的所有步骤和调用中重复使用相同的键，并为不相关的对话使用不同的键。

- **serviceTier** _'priority'_

  使用 Fireworks Priority 服务路径，以在高峰流量期间获得更高的可靠性。提供商将其作为 Fireworks 的 `service_tier` 请求字段发送。

- **thinking** _object_

  用于 Kimi K2.6 等思考/推理模型的配置。
  - **type** _'enabled' | 'disabled'_

    是否启用思考模式。

  - **budgetTokens** _number_

    用于思考的最大 token 数（最小 1024）。

- **reasoningHistory** _'disabled' | 'interleaved' | 'preserved'_

  控制多轮对话中如何处理推理历史：
  - `'disabled'`：从历史中移除推理
  - `'interleaved'`：在单轮对话中，在工具调用之间包含推理
  - `'preserved'`：保留历史中的所有推理

### 提示词缓存亲和性

[Fireworks 提示词缓存](https://docs.fireworks.ai/guides/prompt-caching)是自动的，但缓存的前缀是特定于副本的。将 `promptCacheKey` 设置为一个不透明的会话或对话标识符，以提高缓存亲和性。提供商将其作为 Fireworks 的 [`prompt_cache_key`](https://docs.fireworks.ai/api-reference/post-chatcompletions) 请求字段发送。

AI SDK 在多步骤的 `generateText` 或 `streamText` 调用中，为每个模型步骤重用相同的提供商选项，因此一个键覆盖整个工具循环：

```ts
import {
  fireworks,
  type FireworksLanguageModelOptions,
} from '@ai-sdk/fireworks';
import { generateText, isStepCount, tool } from 'ai';
import { z } from 'zod';

const sessionId = 'conversation-123';

const result = await generateText({
  model: fireworks('accounts/fireworks/models/kimi-k2p6'),
  providerOptions: {
    fireworks: {
      promptCacheKey: sessionId,
    } satisfies FireworksLanguageModelOptions,
  },
  tools: {
    weather: tool({
      description: '获取某个城市的天气。',
      inputSchema: z.object({ city: z.string() }),
      execute: async ({ city }) => `${city} 天气晴朗。`,
    }),
  },
  stopWhen: isStepCount(5),
  prompt: '旧金山的天气怎么样？',
});

console.log(result.usage.inputTokenDetails.cacheReadTokens);
```

对于可重用的 `ToolLoopAgent`，使用调用选项为每个对话提供一个键。在后续继续该对话的智能体调用中，再次传递相同的键：

```ts
import {
  fireworks,
  type FireworksLanguageModelOptions,
} from '@ai-sdk/fireworks';
import { ToolLoopAgent } from 'ai';
import { z } from 'zod';
import { weatherTool } from './weather-tool';

const agent = new ToolLoopAgent({
  model: fireworks('accounts/fireworks/models/kimi-k2p6'),
  callOptionsSchema: z.object({
    sessionId: z.string(),
  }),
  prepareCall: ({ options, ...settings }) => ({
    ...settings,
    providerOptions: {
      fireworks: {
        promptCacheKey: options.sessionId,
      } satisfies FireworksLanguageModelOptions,
    },
  }),
  tools: { weather: weatherTool },
});

const result = await agent.generate({
  prompt: '旧金山的天气怎么样？',
  options: {
    sessionId: 'conversation-123',
  },
});
```

对缓存键使用非标识性值，而不是电子邮件地址或其他个人信息。

### 优先级服务层级

[Fireworks Priority 层级](https://docs.fireworks.ai/serverless/serving-paths) 将受支持的模型优先于标准流量。将 `serviceTier` 设置为 `'priority'` 以发送 Fireworks 的 `service_tier` 请求字段：

```ts
import {
  fireworks,
  type FireworksLanguageModelOptions,
} from '@ai-sdk/fireworks';
import { generateText } from 'ai';

const result = await generateText({
  model: fireworks('accounts/fireworks/models/glm-5p2'),
  providerOptions: {
    fireworks: {
      serviceTier: 'priority',
    } satisfies FireworksLanguageModelOptions,
  },
  prompt: '写一首关于可靠推理的俳句。',
});
```

## 嵌入模型

你可以使用 `.embeddingModel()` 工厂方法创建调用 Fireworks 嵌入 API 的模型：

```ts
const model = fireworks.embeddingModel('nomic-ai/nomic-embed-text-v1.5');
```

你可以使用 Fireworks 嵌入模型通过 `embed` 函数生成嵌入：

```ts
import { fireworks } from '@ai-sdk/fireworks';
import { embed } from 'ai';

const { embedding } = await embed({
  model: fireworks.embeddingModel('nomic-ai/nomic-embed-text-v1.5'),
  value: '阳光明媚的海滩日',
});
```

### 模型能力

| 模型                            | 维度 | 最大 Token 数 |
| -------------------------------- | ---- | ------------- |
| `nomic-ai/nomic-embed-text-v1.5` | 768  | 8192          |

<Note>
  更多嵌入模型，请参阅 [Fireworks 模型页面](https://fireworks.ai/models) 获取可用模型的完整列表。
</Note>

## 图像模型

你可以使用 `.image()` 工厂方法创建 Fireworks 图像模型。
有关使用 AI SDK 生成图像的更多信息，请参见 [generateImage()](/docs/reference/ai-sdk-core/generate-image)。

```ts
import { fireworks, type FireworksImageModelOptions } from '@ai-sdk/fireworks';
import { generateImage } from 'ai';

const { image } = await generateImage({
  model: fireworks.image('accounts/fireworks/models/flux-1-dev-fp8'),
  prompt: '日落时分的未来城市景观',
  aspectRatio: '16:9',
  providerOptions: {
    fireworks: {
      guidance_scale: 4.5,
      num_inference_steps: 8,
    } satisfies FireworksImageModelOptions,
  },
});
```

<Note>
  模型对 `size` 和 `aspectRatio` 参数的支持各不相同。请参阅下面的[模型能力](#模型能力-1)部分了解支持的尺寸，或查看 [Fireworks 模型页面](https://fireworks.ai/models) 上模型的文档以获取更多详细信息。
</Note>

### 提供商选项

Fireworks 图像模型通过 `providerOptions.fireworks` 对象支持灵活的提供商选项。使用 `FireworksImageModelOptions` 类型来验证已知的 Fireworks 图像选项，同时允许特定于模型的选项通过。

以下类型化的提供商选项可用：

- **guidance_scale** _number_

  图像扩散过程的无分类器引导尺度。

- **num_inference_steps** _number_

  FLUX 工作流图像生成的去噪步数。

- **output_format** _'jpeg' | 'png'_

  FLUX Kontext 图像生成和编辑所需的输出格式。

- **prompt_upsampling** _boolean_

  Fireworks 是否应自动修改提示词以进行更具创意的生成。

- **safety_tolerance** _number_

  输入和输出的审核容忍级别，范围从 `0` 到 `6`。Fireworks 将图像到图像的请求限制为 `2`。

- **webhook_url** _string_

  用于接收异步 Kontext 请求的 webhook 通知的 URL。

- **webhook_secret** _string_

  用于 webhook 签名验证的密钥。

- **cfg_scale** _number_

  旧版 `image_generation` 模型的引导尺度。

- **steps** _number_

  旧版 `image_generation` 模型的生成步数。

### 图像编辑

Fireworks 通过 FLUX Kontext 模型（`flux-kontext-pro` 和 `flux-kontext-max`）支持图像编辑。通过 `prompt.images` 传递输入图像以转换或编辑现有图像。

<Note>
  Fireworks Kontext 模型不支持显式遮罩。编辑由提示词驱动——在文本提示词中描述你想要更改的内容。
</Note>

#### 基本图像编辑

使用文本提示词转换现有图像：

```ts
const imageBuffer = readFileSync('./input-image.png');

const { images } = await generateImage({
  model: fireworks.image('accounts/fireworks/models/flux-kontext-pro'),
  prompt: {
    text: '把猫变成一只金毛寻回犬',
    images: [imageBuffer],
  },
  providerOptions: {
    fireworks: {
      output_format: 'jpeg',
      safety_tolerance: 2,
    } satisfies FireworksImageModelOptions,
  },
});
```

#### 风格迁移

将艺术风格应用于图像：

```ts
const imageBuffer = readFileSync('./input-image.png');

const { images } = await generateImage({
  model: fireworks.image('accounts/fireworks/models/flux-kontext-pro'),
  prompt: {
    text: '将此转换为水彩画风格',
    images: [imageBuffer],
  },
  aspectRatio: '1:1',
});
```

<Note>
  输入图像可以作为 `Buffer`、`ArrayBuffer`、`Uint8Array` 或 base64 编码的字符串提供。Fireworks 每个请求仅支持单个输入图像。
</Note>
