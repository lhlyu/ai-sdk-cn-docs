# Fireworks 提供商

[Fireworks](https://fireworks.ai/) 是一个通过其 [API](https://readme.fireworks.ai/) 运行和测试 LLM 的平台。
对于其目录中的模型，建议从 [AI Gateway](/providers/ai-sdk-providers/ai-gateway) 开始（推荐），或使用 `@ai-sdk/fireworks` 直接连接到 Fireworks。

```ts provider="fireworks" model="openai/gpt-oss-120b"
import { generateText } from 'ai';
__PROVIDER_IMPORT__;

const { text } = await generateText({
  model: __MODEL__,
  prompt: 'Write a vegetarian lasagna recipe for 4 people.',
  __GATEWAY_OPTIONS__,
});

console.log(text);
```

## 使用 AI Gateway

AI SDK 默认对模型字符串使用 AI Gateway。Gateway 通过单个 API 密钥提供跨提供商的模型访问，并支持用量和成本跟踪。安装 `ai`：

<InstallPackages packages="ai" />

在环境中设置 [AI Gateway API 密钥](https://vercel.com/docs/ai-gateway/getting-started)：

```bash
export AI_GATEWAY_API_KEY=your_api_key_here
```

Vercel 部署还可以使用 [OIDC 身份验证](/providers/ai-sdk-providers/ai-gateway#oidc-authentication-vercel-deployments)。
有关配置信息，请参阅 [AI Gateway 提供商文档](/providers/ai-sdk-providers/ai-gateway)；有关可用模型，请参阅[模型目录](https://vercel.com/ai-gateway/models)。

该示例将 `providerOptions.gateway.order` 设置为 `['fireworks']`。这会将请求首先发送到 Fireworks，如果 Fireworks 不可用或请求失败，则回退到同一模型的其他可用提供商。`order` 设置的是偏好；它不会将回退限制为仅 Fireworks。请参阅[提供商排序](https://vercel.com/docs/ai-gateway/models-and-providers/provider-filtering-and-ordering)。

下拉列表列出了通过 Gateway 由 Fireworks 提供服务的模型，并附有相应的直接提供商示例。提供商可用性取决于模型以及你团队的[提供商允许列表](https://vercel.com/docs/ai-gateway/models-and-providers/provider-filtering-and-ordering)。

## 使用 `@ai-sdk/fireworks`

如需直接访问 Fireworks，请安装 `ai` 和 `@ai-sdk/fireworks`：

<InstallPackages packages="ai @ai-sdk/fireworks" />

在 `FIREWORKS_API_KEY` 环境变量中设置你的 Fireworks API 凭据：

```bash
export FIREWORKS_API_KEY=your_api_key_here
```

AI Gateway 并未暴露 `@ai-sdk/fireworks` 中的每一个 API。如需使用提供商特定的 API 或自定义连接设置，请使用直接提供商。

<Note>
  以下各节介绍直接使用 `@ai-sdk/fireworks` 提供商的内容，
  包括其模型工厂和设置。Gateway 的模型和功能
  可用性可能有所不同。
</Note>

## 提供商实例

你可以从 `@ai-sdk/fireworks` 导入默认提供商实例 `fireworks`：

```ts
import { fireworks } from '@ai-sdk/fireworks';
```

如果你需要自定义设置，可以从 `@ai-sdk/fireworks` 导入 `createFireworks`，
并使用你的设置创建提供商实例：

```ts
import { createFireworks } from '@ai-sdk/fireworks';

const fireworks = createFireworks({
  apiKey: process.env.FIREWORKS_API_KEY ?? '',
});
```

你可以使用以下可选设置来自定义 Fireworks 提供商实例：

- **baseURL** _string_

  为 API 调用使用不同的 URL 前缀，例如使用代理服务器。
  默认前缀为 `https://api.fireworks.ai/inference/v1`。

- **apiKey** _string_

  通过 `Authorization` 标头发送的 API 密钥。默认使用
  `FIREWORKS_API_KEY` 环境变量。

- **headers** _Record&lt;string,string&gt;_

  要包含在请求中的自定义标头。

- **fetch** _(input: RequestInfo, init?: RequestInit) => Promise&lt;Response&gt;_

  自定义 [fetch](https://developer.mozilla.org/en-US/docs/Web/API/fetch) 实现。

## 语言模型

你可以使用提供商实例创建 [Fireworks 模型](https://fireworks.ai/models)。
第一个参数是模型 ID，例如 `accounts/fireworks/models/firefunction-v1`：

```ts
const model = fireworks('accounts/fireworks/models/firefunction-v1');
```

### 推理模型

对于支持推理强度的模型，请使用顶层 `reasoning` 参数。
Fireworks 会将 `'minimal'` 映射为 `'low'`，将 `'xhigh'` 或 `'max'` 映射为 `'high'`，并在强制转换推理强度时
返回兼容性警告。流式调用会在 `stream-start` 事件中包含
该警告。显式的
`providerOptions.fireworks.reasoningEffort` 优先于顶层
设置。

Fireworks 使用 `<think>` 标签在生成的文本中暴露 `deepseek-r1` 的思考过程。
你可以使用 `extractReasoningMiddleware` 提取该推理内容，并将其作为结果上的 `reasoning` 属性暴露：

```ts
import { fireworks } from '@ai-sdk/fireworks';
import { wrapLanguageModel, extractReasoningMiddleware } from 'ai';

const enhancedModel = wrapLanguageModel({
  model: fireworks('accounts/fireworks/models/deepseek-r1'),
  middleware: extractReasoningMiddleware({ tagName: 'think' }),
});
```

然后你可以在 `generateText` 和 `streamText` 等函数中使用该增强模型。

### 示例

你可以使用 Fireworks 语言模型通过 `generateText` 函数生成文本：

```ts
import { fireworks } from '@ai-sdk/fireworks';
import { generateText } from 'ai';

const { text } = await generateText({
  model: fireworks('accounts/fireworks/models/firefunction-v1'),
  prompt: 'Write a vegetarian lasagna recipe for 4 people.',
});
```

Fireworks 语言模型也可以用于 `streamText` 函数
（请参阅 [AI SDK Core](/docs/ai-sdk-core)）。

### 提供商选项

Fireworks 聊天模型支持不属于
[标准调用设置](/docs/ai-sdk-core/settings)的额外提供商选项。你可以在 `providerOptions` 参数中传入它们：

```ts
import {
  fireworks,
  type FireworksLanguageModelOptions,
} from '@ai-sdk/fireworks';
import { generateText } from 'ai';

const { text, reasoningText } = await generateText({
  model: fireworks('accounts/fireworks/models/kimi-k2p6'),
  providerOptions: {
    fireworks: {
      thinking: { type: 'enabled', budgetTokens: 4096 },
      reasoningHistory: 'interleaved',
    } satisfies FireworksLanguageModelOptions,
  },
  prompt: 'How many "r"s are in the word "strawberry"?',
});
```

Fireworks 聊天模型提供以下可选提供商选项：

- **promptCacheKey** _string_

  一个稳定的不透明键，通过将具有共享提示词前缀的请求路由到
  同一 Fireworks 副本，提高提示词缓存命中率。对于同一对话中的所有步骤和调用，
  请复用同一个键；对于不相关的对话，请使用不同的键。

- **serviceTier** _'priority'_

  使用 Fireworks Priority 服务路径，在高峰流量期间获得更高可靠性。
  提供商会将其作为 Fireworks 的 `service_tier` 请求字段发送。

- **thinking** _object_

  用于 Kimi K2.6 等思考/推理模型的配置。
  - **type** _'enabled' | 'disabled'_

    是否启用思考模式。

  - **budgetTokens** _number_

    思考的最大 token 数（最小 1024）。

- **reasoningHistory** _'disabled' | 'interleaved' | 'preserved'_

  控制多轮对话中推理历史的处理方式：
  - `'disabled'`：从历史中移除推理内容
  - `'interleaved'`：在单轮内包含工具调用之间的推理内容
  - `'preserved'`：在历史中保留所有推理内容

### 提示词缓存亲和性

[Fireworks 提示词缓存](https://docs.fireworks.ai/guides/prompt-caching)
是自动的，但缓存前缀是副本本地的。将
`promptCacheKey` 设置为不透明的会话或对话标识符，以提高
缓存亲和性。提供商会将其作为 Fireworks 的
[`prompt_cache_key`](https://docs.fireworks.ai/api-reference/post-chatcompletions)
请求字段发送。

AI SDK 会在多步 `generateText` 或 `streamText` 调用中为每个模型步骤复用相同的提供商选项，
因此一个键即可覆盖完整的
工具循环：

```ts
import {
  fireworks,
  type FireworksLanguageModelOptions,
} from '@ai-sdk/fireworks';
import { generateText, isStepCount, tool } from 'ai';
import { z } from 'zod';

const sessionId = 'conversation-123';

const result = await generateText({
  model: fireworks('accounts/fireworks/models/kimi-k2p6'),
  providerOptions: {
    fireworks: {
      promptCacheKey: sessionId,
    } satisfies FireworksLanguageModelOptions,
  },
  tools: {
    weather: tool({
      description: 'Get the weather for a city.',
      inputSchema: z.object({ city: z.string() }),
      execute: async ({ city }) => `It is sunny in ${city}.`,
    }),
  },
  stopWhen: isStepCount(5),
  prompt: 'What is the weather in San Francisco?',
});

console.log(result.usage.inputTokenDetails.cacheReadTokens);
```

对于可复用的 `ToolLoopAgent`，请使用调用选项为每个
对话提供键。对于继续该对话的后续智能体调用，请再次传入相同的键：

```ts
import {
  fireworks,
  type FireworksLanguageModelOptions,
} from '@ai-sdk/fireworks';
import { ToolLoopAgent } from 'ai';
import { z } from 'zod';
import { weatherTool } from './weather-tool';

const agent = new ToolLoopAgent({
  model: fireworks('accounts/fireworks/models/kimi-k2p6'),
  callOptionsSchema: z.object({
    sessionId: z.string(),
  }),
  prepareCall: ({ options, ...settings }) => ({
    ...settings,
    providerOptions: {
      fireworks: {
        promptCacheKey: options.sessionId,
      } satisfies FireworksLanguageModelOptions,
    },
  }),
  tools: { weather: weatherTool },
});

const result = await agent.generate({
  prompt: 'What is the weather in San Francisco?',
  options: {
    sessionId: 'conversation-123',
  },
});
```

请为缓存键使用非身份识别值，而不要使用电子邮件地址或其他
个人信息。

### 优先服务层级

[Fireworks Priority 层级](https://docs.fireworks.ai/serverless/serving-paths)
会将支持的模型优先于 Standard 流量处理。将 `serviceTier` 设置为
`'priority'`，以发送 Fireworks 的 `service_tier` 请求字段：

```ts
import {
  fireworks,
  type FireworksLanguageModelOptions,
} from '@ai-sdk/fireworks';
import { generateText } from 'ai';

const result = await generateText({
  model: fireworks('accounts/fireworks/models/glm-5p2'),
  providerOptions: {
    fireworks: {
      serviceTier: 'priority',
    } satisfies FireworksLanguageModelOptions,
  },
  prompt: 'Write a haiku about reliable inference.',
});
```

## 嵌入模型

你可以使用 `.embeddingModel()` 工厂方法创建调用 Fireworks 嵌入 API 的模型：

```ts
const model = fireworks.embeddingModel('nomic-ai/nomic-embed-text-v1.5');
```

你可以使用 Fireworks 嵌入模型通过 `embed` 函数生成嵌入：

```ts
import { fireworks } from '@ai-sdk/fireworks';
import { embed } from 'ai';

const { embedding } = await embed({
  model: fireworks.embeddingModel('nomic-ai/nomic-embed-text-v1.5'),
  value: 'sunny day at the beach',
});
```

## 图像模型

你可以使用 `.image()` 工厂方法创建 Fireworks 图像模型。
有关使用 AI SDK 生成图像的更多信息，请参阅 [generateImage()](/docs/reference/ai-sdk-core/generate-image)。

```ts
import { fireworks, type FireworksImageModelOptions } from '@ai-sdk/fireworks';
import { generateImage } from 'ai';

const { image } = await generateImage({
  model: fireworks.image('accounts/fireworks/models/flux-1-dev-fp8'),
  prompt: 'A futuristic cityscape at sunset',
  aspectRatio: '16:9',
  providerOptions: {
    fireworks: {
      guidance_scale: 4.5,
      num_inference_steps: 8,
    } satisfies FireworksImageModelOptions,
  },
});
```

<Note>
  模型对 `size` 和 `aspectRatio` 参数的支持各不相同。请参阅下方
  [模型能力](#model-capabilities-1)部分了解支持的尺寸，
  或查看 [Fireworks 模型页面](https://fireworks.ai/models)上的模型文档
  以了解更多详情。
</Note>

### 提供商选项

Fireworks 图像模型通过 `providerOptions.fireworks` 对象支持灵活的提供商选项。使用 `FireworksImageModelOptions` 类型来验证已知的 Fireworks 图像选项，同时仍允许模型特定选项通过。

提供以下带类型的提供商选项：

- **guidance_scale** _number_

  图像扩散过程的无分类器引导比例。

- **num_inference_steps** _number_

  FLUX 工作流图像生成的去噪步数。

- **output_format** _'jpeg' | 'png'_

  FLUX Kontext 图像生成和编辑所需的输出格式。

- **prompt_upsampling** _boolean_

  Fireworks 是否应自动修改提示词以获得更具创意的生成结果。

- **safety_tolerance** _number_

  输入和输出的审核容忍级别，范围为 `0` 到 `6`。Fireworks 将图生图请求限制为 `2`。

- **webhook_url** _string_

  用于接收异步 Kontext 请求 webhook 通知的 URL。

- **webhook_secret** _string_

  用于 webhook 签名验证的密钥。

- **cfg_scale** _number_

  旧版 `image_generation` 模型的引导比例。

- **steps** _number_

  旧版 `image_generation` 模型的生成步数。

### 图像编辑

Fireworks 通过 FLUX Kontext 模型（`flux-kontext-pro` 和 `flux-kontext-max`）支持图像编辑。通过 `prompt.images` 传入输入图像，以转换或编辑现有图像。

<Note>
  Fireworks Kontext 模型不支持显式蒙版。编辑由
  提示词驱动——在文本提示词中描述你想要更改的内容。
</Note>

#### 基本图像编辑

使用文本提示词转换现有图像：

```ts
const imageBuffer = readFileSync('./input-image.png');

const { images } = await generateImage({
  model: fireworks.image('accounts/fireworks/models/flux-kontext-pro'),
  prompt: {
    text: 'Turn the cat into a golden retriever dog',
    images: [imageBuffer],
  },
  providerOptions: {
    fireworks: {
      output_format: 'jpeg',
      safety_tolerance: 2,
    } satisfies FireworksImageModelOptions,
  },
});
```

#### 风格迁移

为图像应用艺术风格：

```ts
const imageBuffer = readFileSync('./input-image.png');

const { images } = await generateImage({
  model: fireworks.image('accounts/fireworks/models/flux-kontext-pro'),
  prompt: {
    text: 'Transform this into a watercolor painting style',
    images: [imageBuffer],
  },
  aspectRatio: '1:1',
});
```

<Note>
  输入图像可以提供为 `Buffer`、`ArrayBuffer`、`Uint8Array` 或
  base64 编码字符串。Fireworks 每个请求仅支持一张输入图像。
</Note>
