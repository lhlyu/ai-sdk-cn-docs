# AI Gateway 提供商

[AI Gateway](https://vercel.com/docs/ai-gateway) 提供商通过单一接口将您连接到多个 AI 提供商的模型。您无需分别集成每个提供商，即可访问 OpenAI、Anthropic、Google、Meta、xAI 以及其他提供商及其模型。

## 特性

- 无需安装额外的提供商模块/依赖项，即可访问多个提供商的模型
- 跨不同 AI 提供商使用相同的代码结构
- 轻松切换模型和提供商
- 部署到 Vercel 时自动进行身份验证
- 跨提供商查看定价信息
- 通过 Vercel 仪表盘实现 AI 模型使用情况的可观测性

## 设置

Vercel AI Gateway 提供商是 AI SDK 的一部分。

## 基本用法

对于大多数用例，您可以直接使用模型字符串与 AI Gateway：

```ts
// 使用全局提供商的纯模型字符串
import { generateText } from 'ai';

const { text } = await generateText({
  model: 'openai/gpt-5.4',
  prompt: 'Hello world',
});
```

```ts
// 使用提供商实例（需要 5.0.36 或更高版本）
import { generateText, gateway } from 'ai';

const { text } = await generateText({
  model: gateway('openai/gpt-5.4'),
  prompt: 'Hello world',
});
```

当您以 `creator/model-name` 格式传递模型字符串时，AI SDK 会自动使用 AI Gateway。

## 提供商实例

<Note>
  `gateway` 提供商实例从 `ai` 包的 5.0.36 及更高版本开始可用。
</Note>

您也可以从 `ai` 导入默认的提供商实例 `gateway`：

```ts
import { gateway } from 'ai';
```

当您需要以下情况时，可能需要创建自定义提供商实例：

- 设置自定义配置选项（API 密钥、Vercel 访问令牌、基础 URL、请求头）
- 在[提供商注册表](/docs/ai-sdk-core/provider-management)中使用该提供商
- 使用[中间件](/docs/ai-sdk-core/middleware)包装该提供商
- 为应用程序的不同部分使用不同的设置

要创建自定义提供商实例，请从 `ai` 导入 `createGateway`：

```ts
import { createGateway } from 'ai';

const gateway = createGateway({
  apiKey: process.env.AI_GATEWAY_API_KEY ?? '',
});
```

您可以使用以下可选设置来自定义 AI Gateway 提供商实例：

- **baseURL** _string_

  为 API 调用使用不同的 URL 前缀。默认前缀是 `https://ai-gateway.vercel.sh/v4/ai`。

- **apiKey** _string_

  通过 `Authorization` 请求头发送的 API 密钥或 Vercel 访问令牌。默认为 `AI_GATEWAY_API_KEY` 环境变量。支持 AI Gateway API 密钥、Vercel 个人访问令牌和 Vercel 应用访问令牌。

- **teamIdOrSlug** _string_

  使用多团队 Vercel 访问令牌进行身份验证时，用于限定模型请求范围的 Vercel 团队 ID 或 slug。

- **headers** _Record&lt;string,string&gt;_

  要包含在请求中的自定义请求头。

- **fetch** _(input: RequestInfo, init?: RequestInit) => Promise&lt;Response&gt;_

  自定义 [fetch](https://developer.mozilla.org/en-US/docs/Web/API/fetch) 实现。默认为全局 `fetch` 函数。您可以将其用作拦截请求的中间件，或为测试等目的提供自定义 fetch 实现。

- **metadataCacheRefreshMillis** _number_

  元数据缓存刷新的频率（以毫秒为单位）。默认为 5 分钟（300,000 毫秒）。

## 身份验证

Gateway 提供商支持以下身份验证方法：

### API 密钥身份验证

通过环境变量设置您的 API 密钥：

```bash
AI_GATEWAY_API_KEY=your_api_key_here
```

或直接将其传递给提供商：

```ts
import { createGateway } from 'ai';

const gateway = createGateway({
  apiKey: 'your_api_key_here',
});
```

### 用于模型请求的 Vercel 访问令牌身份验证

对于模型请求的动态运行时身份验证，将 Vercel 个人访问令牌或 Vercel 应用访问令牌传递给自定义 Gateway 提供商实例：

```ts
import { createGateway } from 'ai';

const gateway = createGateway({
  apiKey: 'your_vercel_access_token_here',
  teamIdOrSlug: 'your-team', // 多团队令牌必需
});
```

`apiKey` 优先于 `AI_GATEWAY_API_KEY` 和 OIDC。

<Note>
  带有 `teamIdOrSlug` 的 Vercel 访问令牌支持模型请求。Gateway 辅助方法（如 `getCredits`、`getSpendReport` 和 `getGenerationInfo`）需要 AI Gateway API 密钥或 OIDC 身份验证。
</Note>

### OIDC 身份验证（Vercel 部署）

部署到 Vercel 时，AI Gateway 提供商支持使用 [OIDC（OpenID Connect）令牌](https://vercel.com/docs/oidc) 对模型请求进行身份验证，无需 API 密钥。

#### OIDC 身份验证的工作原理

1. **在生产/预览部署中**：
   - OIDC 身份验证会自动处理
   - 无需手动配置
   - 令牌会自动获取和刷新

2. **在本地开发中**：
   - 首先，安装并使用 [Vercel CLI](https://vercel.com/docs/cli) 进行身份验证
   - 运行 `vercel env pull` 将项目的 OIDC 令牌下载到本地
   - 对于自动令牌管理：
     - 使用 `vercel dev` 启动您的开发服务器——这将自动处理令牌刷新
   - 对于手动令牌管理：
     - 如果不使用 `vercel dev`，请注意 OIDC 令牌在 12 小时后过期
     - 您需要在令牌过期前再次运行 `vercel env pull` 来刷新令牌

<Note>
  如果存在 API 密钥或 Vercel 访问令牌（无论是直接传递还是通过环境变量），即使无效，也始终会使用它而不是 OIDC。
</Note>

在 [Vercel AI Gateway 文档](https://vercel.com/docs/ai-gateway#using-the-ai-gateway-with-a-vercel-oidc-token) 中阅读更多关于使用 OIDC 令牌的信息。

## 自带密钥 (BYOK)

您可以连接自己的提供商凭据以与 Vercel AI Gateway 一起使用。这使您可以使用现有的提供商帐户并访问私有资源。

要设置 BYOK，请在您的 Vercel 团队的 AI Gateway 设置中添加您的提供商凭据。配置完成后，AI Gateway 会自动使用您的凭据。无需更改代码。

对于像 Azure 这样可以使用自定义部署名称的提供商，您可以配置模型映射，将 Gateway 模型 slug 映射到您的部署名称。有关详细信息，请参阅[模型映射](https://vercel.com/docs/ai-gateway/byok#model-mappings)。

在 [BYOK 文档](https://vercel.com/docs/ai-gateway/byok) 中了解更多信息。

## 语言模型

您可以使用提供商实例创建语言模型。第一个参数是格式为 `creator/model-name` 的模型 ID：

```ts
import { generateText } from 'ai';

const { text } = await generateText({
  model: 'openai/gpt-5.4',
  prompt: '用简单的术语解释量子计算',
});
```

AI Gateway 语言模型也可以在 `streamText` 函数中使用，并支持使用 [`Output`](/docs/reference/ai-sdk-core/output) 进行结构化数据生成（请参阅 [AI SDK Core](/docs/ai-sdk-core)）。

## 重排序模型

您可以使用提供商实例上的 `rerankingModel` 方法创建重排序模型：

```ts
import { rerank } from 'ai';
import { gateway } from '@ai-sdk/gateway';

const { ranking } = await rerank({
  model: gateway.rerankingModel('cohere/rerank-v3.5'),
  query: '法国的首都是什么？',
  documents: [
    '巴黎是法国的首都。',
    '柏林是德国的首都。',
    '马德里是西班牙的首都。',
  ],
  topN: 2,
});

console.log(ranking);
// [
//   { originalIndex: 0, score: 0.89, document: '巴黎是法国的首都。' },
//   { originalIndex: 2, score: 0.15, document: '马德里是西班牙的首都。' },
// ]
```

重排序模型对于通过重新评分初始检索步骤后的候选文档来改进检索增强生成 (RAG) 管道中的搜索结果非常有用。

## 实时模型

<Note type="warning">
  实时支持是实验性的，API 可能在补丁版本中发生变化。
</Note>

您可以使用提供商实例上的 `experimental_realtime` 方法创建用于双向音频/文本 WebSocket 会话的实时模型。第一个参数是格式为 `creator/model-name` 的模型 ID：

```ts
import { gateway } from '@ai-sdk/gateway';

const model = gateway.experimental_realtime('openai/gpt-realtime-2');
```

Gateway 对实时模式进行标准化的方式与所有其他模式相同：您的客户端使用[标准化的 AI SDK 实时协议](/docs/ai-sdk-core/realtime)，而 Gateway 则在上游提供商服务器端进行双向转换。这意味着无论哪个提供商支持该模型，相同的客户端代码都能工作。

实时会话在浏览器中运行，并且需要在您的服务器上使用 `gateway.experimental_realtime.getToken()` 创建的短期 Gateway 客户端密钥。该方法使用您的 Gateway 凭据（`apiKey`、`AI_GATEWAY_API_KEY` 或 Vercel OIDC 令牌）来生成一个 `vcst_` 客户端密钥，并返回该模型的 WebSocket URL。

```ts filename='app/api/realtime/setup/route.ts'
import { gateway } from 'ai';

export async function POST() {
  const token = await gateway.experimental_realtime.getToken({
    model: 'openai/gpt-realtime-2',
    expiresAfterSeconds: 60 * 10,
  });

  return Response.json(token);
}
```

在浏览器中使用匹配的 Gateway 实时模型。在浏览器代码中创建模型是安全的；只有 `getToken()` 是服务器端的。

```tsx filename='app/realtime/page.tsx'
'use client';

import { experimental_useRealtime } from '@ai-sdk/react';
import { gateway } from 'ai';

export default function RealtimePage() {
  const realtime = experimental_useRealtime({
    model: gateway.experimental_realtime('openai/gpt-realtime-2'),
    api: {
      token: '/api/realtime/setup',
    },
  });

  // ...
}
```

不要将您的 Gateway API 密钥或 OIDC 令牌暴露给浏览器客户端。仅从 `getToken()` 返回短期设置响应。

<Note>
  Gateway WebSocket 路由通过带版本的 `Sec-WebSocket-Protocol` 子协议传输短期认证令牌，并通过 `?ai-model-id=` 查询参数传输模型 ID——这是 HTTP 路由使用的 `Authorization` 和 `ai-model-id` 请求头的 WebSocket 传输方式。子协议值必须符合 WebSocket 令牌语法，并且完整的 `Sec-WebSocket-Protocol` 请求头应保持紧凑（在 8 KiB 的安全请求头预算内）。
</Note>

### 提供商选项

Gateway [提供商选项](#gateway-提供商选项)——`tags`、`user`、`byok`、合规标志等——在**会话配置**中的 `providerOptions.gateway` 下设置，反映了它们在非实时路由上如何随请求体传递。将它们包含在您发送给 Gateway 的会话配置中，Gateway 会在服务器端应用它们：

```ts
import type { GatewayProviderOptions } from '@ai-sdk/gateway';

const gatewayOptions: GatewayProviderOptions = {
  tags: ['cooking-coach', 'v2'],
  user: 'user-123',
};

const sessionConfig = {
  instructions: '你是一个简洁的语音助手。',
  providerOptions: { gateway: gatewayOptions },
};
```

`GatewayProviderOptions` 类型从 `@ai-sdk/gateway` 导出，用于稳定的客户端字段。该类型还接受服务拥有的选项键，以便 Gateway 服务可以添加或更改服务器端选项，而无需为每个模式更改发布 SDK。运行时验证由 Gateway 服务负责。

<Note>
  提供商选项在套接字打开后的初始会话更新中发送，因此连接时的选项（如 `byok` 和配额选择）需要一个能够从该更新中解析它们的 Gateway。路由控制选项（如 `order` / `only`）不适用于实时模式，因为 Gateway 会选择支持 WebSocket 的提供商。
</Note>

## 可用模型

AI Gateway 支持来自 OpenAI、Anthropic、Google、Meta、xAI、Mistral、DeepSeek、Amazon Bedrock、Cohere、Perplexity、阿里巴巴等提供商的模型。

有关可用模型的完整列表，请参阅 [AI Gateway 文档](https://vercel.com/docs/ai-gateway)。

## 动态模型发现

您可以通过编程方式发现可用模型：

```ts
import { gateway, generateText } from 'ai';

const availableModels = await gateway.getAvailableModels();

// 列出所有可用模型
availableModels.models.forEach(model => {
  console.log(`${model.id}: ${model.name}`);
  if (model.description) {
    console.log(`  描述: ${model.description}`);
  }
  if (model.pricing) {
    console.log(`  输入: $${model.pricing.input}/token`);
    console.log(`  输出: $${model.pricing.output}/token`);
    if (model.pricing.cachedInputTokens) {
      console.log(
        `  缓存输入（读取）: $${model.pricing.cachedInputTokens}/token`,
      );
    }
    if (model.pricing.cacheCreationInputTokens) {
      console.log(
        `  缓存创建（写入）: $${model.pricing.cacheCreationInputTokens}/token`,
      );
    }
  }
});

// 使用纯字符串使用任何发现的模型
const { text } = await generateText({
  model: availableModels.models[0].id, // 例如 'openai/gpt-5.4'
  prompt: 'Hello world',
});
```

## 信用额度使用

您可以检查团队的当前信用余额和使用情况：

```ts
import { gateway } from 'ai';

const credits = await gateway.getCredits();

console.log(`团队余额: ${credits.balance} 信用额度`);
console.log(`团队总使用量: ${credits.total_used} 信用额度`);
```

`getCredits()` 方法根据经过身份验证的 API 密钥或 OIDC 令牌返回您团队的信用信息：

- **balance** _number_ - 您团队当前可用的信用余额
- **total_used** _number_ - 您团队消耗的总信用额度

## 生成查询

通过 ID 查找特定生成的详细信息，包括成本、令牌使用量、延迟和提供商详细信息。生成 ID 可在 `generateText` 和 `streamText` 响应的 `providerMetadata.gateway.generationId` 中获得。

流式传输时，生成 ID 会在第一个内容块中注入，因此您可以在流中尽早捕获它，而无需等待完成。这在网络中断或流中间错误可能阻止您接收最终响应的情况下特别有用——因为 Gateway 在服务器端记录了最终状态，您可以稍后使用生成 ID 通过 `getGenerationInfo()` 查找结果（包括成本、令牌使用量和完成原因）。

```ts
import { gateway, generateText } from 'ai';

// 发起请求
const result = await generateText({
  model: gateway('anthropic/claude-sonnet-4'),
  prompt: '简要解释量子纠缠',
});

// 从提供商元数据中获取生成 ID
const generationId = result.providerMetadata?.gateway?.generationId;

// 查找详细的生成信息
const generation = await gateway.getGenerationInfo({ id: generationId });

console.log(`模型: ${generation.model}`);
console.log(`成本: $${generation.totalCost.toFixed(6)}`);
console.log(`延迟: ${generation.latency}ms`);
console.log(`提示词令牌: ${generation.promptTokens}`);
console.log(`完成令牌: ${generation.completionTokens}`);
```

使用 `streamText`，您可以通过 `stream` 从第一个块中捕获生成 ID：

```ts
import { gateway, streamText } from 'ai';

const result = streamText({
  model: gateway('anthropic/claude-sonnet-4'),
  prompt: '简要解释量子纠缠',
});

let generationId: string | undefined;

for await (const part of result.stream) {
  if (!generationId && part.providerMetadata?.gateway?.generationId) {
    generationId = part.providerMetadata.gateway.generationId as string;
    console.log(`生成 ID（早期）: ${generationId}`);
  }
}

// 流完成后查找成本和用量
if (generationId) {
  const generation = await gateway.getGenerationInfo({ id: generationId });
  console.log(`成本: $${generation.totalCost.toFixed(6)}`);
  console.log(`完成原因: ${generation.finishReason}`);
}
```

`getGenerationInfo()` 方法接受：

- **id** _string_ - 要查找的生成 ID（格式：`gen_<ulid>`，必需）

它返回一个包含以下字段的 `GatewayGenerationInfo` 对象：

- **id** _string_ - 生成 ID
- **totalCost** _number_ - 总成本（美元）
- **upstreamInferenceCost** _number_ - 上游推理成本（美元）（与 BYOK 相关）
- **usage** _number_ - 使用成本（美元）（与 totalCost 相同）
- **createdAt** _string_ - 生成创建的 ISO 8601 时间戳
- **model** _string_ - 使用的模型标识符
- **isByok** _boolean_ - 是否使用了自带密钥凭据
- **providerName** _string_ - 提供此生成的提供商
- **streamed** _boolean_ - 是否使用了流式传输
- **finishReason** _string_ - 完成原因（例如 `'stop'`）
- **latency** _number_ - 到第一个令牌的时间（毫秒）
- **generationTime** _number_ - 总生成时间（毫秒）
- **promptTokens** _number_ - 提示词令牌数量
- **completionTokens** _number_ - 完成令牌数量
- **reasoningTokens** _number_ - 使用的推理令牌（如果适用）
- **cachedTokens** _number_ - 使用的缓存令牌（如果适用）
- **cacheCreationTokens** _number_ - 缓存创建输入令牌
- **billableWebSearchCalls** _number_ - 可计费网络搜索调用次数

## 示例

### 基本文本生成

```ts
import { generateText } from 'ai';

const { text } = await generateText({
  model: 'anthropic/claude-sonnet-4.6',
  prompt: '写一首关于编程的俳句',
});

console.log(text);
```

### 流式传输

```ts
import { streamText } from 'ai';

const { textStream } = await streamText({
  model: 'openai/gpt-5.4',
  prompt: '解释无服务器架构的好处',
});

for await (const textPart of textStream) {
  process.stdout.write(textPart);
}
```

### 工具使用

```ts
import { generateText, tool } from 'ai';
import { z } from 'zod';

const { text } = await generateText({
  model: 'xai/grok-4',
  prompt: '旧金山的天气怎么样？',
  tools: {
    getWeather: tool({
      description: '获取某个位置的当前天气',
      parameters: z.object({
        location: z.string().describe('要获取天气的位置'),
      }),
      execute: async ({ location }) => {
        // 您的天气 API 调用在此处
        return `${location} 天气晴朗`;
      },
    }),
  },
});
```

### 提供商执行的工具

一些提供商提供由其自身执行的工具，例如 [OpenAI 的网络搜索工具](/providers/ai-sdk-providers/openai#web-search-tool)。要通过 AI Gateway 使用这些工具，请导入提供商以访问工具定义：

```ts
import { generateText, isStepCount } from 'ai';
import { openai } from '@ai-sdk/openai';

const result = await generateText({
  model: 'openai/gpt-5.4-mini',
  prompt: '什么是 Vercel AI Gateway？',
  stopWhen: isStepCount(10),
  tools: {
    web_search: openai.tools.webSearch({}),
  },
});

console.dir(result.text);
```

<Note>
  一些提供商执行的工具需要特定于帐户的配置（例如 Claude Agent Skills），并且可能无法通过 AI Gateway 工作。要使用这些工具，您必须直接向提供商提供您自己的密钥 (BYOK)。
</Note>

### Gateway 工具

AI Gateway 提供商包括由 Gateway 本身执行的内置工具。这些工具可以通过 Gateway 与任何模型一起使用。

#### Perplexity 搜索

Perplexity 搜索工具使模型能够使用 [Perplexity 的搜索 API](https://docs.perplexity.ai/guides/search-quickstart) 搜索网络。此工具由 AI Gateway 执行，并返回模型可用于提供最新信息的网络搜索结果。

```ts
import { gateway, generateText } from 'ai';

const result = await generateText({
  model: 'openai/gpt-5.4-nano',
  prompt: '搜索 2025 年 1 月关于 AI 法规的新闻。',
  tools: {
    perplexity_search: gateway.tools.perplexitySearch(),
  },
});

console.log(result.text);
console.log('工具调用:', JSON.stringify(result.toolCalls, null, 2));
console.log('工具结果:', JSON.stringify(result.toolResults, null, 2));
```

您还可以使用可选参数配置搜索：

```ts
import { gateway, generateText } from 'ai';

const result = await generateText({
  model: 'openai/gpt-5.4-nano',
  prompt: '搜索 2025 年 1 月第一周关于 AI 法规的新闻。',
  tools: {
    perplexity_search: gateway.tools.perplexitySearch({
      maxResults: 5,
      searchLanguageFilter: ['en'],
      country: 'US',
      searchDomainFilter: ['reuters.com', 'bbc.com', 'nytimes.com'],
    }),
  },
});

console.log(result.text);
console.log('工具调用:', JSON.stringify(result.toolCalls, null, 2));
console.log('工具结果:', JSON.stringify(result.toolResults, null, 2));
```

Perplexity 搜索工具支持以下可选配置选项：

- **maxResults** _number_

  要返回的最大搜索结果数（1-20，默认：10）。

- **maxTokensPerPage** _number_

  每个搜索结果页面要提取的最大令牌数（256-2048，默认：2048）。

- **maxTokens** _number_

  所有搜索结果中的最大总令牌数（默认：25000，最大：1000000）。

- **searchLanguageFilter** _string[]_

  使用 ISO 639-1 语言代码按语言过滤搜索结果（例如，`['en']` 表示英语，`['en', 'es']` 表示英语和西班牙语）。

- **country** _string_

  使用 ISO 3166-1 alpha-2 国家代码按国家过滤搜索结果（例如，`'US'` 表示美国，`'GB'` 表示英国）。

- **searchDomainFilter** _string[]_

  将搜索结果限制到特定域名（例如，`['reuters.com', 'bbc.com']`）。这对于将结果限制在可信来源非常有用。

- **searchRecencyFilter** _'day' | 'week' | 'month' | 'year'_

  按相对时间段过滤搜索结果。对于始终获取最新结果很有用（例如，'week' 表示过去一周的结果）。

该工具同时适用于 `generateText` 和 `streamText`：

```ts
import { gateway, streamText } from 'ai';

const result = streamText({
  model: 'openai/gpt-5.4-nano',
  prompt: '搜索关于 AI 法规的最新新闻。',
  tools: {
    perplexity_search: gateway.tools.perplexitySearch(),
  },
});

for await (const part of result.stream) {
  switch (part.type) {
    case 'text-delta':
      process.stdout.write(part.text);
      break;
    case 'tool-call':
      console.log('\n工具调用:', JSON.stringify(part, null, 2));
      break;
    case 'tool-result':
      console.log('\n工具结果:', JSON.stringify(part, null, 2));
      break;
  }
}
```

#### Exa 搜索

Exa 搜索工具使模型能够使用 [Exa 的搜索 API](https://exa.ai/docs/reference/search-api-guide-for-coding-agents) 搜索网络。此工具由 AI Gateway 执行，并为智能体工作流返回令牌高效的网络摘录。

```ts
import { gateway, generateText } from 'ai';

const result = await generateText({
  model: 'openai/gpt-5.4-nano',
  prompt: '查找最新的 AI 法规更新并总结关键变化。',
  tools: {
    exa_search: gateway.tools.exaSearch(),
  },
});

console.log(result.text);
console.log('工具调用:', JSON.stringify(result.toolCalls, null, 2));
console.log('工具结果:', JSON.stringify(result.toolResults, null, 2));
```

您还可以使用可选参数配置搜索：

```ts
import { gateway, generateText } from 'ai';

const result = await generateText({
  model: 'openai/gpt-5.4-nano',
  prompt: '从可信来源查找最近的 AI 法规新闻。',
  tools: {
    exa_search: gateway.tools.exaSearch({
      type: 'fast',
      numResults: 5,
      category: 'news',
      includeDomains: ['reuters.com', 'bbc.com', 'nytimes.com'],
      contents: {
        highlights: true,
        maxAgeHours: 24,
      },
    }),
  },
});

console.log(result.text);
console.log('工具调用:', JSON.stringify(result.toolCalls, null, 2));
console.log('工具结果:', JSON.stringify(result.toolResults, null, 2));
```

Exa 搜索工具支持以下可选配置选项：

- **type** _'auto' | 'fast' | 'instant'_

  搜索模式。`'auto'` 是速度和质量的默认平衡。

- **numResults** _number_

  要返回的最大结果数（1-100，默认：10）。

- **category** _'company' | 'people' | 'research paper' | 'news' | 'personal site' | 'financial report'_

  将结果集中在特定的内容类型上。

- **includeDomains** / **excludeDomains** _string[]_

  按域名限制或排除搜索结果。

- **startPublishedDate** / **endPublishedDate** _string_

  按 ISO 8601 发布日期过滤结果。

- **contents** _object_

  控制结果提取和新鲜度：
  - `text` - 返回完整页面文本，可选地使用 `maxCharacters` 限制
  - `highlights` - 返回令牌高效的摘录
  - `maxAgeHours` - 控制缓存内容的新鲜度
  - `livecrawlTimeout` - 实时爬取超时（毫秒）
  - `subpages` / `subpageTarget` - 爬取相关的子页面
  - `extras.links` / `extras.imageLinks` - 从页面提取链接

该工具同时适用于 `generateText` 和 `streamText`。

此初始 Gateway 集成支持 Exa 的普通搜索模式和令牌高效的内容控制。深度合成模式和生成的摘要故意未公开，因为它们与标准搜索有不同的定价。

#### Parallel 搜索

Parallel 搜索工具使模型能够使用 [Parallel AI 的搜索 API](https://docs.parallel.ai/api-reference/search-beta/search) 搜索网络。此工具针对 LLM 消费进行了优化，返回网页的相关摘录，可以用单个调用替换多个关键字搜索。

```ts
import { gateway, generateText } from 'ai';

const result = await generateText({
  model: 'openai/gpt-5.4-nano',
  prompt: '研究量子计算的最新进展。',
  tools: {
    parallel_search: gateway.tools.parallelSearch(),
  },
});

console.log(result.text);
console.log('工具调用:', JSON.stringify(result.toolCalls, null, 2));
console.log('工具结果:', JSON.stringify(result.toolResults, null, 2));
```

您还可以使用可选参数配置搜索：

```ts
import { gateway, generateText } from 'ai';

const result = await generateText({
  model: 'openai/gpt-5.4-nano',
  prompt: '查找关于 TypeScript 5.0 特性的详细信息。',
  tools: {
    parallel_search: gateway.tools.parallelSearch({
      mode: 'agentic',
      maxResults: 5,
      sourcePolicy: {
        includeDomains: ['typescriptlang.org', 'github.com'],
      },
      excerpts: {
        maxCharsPerResult: 8000,
      },
    }),
  },
});

console.log(result.text);
console.log('工具调用:', JSON.stringify(result.toolCalls, null, 2));
console.log('工具结果:', JSON.stringify(result.toolResults, null, 2));
```

Parallel 搜索工具支持以下可选配置选项：

- **mode** _'one-shot' | 'agentic'_

  针对不同用例的模式预设：
  - `'one-shot'` - 为单次回答提供包含较长摘录的全面结果（默认）
  - `'agentic'` - 为多步骤智能体工作流优化的简洁、令牌高效的结果

- **maxResults** _number_

  要返回的最大结果数（1-20）。如果未指定，默认为 10。

- **sourcePolicy** _object_

  用于控制包含/排除哪些域名的来源策略：
  - `includeDomains` - 要包含在搜索结果中的域名列表
  - `excludeDomains` - 要从搜索结果中排除的域名列表
  - `afterDate` - 仅包含在此日期之后发布的结果（ISO 8601 格式）

- **excerpts** _object_

  用于控制结果长度的摘录配置：
  - `maxCharsPerResult` - 每个结果的最大字符数
  - `maxCharsTotal` - 所有结果的最大总字符数

- **fetchPolicy** _object_

  用于控制内容新鲜度的获取策略：
  - `maxAgeSeconds` - 缓存内容的最大年龄（秒）（设置为 0 以始终获取最新内容）

该工具同时适用于 `generateText` 和 `streamText`：

```ts
import { gateway, streamText } from 'ai';

const result = streamText({
  model: 'openai/gpt-5.4-nano',
  prompt: '研究最新的 AI 安全指南。',
  tools: {
    parallel_search: gateway.tools.parallelSearch(),
  },
});

for await (const part of result.stream) {
  switch (part.type) {
    case 'text-delta':
      process.stdout.write(part.text);
      break;
    case 'tool-call':
      console.log('\n工具调用:', JSON.stringify(part, null, 2));
      break;
    case 'tool-result':
      console.log('\n工具结果:', JSON.stringify(part, null, 2));
      break;
  }
}
```

### 自定义报告

使用标签跟踪每个最终用户的用量并对请求进行分类，然后通过报告 API 查询数据。

#### 使用用户和标签进行用量跟踪

```ts
import type { GatewayProviderOptions } from '@ai-sdk/gateway';
import { generateText } from 'ai';

const { text } = await generateText({
  model: 'openai/gpt-5.4',
  prompt: '总结这份文档...',
  providerOptions: {
    gateway: {
      user: 'user-abc-123', // 跟踪此特定最终用户的用量
      tags: ['document-summary', 'premium-feature'], // 为报告进行分类
    } satisfies GatewayProviderOptions,
  },
});
```

这使您可以：

- 在分析中查看按最终用户细分的用量和成本
- 使用标签按功能或用例过滤和分析支出
- 跟踪哪些用户或功能推动了最多的 AI 使用量

#### 查询支出报告

使用 `getSpendReport()` 方法以编程方式查询用量数据。报告 API 仅适用于 Vercel Pro 和 Enterprise 计划。有关定价，请参阅[自定义报告文档](https://vercel.com/docs/ai-gateway/capabilities/custom-reporting)。

```ts
import { gateway } from 'ai';

const report = await gateway.getSpendReport({
  startDate: '2026-03-01',
  endDate: '2026-03-25',
  groupBy: 'model',
});

for (const row of report.results) {
  console.log(`${row.model}: $${row.totalCost.toFixed(4)}`);
}
```

`getSpendReport()` 方法接受以下参数：

- **startDate** _string_ - `YYYY-MM-DD` 格式的开始日期（包含，必需）
- **endDate** _string_ - `YYYY-MM-DD` 格式的结束日期（包含，必需）
- **groupBy** _string_ - 聚合维度：`'day'`（默认）、`'user'`、`'model'`、`'tag'`、`'provider'` 或 `'credential_type'`
- **datePart** _string_ - 当 `groupBy` 为 `'day'` 时的时间粒度：`'day'` 或 `'hour'`
- **userId** _string_ - 过滤到特定用户
- **model** _string_ - 过滤到特定模型（例如 `'anthropic/claude-sonnet-4.5'`）
- **provider** _string_ - 过滤到特定提供商（例如 `'anthropic'`）
- **credentialType** _string_ - 按 `'byok'` 或 `'system'` 凭据过滤
- **tags** _string[]_ - 过滤到匹配这些标签的请求

`results` 中的每一行都包含一个分组字段（与您的 `groupBy` 选择匹配）和指标：

- **totalCost** _number_ - 总成本（美元）
- **marketCost** _number_ - 市场成本（美元）
- **inputTokens** _number_ - 输入令牌数量
- **outputTokens** _number_ - 输出令牌数量
- **cachedInputTokens** _number_ - 缓存输入令牌数量
- **cacheCreationInputTokens** _number_ - 缓存创建输入令牌数量
- **reasoningTokens** _number_ - 推理令牌数量
- **requestCount** _number_ - 请求数量

您可以结合跟踪和查询来分析您定义的标签的支出：

```ts
import type { GatewayProviderOptions } from '@ai-sdk/gateway';
import { gateway, streamText } from 'ai';

// 1. 使用标签发起请求
const result = streamText({
  model: gateway('anthropic/claude-haiku-4.5'),
  prompt: '总结本季度的结果',
  providerOptions: {
    gateway: {
      tags: ['team:finance', 'feature:summaries'],
    } satisfies GatewayProviderOptions,
  },
});

// 2. 稍后，查询按这些标签过滤的支出
const report = await gateway.getSpendReport({
  startDate: '2026-03-01',
  endDate: '2026-03-31',
  groupBy: 'tag',
  tags: ['team:finance'],
});

for (const row of report.results) {
  console.log(`${row.tag}: $${row.totalCost.toFixed(4)} (${row.requestCount} 个请求)`);
}
```

## 提供商选项

AI Gateway 提供商接受控制路由行为和特定于提供商的配置的提供商选项。

### Gateway 提供商选项

您可以在 `providerOptions` 中使用 `gateway` 键来控制 AI Gateway 如何路由请求：

```ts
import type { GatewayProviderOptions } from '@ai-sdk/gateway';
import { generateText } from 'ai';

const { text } = await generateText({
  model: 'anthropic/claude-sonnet-4.6',
  prompt: '解释量子计算',
  providerOptions: {
    gateway: {
      order: ['vertex', 'anthropic'], // 先尝试 Vertex AI，然后是 Anthropic
      only: ['vertex', 'anthropic'], // 仅使用这些提供商
    } satisfies GatewayProviderOptions,
  },
});
```

以下 Gateway 提供商选项可用：

- **order**
