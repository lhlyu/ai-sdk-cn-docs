# Vercel 提供商

[Vercel](https://vercel.com) 提供商使您可以访问 [v0 API](https://v0.app/docs/api/model)，该 API 专为构建现代 Web 应用程序而设计。v0 模型支持文本和图像输入，并提供快速的流式传输响应。

您可以在 [v0.dev](https://v0.dev/chat/settings/keys) 创建您的 Vercel API 密钥。

<Note>
  v0 API 目前处于测试阶段，需要启用按使用量计费的 Premium 或 Team 计划。有关详细信息，请访问[定价页面](https://v0.dev/pricing)。要请求更高的限制，请通过 support@v0.dev 联系 Vercel。
</Note>

## 功能特性

- **框架感知补全**：针对现代技术栈（如 Next.js 和 Vercel）进行评估
- **自动修复**：在生成过程中识别并纠正常见编码问题
- **快速编辑**：在可用时流式传输内联编辑
- **多模态**：支持文本和图像输入

## 设置

Vercel 提供商可通过 `@ai-sdk/vercel` 模块获得。您可以使用以下命令安装：

## 提供商实例

您可以从 `@ai-sdk/vercel` 导入默认提供商实例 `vercel`：

```ts
import { vercel } from '@ai-sdk/vercel';
```

如果您需要自定义设置，可以从 `@ai-sdk/vercel` 导入 `createVercel` 并使用您的设置创建提供商实例：

```ts
import { createVercel } from '@ai-sdk/vercel';

const vercel = createVercel({
  apiKey: process.env.VERCEL_API_KEY ?? '',
});
```

您可以使用以下可选设置来自定义 Vercel 提供商实例：

- **baseURL** _string_

  为 API 调用使用不同的 URL 前缀。默认前缀为 `https://api.v0.dev/v1`。

- **apiKey** _string_

  通过 `Authorization` 标头发送的 API 密钥。默认为 `VERCEL_API_KEY` 环境变量。

- **headers** _Record&lt;string,string&gt;_

  要包含在请求中的自定义标头。

- **fetch** _(input: RequestInfo, init?: RequestInit) => Promise&lt;Response&gt;_

  自定义 [fetch](https://developer.mozilla.org/en-US/docs/Web/API/fetch) 实现。默认为全局 `fetch` 函数。您可以将其用作拦截请求的中间件，或为测试等场景提供自定义 fetch 实现。

## 语言模型

您可以使用提供商实例创建语言模型。第一个参数是模型 ID，例如：

```ts
import { vercel } from '@ai-sdk/vercel';
import { generateText } from 'ai';

const { text } = await generateText({
  model: vercel('v0-1.5-md'),
  prompt: '创建一个 Next.js AI 聊天机器人',
});
```

Vercel 语言模型也可以在 `streamText` 函数中使用（请参阅 [AI SDK Core](/docs/ai-sdk-core)）。

## 模型

### v0-1.5-md

`v0-1.5-md` 模型适用于日常任务和 UI 生成。

### v0-1.5-lg

`v0-1.5-lg` 模型适用于高级思考或推理。

### v0-1.0-md（旧版）

`v0-1.0-md` 模型是 v0 API 提供的旧版模型。

所有 v0 模型均具备以下能力：

- 支持文本和图像输入（多模态）
- 支持函数/工具调用
- 低延迟流式传输响应
- 针对前端和全栈 Web 开发进行了优化
