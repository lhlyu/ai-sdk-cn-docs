# Replicate 提供商

[Replicate](https://replicate.com/) 是一个运行开源 AI 模型的平台。
它是运行图像生成模型的热门选择。

## 安装

Replicate 提供商可通过 `@ai-sdk/replicate` 模块获取。你可以使用以下命令安装它：

<Tabs items={['pnpm', 'npm', 'yarn', 'bun']}>
  <Tab>
    <Snippet text="pnpm add @ai-sdk/replicate" dark />
  </Tab>
  <Tab>
    <Snippet text="npm install @ai-sdk/replicate" dark />
  </Tab>
  <Tab>
    <Snippet text="yarn add @ai-sdk/replicate" dark />
  </Tab>

  <Tab>
    <Snippet text="bun add @ai-sdk/replicate" dark />
  </Tab>
</Tabs>

## 提供商实例

你可以从 `@ai-sdk/replicate` 导入默认提供商实例 `replicate`：

```ts
import { replicate } from '@ai-sdk/replicate';
```

如果你需要自定义设置，可以从 `@ai-sdk/replicate` 导入 `createReplicate`，
并使用你的设置创建提供商实例：

```ts
import { createReplicate } from '@ai-sdk/replicate';

const replicate = createReplicate({
  apiToken: process.env.REPLICATE_API_TOKEN ?? '',
});
```

你可以使用以下可选设置来自定义 Replicate 提供商实例：

- **baseURL** _string_

  为 API 调用使用不同的 URL 前缀，例如使用代理服务器。
  默认前缀是 `https://api.replicate.com/v1`。

- **apiToken** _string_

  通过 `Authorization` 标头发送的 API 令牌。它默认为
  `REPLICATE_API_TOKEN` 环境变量。

- **headers** _Record&lt;string,string&gt;_

  包含在请求中的自定义标头。

- **fetch** _(input: RequestInfo, init?: RequestInit) => Promise&lt;Response&gt;_

  自定义 [fetch](https://developer.mozilla.org/en-US/docs/Web/API/fetch) 实现。

## 图像模型

你可以使用 `.image()` 工厂方法创建 Replicate 图像模型。
有关使用 AI SDK 进行图像生成的更多信息，请参阅 [generateImage()](/docs/reference/ai-sdk-core/generate-image)。

<Note>
  模型对 `size` 和其他参数的支持因模型而异。请查看
  模型在 [Replicate](https://replicate.com/explore) 上的文档，了解
  支持的选项以及可通过 `providerOptions.replicate` 传递的其他参数。
</Note>

### 基本用法

```ts
import { replicate } from '@ai-sdk/replicate';
import { generateImage } from 'ai';
import { writeFile } from 'node:fs/promises';

const { image } = await generateImage({
  model: replicate.image('black-forest-labs/flux-schnell'),
  prompt: 'The Loch Ness Monster getting a manicure',
  aspectRatio: '16:9',
});

await writeFile('image.webp', image.uint8Array);

console.log('Image saved as image.webp');
```

### 模型特定选项

```ts highlight="9-11"
import { replicate, type ReplicateImageModelOptions } from '@ai-sdk/replicate';
import { generateImage } from 'ai';

const { image } = await generateImage({
  model: replicate.image('recraft-ai/recraft-v3'),
  prompt: 'The Loch Ness Monster getting a manicure',
  size: '1365x1024',
  providerOptions: {
    replicate: {
      style: 'realistic_image',
    } satisfies ReplicateImageModelOptions,
  },
});
```

### 版本化模型

import { replicate } from '@ai-sdk/replicate';

const { image } = await generateImage({

### 图像编辑

Replicate 通过各种模型支持图像编辑。通过 `prompt.images` 传递输入图像来转换或编辑现有图像。

#### 基本图像编辑

使用文本提示转换现有图像：

```ts
const imageBuffer = readFileSync('./input-image.png');

const { images } = await generateImage({
  model: replicate.image('black-forest-labs/flux-fill-dev'),
  prompt: {
    text: 'Turn the cat into a golden retriever dog',
    images: [imageBuffer],
  },
  providerOptions: {
    replicate: {
      guidance_scale: 7.5,
      num_inference_steps: 30,
    } satisfies ReplicateImageModelOptions,
  },
});
```

#### 使用遮罩进行修复

使用遮罩编辑图像的特定部分。对于 FLUX Fill 模型，遮罩中的白色区域表示应编辑的图像部分：

```ts
const image = readFileSync('./input-image.png');
const mask = readFileSync('./mask.png'); // 白色 = 修复，黑色 = 保留

const { images } = await generateImage({
  model: replicate.image('black-forest-labs/flux-fill-pro'),
  prompt: {
    text: 'A sunlit indoor lounge area with a pool containing a flamingo',
    images: [image],
    mask: mask,
  },
  providerOptions: {
    replicate: {
      guidance_scale: 7.5,
      num_inference_steps: 30,
    } satisfies ReplicateImageModelOptions,
  },
});
```

#### 多参考图像生成（Flux-2）

Flux-2 模型支持最多 8 张输入参考图像，用于风格迁移、构图和多主体生成：

```ts
import { replicate } from '@ai-sdk/replicate';
import { generateImage } from 'ai';

const reference1 = readFileSync('./style-reference.png');
const reference2 = readFileSync('./subject-reference.png');

const { images } = await generateImage({
  model: replicate.image('black-forest-labs/flux-2-pro'),
  prompt: {
    text: 'Combine the style and subjects from the reference images',
    images: [reference1, reference2],
  },
});
```

<Note>
  Flux-2 模型在内部使用不同的输入格式（`input_image`、
  `input_image_2` 等），这些格式会自动处理。请注意，Flux-2 模型
  不支持基于遮罩的修复。
</Note>

<Note>
  输入图像可以作为 `Buffer`、`ArrayBuffer`、`Uint8Array` 或
  base64 编码的字符串提供。不同的 Replicate 模型具有不同的参数
  名称和功能——请查看模型在
  [Replicate](https://replicate.com/explore) 上的文档以了解详情。
</Note>

### 提供商选项

图像生成的常见提供商选项：

- **maxWaitTimeInSeconds** _number_ - 在同步模式下等待预测完成的最大时间（秒）。默认情况下，Replicate 使用[同步模式](https://replicate.com/docs/topics/predictions/create-a-prediction#timeout-duration)，超时时间为 60 秒。设置为正数以使用自定义持续时间（例如，`120` 表示 2 分钟）。未指定时，使用默认的 60 秒等待时间。
- **guidance_scale** _number_ - 无分类器引导的引导比例。较高的值使输出更接近提示。
- **num_inference_steps** _number_ - 去噪步数。更多步数 = 更高质量但更慢。
- **negative_prompt** _string_ - 负面提示，用于指导生成中应避免的内容。
- **output_format** _'png' | 'jpg' | 'webp'_ - 输出图像格式。
- **output_quality** _number (1-100)_ - 输出图像质量。仅适用于 jpg 和 webp。
- **strength** _number (0-1)_ - 图像到图像转换的强度。较低的值保留更多原始图像。

有关更多详细信息，请参阅 [Replicate 模型页面](https://replicate.com/explore)。
