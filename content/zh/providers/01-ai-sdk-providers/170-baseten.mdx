# Baseten 提供商

[Baseten](https://baseten.co/) 是一个推理平台，通过其 [API](https://docs.baseten.co/overview) 提供前沿、企业级的开源 AI 模型服务。

## 安装

Baseten 提供商可通过 `@ai-sdk/baseten` 模块获取。你可以使用以下命令安装：

<InstallPackages packages="@ai-sdk/baseten" />

## 提供商实例

你可以从 `@ai-sdk/baseten` 导入默认提供商实例 `baseten`：

```ts
import { baseten } from '@ai-sdk/baseten';
```

如果你需要自定义设置，可以从 `@ai-sdk/baseten` 导入 `createBaseten`，并使用你的设置创建提供商实例：

```ts
import { createBaseten } from '@ai-sdk/baseten';

const baseten = createBaseten({
  apiKey: process.env.BASETEN_API_KEY ?? '',
});
```

你可以使用以下可选设置来自定义 Baseten 提供商实例：

- **baseURL** _string_

  为 API 调用使用不同的 URL 前缀，例如使用代理服务器。
  默认前缀为 `https://inference.baseten.co/v1`。

- **apiKey** _string_

  通过 `Authorization` 请求头发送的 API 密钥。默认使用
  `BASETEN_API_KEY` 环境变量。建议你使用 `export` 设置环境变量，这样就不需要每次都包含该字段。
  你可以从[此处](https://app.baseten.co/settings/api_keys)获取你的 Baseten API 密钥。

- **modelURL** _string_

  特定模型（聊天或嵌入）的自定义模型 URL。如果未提供，
  将使用默认的模型 API。

- **headers** _Record&lt;string,string&gt;_

  要包含在请求中的自定义请求头。

- **performanceClient** _PerformanceClient 构造函数_

  选择使用 Baseten 原生的嵌入性能客户端，以实现客户端
  批处理和请求对冲。传入来自
  `@basetenlabs/performance-client` 的 `PerformanceClient` 构造函数，你需要自行安装。如果省略，
  嵌入将使用普通 HTTP。请参阅
  [原生性能客户端](#native-performance-client-optional)。

- **fetch** _(input: RequestInfo, init?: RequestInit) => Promise&lt;Response&gt;_

  自定义 [fetch](https://developer.mozilla.org/en-US/docs/Web/API/fetch) 实现。

## 模型 API

你可以使用提供商实例选择 [Baseten 模型](https://www.baseten.co/products/model-apis/)。
第一个参数是模型 ID，例如 `'moonshotai/Kimi-K2-Instruct-0905'`：模型 API 下支持的完整模型列表可在[此处](https://docs.baseten.co/development/model-apis/overview#supported-models)找到。

```ts
const model = baseten('moonshotai/Kimi-K2-Instruct-0905');
```

### 示例

你可以使用 Baseten 语言模型通过 `generateText` 函数生成文本：

```ts
import { baseten } from '@ai-sdk/baseten';
import { generateText } from 'ai';

const { text } = await generateText({
  model: baseten('moonshotai/Kimi-K2-Instruct-0905'),
  prompt: '生命的意义是什么？用一句话回答。',
});
```

Baseten 语言模型也可以用于 `streamText` 函数
（请参阅 [AI SDK Core](/docs/ai-sdk-core)）。

## 专用模型

Baseten 支持聊天和嵌入模型的专用模型 URL。你需要在创建提供商时指定 `modelURL`：

### OpenAI 兼容端点（`/sync/v1`）

对于使用 Baseten 的 OpenAI 兼容端点部署的模型：

```ts
import { createBaseten } from '@ai-sdk/baseten';

const baseten = createBaseten({
  modelURL: 'https://model-{MODEL_ID}.api.baseten.co/sync/v1',
});
// 由于我们指定了 modelURL，因此不需要 modelId
const model = baseten();
const { text } = await generateText({
  model: model,
  prompt: '从 Baseten 聊天模型打个招呼！',
});
```

### `/predict` 端点

目前**不支持**将 `/predict` 端点用于聊天模型。你必须使用 `/sync/v1` 端点来实现聊天功能。

## 嵌入模型

你可以使用 `.embeddingModel()` 工厂方法创建调用 Baseten 嵌入 API 的模型。Baseten 嵌入推理部署兼容 OpenAI，因此嵌入默认使用普通 HTTP，无需额外依赖。

<Note>
  **重要提示：** 嵌入模型需要具有自定义
  `modelURL` 的专用部署。与聊天模型不同，嵌入无法使用 Baseten 的默认模型
  API，必须指定专用的模型端点。
</Note>

```ts
import { createBaseten } from '@ai-sdk/baseten';
import { embed, embedMany } from 'ai';

const baseten = createBaseten({
  modelURL: 'https://model-{MODEL_ID}.api.baseten.co/sync',
});

const embeddingModel = baseten.embeddingModel();

// 单个嵌入
const { embedding } = await embed({
  model: embeddingModel,
  value: '阳光明媚的海滩日',
});

// 批量嵌入
const { embeddings } = await embedMany({
  model: embeddingModel,
  values: [
    '阳光明媚的海滩日',
    '城市里阴雨绵绵的下午',
    '白雪皑皑的山峰',
  ],
});
```

每个请求最多发送 128 个值。`embedMany` 会将较大的输入拆分为
该大小的块并并行运行，因此你可以传递任意数量的值。

### 嵌入的端点支持

**支持：**

- `/sync` 端点（会自动为你追加 `/v1/embeddings`）
- `/sync/v1` 端点

**不支持：**

- `/predict` 端点

### 原生性能客户端（可选）

Baseten 还发布了 `@basetenlabs/performance-client`，这是一个原生客户端，
在部署已有的服务端动态批处理之上增加了客户端批处理和请求对冲功能。它**不会**默认安装：它是
一个原生插件，因此无法在边缘运行时加载，打包器也无法解析
其平台二进制文件。

要使用它，请自行安装并传入构造函数：

```bash
npm i @basetenlabs/performance-client
```

```ts
import { createBaseten } from '@ai-sdk/baseten';
import { PerformanceClient } from '@basetenlabs/performance-client';

const baseten = createBaseten({
  modelURL:
    'https://model-{MODEL_ID}.api.baseten.co/environments/production/sync',
  performanceClient: PerformanceClient,
});
```

当你选择使用后，客户端会自行处理批处理，因此值会在
单次调用中发送，而不是按 128 个拆分。

## 错误处理

Baseten 提供商包含针对常见 API 错误的内置错误处理：

```ts
import { baseten } from '@ai-sdk/baseten';
import { generateText } from 'ai';

try {
  const { text } = await generateText({
    model: baseten('moonshotai/Kimi-K2-Instruct-0905'),
    prompt: '你好，世界！',
  });
} catch (error) {
  console.error('Baseten API 错误：', error.message);
}
```

### 常见错误场景

```ts
// 嵌入需要 modelURL
try {
  baseten.embeddingModel();
} catch (error) {
  // 错误："No model URL provided for embeddings. Please set modelURL option for embeddings."
}

// /predict 端点不支持聊天模型
try {
  const baseten = createBaseten({
    modelURL:
      'https://model-{MODEL_ID}.api.baseten.co/environments/production/predict',
  });
  baseten(); // 这将抛出错误
} catch (error) {
  // 错误："Not supported. You must use a /sync/v1 endpoint for chat models."
}

// /sync/v1 端点现在支持嵌入
const baseten = createBaseten({
  modelURL:
    'https://model-{MODEL_ID}.api.baseten.co/environments/production/sync/v1',
});
const embeddingModel = baseten.embeddingModel(); // 这可以正常工作！

// /predict 端点不支持嵌入
try {
  const baseten = createBaseten({
    modelURL:
      'https://model-{MODEL_ID}.api.baseten.co/environments/production/predict',
  });
  baseten.embeddingModel(); // 这将抛出错误
} catch (error) {
  // 错误："Not supported. You must use a /sync or /sync/v1 endpoint for embeddings."
}

// 不支持图像模型
try {
  baseten.imageModel('test-model');
} catch (error) {
  // 错误：imageModel 的 NoSuchModelError
}
```
