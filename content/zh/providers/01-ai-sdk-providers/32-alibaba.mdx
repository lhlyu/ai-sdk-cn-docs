# 阿里云提供商

[阿里云百炼平台](https://modelstudio.console.alibabacloud.com/) 提供对通义千问（Qwen）模型系列的访问，包括高级推理能力。

API 密钥可从[控制台](https://modelstudio.console.alibabacloud.com/)获取。

阿里云提供商可通过 `@ai-sdk/alibaba` 模块获取。你可以使用以下命令安装：

## 提供商实例

你可以从 `@ai-sdk/alibaba` 导入默认的提供商实例 `alibaba`：

```ts
import { alibaba } from '@ai-sdk/alibaba';
```

如需自定义配置，可以导入 `createAlibaba` 并使用你的设置创建提供商实例：

```ts
import { createAlibaba } from '@ai-sdk/alibaba';

const alibaba = createAlibaba({
  apiKey: process.env.ALIBABA_API_KEY ?? '',
});
```

你可以使用以下可选设置来自定义阿里云提供商实例：

- **baseURL** _string_

  为 API 调用使用不同的 URL 前缀，例如使用代理服务器或区域端点。
  默认前缀为 `https://dashscope-intl.aliyuncs.com/compatible-mode/v1`。

- **videoBaseURL** _string_

  为视频生成 API 调用使用不同的 URL 前缀。视频 API 使用 DashScope
  原生端点（非 OpenAI 兼容端点）。
  默认前缀为 `https://dashscope-intl.aliyuncs.com`。

- **embeddingBaseURL** _string_

  为嵌入 API 调用使用不同的 URL 前缀。嵌入 API 使用 DashScope
  原生端点（非 OpenAI 兼容端点）。
  默认前缀为 `https://dashscope-intl.aliyuncs.com/api/v1`。

- **apiKey** _string_

  通过 `Authorization` 标头发送的 API 密钥。默认值为
  `ALIBABA_API_KEY` 环境变量。

- **headers** _Record&lt;string,string&gt;_

  要包含在请求中的自定义标头。

- **fetch** _(input: RequestInfo, init?: RequestInit) => Promise&lt;Response&gt;_

  自定义 [fetch](https://developer.mozilla.org/en-US/docs/Web/API/fetch) 实现。

- **includeUsage** _boolean_

  在流式响应中包含使用信息。启用后，令牌使用量将包含在最终块中。
  默认为 `true`。

## 语言模型

你可以使用提供商实例创建语言模型：

```ts
import { alibaba } from '@ai-sdk/alibaba';
import { generateText } from 'ai';

const { text } = await generateText({
  model: alibaba('qwen-plus'),
  prompt: '写一份供4人享用的素食千层面食谱。',
});
```

你也可以使用 `.chatModel()` 或 `.languageModel()` 工厂方法：

```ts
const model = alibaba.chatModel('qwen-plus');
// 或
const model = alibaba.languageModel('qwen-plus');
```

阿里云语言模型可用于 `streamText` 函数
（参见 [AI SDK Core](/docs/ai-sdk-core)）。

阿里云模型提供以下可选提供商选项：

- **enableThinking** _boolean_

  为支持的模型启用思考/推理模式。启用后，模型在生成响应之前会生成推理内容。
  默认为 `false`。

- **thinkingBudget** _number_

  要生成的最大推理令牌数。限制思考内容的长度。

- **parallelToolCalls** _boolean_

  是否在工具使用期间启用并行函数调用。
  默认为 `true`。

### 思考模式

阿里云的通义千问模型支持用于复杂问题解决的思考/推理模式：

```ts
import { alibaba, type AlibabaLanguageModelChatOptions } from '@ai-sdk/alibaba';
import { generateText } from 'ai';

const { text, reasoning } = await generateText({
  model: alibaba('qwen3-max'),
  providerOptions: {
    alibaba: {
      enableThinking: true,
      thinkingBudget: 2048,
    } satisfies AlibabaLanguageModelChatOptions,
  },
  prompt: '"strawberry" 这个单词中有多少个字母 "r"？',
});

console.log('推理过程：', reasoning);
console.log('答案：', text);
```

对于纯思考模型（如 `qwen3-235b-a22b-thinking-2507`），思考模式默认启用。

### 工具调用

阿里云模型支持并行执行的工具调用：

```ts
import { alibaba } from '@ai-sdk/alibaba';
import { generateText, tool } from 'ai';
import { z } from 'zod';

const { text } = await generateText({
  model: alibaba('qwen-plus'),
  tools: {
    weather: tool({
      description: '获取某个位置的天气',
      parameters: z.object({
        location: z.string().describe('要获取天气的位置'),
      }),
      execute: async ({ location }) => ({
        location,
        temperature: 72 + Math.floor(Math.random() * 21) - 10,
      }),
    }),
  },
  prompt: '旧金山的天气怎么样？',
});
```

### 提示词缓存

阿里云支持隐式和显式提示词缓存，以减少重复提示词的成本。

**隐式缓存**自动工作——提供商无需任何配置即可缓存适当的内容。如需更多控制，你可以使用**显式缓存**，通过为特定消息标记 `cacheControl`：

### 单条消息缓存控制

```ts
import { alibaba } from '@ai-sdk/alibaba';
import { generateText } from 'ai';

const { text, usage } = await generateText({
  model: alibaba('qwen-plus'),
  messages: [
    {
      role: 'system',
      content: '你是一个乐于助人的助手。[... 长系统提示词 ...]',
      providerOptions: {
        alibaba: {
          cacheControl: { type: 'ephemeral' },
        },
      },
    },
  ],
});
```

### 多部分消息缓存控制

```ts
import { alibaba } from '@ai-sdk/alibaba';
import { generateText } from 'ai';

const longDocument = '... 大型文档内容 ...';

const { text, usage } = await generateText({
  model: alibaba('qwen-plus'),
  messages: [
    {
      role: 'user',
      content: [
        {
          type: 'text',
          text: '上下文：请分析这份文档。',
        },
        {
          type: 'text',
          text: longDocument,
          providerOptions: {
            alibaba: {
              cacheControl: { type: 'ephemeral' },
            },
          },
        },
      ],
    },
  ],
});
```

**注意：** 缓存块的最小内容长度为 1,024 个令牌。

## 嵌入模型

你可以使用 `.embedding()` 工厂方法创建文本嵌入模型。
有关 AI SDK 中嵌入的更多信息，请参见 [`embed()`](/docs/reference/ai-sdk-core/embed)
和 [`embedMany()`](/docs/reference/ai-sdk-core/embed-many)。

```ts
const model = alibaba.embedding('text-embedding-v4');
```

你可以使用阿里云嵌入模型通过 `embed` 函数生成嵌入：

```ts
import { alibaba, type AlibabaEmbeddingModelOptions } from '@ai-sdk/alibaba';
import { embed } from 'ai';

const { embedding, usage } = await embed({
  model: alibaba.embedding('text-embedding-v4'),
  value: '阳光明媚的海滩日',
  providerOptions: {
    alibaba: {
      textType: 'document',
      dimension: 1024,
      outputType: 'dense',
    } satisfies AlibabaEmbeddingModelOptions,
  },
});
```

使用 `embedMany` 嵌入多个文本值。阿里云文本嵌入模型支持
每次 API 调用最多 10 个值；更大的批次由 `embedMany` 自动拆分。

```ts
import { alibaba, type AlibabaEmbeddingModelOptions } from '@ai-sdk/alibaba';
import { embedMany } from 'ai';

const { embeddings } = await embedMany({
  model: alibaba.embedding('text-embedding-v4'),
  values: [
    '阳光明媚的海滩日',
    '城市里的雨午后',
    '山中的雪夜',
  ],
  providerOptions: {
    alibaba: {
      textType: 'document',
      dimension: 1024,
    } satisfies AlibabaEmbeddingModelOptions,
  },
});
```

阿里云嵌入模型支持可通过 `providerOptions.alibaba` 传递的额外提供商选项：

- **textType** _'query' | 'document'_

  区分查询文本和文档文本，用于非对称检索任务。
  默认为 `document`。

- **dimension** _number_

  输出嵌入向量的维度。默认为 1024。
  `text-embedding-v4` 还支持 1536 和 2048 维度。

- **outputType** _'dense' | 'sparse' | 'dense&sparse'_

  指定输出向量类型。默认为 `dense`。
  AI SDK 嵌入接口返回密集的 `number[]` 向量，因此仅稀疏
  输出不受支持，会抛出错误。使用 `dense&sparse` 可在 `embedding`/`embeddings` 中接收密集
  嵌入，并在 `providerMetadata.alibaba.sparseEmbeddings` 中接收稀疏向量。

### 嵌入模型能力

| 模型                | 默认维度 | 灵活维度                                      | 每次调用最大值 |
| ------------------- | ------- | --------------------------------------------- | -------------- |
| `text-embedding-v4` | 1024    | 64, 128, 256, 512, 768, 1024, 1536, 2048     | 10             |
| `text-embedding-v3` | 1024    | 512, 768, 1024                                | 10             |

<Note>
  上表列出了当前有文档记录的阿里云文本嵌入模型。如有需要，你也可以将任何可用的提供商模型 ID 作为字符串传递。
</Note>

## 视频模型

你可以使用 `.video()` 工厂方法创建调用阿里云 DashScope API 的 [Wan](https://www.alibabacloud.com/help/en/model-studio/use-video-generation) 视频模型。有关 AI SDK 中视频生成的更多信息，请参见 [generateVideo()](/docs/reference/ai-sdk-core/generate-video)。

阿里云支持三种视频生成模式：文本转视频、图像转视频（首帧）和参考转视频。

### 文本转视频

根据文本提示词生成视频：

```ts
import { alibaba, type AlibabaVideoModelOptions } from '@ai-sdk/alibaba';
import { experimental_generateVideo as generateVideo } from 'ai';

const { video } = await generateVideo({
  model: alibaba.video('wan2.6-t2v'),
  prompt: '日落时分宁静的山间湖泊，水面泛起微微涟漪。',
  resolution: '1280x720',
  duration: 5,
  providerOptions: {
    alibaba: {
      promptExtend: true,
      pollTimeoutMs: 600000, // 10 分钟
    } satisfies AlibabaVideoModelOptions,
  },
});
```

### 图像转视频

根据首帧图像和可选的文本提示词生成视频：

```ts
import { alibaba, type AlibabaVideoModelOptions } from '@ai-sdk/alibaba';
import { experimental_generateVideo as generateVideo } from 'ai';

const { video } = await generateVideo({
  model: alibaba.video('wan2.6-i2v'),
  prompt: {
    image: 'https://example.com/landscape.jpg',
    text: '镜头缓慢扫过整个景观',
  },
  duration: 5,
  providerOptions: {
    alibaba: {
      pollTimeoutMs: 600000, // 10 分钟
    } satisfies AlibabaVideoModelOptions,
  },
});
```

你也可以使用顶层的 `frameImages` 选项传递首帧：

```ts
import { alibaba, type AlibabaVideoModelOptions } from '@ai-sdk/alibaba';
import { experimental_generateVideo as generateVideo } from 'ai';

const { video } = await generateVideo({
  model: alibaba.video('wan2.6-i2v'),
  prompt: '镜头缓慢扫过整个景观',
  frameImages: [
    {
      image: 'https://example.com/landscape.jpg',
      frameType: 'first_frame',
    },
  ],
  duration: 5,
  providerOptions: {
    alibaba: {
      pollTimeoutMs: 600000, // 10 分钟
    } satisfies AlibabaVideoModelOptions,
  },
});
```

### 参考转视频

使用参考图像和/或视频生成视频，以保持角色一致性。在提示词中使用角色标识符
（`character1`、`character2` 等）来引用它们：

```ts
import { alibaba, type AlibabaVideoModelOptions } from '@ai-sdk/alibaba';
import { experimental_generateVideo as generateVideo } from 'ai';

const { video } = await generateVideo({
  model: alibaba.video('wan2.6-r2v-flash'),
  prompt: 'character1 走过美丽的花园，并向镜头挥手',
  resolution: '1280x720',
  duration: 5,
  inputReferences: ['https://example.com/character-reference.jpg'],
  providerOptions: {
    alibaba: {
      pollTimeoutMs: 600000, // 10 分钟
    } satisfies AlibabaVideoModelOptions,
  },
});
```

### 视频提供商选项

以下提供商选项可通过 `providerOptions.alibaba` 使用：

- **negativePrompt** _string_

  对生成视频中应避免的内容的描述（最多 500 个字符）。

- **audioUrl** _string_

  用于音视频同步的音频文件 URL（WAV/MP3，3-30 秒，最大 15MB）。

- **promptExtend** _boolean_

  启用提示词扩展/重写以获得更好的生成质量。默认为 `true`。

- **shotType** `'single'` | `'multi'`

  视频生成的镜头类型。`'multi'` 启用多镜头电影叙事（仅限 wan2.6 模型）。

- **watermark** _boolean_

  是否在生成的视频中添加水印。默认为 `false`。

- **audio** _boolean_

  是否生成音频（适用于支持此功能的 I2V 和 R2V 模型）。

- **referenceUrls** _string[]_

  用于参考转视频模式的参考图像/视频 URL 数组。支持 0-5 张图像和 0-3 个视频，总计最多 5 个。
  传递参考图像时，优先使用顶层的 `inputReferences` 选项。

- **pollIntervalMs** _number_

  检查任务状态的轮询间隔（毫秒）。默认为 5000。

- **pollTimeoutMs** _number_

  视频生成的最大等待时间（毫秒）。默认为 600000（10 分钟）。

<Note>
  视频生成是一个异步过程，可能需要几分钟时间。
  建议将 `pollTimeoutMs` 设置为至少 10 分钟（600000 毫秒）以确保可靠运行。
</Note>
