# ByteDance 提供商

[ByteDance](https://www.bytedance.com/) 提供商通过 [BytePlus ModelArk](https://docs.byteplus.com/en/docs/ModelArk/) 平台支持 Seedance 系列视频生成模型和 Seedream 系列图像生成模型。Seedance 提供高质量的文本生成视频和图像生成视频能力，包括音视频同步、首尾帧控制以及多参考图像生成（参见[视频生成 API](https://docs.byteplus.com/en/docs/ModelArk/Video_Generation_API)）。Seedream 提供文本生成图像和图像生成图像能力，包括多图像融合和批量图像生成（参见[图像生成 API](https://docs.byteplus.com/en/docs/ModelArk/1824690)）。

## 设置

ByteDance 提供商通过 `@ai-sdk/bytedance` 模块提供。你可以使用以下命令安装：

<InstallPackages packages="@ai-sdk/bytedance" />

## 提供商实例

你可以从 `@ai-sdk/bytedance` 导入默认提供商实例 `byteDance`：

```ts
import { byteDance } from '@ai-sdk/bytedance';
```

如果你需要自定义设置，可以导入 `createByteDance` 并使用你的设置创建提供商实例：

```ts
import { createByteDance } from '@ai-sdk/bytedance';

const byteDance = createByteDance({
  apiKey: 'your-api-key', // optional, defaults to ARK_API_KEY environment variable
  baseURL: 'custom-url', // optional
  headers: {
    /* custom headers */
  }, // optional
});
```

你可以使用以下可选设置来自定义 ByteDance 提供商实例：

- **baseURL** _string_

  为 API 调用使用不同的 URL 前缀，例如使用代理服务器。
  默认前缀为 `https://ark.ap-southeast.bytepluses.com/api/v3`。

- **apiKey** _string_

  通过 `Authorization` 请求头发送的 API 密钥。
  默认为 `ARK_API_KEY` 环境变量。
  你可以从 BytePlus 控制台[获取 API 密钥](https://console.byteplus.com/ark/apiKey)。

- **headers** _Record&lt;string,string&gt;_

  请求中包含的自定义请求头。

- **fetch** _(input: RequestInfo, init?: RequestInit) => Promise&lt;Response&gt;_

  自定义 [fetch](https://developer.mozilla.org/en-US/docs/Web/API/fetch) 实现。
  你可以将其用作中间件来拦截请求，
  或为测试等场景提供自定义 fetch 实现。

## 图像模型

你可以使用 `.image()` 工厂方法创建 ByteDance Seedream 图像模型。
有关使用 AI SDK 进行图像生成的更多信息，请参阅 [generateImage()](/docs/reference/ai-sdk-core/generate-image)。

### 文本生成图像

根据文本提示词生成图像：

```ts
import { byteDance, type ByteDanceImageModelOptions } from '@ai-sdk/bytedance';
import { generateImage } from 'ai';

const { image } = await generateImage({
  model: byteDance.image('seedream-5-0-260128'),
  prompt: 'A salamander in a forest pond at dusk surrounded by fireflies',
  size: '2048x2048',
  providerOptions: {
    bytedance: {
      watermark: false,
    } satisfies ByteDanceImageModelOptions,
  },
});
```

<Note>
  ByteDance 通过 ModelArk 模型 ID（例如
  `seedream-5-0-260128`）或账户特定的端点 ID（例如 `ep-...`）来标识 Seedream 模型。
  `size` 参数接受像素尺寸（`{width}x{height}`）；分辨率
  级别（如 `2K`）可以通过 `providerOptions.bytedance.size` 传递。
</Note>

### 图像编辑

通过 `prompt.images` 传入输入图像来转换现有图像
（图像生成图像）：

```ts
import { readFileSync } from 'node:fs';
import { byteDance, type ByteDanceImageModelOptions } from '@ai-sdk/bytedance';
import { generateImage } from 'ai';

const inputImage = readFileSync('./input-image.png');

const { image } = await generateImage({
  model: byteDance.image('seedream-5-0-260128'),
  prompt: {
    text: 'Change the salamander to a snow weasel',
    images: [inputImage],
  },
  providerOptions: {
    bytedance: {
      watermark: false,
    } satisfies ByteDanceImageModelOptions,
  },
});
```

你也可以传入多张图像，将多个参考的风格和元素融合到单个输出中
（多图像融合）。图像可以提供为二进制数据、base64 字符串或 URL：

```ts
import { byteDance, type ByteDanceImageModelOptions } from '@ai-sdk/bytedance';
import { generateImage } from 'ai';

const { image } = await generateImage({
  model: byteDance.image('seedream-5-0-260128'),
  prompt: {
    text: 'Replace the clothing in image 1 with the outfit from image 2',
    images: ['https://example.com/model.png', 'https://example.com/outfit.png'],
  },
  providerOptions: {
    bytedance: {
      watermark: false,
    } satisfies ByteDanceImageModelOptions,
  },
});
```

<Note>
  Seedream 不支持基于蒙版的图像修复。请在提示词中描述编辑内容，
  可选地在输入图像上绘制标记（交互式编辑，
  由 `dola-seedream-5-0-pro-260628` 支持）。
</Note>

### 图像模型选项

以下选项可通过 `providerOptions.bytedance` 使用。你可以
使用 `ByteDanceImageModelOptions` 为其添加类型。

- **watermark** _boolean_

  是否在输出图像的右下角添加"AI generated"水印。

- **outputFormat** _'png' | 'jpeg'_

  生成图像文件的格式。由 `seedream-5-0` 和
  `dola-seedream-5-0-pro` 支持；`seedream-4-5` / `seedream-4-0` 始终返回 `jpeg`。

- **size** _string_

  分辨率级别（例如 `1K`、`2K`、`3K`、`4K`），作为通过顶层 `size` 参数
  传递像素尺寸的替代方案。设置后，将覆盖
  顶层 `size`。可用级别因模型而异。

- **sequentialImageGeneration** _'auto' | 'disabled'_

  设置为 `'auto'` 可生成一批相关图像（例如故事板或
  品牌视觉）。默认为 `'disabled'`（单张图像）。

- **maxImages** _number_

  当 `sequentialImageGeneration` 为
  `'auto'` 时要生成的最大图像数量。输入参考图像数量加上生成的图像数量
  不得超过模型的限制。

- **optimizePromptMode** _'standard' | 'fast'_

  提示词优化模式。`seedream-4-0` 同时支持 `standard` 和 `fast`；
  其他模型仅支持 `standard`。

<Note>
  其他 ModelArk 字段也可以通过
  `providerOptions.bytedance` 传递，并由 ModelArk 进行验证。
</Note>

## 视频模型

你可以使用 `.video()` 工厂方法创建 ByteDance 视频模型。
有关使用 AI SDK 进行视频生成的更多信息，请参阅 [generateVideo()](/docs/reference/ai-sdk-core/generate-video)。

### 文本生成视频

根据文本提示词生成视频：

```ts
import { byteDance, type ByteDanceVideoModelOptions } from '@ai-sdk/bytedance';
import { experimental_generateVideo as generateVideo } from 'ai';

const { video } = await generateVideo({
  model: byteDance.video('seedance-1-0-pro-250528'),
  prompt:
    'Photorealistic style: Under a clear blue sky, a vast expanse of white daisy fields stretches out. The camera gradually zooms in and fixates on a close-up of a single daisy.',
  aspectRatio: '16:9',
  duration: 5,
  providerOptions: {
    bytedance: {
      watermark: false,
    } satisfies ByteDanceVideoModelOptions,
  },
});

console.log(video.url);
```

### 图像生成视频

根据首帧图像和可选的文本提示词生成视频：

```ts
import { byteDance, type ByteDanceVideoModelOptions } from '@ai-sdk/bytedance';
import { experimental_generateVideo as generateVideo } from 'ai';

const { video } = await generateVideo({
  model: byteDance.video('seedance-1-5-pro-251215'),
  prompt: {
    image: 'https://example.com/first-frame.png',
    text: 'The cat slowly turns its head and blinks',
  },
  duration: 5,
  providerOptions: {
    bytedance: {
      watermark: false,
    } satisfies ByteDanceVideoModelOptions,
  },
});
```

<Note>
  当输出比例由输入决定时——首帧或
  首尾帧图像生成视频、视频编辑和视频扩展——请传递
  `aspectRatio: 'adaptive'` 或完全省略 `aspectRatio`。较新的 Seedance
  模型在这些路径上拒绝显式比例，因为输出会继承
  输入媒体的比例。
</Note>

### 带音频的图像生成视频

Seedance 1.5 Pro 支持在生成视频的同时生成同步音频：

```ts
import { byteDance, type ByteDanceVideoModelOptions } from '@ai-sdk/bytedance';
import { experimental_generateVideo as generateVideo } from 'ai';

const { video } = await generateVideo({
  model: byteDance.video('seedance-1-5-pro-251215'),
  prompt: {
    image: 'https://example.com/pianist.png',
    text: 'A young man sits at a piano, playing calmly. Gentle piano music plays in sync with his movements.',
  },
  duration: 5,
  providerOptions: {
    bytedance: {
      generateAudio: true,
      watermark: false,
    } satisfies ByteDanceVideoModelOptions,
  },
});
```

### 首尾帧视频

在起始和结束关键帧图像之间生成平滑过渡：

```ts
import { byteDance, type ByteDanceVideoModelOptions } from '@ai-sdk/bytedance';
import { experimental_generateVideo as generateVideo } from 'ai';

const { video } = await generateVideo({
  model: byteDance.video('seedance-1-5-pro-251215'),
  prompt: {
    image: 'https://example.com/first-frame.jpg',
    text: 'Create a 360-degree orbiting camera shot based on this photo',
  },
  duration: 5,
  providerOptions: {
    bytedance: {
      lastFrameImage: 'https://example.com/last-frame.jpg',
      generateAudio: true,
      watermark: false,
    } satisfies ByteDanceVideoModelOptions,
  },
});
```

### 多参考图像生成视频

使用 Seedance 1.0 Lite I2V 模型，你可以提供多张参考图像（1-4 张），模型会使用这些图像忠实地再现物体的形状、颜色和纹理：

```ts
import { byteDance, type ByteDanceVideoModelOptions } from '@ai-sdk/bytedance';
import { experimental_generateVideo as generateVideo } from 'ai';

const { video } = await generateVideo({
  model: byteDance.video('seedance-1-0-lite-i2v-250428'),
  prompt:
    'A boy wearing glasses and a blue T-shirt from [Image 1] and a corgi dog from [Image 2], sitting on the lawn from [Image 3], in 3D cartoon style',
  aspectRatio: '16:9',
  duration: 5,
  providerOptions: {
    bytedance: {
      referenceImages: [
        'https://example.com/boy.png',
        'https://example.com/corgi.png',
        'https://example.com/lawn.png',
      ],
      watermark: false,
    } satisfies ByteDanceVideoModelOptions,
  },
});
```

### 参考视频

Seedance 2.0 支持参考视频，用于指导生成视频的风格、运动或构图：

```ts
import { byteDance, type ByteDanceVideoModelOptions } from '@ai-sdk/bytedance';
import { experimental_generateVideo as generateVideo } from 'ai';

const { video } = await generateVideo({
  model: byteDance.video('dreamina-seedance-2-0-260128'),
  prompt:
    'First-person perspective promotional ad, using the composition and camera movement from the reference video',
  aspectRatio: '16:9',
  duration: 4,
  providerOptions: {
    bytedance: {
      referenceVideos: ['https://example.com/reference-video.mp4'],
      watermark: false,
    } satisfies ByteDanceVideoModelOptions,
  },
});
```

### 参考音频

Seedance 2.0 支持参考音频，用作生成视频的背景音乐或声音：

```ts
import { byteDance, type ByteDanceVideoModelOptions } from '@ai-sdk/bytedance';
import { experimental_generateVideo as generateVideo } from 'ai';

const { video } = await generateVideo({
  model: byteDance.video('dreamina-seedance-2-0-260128'),
  prompt: 'A serene mountain landscape at sunrise with gentle camera movement',
  aspectRatio: '16:9',
  duration: 4,
  providerOptions: {
    bytedance: {
      referenceAudio: ['https://example.com/background-music.mp3'],
      generateAudio: true,
      watermark: false,
    } satisfies ByteDanceVideoModelOptions,
  },
});
```

### 调用方管理的回调

使用 `experimental_startVideo({ model, prompt, webhookUrl })` 注册
应用程序拥有的回调接收器。SDK 会将 `webhookUrl` 作为
`callback_url` 转发，优先于 `providerOptions.bytedance.callback_url`。
当省略 `webhookUrl` 时，原始的 `callback_url` 会原样传递。

[BytePlus 回调协议](https://docs.byteplus.com/en/docs/ModelArk/1520757)
会发送进度通知（`'queued'` 或 `'running'`）以及终态
通知（`'succeeded'`、`'failed'` 或 `'expired'`）。你的接收器必须
过滤进度通知，并将回调与任务关联。使用
`experimental_getVideoStatus(model, { operation })`，传入 `experimental_startVideo`
返回的 operation，以在收到终态通知后检查状态并检索结果。过期的任务会返回错误状态，并附带提供商的
诊断详情。

这些模型有意不暴露 `handleWebhookOption`，因为它们的
回调协议需要能感知进度的接收器。核心
[`generateVideo({ webhook })`](/docs/reference/ai-sdk-core/generate-video)
会回退到轮询，而不调用 webhook 工厂。普通的
`generateVideo()` 也会轮询。Workflow 现有的原生 webhook 能力
检查会拒绝这些直接提供商模型用于基于 webhook 的生成；
请使用显式的启动/状态流程来实现调用方管理的回调。

### 视频模型选项

以下选项可通过 `providerOptions.bytedance` 使用。你可以
使用 `ByteDanceVideoModelOptions` 为其添加类型。

#### 生成选项

- **watermark** _boolean_

  是否在生成的视频中添加水印。

- **generateAudio** _boolean_

  是否为视频生成同步音频。由 Seedance
  1.5 Pro 和 Seedance 2.0 支持。

- **cameraFixed** _boolean_

  是否在生成过程中固定摄像机。

- **returnLastFrame** _boolean_

  是否返回生成视频的最后一帧。用于串联连续视频。

- **serviceTier** _'default' | 'flex'_

  推理层级。`'default'` 用于在线推理。`'flex'` 用于离线推理，价格为 50%，延迟更高（响应时间以小时计）。

- **draft** _boolean_

  启用草稿样本模式以进行低成本预览生成。仅由 Seedance 1.5 Pro 支持。生成 480p 预览视频，用于在提交全质量生成之前快速迭代。

#### 图像输入选项

- **lastFrameImage** _string_

  用于首尾帧视频生成的尾帧图像 URL。模型会在首帧（通过 `image` 提示词提供）和此尾帧之间生成平滑过渡。由 Seedance 1.5 Pro、1.0 Pro 和 1.0 Lite I2V 支持。

- **referenceImages** _string[]_

  用于多参考图像生成视频的参考图像 URL 数组。
  模型会从每张图像中提取关键特征，并在
  视频中再现它们。在提示词中使用 `[Image 1]`、`[Image 2]` 等来引用
  特定图像。

#### 媒体参考选项

- **referenceVideos** _string[]_

  用于参考引导视频生成的参考视频 URL 数组（最多 3 个视频，每个最长 15 秒）。模型使用参考视频来指导风格、运动或构图。由 Seedance 2.0 支持。

- **referenceAudio** _string[]_

  用于音频引导视频生成的参考音频 URL 数组（最多 3 个，每个最长 15 秒）。模型使用参考音频作为背景音乐或同步声音。支持 data URI（例如 `data:audio/wav;base64,...`）。由 Seedance 2.0 支持。

#### 轮询选项

ByteDance 视频生成是基于任务的：提供商创建任务，AI
SDK 轮询任务直到完成。使用 [`generateVideo()`](/docs/reference/ai-sdk-core/generate-video)
的顶层 `poll` 选项配置轮询：

配置的 ByteDance API 源在首次状态请求时受信任，
而每次重定向到其他源时都会在跟随之前进行验证。

```ts
const { video } = await generateVideo({
  model: byteDance.video('seedance-1-0-pro-250528'),
  prompt: 'A futuristic city with flying cars',
  poll: {
    intervalMs: 2000, // how often to check the task (default: 5000)
    timeoutMs: 900000, // give up after 15 minutes (default: 600000)
  },
});
```

<Note>
  `pollIntervalMs` 和 `pollTimeoutMs` 提供商选项已弃用并
  被忽略。传递任一选项都会发出警告。视频生成可能需要数
  分钟，因此对于长时间任务，请将 `poll.timeoutMs` 提高到 10 分钟默认值以上。
</Note>
