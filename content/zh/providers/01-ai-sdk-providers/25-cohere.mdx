# Cohere 提供商

[Cohere](https://cohere.com/) 提供商为 Cohere 聊天 API 提供语言和嵌入模型支持。

## 安装

Cohere 提供商位于 `@ai-sdk/cohere` 模块中。您可以通过以下命令安装：

<InstallPackages packages="@ai-sdk/cohere" />

## 提供商实例

您可以从 `@ai-sdk/cohere` 导入默认的提供商实例 `cohere`：

```ts
import { cohere } from '@ai-sdk/cohere';
```

如果您需要自定义设置，可以从 `@ai-sdk/cohere` 导入 `createCohere` 并使用您的设置创建提供商实例：

```ts
import { createCohere } from '@ai-sdk/cohere';

const cohere = createCohere({
  // 自定义设置
});
```

您可以使用以下可选设置来自定义 Cohere 提供商实例：

- **baseURL** _string_

  为 API 调用使用不同的 URL 前缀，例如使用代理服务器。
  默认前缀为 `https://api.cohere.com/v2`。

- **apiKey** _string_

  通过 `Authorization` 标头发送的 API 密钥。
  默认为 `COHERE_API_KEY` 环境变量。

- **headers** _Record&lt;string,string&gt;_

  要包含在请求中的自定义标头。

- **fetch** _(input: RequestInfo, init?: RequestInit) => Promise&lt;Response&gt;_

  自定义 [fetch](https://developer.mozilla.org/en-US/docs/Web/API/fetch) 实现。
  默认为全局 `fetch` 函数。
  您可以将其用作拦截请求的中间件，
  或为测试等提供自定义 fetch 实现。

- **generateId** _() => string_

  为每个请求生成唯一 ID 的可选函数。
  默认为 SDK 内置的 ID 生成器。

## 语言模型

您可以使用提供商实例创建调用 [Cohere 聊天 API](https://docs.cohere.com/v2/docs/chat-api) 的模型。
第一个参数是模型 ID，例如 `command-r-plus`。
某些 Cohere 聊天模型支持工具调用。

```ts
const model = cohere('command-r-plus');
```

### 示例

您可以使用 Cohere 语言模型通过 `generateText` 函数生成文本：

```ts
import { cohere } from '@ai-sdk/cohere';
import { generateText } from 'ai';

const { text } = await generateText({
  model: cohere('command-r-plus'),
  prompt: '写一份供 4 人食用的素食千层面食谱。',
});
```

Cohere 语言模型也可以在 `streamText` 函数中使用，
并支持通过 [`Output`](/docs/reference/ai-sdk-core/output) 生成结构化数据
（请参阅 [AI SDK Core](/docs/ai-sdk-core)）。

#### 图像输入

支持视觉的 Cohere 模型（例如 `command-a-vision-07-2025`）接受图像输入作为消息内容的一部分。您可以将图像作为原始字节、base64 编码字符串或 URL 传递：

```ts
import { cohere } from '@ai-sdk/cohere';
import { generateText } from 'ai';
import { readFileSync } from 'node:fs';

const { text } = await generateText({
  model: cohere('command-a-vision-07-2025'),
  messages: [
    {
      role: 'user',
      content: [
        { type: 'text', text: '详细描述这张图片。' },
        {
          type: 'file',
          mediaType: 'image',
          data: readFileSync('./data/comic-cat.png'),
        },
      ],
    },
  ],
});
```

您可以在文件部分使用 `cohere` 提供商选项来设置 [图像输入细节](https://docs.cohere.com/docs/image-inputs) 为 `high`、`low` 或 `auto`：

```ts highlight="2,16-18"
import { cohere } from '@ai-sdk/cohere';
import { generateText } from 'ai';

const { text } = await generateText({
  model: cohere('command-a-vision-07-2025'),
  messages: [
    {
      role: 'user',
      content: [
        { type: 'text', text: '详细描述这张图片。' },
        {
          type: 'file',
          mediaType: 'image',
          data: 'https://github.com/vercel/ai/blob/main/examples/ai-functions/data/comic-cat.png?raw=true',

          // Cohere 特定选项 - 图像细节：
          providerOptions: {
            cohere: { detail: 'high' },
          },
        },
      ],
    },
  ],
});
```

#### 推理

Cohere 通过 `command-a-reasoning-08-2025` 模型引入了推理功能。您可以在 https://docs.cohere.com/docs/reasoning 了解更多信息。

```ts
import { cohere, type CohereLanguageModelChatOptions } from '@ai-sdk/cohere';
import { generateText } from 'ai';

async function main() {
  const { text, reasoning } = await generateText({
    model: cohere('command-a-reasoning-08-2025'),
    prompt:
      "爱丽丝有 3 个兄弟，她还有 2 个姐妹。爱丽丝的兄弟有多少个姐妹？",
    // 可选：推理选项
    providerOptions: {
      cohere: {
        thinking: {
          type: 'enabled',
          tokenBudget: 100,
        },
      } satisfies CohereLanguageModelChatOptions,
    },
  });

  console.log(reasoning);
  console.log(text);
}

main().catch(console.error);
```

## 嵌入模型

您可以使用 `.embedding()` 工厂方法创建调用 [Cohere 嵌入 API](https://docs.cohere.com/v2/reference/embed) 的模型。

```ts
const model = cohere.embedding('embed-english-v3.0');
```

您可以使用 Cohere 嵌入模型通过 `embed` 函数生成嵌入：

```ts
import { cohere, type CohereEmbeddingModelOptions } from '@ai-sdk/cohere';
import { embed } from 'ai';

const { embedding } = await embed({
  model: cohere.embedding('embed-english-v3.0'),
  value: '阳光明媚的海滩日',
  providerOptions: {
    cohere: {
      inputType: 'search_document',
    } satisfies CohereEmbeddingModelOptions,
  },
});
```

Cohere 嵌入模型支持通过 `providerOptions.cohere` 传递额外的提供商选项：

```ts
import { cohere, type CohereEmbeddingModelOptions } from '@ai-sdk/cohere';
import { embed } from 'ai';

const { embedding } = await embed({
  model: cohere.embedding('embed-english-v3.0'),
  value: '阳光明媚的海滩日',
  providerOptions: {
    cohere: {
      inputType: 'search_document',
      truncate: 'END',
    } satisfies CohereEmbeddingModelOptions,
  },
});
```

以下提供商选项可用：

- **inputType** _'search_document' | 'search_query' | 'classification' | 'clustering'_

  指定传递给模型的输入类型。默认为 `search_query`。
  - `search_document`：用于存储在向量数据库中用于搜索场景的嵌入。
  - `search_query`：用于针对向量数据库运行以查找相关文档的搜索查询的嵌入。
  - `classification`：用于通过文本分类器传递的嵌入。
  - `clustering`：用于通过聚类算法运行的嵌入。

- **truncate** _'NONE' | 'START' | 'END'_

  指定 API 如何处理超过最大令牌长度的输入。
  默认为 `END`。
  - `NONE`：如果选择，当输入超过最大输入令牌长度时将返回错误。
  - `START`：将丢弃输入的开头，直到剩余输入恰好是模型的最大输入令牌长度。
  - `END`：将丢弃输入的结尾，直到剩余输入恰好是模型的最大输入令牌长度。

## 重排序模型

您可以使用 `.reranking()` 工厂方法创建调用 [Cohere 重排序 API](https://docs.cohere.com/v2/reference/rerank) 的模型。

```ts
const model = cohere.reranking('rerank-v3.5');
```

您可以使用 Cohere 重排序模型通过 `rerank` 函数对文档进行重排序：

```ts
import { cohere } from '@ai-sdk/cohere';
import { rerank } from 'ai';

const documents = [
  '阳光明媚的海滩日',
  '城市里的雨日下午',
  '山里的雪夜',
];

const { ranking } = await rerank({
  model: cohere.reranking('rerank-v3.5'),
  documents,
  query: '谈论下雨',
  topN: 2,
});

console.log(ranking);
// [
//   { originalIndex: 1, score: 0.9, document: '城市里的雨日下午' },
//   { originalIndex: 0, score: 0.3, document: '阳光明媚的海滩日' }
// ]
```

Cohere 重排序模型支持通过 `providerOptions.cohere` 传递额外的提供商选项：

```ts
import { cohere, type CohereRerankingModelOptions } from '@ai-sdk/cohere';
import { rerank } from 'ai';

const { ranking } = await rerank({
  model: cohere.reranking('rerank-v3.5'),
  documents: ['阳光明媚的海滩日', '城市里的雨日下午'],
  query: '谈论下雨',
  providerOptions: {
    cohere: {
      maxTokensPerDoc: 1000,
      priority: 1,
    } satisfies CohereRerankingModelOptions,
  },
});
```

以下提供商选项可用：

- **maxTokensPerDoc** _number_

  每个文档的最大令牌数。默认为 `4096`。

- **priority** _number_

  请求的优先级。默认为 `0`。

### 模型能力

| 模型                         |
| ---------------------------- |
| `rerank-v3.5`                |
| `rerank-english-v3.0`        |
| `rerank-multilingual-v3.0`   |
