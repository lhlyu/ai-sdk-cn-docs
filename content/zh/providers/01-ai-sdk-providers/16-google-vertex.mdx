# Google Vertex 提供商

[AI SDK](/docs) 的 Google Vertex 提供商包含对 [Google Vertex AI](https://cloud.google.com/vertex-ai) API 的语言模型支持。这包括对 [Google 的 Gemini 模型](https://cloud.google.com/vertex-ai/generative-ai/docs/learn/models)、[Anthropic 的 Claude 合作模型](https://cloud.google.com/vertex-ai/generative-ai/docs/partner-models/use-claude)、[xAI 的 Grok 合作模型](https://cloud.google.com/vertex-ai/generative-ai/docs/partner-models/grok)以及 [MaaS（模型即服务）开放模型](https://cloud.google.com/vertex-ai/generative-ai/docs/maas/use-open-models)的支持。
对于其目录中的模型，建议从 [AI Gateway](/providers/ai-sdk-providers/ai-gateway) 开始（推荐），或使用 `@ai-sdk/google-vertex` 直接连接到 Google Vertex AI。

```ts provider="google-vertex" model="google/gemini-4-argon"
import { generateText } from 'ai';
__PROVIDER_IMPORT__;

const { text } = await generateText({
  model: __MODEL__,
  prompt: 'Write a vegetarian lasagna recipe for 4 people.',
  __GATEWAY_OPTIONS__,
});

console.log(text);
```

## 使用 AI Gateway

AI SDK 默认对模型字符串使用 AI Gateway。Gateway 通过单个 API 密钥提供跨提供商的模型访问，并支持用量和成本跟踪。安装 `ai`：

<InstallPackages packages="ai" />

在环境中设置 [AI Gateway API 密钥](https://vercel.com/docs/ai-gateway/getting-started)：

```bash
export AI_GATEWAY_API_KEY=your_api_key_here
```

Vercel 部署也可以使用 [OIDC 身份验证](/providers/ai-sdk-providers/ai-gateway#oidc-authentication-vercel-deployments)。
有关配置，请参阅 [AI Gateway 提供商文档](/providers/ai-sdk-providers/ai-gateway)；有关可用模型，请参阅[模型目录](https://vercel.com/ai-gateway/models)。

该示例将 `providerOptions.gateway.order` 设置为 `['vertex']`。这会将请求首先发送到 Google Vertex AI，如果 Google Vertex AI 不可用或请求失败，则回退到同一模型的其他可用提供商。`order` 设置的是偏好；它不会将回退限制为仅 Google Vertex AI。请参阅[提供商排序](https://vercel.com/docs/ai-gateway/models-and-providers/provider-filtering-and-ordering)。

下拉列表列出了通过 Gateway 由 Google Vertex AI 提供服务的模型，并附有相应的直接提供商示例。提供商可用性取决于模型以及你团队的[提供商允许列表](https://vercel.com/docs/ai-gateway/models-and-providers/provider-filtering-and-ordering)。

Gateway 对 Google Vertex AI 上的 Gemini 使用 `vertex` 路由，并处理 Google Cloud 身份验证。该示例不使用你的 `GOOGLE_VERTEX_PROJECT`、位置或服务账号凭据；请使用直接提供商连接到自己的项目。

## 使用 `@ai-sdk/google-vertex`

要直接访问 Google Vertex AI，请安装 `ai` 和 `@ai-sdk/google-vertex`：

<InstallPackages packages="ai @ai-sdk/google-vertex" />

设置你的 Google Cloud 项目、位置以及服务账号凭据文件的路径：

```bash
export GOOGLE_VERTEX_PROJECT=your_project_id
export GOOGLE_VERTEX_LOCATION=us-central1
export GOOGLE_APPLICATION_CREDENTIALS=/path/to/credentials.json
```

Node.js 提供商使用 Google 应用默认凭据。你也可以在本地使用 `gcloud auth application-default login` 进行身份验证。有关 Edge 和 Express 模式的身份验证，请参阅下面的运行时部分。

对于 Google Cloud 身份验证、Vertex 部署、合作模型或 Vertex 特定 API，请使用直接提供商。Gateway 请求不使用你的项目配置。

<Note>
  以下部分介绍直接 `@ai-sdk/google-vertex` 提供商，包括其模型工厂和设置。Gateway 的模型和功能可用性可能有所不同。
</Note>

<Note>
  Google Vertex 提供商同时兼容 Node.js 和 Edge 运行时。Edge 运行时通过 `@ai-sdk/google-vertex/edge` 子模块提供支持。更多详细信息请参阅下面的 [Google Vertex Edge 运行时](#google-vertex-edge-runtime)、[Google Vertex Anthropic Edge 运行时](#google-vertex-anthropic-edge-runtime)和 [Google Vertex MaaS Edge 运行时](#google-vertex-maas-edge-runtime)部分。
</Note>

## Google Vertex 提供商用法

Google Vertex 提供商实例用于创建调用 Vertex AI API 的模型实例。此提供商可用的模型包括 [Google 的 Gemini 模型](https://cloud.google.com/vertex-ai/generative-ai/docs/learn/models)。如果你想使用 [Anthropic 的 Claude 模型](https://cloud.google.com/vertex-ai/generative-ai/docs/partner-models/use-claude)，请参阅下面的 [Google Vertex Anthropic 提供商](#google-vertex-anthropic-provider-usage)部分。

<Note>
  Vertex Gemini 模型与 Google 提供商共享向前兼容的模型分类。无法识别的 `gemini-*` ID 和 `-latest` 别名使用最新的受支持 Gemini 请求行为，而已知的旧版 ID 保留其特定于代次的工具、推理、函数响应和思考签名处理。所选的 Vertex 模型仍必须支持每个请求的功能。
</Note>

### 提供商实例

你可以从 `@ai-sdk/google-vertex` 导入默认提供商实例 `googleVertex`：

```ts
import { googleVertex } from '@ai-sdk/google-vertex';
```

如果你需要自定义设置，可以从 `@ai-sdk/google-vertex` 导入 `createGoogleVertex`，并使用你的设置创建提供商实例：

```ts
import { createGoogleVertex } from '@ai-sdk/google-vertex';

const googleVertex = createGoogleVertex({
  project: 'my-project', // optional
  location: 'us-central1', // optional
});
```

Google Vertex 根据你的运行时环境和需求支持多种身份验证方法。

#### Node.js 运行时

Node.js 运行时是 AI SDK 支持的默认运行时。它通过 [`google-auth-library`](https://github.com/googleapis/google-auth-library-nodejs?tab=readme-ov-file#ways-to-authenticate) 支持所有标准 Google Cloud 身份验证选项。典型用法是在 `GOOGLE_APPLICATION_CREDENTIALS` 环境变量中设置 JSON 凭据文件的路径。凭据文件可以从 [Google Cloud 控制台](https://console.cloud.google.com/apis/credentials)获取。

如果你想自定义 Google 身份验证选项，可以将它们作为选项传递给 `createGoogleVertex` 函数，例如：

```ts
import { createGoogleVertex } from '@ai-sdk/google-vertex';

const googleVertex = createGoogleVertex({
  googleAuthOptions: {
    credentials: {
      client_email: 'my-email',
      private_key: 'my-private-key',
    },
  },
});
```

##### 可选的提供商设置

你可以使用以下可选设置来自定义提供商实例：

- **project** _string_

  你希望用于 API 调用的 Google Cloud 项目 ID。
  默认使用 `GOOGLE_VERTEX_PROJECT` 环境变量。

- **location** _string_

  你希望用于 API 调用的 Google Cloud 位置，例如 `us-central1`。
  默认使用 `GOOGLE_VERTEX_LOCATION` 环境变量。

- **googleAuthOptions** _object_

  可选。[Google Auth Library](https://github.com/googleapis/google-auth-library-nodejs/) 使用的身份验证选项。另请参阅 [GoogleAuthOptions](https://github.com/googleapis/google-auth-library-nodejs/blob/08978822e1b7b5961f0e355df51d738e012be392/src/auth/googleauth.ts#L87C18-L87C35) 接口。
  - **authClient** _object_
    要使用的 `AuthClient`。

  - **keyFilename** _string_
    .json、.pem 或 .p12 密钥文件的路径。

  - **keyFile** _string_
    .json、.pem 或 .p12 密钥文件的路径。

  - **credentials** _object_
    包含 client_email 和 private_key 属性的对象，或外部账号客户端选项。

  - **clientOptions** _object_
    传递给客户端构造函数的选项对象。

  - **scopes** _string | string[]_
    所需 API 请求所需的作用域。

  - **projectId** _string_
    你的项目 ID。

  - **universeDomain** _string_
    给定 Cloud universe 的默认服务域。

- **headers** _Resolvable&lt;Record&lt;string, string | undefined&gt;&gt;_

  要包含在请求中的标头。可以通过多种格式提供：
  - 标头键值对记录：`Record<string, string | undefined>`
  - 返回标头的函数：`() => Record<string, string | undefined>`
  - 返回标头的异步函数：`async () => Record<string, string | undefined>`
  - 解析为标头的 Promise：`Promise<Record<string, string | undefined>>`

- **fetch** _(input: RequestInfo, init?: RequestInit) => Promise&lt;Response&gt;_

  自定义 [fetch](https://developer.mozilla.org/en-US/docs/Web/API/fetch) 实现。
  默认为全局 `fetch` 函数。
  你可以将其用作中间件来拦截请求，
  或为例如测试提供自定义 fetch 实现。

- **baseURL** _string_

  可选。Google Vertex API 调用的基础 URL，例如用于代理服务器。默认情况下，它使用位置和项目构造：
  `https://${location}-aiplatform.googleapis.com/v1/projects/${project}/locations/${location}/publishers/google`

- **toolResultDownloads** _object_

  在将工具结果中的远程文件作为内联数据发送到 Vertex 之前，下载这些文件的设置。
  对于 Gemini 3 及更高版本的模型，受支持的 Google Cloud Storage URL 会直接转发。
  有关支持的 MIME 类型，请参阅[工具结果文件](#tool-result-files)。
  - **maxBytes** _number_

    每个下载文件的最大字节数。默认为 7 MiB。

<a id="google-vertex-edge-runtime"></a>
#### Edge 运行时

Edge 运行时（如 Cloudflare Workers）是轻量级 JavaScript 环境，在网络边缘更靠近用户运行。它们仅提供标准 Node.js API 的子集。
例如，无法直接访问文件系统，并且许多 Node.js 专用库
（包括标准 Google Auth 库）不兼容。

Google Vertex 提供商的 Edge 运行时版本通过环境变量支持 Google 的[应用默认凭据](https://github.com/googleapis/google-auth-library-nodejs?tab=readme-ov-file#application-default-credentials)。这些值可以从 [Google Cloud 控制台](https://console.cloud.google.com/apis/credentials)的 JSON 凭据文件中获取。

你可以从 `@ai-sdk/google-vertex/edge` 导入默认提供商实例 `googleVertex`：

```ts
import { googleVertex } from '@ai-sdk/google-vertex/edge';
```

<Note>
  `/edge` 子模块包含在 `@ai-sdk/google-vertex` 包中，因此你无需单独安装。你必须从 `@ai-sdk/google-vertex/edge` 导入，以将其与 Node.js 提供商区分开。
</Note>

如果你需要自定义设置，可以从 `@ai-sdk/google-vertex/edge` 导入 `createGoogleVertex`，并使用你的设置创建提供商实例：

```ts
import { createGoogleVertex } from '@ai-sdk/google-vertex/edge';

const googleVertex = createGoogleVertex({
  project: 'my-project', // optional
  location: 'us-central1', // optional
});
```

对于 Edge 运行时身份验证，你需要从 Google 默认应用凭据 JSON 文件中设置以下环境变量：

- `GOOGLE_CLIENT_EMAIL`
- `GOOGLE_PRIVATE_KEY`
- `GOOGLE_PRIVATE_KEY_ID`（可选）

这些值可以从 [Google Cloud 控制台](https://console.cloud.google.com/apis/credentials)的服务账号 JSON 文件中获取。

##### 可选的提供商设置

你可以使用以下可选设置来自定义提供商实例：

- **project** _string_

  你希望用于 API 调用的 Google Cloud 项目 ID。
  默认使用 `GOOGLE_VERTEX_PROJECT` 环境变量。

- **location** _string_

  你希望用于 API 调用的 Google Cloud 位置，例如 `us-central1`。
  默认使用 `GOOGLE_VERTEX_LOCATION` 环境变量。

- **googleCredentials** _object_

  可选。Edge 提供商用于身份验证的凭据。这些凭据通常通过环境变量设置，并源自服务账号 JSON 文件。
  - **clientEmail** _string_
    服务账号 JSON 文件中的客户端电子邮件。默认为 `GOOGLE_CLIENT_EMAIL` 环境变量的内容。

  - **privateKey** _string_
    服务账号 JSON 文件中的私钥。默认为 `GOOGLE_PRIVATE_KEY` 环境变量的内容。

  - **privateKeyId** _string_
    服务账号 JSON 文件中的私钥 ID（可选）。默认为 `GOOGLE_PRIVATE_KEY_ID` 环境变量的内容。

- **headers** _Resolvable&lt;Record&lt;string, string | undefined&gt;&gt;_

  要包含在请求中的标头。可以通过多种格式提供：
  - 标头键值对记录：`Record<string, string | undefined>`
  - 返回标头的函数：`() => Record<string, string | undefined>`
  - 返回标头的异步函数：`async () => Record<string, string | undefined>`
  - 解析为标头的 Promise：`Promise<Record<string, string | undefined>>`

- **fetch** _(input: RequestInfo, init?: RequestInit) => Promise&lt;Response&gt;_

  自定义 [fetch](https://developer.mozilla.org/en-US/docs/Web/API/fetch) 实现。
  默认为全局 `fetch` 函数。
  你可以将其用作中间件来拦截请求，
  或为例如测试提供自定义 fetch 实现。

#### Express 模式

Express 模式提供了一种简化的身份验证方法，使用 API 密钥而不是 OAuth 或服务账号凭据。使用 Express 模式时，不需要 `project` 和 `location` 设置。

```ts
import { createGoogleVertex } from '@ai-sdk/google-vertex';

const googleVertex = createGoogleVertex({
  apiKey: process.env.GOOGLE_VERTEX_API_KEY,
});
```

##### 可选的提供商设置

- **apiKey** _string_

  Google Vertex AI 的 API 密钥。提供后，提供商将使用带 API 密钥身份验证的 Express 模式，而不是 OAuth。
  默认使用 `GOOGLE_VERTEX_API_KEY` 环境变量。

### 语言模型

你可以使用提供商实例创建调用 Vertex API 的模型。
第一个参数是模型 ID，例如 `gemini-3.8-flash`。

```ts
const model = googleVertex('gemini-3.8-flash');
```

<Note>
  如果你使用[自己的模型](https://cloud.google.com/vertex-ai/docs/training-overview)，模型名称需要以 `projects/` 开头。
</Note>

Google Vertex 模型还支持一些不属于[标准调用设置](/docs/ai-sdk-core/settings)的模型特定设置。你可以将它们作为选项参数传递：

```ts
import { googleVertex } from '@ai-sdk/google-vertex';
import { type GoogleLanguageModelOptions } from '@ai-sdk/google';

const model = googleVertex('gemini-3.1-pro-preview');

await generateText({
  model,
  providerOptions: {
    vertex: {
      safetySettings: [
        {
          category: 'HARM_CATEGORY_UNSPECIFIED',
          threshold: 'BLOCK_LOW_AND_ABOVE',
        },
      ],
    } satisfies GoogleLanguageModelOptions,
  },
});
```

Google Vertex 模型可使用以下可选提供商选项：

- **cachedContent** _string_

  可选。用作上下文以服务预测的缓存内容名称。
  格式：projects/\{project\}/locations/\{location\}/cachedContents/\{cachedContent\}

- **structuredOutputs** _boolean_

  可选。启用结构化输出。默认为 true。

  当 JSON Schema 包含 Google Vertex 使用的 OpenAPI schema 版本不支持的元素时，这很有用。如果需要，你可以使用它来禁用结构化输出。

  有关更多详细信息，请参阅[故障排除：Schema 限制](#schema-limitations)。

- **safetySettings** _Array\<\{ category: string; threshold: string \}\>_

  可选。模型的安全设置。
  - **category** _string_

    安全设置的类别。可以是以下之一：
    - `HARM_CATEGORY_UNSPECIFIED`
    - `HARM_CATEGORY_HATE_SPEECH`
    - `HARM_CATEGORY_DANGEROUS_CONTENT`
    - `HARM_CATEGORY_HARASSMENT`
    - `HARM_CATEGORY_SEXUALLY_EXPLICIT`
    - `HARM_CATEGORY_CIVIC_INTEGRITY`

  - **threshold** _string_

    安全设置的阈值。可以是以下之一：
    - `HARM_BLOCK_THRESHOLD_UNSPECIFIED`
    - `BLOCK_LOW_AND_ABOVE`
    - `BLOCK_MEDIUM_AND_ABOVE`
    - `BLOCK_ONLY_HIGH`
    - `BLOCK_NONE`

- **audioTimestamp** _boolean_

  可选。启用音频文件的时间戳理解。默认为 false。

  这对于生成带有准确时间戳的转录文本很有用。
  有关用法详细信息，请参阅 [Google 的文档](https://cloud.google.com/vertex-ai/generative-ai/docs/multimodal/audio-understanding)。

- **labels** _object_

  可选。定义计费报告中使用的标签。

  有关用法详细信息，请参阅 [Google 的文档](https://cloud.google.com/vertex-ai/generative-ai/docs/multimodal/add-labels-to-api-calls)。

- **imageConfig** _object_

  可选。图像生成配置。仅受 Gemini 图像模型支持。

  有关用法详细信息，请参阅 [Google 的 GenerationConfig 文档](https://docs.cloud.google.com/vertex-ai/generative-ai/docs/reference/rest/v1/GenerationConfig)。
  - **aspectRatio** _string_

    可选。生成图像的宽高比。默认为 1:1 正方形，或将输出图像尺寸匹配到输入图像尺寸。可以是以下之一：
    - 1:1
    - 2:3
    - 3:2
    - 3:4
    - 4:3
    - 4:5
    - 5:4
    - 9:16
    - 16:9
    - 21:9

  - **imageSize** _string_

    可选。控制输出图像分辨率。默认为 1K。可以是以下之一：
    - 1K
    - 2K
    - 4K

  - **personGeneration** _string_

    可选。控制图像中人物的生成。可以是以下之一：
    - `PERSON_GENERATION_UNSPECIFIED`
    - `ALLOW_ALL`
    - `ALLOW_ADULT`
    - `ALLOW_NONE`

  - **prominentPeople** _string_

    可选。控制是否允许生成知名人物（名人）。当与 `personGeneration` 一起设置时，`personGeneration` 优先。可以是以下之一：
    - `PROMINENT_PEOPLE_UNSPECIFIED`
    - `ALLOW_PROMINENT_PEOPLE`
    - `BLOCK_PROMINENT_PEOPLE`

  - **imageOutputOptions** _\{ mimeType?: 'image/jpeg' | 'image/png', compressionQuality?: number \}_

    可选。生成图像的图像输出格式。

- **streamFunctionCallArguments** _boolean_

  可选。设置为 true 时，函数调用参数将在流式响应中增量流式传输。这使 `tool-input-delta` 事件能够在模型生成函数调用参数时到达，从而减少工具调用的感知延迟。默认为 `false`。仅在 Vertex AI API（而非 Gemini API）上受支持，且需要 Gemini 3+ 模型。

  有关详细信息，请参阅 [Google 的文档](https://docs.cloud.google.com/vertex-ai/generative-ai/docs/multimodal/function-calling#streaming-fc)。

- **sharedRequestType** _'priority' | 'flex' | 'standard'_

  可选。通过设置 `X-Vertex-AI-LLM-Shared-Request-Type` 请求标头来选择按需付费（PayGo）层级。使用 `'priority'` 以溢价获得一致的低延迟性能，或使用 `'flex'` 获得 50% 折扣但预期延迟更长。两者仅在 `global` 端点和部分 Gemini 模型上受支持。

  默认情况下——已分配预配吞吐量且未设置 `requestType` 时——请求首先消耗预配吞吐量配额，仅在 PT 容量耗尽时才回退到所选的共享层级。要完全绕过预配吞吐量，还需设置 `requestType: 'shared'`。

  实际服务的层级会通过 `result.providerMetadata.googleVertex.usageMetadata.trafficType` 报告为 `ON_DEMAND_PRIORITY`、`ON_DEMAND_FLEX`，或（如果在负载下降级）普通的 `ON_DEMAND`。

  有关支持的模型、爬坡限制和降级行为，请参阅 [Priority PayGo](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/priority-paygo) 和 [Flex PayGo](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/flex-paygo)。

- **requestType** _'shared'_

  可选。设置 `X-Vertex-AI-LLM-Request-Type` 请求标头。与 `sharedRequestType` 结合使用可完全跳过预配吞吐量，并通过共享 PayGo 容量路由请求。请参阅 [Priority PayGo](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/priority-paygo)。

你可以使用 Google Vertex 语言模型通过 `generateText` 函数生成文本：

```ts highlight="1,4"
import { googleVertex } from '@ai-sdk/google-vertex';
import { generateText } from 'ai';

const { text } = await generateText({
  model: googleVertex('gemini-3.1-pro-preview'),
  prompt: 'Write a vegetarian lasagna recipe for 4 people.',
});
```

Google Vertex 语言模型也可以在 `streamText` 函数中使用
（请参阅 [AI SDK Core](/docs/ai-sdk-core)）。

#### 调优模型

[调优模型](https://cloud.google.com/vertex-ai/generative-ai/docs/deploy/overview)
从已部署的端点提供服务，并通过其端点 ID 而不是已发布的模型名称来寻址。使用 `endpoints/` 前缀传递端点资源，提供商将把请求路由到已部署的端点
（`.../locations/{location}/endpoints/{ENDPOINT_ID}`），而不是基础模型路径（`.../publishers/google/models/{MODEL_ID}`）：

```ts
import { googleVertex } from '@ai-sdk/google-vertex';
import { generateText } from 'ai';

const { text } = await generateText({
  model: googleVertex('endpoints/YOUR_ENDPOINT_ID'),
  prompt: 'Write a vegetarian lasagna recipe for 4 people.',
});
```

使用已部署的**端点** ID，而不是调优模型 ID（调优模型同时具有 `models/...` 资源和单独的 `endpoints/...` 资源；只有端点可用于推理调用）。请求和响应格式与基础模型相同，因此所有标准调用设置和提供商选项继续有效。

<Note>
  调优模型需要标准 Google Cloud 凭据以及已部署端点的项目/位置（通过 `GOOGLE_VERTEX_PROJECT` / `GOOGLE_VERTEX_LOCATION` 或 `createGoogleVertex`）。调优模型不支持 [Express 模式](#express-mode) API 密钥。
</Note>

#### 代码执行

借助[代码执行](https://cloud.google.com/vertex-ai/generative-ai/docs/multimodal/code-execution)，Vertex AI 上的某些 Gemini 模型可以生成并执行 Python 代码。这允许模型执行计算、数据操作和其他编程任务，以增强其响应。

你可以通过向请求添加 `code_execution` 工具来启用代码执行。

```ts
import { googleVertex } from '@ai-sdk/google-vertex';
import { generateText } from 'ai';

const result = await generateText({
  model: googleVertex('gemini-3.1-pro-preview'),
  tools: { code_execution: googleVertex.tools.codeExecution({}) },
  prompt:
    'Use python to calculate 20th fibonacci number. Then find the nearest palindrome to it.',
});
```

响应将包含已执行代码的 `tool-call` 和 `tool-result` 部分。

#### 流式函数调用参数

对于 Vertex AI 上的 Gemini 3 Pro 及更高版本模型，你可以通过将 `streamFunctionCallArguments` 设置为 `true`，在函数调用参数生成时进行流式传输。这减少了需要调用函数时的感知延迟，因为 `tool-input-delta` 事件会增量到达，而不是等待完整参数。此选项默认为 `false`。

```ts
import { googleVertex } from '@ai-sdk/google-vertex';
import { type GoogleLanguageModelOptions } from '@ai-sdk/google';
import { streamText } from 'ai';
import { z } from 'zod';

const result = streamText({
  model: googleVertex('gemini-3.1-pro-preview'),
  prompt: 'What is the weather in Boston and San Francisco?',
  tools: {
    getWeather: {
      description: 'Get the current weather in a given location',
      inputSchema: z.object({
        location: z.string().describe('City name'),
      }),
    },
  },
  providerOptions: {
    vertex: {
      streamFunctionCallArguments: true,
    } satisfies GoogleLanguageModelOptions,
  },
});

for await (const part of result.stream) {
  switch (part.type) {
    case 'tool-input-start':
      console.log(`Tool call started: ${part.toolName}`);
      break;
    case 'tool-input-delta':
      process.stdout.write(part.delta);
      break;
    case 'tool-call':
      console.log(`Tool call complete: ${part.toolName}`, part.input);
      break;
  }
}
```

<Note>
  此功能仅在 Vertex AI API 上可用。Gemini API 不支持此功能。与 Google 提供商一起使用时，将发出警告并忽略该选项。
</Note>

#### 推理（思考令牌）

Google Vertex AI 通过其对 Gemini 模型的支持，还可以发出表示模型推理过程的“思考”令牌。AI SDK 将这些作为推理信息暴露。

要通过 Vertex 为兼容的 Gemini 模型启用思考令牌，请在 `thinkingConfig` 提供商选项中设置 `includeThoughts: true`。这些选项通过 `providerOptions.vertex` 传递：

```ts
import { googleVertex } from '@ai-sdk/google-vertex';
import { type GoogleLanguageModelOptions } from '@ai-sdk/google';
import { generateText, streamText } from 'ai';

// For generateText:
const { text, reasoningText, reasoning } = await generateText({
  model: googleVertex('gemini-3.8-flash'), // Or other supported model via Vertex
  providerOptions: {
    vertex: {
      thinkingConfig: {
        includeThoughts: true,
        // thinkingLevel: 'high', // Optional
      },
    } satisfies GoogleLanguageModelOptions,
  },
  prompt: 'Explain quantum computing in simple terms.',
});

console.log('Reasoning:', reasoningText);
console.log('Reasoning Details:', reasoning);
console.log('Final Text:', text);

// For streamText:
const result = streamText({
  model: googleVertex('gemini-3.8-flash'), // Or other supported model via Vertex
  providerOptions: {
    vertex: {
      thinkingConfig: {
        includeThoughts: true,
        // thinkingLevel: 'high', // Optional
      },
    } satisfies GoogleLanguageModelOptions,
  },
  prompt: 'Explain quantum computing in simple terms.',
});

for await (const part of result.stream) {
  if (part.type === 'reasoning') {
    process.stdout.write(`THOUGHT: ${part.textDelta}\n`);
  } else if (part.type === 'text-delta') {
    process.stdout.write(part.textDelta);
  }
}
```

当 `includeThoughts` 为 true 时，API 响应中标记为 `thought: true` 的部分将被处理为推理。

- 在 `generateText` 中，这些内容会贡献到 `reasoningText`（字符串）和 `reasoning`（数组）字段。
- 在 `streamText` 中，这些内容会作为 `reasoning` 流部分发出。

<Note>
  有关模型兼容性和更多详细信息，请参阅 [Google Vertex AI 关于“思考”的文档](https://cloud.google.com/vertex-ai/generative-ai/docs/thinking)。
</Note>

### 长解码

`gemini-4-argon` 等 Gemini 4 模型在 Vertex AI 上支持长解码，方式与 Gemini API 相同：将 `maxOutputTokens` 设置为高于每请求上限（最高 1M 减去输入），提供商将自动继续响应。有关预算、跨请求用量以及使用延续令牌恢复的详细信息，请参阅[长解码](/providers/ai-sdk-providers/google#long-decode)。

Vertex AI Interactions API（预览版）不支持长解码。

### 工具结果文件

对于 Gemini 3 及更高版本的模型，工具结果可以包含 Google Cloud Storage（`gs://`）文件 URL。Vertex 会直接将这些引用作为 `functionResponse.parts[].fileData` 接收，而不会将文件下载到 SDK 进程中。支持的 MIME 类型为 `image/png`、`image/jpeg`、`image/webp`、`application/pdf` 和 `text/plain`。请指定完整的 MIME 类型；像 `image` 这样的顶级类型不足以用于 GCS 工具结果。

在工具的 `toModelOutput` 结果中使用文件部分：

```ts
toModelOutput: ({ output }) => ({
  type: 'content',
  value: [
    {
      type: 'file',
      mediaType: 'image/png',
      data: {
        type: 'url',
        url: new URL(output.gcsUri),
        originalUrl: output.gcsUri,
      },
    },
  ],
}),
```

当 URL 解析会改变不透明的 GCS URI（例如包含空格的路径）时，请包含 `originalUrl`，以便 Vertex 接收到确切的对象引用。Vertex 调用方必须有权访问所引用的对象。

HTTP(S) 工具结果文件会被下载并作为内联数据发送，受 `toolResultDownloads.maxBytes` 限制。较旧的 Gemini 模型或上述列表之外的 MIME 类型不支持直接转发 GCS 工具结果。

### 缓存内容

Google Vertex AI 支持显式和隐式缓存，以帮助降低重复内容的成本。

#### 隐式缓存

```ts
import { googleVertex } from '@ai-sdk/google-vertex';
import { generateText } from 'ai';

// Structure prompts with consistent content at the beginning
const baseContext =
  'You are a cooking assistant with expertise in Italian cuisine. Here are 1000 lasagna recipes for reference...';

// Second request with same prefix - eligible for cache hit
const { text: meatLasagna, providerMetadata } = await generateText({
  model: googleVertex('gemini-3.1-pro-preview'),

// Check cached token count in usage metadata
console.log('Cached tokens:', providerMetadata.vertex);
// e.g.
// {
//   groundingMetadata: null,
//   safetyRatings: null,
//   usageMetadata: {
//     cachedContentTokenCount: 2027,
//     thoughtsTokenCount: 702,
//     promptTokenCount: 2152,
//     candidatesTokenCount: 710,
//     totalTokenCount: 3564
//   }
// }
```

#### 显式缓存

你可以对 Gemini 模型使用显式缓存。请参阅 [Vertex AI 上下文缓存文档](https://cloud.google.com/vertex-ai/generative-ai/docs/context-cache/context-cache-overview)，以检查你的模型是否支持缓存。

首先，使用启用 Vertex 模式的 Google GenAI SDK 创建缓存：

```ts
import { GoogleGenAI } from '@google/genai';

const ai = new GoogleGenAI({
  vertexai: true,
  project: process.env.GOOGLE_VERTEX_PROJECT,
  location: process.env.GOOGLE_VERTEX_LOCATION,
});

const model = 'gemini-3.1-pro-preview';

// Create a cache with the content you want to reuse
const cache = await ai.caches.create({
  model,
  config: {
    contents: [
      {
        role: 'user',
        parts: [{ text: '1000 Lasagna Recipes...' }],
      },
    ],
    ttl: '300s', // Cache expires after 5 minutes
  },
});

console.log('Cache created:', cache.name);
// e.g. projects/my-project/locations/us-central1/cachedContents/abc123
```

然后与 AI SDK 一起使用该缓存：

```ts
import { googleVertex } from '@ai-sdk/google-vertex';
import { type GoogleLanguageModelOptions } from '@ai-sdk/google';
import { generateText } from 'ai';

const { text: veggieLasagnaRecipe } = await generateText({
  model: googleVertex('gemini-3.1-pro-preview'),
  prompt: 'Write a vegetarian lasagna recipe for 4 people.',
  providerOptions: {
    vertex: {
      cachedContent: cache.name,
    } satisfies GoogleLanguageModelOptions,
  },
});

const { text: meatLasagnaRecipe } = await generateText({
  model: googleVertex('gemini-3.1-pro-preview'),
  prompt: 'Write a meat lasagna recipe for 12 people.',
  providerOptions: {
    vertex: {
      cachedContent: cache.name,
    } satisfies GoogleLanguageModelOptions,
  },
});
```

### 故障排除

#### Schema 限制

Google Vertex API 使用 OpenAPI 3.0 schema 的子集，
不支持联合类型等功能。
在这种情况下，你会遇到的错误如下所示：

`GenerateContentRequest.generation_config.response_schema.properties[occupation].type: must be specified`

默认情况下，结构化输出处于启用状态（对于工具调用，它们是必需的）。
作为变通方法，你可以为对象生成禁用结构化输出：

```ts highlight="7,12"
import { googleVertex } from '@ai-sdk/google-vertex';
import { type GoogleLanguageModelOptions } from '@ai-sdk/google';
import { generateText, Output } from 'ai';

const result = await generateText({
  model: googleVertex('gemini-3.1-pro-preview'),
  providerOptions: {
    vertex: {
      structuredOutputs: false,
    } satisfies GoogleLanguageModelOptions,
  },
  output: Output.object({
    schema: z.object({
      name: z.string(),
      age: z.number(),
      contact: z.union([
        z.object({
          type: z.literal('email'),
          value: z.string(),
        }),
        z.object({
          type: z.literal('phone'),
          value: z.string(),
        }),
      ]),
    }),
  }),
  prompt: 'Generate an example person for testing.',
});
```

以下 Zod 功能已知无法与 Google Vertex 一起使用：

- `z.union`
- `z.record`

### 嵌入模型

你可以使用 `.embeddingModel()` 工厂方法创建调用 Google Vertex AI 嵌入 API 的模型：

```ts
const model = googleVertex.embeddingModel('text-embedding-005');
```

Google Vertex AI 嵌入模型支持其他设置。你可以将它们作为选项参数传递：

```ts
import {
  googleVertex,
  type GoogleVertexEmbeddingModelOptions,
} from '@ai-sdk/google-vertex';
import { embed } from 'ai';

const model = googleVertex.embeddingModel('text-embedding-005');

const { embedding } = await embed({
  model,
  value: 'sunny day at the beach',
  providerOptions: {
    vertex: {
      outputDimensionality: 512, // optional, number of dimensions for the embedding
      taskType: 'SEMANTIC_SIMILARITY', // optional, specifies the task type for generating embeddings
      autoTruncate: false, // optional
    } satisfies GoogleVertexEmbeddingModelOptions,
  },
});
```

Google Vertex AI 嵌入模型可使用以下可选提供商选项：

- **outputDimensionality**：_number_

  可选，用于降低输出嵌入的维度。如果设置，输出嵌入中多余的值将从末尾截断。

- **taskType**：_string_

  可选。指定生成嵌入的任务类型。支持的任务类型包括：
  - `SEMANTIC_SIMILARITY`：针对文本相似度优化。
  - `CLASSIFICATION`：针对文本分类优化。
  - `CLUSTERING`：针对基于相似度的文本聚类优化。
  - `RETRIEVAL_DOCUMENT`：针对文档检索优化。
  - `RETRIEVAL_QUERY`：针对基于查询的检索优化。
  - `QUESTION_ANSWERING`：针对回答问题优化。
  - `FACT_VERIFICATION`：针对验证事实信息优化。
  - `CODE_RETRIEVAL_QUERY`：针对基于自然语言查询检索代码块优化。

- **title**：_string_

  可选。正在嵌入的文档标题。这通过提供额外上下文帮助模型生成更好的嵌入。仅在 `taskType` 设置为 `'RETRIEVAL_DOCUMENT'` 时有效。

- **autoTruncate**：_boolean_

  可选。设置为 `true` 时，如果输入文本超过最大长度，将被截断。设置为 `false` 时，如果输入文本过长，将返回错误。默认为 `true`。

### 图像模型

你可以使用 `.image()` 工厂方法创建 Gemini 图像模型。这些模型通过语言模型 `:generateContent` API 提供图像输出。
有关使用 AI SDK 进行图像生成的更多信息，请参阅 [generateImage()](/docs/reference/ai-sdk-core/generate-image)。

#### Gemini 图像模型

[Gemini 图像模型](https://cloud.google.com/vertex-ai/generative-ai/docs/models/gemini/2-5-flash-image)（例如 `gemini-3.1-flash-image-preview`）是多模态输出语言模型，可与 `generateImage()` 一起使用，以获得更简单的图像生成体验。在内部，提供商使用 `responseModalities: ['IMAGE']` 调用语言模型 API。

```ts
import { googleVertex } from '@ai-sdk/google-vertex';
import { generateImage } from 'ai';

const { image } = await generateImage({
  model: googleVertex.image('gemini-3.1-flash-image-preview'),
  prompt: 'A photorealistic image of a cat wearing a wizard hat',
  aspectRatio: '1:1',
});
```

Gemini 图像模型还通过提供输入图像支持图像编辑：

```ts
import { googleVertex } from '@ai-sdk/google-vertex';
import { generateImage } from 'ai';
import fs from 'node:fs';

const sourceImage = fs.readFileSync('./cat.png');

const { image } = await generateImage({
  model: googleVertex.image('gemini-3.1-flash-image-preview'),
  prompt: {
    text: 'Add a small wizard hat to this cat',
    images: [sourceImage],
  },
});
```

<Note>
  输入图像必须提供为 `Buffer`、`ArrayBuffer`、`Uint8Array` 或 base64 编码字符串。Google Vertex 图像模型的 `generateImage()` 不支持 URL 输入，包括 HTTP 和 `gs://` URL。
</Note>

<Note>
  Gemini 图像模型不支持 `size` 或 `n` 参数。请使用 `aspectRatio` 而不是 `size`。也不支持基于蒙版的修复。
</Note>

<Note>

### 转录模型

你可以使用 `.transcription()` 工厂方法结合 [`transcribe()`](/docs/reference/ai-sdk-core/transcribe) 使用 Google Cloud Speech-to-Text 模型转录音频。

```ts
import { googleVertex } from '@ai-sdk/google-vertex';
import { transcribe } from 'ai';
import { readFile } from 'fs/promises';

const result = await transcribe({
  model: googleVertex.transcription('chirp_2'),
  audio: await readFile('audio.wav'),
});
```

提供商支持 [Chirp](https://docs.cloud.google.com/speech-to-text/docs/models/chirp-3) 模型 `chirp_2` 和 `chirp_3`，以及用于电话音频的 `telephony`。
Speech-to-Text 使用标准 Google Cloud 凭据（OAuth、应用默认凭据或服务账号），并调用 Cloud Speech-to-Text API。
转录模型不支持 Express 模式 API 密钥。将 `GOOGLE_VERTEX_LOCATION`（或 `providerOptions.googleVertex.region`）设置为 Speech-to-Text 区域。对于 Chirp，`chirp_2` 在 `us-central1`、`europe-west4` 和 `asia-southeast1` 可用；`chirp_3` 在 `us` 和 `eu` 多区域可用。Chirp 在 `global` Speech-to-Text 位置不可用，且这些区域与 Vertex AI 区域不同。`telephony` 的可用性取决于所选的 Speech-to-Text 区域和语言。

同步 API 可转录最长一分钟或 10 MB 的音频，以先达到者为准。默认自动检测口语语言；传递 `languageCodes` 可限制语言。对于 `telephony`，请传递受支持的语言代码，例如 `['en-US']`。

```ts
const result = await transcribe({
  model: googleVertex.transcription('chirp_3'),
  audio: await readFile('audio.wav'),
  providerOptions: {
    googleVertex: {
      region: 'us',
      languageCodes: ['en-US'],
    },
  },
});
```

以下提供商选项可用：

- **languageCodes** _string[]_

  要识别的 BCP-47 语言代码，或 `['auto']` 以检测口语语言。默认为 `['auto']`。多个显式语言代码需要多区域 Speech-to-Text 端点，例如 `us` 或 `eu`。

- **enableAutomaticPunctuation** _boolean_

  是否在转录文本中添加标点。默认为 `true`。

- **enableWordTimeOffsets** _boolean_

  是否在 `result.segments` 中包含词级时间戳。默认为 `true`。Google 指出，启用词级时间戳可能会降低转录质量和速度。

- **region** _string_

  请求的 Speech-to-Text 区域。默认为提供商的 `location`。

#### 转录模型能力

| 模型        | 词级时间戳                                       | 语言检测                                                                       |
| ----------- | ------------------------------------------------ | ------------------------------------------------------------------------------ |
| `chirp_2`   | 可用，但可能存在质量和速度权衡                   | 使用 `['auto']` 自动检测                                                        |
| `chirp_3`   | 可用，但可能存在转录质量权衡                     | 使用 `['auto']` 自动检测                                                        |
| `telephony` | 可用                                             | 显式支持的语言代码，并支持替代语言检测                                          |

## Google Vertex Anthropic 提供商用法

[AI SDK](/docs) 的 Google Vertex Anthropic 提供商通过 Google Vertex AI API 提供对 Anthropic 的 Claude 模型的支持。本节详细介绍如何设置和使用 Google Vertex Anthropic 提供商。

```typescript
import { createVertexAnthropic } from '@ai-sdk/google-vertex/anthropic';
```

### 语言模型

你可以使用提供商实例创建调用 [Anthropic Messages API](https://docs.anthropic.com/claude/reference/messages_post) 的模型。
第一个参数是模型 ID，例如 `claude-sonnet-5-5`。
某些模型具有多模态能力。

```ts
const model = vertexAnthropic('claude-sonnet-5-5');
```

你可以使用 Anthropic 语言模型通过 `generateText` 函数生成文本：

```ts
import { vertexAnthropic } from '@ai-sdk/google-vertex/anthropic';
import { generateText } from 'ai';

const { text } = await generateText({
  model: vertexAnthropic('claude-sonnet-5-5'),
  prompt: 'Write a vegetarian lasagna recipe for 4 people.',
});
```

Anthropic 语言模型也可以在 `streamText` 函数中使用，
并支持使用 [`Output`](/docs/reference/ai-sdk-core/output) 生成结构化数据
（请参阅 [AI SDK Core](/docs/ai-sdk-core)）。

<Note>
  Anthropic API 会在延迟后一次性返回流式工具调用。这导致结构化输出生成在延迟后完全完成，而不是增量流式传输。
</Note>

Anthropic 模型可使用以下可选提供商选项：

- `sendReasoning` _boolean_

  可选。在发送给模型的请求中包含推理内容。默认为 `true`。

  如果你遇到模型处理涉及推理内容的请求时出现问题，可以将其设置为 `false`，以从请求中省略这些内容。

- `thinking` _object_

  可选。有关更多详细信息，请参阅[推理部分](#reasoning)。

- `metadata` _object_

  可选。随请求包含的元数据。有关详细信息，请参阅 [Anthropic API 文档](https://platform.claude.com/docs/en/api/messages/create)。
  - `userId` _string_ - 最终用户的外部标识符。

### 计费标签

使用 `providerOptions.vertex.labels` 为 Claude 请求传递计费标签。
标签是字符串键到字符串值的映射，可与 `generateText` 和 `streamText` 一起使用：

```ts
import { vertexAnthropic } from '@ai-sdk/google-vertex/anthropic';
import { generateText } from 'ai';

const { text } = await generateText({
  model: vertexAnthropic('claude-sonnet-4-6@default'),
  prompt: 'Write a vegetarian lasagna recipe for 4 people.',
  providerOptions: {
    vertex: {
      labels: { team: 'data-platform', feature: 'my-app' },
    },
  },
});
```

提供商将标签以 base64 编码的 UTF-8 JSON 形式发送到 `X-Vertex-AI-Labels` 标头中。显式提供的标签标头优先于 `providerOptions.vertex.labels`。

有关标签要求和受支持的计费选项，请参阅 [Google 的计费标签文档](https://docs.cloud.google.com/vertex-ai/generative-ai/docs/multimodal/add-labels-to-api-calls#add_a_label_to_a_partner_model_api_call)。

### 推理

Anthropic 对 `claude-3-7-sonnet@20250219` 模型提供推理支持。

你可以使用 `thinking` 提供商选项并指定以令牌为单位的思考预算来启用它。

```ts
import { vertexAnthropic } from '@ai-sdk/google-vertex/anthropic';
import { generateText } from 'ai';

const { text, reasoningText, reasoning } = await generateText({
  model: vertexAnthropic('claude-3-7-sonnet@20250219'),
  prompt: 'How many people will live in the world in 2040?',
  providerOptions: {
    anthropic: {
      thinking: { type: 'enabled', budgetTokens: 12000 },
    },
  },
});

console.log(reasoningText); // reasoning text
console.log(reasoning); // reasoning details including redacted reasoning
console.log(text); // text response
```

有关如何将推理集成到聊天机器人中的更多详细信息，请参阅 [AI SDK UI：聊天机器人](/docs/ai-sdk-ui/chatbot#reasoning)。

#### 缓存控制

<Note>
  Anthropic 缓存控制在 Google Vertex 上处于预正式发布（GA）状态。更多信息请参阅 [Google Vertex Anthropic 缓存控制文档](https://cloud.google.com/vertex-ai/generative-ai/docs/partner-models/claude-prompt-caching)。
</Note>

在消息和消息部分中，你可以使用 `providerOptions` 属性设置缓存控制断点。
你需要将 `providerOptions` 对象中的 `anthropic` 属性设置为 `{ cacheControl: { type: 'ephemeral' } }` 以设置缓存控制断点。

缓存读取和缓存写入（创建）令牌计数会在 `generateText` 和 `streamText` 的标准 `usage` 对象上返回。你可以通过 `result.usage.inputTokenDetails.cacheReadTokens` 和 `result.usage.inputTokenDetails.cacheWriteTokens` 访问它们。

```ts highlight="8,16-18,27-31"
import { vertexAnthropic } from '@ai-sdk/google-vertex/anthropic';
import { generateText } from 'ai';

const errorMessage = '... long error message ...';

const result = await generateText({
  model: vertexAnthropic('claude-sonnet-5-5'),
  messages: [
    {
      role: 'user',
      content: [
        { type: 'text', text: 'You are a JavaScript expert.' },
        {
          type: 'text',
          text: `Error message: ${errorMessage}`,
          providerOptions: {
            anthropic: { cacheControl: { type: 'ephemeral' } },
          },
        },
        { type: 'text', text: 'Explain the error message.' },
      ],
    },
  ],
});

console.log(result.text);
console.log(
  'Cache read tokens:',
  result.usage.inputTokenDetails.cacheReadTokens,
);
console.log(
  'Cache write tokens:',
  result.usage.inputTokenDetails.cacheWriteTokens,
);
```

你还可以通过在消息数组开头提供多个系统消息，在系统消息上使用缓存控制：

```ts highlight="3,7-9"
const result = await generateText({
  model: vertexAnthropic('claude-sonnet-5-5'),
  messages: [
    {
      role: 'system',
      content: 'Cached system message part',
      providerOptions: {
        anthropic: { cacheControl: { type: 'ephemeral' } },
      },
    },
    {
      role: 'system',
      content: 'Uncached system message part',
    },
    {
      role: 'user',
      content: 'User prompt',
    },
  ],
});
```

有关 Anthropic 提示词缓存的更多信息，请参阅 [Google Vertex AI 的 Claude 提示词缓存文档](https://cloud.google.com/vertex-ai/generative-ai/docs/partner-models/claude-prompt-caching)和 [Anthropic 的缓存控制文档](https://docs.anthropic.com/en/docs/build-with-claude/prompt-caching)。

### 工具

Google Vertex Anthropic 支持 Anthropic 内置工具的子集。以下工具可通过提供商实例的 `tools` 属性使用：

1. **Bash 工具**：允许运行 bash 命令。
2. **文本编辑器工具**：提供查看和编辑文本文件的功能。
3. **计算机工具**：支持控制计算机上的键盘和鼠标操作。
4. **网络搜索工具**：提供对实时网络内容的访问。

<Note>
  Google Vertex 仅支持 Anthropic 工具的子集。代码执行、记忆和网络抓取等工具不可用。如果你需要访问所有 Anthropic 工具，请使用常规的 `@ai-sdk/anthropic` 提供商。
</Note>

<Note>
  Google Vertex Anthropic 不支持工具定义上的严格模式。在工具上设置 `strict: true` 将被忽略，并会发出警告。
</Note>

有关 Anthropic 工具的更多背景信息，请参阅 [Anthropic 的文档](https://platform.claude.com/docs/en/agents-and-tools/tool-use/overview)。

#### Bash 工具

Bash 工具允许运行 bash 命令。以下是创建和使用它的方法：

```ts
const bashTool = vertexAnthropic.tools.bash_20250124({
  execute: async ({ command, restart }) => {
    // Implement your bash command execution logic here
    // Return the result of the command execution
  },
});
```

参数：

- `command`（string）：要运行的 bash 命令。除非正在重启工具，否则为必需。
- `restart`（boolean，可选）：指定 true 将重启此工具。

#### 文本编辑器工具

文本编辑器工具提供查看和编辑文本文件的功能：

```ts
const textEditorTool = vertexAnthropic.tools.textEditor_20250124({
  execute: async ({
    command,
    path,
    file_text,
    insert_line,
    new_str,
    insert_text,
    old_str,
    view_range,
  }) => {
    // Implement your text editing logic here
    // Return the result of the text editing operation
  },
});
```

参数：

- `command`（'view' | 'create' | 'str_replace' | 'insert' | 'undo_edit'）：要运行的命令。注意：`textEditor_20250429` 和 `textEditor_20250728` 不支持 `undo_edit`。
- `path`（string）：文件或目录的绝对路径，例如 `/repo/file.py` 或 `/repo`。
- `file_text`（string，可选）：`create` 命令必需，包含要创建的文件内容。
- `insert_line`（number，可选）：`insert` 命令必需。在其后插入新字符串的行号。
- `new_str`（string，可选）：`str_replace` 命令的新字符串。
- `insert_text`（string，可选）：`insert` 命令必需，包含要插入的文本。
- `old_str`（string，可选）：`str_replace` 命令必需，包含要替换的字符串。
- `view_range`（number[]，可选）：`view` 命令可选，用于指定要显示的行范围。
- `max_characters`（number，可选）：可选，文件中要查看的最大字符数（仅在 `textEditor_20250728` 中可用）。

#### 计算机工具

计算机工具支持控制计算机上的键盘和鼠标操作：

```ts
const computerTool = vertexAnthropic.tools.computer_20241022({
  displayWidthPx: 1920,
  displayHeightPx: 1080,
  displayNumber: 0, // Optional, for X11 environments

  execute: async ({ action, coordinate, text }) => {
    // Implement your computer control logic here
    // Return the result of the action

    // Example code:
    switch (action) {
      case 'screenshot': {
        // multipart result:
        return {
          type: 'image',
          data: fs
            .readFileSync('./data/screenshot-editor.png')
            .toString('base64'),
        };
      }
      default: {
        console.log('Action:', action);
        console.log('Coordinate:', coordinate);
        console.log('Text:', text);
        return `executed ${action}`;
      }
    }
  },

  // map to tool result content for LLM consumption:
  toModelOutput({ output }) {
    return typeof output === 'string'
      ? [{ type: 'text', text: output }]
      : [{ type: 'file-data', data: output.data, mediaType: 'image/png' }];
  },
});
```

参数：

- `action`（'key' | 'type' | 'mouse_move' | 'left_click' | 'left_click_drag' | 'right_click' | 'middle_click' | 'double_click' | 'screenshot' | 'cursor_position'）：要执行的操作。
- `coordinate`（number[]，可选）：`mouse_move` 和 `left_click_drag` 操作必需。指定 (x, y) 坐标。
- `text`（string，可选）：`type` 和 `key` 操作必需。

#### 网络搜索工具

网络搜索工具为 Claude 提供对实时网络内容的直接访问：

```ts
const webSearchTool = vertexAnthropic.tools.webSearch_20250305({
  maxUses: 5, // Optional: Maximum number of web searches Claude can perform
  allowedDomains: ['example.com'], // Optional: Only search these domains
  blockedDomains: ['spam.com'], // Optional: Never search these domains
  userLocation: {
    // Optional: Provide location for geographically relevant results
    type: 'approximate',
    city: 'San Francisco',
    region: 'CA',
    country: 'US',
    timezone: 'America/Los_Angeles',
  },
});
```

参数：

- `maxUses`（number，可选）：Claude 在对话期间可以执行的最大网络搜索次数。
- `allowedDomains`（string[]，可选）：允许 Claude 搜索的域的可选列表。
- `blockedDomains`（string[]，可选）：Claude 在搜索时应避免的域的可选列表。
- `userLocation`（object，可选）：可选的用户位置信息，用于提供地理相关的搜索结果。
  - `type`（'approximate'）：位置类型（必须为 approximate）。
  - `city`（string，可选）：城市名称。
  - `region`（string，可选）：地区或州。
  - `country`（string，可选）：国家。
  - `timezone`（string，可选）：IANA 时区 ID。

这些工具可以与受支持的 Claude 模型结合使用，以实现更复杂的交互和任务。

```typescript
import { createGoogleVertexXai } from '@ai-sdk/google-vertex/xai';

const googleVertexXai = createGoogleVertexXai({
```

##### 可选的提供商设置

- **project** _string_

  Google Cloud 项目 ID。默认为 `GOOGLE_VERTEX_PROJECT` 环境变量。

- **googleAuthOptions** _object_

  可选。[Google Auth Library](https://github.com/googleapis/google-auth-library-nodejs/) 使用的身份验证选项。

- **headers** _Resolvable&lt;Record&lt;string, string | undefined&gt;&gt;_

  要包含在请求中的标头。

- **fetch** _(input: RequestInfo, init?: RequestInit) => Promise&lt;Response&gt;_

  自定义 [fetch](https://developer.mozilla.org/en-US/docs/Web/API/fetch) 实现。

### 函数调用

Vertex 上的 Grok 模型支持 OpenAI 兼容的函数调用。你可以像往常一样使用 AI SDK 工具：

```ts
import { googleVertexXai } from '@ai-sdk/google-vertex/xai';
import { generateText, tool } from 'ai';

const result = await generateText({
```

```ts
const result = await generateText({
```
