# Google Vertex 提供商

[AI SDK](/docs) 的 Google Vertex 提供商包含对 [Google Vertex AI](https://cloud.google.com/vertex-ai) API 的语言模型支持。这包括对 [Google 的 Gemini 模型](https://cloud.google.com/vertex-ai/generative-ai/docs/learn/models)、[Anthropic 的 Claude 合作伙伴模型](https://cloud.google.com/vertex-ai/generative-ai/docs/partner-models/use-claude)、[xAI 的 Grok 合作伙伴模型](https://cloud.google.com/vertex-ai/generative-ai/docs/partner-models/grok) 以及 [MaaS（模型即服务）开放模型](https://cloud.google.com/vertex-ai/generative-ai/docs/maas/use-open-models) 的支持。

<Note>
  Google Vertex 提供商兼容 Node.js 和 Edge 运行时。
  通过 `@ai-sdk/google-vertex/edge` 子模块支持 Edge 运行时。
  更多详情请参见下面的 [Google Vertex Edge 运行时](#google-vertex-edge-runtime)、[Google Vertex Anthropic Edge 运行时](#google-vertex-anthropic-edge-runtime) 和 [Google Vertex MaaS Edge 运行时](#google-vertex-maas-edge-runtime) 部分。
</Note>

## 设置

Google Vertex、Google Vertex Anthropic、Google Vertex xAI 和 Google Vertex MaaS 提供商在 `@ai-sdk/google-vertex` 模块中可用。你可以通过以下命令安装它：

<InstallPackages packages="@ai-sdk/google-vertex" />

## Google Vertex 提供商用法

Google Vertex 提供商实例用于创建调用 Vertex AI API 的模型实例。此提供商可用的模型包括 [Google 的 Gemini 模型](https://cloud.google.com/vertex-ai/generative-ai/docs/learn/models)。如果你希望使用 [Anthropic 的 Claude 模型](https://cloud.google.com/vertex-ai/generative-ai/docs/partner-models/use-claude)，请参见下面的 [Google Vertex Anthropic 提供商](#google-vertex-anthropic-provider-usage) 部分。

### 提供商实例

你可以从 `@ai-sdk/google-vertex` 导入默认的提供商实例 `googleVertex`：

```ts
import { googleVertex } from '@ai-sdk/google-vertex';
```

如果你需要自定义设置，可以从 `@ai-sdk/google-vertex` 导入 `createGoogleVertex` 并使用你的设置创建提供商实例：

```ts
import { createGoogleVertex } from '@ai-sdk/google-vertex';

const googleVertex = createGoogleVertex({
  project: 'my-project', // 可选
  location: 'us-central1', // 可选
});
```

Google Vertex 支持多种认证方法，具体取决于你的运行时环境和需求。

#### Node.js 运行时

Node.js 运行时是 AI SDK 支持的默认运行时。它通过 [`google-auth-library`](https://github.com/googleapis/google-auth-library-nodejs?tab=readme-ov-file#ways-to-authenticate) 支持所有标准的 Google Cloud 认证选项。典型用法是在 `GOOGLE_APPLICATION_CREDENTIALS` 环境变量中设置 JSON 凭据文件的路径。凭据文件可以从 [Google Cloud 控制台](https://console.cloud.google.com/apis/credentials) 获取。

如果你想自定义 Google 认证选项，可以将它们作为选项传递给 `createGoogleVertex` 函数，例如：

```ts
import { createGoogleVertex } from '@ai-sdk/google-vertex';

const googleVertex = createGoogleVertex({
  googleAuthOptions: {
    credentials: {
      client_email: 'my-email',
      private_key: 'my-private-key',
    },
  },
});
```

##### 可选的提供商设置

你可以使用以下可选设置来自定义提供商实例：

- **project** _string_

  你希望用于 API 调用的 Google Cloud 项目 ID。
  默认使用 `GOOGLE_VERTEX_PROJECT` 环境变量。

- **location** _string_

  你希望用于 API 调用的 Google Cloud 位置，例如 `us-central1`。
  默认使用 `GOOGLE_VERTEX_LOCATION` 环境变量。

- **googleAuthOptions** _object_

  可选。由 [Google Auth Library](https://github.com/googleapis/google-auth-library-nodejs/) 使用的认证选项。另请参见 [GoogleAuthOptions](https://github.com/googleapis/google-auth-library-nodejs/blob/08978822e1b7b5961f0e355df51d738e012be392/src/auth/googleauth.ts#L87C18-L87C35) 接口。
  - **authClient** _object_
    要使用的 `AuthClient`。

  - **keyFilename** _string_
    .json、.pem 或 .p12 密钥文件的路径。

  - **keyFile** _string_
    .json、.pem 或 .p12 密钥文件的路径。

  - **credentials** _object_
    包含 client_email 和 private_key 属性的对象，或外部账户客户端选项。

  - **clientOptions** _object_
    传递给客户端构造函数的选项对象。

  - **scopes** _string | string[]_
    所需 API 请求所需的作用域。

  - **projectId** _string_
    你的项目 ID。

  - **universeDomain** _string_
    给定 Cloud 宇宙的默认服务域。

- **headers** _Resolvable&lt;Record&lt;string, string | undefined&gt;&gt;_

  要包含在请求中的标头。可以以多种格式提供：
  - 标头键值对记录：`Record<string, string | undefined>`
  - 返回标头的函数：`() => Record<string, string | undefined>`
  - 返回标头的异步函数：`async () => Record<string, string | undefined>`
  - 解析为标头的 Promise：`Promise<Record<string, string | undefined>>`

- **fetch** _(input: RequestInfo, init?: RequestInit) => Promise&lt;Response&gt;_

  自定义 [fetch](https://developer.mozilla.org/en-US/docs/Web/API/fetch) 实现。
  默认为全局 `fetch` 函数。
  你可以将其用作拦截请求的中间件，
  或为测试等提供自定义 fetch 实现。

- **baseURL** _string_

  可选。Google Vertex API 调用的基础 URL，例如用于代理服务器。默认情况下，它使用位置和项目构建：
  `https://${location}-aiplatform.googleapis.com/v1/projects/${project}/locations/${location}/publishers/google`

#### Edge 运行时

Edge 运行时（如 Vercel Edge Functions 和 Cloudflare Workers）是在网络边缘更靠近用户运行的轻量级 JavaScript 环境。
它们只提供标准 Node.js API 的子集。
例如，直接文件系统访问不可用，并且许多 Node.js 特定的库
（包括标准的 Google Auth 库）不兼容。

Google Vertex 提供商的 Edge 运行时版本通过环境变量支持 Google 的 [Application Default Credentials](https://github.com/googleapis/google-auth-library-nodejs?tab=readme-ov-file#application-default-credentials)。这些值可以从 [Google Cloud 控制台](https://console.cloud.google.com/apis/credentials) 的 JSON 凭据文件中获取。

你可以从 `@ai-sdk/google-vertex/edge` 导入默认的提供商实例 `googleVertex`：

```ts
import { googleVertex } from '@ai-sdk/google-vertex/edge';
```

<Note>
  `/edge` 子模块包含在 `@ai-sdk/google-vertex` 包中，因此
  你无需单独安装。你必须从
  `@ai-sdk/google-vertex/edge` 导入以区别于 Node.js 提供商。
</Note>

如果你需要自定义设置，可以从 `@ai-sdk/google-vertex/edge` 导入 `createGoogleVertex` 并使用你的设置创建提供商实例：

```ts
import { createGoogleVertex } from '@ai-sdk/google-vertex/edge';

const googleVertex = createGoogleVertex({
  project: 'my-project', // 可选
  location: 'us-central1', // 可选
});
```

对于 Edge 运行时认证，你需要从 Google Default Application Credentials JSON 文件中设置这些环境变量：

- `GOOGLE_CLIENT_EMAIL`
- `GOOGLE_PRIVATE_KEY`
- `GOOGLE_PRIVATE_KEY_ID`（可选）

这些值可以从 [Google Cloud 控制台](https://console.cloud.google.com/apis/credentials) 的服务账户 JSON 文件中获取。

##### 可选的提供商设置

你可以使用以下可选设置来自定义提供商实例：

- **project** _string_

  你希望用于 API 调用的 Google Cloud 项目 ID。
  默认使用 `GOOGLE_VERTEX_PROJECT` 环境变量。

- **location** _string_

  你希望用于 API 调用的 Google Cloud 位置，例如 `us-central1`。
  默认使用 `GOOGLE_VERTEX_LOCATION` 环境变量。

- **googleCredentials** _object_

  可选。Edge 提供商用于认证的凭据。这些凭据通常通过环境变量设置，并源自服务账户 JSON 文件。
  - **clientEmail** _string_
    服务账户 JSON 文件中的客户端电子邮件。默认为 `GOOGLE_CLIENT_EMAIL` 环境变量的内容。

  - **privateKey** _string_
    服务账户 JSON 文件中的私钥。默认为 `GOOGLE_PRIVATE_KEY` 环境变量的内容。

  - **privateKeyId** _string_
    服务账户 JSON 文件中的私钥 ID（可选）。默认为 `GOOGLE_PRIVATE_KEY_ID` 环境变量的内容。

- **headers** _Resolvable&lt;Record&lt;string, string | undefined&gt;&gt;_

  要包含在请求中的标头。可以以多种格式提供：
  - 标头键值对记录：`Record<string, string | undefined>`
  - 返回标头的函数：`() => Record<string, string | undefined>`
  - 返回标头的异步函数：`async () => Record<string, string | undefined>`
  - 解析为标头的 Promise：`Promise<Record<string, string | undefined>>`

- **fetch** _(input: RequestInfo, init?: RequestInit) => Promise&lt;Response&gt;_

  自定义 [fetch](https://developer.mozilla.org/en-US/docs/Web/API/fetch) 实现。
  默认为全局 `fetch` 函数。
  你可以将其用作拦截请求的中间件，
  或为测试等提供自定义 fetch 实现。

#### Express 模式

Express 模式提供了一种简化的认证方法，使用 API 密钥而不是 OAuth 或服务账户凭据。使用 Express 模式时，不需要 `project` 和 `location` 设置。

```ts
import { createGoogleVertex } from '@ai-sdk/google-vertex';

const googleVertex = createGoogleVertex({
  apiKey: process.env.GOOGLE_VERTEX_API_KEY,
});
```

##### 可选的提供商设置

- **apiKey** _string_

  Google Vertex AI 的 API 密钥。提供时，提供商使用 API 密钥认证的 Express 模式，而不是 OAuth。
  默认使用 `GOOGLE_VERTEX_API_KEY` 环境变量。

### 语言模型

你可以使用提供商实例创建调用 Vertex API 的模型。
第一个参数是模型 ID，例如 `gemini-2.5-pro`。

```ts
const model = googleVertex('gemini-2.5-pro');
```

<Note>
  如果你使用 [自己的模型](https://cloud.google.com/vertex-ai/docs/training-overview)，
  你的模型名称需要以 `projects/` 开头。
</Note>

Google Vertex 模型还支持一些不属于 [标准调用设置](/docs/ai-sdk-core/settings) 的模型特定设置。你可以将它们作为选项参数传递：

```ts
import { googleVertex } from '@ai-sdk/google-vertex';
import { type GoogleLanguageModelOptions } from '@ai-sdk/google';

const model = googleVertex('gemini-2.5-pro');

await generateText({
  model,
  providerOptions: {
    vertex: {
      safetySettings: [
        {
          category: 'HARM_CATEGORY_UNSPECIFIED',
          threshold: 'BLOCK_LOW_AND_ABOVE',
        },
      ],
    } satisfies GoogleLanguageModelOptions,
  },
});
```

以下可选的提供商选项可用于 Google Vertex 模型：

- **cachedContent** _string_

  可选。用作预测上下文的缓存内容名称。
  格式：projects/\{project\}/locations/\{location\}/cachedContents/\{cachedContent\}

- **structuredOutputs** _boolean_

  可选。启用结构化输出。默认为 true。

  当 JSON Schema 包含
  Google Vertex 使用的 OpenAPI schema 版本不支持的
  元素时，这很有用。如果需要，你可以使用此选项禁用
  结构化输出。

  有关更多详细信息，请参见 [故障排除：Schema 限制](#schema-limitations)。

- **safetySettings** _Array\<\{ category: string; threshold: string \}\>_

  可选。模型的安全设置。
  - **category** _string_

    安全设置的类别。可以是以下之一：
    - `HARM_CATEGORY_UNSPECIFIED`
    - `HARM_CATEGORY_HATE_SPEECH`
    - `HARM_CATEGORY_DANGEROUS_CONTENT`
    - `HARM_CATEGORY_HARASSMENT`
    - `HARM_CATEGORY_SEXUALLY_EXPLICIT`
    - `HARM_CATEGORY_CIVIC_INTEGRITY`

  - **threshold** _string_

    安全设置的阈值。可以是以下之一：
    - `HARM_BLOCK_THRESHOLD_UNSPECIFIED`
    - `BLOCK_LOW_AND_ABOVE`
    - `BLOCK_MEDIUM_AND_ABOVE`
    - `BLOCK_ONLY_HIGH`
    - `BLOCK_NONE`

- **audioTimestamp** _boolean_

  可选。启用音频文件的时间戳理解。默认为 false。

  这对于生成带有准确时间戳的转录很有用。
  有关用法详情，请参阅 [Google 的文档](https://cloud.google.com/vertex-ai/generative-ai/docs/multimodal/audio-understanding)。

- **labels** _object_

  可选。定义账单报告中使用的标签。

  有关用法详情，请参阅 [Google 的文档](https://cloud.google.com/vertex-ai/generative-ai/docs/multimodal/add-labels-to-api-calls)。

- **streamFunctionCallArguments** _boolean_

  可选。设置为 true 时，函数调用参数将在流式响应中逐步流式传输。这使得 `tool-input-delta` 事件能够在模型生成函数调用参数时到达，从而减少工具调用的感知延迟。默认为 `false`。仅 Vertex AI API（非 Gemini API）上的 Gemini 3+ 模型支持。

  有关详细信息，请参阅 [Google 的文档](https://docs.cloud.google.com/vertex-ai/generative-ai/docs/multimodal/function-calling#streaming-fc)。

- **sharedRequestType** _'priority' | 'flex' | 'standard'_

  可选。通过设置 `X-Vertex-AI-LLM-Shared-Request-Type` 请求标头来选择即用即付 (PayGo) 层级。使用 `'priority'` 以获得一致的低延迟性能（需支付溢价），或使用 `'flex'` 以获得 50% 的折扣（预期延迟较长）。两者仅在 `global` 端点和部分 Gemini 模型上支持。

  默认情况下——在分配了预配吞吐量且未设置 `requestType` 时——请求首先消耗预配吞吐量配额，并且仅在 PT 容量耗尽时才回退到所选的共享层级。要完全绕过预配吞吐量，还需设置 `requestType: 'shared'`。

  服务层级通过 `result.providerMetadata.googleVertex.usageMetadata.trafficType` 报告为 `ON_DEMAND_PRIORITY`、`ON_DEMAND_FLEX`，或（如果在负载下降级）为普通的 `ON_DEMAND`。

  有关支持的模型、速率限制和降级行为，请参见 [Priority PayGo](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/priority-paygo) 和 [Flex PayGo](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/flex-paygo)。

- **requestType** _'shared'_

  可选。设置 `X-Vertex-AI-LLM-Request-Type` 请求标头。与 `sharedRequestType` 结合使用以完全跳过预配吞吐量并通过共享 PayGo 容量路由请求。请参见 [Priority PayGo](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/priority-paygo)。

你可以使用 Google Vertex 语言模型通过 `generateText` 函数生成文本：

```ts highlight="1,4"
import { googleVertex } from '@ai-sdk/google-vertex';
import { generateText } from 'ai';

const { text } = await generateText({
  model: googleVertex('gemini-2.5-pro'),
  prompt: '为 4 个人写一份素食千层面食谱。',
});
```

Google Vertex 语言模型也可以在 `streamText` 函数中使用
（参见 [AI SDK Core](/docs/ai-sdk-core)）。

#### 微调模型

[微调模型](https://cloud.google.com/vertex-ai/generative-ai/docs/deploy/overview)
从已部署的端点提供服务，并通过其端点 ID 而不是
已发布的模型名称来寻址。使用 `endpoints/` 前缀传递端点资源，
提供商将把请求路由到已部署的端点
（`.../locations/{location}/endpoints/{ENDPOINT_ID}`），而不是基础模型
路径（`.../publishers/google/models/{MODEL_ID}`）：

```ts
import { googleVertex } from '@ai-sdk/google-vertex';
import { generateText } from 'ai';

const { text } = await generateText({
  model: googleVertex('endpoints/YOUR_ENDPOINT_ID'),
  prompt: '为 4 个人写一份素食千层面食谱。',
});
```

使用已部署的 **端点** ID，而不是微调模型 ID（微调模型同时具有
`models/...` 资源和单独的 `endpoints/...` 资源；只有端点
可用于推理）。请求和响应格式与
基础模型相同，因此所有标准调用设置和提供商选项继续有效。

<Note>
  微调模型需要标准的 Google Cloud 凭据以及
  已部署端点的项目/位置（通过 `GOOGLE_VERTEX_PROJECT` /
  `GOOGLE_VERTEX_LOCATION` 或 `createGoogleVertex`）。微调模型不支持 [Express
  模式](#express-mode) API 密钥。
</Note>

#### 代码执行

通过 [代码执行](https://cloud.google.com/vertex-ai/generative-ai/docs/multimodal/code-execution)，Vertex AI 上的某些 Gemini 模型可以生成并执行 Python 代码。这允许模型执行计算、数据处理和其他编程任务以增强其响应。

你可以通过将 `code_execution` 工具添加到请求中来启用代码执行。

```ts
import { googleVertex } from '@ai-sdk/google-vertex';
import { generateText } from 'ai';

const result = await generateText({
  model: googleVertex('gemini-2.5-pro'),
  tools: { code_execution: googleVertex.tools.codeExecution({}) },
  prompt:
    '使用 python 计算第 20 个斐波那契数。然后找到离它最近的回文数。',
});
```

响应将包含已执行代码的 `tool-call` 和 `tool-result` 部分。

#### URL 上下文

URL 上下文允许 Gemini 模型检索和分析 URL 中的内容。支持的模型：Gemini 2.5 Flash-Lite、2.5 Pro、2.5 Flash、2.0 Flash。

```ts
import { googleVertex } from '@ai-sdk/google-vertex';
import { generateText } from 'ai';

const result = await generateText({
  model: googleVertex('gemini-2.5-pro'),
  tools: { url_context: googleVertex.tools.urlContext({}) },
  prompt: 'https://example.com/article 的关键点是什么？',
});
```

#### Google 搜索

Google 搜索使 Gemini 模型能够访问实时网络信息。支持的模型：Gemini 2.5 Flash-Lite、2.5 Flash、2.0 Flash、2.5 Pro。

```ts
import { googleVertex } from '@ai-sdk/google-vertex';
import { generateText } from 'ai';

const result = await generateText({
  model: googleVertex('gemini-2.5-pro'),
  tools: { google_search: googleVertex.tools.googleSearch({}) },
  prompt: 'AI 的最新发展是什么？',
});
```

#### 企业级网络搜索

[企业级网络搜索](https://cloud.google.com/vertex-ai/generative-ai/docs/grounding/web-grounding-enterprise) 使用专为金融、医疗保健和公共部门等高度监管行业设计的合规性网络索引提供基础。与标准 Google 搜索基础不同，企业级网络搜索不记录客户数据，并支持 VPC 服务控制。支持的模型：Gemini 2.0 及更新版本。

```ts
import { googleVertex } from '@ai-sdk/google-vertex';
import { generateText } from 'ai';

const result = await generateText({
  model: googleVertex('gemini-2.5-flash'),
  tools: {
    enterprise_web_search: googleVertex.tools.enterpriseWebSearch({}),
  },
  prompt: 'FDA 关于临床试验的最新规定是什么？',
});
```

#### Google 地图

Google 地图基础使 Gemini 模型能够访问 Google 地图数据以获取位置感知响应。支持的模型：Gemini 2.5 Flash-Lite、2.5 Flash、2.0 Flash、2.5 Pro、3.0 Pro。

```ts
import { googleVertex } from '@ai-sdk/google-vertex';
import { type GoogleLanguageModelOptions } from '@ai-sdk/google';
import { generateText } from 'ai';

const result = await generateText({
  model: googleVertex('gemini-2.5-flash'),
  tools: {
    google_maps: googleVertex.tools.googleMaps({}),
  },
  providerOptions: {
    vertex: {
      retrievalConfig: {
        latLng: { latitude: 34.090199, longitude: -117.881081 },
      },
    } satisfies GoogleLanguageModelOptions,
  },
  prompt: '附近最好的意大利餐厅有哪些？',
});
```

可选的 `retrievalConfig.latLng` 提供商选项为附近地点的查询提供位置上下文。此配置适用于任何支持位置上下文的基础工具。

#### 流式函数调用参数

对于 Vertex AI 上的 Gemini 3 Pro 及更高版本模型，你可以通过将 `streamFunctionCallArguments` 设置为 `true` 来流式传输生成的函数调用参数。这减少了需要调用函数时的感知延迟，因为 `tool-input-delta` 事件会逐步到达，而不是等待完整的参数。此选项默认为 `false`。

```ts
import { googleVertex } from '@ai-sdk/google-vertex';
import { type GoogleLanguageModelOptions } from '@ai-sdk/google';
import { streamText } from 'ai';
import { z } from 'zod';

const result = streamText({
  model: googleVertex('gemini-3.1-pro-preview'),
  prompt: '波士顿和旧金山的天气怎么样？',
  tools: {
    getWeather: {
      description: '获取给定位置的当前天气',
      inputSchema: z.object({
        location: z.string().describe('城市名称'),
      }),
    },
  },
  providerOptions: {
    vertex: {
      streamFunctionCallArguments: true,
    } satisfies GoogleLanguageModelOptions,
  },
});

for await (const part of result.stream) {
  switch (part.type) {
    case 'tool-input-start':
      console.log(`工具调用开始：${part.toolName}`);
      break;
    case 'tool-input-delta':
      process.stdout.write(part.delta);
      break;
    case 'tool-call':
      console.log(`工具调用完成：${part.toolName}`, part.input);
      break;
  }
}
```

<Note>
  此功能仅在 Vertex AI API 上可用。Gemini API 不支持。
  与 Google 提供商一起使用时，将发出警告并忽略该选项。
</Note>

#### 推理（思考 Token）

Google Vertex AI 通过其对 Gemini 模型的支持，也可以发出“思考”Token，代表模型的推理过程。AI SDK 将其公开为推理信息。

要为通过 Vertex 兼容的 Gemini 模型启用思考 Token，请在 `thinkingConfig` 提供商选项中设置 `includeThoughts: true`。这些选项通过 `providerOptions.vertex` 传递：

```ts
import { googleVertex } from '@ai-sdk/google-vertex';
import { type GoogleLanguageModelOptions } from '@ai-sdk/google';
import { generateText, streamText } from 'ai';

// 对于 generateText：
const { text, reasoningText, reasoning } = await generateText({
  model: googleVertex('gemini-2.0-flash-001'), // 或通过 Vertex 的其他受支持模型
  providerOptions: {
    vertex: {
      thinkingConfig: {
        includeThoughts: true,
        // thinkingBudget: 2048, // 可选
      },
    } satisfies GoogleLanguageModelOptions,
  },
  prompt: '用简单的术语解释量子计算。',
});

console.log('推理：', reasoningText);
console.log('推理详情：', reasoning);
console.log('最终文本：', text);

// 对于 streamText：
const result = streamText({
  model: googleVertex('gemini-2.0-flash-001'), // 或通过 Vertex 的其他受支持模型
  providerOptions: {
    vertex: {
      thinkingConfig: {
        includeThoughts: true,
        // thinkingBudget: 2048, // 可选
      },
    } satisfies GoogleLanguageModelOptions,
  },
  prompt: '用简单的术语解释量子计算。',
});

for await (const part of result.stream) {
  if (part.type === 'reasoning') {
    process.stdout.write(`思考：${part.textDelta}\n`);
  } else if (part.type === 'text-delta') {
    process.stdout.write(part.textDelta);
  }
}
```

当 `includeThoughts` 为 true 时，API 响应中标记为 `thought: true` 的部分将被处理为推理。

- 在 `generateText` 中，这些部分贡献给 `reasoningText`（字符串）和 `reasoning`（数组）字段。
- 在 `streamText` 中，这些部分作为 `reasoning` 流部分发出。

<Note>
  有关模型兼容性和更多详细信息，请参阅 [Google Vertex AI 关于“思考”的文档](https://cloud.google.com/vertex-ai/generative-ai/docs/thinking)。
</Note>

### 故障排除

#### Schema 限制

Google Vertex API 使用 OpenAPI 3.0 schema 的子集，
它不支持联合等特性。
在这种情况下，你遇到的错误如下所示：

`GenerateContentRequest.generation_config.response_schema.properties[occupation].type: must be specified`

默认情况下，结构化输出已启用（并且对于工具调用是必需的）。
你可以禁用对象生成的结构化输出作为解决方法：

```ts highlight="7,12"
import { googleVertex } from '@ai-sdk/google-vertex';
import { type GoogleLanguageModelOptions } from '@ai-sdk/google';
import { generateText, Output } from 'ai';

const result = await generateText({
  model: googleVertex('gemini-2.5-pro'),
  providerOptions: {
    vertex: {
      structuredOutputs: false,
    } satisfies GoogleLanguageModelOptions,
  },
  output: Output.object({
    schema: z.object({
      name: z.string(),
      age: z.number(),
      contact: z.union([
        z.object({
          type: z.literal('email'),
          value: z.string(),
        }),
        z.object({
          type: z.literal('phone'),
          value: z.string(),
        }),
      ]),
    }),
  }),
  prompt: '生成一个用于测试的示例人物。',
});
```

已知以下 Zod 特性无法与 Google Vertex 一起使用：

- `z.union`
- `z.record`

### 嵌入模型

你可以使用 `.embeddingModel()` 工厂方法创建调用 Google Vertex AI 嵌入 API 的模型：

```ts
const model = googleVertex.embeddingModel('text-embedding-005');
```

Google Vertex AI 嵌入模型支持其他设置。你可以将它们作为选项参数传递：

```ts
import {
  googleVertex,
  type GoogleVertexEmbeddingModelOptions,
} from '@ai-sdk/google-vertex';
import { embed } from 'ai';

const model = googleVertex.embeddingModel('text-embedding-005');

const { embedding } = await embed({
  model,
  value: '阳光明媚的海滩日',
  providerOptions: {
    vertex: {
      outputDimensionality: 512, // 可选，嵌入的维度数
      taskType: 'SEMANTIC_SIMILARITY', // 可选，指定生成嵌入的任务类型
      autoTruncate: false, // 可选
    } satisfies GoogleVertexEmbeddingModelOptions,
  },
});
```

以下可选的提供商选项可用于 Google Vertex AI 嵌入模型：

- **outputDimensionality**: _number_

  可选。输出嵌入的缩减维度。如果设置，输出嵌入中的多余值将从末尾截断。

- **taskType**: _string_

  可选。指定生成嵌入的任务类型。支持的任务类型包括：
  - `SEMANTIC_SIMILARITY`：针对文本相似度优化。
  - `CLASSIFICATION`：针对文本分类优化。
  - `CLUSTERING`：针对基于相似度的文本聚类优化。
  - `RETRIEVAL_DOCUMENT`：针对文档检索优化。
  - `RETRIEVAL_QUERY`：针对基于查询的检索优化。
  - `QUESTION_ANSWERING`：针对回答问题优化。
  - `FACT_VERIFICATION`：针对验证事实信息优化。
  - `CODE_RETRIEVAL_QUERY`：针对基于自然语言查询检索代码块优化。

- **title**: _string_

  可选。正在嵌入的文档的标题。这通过提供额外的上下文帮助模型生成更好的嵌入。仅当 `taskType` 设置为 `'RETRIEVAL_DOCUMENT'` 时有效。

- **autoTruncate**: _boolean_

  可选。设置为 `true` 时，如果输入文本超过最大长度，将被截断。设置为 `false` 时，如果输入文本过长，将返回错误。默认为 `true`。

#### 模型能力

| 模型                           | 每次调用的最大值 | 并行调用 | 多模态 |
| ------------------------------ | ---------------- | -------- | ------ |
| `text-embedding-005`           | 2048             | <Check /> | <Cross /> |
| `gemini-embedding-2`           | 2048             | <Check /> | <Check /> |
| `gemini-embedding-2-preview`   | 2048             | <Check /> | <Check /> |

<Note>
  上表列出了流行模型。如果需要，你也可以将任何可用的提供商模型 ID 作为字符串传递。
</Note>

### 图像模型

你可以使用 `.image()` 工厂方法创建图像模型。Google Vertex 提供商支持 [Imagen](https://cloud.google.com/vertex-ai/generative-ai/docs/image/overview) 和 [Gemini 图像模型](https://cloud.google.com/vertex-ai/generative-ai/docs/models/gemini/2-5-flash-image)。有关使用 AI SDK 生成图像的更多信息，请参见 [generateImage()](/docs/reference/ai-sdk-core/generate-image)。

#### Imagen 模型

[Imagen 模型](https://cloud.google.com/vertex-ai/generative-ai/docs/image/generate-images) 使用 Vertex AI 上的 Imagen API 生成图像。

```ts
import { googleVertex } from '@ai-sdk/google-vertex';
import { generateImage } from 'ai';

const { image } = await generateImage({
  model: googleVertex.image('imagen-4.0-generate-001'),
  prompt: '日落时分的未来城市景观',
  aspectRatio: '16:9',
});
```

可以使用 Google Vertex 提供商选项进行进一步配置。你可以使用 `GoogleVertexImageModelOptions` 类型验证提供商选项。

```ts
import { googleVertex } from '@ai-sdk/google-vertex';
import { GoogleVertexImageModelOptions } from '@ai-sdk/google-vertex';
import { generateImage } from 'ai';

const { image } = await generateImage({
  model: googleVertex.image('imagen-4.0-generate-001'),
  providerOptions: {
    vertex: {
      negativePrompt: '像素化、模糊、低质量',
    } satisfies GoogleVertexImageModelOptions,
  },
  // ...
});
```

以下提供商选项可用：

- **negativePrompt** _string_
  对生成图像中不鼓励的内容的描述。

- **personGeneration** `allow_adult` | `allow_all` | `dont_allow`
  是否允许生成人物。默认为 `allow_adult`。

- **safetySetting** `block_low_and_above` | `block_medium_and_above` | `block_only_high` | `block_none`
  是否阻止不安全内容。默认为 `block_medium_and_above`。

- **addWatermark** _boolean_
  是否向生成的图像添加不可见水印。默认为 `true`。

- **storageUri** _string_
  用于存储生成图像的 Cloud Storage URI。

<Note>
  Imagen 模型不支持 `size` 参数。请改用 `aspectRatio` 参数。
</Note>

可以使用 Google Vertex 元数据检索有关图像的附加信息。

```ts
import { googleVertex } from '@ai-sdk/google-vertex';
import { GoogleVertexImageModelOptions } from '@ai-sdk/google-vertex';
import { generateImage } from 'ai';

const { image, providerMetadata } = await generateImage({
  model: googleVertex.image('imagen-4.0-generate-001'),
  prompt: '日落时分的未来城市景观',
  aspectRatio: '16:9',
});

console.log(
  `修订后的提示词：${providerMetadata.vertex.images[0].revisedPrompt}`,
);
```

##### 图像编辑

Google Vertex Imagen 模型支持通过内绘、外绘和其他编辑模式进行图像编辑。通过 `prompt.images` 传递输入图像，并可选地通过 `prompt.mask` 传递蒙版。

<Note>
  图像编辑由 `imagen-3.0-capability-001` 支持。
  `imagen-4.0-generate-001` 模型目前不支持编辑操作。
</Note>

###### 内绘（插入对象）

使用蒙版在特定区域插入或替换对象：

```ts
import {
  googleVertex,
  GoogleVertexImageModelOptions,
} from '@ai-sdk/google-vertex';
import { generateImage } from 'ai';
import fs from 'fs';

const image = fs.readFileSync('./input-image.png');
const mask = fs.readFileSync('./mask.png'); // 白色 = 编辑区域

const { images } = await generateImage({
  model: googleVertex.image('imagen-3.0-capability-001'),
  prompt: {
    text: '一个阳光明媚的室内休息区，里面有一个游泳池，池中有一只火烈鸟',
    images: [image],
    mask,
  },
  providerOptions: {
    vertex: {
      edit: {
        baseSteps: 50,
        mode: 'EDIT_MODE_INPAINT_INSERTION',
        maskMode: 'MASK_MODE_USER_PROVIDED',
        maskDilation: 0.01,
      },
    } satisfies GoogleVertexImageModelOptions,
  },
});
```

###### 外绘（扩展图像）

将图像扩展到其原始边界之外：

```ts
import {
  googleVertex,
  GoogleVertexImageModelOptions,
} from '@ai-sdk/google-vertex';
import { generateImage } from 'ai';
import fs from 'fs';

const image = fs.readFileSync('./input-image.png');
const mask = fs.readFileSync('./outpaint-mask.png'); // 白色 = 扩展区域

const { images } = await generateImage({
  model: googleVertex.image('imagen-3.0-capability-001'),
  prompt: {
    text: '用更多的森林背景扩展场景',
    images: [image],
    mask,
  },
  providerOptions: {
    vertex: {
      edit: {
        baseSteps: 50,
        mode: 'EDIT_MODE_OUTPAINT',
        maskMode: 'MASK_MODE_USER_PROVIDED',
      },
    } satisfies GoogleVertexImageModelOptions,
  },
});
```

###### 编辑提供商选项

以下选项在 `providerOptions.vertex.edit` 下可用：

- **mode** - 要使用的编辑模式：
  - `EDIT_MODE_INPAINT_INSERTION` - 将对象插入蒙版区域
  - `EDIT_MODE_INPAINT_REMOVAL` - 从蒙版区域移除对象
  - `EDIT_MODE_OUTPAINT` - 将图像扩展到边界之外
  - `EDIT_MODE_CONTROLLED_EDITING` - 受控编辑
  - `EDIT_MODE_PRODUCT_IMAGE` - 产品图像编辑
  - `EDIT_MODE_BGSWAP` - 背景交换

- **baseSteps** _number_ - 采样步数（35-75）。值越高，质量越好，但速度越慢。

- **maskMode** - 如何解释蒙版：
  - `MASK_MODE_USER_PROVIDED` - 直接使用提供的蒙版
  - `MASK_MODE_DEFAULT` - 默认蒙版模式
  - `MASK_MODE_DETECTION_BOX` - 从检测到的边界框生成蒙版
  - `MASK_MODE_CLOTHING_AREA` - 从服装分割生成蒙版
  - `MASK_MODE_PARSED_PERSON` - 从人物解析生成蒙版

- **maskDilation** _number_ - 扩展蒙版的百分比（0-1）。推荐值：0.01。

<Note>
  输入图像必须作为 `Buffer`、`ArrayBuffer`、`Uint8Array` 或
  base64 编码字符串提供。Google Vertex 图像编辑不支持基于 URL 的图像。
</Note>

```ts
import { googleVertex } from '@ai-sdk/google-vertex';

const { image } = await generateImage({
```

```ts
import { googleVertex } from '@ai-sdk/google-vertex';
import { generateImage } from 'ai';
import fs from 'node:fs';

const sourceImage = fs.readFileSync('./cat.png');

const { image } = await generateImage({
```

```ts
import { googleVertex } from '@ai-sdk/google-vertex';
import { generateImage } from 'ai';

const { image } = await generateImage({
```

</Note>

<Note>

### 转录模型

你可以使用 `.transcription()` 工厂方法结合
[`transcribe()`](/docs/reference/ai-sdk-core/transcribe) 使用 Google Cloud Speech-to-Text 模型转录音频。

```ts
import { googleVertex } from '@ai-sdk/google-vertex';
import { transcribe } from 'ai';
import { readFile } from 'fs/promises';

const result = await transcribe({
  model: googleVertex.transcription('chirp_2'),
  audio: await readFile('audio.wav'),
});
```

该提供商支持 [Chirp](https://docs.cloud.google.com/speech-to-text/docs/models/chirp-3)
模型 `chirp_2` 和 `chirp_3`，以及用于电话通话音频的 `telephony`。
Speech-to-Text 使用标准的 Google Cloud 凭据（OAuth、Application Default
Credentials 或服务账户）并调用 Cloud Speech-to-Text API。
转录模型不支持 Express 模式 API 密钥。设置
`GOOGLE_VERTEX_LOCATION`（或 `providerOptions.googleVertex.region`）为
Speech-to-Text 区域。对于 Chirp，`chirp_2` 在 `us-central1`、
`europe-west4` 和 `asia-southeast1` 中可用；`chirp_3` 在 `us` 和 `eu`
多区域中可用。Chirp 在 `global` Speech-to-Text 位置不可用，
并且这些区域与 Vertex AI 区域不同。`telephony` 的可用性
取决于所选的 Speech-to-Text 区域和语言。

同步 API 可转录最长一分钟或最大 10 MB 的音频，以先到者为准。
默认情况下，口语会自动检测；传递 `languageCodes` 以限制它。
对于 `telephony`，传递受支持的语言代码，例如 `['en-US']`。

```ts
const result = await transcribe({
  model: googleVertex.transcription('chirp_3'),
  audio: await readFile('audio.wav'),
  providerOptions: {
    googleVertex: {
      region: 'us',
      languageCodes: ['en-US'],
    },
  },
});
```

以下提供商选项可用：

- **languageCodes** _string[]_

  要识别的 BCP-47 语言代码，或 `['auto']` 以检测口语。
  默认为 `['auto']`。多个显式语言代码需要
  多区域 Speech-to-Text 端点，例如 `us` 或 `eu`。

- **enableAutomaticPunctuation** _boolean_

  是否向转录添加标点。默认为 `true`。

- **enableWordTimeOffsets** _boolean_

  是否在 `result.segments` 中包含单词级时间戳。默认为
  `true`。Google 指出，启用单词级时间戳可能会降低
  转录质量和速度。

- **region** _string_

  请求的 Speech-to-Text 区域。默认为提供商
  `location`。

#### 转录模型能力

| 模型         | 单词时间戳                                               | 语言检测                                                             |
| ------------ | -------------------------------------------------------- | -------------------------------------------------------------------- |
| `chirp_2`    | 可用，但可能存在质量和速度权衡                           | 使用 `['auto']` 自动检测                                             |
| `chirp_3`    | 可用，但可能存在转录质量权衡                             | 使用 `['auto']` 自动检测                                             |
| `telephony`  | 可用                                                     | 显式支持的语言代码，支持替代语言检测                                 |

```ts
const model = anthropic('claude-3-haiku-20240307');
```

```ts
import { vertexAnthropic } from '@ai-sdk/google-vertex/anthropic';
```

### 推理

Anthropic 对 `claude-3-7-sonnet@20250219` 模型具有推理支持。

你可以使用 `thinking` 提供商选项启用它，
并指定以 Token 为单位的推理预算。

```ts
import { vertexAnthropic } from '@ai-sdk/google-vertex/anthropic';
import { generateText } from 'ai';

const { text, reasoningText, reasoning } = await generateText({
  model: vertexAnthropic('claude-3-7-sonnet@20250219'),
  prompt: '2040 年世界上将有多少人居住？',
  providerOptions: {
    anthropic: {
      thinking: { type: 'enabled', budgetTokens: 12000 },
    },
  },
});

console.log(reasoningText); // 推理文本
console.log(reasoning); // 推理详情，包括已编辑的推理
console.log(text); // 文本响应
```

有关如何将推理集成到聊天机器人中的更多详细信息，
请参见 [AI SDK UI：聊天机器人](/docs/ai-sdk-ui/chatbot#reasoning)。

#### 缓存控制

<Note>
  Anthropic 缓存控制在 Google Vertex 上处于预通用可用性 (Pre-GA) 状态。有关更多信息，请参见 [Google Vertex Anthropic 缓存控制文档](https://cloud.google.com/vertex-ai/generative-ai/docs/partner-models/claude-prompt-caching)。
</Note>

在消息和消息部分中，你可以使用 `providerOptions` 属性设置缓存控制断点。
你需要在 `providerOptions` 对象中将 `anthropic` 属性设置为 `{ cacheControl: { type: 'ephemeral' } }` 以设置缓存控制断点。

缓存读取和缓存写入（创建）Token 计数在标准
`usage` 对象上返回，适用于 `generateText` 和 `streamText`。你可以通过
`result.usage.inputTokenDetails.cacheReadTokens` 和
`result.usage.inputTokenDetails.cacheWriteTokens` 访问它们。

```ts highlight="8,16-18,27-31"
import { vertexAnthropic } from '@ai-sdk/google-vertex/anthropic';
import { generateText } from 'ai';

const errorMessage = '... 长错误消息 ...';

const result = await generateText({
  model: vertexAnthropic('claude-3-5-sonnet-20240620'),
  messages: [
    {
      role: 'user',
      content: [
        { type: 'text', text: '你是一位 JavaScript 专家。' },
        {
          type: 'text',
          text: `错误消息：${errorMessage}`,
          providerOptions: {
            anthropic: { cacheControl: { type: 'ephemeral' } },
          },
        },
        { type: 'text', text: '解释错误消息。' },
      ],
    },
  ],
});

console.log(result.text);
console.log(
  '缓存读取 Token：',
  result.usage.inputTokenDetails.cacheReadTokens,
);
console.log(
  '缓存写入 Token：',
  result.usage.inputTokenDetails.cacheWriteTokens,
);
```

你也可以通过在消息数组的开头提供多个系统消息来对系统消息使用缓存控制：

```ts highlight="3,7-9"
const result = await generateText({
  model: vertexAnthropic('claude-3-5-sonnet-20240620'),
  messages: [
    {
      role: 'system',
      content: '缓存的系统消息部分',
      providerOptions: {
        anthropic: { cacheControl: { type: 'ephemeral' } },
      },
    },
    {
      role: 'system',
      content: '未缓存的系统消息部分',
    },
    {
      role: 'user',
      content: '用户提示词',
    },
  ],
});
```

有关使用 Anthropic 进行提示词缓存的更多信息，请参见 [Google Vertex AI 的 Claude 提示词缓存文档](https://cloud.google.com/vertex-ai/generative-ai/docs/partner-models/claude-prompt-caching) 和 [Anthropic 的缓存控制文档](https://docs.anthropic.com/en/docs/build-with-claude/prompt-caching)。

### 工具

Google Vertex Anthropic 支持 Anthropic 内置工具的子集。以下工具可通过提供商实例的 `tools` 属性获得：

1. **Bash 工具**：允许运行 bash 命令。
2. **文本编辑器工具**：提供查看和编辑文本文件的功能。
3. **计算机工具**：启用对计算机键盘和鼠标操作的控制。
4. **网络搜索工具**：提供对实时网络内容的访问。

<Note>
  Google Vertex 上仅支持 Anthropic 工具的子集。像
  代码执行、记忆和网络获取等工具不可用。如果你需要访问所有
  Anthropic 工具，请使用常规的 `@ai-sdk/anthropic` 提供商。
</Note>

<Note>
  Google Vertex Anthropic 不支持工具定义的严格模式。
  在工具上设置 `strict: true` 将被忽略，并发出警告。
</Note>

有关 Anthropic 工具的更多背景信息，请参见 [Anthropic 的文档](https://platform.claude.com/docs/en/agents-and-tools/tool-use/overview)。

#### Bash 工具

Bash 工具允许运行 bash 命令。以下是创建和使用它的方法：

```ts
const bashTool = vertexAnthropic.tools.bash_20250124({
  execute: async ({ command, restart }) => {
    // 在此处实现你的 bash 命令执行逻辑
    // 返回命令执行的结果
  },
});
```

参数：

- `command` (string)：要运行的 bash 命令。除非工具正在重新启动，否则为必需。
- `restart` (boolean, 可选)：指定 true 将重新启动此工具。

#### 文本编辑器工具

文本编辑器工具提供查看和编辑文本文件的功能：

```ts
const textEditorTool = vertexAnthropic.tools.textEditor_20250124({
  execute: async ({
    command,
    path,
    file_text,
    insert_line,
    new_str,
    insert_text,
    old_str,
    view_range,
  }) => {
    // 在此处实现你的文本编辑逻辑
    // 返回文本编辑操作的结果
  },
});
```

参数：

- `command` ('view' | 'create' | 'str_replace' | 'insert' | 'undo_edit')：要运行的命令。注意：`undo_edit` 在 `textEditor_20250429` 和 `textEditor_20250728` 中不受支持。
- `path` (string)：文件或目录的绝对路径，例如 `/repo/file.py` 或 `/repo`。
- `file_text` (string, 可选)：`create` 命令必需，包含要创建的文件的内容。
- `insert_line` (number, 可选)：`insert` 命令必需。要在其后插入新字符串的行号。
- `new_str` (string, 可选)：`str_replace` 命令的新字符串。
- `insert_text` (string, 可选)：`insert` 命令必需，包含要插入的文本。
- `old_str` (string, 可选)：`str_replace` 命令必需，包含要替换的字符串。
- `view_range` (number[], 可选)：`view` 命令的可选参数，用于指定要显示的行范围。
- `max_characters` (number, 可选)：可选，在文件中查看的最大字符数（仅在 `textEditor_20250728` 中可用）。

#### 计算机工具

计算机工具启用对计算机键盘和鼠标操作的控制：

```ts
const computerTool = vertexAnthropic.tools.computer_20241022({
  displayWidthPx: 1920,
  displayHeightPx: 1080,
  displayNumber: 0, // 可选，适用于 X11 环境

  execute: async ({ action, coordinate, text }) => {
    // 在此处实现你的计算机控制逻辑
    // 返回操作的结果

    // 示例代码：
    switch (action) {
      case 'screenshot': {
        // 多部分结果：
        return {
          type: 'image',
          data: fs
            .readFileSync('./data/screenshot-editor.png')
            .toString('base64'),
        };
      }
      default: {
        console.log('操作：', action);
        console.log('坐标：', coordinate);
        console.log('文本：', text);
        return `已执行 ${action}`;
      }
    }
  },

  // 映射到供 LLM 使用的工具结果内容：
  toModelOutput({ output }) {
    return typeof output === 'string'
      ? [{ type: 'text', text: output }]
      : [{ type: 'file-data', data: output.data, mediaType: 'image/png' }];
  },
});
```

参数：

- `action` ('key' | 'type' | 'mouse_move' | 'left_click' | 'left_click_drag' | 'right_click' | 'middle_click' | 'double_click' | 'screenshot' | 'cursor_position')：要执行的操作。
- `coordinate` (number[], 可选)：`mouse_move` 和 `left_click_drag` 操作必需。指定 (x, y) 坐标。
- `text` (string, 可选)：`type` 和 `key` 操作必需。

#### 网络搜索工具

网络搜索工具为 Claude 提供对实时网络内容的直接访问：

```ts
const webSearchTool = vertexAnthropic.tools.webSearch_20250305({
  maxUses: 5, // 可选：Claude 可以执行的最大网络搜索次数
  allowedDomains: ['example.com'], // 可选：仅搜索这些域
  blockedDomains: ['spam.com'], // 可选：从不搜索这些域
  userLocation: {
    // 可选：为地理相关结果提供位置
    type: 'approximate',
    city: 'San Francisco',
    region: 'CA',
    country: 'US',
    timezone: 'America/Los_Angeles',
  },
});
```

参数：

- `maxUses` (number, 可选)：对话期间 Claude 可以执行的最大网络搜索次数。
- `allowedDomains` (string[], 可选)：允许 Claude 搜索的域的可选列表。
- `blockedDomains` (string[], 可选)：Claude 在搜索时应避免的域的可选列表。
- `userLocation` (object, 可选)：可选的用户位置信息，用于提供地理相关的搜索结果。
  - `type` ('approximate')：位置类型（必须为 approximate）。
  - `city` (string, 可选)：城市名称。
  - `region` (string, 可选)：地区或州。
  - `country` (string, 可选)：国家。
  - `timezone` (string, 可选)：IANA 时区 ID。

这些工具可以与受支持的 Claude 模型结合使用，以实现更复杂的交互和任务。

```typescript
import { googleVertexXai } from '@ai-sdk/google-vertex/xai';
```

```typescript
import { createGoogleVertexXai } from '@ai-sdk/google-vertex/xai';
```

#### Node.js 运行时

对于 Node.js 环境，Google Vertex xAI 提供商通过 `google-auth-library` 支持所有标准的 Google Cloud 认证选项：

```typescript
import { createGoogleVertexXai } from '@ai-sdk/google-vertex/xai';

const googleVertexXai = createGoogleVertexXai({
  googleAuthOptions: {
    credentials: {
      client_email: 'my-email',
      private_key: 'my-private-key',
    },
  },
});
```

##### 可选的提供商设置

- **project** _string_

  Google Cloud 项目 ID。默认为 `GOOGLE_VERTEX_PROJECT` 环境变量。

- **location** _string_

  Google Cloud 位置。Grok 模型在全局端点上可用。默认为 `GOOGLE_VERTEX_LOCATION` 环境变量。如果未设置，默认为 `global`。

- **googleAuthOptions** _object_

  可选。由 [Google Auth Library](https://github.com/googleapis/google-auth-library-nodejs/) 使用的认证选项。

- **headers** _Resolvable&lt;Record&lt;string, string | undefined&gt;&gt;_

  要包含在请求中的标头。

- **fetch** _(input: RequestInfo, init?: RequestInit) => Promise&lt;Response&gt;_

  自定义 [fetch](https://developer.mozilla.org/en-US/docs/Web/API/fetch) 实现。

### 函数调用

Vertex 上的 Grok 模型支持 OpenAI 兼容的函数调用。你可以像往常一样使用 AI SDK 工具：

```ts
import { googleVertexXai } from '@ai-sdk/google-vertex/xai';
import { generateText, tool } from 'ai';
import { z } from 'zod';

const result = await generateText({
  model: googleVertexXai('xai/grok-4.1-fast-reasoning'),
```

```ts
const result = await generateText({
```
