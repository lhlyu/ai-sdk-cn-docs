# Hume 提供商

[Hume](https://hume.ai/) 提供商支持 Hume 文本转语音 (TTS) API。

## 安装

Hume 提供商可在 `@ai-sdk/hume` 模块中获得。您可以通过以下命令安装它：

<InstallPackages packages="@ai-sdk/hume" />

## 提供商实例

您可以从 `@ai-sdk/hume` 导入默认的提供商实例 `hume`：

```ts
import { hume } from '@ai-sdk/hume';
```

如果您需要自定义设置，可以从 `@ai-sdk/hume` 导入 `createHume`，并使用您的设置创建一个提供商实例：

```ts
import { createHume } from '@ai-sdk/hume';

const hume = createHume({
  // 自定义设置，例如
  fetch: customFetch,
});
```

您可以使用以下可选设置来自定义 Hume 提供商实例：

- **apiKey** _string_

  通过 `X-Hume-Api-Key` 标头发送的 API 密钥。
  默认为 `HUME_API_KEY` 环境变量。

- **headers** _Record&lt;string,string&gt;_

  要包含在请求中的自定义标头。

- **fetch** _(input: RequestInfo, init?: RequestInit) => Promise&lt;Response&gt;_

  自定义 [fetch](https://developer.mozilla.org/en-US/docs/Web/API/fetch) 实现。
  默认为全局 `fetch` 函数。
  您可以将其用作拦截请求的中间件，
  或为测试等提供自定义 fetch 实现。

## 语音模型

您可以使用 `.speech()` 工厂方法创建调用 [Hume 语音 API](https://dev.hume.ai/docs/text-to-speech-tts/overview) 的模型。

```ts
const model = hume.speech();
```

您可以传递标准的语音生成选项，例如 `voice`、`speed`、`instructions` 和 `outputFormat`：

```ts
import { generateSpeech } from 'ai';
import { hume } from '@ai-sdk/hume';

const result = await generateSpeech({
  model: hume.speech(),
  text: 'Hello, world!',
  voice: 'd8ab67c6-953d-4bd8-9370-8fa53a0f1453',
  speed: 1.0,
  instructions: 'Speak in a friendly, conversational tone.',
  outputFormat: 'mp3',
});
```

### 支持的参数

- **text** _string_ (必需)

  要转换为语音的文本。

- **voice** _string_

  用于生成音频的语音 ID。
  默认为 `'d8ab67c6-953d-4bd8-9370-8fa53a0f1453'`。

- **speed** _number_

  语速倍数。

- **instructions** _string_

  关于文本应如何朗读的描述或指令。

- **outputFormat** _string_

  要生成的音频格式。支持的值：`'mp3'`、`'pcm'`、`'wav'`。
  默认为 `'mp3'`。

<Note>
  Hume 语音模型不支持 `language` 参数，该参数将被忽略并发出警告。
</Note>

### 提供商选项

您可以使用 `providerOptions` 参数传递额外的提供商特定选项：

```ts
import { generateSpeech } from 'ai';
import { hume } from '@ai-sdk/hume';
import { type HumeSpeechModelOptions } from '@ai-sdk/hume';

const result = await generateSpeech({
  model: hume.speech(),
  text: 'Hello, world!',
  providerOptions: {
    hume: {
      context: {
        generationId: 'previous-generation-id',
      },
    } satisfies HumeSpeechModelOptions,
  },
});
```

可用的提供商选项如下：

- **context** _object_

  语音合成请求的上下文。可以是：
  - `{ generationId: string }` - 用作上下文的先前生成的语音合成的 ID。
  - `{ utterances: Utterance[] }` - 用于上下文的语音对象数组，其中每个语音包含：
    - `text` _string_ (必需) - 文本内容。
    - `description` _string_ - 关于文本应如何朗读的指令。
    - `speed` _number_ - 语速倍数。
    - `trailingSilence` _number_ - 在语音后添加的静音持续时间（以秒为单位）。
    - `voice` _object_ - 语音配置，可以是 `{ id: string, provider?: 'HUME_AI' | 'CUSTOM_VOICE' }` 或 `{ name: string, provider?: 'HUME_AI' | 'CUSTOM_VOICE' }`。

| 模型      | 指令       | 速度       | 输出格式           |
| --------- | ---------- | ---------- | ------------------ |
| `default` | <Check />  | <Check />  | mp3, pcm, wav      |
