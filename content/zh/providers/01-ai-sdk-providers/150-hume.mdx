# Hume 提供商

[Hume](https://hume.ai/) 提供商支持 Hume 文本转语音（TTS）API。
Hume 模型目前无法通过 [AI Gateway](https://vercel.com/ai-gateway/models) 使用，因此开头的示例直接使用 `@ai-sdk/hume`。支持的替代方案请参见下方的[使用 AI Gateway](#using-ai-gateway)。

```ts
import { generateSpeech } from 'ai';
import { hume } from '@ai-sdk/hume';
import { writeFile } from 'node:fs/promises';

const { audio } = await generateSpeech({
  model: hume.speech(),
  text: 'Hello, world!',
  outputFormat: 'mp3',
});

await writeFile('speech.mp3', audio.uint8Array);
```

## 使用 AI Gateway

当前的 [AI Gateway 模型目录](https://vercel.com/ai-gateway/models)未列出 Hume 模型。本页面的 API 请使用 `@ai-sdk/hume`。如需通过 Gateway 使用其他语音模型，请安装 `ai` 并配置 Gateway API 密钥：

<InstallPackages packages="ai" />

在环境中设置 [AI Gateway API 密钥](https://vercel.com/docs/ai-gateway/getting-started)：

```bash
export AI_GATEWAY_API_KEY=your_api_key_here
```

Vercel 部署还可以使用 [OIDC 身份验证](/providers/ai-sdk-providers/ai-gateway#oidc-authentication-vercel-deployments)。
支持的模型和 API 请参见 [Gateway 文档](/providers/ai-sdk-providers/ai-gateway)。

## 使用 `@ai-sdk/hume`

如需直接访问 Hume，请安装 `ai` 和 `@ai-sdk/hume`：

<InstallPackages packages="ai @ai-sdk/hume" />

在 `HUME_API_KEY` 环境变量中设置你的 Hume API 凭据：

```bash
export HUME_API_KEY=your_api_key_here
```

<Note>
  以下各节介绍直接使用 `@ai-sdk/hume` 提供商的内容，包括其模型工厂和设置。Gateway 的模型和功能可用性可能有所不同。
</Note>

## 提供商实例

你可以从 `@ai-sdk/hume` 导入默认提供商实例 `hume`：

```ts
import { hume } from '@ai-sdk/hume';
```

如果需要自定义设置，可以从 `@ai-sdk/hume` 导入 `createHume` 并使用你的设置创建提供商实例：

```ts
import { createHume } from '@ai-sdk/hume';

const hume = createHume({
  // custom settings, e.g.
  fetch: customFetch,
});
```

你可以使用以下可选设置来自定义 Hume 提供商实例：

- **apiKey** _string_

  通过 `X-Hume-Api-Key` 请求头发送的 API 密钥。
  默认为 `HUME_API_KEY` 环境变量。

- **headers** _Record&lt;string,string&gt;_

  请求中包含的自定义请求头。

- **fetch** _(input: RequestInfo, init?: RequestInit) => Promise&lt;Response&gt;_

  自定义 [fetch](https://developer.mozilla.org/en-US/docs/Web/API/fetch) 实现。
  默认为全局 `fetch` 函数。
  你可以将其用作中间件来拦截请求，
  或为例如测试提供自定义 fetch 实现。

## 语音模型

你可以使用 `.speech()` 工厂方法创建调用 [Hume 语音 API](https://dev.hume.ai/docs/text-to-speech-tts/overview) 的模型。

```ts
const model = hume.speech();
```

你可以传入标准的语音生成选项，例如 `voice`、`speed`、`instructions` 和 `outputFormat`：

```ts
import { generateSpeech } from 'ai';
import { hume } from '@ai-sdk/hume';

const result = await generateSpeech({
  model: hume.speech(),
  text: 'Hello, world!',
  voice: 'd8ab67c6-953d-4bd8-9370-8fa53a0f1453',
  speed: 1.0,
  instructions: 'Speak in a friendly, conversational tone.',
  outputFormat: 'mp3',
});
```

### 支持的参数

- **text** _string_（必填）

  要转换为语音的文本。

- **voice** _string_

  用于生成音频的语音 ID。
  默认为 `'d8ab67c6-953d-4bd8-9370-8fa53a0f1453'`。

- **speed** _number_

  语速倍率。

- **instructions** _string_

  关于文本应如何朗读的描述或说明。

- **outputFormat** _string_

  要生成的音频格式。支持的值为：`'mp3'`、`'pcm'`、`'wav'`。
  默认为 `'mp3'`。

<Note>
  Hume 语音模型不支持 `language` 参数，该参数将被忽略并给出警告。
</Note>

### 提供商选项

你可以使用 `providerOptions` 参数传入额外的提供商特定选项：

```ts
import { generateSpeech } from 'ai';
import { hume } from '@ai-sdk/hume';
import { type HumeSpeechModelOptions } from '@ai-sdk/hume';

const result = await generateSpeech({
  model: hume.speech(),
  text: 'Hello, world!',
  providerOptions: {
    hume: {
      context: {
        generationId: 'previous-generation-id',
      },
    } satisfies HumeSpeechModelOptions,
  },
});
```

以下提供商选项可用：

- **context** _object_

  语音合成请求的上下文。可以是以下之一：
  - `{ generationId: string }` - 用作上下文的先前生成的语音合成的 ID。
  - `{ utterances: Utterance[] }` - 用于上下文的 utterance 对象数组，其中每个 utterance 包含：
    - `text` _string_（必填）- 文本内容。
    - `description` _string_ - 关于文本应如何朗读的说明。
    - `speed` _number_ - 语速倍率。
    - `trailingSilence` _number_ - 在 utterance 之后添加的静音时长（秒）。
    - `voice` _object_ - 语音配置，可以是 `{ id: string, provider?: 'HUME_AI' | 'CUSTOM_VOICE' }` 或 `{ name: string, provider?: 'HUME_AI' | 'CUSTOM_VOICE' }`。
