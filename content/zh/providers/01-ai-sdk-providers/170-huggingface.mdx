# Hugging Face 提供商

[Hugging Face](https://huggingface.co/) 提供商通过 [Hugging Face Inference Providers](https://huggingface.co/docs/inference-providers/index) 提供对数千种语言模型的访问，包括来自 Meta、DeepSeek、Qwen 等公司的模型。
对于下方展示的共享模型，可使用 [AI Gateway](/providers/ai-sdk-providers/ai-gateway)，由 Gateway 支持的提供商提供服务；或使用 `@ai-sdk/huggingface` 将请求直接发送到 Hugging Face。Gateway 目前不会将请求路由到 Hugging Face。

```ts provider="huggingface" model="meta/llama-3.3-70b"
import { generateText } from 'ai';
__PROVIDER_IMPORT__;

const { text } = await generateText({
  model: __MODEL__,
  prompt: 'Write a vegetarian lasagna recipe for 4 people.',
});

console.log(text);
```

## 使用 AI Gateway

AI SDK 默认对模型字符串使用 AI Gateway。Gateway 通过单个 API 密钥提供跨提供商访问模型的能力，并支持用量和成本跟踪。安装 `ai`：

<InstallPackages packages="ai" />

在环境中设置 [AI Gateway API 密钥](https://vercel.com/docs/ai-gateway/getting-started)：

```bash
export AI_GATEWAY_API_KEY=your_api_key_here
```

Vercel 部署还可以使用 [OIDC 身份验证](/providers/ai-sdk-providers/ai-gateway#oidc-authentication-vercel-deployments)。
有关配置信息，请参阅 [AI Gateway 提供商文档](/providers/ai-sdk-providers/ai-gateway)；有关可用模型，请参阅[模型目录](https://vercel.com/ai-gateway/models)。

当前的 [Gateway 提供商列表](https://vercel.com/docs/ai-gateway/models-and-providers/provider-options#available-providers) 不包含 Hugging Face 作为推理提供商。Gateway 标签页调用的模型也可从 Hugging Face 获取，但 Gateway 会通过其支持的推理提供商路由这些请求。它不会将请求发送到 Hugging Face。请使用直接标签页调用 Hugging Face；不要将 `providerOptions.gateway.order` 设置为不受支持的提供商 slug。

## 使用 `@ai-sdk/huggingface`

如需直接访问 Hugging Face，请安装 `ai` 和 `@ai-sdk/huggingface`：

<InstallPackages packages="ai @ai-sdk/huggingface" />

在 `HUGGINGFACE_API_KEY` 环境变量中设置你的 Hugging Face API 凭据：

```bash
export HUGGINGFACE_API_KEY=your_api_key_here
```

使用 `@ai-sdk/huggingface` 通过你的 Hugging Face 账户进行身份验证，并直接调用其平台 API。上面的 Gateway 替代方案则使用受支持的推理提供商。

<Note>
  以下各节介绍直接使用 `@ai-sdk/huggingface` 提供商的内容，
  包括其模型工厂和设置。Gateway 的模型和功能
  可用性可能有所不同。
</Note>

API 密钥可从 [Hugging Face 设置](https://huggingface.co/settings/tokens) 获取。

## 提供商实例

你可以从 `@ai-sdk/huggingface` 导入默认提供商实例 `huggingFace`：

```ts
import { huggingFace } from '@ai-sdk/huggingface';
```

如需自定义配置，可以导入 `createHuggingFace` 并使用你的设置创建提供商实例：

```ts
import { createHuggingFace } from '@ai-sdk/huggingface';

const huggingFace = createHuggingFace({
  apiKey: process.env.HUGGINGFACE_API_KEY ?? '',
});
```

你可以使用以下可选设置来自定义 Hugging Face 提供商实例：

- **baseURL** _string_

  为 API 调用使用不同的 URL 前缀，例如使用代理服务器。
  默认前缀为 `https://router.huggingface.co/v1`。

- **apiKey** _string_

  通过 `Authorization` 标头发送的 API 密钥。默认使用
  `HUGGINGFACE_API_KEY` 环境变量。你可以从
  [Hugging Face 设置](https://huggingface.co/settings/tokens) 获取 API 密钥。

- **headers** _Record&lt;string,string&gt;_

  要包含在请求中的自定义标头。

- **fetch** _(input: RequestInfo, init?: RequestInit) => Promise&lt;Response&gt;_

  自定义 [fetch](https://developer.mozilla.org/en-US/docs/Web/API/fetch) 实现。

## 语言模型

你可以使用提供商实例创建语言模型：

```ts
import { huggingFace } from '@ai-sdk/huggingface';
import { generateText } from 'ai';

const { text } = await generateText({
  model: huggingFace('deepseek-ai/DeepSeek-V3-0324'),
  prompt: 'Write a vegetarian lasagna recipe for 4 people.',
});
```

你也可以使用 `.responses()` 或 `.languageModel()` 工厂方法：

```ts
const model = huggingFace.responses('deepseek-ai/DeepSeek-V3-0324');
// or
const model = huggingFace.languageModel('moonshotai/Kimi-K2-Instruct');
```

Hugging Face 语言模型可用于 `streamText` 函数
（参见 [AI SDK Core](/docs/ai-sdk-core)）。

你可以在 [Hugging Face Inference Models](https://huggingface.co/inference/models) 页面上探索最新和热门模型及其能力、上下文大小、吞吐量和定价。

### 提供商选项

Hugging Face 语言模型支持提供商特定选项，你可以通过 `providerOptions.huggingface` 传递这些选项：

```ts
import { huggingFace } from '@ai-sdk/huggingface';
import { generateText } from 'ai';

const { text } = await generateText({
  model: huggingFace('deepseek-ai/DeepSeek-R1'),
  prompt: 'Explain the theory of relativity.',
  providerOptions: {
    huggingface: {
      reasoningEffort: 'high',
      instructions: 'Respond in a clear and educational manner.',
    },
  },
});
```

以下提供商选项可用：

- **metadata** _Record&lt;string, string&gt;_

  要随请求包含的额外元数据。

- **instructions** _string_

  给模型的指令。可用于提供额外上下文或指导。

- **strictJsonSchema** _boolean_

  是否对结构化输出使用严格 JSON schema 验证。默认为 `false`。

- **reasoningEffort** _string_

  控制推理模型（如 DeepSeek-R1）的推理强度。值越高，推理越详尽。

### 推理输出

对于 `deepseek-ai/DeepSeek-R1` 等推理模型，你可以控制推理强度，并在响应中访问模型的推理过程：

```ts
import { huggingFace } from '@ai-sdk/huggingface';
import { streamText } from 'ai';

const result = streamText({
  model: huggingFace('deepseek-ai/DeepSeek-R1'),
  prompt: 'How many r letters are in the word strawberry?',
  providerOptions: {
    huggingface: {
      reasoningEffort: 'high',
    },
  },
});

for await (const part of result.stream) {
  if (part.type === 'reasoning') {
    console.log(`Reasoning: ${part.textDelta}`);
  } else if (part.type === 'text-delta') {
    process.stdout.write(part.textDelta);
  }
}
```

对于使用 `generateText` 的非流式调用，推理内容可在响应的 `reasoning` 字段中获取：

```ts
import { huggingFace } from '@ai-sdk/huggingface';
import { generateText } from 'ai';

const result = await generateText({
  model: huggingFace('deepseek-ai/DeepSeek-R1'),
  prompt: 'What is 25 * 37?',
  providerOptions: {
    huggingface: {
      reasoningEffort: 'medium',
    },
  },
});

console.log('Reasoning:', result.reasoning);
console.log('Answer:', result.text);
```

### 图像输入

对于 `Qwen/Qwen2.5-VL-7B-Instruct` 等支持视觉的模型，你可以将图像作为消息内容的一部分传递：

```ts
import { huggingFace } from '@ai-sdk/huggingface';
import { generateText } from 'ai';
import { readFileSync } from 'fs';

const result = await generateText({
  model: huggingFace('Qwen/Qwen2.5-VL-7B-Instruct'),
  messages: [
    {
      role: 'user',
      content: [
        { type: 'text', text: 'Describe this image in detail.' },
        {
          type: 'file',
          mediaType: 'image',
          data: readFileSync('./image.png'),
        },
      ],
    },
  ],
});
```

你也可以传递图像 URL：

```ts
{
  type: 'file',
  mediaType: 'image',
  data: 'https://example.com/image.png',
}
```
