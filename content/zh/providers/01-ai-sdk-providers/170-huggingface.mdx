# Hugging Face 提供商

[Hugging Face](https://huggingface.co/) 提供商通过 [Hugging Face Inference Providers](https://huggingface.co/docs/inference-providers/index) 提供对数千个语言模型的访问，包括来自 Meta、DeepSeek、Qwen 等的模型。

API 密钥可以从 [Hugging Face 设置](https://huggingface.co/settings/tokens) 获取。

## 安装

Hugging Face 提供商可通过 `@ai-sdk/huggingface` 模块获得。你可以使用以下命令安装：

## 提供商实例

你可以从 `@ai-sdk/huggingface` 导入默认的提供商实例 `huggingFace`：

```ts
import { huggingFace } from '@ai-sdk/huggingface';
```

对于自定义配置，你可以导入 `createHuggingFace` 并使用你的设置创建一个提供商实例：

```ts
import { createHuggingFace } from '@ai-sdk/huggingface';

const huggingFace = createHuggingFace({
  apiKey: process.env.HUGGINGFACE_API_KEY ?? '',
});
```

你可以使用以下可选设置来自定义 Hugging Face 提供商实例：

- **baseURL** _string_

  为 API 调用使用不同的 URL 前缀，例如使用代理服务器。
  默认前缀是 `https://router.huggingface.co/v1`。

- **apiKey** _string_

  通过 `Authorization` 标头发送的 API 密钥。它默认为
  `HUGGINGFACE_API_KEY` 环境变量。你可以从 [Hugging Face 设置](https://huggingface.co/settings/tokens) 获取你的 API 密钥。

- **headers** _Record&lt;string,string&gt;_

  要包含在请求中的自定义标头。

- **fetch** _(input: RequestInfo, init?: RequestInit) => Promise&lt;Response&gt;_

  自定义 [fetch](https://developer.mozilla.org/en-US/docs/Web/API/fetch) 实现。

## 语言模型

你可以使用提供商实例创建语言模型：

```ts
import { huggingFace } from '@ai-sdk/huggingface';
import { generateText } from 'ai';

const { text } = await generateText({
  model: huggingFace('deepseek-ai/DeepSeek-V3-0324'),
  prompt: '写一份供4人食用的素食千层面食谱。',
});
```

你也可以使用 `.responses()` 或 `.languageModel()` 工厂方法：

```ts
const model = huggingFace.responses('deepseek-ai/DeepSeek-V3-0324');
// 或
const model = huggingFace.languageModel('moonshotai/Kimi-K2-Instruct');
```

Hugging Face 语言模型可以在 `streamText` 函数中使用
（参见 [AI SDK Core](/docs/ai-sdk-core)）。

你可以在 [Hugging Face Inference Models](https://huggingface.co/inference/models) 页面上探索最新和热门的模型，包括它们的能力、上下文大小、吞吐量和定价。

### 提供商选项

Hugging Face 语言模型支持特定于提供商的选项，你可以通过 `providerOptions.huggingface` 传递：

```ts
import { huggingFace } from '@ai-sdk/huggingface';
import { generateText } from 'ai';

const { text } = await generateText({
  model: huggingFace('deepseek-ai/DeepSeek-R1'),
  prompt: '解释相对论。',
  providerOptions: {
    huggingface: {
      reasoningEffort: 'high',
      instructions: '以清晰且具有教育意义的方式回应。',
    },
  },
});
```

以下提供商选项可用：

- **metadata** _Record&lt;string, string&gt;_

  要包含在请求中的附加元数据。

- **instructions** _string_

  给模型的指令。可用于提供额外的上下文或指导。

- **strictJsonSchema** _boolean_

  是否对结构化输出使用严格的 JSON schema 验证。默认为 `false`。

- **reasoningEffort** _string_

  控制像 DeepSeek-R1 这样的推理模型的推理努力程度。值越高，推理越彻底。

### 推理输出

对于像 `deepseek-ai/DeepSeek-R1` 这样的推理模型，你可以控制推理努力程度并在响应中访问模型的推理过程：

```ts
import { huggingFace } from '@ai-sdk/huggingface';
import { streamText } from 'ai';

const result = streamText({
  model: huggingFace('deepseek-ai/DeepSeek-R1'),
  prompt: '单词 strawberry 中有多少个字母 r？',
  providerOptions: {
    huggingface: {
      reasoningEffort: 'high',
    },
  },
});

for await (const part of result.stream) {
  if (part.type === 'reasoning') {
    console.log(`推理：${part.textDelta}`);
  } else if (part.type === 'text-delta') {
    process.stdout.write(part.textDelta);
  }
}
```

对于使用 `generateText` 的非流式调用，推理内容在响应的 `reasoning` 字段中可用：

```ts
import { huggingFace } from '@ai-sdk/huggingface';
import { generateText } from 'ai';

const result = await generateText({
  model: huggingFace('deepseek-ai/DeepSeek-R1'),
  prompt: '25 * 37 等于多少？',
  providerOptions: {
    huggingface: {
      reasoningEffort: 'medium',
    },
  },
});

console.log('推理：', result.reasoning);
console.log('答案：', result.text);
```

### 图像输入

对于像 `Qwen/Qwen2.5-VL-7B-Instruct` 这样的视觉模型，你可以将图像作为消息内容的一部分传递：

```ts
import { huggingFace } from '@ai-sdk/huggingface';
import { generateText } from 'ai';
import { readFileSync } from 'fs';

const result = await generateText({
  model: huggingFace('Qwen/Qwen2.5-VL-7B-Instruct'),
  messages: [
    {
      role: 'user',
      content: [
        { type: 'text', text: '详细描述这张图片。' },
        {
          type: 'file',
          mediaType: 'image',
          data: readFileSync('./image.png'),
        },
      ],
    },
  ],
});
```

你也可以传递图像 URL：

```ts
{
  type: 'file',
  mediaType: 'image',
  data: 'https://example.com/image.png',
}
```
