# Rev.ai 提供商

[Rev.ai](https://www.rev.ai/) 提供商包含对 Rev.ai 转录 API 的语言模型支持。
Rev.ai 模型目前无法通过 [AI Gateway](https://vercel.com/ai-gateway/models) 使用，因此开头的示例直接使用 `@ai-sdk/revai`。支持的替代方案请参见下方的[使用 AI Gateway](#using-ai-gateway)。

```ts
import { transcribe } from 'ai';
import { revai } from '@ai-sdk/revai';
import { readFile } from 'node:fs/promises';

const { text } = await transcribe({
  model: revai.transcription('machine'),
  audio: await readFile('audio.mp3'),
});

console.log(text);
```

该示例会转录项目中的 `audio.mp3` 文件。

## 使用 AI Gateway

当前的 [AI Gateway 模型目录](https://vercel.com/ai-gateway/models)未列出 Rev.ai 模型。本页面的 API 请使用 `@ai-sdk/revai`。如需通过 Gateway 使用其他转录模型，请安装 `ai` 并配置 Gateway API 密钥：

<InstallPackages packages="ai" />

在环境中设置 [AI Gateway API 密钥](https://vercel.com/docs/ai-gateway/getting-started)：

```bash
export AI_GATEWAY_API_KEY=your_api_key_here
```

Vercel 部署还可以使用 [OIDC 身份验证](/providers/ai-sdk-providers/ai-gateway#oidc-authentication-vercel-deployments)。
支持的模型和 API 请参见 [Gateway 文档](/providers/ai-sdk-providers/ai-gateway)。

## 使用 `@ai-sdk/revai`

如需直接访问 Rev.ai，请安装 `ai` 和 `@ai-sdk/revai`：

<InstallPackages packages="ai @ai-sdk/revai" />

在 `REVAI_API_KEY` 环境变量中设置你的 Rev.ai API 凭据：

```bash
export REVAI_API_KEY=your_api_key_here
```

<Note>
  以下各节介绍直接使用 `@ai-sdk/revai` 提供商，包括其模型工厂和设置。Gateway
  的模型和功能可用性可能有所不同。
</Note>

## 提供商实例

你可以从 `@ai-sdk/revai` 导入默认提供商实例 `revai`：

```ts
import { revai } from '@ai-sdk/revai';
```

如果需要自定义设置，可以从 `@ai-sdk/revai` 导入 `createRevai`，并使用你的设置创建提供商实例：

```ts
import { createRevai } from '@ai-sdk/revai';

const revai = createRevai({
  // custom settings, e.g.
  fetch: customFetch,
});
```

你可以使用以下可选设置来自定义 Rev.ai 提供商实例：

- **apiKey** _string_

  通过 `Authorization` 标头发送的 API 密钥。
  默认为 `REVAI_API_KEY` 环境变量。

- **headers** _Record&lt;string,string&gt;_

  要包含在请求中的自定义标头。

- **fetch** _(input: RequestInfo, init?: RequestInit) => Promise&lt;Response&gt;_

  自定义 [fetch](https://developer.mozilla.org/en-US/docs/Web/API/fetch) 实现。
  默认为全局 `fetch` 函数。
  你可以将其用作中间件来拦截请求，
  或为例如测试提供自定义 fetch 实现。

## 转录模型

你可以使用 `.transcription()` 工厂方法创建调用 [Rev.ai 转录 API](https://www.rev.ai/docs/api/transcription) 的模型。

第一个参数是模型 ID，例如 `machine`。

```ts
const model = revai.transcription('machine');
```

你还可以使用 `providerOptions` 参数传递额外的提供商特定选项。例如，如果事先知道输入语言，以 ISO-639-1（例如 `en`）格式提供输入语言有时可以提高转录性能。

```ts highlight="7"
import { transcribe } from 'ai';
import { revai } from '@ai-sdk/revai';
import { type RevaiTranscriptionModelOptions } from '@ai-sdk/revai';
import { readFile } from 'fs/promises';

const result = await transcribe({
  model: revai.transcription('machine'),
  audio: await readFile('audio.mp3'),
  providerOptions: {
    revai: { language: 'en' } satisfies RevaiTranscriptionModelOptions,
  },
});
```

以下提供商选项可用：

- **metadata** _string_

  可选的元数据字符串，用于关联转录任务。

- **notification_config** _object_

  任务完成时 webhook 通知的配置。
  - **url** _string_ - 发送通知的 URL。
  - **auth_headers** _object_ - 通知请求的可选授权标头。
    - **Authorization** _string_ - Authorization 标头值。

- **delete_after_seconds** _integer_

  任务自动删除前的秒数。

- **verbatim** _boolean_

  是否在转录中包含填充词和错误开头。

- **rush** _boolean_

  [不支持 HIPAA] 是否优先处理任务以加快处理速度。仅适用于人工转录选项。

- **test_mode** _boolean_

  是否在测试模式下运行任务。默认为 `false`。

- **segments_to_transcribe** _Array_

  要转录的音频特定片段。
  - **start** _number_ - 片段的开始时间（秒）。
  - **end** _number_ - 片段的结束时间（秒）。

- **speaker_names** _Array_

  为转录中的说话者分配的名称。
  - **display_name** _string_ - 说话者的显示名称。

- **skip_diarization** _boolean_

  是否跳过说话者分离。默认为 `false`。

- **skip_postprocessing** _boolean_

  是否跳过后处理步骤。仅适用于英语和西班牙语。默认为 `false`。

- **skip_punctuation** _boolean_

  是否跳过在转录中添加标点符号。默认为 `false`。

- **remove_disfluencies** _boolean_

  是否从转录中移除不流畅词（um、uh 等）。默认为 `false`。

- **remove_atmospherics** _boolean_

  是否从转录中移除氛围音（如 `<laugh>`、`<affirmative>`）。默认为 `false`。

- **filter_profanity** _boolean_

  是否通过将字符替换为星号（首尾字符除外）来过滤转录中的脏话。默认为 `false`。

- **speaker_channels_count** _integer_

  音频中的说话者声道数。仅适用于英语、西班牙语和法语。

- **speakers_count** _integer_

  音频中预期的说话者数量。仅适用于英语、西班牙语和法语。

- **diarization_type** _string_

  要使用的说话者分离类型。可能的值："standard"（默认）、"premium"。

- **custom_vocabulary_id** _string_

  用于转录的自定义词汇表 ID，通过 Custom Vocabularies API 提交。

- **custom_vocabularies** _Array_

  用于转录的自定义词汇表。

- **strict_custom_vocabulary** _boolean_

  是否严格强制执行自定义词汇表。

- **summarization_config** _object_

  生成转录摘要的配置。
  - **model** _string_ - 用于摘要的模型。可能的值："standard"（默认）、"premium"。
  - **type** _string_ - 摘要的格式。可能的值："paragraph"（默认）、"bullets"。
  - **prompt** _string_ - 用于摘要的自定义提示词（与 type 互斥）。

- **translation_config** _object_

  翻译转录的配置。
  - **target_languages** _Array_ - 翻译的目标语言。每一项是一个对象，包含：
    - **language** _string_ - 语言代码。可能的值："en"、"en-us"、"en-gb"、"ar"、"pt"、"pt-br"、"pt-pt"、"fr"、"fr-ca"、"es"、"es-es"、"es-la"、"it"、"ja"、"ko"、"de"、"ru"。
  - **model** _string_ - 用于翻译的模型。可能的值："standard"（默认）、"premium"。

- **language** _string_

  音频内容的语言，以 ISO 639-1 语言代码提供，但有一些例外，例如带区域限定的代码（例如 "en-us"）。默认为 "en"。

- **forced_alignment** _boolean_

  是否执行强制对齐，这可以提高逐词时间戳的准确性。
  默认为 `false`。

  当前支持的语言：
  - 英语（en、en-us、en-gb）
  - 法语（fr）
  - 意大利语（it）
  - 德语（de）
  - 西班牙语（es）

  注意：此选项在低成本环境中不可用。
