# Rev.ai 提供商

[Rev.ai](https://www.rev.ai/) 提供商包含对 Rev.ai 转录 API 的语言模型支持。

## 安装

Rev.ai 提供商在 `@ai-sdk/revai` 模块中可用。你可以通过以下方式安装：

## 提供商实例

你可以从 `@ai-sdk/revai` 导入默认提供商实例 `revai`：

```ts
import { revai } from '@ai-sdk/revai';
```

如果你需要自定义设置，可以从 `@ai-sdk/revai` 导入 `createRevai` 并使用你的设置创建提供商实例：

```ts
import { createRevai } from '@ai-sdk/revai';

const revai = createRevai({
  // 自定义设置，例如
  fetch: customFetch,
});
```

你可以使用以下可选设置来自定义 Rev.ai 提供商实例：

- **apiKey** _string_

  通过 `Authorization` 标头发送的 API 密钥。
  默认为 `REVAI_API_KEY` 环境变量。

- **headers** _Record&lt;string,string&gt;_

  要包含在请求中的自定义标头。

- **fetch** _(input: RequestInfo, init?: RequestInit) => Promise&lt;Response&gt;_

  自定义 [fetch](https://developer.mozilla.org/en-US/docs/Web/API/fetch) 实现。
  默认为全局 `fetch` 函数。
  你可以将其用作中间件来拦截请求，
  或为测试等场景提供自定义 fetch 实现。

## 转录模型

你可以使用 `.transcription()` 工厂方法创建调用 [Rev.ai 转录 API](https://www.rev.ai/docs/api/transcription) 的模型。

第一个参数是模型 ID，例如 `machine`。

```ts
const model = revai.transcription('machine');
```

你还可以使用 `providerOptions` 参数传递额外的提供商特定选项。例如，如果事先知道输入语言，以 ISO-639-1 格式（例如 `en`）提供有时可以提高转录性能。

```ts highlight="7"
import { transcribe } from 'ai';
import { revai } from '@ai-sdk/revai';
import { type RevaiTranscriptionModelOptions } from '@ai-sdk/revai';
import { readFile } from 'fs/promises';

const result = await transcribe({
  model: revai.transcription('machine'),
  audio: await readFile('audio.mp3'),
  providerOptions: {
    revai: { language: 'en' } satisfies RevaiTranscriptionModelOptions,
  },
});
```

以下提供商选项可用：

- **metadata** _string_

  要与转录作业关联的可选元数据字符串。

- **notification_config** _object_

  作业完成时 Webhook 通知的配置。
  - **url** _string_ - 发送通知的 URL。
  - **auth_headers** _object_ - 通知请求的可选授权标头。
    - **Authorization** _string_ - 授权标头值。

- **delete_after_seconds** _integer_

  作业自动删除前的秒数。

- **verbatim** _boolean_

  是否在转录中包含填充词和错误开始。

- **rush** _boolean_

  [不支持 HIPAA] 是否优先处理作业以加快处理速度。仅适用于人工转录员选项。

- **test_mode** _boolean_

  是否在测试模式下运行作业。默认为 `false`。

- **segments_to_transcribe** _Array_

  要转录的音频特定片段。
  - **start** _number_ - 片段的开始时间（秒）。
  - **end** _number_ - 片段的结束时间（秒）。

- **speaker_names** _Array_

  分配给转录中说话者的名称。
  - **display_name** _string_ - 说话者的显示名称。

- **skip_diarization** _boolean_

  是否跳过说话者分离。默认为 `false`。

- **skip_postprocessing** _boolean_

  是否跳过后处理步骤。仅适用于英语和西班牙语。默认为 `false`。

- **skip_punctuation** _boolean_

  是否跳过在转录中添加标点符号。默认为 `false`。

- **remove_disfluencies** _boolean_

  是否从转录中移除不流畅部分（如嗯、呃等）。默认为 `false`。

- **remove_atmospherics** _boolean_

  是否从转录中移除环境声音（如 `<laugh>`、`<affirmative>`）。默认为 `false`。

- **filter_profanity** _boolean_

  是否通过将字符替换为星号（首尾字符除外）来过滤转录中的脏话。默认为 `false`。

- **speaker_channels_count** _integer_

  音频中的说话者通道数。仅适用于英语、西班牙语和法语。

- **speakers_count** _integer_

  音频中的预期说话者数量。仅适用于英语、西班牙语和法语。

- **diarization_type** _string_

  要使用的分离类型。可能的值："standard"（默认）、"premium"。

- **custom_vocabulary_id** _string_

  通过自定义词汇 API 提交的用于转录的自定义词汇 ID。

- **custom_vocabularies** _Array_

  用于转录的自定义词汇。

- **strict_custom_vocabulary** _boolean_

  是否严格强制使用自定义词汇。

- **summarization_config** _object_

  生成转录摘要的配置。
  - **model** _string_ - 用于摘要的模型。可能的值："standard"（默认）、"premium"。
  - **type** _string_ - 摘要的格式。可能的值："paragraph"（默认）、"bullets"。
  - **prompt** _string_ - 摘要的自定义提示词（与 type 互斥）。

- **translation_config** _object_

  翻译转录的配置。
  - **target_languages** _Array_ - 目标语言。每个项是一个对象，包含：
    - **language** _string_ - 语言代码。可能的值："en"、"en-us"、"en-gb"、"ar"、"pt"、"pt-br"、"pt-pt"、"fr"、"fr-ca"、"es"、"es-es"、"es-la"、"it"、"ja"、"ko"、"de"、"ru"。
  - **model** _string_ - 用于翻译的模型。可能的值："standard"（默认）、"premium"。

- **language** _string_

  音频内容的语言，以 ISO 639-1 语言代码提供。默认为 "en"。

- **forced_alignment** _boolean_

  是否执行强制对齐，这可以提高逐词时间戳的准确性。
  默认为 `false`。

  当前支持的语言：
  - 英语 (en, en-us, en-gb)
  - 法语 (fr)
  - 意大利语 (it)
  - 德语 (de)
  - 西班牙语 (es)

  注意：此选项在低成本环境中不可用。
