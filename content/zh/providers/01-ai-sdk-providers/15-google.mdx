# Google 提供商

[Google](https://ai.google.dev) 提供商包含对 [Google](https://ai.google.dev/api/rest) API 的语言模型和嵌入模型支持。

## 设置

Google 提供商位于 `@ai-sdk/google` 模块中。你可以使用以下命令安装：

<InstallPackages packages="@ai-sdk/google" />

## 提供商实例

你可以从 `@ai-sdk/google` 导入默认提供商实例 `google`：

```ts
import { google } from '@ai-sdk/google';
```

如果你需要自定义设置，可以从 `@ai-sdk/google` 导入 `createGoogle` 并使用你的设置创建提供商实例：

```ts
import { createGoogle } from '@ai-sdk/google';

const google = createGoogle({
  // custom settings
});
```

你可以使用以下可选设置来自定义 Google 提供商实例：

- **baseURL** _string_

  为 API 调用使用不同的 URL 前缀，例如使用代理服务器。
  默认前缀为 `https://generativelanguage.googleapis.com/v1beta`。

- **apiKey** _string_

  通过 `x-goog-api-key` 请求头发送的 API 密钥。
  默认为 `GOOGLE_GENERATIVE_AI_API_KEY` 环境变量。

- **headers** _Record&lt;string,string&gt;_

  要包含在请求中的自定义请求头。

- **fetch** _(input: RequestInfo, init?: RequestInit) => Promise&lt;Response&gt;_

  自定义 [fetch](https://developer.mozilla.org/en-US/docs/Web/API/fetch) 实现。
  默认为全局 `fetch` 函数。
  你可以将其用作中间件来拦截请求，
  或为测试等场景提供自定义 fetch 实现。

- **generateId** _() => string_

  可选函数，用于为每个请求生成唯一 ID。
  默认为 SDK 内置的 ID 生成器。

- **name** _string_

  自定义提供商名称。
  默认为 `'google.generative-ai'`。

## 语言模型

你可以使用提供商实例创建调用 [Google Generative AI API](https://ai.google.dev/api/rest) 的模型。
第一个参数是模型 ID，例如 `gemini-3.8-flash`。
这些模型支持工具调用，部分模型具有多模态能力。

```ts
const model = google('gemini-3.8-flash');
```

你可以使用 Google 语言模型通过 `generateText` 函数生成文本：

```ts
import { google } from '@ai-sdk/google';
import { generateText } from 'ai';

const { text } = await generateText({
  model: google('gemini-3.8-flash'),
  prompt: 'Write a vegetarian lasagna recipe for 4 people.',
});
```

Google 语言模型也可用于 `streamText` 函数，
并支持使用 [`Output`](/docs/reference/ai-sdk-core/output) 生成结构化数据
（参见 [AI SDK Core](/docs/ai-sdk-core)）。

<Note>
  为了保持向前兼容，提供商会将未识别的 `gemini-*` 模型 ID 和 `-latest`
  别名视为最新的受支持 Gemini 代次。目前，这意味着对提供商定义工具和混合
  工具、`thinkingLevel` 推理、多模态函数响应以及思考签名采用 Gemini 3 的
  请求行为。已知的旧版 Gemini 模型 ID 保留其特定代次的请求行为。此 SDK
  默认值控制请求序列化；所选模型仍必须在 Google API 中支持各项功能。
</Note>

Google 还支持一些不属于[标准调用设置](/docs/ai-sdk-core/settings)的模型特定设置。
你可以将它们作为选项参数传入：

```ts
import { google, type GoogleLanguageModelOptions } from '@ai-sdk/google';

const model = google('gemini-3.8-flash');

await generateText({
  model,
  providerOptions: {
    google: {
      safetySettings: [
        {
          category: 'HARM_CATEGORY_UNSPECIFIED',
          threshold: 'BLOCK_LOW_AND_ABOVE',
        },
      ],
    } satisfies GoogleLanguageModelOptions,
  },
});
```

Google 模型可使用以下可选提供商选项：

- **cachedContent** _string_

  可选。用作上下文以服务预测的缓存内容名称。
  格式：cachedContents/\{cachedContent\}

- **structuredOutputs** _boolean_

  可选。启用结构化输出。默认为 true。

  当 JSON Schema 包含 Google 使用的 OpenAPI schema 版本
  不支持的元素时，此选项很有用。如有需要，
  你可以使用它来禁用结构化输出。

  更多详情请参见[故障排除：Schema 限制](#schema-limitations)。

- **safetySettings** _Array\<\{ category: string; threshold: string \}\>_

  可选。模型的安全设置。
  - **category** _string_

    安全设置的类别。可以是以下之一：
    - `HARM_CATEGORY_UNSPECIFIED`
    - `HARM_CATEGORY_HATE_SPEECH`
    - `HARM_CATEGORY_DANGEROUS_CONTENT`
    - `HARM_CATEGORY_HARASSMENT`
    - `HARM_CATEGORY_SEXUALLY_EXPLICIT`
    - `HARM_CATEGORY_CIVIC_INTEGRITY`

  - **threshold** _string_

    安全设置的阈值。可以是以下之一：
    - `HARM_BLOCK_THRESHOLD_UNSPECIFIED`
    - `BLOCK_LOW_AND_ABOVE`
    - `BLOCK_MEDIUM_AND_ABOVE`
    - `BLOCK_ONLY_HIGH`
    - `BLOCK_NONE`
    - `OFF`

- **responseModalities** _string[]_
  用于响应的模态。支持以下模态：`TEXT`、`IMAGE`。未定义或为空时，模型默认仅返回文本。

- **thinkingConfig** _\{ thinkingLevel?: 'minimal' | 'low' | 'medium' | 'high'; thinkingBudget?: number; includeThoughts?: boolean \}_

  可选。模型思考过程的配置。仅受特定 [Google 模型](https://ai.google.dev/gemini-api/docs/thinking)支持。
  - **thinkingLevel** _'minimal' | 'low' | 'medium' | 'high'_

    可选。控制 Gemini 3 及更高版本模型的思考深度。Gemini 3.1 Pro 支持 'low'、'medium' 和 'high'，Gemini 3 Pro 支持 'low' 和 'high'，而 Gemini 3 Flash 支持全部四个级别：'minimal'、'low'、'medium' 和 'high'。

  - **thinkingBudget** _number_

    可选。为模型提供生成响应时可使用的思考 token 数量的指导。如果模型支持，将其设置为 0 可禁用思考。
    有关每个模型可能的值范围的更多信息，请参见 [Google 思考文档](https://ai.google.dev/gemini-api/docs/thinking#set-budget)。

    <Note>
      此选项适用于 Gemini 2.5 模型。Gemini 3 及更高版本模型应改用
      `thinkingLevel`。
    </Note>

  - **includeThoughts** _boolean_

    可选。如果设置为 true，将返回思考摘要，这是模型原始思考的综合版本，可提供对模型内部推理过程的洞察。

- **imageConfig** _\{ aspectRatio?: string, imageSize?: string \}_

  可选。模型图像生成的配置。仅受特定 [Google 模型](https://ai.google.dev/gemini-api/docs/image-generation)支持。
  - **aspectRatio** _string_

    模型默认生成 1:1 正方形，或将输出图像尺寸匹配为输入图像尺寸。可以是以下之一：
    - 1:1
    - 2:3
    - 3:2
    - 3:4
    - 4:3
    - 4:5
    - 5:4
    - 9:16
    - 16:9
    - 21:9

  - **imageSize** _string_

    控制输出图像分辨率。默认为 1K。可以是以下之一：
    - 1K
    - 2K
    - 4K

- **audioTimestamp** _boolean_

  可选。为纯音频文件启用时间戳理解。
  参见 [Google Cloud 音频理解文档](https://cloud.google.com/vertex-ai/generative-ai/docs/multimodal/audio-understanding)。

- **mediaResolution** _string_

  可选。如果指定，将使用指定的媒体分辨率。可以是以下之一：
  - `MEDIA_RESOLUTION_UNSPECIFIED`
  - `MEDIA_RESOLUTION_LOW`
  - `MEDIA_RESOLUTION_MEDIUM`
  - `MEDIA_RESOLUTION_HIGH`

  参见 [Google API MediaResolution 文档](https://ai.google.dev/api/generate-content#MediaResolution)。

- **labels** _Record&lt;string, string&gt;_

  可选。定义账单报告中使用的标签。仅在 Vertex AI 上可用。
  参见 [Google Cloud 标签文档](https://cloud.google.com/vertex-ai/generative-ai/docs/multimodal/add-labels-to-api-calls)。

- **serviceTier** _'standard' | 'flex' | 'priority'_

  可选。用于请求的服务层级。
  设置为 `'flex'` 可获得便宜 50% 的处理，代价是延迟增加。
  设置为 `'priority'` 可获得超低延迟，价格比 `'standard'` 高 75-100%。

  由于 Priority 在负载下可以优雅降级为 Standard，
  请求实际运行的层级会显示在
  `result.providerMetadata.google.serviceTier` 上。参见
  [Priority 推理](https://ai.google.dev/gemini-api/docs/priority-inference)
  和 [Flex 推理](https://ai.google.dev/gemini-api/docs/flex-inference)。

- **threshold** _string_

  可选。独立阈值设置，可独立于 `safetySettings` 使用。
  使用与 `safetySettings` 阈值相同的值。

### 思考

Gemini 2.5 和 Gemini 3 及更高版本系列模型使用内部“思考过程”，显著提升其推理和多步规划能力，使其对编码、高等数学和数据分析等复杂任务非常高效。更多信息请参见 [Google 思考文档](https://ai.google.dev/gemini-api/docs/thinking)。

#### Gemini 3 及更高版本模型

对于 Gemini 3 及更高版本模型，使用 `thinkingLevel` 参数控制推理深度：

```ts
import { google, GoogleLanguageModelOptions } from '@ai-sdk/google';
import { generateText } from 'ai';

const model = google('gemini-3.8-flash');

const { text, reasoning } = await generateText({
  model: model,
  prompt: 'What is the sum of the first 10 prime numbers?',
  providerOptions: {
    google: {
      thinkingConfig: {
        thinkingLevel: 'high',
        includeThoughts: true,
      },
    } satisfies GoogleLanguageModelOptions,
  },
});

console.log(text);

console.log(reasoning); // Reasoning summary
```

#### Gemini 2.5 模型

对于 Gemini 2.5 模型，使用 `thinkingBudget` 参数控制思考 token 的数量：

```ts
import { google, GoogleLanguageModelOptions } from '@ai-sdk/google';
import { generateText } from 'ai';

const model = google('gemini-2.5-flash');

const { text, reasoning } = await generateText({
  model: model,
  prompt: 'What is the sum of the first 10 prime numbers?',
  providerOptions: {
    google: {
      thinkingConfig: {
        thinkingBudget: 8192,
        includeThoughts: true,
      },
    } satisfies GoogleLanguageModelOptions,
  },
});

console.log(text);

console.log(reasoning); // Reasoning summary
```

### 文件输入

Google 提供商支持文件输入，例如 PDF 文件。

```ts
import { google } from '@ai-sdk/google';
import { generateText } from 'ai';

const result = await generateText({
  model: google('gemini-3.8-flash'),
  messages: [
    {
      role: 'user',
      content: [
        {
          type: 'text',
          text: 'What is an embedding model according to this document?',
        },
        {
          type: 'file',
          data: fs.readFileSync('./data/ai.pdf'),
          mediaType: 'application/pdf',
        },
      ],
    },
  ],
});
```

你也可以直接使用 YouTube URL：

```ts
import { google } from '@ai-sdk/google';
import { generateText } from 'ai';

const result = await generateText({
  model: google('gemini-3.8-flash'),
  messages: [
    {
      role: 'user',
      content: [
        {
          type: 'text',
          text: 'Summarize this video',
        },
        {
          type: 'file',
          data: 'https://www.youtube.com/watch?v=dQw4w9WgXcQ',
          mediaType: 'video/mp4',
        },
      ],
    },
  ],
});
```

<Note>
  如果你将 URL 作为数据传入，AI SDK 会自动下载它们，但
  `https://generativelanguage.googleapis.com/v1beta/files/` 和 YouTube
  URL 除外。你可以使用 Google Generative AI Files API 将较大的文件上传到
  该位置。YouTube URL（公开或不公开的视频）可直接支持
  - 每个请求可以指定一个 YouTube 视频 URL。
</Note>

有关如何在提示词中使用文件的详细信息，请参见[文件部分](/docs/foundations/prompts#file-parts)。

### 缓存内容

Google 支持显式和隐式缓存，以帮助降低重复内容的成本。

#### 隐式缓存

Gemini 模型自动提供缓存成本节省，无需创建显式缓存。当你发送与之前请求共享公共前缀的请求时，缓存内容将获得 75% 的 token 折扣。

要最大化隐式缓存的缓存命中：

- 保持请求开头的内容一致
- 在提示词末尾添加可变内容（如用户问题）
- 确保请求满足最低 token 要求：
  - Gemini 3 系列：最少 4096 个 token
  - Gemini 2.5 系列：最少 2048 个 token

```ts
import { google } from '@ai-sdk/google';
import { generateText } from 'ai';

// Structure prompts with consistent content at the beginning
const baseContext =
  'You are a cooking assistant with expertise in Italian cuisine. Here are 1000 lasagna recipes for reference...';

const { text: veggieLasagna } = await generateText({
  model: google('gemini-3.8-flash'),
  prompt: `${baseContext}\n\nWrite a vegetarian lasagna recipe for 4 people.`,
});

// Second request with same prefix - eligible for cache hit
const { text: meatLasagna, providerMetadata } = await generateText({
  model: google('gemini-3.8-flash'),
  prompt: `${baseContext}\n\nWrite a meat lasagna recipe for 12 people.`,
});

// Check cached token count in usage metadata
console.log('Cached tokens:', providerMetadata.google);
// e.g.
// {
//   groundingMetadata: null,
//   safetyRatings: null,
//   usageMetadata: {
//     cachedContentTokenCount: 5027,
//     thoughtsTokenCount: 702,
//     promptTokenCount: 5152,
//     candidatesTokenCount: 710,
//     totalTokenCount: 6564
//   }
// }
```

<Note>
  使用元数据在 `@ai-sdk/google@1.2.23` 中被添加到 `providerMetadata`。如果你
  使用的是较旧版本，使用元数据可在 `generateText` 返回值中返回的原始 HTTP
  `response` 正文中找到。
</Note>

#### 显式缓存

为了确保成本节省，你仍然可以对 Gemini 2.5 和 3 系列模型使用显式缓存。请查看[模型页面](https://ai.google.dev/gemini-api/docs/models)以确认所使用的模型是否支持缓存：

```ts
import { google, type GoogleLanguageModelOptions } from '@ai-sdk/google';
import { GoogleGenAI } from '@google/genai';
import { generateText } from 'ai';

const ai = new GoogleGenAI({
  apiKey: process.env.GOOGLE_GENERATIVE_AI_API_KEY,
});

const model = 'gemini-3.8-flash';

// Create a cache with the content you want to reuse
const cache = await ai.caches.create({
  model,
  config: {
    contents: [
      {
        role: 'user',
        parts: [{ text: '1000 Lasagna Recipes...' }],
      },
    ],
    ttl: '300s', // Cache expires after 5 minutes
  },
});

const { text: veggieLasagnaRecipe } = await generateText({
  model: google(model),
  prompt: 'Write a vegetarian lasagna recipe for 4 people.',
  providerOptions: {
    google: {
      cachedContent: cache.name,
    } satisfies GoogleLanguageModelOptions,
  },
});

const { text: meatLasagnaRecipe } = await generateText({
  model: google(model),
  prompt: 'Write a meat lasagna recipe for 12 people.',
  providerOptions: {
    google: {
      cachedContent: cache.name,
    } satisfies GoogleLanguageModelOptions,
  },
});
```

### 代码执行

通过[代码执行](https://ai.google.dev/gemini-api/docs/code-execution)，某些模型可以生成并执行 Python 代码来执行计算、解决问题或提供更准确的信息。

你可以通过向请求添加 `code_execution` 工具来启用代码执行。

```ts
import { google } from '@ai-sdk/google';
import { googleTools } from '@ai-sdk/google/internal';
import { generateText } from 'ai';

const { text, toolCalls, toolResults } = await generateText({
  model: google('gemini-3.8-flash'),
  tools: { code_execution: google.tools.codeExecution({}) },
  prompt: 'Use python to calculate the 20th fibonacci number.',
});
```

响应将包含代码执行产生的工具调用和结果。

### Google 搜索

通过 [Google 搜索接地](https://ai.google.dev/gemini-api/docs/google-search)，
模型可以使用 Google 搜索访问最新信息。

```ts highlight="8,17-19"
import { google } from '@ai-sdk/google';
import { GoogleProviderMetadata } from '@ai-sdk/google';
import { generateText } from 'ai';

const { text, sources, providerMetadata } = await generateText({
  model: google('gemini-3.8-flash'),
  tools: {
    google_search: google.tools.googleSearch({}),
  },
  prompt:
    'List the top 5 San Francisco news from the past week.' +
    'You must include the date of each article.',
});

// access the grounding metadata. Casting to the provider metadata type
// is optional but provides autocomplete and type safety.
const metadata = providerMetadata?.google as GoogleProviderMetadata | undefined;
const groundingMetadata = metadata?.groundingMetadata;
const safetyRatings = metadata?.safetyRatings;
```

`googleSearch` 工具接受以下可选配置选项：

- **searchTypes** _object_

  启用特定的搜索类型。两者可以组合使用。
  - `webSearch`：启用网络搜索接地（传入 `{}` 以启用）。这是默认值。
  - `imageSearch`：启用[图像搜索接地](https://ai.google.dev/gemini-api/docs/image-generation#image-search)（传入 `{}` 以启用）。

- **timeRangeFilter** _object_

  将搜索结果限制在特定的时间范围内。`startTime` 和 `endTime` 都是必需的。
  - `startTime`：ISO 8601 格式的开始时间（例如 `'2025-01-01T00:00:00Z'`）。
  - `endTime`：ISO 8601 格式的结束时间（例如 `'2025-12-31T23:59:59Z'`）。

```ts
google.tools.googleSearch({
  searchTypes: { webSearch: {} },
  timeRangeFilter: {
    startTime: '2025-01-01T00:00:00Z',
    endTime: '2025-12-31T23:59:59Z',
  },
});
```

启用 Google 搜索接地后，模型将在响应中包含来源。

此外，接地元数据包含有关如何使用搜索结果来接地模型响应的详细信息。以下是可用字段：

- **`webSearchQueries`** (`string[] | null`)
  - 用于检索信息的搜索查询数组
  - 示例：`["What's the weather in Chicago this weekend?"]`

- **`searchEntryPoint`** (`{ renderedContent: string } | null`)
  - 包含用作入口点的主要搜索结果内容
  - `renderedContent` 字段包含格式化内容

- **`groundingSupports`**（支持对象数组 | null）
  - 包含有关特定响应部分如何由搜索结果支持的详细信息
  - 每个支持对象包括：
    - **`segment`**：有关接地文本段的信息
      - `text`：实际文本段
      - `startIndex`：响应中的起始位置
      - `endIndex`：响应中的结束位置
    - **`groundingChunkIndices`**：对支持搜索结果块的引用
    - **`confidenceScores`**：每个支持块的置信度分数（0-1）

示例响应：

```json
{
  "groundingMetadata": {
    "webSearchQueries": ["What's the weather in Chicago this weekend?"],
    "searchEntryPoint": {
      "renderedContent": "..."
    },
    "groundingSupports": [
      {
        "segment": {
          "startIndex": 0,
          "endIndex": 65,
          "text": "Chicago weather changes rapidly, so layers let you adjust easily."
        },
        "groundingChunkIndices": [0],
        "confidenceScores": [0.99]
      }
    ]
  }
}
```

### 企业网络搜索

通过[企业网络搜索](https://cloud.google.com/vertex-ai/generative-ai/docs/grounding/web-grounding-enterprise)，
模型可以访问专为金融、医疗和公共部门等高度监管行业设计的合规性网络索引。

<Note>
  企业网络搜索仅在 Vertex AI 上可用。你必须使用 Google
  Vertex 提供商（`@ai-sdk/google-vertex`）而不是标准 Google
  提供商（`@ai-sdk/google`）才能使用此功能。需要 Gemini 2.0 或更新版本的
  模型。
</Note>

```ts
import { createGoogleVertex } from '@ai-sdk/google-vertex';
import { generateText } from 'ai';

const vertex = createGoogleVertex({
  project: 'my-project',
  location: 'us-central1',
});

const { text, sources, providerMetadata } = await generateText({
  model: vertex('gemini-3.8-flash'),
  tools: {
    enterprise_web_search: vertex.tools.enterpriseWebSearch({}),
  },
  prompt: 'What are the latest regulatory updates for financial services?',
});
```

企业网络搜索提供以下优势：

- 不记录客户数据
- 支持 VPC 服务控制
- 面向受监管行业的合规性网络索引

### 文件搜索

[文件搜索工具](https://ai.google.dev/gemini-api/docs/file-search)让 Gemini 从你在文件搜索存储中索引的自有文档中检索上下文。该提供商为 Gemini 2.5 和 Gemini 3 及更高版本模型 ID（包括未识别的未来 Gemini ID）启用此工具。

```ts highlight="9-13"
import { google } from '@ai-sdk/google';
import { generateText } from 'ai';

const { text, sources } = await generateText({
  model: google('gemini-3.8-flash'),
  tools: {
    file_search: google.tools.fileSearch({
      fileSearchStoreNames: [
        'projects/my-project/locations/us/fileSearchStores/my-store',
      ],
      metadataFilter: 'author = "Robert Graves"',
      topK: 8,
    }),
  },
  prompt: "Summarise the key themes of 'I, Claudius'.",
});
```

文件搜索响应通过常规 `sources` 字段包含引用，并在 `providerMetadata.google.groundingMetadata` 中暴露原始[接地元数据](#google-search)。

### URL 上下文

Google 提供提供商定义的 URL 上下文工具。

URL 上下文工具允许你直接在提示词中提供希望模型分析的特定 URL。

```ts highlight="9,13-15"
import { google } from '@ai-sdk/google';
import { generateText } from 'ai';

const { text, sources, providerMetadata } = await generateText({
  model: google('gemini-3.8-flash'),
```

```ts highlight="7-16"
import { google, type GoogleLanguageModelOptions } from '@ai-sdk/google';
import { GoogleProviderMetadata } from '@ai-sdk/google';
import { generateText } from 'ai';

const { text, sources, providerMetadata } = await generateText({

  },
  prompt:
    'What are the best Italian restaurants within a 15-minute walk from here?',
});

const metadata = providerMetadata?.google as GoogleProviderMetadata | undefined;
const groundingMetadata = metadata?.groundingMetadata;
```

可选的 `retrievalConfig.latLng` 提供商选项为有关附近地点的查询提供位置上下文。此配置适用于任何支持位置上下文的接地工具，包括 Google Maps 和 Google Search。

启用 Google Maps 接地后，模型的响应将包含指向 Google Maps URL 的来源。接地元数据包含带有地点信息的 `maps` 块：

### RAG Engine 接地

通过 [RAG Engine 接地](https://cloud.google.com/vertex-ai/generative-ai/docs/rag-engine/use-vertexai-search#generate-content-using-gemini-api)，
模型可以使用 Vertex RAG Engine 访问你的自定义知识库。
这使模型能够基于你的特定数据源和文档提供答案。

<Note>
  RAG Engine 接地仅支持 Vertex Gemini 模型。你必须使用
  Google Vertex 提供商（`@ai-sdk/google-vertex`）而不是标准
  Google 提供商（`@ai-sdk/google`）才能使用此功能。
</Note>

```ts highlight="5-8,13-17,25-27"
import { createGoogleVertex } from '@ai-sdk/google-vertex';
import { GoogleProviderMetadata } from '@ai-sdk/google';
import { generateText } from 'ai';

const vertex = createGoogleVertex({
  project: 'my-project',
  location: 'us-central1',
});

const { text, sources, providerMetadata } = await generateText({
  model: vertex('gemini-3.8-flash'),
  tools: {
    vertex_rag_store: vertex.tools.vertexRagStore({
      ragCorpus:
        'projects/my-project/locations/us-central1/ragCorpora/my-rag-corpus',
      topK: 5,
    }),
  },
  prompt:
    'What are the key features of our product according to our documentation?',
});

// access the grounding metadata. Casting to the provider metadata type
// is optional but provides autocomplete and type safety.
const metadata = providerMetadata?.google as GoogleProviderMetadata | undefined;
const groundingMetadata = metadata?.groundingMetadata;
const safetyRatings = metadata?.safetyRatings;
```

启用 RAG Engine 接地后，模型将在响应中包含来自你的 RAG 语料库的来源。

此外，接地元数据包含有关如何使用 RAG 结果来接地模型响应的详细信息。以下是可用字段：

- **`groundingChunks`**（块对象数组 | null）
  - 包含从你的 RAG 语料库检索到的上下文块
  - 每个块包括：
    - **`retrievedContext`**：有关检索到的上下文的信息
      - `uri`：源文档的 URI 或标识符
      - `title`：源文档的标题（可选）
      - `text`：块的实际文本内容

- **`groundingSupports`**（支持对象数组 | null）
  - 包含有关特定响应部分如何由 RAG 结果支持的详细信息
  - 每个支持对象包括：
    - **`segment`**：有关接地文本段的信息
      - `text`：实际文本段
      - `startIndex`：响应中的起始位置
      - `endIndex`：响应中的结束位置
    - **`groundingChunkIndices`**：对支持 RAG 结果块的引用
    - **`confidenceScores`**：每个支持块的置信度分数（0-1）

示例响应：

```json
{
  "groundingMetadata": {
    "groundingChunks": [
      {
        "retrievedContext": {
          "uri": "gs://my-bucket/docs/product-guide.pdf",
          "title": "Product User Guide",
          "text": "Our product includes advanced AI capabilities, real-time processing, and enterprise-grade security features."
        }
      }
    ],
    "groundingSupports": [
      {
        "segment": {
          "startIndex": 0,
          "endIndex": 45,
          "text": "Our product includes advanced AI capabilities and real-time processing."
        },
        "groundingChunkIndices": [0],
        "confidenceScores": [0.95]
      }
    ]
  }
}
```

#### 配置选项

`vertexRagStore` 工具接受以下配置选项：

- **`ragCorpus`**（`string`，必需）
  - RagCorpus 资源名称，格式为：`projects/{project}/locations/{location}/ragCorpora/{rag_corpus}`
  - 这标识了你要搜索的特定 RAG 语料库

- **`topK`**（`number`，可选）
  - 从你的 RAG 语料库中检索的顶部上下文数量
  - 如果未指定，默认为语料库配置

### 批处理

<Note type="warning">
  批处理支持是实验性的，API 可能会在补丁版本中发生变化。
</Note>

Google 提供商通过 [Gemini
Batch API](https://ai.google.dev/gemini-api/docs/batch-api) 支持异步文本生成。将 Google
提供商传递给 AI SDK 的 [Batch](/docs/ai-sdk-core/batch)
API 以完成完整工作流，包括轮询、持久化和结果处理。

每个请求指定其 `type` 和 `model`。Google 要求批处理中的每个文本
请求使用相同的模型，当模型不同时会在提交前抛出错误。

#### Webhook

你可以传入 `webhookUrl` 以在批处理达到终止状态时接收通知：

```ts
import { google } from '@ai-sdk/google';
import { experimental_startBatch as startBatch } from 'ai';

const model = 'gemini-3.8-flash';

const batch = await startBatch({
  provider: google,
  requests: [
    {
      id: 'capital-france',
      type: 'text',
      model,
      prompt: 'What is the capital of France?',
    },
    {
      id: 'capital-germany',
      type: 'text',
      model,
      prompt: 'What is the capital of Germany?',
    },
  ],
  webhookUrl: 'https://example.com/api/google-batch-webhook',
});
```

Google 向 webhook URL 发送一个轻量事件。在接收并验证事件后，使用持久化的批处理引用调用 `getBatchStatus` 或 `getBatchResults`。你的应用程序负责处理 webhook 并[验证 Google 的动态 webhook 签名](https://ai.google.dev/gemini-api/docs/webhooks#verify_dynamic_signatures_jwks)。

#### 大批量

当序列化的批处理创建正文小于 20 MB 时，提供商会内联发送请求。达到 20 MB 或以上时，它会通过 Gemini Files API 上传 JSONL 输入文件。

## 实时模型

<Note type="warning">实时是实验性功能。</Note>

你可以使用 `.experimental_realtime()` 工厂方法创建调用 [Gemini Live API](https://ai.google.dev/gemini-api/docs/live)
的模型。

```ts
import { google } from '@ai-sdk/google';

const model = google.experimental_realtime('gemini-3.1-flash-live-preview');
```

实时会话在浏览器中运行，需要在你服务器上使用
`google.experimental_realtime.getToken()` 创建的短期令牌：

```ts
const token = await google.experimental_realtime.getToken({
  model: 'gemini-3.1-flash-live-preview',
});
```

Google 实时模型可能需要特定于提供商的音频格式，具体取决于
模型和模态。有关完整设置和工具调用模式，请参见[实时](/docs/ai-sdk-core/realtime)。

没有提供商中立等价物的 Gemini 生命周期信号
会作为自定义事件发出。检查 `rawType` 中的 `goAway`、
`sessionResumptionUpdate` 和 `generationComplete`，并使用事件的 `raw`
负载获取提供商特定的详细信息。

### 实时翻译

使用 `gemini-3.5-live-translate-preview` 进行低延迟语音到语音
翻译。在创建令牌时使用的实时会话配置中，通过
`providerOptions.google.translationConfig` 配置目标语言：

```ts
import {
  google,
  type Experimental_GoogleRealtimeModelOptions as GoogleRealtimeModelOptions,
} from '@ai-sdk/google';

const token = await google.experimental_realtime.getToken({
  model: 'gemini-3.5-live-translate-preview',
  sessionConfig: {
    outputModalities: ['audio'],
    inputAudioTranscription: {},
    outputAudioTranscription: {},
    providerOptions: {
      google: {
        translationConfig: {
          targetLanguageCode: 'pl',
          echoTargetLanguage: true,
        },
      } satisfies GoogleRealtimeModelOptions,
    },
  },
});
```

将 `targetLanguageCode` 设置为 BCP-47 语言代码（默认为 `en`）。当
`echoTargetLanguage` 为 `true` 时，已经是目标语言的输入音频会被回显，而不是产生静音。

Gemini Live Translation 接受音频输入并产生翻译后的音频
输出。此模型不支持文本输入、工具和自定义指令。

### Gemini 3.8 Live

`gemini-3.8-live` 和 `gemini-3.8-live-extended-thinking` 是纯音频
实时模型：请求 `outputModalities: ['audio']`，如果你想要助手的转录文本作为
`audio-transcript-delta` 事件，请添加
`outputAudioTranscription: {}`。服务器端语音活动检测和
主动音频始终开启。

`gemini-3.8-live-extended-thinking` 在流式传输音频时在后台进行推理。Google 要求它必须恰好设置 `thinkingLevel`（`low`、`medium`、`high`）
或 `thinkingBudget` 之一；当你两者都未设置时，提供商会发送 `thinkingLevel: 'low'`。通过 `providerOptions.google.thinkingConfig` 覆盖它：

```ts
import {
  google,
  type Experimental_GoogleRealtimeModelOptions as GoogleRealtimeModelOptions,
} from '@ai-sdk/google';

const token = await google.experimental_realtime.getToken({
  model: 'gemini-3.8-live-extended-thinking',
  sessionConfig: {
    outputModalities: ['audio'],
    outputAudioTranscription: {},
    providerOptions: {
      google: {
        thinkingConfig: { thinkingLevel: 'high' },
      } satisfies GoogleRealtimeModelOptions,
    },
  },
});
```

在会话配置中声明的工具在这些模型上默认异步运行（`NON_BLOCKING`），
因此模型在工具调用进行时继续说话。在
`gemini-3.8-live` 上设置 `providerOptions.google.defaultToolBehavior: 'BLOCKING'` 使其改为等待结果。

在扩展思考模型上，`turnComplete`（`response-done` 事件）并不
意味着模型处于空闲状态。观察 `interactionStatus` 自定义事件：其
`raw.interactionStatus` 为 `IN_PROGRESS`、`IDLE` 或 `WAITING_FOR_INPUT`。当模型已停止并需要
用户输入才能继续时，会发出 `waitingForInput` 自定义事件。

## 翻译模型

<Note type="warning">语音翻译是实验性功能。</Note>

对于服务器端流式翻译，你可以使用
`.translation()` 工厂方法创建调用
[Gemini Live API](https://ai.google.dev/gemini-api/docs/live) 的模型。翻译模型仅支持流式传输，并与
[`experimental_streamTranslate`](/docs/reference/ai-sdk-core/stream-translate) 一起使用。

第一个参数是模型 ID，例如 `gemini-3.5-live-translate-preview`。

```ts
const model = google.translation('gemini-3.5-live-translate-preview');
```

```ts
import { experimental_streamTranslate as streamTranslate } from 'ai';
import { google } from '@ai-sdk/google';

const result = streamTranslate({
  model: google.translation('gemini-3.5-live-translate-preview'),
  audio: audioStream, // ReadableStream<Uint8Array | string>
  inputAudioFormat: { type: 'audio/pcm', rate: 16000 },
  targetLanguage: 'es',
});

for await (const part of result.fullStream) {
  if (part.type === 'output-text-delta') {
    process.stdout.write(part.delta);
  }
}
```

Gemini Live API 自动检测源语言（不支持 `sourceLanguage`），
并始终输出 24kHz 16 位 PCM 音频（不支持 `outputAudioFormat`）。不支持的设置会作为调用警告显示。

以下提供商选项可用：

- **echoTargetLanguage** _boolean_
  是否回显已经是目标语言的输入音频，而不是
  产生静音。
  可选。

## Interactions API

[Gemini Interactions API](https://ai.google.dev/gemini-api/docs/interactions)
（`POST /v1beta/interactions`）是一个独立的 Google 端点，具有服务器端
状态、统一内容块、一等内置工具、智能体预设、
在沙盒 Linux 环境中运行的管理智能体，以及原生
多模态图像和视频输出。它通过
`google.interactions(...)` 工厂访问：

```ts
import { google } from '@ai-sdk/google';
import { generateText } from 'ai';

const { text } = await generateText({
  model: google.interactions('gemini-3.8-flash'),
  prompt: 'Hello, how are you?',
});
```

`google.interactions(...)` 接受模型 ID 字符串（例如
`'gemini-3.8-flash'`、`'gemini-3.1-pro-preview'`）、`{ agent: <name> }` 以使用
Gemini [智能体预设](#agent-presets)，或 `{ managedAgent: <name> }` 以
调用你在 Google 侧创建的[管理智能体](#managed-agents)。
返回的模型可以像任何其他 AI SDK 语言模型一样传递给 `generateText` 和 `streamText`。

<Note>
  使用 `google(...)` 访问标准 `:generateContent` /
  `:streamGenerateContent` 端点，使用 `google.interactions(...)` 访问新的
  Interactions 端点。每个模型实例选择一种——它们针对不同的
  请求正文和 SSE 事件词汇表。
</Note>

### 提供商选项

Interactions 模型从共享的
`providerOptions.google.*` 命名空间读取其选项。使用
`GoogleLanguageModelInteractionsOptions` 类型验证它们：

```ts
import {
  google,
  type GoogleLanguageModelInteractionsOptions,
} from '@ai-sdk/google';
import { generateText } from 'ai';

await generateText({
  model: google.interactions('gemini-3.8-flash'),
  prompt: 'What color is the sky in one word?',
  providerOptions: {
    google: {
      serviceTier: 'priority',
    } satisfies GoogleLanguageModelInteractionsOptions,
  },
});
```

以下可选提供商选项可用：

- **previousInteractionId** _string_

  来自上一轮的服务器端交互 ID。设置后，服务器从其自身状态拉取
  先前上下文，线上仅发送新的用户消息。与默认 `store: true` 配对以链接有状态
  对话。参见[有状态链接](#stateful-chaining)。

- **store** _boolean_

  服务器是否应持久化交互。默认为 `true`。
  对于无状态多轮对话，设置为 `false`，其中完整的
  消息历史在每一轮重新发送。

- **agent** _string_

  Gemini 智能体预设的名称（例如 `'deep-research-pro-preview-12-2025'`）。

      <Note>

  优先使用工厂形式 `google.interactions({ agent: '...' })` 而不是
  在提供商选项中设置 `agent`——工厂会根据支持的智能体名称进行类型检查。

  </Note>

- **agentConfig** _object_

  每个智能体的配置。目前支持 `{ type: 'dynamic' }` 和
  `{ type: 'deep-research', thinkingSummaries?, visualization?, collaborativePlanning? }`。

- **thinkingLevel** _'minimal' | 'low' | 'medium' | 'high'_

  控制支持思考的模型的推理深度。映射到
  Interactions 请求的 `thinking_level`。

- **thinkingSummaries** _'auto' | 'none'_

  模型是否在推理部分返回综合的思考摘要。默认为 API 默认值。

- **responseFormat** _Array\<ResponseFormatEntry\>_

  直接映射到 API 的 `response_format`
  数组的输出格式条目。条目具有以下形状：

  ```ts
  type ResponseFormatEntry =
    | { type: 'text'; mimeType?: string; schema?: unknown }
    | {
        type: 'image';
        mimeType?: string;
        aspectRatio?: string;
        imageSize?: '1K' | '2K' | '4K' | '512';
      }
    | { type: 'audio'; mimeType?: string }
    | {
        type: 'video';
        aspectRatio?: '16:9' | '9:16';
        resolution?: '360p' | '720p' | '1080p' | '4k';
        duration?: string;
        delivery?: 'inline' | 'uri';
        gcsUri?: string;
      };
  ```

  用于对图像、音频、视频或非 JSON
  文本输出进行细粒度控制。视频条目可以控制宽高比、分辨率、时长
  以及内联或 URI 交付；在交付到 Google Cloud
  Storage 时设置 `gcsUri`。内联视频由 `generateText` 在 `result.files` 中返回，并由 `streamText`
  作为 `file` 部分发出。
  AI SDK 调用级别的 `responseFormat: { type: 'json', schema }` 仍然
  自动驱动 JSON 模式并前置匹配的文本条目；
  此处列出的条目会被追加。

  对于图像条目，`aspectRatio` 接受 `1:1`、`2:3`、`3:2`、`3:4`、`4:3`、
  `4:5`、`5:4`、`9:16`、`16:9`、`21:9`、`1:8`、`8:1`、`1:4`、`4:1`。

- **imageConfig** _\{ aspectRatio?: string; imageSize?: '1K' | '2K' | '4K' | '512' \}_（已弃用）

  改用带有 `{ type: 'image', ... }` 条目的 **responseFormat**。
  保留用于向后兼容；SDK 将 `imageConfig`
  转换为匹配的 `response_format` 图像条目，并在设置时发出警告。当 `responseFormat` 已提供图像条目时忽略。

- **mediaResolution** _'low' | 'medium' | 'high' | 'ultra_high'_

  应用于图像输入/输出的媒体分辨率。

- **serviceTier** _'flex' | 'standard' | 'priority'_

  请求的服务层级。镜像回
  `result.providerMetadata.google.serviceTier` 以供可观测性。

- **systemInstruction** _string_

  AI SDK `system` 消息的替代方案。如果两者都设置，AI SDK
  `system` 消息优先并发出警告。

- **background** _boolean_

  在后台运行交互。对于服务器端工作流无法在单个请求/响应内完成的智能体是必需的；
  仅支持同步调用的智能体会拒绝。当为 `true` 时，
  POST 返回非终止状态，SDK 轮询
  `GET /interactions/{id}` 直到工作完成。

- **environment** _string \| object_

  [管理智能体](#managed-agents)的沙盒环境配置。
  传入 `'remote'` 以配置新的沙盒，传入 `environment_id`
  字符串以重用现有的，或传入形式为
  `{ type: 'remote', sources?, network? }` 的对象以预加载文件和/或
  限制出站流量。仅适用于智能体调用。

- **pollingTimeoutMs** _number_

  在放弃之前轮询后台交互的最长时间（以毫秒为单位）。默认为 30 分钟（1,800,000 毫秒）。长时间运行的智能体
  可能需要更长的时间。

### 提供商元数据

`result.providerMetadata.google`（通过 `GoogleInteractionsProviderMetadata` 类型化）
暴露：

- **interactionId** _string_

  服务器端交互 ID。在下一轮将其作为 `previousInteractionId` 传回以链接。

- **serviceTier** _string_

  请求实际运行的服务层级。

- **signature** _string_

  每个块的签名字符串，由 SDK 在输出推理和
  工具调用或智能体视频处理部分上设置。在下一轮自动往返。

智能体视频自定义部分额外暴露：

- **processingId** _string_

  智能体视频 `processing_call` 的 ID。存在于
  `google.processing_call` 自定义部分上。

- **processingCallId** _string_

  匹配的智能体视频处理调用的 ID。存在于
  `google.processing_result` 自定义部分上。

### 有状态链接

使用默认 `store: true`，服务器保留上一轮，因此
下一个请求只需要发送新的用户消息和
`previousInteractionId`：

```ts
import {
  google,
  type GoogleLanguageModelInteractionsOptions,
} from '@ai-sdk/google';
import { generateText } from 'ai';

const turn1 = await generateText({
  model: google.interactions('gemini-3.8-flash'),
  prompt: 'What are the three largest cities in Spain?',
});

const interactionId = turn1.providerMetadata?.google?.interactionId as
  | string
  | undefined;

const turn2 = await generateText({
  model: google.interactions('gemini-3.8-flash'),
  prompt: 'What is the most famous landmark in the second one?',
  providerOptions: {
    google: {
      previousInteractionId: interactionId,
    } satisfies GoogleLanguageModelInteractionsOptions,
  },
});
```

对于无状态多轮对话，设置 `store: false` 并在每一轮重新发送
完整消息历史（不使用 `previousInteractionId`）：

```ts
import {
  google,
  type GoogleLanguageModelInteractionsOptions,
} from '@ai-sdk/google';
import { generateText, type ModelMessage } from 'ai';

const messages: Array<ModelMessage> = [
  { role: 'user', content: 'What are the three largest cities in Spain?' },
];

const turn1 = await generateText({
  model: google.interactions('gemini-3.8-flash'),
  messages,
  providerOptions: {
    google: { store: false } satisfies GoogleLanguageModelInteractionsOptions,
  },
});

messages.push(...turn1.responseMessages);
messages.push({
  role: 'user',
  content: 'What is the most famous landmark in the second one?',
});

const turn2 = await generateText({
  model: google.interactions('gemini-3.8-flash'),
  messages,
  providerOptions: {
    google: { store: false } satisfies GoogleLanguageModelInteractionsOptions,
  },
});
```

### 智能体视频理解

Gemini 3.7 Flash、3.6 Flash 和 3.5 Flash Lite 通过 Interactions API 支持智能体视频
理解。模型不是以固定帧率采样整个
视频，而是动态导航时间线并
加载提示词所需的转录文本、帧或音频。

在单个视频文件部分的 Google 提供商选项中设置 `processing: 'agentic'`。你可以使用
`GoogleInteractionsVideoOptions` 验证每个文件的选项：

```ts
import { google, type GoogleInteractionsVideoOptions } from '@ai-sdk/google';
import { generateText } from 'ai';

const result = await generateText({
  model: google.interactions('gemini-3.8-flash'),
  messages: [
    {
      role: 'user',
      content: [
        {
          type: 'file',
          data: 'https://www.youtube.com/watch?v=9hE5-98ZeCg',
          mediaType: 'video',
          providerOptions: {
            google: {
              processing: 'agentic',
            } satisfies GoogleInteractionsVideoOptions,
          },
        },
        {
          type: 'text',
          text: 'Identify the three most important moments and include timestamps.',
        },
      ],
    },
  ],
  providerOptions: {
    google: {
      thinkingSummaries: 'auto',
    },
  },
});

const processingSteps = result.content.filter(
  part =>
    part.type === 'custom' &&
    (part.kind === 'google.processing_call' ||
      part.kind === 'google.processing_result'),
);
```

智能体导航作为 `custom` 内容部分暴露：

- `google.processing_call` 标记模型检查视频一部分的请求。其 `providerMetadata.google.processingId` 包含处理 ID。
- `google.processing_result` 标记该请求的完成。其
  `providerMetadata.google.processingCallId` 将其链接到处理调用。

这些部分仅供参考，不需要工具响应。它们
可从 `generateText` 和 `streamText` 获得。

对于静态处理，使用 `'static'` 或提供剪辑和帧率
选项：

```ts
const video = {
  type: 'file' as const,
  data: videoBytes,
  mediaType: 'video/mp4',
  providerOptions: {
    google: {
      processing: {
        type: 'static',
        startOffset: 1200,
        endOffset: 1500,
        fps: 0.5,
      },
    } satisfies GoogleInteractionsVideoOptions,
  },
};
```

对于有状态对话，将返回的 `interactionId` 作为
`previousInteractionId` 传入；Gemini 在服务器端保留视频上下文。使用
`store: false` 时，追加 `result.responseMessages` 并重新发送完整历史。
处理自定义部分及其签名随后作为
原生 `processing_call` 和 `processing_result` 步骤往返，以便保留视频上下文。

### 内置工具

Interactions API 附带内置工具目录。`google.tools.*` 下的提供商定义
工具映射到 Interactions 工具描述符：

| AI SDK 工具                            | Interactions 工具类型   | 备注                                       |
| ------------------------------------- | ---------------------- | ----------------------------------------- |
| `google.tools.googleSearch`           | `google_search`        | 网络/图像搜索接地。                        |
| `google.tools.codeExecution`          | `code_execution`       | 服务器端 Python 执行。                     |
| `google.tools.urlContext`             | `url_context`          | 获取提示词中引用的 URL。                   |
| `google.tools.fileSearch`             | `file_search`          | 从文件搜索存储检索。                       |
| `google.tools.googleMaps`             | `google_maps`          | 附近地点查询的地图接地。                   |
| _提供商工具_ `google.computer_use`     | `computer_use`         | 计算机使用（浏览器环境）。                 |
| _提供商工具_ `google.mcp_server`       | `mcp_server`           | 远程 MCP 服务器透传。                      |
| _提供商工具_ `google.retrieval`        | `retrieval`            | Vertex AI Search 检索。                    |

使用 AI SDK `tool(...)`
辅助函数定义的函数工具（`type: 'function'`）被转换为 Interactions `function` 工具描述符。其他
工具类型会发出警告并被丢弃。

```ts
import { google } from '@ai-sdk/google';
import { generateText } from 'ai';

const { text, sources } = await generateText({
  model: google.interactions('gemini-3.8-flash'),
  tools: {
    google_search: google.tools.googleSearch({}),
  },
  prompt:
    "What's a notable AI development from this past week? " +
    'Include the date for each item you mention.',
});
```

函数工具的工作方式与标准提供商相同：

```ts
import { google } from '@ai-sdk/google';
import { generateText, isStepCount, tool } from 'ai';
import { z } from 'zod';

const weatherTool = tool({
  description: 'Get the weather for a city.',
  inputSchema: z.object({ city: z.string() }),
  execute: async ({ city }) => `It is sunny in ${city}.`,
});

const { text, toolCalls } = await generateText({
  model: google.interactions('gemini-3.8-flash'),
  tools: { getWeather: weatherTool },
  stopWhen: isStepCount(5),
  prompt: 'What is the weather in San Francisco right now?',
});
```

### 通过 Interactions 输出图像

在支持 Gemini 图像能力的模型上，向 `responseFormat` 添加 `{ type: 'image' }` 条目，以在
响应中获得作为 `LanguageModelV4FilePart` 文件的图像。无需工具包装，该条目同时作为
设置 `aspectRatio`、`imageSize` 和 `mimeType` 的位置。

```ts
import {
  google,
  type GoogleLanguageModelInteractionsOptions,
} from '@ai-sdk/google';
import { generateText } from 'ai';

const result = await generateText({
  model: google.interactions('gemini-3-pro-image-preview'),
  prompt: 'Generate an image of a comic cat in a spaceship.',
  providerOptions: {
    google: {
      responseFormat: [{ type: 'image' }],
    } satisfies GoogleLanguageModelInteractionsOptions,
  },
});

for (const file of result.files) {
  if (file.mediaType.startsWith('image/')) {
    // file.uint8Array | file.base64 | file.mediaType
  }
}
```

要控制宽高比、图像大小或输出 mime 类型，请将那些
字段添加到同一图像条目：

```ts
import {
  google,
  type GoogleLanguageModelInteractionsOptions,
} from '@ai-sdk/google';
import { generateText } from 'ai';

const result = await generateText({
  model: google.interactions('gemini-3-pro-image-preview'),
  prompt: 'Generate a high-quality landscape photo of mountains at sunset.',
  providerOptions: {
    google: {
      responseFormat: [
        {
          type: 'image',
          aspectRatio: '16:9',
          imageSize: '4K',
        },
      ],
    } satisfies GoogleLanguageModelInteractionsOptions,
  },
});
```

对于多模态输出，为每个模态列出一个条目。模型在 `result.text` 中返回
文本，并在 `result.files` 中返回附带的图像：

```ts
import {
  google,
  type GoogleLanguageModelInteractionsOptions,
} from '@ai-sdk/google';
import { generateText } from 'ai';

const result = await generateText({
  model: google.interactions('gemini-3.1-flash-image-preview'),
  prompt:
    'Tell me a three sentence bedtime story about a unicorn, accompanied by a suitable illustration.',
  providerOptions: {
    google: {
      responseFormat: [
        { type: 'text' },
        { type: 'image', aspectRatio: '16:9' },
      ],
    } satisfies GoogleLanguageModelInteractionsOptions,
  },
});

console.log(result.text);

const images = result.files.filter(file => file.mediaType.startsWith('image/'));
// images[0].uint8Array | images[0].base64 | images[0].mediaType
```

迭代图像编辑与有状态链接自然配对——在轮次之间保持
`previousInteractionId` 设置，模型会编辑其先前的
输出：

```ts
import {
  google,
  type GoogleLanguageModelInteractionsOptions,
} from '@ai-sdk/google';
import { generateText } from 'ai';

const model = google.interactions('gemini-3-pro-image-preview');

const turn1 = await generateText({
  model,
  prompt: 'Generate an image of a comic cat in a spaceship.',
  providerOptions: {
    google: {
      responseFormat: [{ type: 'image' }],
    } satisfies GoogleLanguageModelInteractionsOptions,
  },
});

const interactionId = turn1.providerMetadata?.google?.interactionId as
  | string
  | undefined;

const turn2 = await generateText({
  model,
  prompt: 'now make the cat red',
  providerOptions: {
    google: {
      responseFormat: [{ type: 'image' }],
      previousInteractionId: interactionId,
    } satisfies GoogleLanguageModelInteractionsOptions,
  },
});
```

### 智能体预设

传入 `{ agent: <name> }` 以定位 Gemini 智能体预设。工厂
会根据支持的集合对智能体名称进行类型检查：

```ts
import {
  google,
  type GoogleLanguageModelInteractionsOptions,
} from '@ai-sdk/google';
import { generateText } from 'ai';

const result = await generateText({
  model: google.interactions({
    agent: 'deep-research-pro-preview-12-2025',
  }),
  prompt:
    'Briefly summarize the most-cited papers on retrieval-augmented generation since 2024 (2-3 sentences).',
  providerOptions: {
    google: {
      background: true,
    } satisfies GoogleLanguageModelInteractionsOptions,
  },
});
```

智能体是同步运行还是在后台运行取决于
智能体。长时间运行的预设（例如 `deep-research-*` 系列）
需要 `background: true`——POST 返回非终止状态，
SDK 在内部轮询 `GET /interactions/{id}` 直到交互
完成。其他智能体仅接受同步调用，并将拒绝
`background: true`。通过
`providerOptions.google.background` 显式设置该标志。

默认轮询超时为 30 分钟；对于较慢的智能体，通过
`pollingTimeoutMs` 提高它：

```ts
import {
  google,
  type GoogleLanguageModelInteractionsOptions,
} from '@ai-sdk/google';
import { generateText } from 'ai';

await generateText({
  model: google.interactions({ agent: 'deep-research-max-preview-04-2026' }),
  prompt: 'Produce a long-form research brief on ...',
  providerOptions: {
    google: {
      background: true,
      pollingTimeoutMs: 60 * 60 * 1000, // 1 hour
    } satisfies GoogleLanguageModelInteractionsOptions,
  },
});
```

智能体也像模型 ID 调用一样通过 `previousInteractionId` 链接。

### 管理智能体

[管理智能体](https://ai.google.dev/gemini-api/docs/agents)在每次交互配置的
沙盒 Linux 环境中运行。传入 `environment`
提供商选项以控制沙盒的设置方式；该选项仅在
智能体调用时被接受。

最简单的形式配置一个新的沙盒：

```ts
import {
  google,
  type GoogleLanguageModelInteractionsOptions,
} from '@ai-sdk/google';
import { generateText } from 'ai';

const result = await generateText({
  model: google.interactions({ agent: 'antigravity-preview-05-2026' }),
  prompt: 'What is 2 + 2?',
  providerOptions: {
    google: {
      environment: 'remote',
    } satisfies GoogleLanguageModelInteractionsOptions,
  },
});
```

`environment` 接受三种形式：

- `'remote'`——为此调用配置一个新的沙盒。
- 任何其他字符串——要重用的 `environment_id`，分叉先前的
  沙盒，使其文件系统和已安装的包持久化。
- 一个对象——配置一个新的沙盒，并可选择预加载 `sources`
  和/或通过 `network` 限制出站流量：

```ts
import {
  google,
  type GoogleLanguageModelInteractionsOptions,
} from '@ai-sdk/google';
import { generateText } from 'ai';

await generateText({
  model: google.interactions({ agent: 'antigravity-preview-05-2026' }),
  prompt:
    'Read the file at /data/note.txt and tell me exactly what it contains.',
  providerOptions: {
    google: {
      environment: {
        type: 'remote',
        sources: [
          {
            type: 'inline',
            content: 'hello from the AI SDK example\n',
            target: '/data/note.txt',
          },
        ],
      },
    } satisfies GoogleLanguageModelInteractionsOptions,
  },
});
```

支持三种源类型：`inline`（将字符串写入
沙盒中的 `target`）、`repository`（克隆 git 仓库——将
URL 作为 `source` 传入）和 `gcs`（挂载 Google Cloud Storage 前缀）。

`network` 字段接受字符串 `'disabled'` 以阻止所有
出站流量，或接受带有 `allowlist` 数组的对象，其条目
每个都带有 `domain` 以及可选的 `transform` 数组，其中包含要注入到匹配请求的请求头
对象。

#### 自定义管理智能体

对于你通过
Gemini API 的 `/v1beta/agents` 端点在 Google 侧创建的用户定义智能体，通过专用的
`managedAgent` 工厂形式传入智能体名称，而不是 `agent`（后者仅接受
已知的预设名称）：

```ts
import {
  google,
  type GoogleLanguageModelInteractionsOptions,
} from '@ai-sdk/google';
import { generateText } from 'ai';

const result = await generateText({
  model: google.interactions({ managedAgent: 'my-custom-agent' }),
  prompt: 'Hello!',
  providerOptions: {
    google: {
      environment: 'remote',
    } satisfies GoogleLanguageModelInteractionsOptions,
  },
});
```

### 流式传输

支持 `streamText`。流的 `finish` 部分在 `providerMetadata.google` 上暴露
`interactionId`，以便调用者可以链接。

```ts
import { google } from '@ai-sdk/google';
import { streamText } from 'ai';

const result = streamText({
  model: google.interactions('gemini-3.8-flash'),
  prompt: 'Hello, how are you?',
});

for await (const textPart of result.textStream) {
  process.stdout.write(textPart);
}

const googleMetadata = (await result.providerMetadata)?.google;
console.log('Interaction id:', googleMetadata?.interactionId);
```

## Gemma 模型

你可以将 [Gemma 模型](https://deepmind.google/models/gemma/)与 Google Generative AI API 一起使用。
以下 Gemma 模型可用：

- `gemma-3-27b-it`
- `gemma-3-12b-it`

Gemma 模型原生不支持 `systemInstruction` 参数，但提供商会自动处理系统指令，将其前置到第一条用户消息。这允许你无缝地将系统指令与 Gemma 模型一起使用：

```ts
import { google } from '@ai-sdk/google';
import { generateText } from 'ai';

const { text } = await generateText({
  model: google('gemma-3-27b-it'),
  instructions: 'You are a helpful assistant that responds concisely.',
  prompt: 'What is machine learning?',
});
```

系统指令会自动格式化并包含在对话中，因此 Gemma 模型无需任何额外配置即可遵循指导。

## 嵌入模型

你可以使用 `.embedding()` 工厂方法创建调用 [Google Generative AI 嵌入 API](https://ai.google.dev/gemini-api/docs/embeddings)
的模型。

```ts
const model = google.embedding('gemini-embedding-2');
```

Google 提供商根据嵌入类型将 API 调用发送到正确的端点：

- **单个嵌入**：使用 `embed()` 嵌入单个值时，提供商使用单个 `:embedContent` 端点，与批处理端点相比，它通常具有更高的速率限制。
- **批量嵌入**：使用 `embedMany()` 嵌入多个值或在 `embed()` 中嵌入多个值时，提供商使用 `:batchEmbedContents` 端点。

Google 嵌入模型支持额外设置。你可以将它们作为选项参数传入：

```ts
import { google, type GoogleEmbeddingModelOptions } from '@ai-sdk/google';
import { embed } from 'ai';

const model = google.embedding('gemini-embedding-001');

const { embedding } = await embed({
  model,
  value: 'sunny day at the beach',
  providerOptions: {
    google: {
      outputDimensionality: 512, // optional, number of dimensions for the embedding
      taskType: 'SEMANTIC_SIMILARITY', // optional, specifies the task type for generating embeddings
      content: [[{ text: 'additional context' }]], // optional, per-value multimodal content (only 1 here, since `value` is only a single one)
    } satisfies GoogleEmbeddingModelOptions,
  },
});
```

使用 `embedMany` 时，通过 `content` 选项提供每个值的多模态内容。每个条目对应相同索引处的值；对于纯文本条目使用 `null`：

```ts
import { google, type GoogleEmbeddingModelOptions } from '@ai-sdk/google';
import { embedMany } from 'ai';

const { embeddings } = await embedMany({
  model: google.embedding('gemini-embedding-2'),
  values: ['sunny day at the beach', 'rainy afternoon in the city'],
  providerOptions: {
    google: {
      // content array must have the same length as values
      content: [
        [{ inlineData: { mimeType: 'image/png', data: '<base64>' } }], // pairs with values[0]
        null, // text-only, pairs with values[1]
      ],
    } satisfies GoogleEmbeddingModelOptions,
  },
});
```

Google 嵌入模型可使用以下可选提供商选项：

- **outputDimensionality**：_number_

  输出嵌入的可选降维。如果设置，输出嵌入中的多余值将从末尾截断。

- **taskType**：_string_

  可选。指定生成嵌入的任务类型。支持的任务类型包括：
  - `SEMANTIC_SIMILARITY`：针对文本相似度优化。
  - `CLASSIFICATION`：针对文本分类优化。
  - `CLUSTERING`：针对基于相似度的文本聚类优化。
  - `RETRIEVAL_DOCUMENT`：针对文档检索优化。
  - `RETRIEVAL_QUERY`：针对基于查询的检索优化。
  - `QUESTION_ANSWERING`：针对回答问题优化。
  - `FACT_VERIFICATION`：针对验证事实信息优化。
  - `CODE_RETRIEVAL_QUERY`：针对基于自然语言查询检索代码块优化。

- **content**：_array_

  可选。用于嵌入非文本内容（图像、视频、PDF、音频）的每个值的多模态内容部分。每个条目对应相同索引处的嵌入值——其部分与请求中的文本值合并。对于纯文本条目使用 `null`。数组长度必须与被嵌入的值的数量匹配。每个非 null 条目是部分数组，其中每个部分可以是 `{ text: string }`、用于内联 base64 数据的 `{ inlineData: { mimeType: string, data: string } }`，或用于通过 HTTP URL 或 Google Cloud Storage URI（`gs://...`）引用远程内容的 `{ fileData: { fileUri: string, mimeType: string } }`。由 `gemini-embedding-2-preview` 支持。

### 模型能力

| ---------------------------- | ------------------ | ----------------- | ---------- |
| `gemini-embedding-001`       | 3072               | <Check />         | <Cross />  |
| `gemini-embedding-2`         | 3072               | <Check />         | <Check />  |

## 图像模型

你可以使用 `.image()` 工厂方法创建调用 Google Generative AI API 的图像模型。
有关使用 AI SDK 进行图像生成的更多信息，请参见 [generateImage()](/docs/reference/ai-sdk-core/generate-image)。

`.image()` 工厂通过 `:generateContent` API 支持具有图像
输出能力的 Gemini 多模态语言模型。

### Gemini 图像模型

[Gemini 图像模型](https://ai.google.dev/gemini-api/docs/image-generation)（例如 `gemini-3.1-flash-image-preview`）在技术上是多模态输出语言模型，但它们可以与 `generateImage()` 函数一起使用，以获得更简单的图像生成体验。在内部，提供商使用 `responseModalities: ['IMAGE']` 调用语言模型 API。

```ts
import { google } from '@ai-sdk/google';
import { generateImage } from 'ai';

const { image } = await generateImage({
  model: google.image('gemini-3.1-flash-image-preview'),
  prompt: 'A photorealistic image of a cat wearing a wizard hat',
  aspectRatio: '1:1',
});
```

Gemini 图像模型还通过提供输入图像支持图像编辑：

```ts
import { google } from '@ai-sdk/google';
import { generateImage } from 'ai';
import fs from 'node:fs';

const sourceImage = fs.readFileSync('./cat.png');

const { image } = await generateImage({
  model: google.image('gemini-3.1-flash-image-preview'),
  prompt: {
    text: 'Add a small wizard hat to this cat',
    images: [sourceImage],
  },
});
```

你也可以为输入图像使用 URL：

```ts
import { google } from '@ai-sdk/google';
import { generateImage } from 'ai';

const { image } = await generateImage({
  model: google.image('gemini-3.1-flash-image-preview'),
  prompt: {
    text: 'Add a small wizard hat to this cat',
    images: ['https://example.com/cat.png'],
  },
});
```

<Note>
  Gemini 图像模型不支持 `size` 或 `n` 参数。使用
  `aspectRatio` 而不是 `size`。也不支持基于蒙版的修复。
</Note>

<Note>
  对于需要文本和图像输出的更高级用例，或
  希望对生成过程有更多控制，你可以直接将 Gemini 图像模型
  与 `generateText()` 一起使用。详情请参见[图像输出](#image-outputs)。
</Note>

#### Google 搜索接地

Gemini 图像模型通过 `providerOptions.google.googleSearch` 支持 [Google 搜索接地](#google-search)。该值与 `google.tools.googleSearch(...)` 的参数匹配；传入 `{}` 以使用默认值启用，或传入 `{ searchTypes: { imageSearch: {} } }` 以基于参考照片接地。

```ts
import { google, type GoogleImageModelOptions } from '@ai-sdk/google';
import { generateImage } from 'ai';

const result = await generateImage({
  model: google.image('gemini-3.1-flash-image-preview'),
  prompt:
    'Search for live footage of the 2026 Super Bowl halftime show artist, then generate a close-up in space.',
  providerOptions: {
    google: {
      googleSearch: { searchTypes: { imageSearch: {} } },
    } satisfies GoogleImageModelOptions,
  },
});

// Grounding metadata is forwarded onto the image result:
console.log(result.providerMetadata?.google?.groundingMetadata);
```

| `gemini-3-pro-image-preview`     | <Check />        | <Check />     | 1:1, 2:3, 3:2, 3:4, 4:3, 4:5, 5:4, 9:16, 16:9, 21:9 |
| `gemini-3.1-flash-image-preview` | <Check />        | <Check />     | 1:1, 2:3, 3:2, 3:4, 4:3, 4:5, 5:4, 9:16, 16:9, 21:9 |

  2K、4K 通过 `providerOptions.google.imageConfig.imageSize`）以及 Google 搜索

</Note>

## 语音模型

你可以使用 `.speech()` 工厂方法创建调用 [Gemini 文本转语音 API](https://ai.google.dev/gemini-api/docs/speech-generation)
的模型。

第一个参数是模型 ID，例如 `gemini-3.8-flash-tts` 或
`gemini-3.8-flash-lite-tts`。语音生成使用 `generateContent` API。

```ts
const model = google.speech('gemini-3.8-flash-tts');
```

`voice` 参数可以设置为 Gemini 的 [30 个预构建语音](https://ai.google.dev/gemini-api/docs/speech-generation#voices)
之一，例如 `Kore`、`Puck`、`Zephyr` 或 `Charon`。语音名称区分大小写。
默认语音是 `Kore`。不支持自定义语音 ID 和复制密钥。

```ts highlight="6"
import { generateSpeech } from 'ai';
import { google } from '@ai-sdk/google';

const result = await generateSpeech({
  model: google.speech('gemini-3.8-flash-tts'),
  text: 'Hello, world!',
  voice: 'Kore', // Gemini voice name
});
```

默认情况下，生成的音频作为可播放的 WAV 文件返回
（`result.audio.mediaType` 为 `audio/wav`）。Gemini 3.8 返回完整的 WAV 文件；
提供商将这些字节原样传递。较旧的模型返回原始 PCM，
提供商会将其包装在 WAV 容器中。直接将 `result.audio.uint8Array`
写入磁盘，无需添加另一个 WAV 头。

Gemini 3.8 支持以下 `outputFormat` 值：

| 格式   | 值                     | 结果                         |
| ------ | ---------------------- | ---------------------------- |
| WAV    | `wav`, `audio/wav`     | 带 RIFF 头的 WAV             |
| PCM    | `pcm`, `audio/l16`     | 无头有符号 16 位 PCM         |
| Mu-law | `mulaw`, `audio/mulaw` | 无头 mu-law 音频             |
| A-law  | `alaw`, `audio/alaw`   | 无头 A-law 音频              |

这些映射到
`generateContent` 中的 `generationConfig.responseFormat.audio.mimeType`。较旧的模型支持 `wav` 和 `pcm`。源 MIME 类型和
采样率可在 `result.providerMetadata.google` 中获得。

Gemini 2.5 和 3.1 模型 ID 保留旧版请求格式。其他模型 ID，
包括自定义别名，使用结构化语音格式。

### Gemini 3.8 中的语音指导

Gemini 3.8 将文本视为逐字转录。提供商将 `instructions`
作为 `speechMetadata.style` 发送，保持文本不变。你也可以提供
`providerOptions.google.speechMetadata`，带有 `style` 和 `speaker` 字段。
显式样式会覆盖 `instructions`，包括空样式字符串。

```ts
const result = await generateSpeech({
  model: google.speech('gemini-3.8-flash-tts'),
  text: 'Welcome back. <short pause> It is good to see you. <laugh>',
  instructions: 'Warm, relaxed, and speaking slowly',
});
```

将持续的说话指导（如低语、缓慢说话或
喘不过气）放在元数据中。将瞬间的语音事件和停顿（如
`<laugh>`、`<sigh>`、`<cough>`、`<breath>` 和 `<short pause>`）保留在转录文本中。
避免使用掌声或重击等音效标签。提供商会按原样保留内联
标签。

对于 Gemini 3.1 及更早版本，提供商保留将 `instructions` 前置到单说话人文本的现有行为。对于较旧的多说话人请求，它会忽略指令并发出
警告。结构化 `turns` 和 `speechMetadata`
需要 Gemini 3.8。

### 多说话人音频

对于 Gemini 3.8 对话，通过
`providerOptions.google` 传入 `multiSpeakerVoiceConfig` 和 `turns`。每一轮都必须包含与已配置说话人匹配的 `speechMetadata.speaker`；缺失或未知的说话人会在请求发送前产生错误。说话人标签属于元数据，而不是文本。

`turns` 数组替换顶层文本，因此传入 `text: ''`。合并的
轮次文本必须非空。传入
非空顶层文本与轮次会产生警告。将元数据放在每一轮上，
而不是将轮次与顶层 `speechMetadata` 组合。每一轮的样式会覆盖 `instructions`；没有样式的轮次继承 `instructions`。

`multiSpeakerVoiceConfig` 覆盖顶层 `voice`。每个 `voiceConfig`
使用 `prebuiltVoiceConfig: { voiceName: 'Kore' }`。Google 在多说话人请求中最多支持两个
预构建语音。

```ts
import { generateSpeech } from 'ai';
import { google, type GoogleSpeechModelOptions } from '@ai-sdk/google';

const result = await generateSpeech({
  model: google.speech('gemini-3.8-flash-lite-tts'),
  text: '',
  providerOptions: {
    google: {
      multiSpeakerVoiceConfig: {
        speakerVoiceConfigs: [
          {
            speaker: 'Joe',
            voiceConfig: { prebuiltVoiceConfig: { voiceName: 'Kore' } },
          },
          {
            speaker: 'Jane',
            voiceConfig: { prebuiltVoiceConfig: { voiceName: 'Puck' } },
          },
        ],
      },
      turns: [
        {
          text: 'How are you?',
          speechMetadata: { speaker: 'Joe', style: 'curious' },
        },
        {
          text: '<laugh> Doing great, thanks!',
          speechMetadata: { speaker: 'Jane', style: 'cheerful' },
        },
      ],
    } satisfies GoogleSpeechModelOptions,
  },
});
```

较旧的模型继续使用带标签的转录文本，例如
`text: 'Joe: How are you? Jane: Doing great, thanks!'`，配合
`multiSpeakerVoiceConfig` 且不使用 `turns`。

<Note>
  Gemini TTS 模型不支持 `speed` 或 `language` 选项；传入
  它们会向 `result.warnings` 添加警告。语言会根据输入文本
  自动检测。
</Note>

| `gemini-2.5-pro-preview-tts`   | <Check />     | <Check />              |

## 评估模型

使用 `google.evaluationModel(modelId)` 创建实验性评估模型。
它使用 Gemini 结构化输出处理 Choice、Score 和 Boolean 问题。选择一个
支持结构化输出的模型，例如 `gemini-3.5-flash-lite`。

```ts
import { google } from '@ai-sdk/google';
import { experimental_evaluate } from 'ai';

const { answers } = await experimental_evaluate({
  model: google.evaluationModel('gemini-3.5-flash-lite'),
  state: 'I was charged twice.',
  questions: {
    requestsRefund: {
      type: 'boolean',
      instructions: 'Is the customer requesting money back?',
    },
    department: {
      type: 'choice',
      instructions: 'Which team should handle this?',
      criteria: { billing: 'Charges and refunds', support: 'Other requests' },
    },
  },
  providerOptions: {
    google: { thinkingConfig: { thinkingLevel: 'minimal' } },
  },
});
```

该工厂遵循 `createGoogle` 设置并转发 `providerOptions.google`，
包括思考配置。思考控制取决于所选模型；
使用该模型支持的选项。现有的 Gemini 实现将
答案 schema 作为 `generationConfig.responseJsonSchema` 发送。

Choice 标签会精确返回，Score 是有序评分标准内的有限小数位置。适配器在解析后验证完整答案，
并拒绝被安全阻止、截断或无效的输出。它保留使用情况
（包括推理 token）、警告、响应数据和提供商元数据。

Choice 和 Score 答案不包含概率分布。Boolean
答案包含 P(true) 的提示估计，验证为有限且在
`[0, 1]` 内。这些估计不保证经过校准。在应用程序代码中应用阈值，
例如 `answers.requestsRefund.probability >= 0.5`。参见[评估](/docs/ai-sdk-core/evaluation)。

评估模型也可以通过 `customProvider` 别名或
`createProviderRegistry().evaluationModel('provider:model')` 访问。直接字符串 ID
默认使用 Gateway，或使用显式配置的具有
`evaluationModel` 方法的默认提供商。参见
[模型别名和注册表](/docs/ai-sdk-core/evaluation#model-aliases-and-registries)。
