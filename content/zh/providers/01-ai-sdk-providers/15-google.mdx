# Google 提供商

[Google](https://ai.google.dev) 提供商包含对 [Google](https://ai.google.dev/api/rest) API 的语言和嵌入模型支持。

## 安装

Google 提供商可在 `@ai-sdk/google` 模块中使用。你可以通过以下命令安装：

<InstallPackages packages="@ai-sdk/google" />

## 提供商实例

你可以从 `@ai-sdk/google` 导入默认提供商实例 `google`：

```ts
import { google } from '@ai-sdk/google';
```

如果你需要自定义设置，可以从 `@ai-sdk/google` 导入 `createGoogle` 并使用你的设置创建提供商实例：

```ts
import { createGoogle } from '@ai-sdk/google';

const google = createGoogle({
  // 自定义设置
});
```

你可以使用以下可选设置来自定义 Google 提供商实例：

- **baseURL** _string_

  为 API 调用使用不同的 URL 前缀，例如使用代理服务器。
  默认前缀为 `https://generativelanguage.googleapis.com/v1beta`。

- **apiKey** _string_

  通过 `x-goog-api-key` 请求头发送的 API 密钥。
  默认为 `GOOGLE_GENERATIVE_AI_API_KEY` 环境变量。

- **headers** _Record&lt;string,string&gt;_

  要包含在请求中的自定义请求头。

- **fetch** _(input: RequestInfo, init?: RequestInit) => Promise&lt;Response&gt;_

  自定义 [fetch](https://developer.mozilla.org/en-US/docs/Web/API/fetch) 实现。
  默认为全局 `fetch` 函数。
  你可以将其用作中间件来拦截请求，
  或提供自定义 fetch 实现，例如用于测试。

- **generateId** _() => string_

  为每个请求生成唯一 ID 的可选函数。
  默认为 SDK 内置的 ID 生成器。

- **name** _string_

  自定义提供商名称。
  默认为 `'google.generative-ai'`。

## 语言模型

你可以使用提供商实例创建调用 [Google Generative AI API](https://ai.google.dev/api/rest) 的模型。
第一个参数是模型 ID，例如 `gemini-3.7-flash`。
这些模型支持工具调用，部分模型具有多模态能力。

```ts
const model = google('gemini-3.7-flash');
```

你可以使用 Google 语言模型通过 `generateText` 函数生成文本：

```ts
import { google } from '@ai-sdk/google';
import { generateText } from 'ai';

const { text } = await generateText({
  model: google('gemini-3.7-flash'),
  prompt: '为 4 人写一份素食千层面食谱。',
});
```

Google 语言模型也可以用于 `streamText` 函数，
并支持通过 [`Output`](/docs/reference/ai-sdk-core/output) 进行结构化数据生成
（参见 [AI SDK Core](/docs/ai-sdk-core)）。

<Note>
  为了保持向前兼容，提供商将无法识别的 `gemini-*` 模型 ID 和 `-latest` 别名视为最新支持的 Gemini 代际。
  目前，这意味着 Gemini 3 对提供商定义和混合工具、`thinkingLevel` 推理、多模态函数响应和思维签名的请求行为。
  已知的旧版 Gemini 模型 ID 保持其特定代际的请求行为。
  此 SDK 默认值控制请求序列化；所选模型仍必须支持 Google API 中的每个功能。
</Note>

Google 还支持一些不属于[标准调用设置](/docs/ai-sdk-core/settings)的模型特定设置。
你可以将它们作为选项参数传递：

```ts
import { google, type GoogleLanguageModelOptions } from '@ai-sdk/google';

const model = google('gemini-3.7-flash');

await generateText({
  model,
  providerOptions: {
    google: {
      safetySettings: [
        {
          category: 'HARM_CATEGORY_UNSPECIFIED',
          threshold: 'BLOCK_LOW_AND_ABOVE',
        },
      ],
    } satisfies GoogleLanguageModelOptions,
  },
});
```

以下可选的提供商选项可用于 Google 模型：

- **cachedContent** _string_

  可选。用作预测上下文的缓存内容名称。
  格式：cachedContents/\{cachedContent\}

- **structuredOutputs** _boolean_

  可选。启用结构化输出。默认为 true。

  当 JSON Schema 包含 Google 使用的 OpenAPI schema 版本不支持的
  元素时，此选项很有用。如果需要，你可以使用此选项禁用
  结构化输出。

  有关更多详细信息，请参阅[故障排除：Schema 限制](#schema-limitations)。

- **safetySettings** _Array\<\{ category: string; threshold: string \}\>_

  可选。模型的安全设置。
  - **category** _string_

    安全设置的类别。可以是以下之一：
    - `HARM_CATEGORY_UNSPECIFIED`
    - `HARM_CATEGORY_HATE_SPEECH`
    - `HARM_CATEGORY_DANGEROUS_CONTENT`
    - `HARM_CATEGORY_HARASSMENT`
    - `HARM_CATEGORY_SEXUALLY_EXPLICIT`
    - `HARM_CATEGORY_CIVIC_INTEGRITY`

  - **threshold** _string_

    安全设置的阈值。可以是以下之一：
    - `HARM_BLOCK_THRESHOLD_UNSPECIFIED`
    - `BLOCK_LOW_AND_ABOVE`
    - `BLOCK_MEDIUM_AND_ABOVE`
    - `BLOCK_ONLY_HIGH`
    - `BLOCK_NONE`
    - `OFF`

- **responseModalities** _string[]_
  响应的模态。支持以下模态：`TEXT`、`IMAGE`。未定义或为空时，模型默认仅返回文本。

- **thinkingConfig** _\{ thinkingLevel?: 'minimal' | 'low' | 'medium' | 'high'; thinkingBudget?: number; includeThoughts?: boolean \}_

  可选。模型思考过程的配置。仅受特定 [Google 模型](https://ai.google.dev/gemini-api/docs/thinking) 支持。
  - **thinkingLevel** _'minimal' | 'low' | 'medium' | 'high'_

    可选。控制 Gemini 3 及更高版本模型的思考深度。Gemini 3.1 Pro 支持 'low'、'medium' 和 'high'，Gemini 3 Pro 支持 'low' 和 'high'，而 Gemini 3 Flash 支持全部四个级别：'minimal'、'low'、'medium' 和 'high'。

  - **thinkingBudget** _number_

    可选。为模型生成响应时可使用的思考 token 数量提供指导。设置为 0 可禁用思考（如果模型支持）。
    有关每个模型可能的值范围的更多信息，请参阅 [Google 思考文档](https://ai.google.dev/gemini-api/docs/thinking#set-budget)。

    <Note>
      此选项适用于 Gemini 2.5 模型。Gemini 3 及更高版本模型应使用
      `thinkingLevel` 代替。
    </Note>

  - **includeThoughts** _boolean_

    可选。如果设置为 true，则返回思考摘要，这些摘要是模型原始思考的综合版本，可提供对模型内部推理过程的洞察。

- **imageConfig** _\{ aspectRatio?: string, imageSize?: string \}_

  可选。模型图像生成的配置。仅受特定 [Google 模型](https://ai.google.dev/gemini-api/docs/image-generation) 支持。
  - **aspectRatio** _string_

    模型默认生成 1:1 正方形，或将输出图像大小与输入图像匹配。可以是以下之一：
    - 1:1
    - 2:3
    - 3:2
    - 3:4
    - 4:3
    - 4:5
    - 5:4
    - 9:16
    - 16:9
    - 21:9

  - **imageSize** _string_

    控制输出图像分辨率。默认为 1K。可以是以下之一：
    - 1K
    - 2K
    - 4K

- **audioTimestamp** _boolean_

  可选。启用仅音频文件的时间戳理解。
  参见 [Google Cloud 音频理解文档](https://cloud.google.com/vertex-ai/generative-ai/docs/multimodal/audio-understanding)。

- **mediaResolution** _string_

  可选。如果指定，将使用指定的媒体分辨率。可以是以下之一：
  - `MEDIA_RESOLUTION_UNSPECIFIED`
  - `MEDIA_RESOLUTION_LOW`
  - `MEDIA_RESOLUTION_MEDIUM`
  - `MEDIA_RESOLUTION_HIGH`

  参见 [Google API MediaResolution 文档](https://ai.google.dev/api/generate-content#MediaResolution)。

- **labels** _Record&lt;string, string&gt;_

  可选。定义计费报告中使用的标签。仅在 Vertex AI 上可用。
  参见 [Google Cloud 标签文档](https://cloud.google.com/vertex-ai/generative-ai/docs/multimodal/add-labels-to-api-calls)。

- **serviceTier** _'standard' | 'flex' | 'priority'_

  可选。请求使用的服务层级。
  设置为 `'flex'` 可享受 50% 的折扣，但延迟会增加。
  设置为 `'priority'` 可获得超低延迟，但价格比 `'standard'` 高 75-100%。

  由于 Priority 在负载下可以优雅地降级为 Standard，因此请求实际运行的层级会显示在
  `result.providerMetadata.google.serviceTier` 上。参见
  [Priority 推理](https://ai.google.dev/gemini-api/docs/priority-inference)
  和 [Flex 推理](https://ai.google.dev/gemini-api/docs/flex-inference)。

- **threshold** _string_

  可选。独立的阈值设置，可独立于 `safetySettings` 使用。
  使用与 `safetySettings` 阈值相同的值。

### 思考

Gemini 2.5 和 Gemini 3 及更高版本系列模型使用内部"思考过程"，显著提高了推理和多步规划能力，使其在编码、高等数学和数据分析等复杂任务中非常高效。有关更多信息，请参阅 [Google 思考文档](https://ai.google.dev/gemini-api/docs/thinking)。

#### Gemini 3 及更高版本模型

对于 Gemini 3 及更高版本模型，使用 `thinkingLevel` 参数控制推理深度：

```ts
import { google, GoogleLanguageModelOptions } from '@ai-sdk/google';
import { generateText } from 'ai';

const model = google('gemini-3.7-flash');

const { text, reasoning } = await generateText({
  model: model,
  prompt: '前 10 个质数的和是多少？',
  providerOptions: {
    google: {
      thinkingConfig: {
        thinkingLevel: 'high',
        includeThoughts: true,
      },
    } satisfies GoogleLanguageModelOptions,
  },
});

console.log(text);

console.log(reasoning); // 推理摘要
```

#### Gemini 2.5 模型

对于 Gemini 2.5 模型，使用 `thinkingBudget` 参数控制思考 token 的数量：

```ts
import { google, GoogleLanguageModelOptions } from '@ai-sdk/google';
import { generateText } from 'ai';

const model = google('gemini-2.5-flash');

const { text, reasoning } = await generateText({
  model: model,
  prompt: '前 10 个质数的和是多少？',
  providerOptions: {
    google: {
      thinkingConfig: {
        thinkingBudget: 8192,
        includeThoughts: true,
      },
    } satisfies GoogleLanguageModelOptions,
  },
});

console.log(text);

console.log(reasoning); // 推理摘要
```

### 文件输入

Google 提供商支持文件输入，例如 PDF 文件。

```ts
import { google } from '@ai-sdk/google';
import { generateText } from 'ai';

const result = await generateText({
  model: google('gemini-3.7-flash'),
  messages: [
    {
      role: 'user',
      content: [
        {
          type: 'text',
          text: '根据此文档，什么是嵌入模型？',
        },
        {
          type: 'file',
          data: fs.readFileSync('./data/ai.pdf'),
          mediaType: 'application/pdf',
        },
      ],
    },
  ],
});
```

你也可以直接使用 YouTube URL：

```ts
import { google } from '@ai-sdk/google';
import { generateText } from 'ai';

const result = await generateText({
  model: google('gemini-3.7-flash'),
  messages: [
    {
      role: 'user',
      content: [
        {
          type: 'text',
          text: '总结这个视频',
        },
        {
          type: 'file',
          data: 'https://www.youtube.com/watch?v=dQw4w9WgXcQ',
          mediaType: 'video/mp4',
        },
      ],
    },
  ],
});
```

<Note>
  AI SDK 会自动下载你作为数据传递的 URL，但
  `https://generativelanguage.googleapis.com/v1beta/files/` 和 YouTube
  URL 除外。你可以使用 Google Generative AI Files API 将较大的文件上传到该位置。YouTube URL（公开或未列出的视频）直接受支持
  - 每个请求可以指定一个 YouTube 视频 URL。
</Note>

有关如何在提示词中使用文件的详细信息，请参阅[文件部分](/docs/foundations/prompts#file-parts)。

### 缓存内容

Google 支持显式和隐式缓存，以帮助降低重复内容的成本。

#### 隐式缓存

Gemini 模型自动提供缓存成本节省，无需创建显式缓存。当你发送与先前请求共享公共前缀的请求时，缓存内容将获得 75% 的 token 折扣。

要最大化隐式缓存的缓存命中率：

- 保持请求开头的内容一致
- 在提示词末尾添加可变内容（如用户问题）
- 确保请求满足最低 token 要求：
  - Gemini 3 系列：最低 4096 个 token
  - Gemini 2.5 系列：最低 2048 个 token

```ts
import { google } from '@ai-sdk/google';
import { generateText } from 'ai';

// 在开头使用一致的内容构建提示词
const baseContext =
  '你是一位精通意大利美食的烹饪助手。这里有 1000 份千层面食谱供参考...';

const { text: veggieLasagna } = await generateText({
  model: google('gemini-3.7-flash'),
  prompt: `${baseContext}\n\n为 4 人写一份素食千层面食谱。`,
});

// 具有相同前缀的第二个请求 - 符合缓存命中条件
const { text: meatLasagna, providerMetadata } = await generateText({
  model: google('gemini-3.7-flash'),
  prompt: `${baseContext}\n\n为 12 人写一份肉酱千层面食谱。`,
});

// 在 usage 元数据中检查缓存的 token 数量
console.log('缓存的 token:', providerMetadata.google);
// 例如
// {
//   groundingMetadata: null,
//   safetyRatings: null,
//   usageMetadata: {
//     cachedContentTokenCount: 5027,
//     thoughtsTokenCount: 702,
//     promptTokenCount: 5152,
//     candidatesTokenCount: 710,
//     totalTokenCount: 6564
//   }
// }
```

<Note>
  Usage 元数据在 `@ai-sdk/google@1.2.23` 中添加到 `providerMetadata`。如果你使用的是旧版本，usage 元数据可在 `generateText` 返回值中的原始 HTTP `response` 主体中获得。
</Note>

#### 显式缓存

为保证成本节省，你仍然可以对 Gemini 2.5 和 3 系列模型使用显式缓存。请参阅[模型页面](https://ai.google.dev/gemini-api/docs/models)检查所用模型是否支持缓存：

```ts
import { google, type GoogleLanguageModelOptions } from '@ai-sdk/google';
import { GoogleGenAI } from '@google/genai';
import { generateText } from 'ai';

const ai = new GoogleGenAI({
  apiKey: process.env.GOOGLE_GENERATIVE_AI_API_KEY,
});

const model = 'gemini-3.7-flash';

// 使用要重复使用的内容创建缓存
const cache = await ai.caches.create({
  model,
  config: {
    contents: [
      {
        role: 'user',
        parts: [{ text: '1000 份千层面食谱...' }],
      },
    ],
    ttl: '300s', // 缓存 5 分钟后过期
  },
});

const { text: veggieLasagnaRecipe } = await generateText({
  model: google(model),
  prompt: '为 4 人写一份素食千层面食谱。',
  providerOptions: {
    google: {
      cachedContent: cache.name,
    } satisfies GoogleLanguageModelOptions,
  },
});

const { text: meatLasagnaRecipe } = await generateText({
  model: google(model),
  prompt: '为 12 人写一份肉酱千层面食谱。',
  providerOptions: {
    google: {
      cachedContent: cache.name,
    } satisfies GoogleLanguageModelOptions,
  },
});
```

### 代码执行

通过[代码执行](https://ai.google.dev/gemini-api/docs/code-execution)，某些模型可以生成并执行 Python 代码来执行计算、解决问题或提供更准确的信息。

你可以通过在请求中添加 `code_execution` 工具来启用代码执行。

```ts
import { google } from '@ai-sdk/google';
import { googleTools } from '@ai-sdk/google/internal';
import { generateText } from 'ai';

const { text, toolCalls, toolResults } = await generateText({
  model: google('gemini-3.7-flash'),
  tools: { code_execution: google.tools.codeExecution({}) },
  prompt: '使用 python 计算第 20 个斐波那契数。',
});
```

响应将包含代码执行的工具调用和结果。

### Google 搜索

通过 [Google 搜索接地](https://ai.google.dev/gemini-api/docs/google-search)，
模型可以使用 Google 搜索访问最新信息。

```ts highlight="8,17-19"
import { google } from '@ai-sdk/google';
import { GoogleProviderMetadata } from '@ai-sdk/google';
import { generateText } from 'ai';

const { text, sources, providerMetadata } = await generateText({
  model: google('gemini-3.7-flash'),
  tools: {
    google_search: google.tools.googleSearch({}),
  },
  prompt:
    '列出过去一周旧金山的前 5 条新闻。' +
    '你必须包含每篇文章的日期。',
});

// 访问 grounding 元数据。转换为提供商元数据类型
// 是可选的，但提供自动完成和类型安全。
const metadata = providerMetadata?.google as GoogleProviderMetadata | undefined;
const groundingMetadata = metadata?.groundingMetadata;
const safetyRatings = metadata?.safetyRatings;
```

`googleSearch` 工具接受以下可选配置选项：

- **searchTypes** _object_

  启用特定搜索类型。两者可以组合。
  - `webSearch`：启用网页搜索接地（传递 `{}` 启用）。这是默认设置。
  - `imageSearch`：启用[图像搜索接地](https://ai.google.dev/gemini-api/docs/image-generation#image-search)（传递 `{}` 启用）。

- **timeRangeFilter** _object_

  将搜索结果限制在特定时间范围内。`startTime` 和 `endTime` 都是必需的。
  - `startTime`：ISO 8601 格式的开始时间（例如 `'2025-01-01T00:00:00Z'`）。
  - `endTime`：ISO 8601 格式的结束时间（例如 `'2025-12-31T23:59:59Z'`）。

```ts
google.tools.googleSearch({
  searchTypes: { webSearch: {} },
  timeRangeFilter: {
    startTime: '2025-01-01T00:00:00Z',
    endTime: '2025-12-31T23:59:59Z',
  },
});
```

启用 Google 搜索接地后，模型将在响应中包含来源。

此外，grounding 元数据包含有关搜索结果如何用于接地模型响应的详细信息。以下是可用字段：

- **`webSearchQueries`** (`string[] | null`)
  - 用于检索信息的搜索查询数组
  - 示例：`["What's the weather in Chicago this weekend?"]`

- **`searchEntryPoint`** (`{ renderedContent: string } | null`)
  - 包含用作入口点的主要搜索结果内容
  - `renderedContent` 字段包含格式化内容

- **`groundingSupports`** (支持对象数组 | null)
  - 包含有关特定响应部分如何受搜索结果支持的详细信息
  - 每个支持对象包括：
    - **`segment`**：有关接地文本段的信息
      - `text`：实际文本段
      - `startIndex`：响应中的起始位置
      - `endIndex`：响应中的结束位置
    - **`groundingChunkIndices`**：对支持搜索结果块的引用
    - **`confidenceScores`**：每个支持块的置信度分数（0-1）

示例响应：

```json
{
  "groundingMetadata": {
    "webSearchQueries": ["What's the weather in Chicago this weekend?"],
    "searchEntryPoint": {
      "renderedContent": "..."
    },
    "groundingSupports": [
      {
        "segment": {
          "startIndex": 0,
          "endIndex": 65,
          "text": "Chicago weather changes rapidly, so layers let you adjust easily."
        },
        "groundingChunkIndices": [0],
        "confidenceScores": [0.99]
      }
    ]
  }
}
```

### 企业级网页搜索

通过[企业级网页搜索](https://cloud.google.com/vertex-ai/generative-ai/docs/grounding/web-grounding-enterprise)，
模型可以访问面向金融、医疗保健和公共部门等高度监管行业的合规性网页索引。

<Note>
  企业级网页搜索仅在 Vertex AI 上可用。你必须使用 Google
  Vertex 提供商（`@ai-sdk/google-vertex`）而不是标准 Google
  提供商（`@ai-sdk/google`）来使用此功能。需要 Gemini 2.0 或更新版本
  的模型。
</Note>

```ts
import { createGoogleVertex } from '@ai-sdk/google-vertex';
import { generateText } from 'ai';

const vertex = createGoogleVertex({
  project: 'my-project',
  location: 'us-central1',
});

const { text, sources, providerMetadata } = await generateText({
  model: vertex('gemini-3.7-flash'),
  tools: {
    enterprise_web_search: vertex.tools.enterpriseWebSearch({}),
  },
  prompt: '金融服务的最新监管更新是什么？',
});
```

企业级网页搜索提供以下优势：

- 不记录客户数据
- 支持 VPC 服务控制
- 面向受监管行业的合规性网页索引

### 文件搜索

[文件搜索工具](https://ai.google.dev/gemini-api/docs/file-search) 允许 Gemini 从你在文件搜索存储中索引的自己的文档中检索上下文。提供商为 Gemini 2.5 和 Gemini 3 及更高版本的模型 ID 启用此工具，包括无法识别的未来 Gemini ID。

```ts highlight="9-13"
import { google } from '@ai-sdk/google';
import { generateText } from 'ai';

const { text, sources } = await generateText({
  model: google('gemini-3.7-flash'),
  tools: {
    file_search: google.tools.fileSearch({
      fileSearchStoreNames: [
        'projects/my-project/locations/us/fileSearchStores/my-store',
      ],
      metadataFilter: 'author = "Robert Graves"',
      topK: 8,
    }),
  },
  prompt: "总结《我，克劳狄斯》的关键主题。",

```

文件搜索响应通过常规 `sources` 字段包含引用，并在 `providerMetadata.google.groundingMetadata` 中暴露原始 [grounding 元数据](#google-search)。

### URL 上下文

Google 提供提供商定义的 URL 上下文工具。

URL 上下文工具允许你直接在提示词中提供希望模型分析的特定 URL。

```ts highlight="9,13-15"
import { google } from '@ai-sdk/google';
import { generateText } from 'ai';

const { text, sources, providerMetadata } = await generateText({
  model: google('gemini-3.7-flash'),
  prompt: `基于文档：https://ai.google.dev/gemini-api/docs/url-context。
          回答这个问题：一个请求中可以消费多少个链接？`,
  tools: {
    url_context: google.tools.urlContext({}),
  },
});

const metadata = providerMetadata?.google as GoogleProviderMetadata | undefined;
const groundingMetadata = metadata?.groundingMetadata;
const urlContextMetadata = metadata?.urlContextMetadata;
```

URL 上下文元数据包含有关模型如何使用 URL 上下文生成响应的详细信息。以下是可用字段：

- **`urlMetadata`** (`{ retrievedUrl: string; urlRetrievalStatus: string; }[] | null`)
  - URL 上下文元数据数组
  - 每个对象包括：
    - **`retrievedUrl`**：上下文的 URL
    - **`urlRetrievalStatus`**：URL 检索的状态

示例响应：

```json
{
  "urlMetadata": [
    {
      "retrievedUrl": "https://ai-sdk.dev/providers/ai-sdk-providers/google",
      "urlRetrievalStatus": "URL_RETRIEVAL_STATUS_SUCCESS"
    }
  ]
}
```

```json
"groundingMetadata": {
    "groundingChunks": [
        {
            "web": {
```

### Google 地图接地

通过 [Google 地图接地](https://ai.google.dev/gemini-api/docs/maps-grounding)，
模型可以访问 Google 地图数据以提供位置感知响应。这可以启用本地数据和地理空间上下文，例如查找附近的餐厅。

```ts highlight="7-16"
import { google, type GoogleLanguageModelOptions } from '@ai-sdk/google';
import { GoogleProviderMetadata } from '@ai-sdk/google';
import { generateText } from 'ai';

const { text, sources, providerMetadata } = await generateText({
  model: google('gemini-3.7-flash'),
  tools: {
    google_maps: google.tools.googleMaps({}),
  },
  providerOptions: {
    google: {
      retrievalConfig: {
        latLng: { latitude: 34.090199, longitude: -117.881081 },
      },
    } satisfies GoogleLanguageModelOptions,
  },
  prompt:
    '从这里步行 15 分钟内最好的意大利餐厅有哪些？',
});

const metadata = providerMetadata?.google as GoogleProviderMetadata | undefined;
const groundingMetadata = metadata?.groundingMetadata;
```

可选的 `retrievalConfig.latLng` 提供商选项为附近地点的查询提供位置上下文。此配置适用于任何支持位置上下文的 grounding 工具，包括 Google 地图和 Google 搜索。

启用 Google 地图接地后，模型的响应将包含指向 Google 地图 URL 的来源。grounding 元数据包含带有地点信息的 `maps` 块：

```json

```

### RAG 引擎接地

通过 [RAG 引擎接地](https://cloud.google.com/vertex-ai/generative-ai/docs/rag-engine/use-vertexai-search#generate-content-using-gemini-api)，
模型可以使用 Vertex RAG 引擎访问你的自定义知识库。
这使模型能够基于你的特定数据源和文档提供答案。

<Note>
  RAG 引擎接地仅支持 Vertex Gemini 模型。你必须使用
  Google Vertex 提供商（`@ai-sdk/google-vertex`）而不是标准 Google
  提供商（`@ai-sdk/google`）来使用此功能。
</Note>

```ts highlight="5-8,13-17,25-27"
import { createGoogleVertex } from '@ai-sdk/google-vertex';
import { GoogleProviderMetadata } from '@ai-sdk/google';
import { generateText } from 'ai';

const vertex = createGoogleVertex({
  project: 'my-project',
  location: 'us-central1',
});

const { text, sources, providerMetadata } = await generateText({
  model: vertex('gemini-3.7-flash'),
  tools: {
    vertex_rag_store: vertex.tools.vertexRagStore({
      ragCorpus:
        'projects/my-project/locations/us-central1/ragCorpora/my-rag-corpus',
      topK: 5,
    }),
  },
  prompt:
    '根据我们的文档，我们产品的关键特性是什么？',
});

// 访问 grounding 元数据。转换为提供商元数据类型
// 是可选的，但提供自动完成和类型安全。
const metadata = providerMetadata?.google as GoogleProviderMetadata | undefined;
const groundingMetadata = metadata?.groundingMetadata;
const safetyRatings = metadata?.safetyRatings;
```

启用 RAG 引擎接地后，模型将在响应中包含来自 RAG 语料库的来源。

此外，grounding 元数据包含有关 RAG 结果如何用于接地模型响应的详细信息。以下是可用字段：

- **`groundingChunks`** (块对象数组 | null)
  - 包含从 RAG 语料库检索的上下文块
  - 每个块包括：
    - **`retrievedContext`**：有关检索上下文的信息
      - `uri`：源文档的 URI 或标识符
      - `title`：源文档的标题（可选）
      - `text`：块的实际文本内容

- **`groundingSupports`** (支持对象数组 | null)
  - 包含有关特定响应部分如何受 RAG 结果支持的详细信息
  - 每个支持对象包括：
    - **`segment`**：有关接地文本段的信息
      - `text`：实际文本段
      - `startIndex`：响应中的起始位置
      - `endIndex`：响应中的结束位置
    - **`groundingChunkIndices`**：对支持 RAG 结果块的引用
    - **`confidenceScores`**：每个支持块的置信度分数（0-1）

示例响应：

```json
{
  "groundingMetadata": {
    "groundingChunks": [
      {
        "retrievedContext": {
          "uri": "gs://my-bucket/docs/product-guide.pdf",
          "title": "Product User Guide",
          "text": "Our product includes advanced AI capabilities, real-time processing, and enterprise-grade security features."
        }
      }
    ],
    "groundingSupports": [
      {
        "segment": {
          "startIndex": 0,
          "endIndex": 45,
          "text": "Our product includes advanced AI capabilities and real-time processing."
        },
        "groundingChunkIndices": [0],
        "confidenceScores": [0.95]
      }
    ]
  }
}
```

#### 配置选项

`vertexRagStore` 工具接受以下配置选项：

- **`ragCorpus`** (`string`，必需)
  - RagCorpus 资源名称，格式为：`projects/{project}/locations/{location}/ragCorpora/{rag_corpus}`
  - 这标识你要搜索的特定 RAG 语料库

- **`topK`** (`number`，可选)
  - 从 RAG 语料库检索的顶部上下文数量
  - 如果未指定，默认为语料库配置

#### Schema 限制

```ts highlight="3,8"
  output: Output.object({

      name: z.string(),
      age: z.number(),
      contact: z.union([
        z.object({
          type: z.literal('email'),
          value: z.string(),
        }),
        z.object({
          type: z.literal('phone'),
          value: z.string(),
        }),
      ]),
    }),
  }),
  prompt: '生成一个用于测试的示例人物。',
});
```

以下 Zod 功能已知不适用于 Google：

- `z.union`
- `z.record`

### 文本批处理

<Note type="warning">
  文本批处理支持是实验性的，API 可能在补丁版本中更改。
</Note>

Google 提供商通过
[Gemini Batch API](https://ai.google.dev/gemini-api/docs/batch-api) 支持异步文本生成。使用
实验性文本批处理 API 启动批处理、轮询其状态并流式传输其
结果：

```ts
import { google } from '@ai-sdk/google';
import {
  experimental_getBatchResults as getBatchResults,
  experimental_getBatchStatus as getBatchStatus,
  experimental_startTextBatch as startTextBatch,
} from 'ai';
import { setTimeout } from 'node:timers/promises';

const model = google('gemini-3.6-flash');

const batch = await startTextBatch({
  model,
  requests: [
    { id: 'capital-france', prompt: '法国的首都是什么？' },
    { id: 'capital-germany', prompt: '德国的首都是什么？' },
  ],
});

let status = batch.status;
while (status === 'pending') {
  await setTimeout(60_000);
  ({ status } = await getBatchStatus({ model, batch }));
}

for await (const item of getBatchResults({ model, batch })) {
  if (item.status === 'succeeded') {
    console.log(item.id, item.text);
  } else {
    console.error(item.id, item.error);
  }
}
```

`startTextBatch` 返回一个可序列化的批处理引用。持久化此引用
以从另一个进程检查批处理状态或检索其结果。结果
到达的顺序可能与输入请求不同，因此请根据其 `id` 匹配每个结果。

#### Webhooks

你可以传递 `webhookUrl` 以在批处理达到终止状态时接收通知：

```ts
const batch = await startTextBatch({
  model,
  requests: [
    { id: 'capital-france', prompt: '法国的首都是什么？' },
    { id: 'capital-germany', prompt: '德国的首都是什么？' },
  ],
  webhookUrl: 'https://example.com/api/google-batch-webhook',
});
```

Google 向 webhook URL 发送一个精简事件。收到并验证事件后，使用持久化的批处理引用配合 `getBatchStatus` 或 `getBatchResults`。你的应用程序负责处理 webhook 并[验证 Google 的动态 webhook 签名](https://ai.google.dev/gemini-api/docs/webhooks#verify_dynamic_signatures_jwks)。

#### 大批处理

当序列化的批处理创建主体小于 20 MB 时，提供商内联发送请求。达到 20 MB 或更多时，它通过 Gemini Files API 上传 JSONL 输入文件。

## 实时模型

<Note type="warning">实时是实验性功能。</Note>

你可以使用 `.experimental_realtime()` 工厂方法创建调用 [Gemini Live API](https://ai.google.dev/gemini-api/docs/live) 的模型。

```ts
import { google } from '@ai-sdk/google';

const model = google.experimental_realtime('gemini-3.1-flash-live-preview');
```

实时会话在浏览器中运行，需要你在服务器上使用 `google.experimental_realtime.getToken()` 创建的短期 token：

```ts
const token = await google.experimental_realtime.getToken({
  model: 'gemini-3.1-flash-live-preview',
});
```

Google 实时模型可能需要提供商特定的音频格式，具体取决于
模型和模态。参见 [实时](/docs/ai-sdk-core/realtime) 了解
完整设置和工具调用模式。

没有提供商中立等价物的 Gemini 生命周期信号
作为自定义事件发出。检查 `rawType` 是否为 `goAway`、
`sessionResumptionUpdate` 和 `generationComplete`，并使用事件的 `raw`
负载获取提供商特定的详细信息。

### 实时翻译

使用 `gemini-3.5-live-translate-preview` 进行低延迟语音到语音
翻译。在创建 token 时使用的实时会话配置中，通过
`providerOptions.google.translationConfig` 配置目标语言：

```ts
import {
  google,
  type Experimental_GoogleRealtimeModelOptions as GoogleRealtimeModelOptions,
} from '@ai-sdk/google';

const token = await google.experimental_realtime.getToken({
  model: 'gemini-3.5-live-translate-preview',
  sessionConfig: {
    outputModalities: ['audio'],
    inputAudioTranscription: {},
    outputAudioTranscription: {},
    providerOptions: {
      google: {
        translationConfig: {
          targetLanguageCode: 'pl',
          echoTargetLanguage: true,
        },
      } satisfies GoogleRealtimeModelOptions,
    },
  },
});
```

将 `targetLanguageCode` 设置为 BCP-47 语言代码（默认为 `en`）。当
`echoTargetLanguage` 为 `true` 时，已经是目标语言的输入音频会被
回显而不是产生静音。

Gemini Live Translation 接受音频输入并产生翻译后的音频
输出。此模型不支持文本输入、工具和自定义指令。

## 翻译模型

<Note type="warning">语音翻译是实验性功能。</Note>

对于服务器端流式翻译，你可以使用
`.translation()` 工厂方法创建调用
[Gemini Live API](https://ai.google.dev/gemini-api/docs/live) 的模型。翻译模型仅支持流式传输，并与
[`experimental_streamTranslate`](/docs/reference/ai-sdk-core/stream-translate) 一起使用。

第一个参数是模型 ID，例如 `gemini-3.5-live-translate-preview`。

```ts
const model = google.translation('gemini-3.5-live-translate-preview');
```

```ts
import { experimental_streamTranslate as streamTranslate } from 'ai';
import { google } from '@ai-sdk/google';

const result = streamTranslate({
  model: google.translation('gemini-3.5-live-translate-preview'),
  audio: audioStream, // ReadableStream<Uint8Array | string>
  inputAudioFormat: { type: 'audio/pcm', rate: 16000 },
  targetLanguage: 'es',
});

for await (const part of result.fullStream) {
  if (part.type === 'output-text-delta') {
    process.stdout.write(part.delta);
  }
}
```

Gemini Live API 自动检测源语言（不支持 `sourceLanguage`），
并且始终输出 24kHz 16 位 PCM 音频（不支持 `outputAudioFormat`）。
不支持的设置会作为调用警告显示。

以下提供商选项可用：

- **echoTargetLanguage** _boolean_
  是否应回显已经是目标语言的输入音频，而不是
  产生静音。
  可选。

## Interactions API

[Gemini Interactions API](https://ai.google.dev/gemini-api/docs/interactions)
（`POST /v1beta/interactions`）是一个独立的 Google 端点，具有服务器端
状态、统一内容块、一流的內建工具、智能体预设、
在沙盒 Linux 环境中运行的托管智能体，以及原生
多模态图像输出。通过 `google.interactions(...)`
工厂访问：

```ts
import { google } from '@ai-sdk/google';
import { generateText } from 'ai';

const { text } = await generateText({
  model: google.interactions('gemini-3.7-flash'),
  prompt: '你好，你好吗？',
});
```

`google.interactions(...)` 接受模型 ID 字符串（例如
`'gemini-3.7-flash'`、`'gemini-3.1-pro-preview'`）、`{ agent: <name> }` 以使用
Gemini [智能体预设](#agent-presets)，或 `{ managedAgent: <name> }` 以
调用你在 Google 端创建的[托管智能体](#managed-agents)。
返回的模型可以像任何其他 AI SDK 语言模型一样传递给 `generateText` 和 `streamText`。

<Note>
  对标准 `:generateContent` /
  `:streamGenerateContent` 端点使用 `google(...)`，对新
  Interactions 端点使用 `google.interactions(...)`。每个模型实例选择一个 — 它们针对不同的
  请求体和 SSE 事件词汇表。
</Note>

### 提供商选项

Interactions 模型从共享的
`providerOptions.google.*` 命名空间读取其选项。使用
`GoogleLanguageModelInteractionsOptions` 类型验证它们：

```ts
import {
  google,
  type GoogleLanguageModelInteractionsOptions,
} from '@ai-sdk/google';
import { generateText } from 'ai';

await generateText({
  model: google.interactions('gemini-3.7-flash'),
  prompt: '用一个词描述天空是什么颜色？',
  providerOptions: {
    google: {
      serviceTier: 'priority',
    } satisfies GoogleLanguageModelInteractionsOptions,
  },
});
```

以下可选的提供商选项可用：

- **previousInteractionId** _string_

  来自先前轮次的服务器端交互 ID。设置后，服务器从
  其自身状态拉取先前上下文，并且只发送新的用户消息
  在线路上。与默认的 `store: true` 配对以链接有状态
  对话。参见[有状态链接](#stateful-chaining)。

- **store** _boolean_

  服务器是否应持久化交互。默认为 `true`。
  对于无状态多轮对话设置为 `false`，其中完整
  消息历史在每轮重新发送。

- **agent** _string_

  Gemini 智能体预设的名称（例如 `'deep-research-pro-preview-12-2025'`）。

      <Note>

  优先使用工厂形式 `google.interactions({ agent: '...' })` 而不是
  在提供商选项中设置 `agent` — 工厂会针对
  支持的智能体名称进行类型检查。

  </Note>

- **agentConfig** _object_

  每个智能体的配置。目前支持 `{ type: 'dynamic' }` 和
  `{ type: 'deep-research', thinkingSummaries?, visualization?, collaborativePlanning? }`。

- **thinkingLevel** _'minimal' | 'low' | 'medium' | 'high'_

  控制支持思考的模型的推理深度。映射到
  Interactions 请求的 `thinking_level`。

- **thinkingSummaries** _'auto' | 'none'_

  模型是否在推理部分返回综合思考摘要。默认为 API 默认值。

- **responseFormat** _Array\<\{ type: 'text' | 'image' | 'audio'; mimeType?: string; schema?: unknown; aspectRatio?: string; imageSize?: '1K' \| '2K' \| '4K' \| '512' \}\>_

  直接映射到 API 的 `response_format` 数组的输出格式条目。使用此选项对图像、音频或非 JSON 文本输出进行细粒度控制（例如图像生成的 `aspectRatio` 和 `imageSize`）。
  AI SDK 调用级 `responseFormat: { type: 'json', schema }` 仍然
  自动驱动 JSON 模式并前置匹配的文本条目；
  此处列出的条目会被追加。

  `aspectRatio` 接受 `1:1`、`2:3`、`3:2`、`3:4`、`4:3`、`4:5`、`5:4`、
  `9:16`、`16:9`、`21:9`、`1:8`、`8:1`、`1:4`、`4:1`。

- **imageConfig** _\{ aspectRatio?: string; imageSize?: '1K' | '2K' | '4K' | '512' \}_ (已弃用)

  改用 **responseFormat** 配合 `{ type: 'image', ... }` 条目。
  为向后兼容而保留；SDK 将 `imageConfig`
  转换为匹配的 `response_format` 图像条目，并在设置时发出警告。当 `responseFormat` 已提供图像条目时忽略。

- **mediaResolution** _'low' | 'medium' | 'high' | 'ultra_high'_

  应用于图像输入/输出的媒体分辨率。

- **serviceTier** _'flex' | 'standard' | 'priority'_

  请求的服务层级。镜像回
  `result.providerMetadata.google.serviceTier` 以进行可观测性。

- **systemInstruction** _string_

  AI SDK `system` 消息的替代方案。如果两者都设置，AI SDK
  `system` 消息优先并发出警告。

- **background** _boolean_

  在后台运行交互。对于服务器端工作流无法在单个请求/响应中完成的智能体是必需的；仅支持同步调用的智能体会拒绝。当 `true` 时，
  POST 返回非终止状态，SDK 轮询
  `GET /interactions/{id}` 直到工作完成。

- **environment** _string \| object_

  [托管智能体](#managed-agents)的沙盒环境配置。
  传递 `'remote'` 以配置新的沙盒，传递 `environment_id`
  字符串以重用现有沙盒，或传递以下形式的对象
  `{ type: 'remote', sources?, network? }` 以预加载文件和/或
  限制出站流量。仅适用于智能体调用。

- **pollingTimeoutMs** _number_

  在放弃之前轮询后台交互的最大时间（毫秒）。默认为 30 分钟（1,800,000 毫秒）。长时间运行的智能体
  可能需要更长时间。

### 提供商元数据

`result.providerMetadata.google`（通过 `GoogleInteractionsProviderMetadata` 类型化）暴露：

- **interactionId** _string_

  服务器端交互 ID。在下一轮将其作为 `previousInteractionId` 传回以进行链接。

- **serviceTier** _string_

  请求实际运行的服务层级。

- **signature** _string_

  每个块的签名哈希，由 SDK 在输出推理和
  工具调用部分设置。在下一轮自动往返。

### 有状态链接

使用默认的 `store: true`，服务器保留先前轮次，因此
下一个请求只需要发送新的用户消息和
`previousInteractionId`：

```ts
import {
  google,
  type GoogleLanguageModelInteractionsOptions,
} from '@ai-sdk/google';
import { generateText } from 'ai';

const turn1 = await generateText({
  model: google.interactions('gemini-3.7-flash'),
  prompt: '西班牙最大的三个城市是什么？',
});

const interactionId = turn1.providerMetadata?.google?.interactionId as
  | string
  | undefined;

const turn2 = await generateText({
  model: google.interactions('gemini-3.7-flash'),
  prompt: '第二个城市最著名的地标是什么？',
  providerOptions: {
    google: {
      previousInteractionId: interactionId,
    } satisfies GoogleLanguageModelInteractionsOptions,
  },
});
```

对于无状态多轮对话，设置 `store: false` 并在每轮重新发送
完整消息历史（无 `previousInteractionId`）：

```ts
import {
  google,
  type GoogleLanguageModelInteractionsOptions,
} from '@ai-sdk/google';
import { generateText, type ModelMessage } from 'ai';

const messages: Array<ModelMessage> = [
  { role: 'user', content: '西班牙最大的三个城市是什么？' },
];

const turn1 = await generateText({
  model: google.interactions('gemini-3.7-flash'),
  messages,
  providerOptions: {
    google: { store: false } satisfies GoogleLanguageModelInteractionsOptions,
  },
});

messages.push(...turn1.responseMessages);
messages.push({
  role: 'user',
  content: '第二个城市最著名的地标是什么？',
});

const turn2 = await generateText({
  model: google.interactions('gemini-3.7-flash'),
  messages,
  providerOptions: {
    google: { store: false } satisfies GoogleLanguageModelInteractionsOptions,
  },
});
```

### 內建工具

Interactions API 附带內建工具目录。`google.tools.*` 下的提供商定义工具映射到 Interactions 工具描述符：

| AI SDK 工具                           | Interactions 工具类型 | 说明                                     |
| ------------------------------------- | ---------------------- | ----------------------------------------- |
| `google.tools.googleSearch`           | `google_search`        | 网页/图像搜索接地。             |
| `google.tools.codeExecution`          | `code_execution`       | 服务器端 Python 执行。             |
| `google.tools.urlContext`             | `url_context`          | 获取提示词中引用的 URL。      |
| `google.tools.fileSearch`             | `file_search`          | 从文件搜索存储检索。        |
| `google.tools.googleMaps`             | `google_maps`          | 附近地点查询的地图接地。 |
| _提供商工具_ `google.computer_use` | `computer_use`         | 计算机使用（浏览器环境）。       |
| _提供商工具_ `google.mcp_server`   | `mcp_server`           | 远程 MCP 服务器透传。            |
| _提供商工具_ `google.retrieval`    | `retrieval`            | Vertex AI 搜索检索。               |

使用 AI SDK `tool(...)` 辅助函数定义的函数工具（`type: 'function'`）被转换为 Interactions `function` 工具描述符。其他工具类型会发出警告并被丢弃。

```ts
import { google } from '@ai-sdk/google';
import { generateText } from 'ai';

const { text, sources } = await generateText({
  model: google.interactions('gemini-3.7-flash'),
  tools: {
    google_search: google.tools.googleSearch({}),
  },
  prompt:
    "过去一周有什么值得注意的 AI 发展？" +
    '为你提到的每个项目包含日期。',
});
```

函数工具的工作方式与标准提供商相同：

```ts
import { google } from '@ai-sdk/google';
import { generateText, isStepCount, tool } from 'ai';
import { z } from 'zod';

const weatherTool = tool({
  description: '获取一个城市的天气。',
  inputSchema: z.object({ city: z.string() }),
  execute: async ({ city }) => `${city} 是晴天。`,
});

const { text, toolCalls } = await generateText({
  model: google.interactions('gemini-3.7-flash'),
  tools: { getWeather: weatherTool },
  stopWhen: isStepCount(5),
  prompt: '旧金山现在的天气怎么样？',
});
```

### 通过 Interactions 输出图像

在支持图像的 Gemini 模型上的 `responseFormat` 中添加 `{ type: 'image' }` 条目，以在响应中获取 `LanguageModelV4FilePart` 文件。不需要工具包装，该条目兼作设置 `aspectRatio`、`imageSize` 和 `mimeType` 的位置。

```ts
import {
  google,
  type GoogleLanguageModelInteractionsOptions,
} from '@ai-sdk/google';
import { generateText } from 'ai';

const result = await generateText({
  model: google.interactions('gemini-3-pro-image-preview'),
  prompt: '生成一张漫画猫在宇宙飞船中的图像。',
  providerOptions: {
    google: {
      responseFormat: [{ type: 'image' }],
    } satisfies GoogleLanguageModelInteractionsOptions,
  },
});

for (const file of result.files) {
  if (file.mediaType.startsWith('image/')) {
    // file.uint8Array | file.base64 | file.mediaType
  }
}
```

要控制宽高比、图像大小或输出 MIME 类型，请将
这些字段添加到同一图像条目：

```ts
import {
  google,
  type GoogleLanguageModelInteractionsOptions,
} from '@ai-sdk/google';
import { generateText } from 'ai';

const result = await generateText({
  model: google.interactions('gemini-3-pro-image-preview'),
  prompt: '生成一张日落时山脉的高质量风景照片。',
  providerOptions: {
    google: {
      responseFormat: [
        {
          type: 'image',
          aspectRatio: '16:9',
          imageSize: '4K',
        },
      ],
    } satisfies GoogleLanguageModelInteractionsOptions,
  },
});
```

对于多模态输出，每种模态列出一个条目。模型返回
`result.text` 中的文本和 `result.files` 中的伴随图像：

```ts
import {
  google,
  type GoogleLanguageModelInteractionsOptions,
} from '@ai-sdk/google';
import { generateText } from 'ai';

const result = await generateText({
  model: google.interactions('gemini-2.5-flash-image'),
  prompt:
    '给我讲一个关于独角兽的三句话睡前故事，并配上一幅合适的插图。',
  providerOptions: {
    google: {
      responseFormat: [
        { type: 'text' },
        { type: 'image', aspectRatio: '16:9' },
      ],
    } satisfies GoogleLanguageModelInteractionsOptions,
  },
});

console.log(result.text);

const images = result.files.filter(file => file.mediaType.startsWith('image/'));
// images[0].uint8Array | images[0].base64 | images[0].mediaType
```

迭代式图像编辑与有状态链接自然配对 — 保持
跨轮次设置 `previousInteractionId`，模型编辑其先前的
输出：

```ts
import {
  google,
  type GoogleLanguageModelInteractionsOptions,
} from '@ai-sdk/google';
import { generateText } from 'ai';

const model = google.interactions('gemini-3-pro-image-preview');

const turn1 = await generateText({
  model,
  prompt: '生成一张漫画猫在宇宙飞船中的图像。',
  providerOptions: {
    google: {
      responseFormat: [{ type: 'image' }],
    } satisfies GoogleLanguageModelInteractionsOptions,
  },
});

const interactionId = turn1.providerMetadata?.google?.interactionId as
  | string
  | undefined;

const turn2 = await generateText({
  model,
  prompt: '现在把猫变成红色',
  providerOptions: {
    google: {
      responseFormat: [{ type: 'image' }],
      previousInteractionId: interactionId,
    } satisfies GoogleLanguageModelInteractionsOptions,
  },
});
```

### 智能体预设

传递 `{ agent: <name> }` 以定位 Gemini 智能体预设。工厂
针对支持的集合对智能体名称进行类型检查：

```ts
import {
  google,
  type GoogleLanguageModelInteractionsOptions,
} from '@ai-sdk/google';
import { generateText } from 'ai';

const result = await generateText({
  model: google.interactions({
    agent: 'deep-research-pro-preview-12-2025',
  }),
  prompt:
    '简要总结自 2024 年以来关于检索增强生成被引用最多的论文（2-3 句话）。',
  providerOptions: {
    google: {
      background: true,
    } satisfies GoogleLanguageModelInteractionsOptions,
  },
});
```

智能体是同步运行还是在后台运行取决于
智能体。长时间运行的预设（如 `deep-research-*` 系列）
需要 `background: true` — POST 返回非终止状态，
SDK 在内部轮询 `GET /interactions/{id}` 直到交互
完成。其他智能体仅接受同步调用，并将拒绝
`background: true`。通过
`providerOptions.google.background` 显式设置标志。

默认轮询超时为 30 分钟；对于较慢的智能体，通过
`pollingTimeoutMs` 提高：

```ts
import {
  google,
  type GoogleLanguageModelInteractionsOptions,
} from '@ai-sdk/google';
import { generateText } from 'ai';

await generateText({
  model: google.interactions({ agent: 'deep-research-max-preview-04-2026' }),
  prompt: '制作一份关于...的长篇研究简报',
  providerOptions: {
    google: {
      background: true,
      pollingTimeoutMs: 60 * 60 * 1000, // 1 小时
    } satisfies GoogleLanguageModelInteractionsOptions,
  },
});
```

智能体也像模型 ID 调用一样通过 `previousInteractionId` 链接。

### 托管智能体

[托管智能体](https://ai.google.dev/gemini-api/docs/agents) 在
每次交互配置的沙盒 Linux 环境中运行。传递 `environment`
提供商选项以控制沙盒的设置方式；该选项仅在
智能体调用时接受。

最简单的形式配置一个新的沙盒：

```ts
import {
  google,
  type GoogleLanguageModelInteractionsOptions,
} from '@ai-sdk/google';
import { generateText } from 'ai';

const result = await generateText({
  model: google.interactions({ agent: 'antigravity-preview-05-2026' }),
  prompt: '2 + 2 等于多少？',
  providerOptions: {
    google: {
      environment: 'remote',
    } satisfies GoogleLanguageModelInteractionsOptions,
  },
});
```

`environment` 接受三种形式：

- `'remote'` — 为此调用配置一个新的沙盒。
- 任何其他字符串 — 要重用的 `environment_id`，分叉先前的
  沙盒，使其文件系统和已安装的包持久化。
- 一个对象 — 配置一个新的沙盒，并可选地预加载 `sources`
  和/或通过 `network` 限制出站流量：

```ts
import {
  google,
  type GoogleLanguageModelInteractionsOptions,
} from '@ai-sdk/google';
import { generateText } from 'ai';

await generateText({
  model: google.interactions({ agent: 'antigravity-preview-05-2026' }),
  prompt:
    '读取 /data/note.txt 中的文件并准确告诉我其中包含的内容。',
  providerOptions: {
    google: {
      environment: {
        type: 'remote',
        sources: [
          {
            type: 'inline',
            content: '来自 AI SDK 示例的问候\n',
            target: '/data/note.txt',
          },
        ],
      },
    } satisfies GoogleLanguageModelInteractionsOptions,
  },
});
```

支持三种源类型：`inline`（将字符串写入
沙盒中的 `target`）、`repository`（克隆 git 仓库 — 传递
URL 作为 `source`）和 `gcs`（挂载 Google Cloud Storage 前缀）。

`network` 字段接受字符串 `'disabled'` 以阻止所有
出站流量，或一个带有 `allowlist` 数组的对象，其条目
每个包含一个 `domain` 以及可选的 `transform` 头对象数组
以注入匹配的请求。

#### 自定义托管智能体

对于你通过
Gemini API 的 `/v1beta/agents` 端点在 Google 端创建的用户定义智能体，通过专用的
`managedAgent` 工厂形式传递智能体的名称，而不是 `agent`（它只接受
已知的预设名称）：

```ts
import {
  google,
  type GoogleLanguageModelInteractionsOptions,
} from '@ai-sdk/google';
import { generateText } from 'ai';

const result = await generateText({
  model: google.interactions({ managedAgent: 'my-custom-agent' }),
  prompt: '你好！',
  providerOptions: {
    google: {
      environment: 'remote',
    } satisfies GoogleLanguageModelInteractionsOptions,
  },
});
```

### 流式传输

支持 `streamText`。流的 `finish` 部分在 `providerMetadata.google` 上暴露 `interactionId`，以便调用者可以链接。

```ts
import { google } from '@ai-sdk/google';
import { streamText } from 'ai';

const result = streamText({
  model: google.interactions('gemini-3.7-flash'),
  prompt: '你好，你好吗？',
});

for await (const textPart of result.textStream) {
  process.stdout.write(textPart);
}

const googleMetadata = (await result.providerMetadata)?.google;
console.log('交互 ID:', googleMetadata?.interactionId);
```

## Gemma 模型

你可以使用 [Gemma 模型](https://deepmind.google/models/gemma/) 配合 Google Generative AI API。
以下 Gemma 模型可用：

- `gemma-3-27b-it`
- `gemma-3-12b-it`

Gemma 模型原生不支持 `systemInstruction` 参数，但提供商通过将系统指令前置到第一条用户消息来自动处理。这使你可以无缝地将系统指令与 Gemma 模型一起使用：

```ts
import { google } from '@ai-sdk/google';
import { generateText } from 'ai';

const { text } = await generateText({
  model: google('gemma-3-27b-it'),
  instructions: '你是一个简洁回答的有用助手。',
  prompt: '什么是机器学习？',
});
```

系统指令会自动格式化并包含在对话中，因此 Gemma 模型可以在无需任何额外配置的情况下遵循指导。

## 嵌入模型

你可以使用 `.embedding()` 工厂方法创建调用 [Google Generative AI 嵌入 API](https://ai.google.dev/gemini-api/docs/embeddings) 的模型。

```ts
const model = google.embedding('gemini-embedding-001');
```

Google 提供商根据嵌入类型将 API 调用发送到正确的端点：

- **单个嵌入**：当使用 `embed()` 嵌入单个值时，提供商使用单个 `:embedContent` 端点，该端点通常比批处理端点具有更高的速率限制。
- **批处理嵌入**：当使用 `embedMany()` 嵌入多个值或 `embed()` 中的多个值时，提供商使用 `:batchEmbedContents` 端点。

Google 嵌入模型支持其他设置。你可以将它们作为选项参数传递：

```ts
import { google, type GoogleEmbeddingModelOptions } from '@ai-sdk/google';
import { embed } from 'ai';

const model = google.embedding('gemini-embedding-001');

const { embedding } = await embed({
  model,
  value: '阳光明媚的海滩日',
  providerOptions: {
    google: {
      outputDimensionality: 512, // 可选，嵌入的维度数
      taskType: 'SEMANTIC_SIMILARITY', // 可选，指定生成嵌入的任务类型
      content: [[{ text: '附加上下文' }]], // 可选，每个值的多模态内容（这里只有 1 个，因为 `value` 只有一个）
    } satisfies GoogleEmbeddingModelOptions,
  },
});
```

使用 `embedMany` 时，通过 `content` 选项提供每个值的多模态内容。每个条目对应同一索引处的值；对纯文本条目使用 `null`：

```ts
import { google, type GoogleEmbeddingModelOptions } from '@ai-sdk/google';
import { embedMany } from 'ai';

const { embeddings } = await embedMany({
  model: google.embedding('gemini-embedding-2-preview'),
  values: ['阳光明媚的海滩日', '城市中的雨天下午'],
  providerOptions: {
    google: {
      // content 数组必须与 values 长度相同
      content: [
        [{ inlineData: { mimeType: 'image/png', data: '<base64>' } }], // 与 values[0] 配对
        null, // 纯文本，与 values[1] 配对
      ],
    } satisfies GoogleEmbeddingModelOptions,
  },
});
```

以下可选的提供商选项可用于 Google 嵌入模型：

- **outputDimensionality**: _number_

  可选。输出嵌入的缩减维度。如果设置，输出嵌入中的多余值将从末尾截断。

- **taskType**: _string_

  可选。指定生成嵌入的任务类型。支持的任务类型包括：
  - `SEMANTIC_SIMILARITY`：针对文本相似性优化。
  - `CLASSIFICATION`：针对文本分类优化。
  - `CLUSTERING`：针对基于相似性的文本聚类优化。
  - `RETRIEVAL_DOCUMENT`：针对文档检索优化。
  - `RETRIEVAL_QUERY`：针对基于查询的检索优化。
  - `QUESTION_ANSWERING`：针对回答问题优化。
  - `FACT_VERIFICATION`：针对验证事实信息优化。
  - `CODE_RETRIEVAL_QUERY`：针对基于自然语言查询检索代码块优化。

- **content**: _array_

  可选。用于嵌入非文本内容（图像、视频、PDF、音频）的每个值的多模态内容部分。每个条目对应同一索引处的嵌入值 — 其部分与请求中的文本值合并。对纯文本条目使用 `null`。数组长度必须与要嵌入的值数量匹配。每个非 null 条目是一个部分数组，其中每个部分可以是 `{ text: string }`、`{ inlineData: { mimeType: string, data: string } }` 用于内联 base64 数据，或 `{ fileData: { fileUri: string, mimeType: string } }` 用于通过 HTTP URL 或 Google Cloud Storage URI（`gs://...`）引用远程内容。由 `gemini-embedding-2-preview` 支持。

## 图像模型

你可以使用 `.image()` 工厂方法创建调用 Google Generative AI API 的图像模型。
有关使用 AI SDK 进行图像生成的更多信息，请参阅 [generateImage()](/docs/reference/ai-sdk-core/generate-image)。

`.image()` 工厂通过 `:generateContent` API 支持具有图像输出能力的 Gemini 多模态语言模型。

### Gemini 图像模型

[Gemini 图像模型](https://ai.google.dev/gemini-api/docs/image-generation)（例如 `gemini-2.5-flash-image`）在技术上是多模态输出语言模型，但它们可以与 `generateImage()` 函数一起使用以获得更简单的图像生成体验。在内部，提供商使用 `responseModalities: ['IMAGE']` 调用语言模型 API。

```ts
import { google } from '@ai-sdk/google';
import { generateImage } from 'ai';

const { image } = await generateImage({
  model: google.image('gemini-2.5-flash-image'),
  prompt: '一只戴着巫师帽的猫的照片级真实图像',
  aspectRatio: '1:1',
});
```

Gemini 图像模型还通过提供输入图像来支持图像编辑：

```ts
import { google } from '@ai-sdk/google';
import { generateImage } from 'ai';
import fs from 'node:fs';

const sourceImage = fs.readFileSync('./cat.png');

const { image } = await generateImage({
  model: google.image('gemini-2.5-flash-image'),
  prompt: {
    text: '给这只猫添加一顶小巫师帽',
    images: [sourceImage],
  },
});
```

你也可以使用 URL 作为输入图像：

```ts
import { google } from '@ai-sdk/google';
import { generateImage } from 'ai';

const { image } = await generateImage({
  model: google.image('gemini-2.5-flash-image'),
  prompt: {
    text: '给这只猫添加一顶小巫师帽',
    images: ['https://example.com/cat.png'],
  },
});
```

<Note>
  Gemini 图像模型不支持 `size` 或 `n` 参数。使用
  `aspectRatio` 代替 `size`。也不支持基于掩码的修复。
</Note>

<Note>
  对于需要同时获得文本和图像输出的更高级用例，或
  希望更精细地控制生成过程，你可以直接使用 Gemini 图像模型
  配合 `generateText()`。参见 [图像输出](#image-outputs) 了解
  详情。
</Note>

#### Google 搜索接地

Gemini 图像模型通过 `providerOptions.google.googleSearch` 支持 [Google 搜索接地](#google-search)。该值与 `google.tools.googleSearch(...)` 的参数匹配；传递 `{}` 以默认设置启用，或传递 `{ searchTypes: { imageSearch: {} } }` 以参考照片接地。

```ts
import { google, type GoogleImageModelOptions } from '@ai-sdk/google';
import { generateImage } from 'ai';

const result = await generateImage({
  model: google.image('gemini-3.1-flash-image-preview'),
  prompt:
    '搜索 2026 年超级碗中场秀艺术家的现场镜头，然后在太空中生成一张特写。',
  providerOptions: {
    google: {
      googleSearch: { searchTypes: { imageSearch: {} } },
    } satisfies GoogleImageModelOptions,
  },
});

// Grounding 元数据转发到图像结果：
console.log(result.providerMetadata?.google?.groundingMetadata);
```

## 语音模型

你可以使用 `.speech()` 工厂方法创建调用 [Gemini 文本转语音 API](https://ai.google.dev/gemini-api/docs/speech-generation) 的模型。

第一个参数是模型 ID，例如 `gemini-2.5-flash-preview-tts`。

```ts
const model = google.speech('gemini-2.5-flash-preview-tts');
```

`voice` 参数可以设置为 Gemini 的 [30 个预建语音](https://ai.google.dev/gemini-api/docs/speech-generation#voices) 之一，例如 `Kore`、`Puck`、`Zephyr` 或 `Charon`。语音名称区分大小写。默认为 `Kore`。

```ts highlight="6"
import { generateSpeech } from 'ai';
import { google } from '@ai-sdk/google';

const result = await generateSpeech({
  model: google.speech('gemini-2.5-flash-preview-tts'),
  text: '你好，世界！',
  voice: 'Kore', // Gemini 语音名称
});
```

默认情况下，生成的音频作为可播放的 WAV 文件返回（`result.audio.mediaType` 为
`audio/wav`）。设置 `outputFormat: 'pcm'` 以接收原始有符号 16 位小端单声道 PCM
字节；采样率在 `result.providerMetadata.google.sampleRate` 中报告。

Gemini 尊重自然语言风格指导。`instructions` 参数前置到
口语文本，因此 `instructions: 'Say cheerfully'` 配合 `text: 'Hello'` 会说出 `Say cheerfully: Hello`。

### 多说话人音频

对于多说话人对话，通过 `providerOptions` 传递 `multiSpeakerVoiceConfig`。每个说话人
名称必须与输入文本中使用的名称匹配。设置后，它将覆盖顶层 `voice`。

```ts highlight="7-22"
import { generateSpeech } from 'ai';
import { google, type GoogleSpeechModelOptions } from '@ai-sdk/google';

const result = await generateSpeech({
  model: google.speech('gemini-2.5-flash-preview-tts'),
  text: 'Joe: 你好吗？ Jane: 很好，谢谢！',
  providerOptions: {
    google: {
      multiSpeakerVoiceConfig: {
        speakerVoiceConfigs: [
          {
            speaker: 'Joe',
            voiceConfig: { prebuiltVoiceConfig: { voiceName: 'Kore' } },
          },
          {
            speaker: 'Jane',
            voiceConfig: { prebuiltVoiceConfig: { voiceName: 'Puck' } },
          },
        ],
      },
    } satisfies GoogleSpeechModelOptions,
  },
});
```

<Note>
  Gemini TTS 模型不支持 `speed` 或 `language` 选项；传递
  它们会向 `result.warnings` 添加警告。语言从输入文本自动检测。
</Note>

| `gemini-2.5-pro-preview-tts`   | <Check />     | <Check />              |
