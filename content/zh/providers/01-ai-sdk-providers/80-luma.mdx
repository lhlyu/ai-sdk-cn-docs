# Luma 提供商

[Luma AI](https://lumalabs.ai/) 通过其 Dream Machine 平台提供最先进的图像生成模型。这些模型提供超高画质的图像生成，具有卓越的提示词理解能力以及角色一致性和多图像参考支持等独特功能。

## 提供商实例

你可以从 `@ai-sdk/luma` 导入默认的提供商实例 `luma`：

```ts
import { luma } from '@ai-sdk/luma';
```

如果你需要自定义设置，可以导入 `createLuma` 并使用你的配置创建提供商实例：

```ts
import { createLuma } from '@ai-sdk/luma';

const luma = createLuma({
  apiKey: 'your-api-key', // 可选，默认为 LUMA_API_KEY 环境变量
  baseURL: 'custom-url', // 可选
  headers: {
    /* 自定义请求头 */
  }, // 可选
});
```

你可以使用以下可选设置来自定义 Luma 提供商实例：

- **baseURL** _string_

  为 API 调用使用不同的 URL 前缀，例如使用代理服务器。
  默认前缀为 `https://api.lumalabs.ai`。

- **apiKey** _string_

  通过 `Authorization` 请求头发送的 API 密钥。
  默认为 `LUMA_API_KEY` 环境变量。

- **headers** _Record&lt;string,string&gt;_

  要包含在请求中的自定义请求头。

- **fetch** _(input: RequestInfo, init?: RequestInit) => Promise&lt;Response&gt;_

  自定义 [fetch](https://developer.mozilla.org/en-US/docs/Web/API/fetch) 实现。
  你可以将其用作中间件来拦截请求，
  或为测试等场景提供自定义 fetch 实现。

## 图像模型

你可以使用 `.image()` 工厂方法创建 Luma 图像模型。
有关使用 AI SDK 进行图像生成的更多信息，请参阅 [generateImage()](/docs/reference/ai-sdk-core/generate-image)。

### 基本用法

```ts
import { luma, type LumaImageModelOptions } from '@ai-sdk/luma';
import { generateImage } from 'ai';
import fs from 'fs';

const { image } = await generateImage({
  model: luma.image('photon-1'),
  prompt: 'A serene mountain landscape at sunset',
  aspectRatio: '16:9',
});

const filename = `image-${Date.now()}.png`;
fs.writeFileSync(filename, image.uint8Array);
console.log(`Image saved to ${filename}`);
```

### 图像模型设置

你可以使用可选设置自定义生成行为：

```ts
const { image } = await generateImage({
  model: luma.image('photon-1'),
  prompt: 'A serene mountain landscape at sunset',
  aspectRatio: '16:9',
  maxImagesPerCall: 1, // 每次 API 调用生成的最大图像数量
  providerOptions: {
    luma: {
      pollIntervalMillis: 5000, // 检查图像是否完成的频率（毫秒）
      maxPollAttempts: 10, // 超时前的最大轮询尝试次数
    },
  } satisfies LumaImageModelOptions,
});
```

由于 Luma 通过异步队列系统处理图像，这些设置允许你调整轮询行为：

- **maxImagesPerCall** _number_

  覆盖每次 API 调用生成的最大图像数量。默认为 1。

- **pollIntervalMillis** _number_

  控制检查 API 中已完成图像的频率。
  默认为 500 毫秒。

- **maxPollAttempts** _number_

  限制等待结果的时间，超时后停止，因为图像生成是异步排队的。
  默认为 120 次尝试。

### 模型能力

Luma 提供两个主要模型：

| 模型              | 描述                                             |
| ----------------- | ------------------------------------------------ |
| `photon-1`        | 高质量图像生成，具有卓越的提示词理解能力         |
| `photon-flash-1`  | 更快的生成速度，在保持质量的同时优化速度         |

两个模型均支持以下宽高比：

- 1:1
- 3:4
- 4:3
- 9:16
- 16:9（默认）
- 9:21
- 21:9

有关支持的宽高比的更多详细信息，请参阅 [Luma 图像生成文档](https://docs.lumalabs.ai/docs/image-generation)。

Luma 模型的主要功能包括：

- 超高画质图像生成
- 相比类似模型成本效率提高 10 倍
- 卓越的提示词理解和遵循能力
- 基于单张参考图像的独特角色一致性能力
- 多图像参考支持，实现精确的风格匹配

### 图像编辑

Luma 支持引用其他图像的不同生成模式。

#### 修改图像

图像必须以 URL 形式传递。可以在 `providerOptions.luma.images` 数组中为每个图像配置 `weight`。

```ts
await generateImage({
  model: luma.image('photon-flash-1'),
  prompt: {
    text: 'transform the bike to a boat',
    images: [
      'https://hebbkx1anhila5yf.public.blob.vercel-storage.com/future-me-8hcBWcZOkbE53q3gshhEm16S87qDpF.jpeg',
    ],
  },
  providerOptions: {
    luma: {
      referenceType: 'modify_image',
      images: [{ weight: 1.0 }],
    } satisfies LumaImageModelOptions,
  },
});
```

了解更多信息，请访问 https://docs.lumalabs.ai/docs/image-generation#modify-image。

#### 参考图像

使用最多 4 张参考图像来指导生成。适用于创建变体或可视化复杂概念。调整每张图像的 `weight`（0-1）以控制参考图像的影响。

```ts
await generateImage({
  model: luma.image('photon-flash-1'),
  prompt: {
    text: 'A salamander at dusk in a forest pond, in the style of ukiyo-e',
    images: [
      'https://hebbkx1anhila5yf.public.blob.vercel-storage.com/future-me-8hcBWcZOkbE53q3gshhEm16S87qDpF.jpeg',
    ],
  },
  aspectRatio: '1:1',
  providerOptions: {
    luma: {
      referenceType: 'image',
      images: [{ weight: 0.8 }],
    } satisfies LumaImageModelOptions,
  },
});
```

了解更多信息，请访问 https://docs.lumalabs.ai/docs/image-generation#image-reference

#### 风格参考

使用参考图像将特定的视觉风格应用于你的生成。使用 `weight` 参数控制风格影响。

```ts
await generateImage({
  model: luma.image('photon-flash-1'),
  prompt: {
    text: 'A blue cream Persian cat launching its website on Vercel',
    images: [
      'https://hebbkx1anhila5yf.public.blob.vercel-storage.com/future-me-8hcBWcZOkbE53q3gshhEm16S87qDpF.jpeg',
    ],
  },
  aspectRatio: '1:1',
  providerOptions: {
    luma: {
      referenceType: 'style',
      images: [{ weight: 0.8 }],
    } satisfies LumaImageModelOptions,
  },
});
```

了解更多信息，请访问 https://docs.lumalabs.ai/docs/image-generation#style-reference

#### 角色参考

使用同一主题的最多 4 张参考图像创建一致且个性化的角色。更多的参考图像可以改善角色表现。

```ts
await generateImage({
  model: luma.image('photon-flash-1'),
  prompt: {
    text: 'A woman with a cat riding a broomstick in a forest',
    images: [
      'https://hebbkx1anhila5yf.public.blob.vercel-storage.com/future-me-8hcBWcZOkbE53q3gshhEm16S87qDpF.jpeg',
    ],
  },
  aspectRatio: '1:1',
  providerOptions: {
    luma: {
      referenceType: 'character',
      images: [
        {
          id: 'identity0',
        },
      ],
    } satisfies LumaImageModelOptions,
  },
});
```

了解更多信息，请访问 https://docs.lumalabs.ai/docs/image-generation#character-reference
