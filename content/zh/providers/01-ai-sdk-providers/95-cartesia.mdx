# Cartesia 提供商

[Cartesia](https://cartesia.ai/) 提供商包含 Sonic 语音生成、Ink-Whisper 批量转录，以及 Ink 2 实时和流式转录支持。
Cartesia 模型目前无法通过 [AI Gateway](https://vercel.com/ai-gateway/models) 使用，因此开头的示例直接使用 `@ai-sdk/cartesia`。支持的替代方案请参见下方的[使用 AI Gateway](#using-ai-gateway)。

```ts
import { generateSpeech } from 'ai';
import { cartesia } from '@ai-sdk/cartesia';
import { writeFile } from 'node:fs/promises';

const { audio } = await generateSpeech({
  model: cartesia.speech('sonic-3.5'),
  text: 'Hello, world!',
  outputFormat: 'mp3',
  voice: '694f9389-aac1-45b6-b726-9d9369183238',
});

await writeFile('speech.mp3', audio.uint8Array);
```

## 使用 AI Gateway

当前的 [AI Gateway 模型目录](https://vercel.com/ai-gateway/models)未列出 Cartesia 模型。本页面的 API 请使用 `@ai-sdk/cartesia`。如需通过 Gateway 使用其他语音模型，请安装 `ai` 并配置 Gateway API 密钥：

<InstallPackages packages="ai" />

在环境中设置 [AI Gateway API 密钥](https://vercel.com/docs/ai-gateway/getting-started)：

```bash
export AI_GATEWAY_API_KEY=your_api_key_here
```

Vercel 部署还可以使用 [OIDC 身份验证](/providers/ai-sdk-providers/ai-gateway#oidc-authentication-vercel-deployments)。
支持的模型和 API 请参见 [Gateway 文档](/providers/ai-sdk-providers/ai-gateway)。

## 使用 `@ai-sdk/cartesia`

如需直接访问 Cartesia，请安装 `ai` 和 `@ai-sdk/cartesia`：

<InstallPackages packages="ai @ai-sdk/cartesia" />

在 `CARTESIA_API_KEY` 环境变量中设置你的 Cartesia API 凭据：

```bash
export CARTESIA_API_KEY=your_api_key_here
```

  以下各节介绍直接使用 `@ai-sdk/cartesia` 提供商的内容，
  包括其模型工厂和设置。Gateway 的模型和功能
  可用性可能有所不同。
</Note>

## 提供商实例

你可以从 `@ai-sdk/cartesia` 导入默认提供商实例 `cartesia`：

```ts
import { cartesia } from '@ai-sdk/cartesia';
```

如果你需要自定义设置，可以从 `@ai-sdk/cartesia` 导入 `createCartesia` 并使用你的设置创建提供商实例：

```ts
import { createCartesia } from '@ai-sdk/cartesia';

const cartesia = createCartesia({
  // custom settings, e.g.
  fetch: customFetch,
});
```

你可以使用以下可选设置来自定义 Cartesia 提供商实例：

- **apiKey** _string_

  通过 `Authorization` 请求头发送的 API 密钥。
  默认为 `CARTESIA_API_KEY` 环境变量。

- **version** _string_

  要使用的 Cartesia API 版本（通过 `Cartesia-Version` 请求头发送）。

- **headers** _Record&lt;string,string&gt;_

  要包含在请求中的自定义请求头。

- **fetch** _(input: RequestInfo, init?: RequestInit) => Promise&lt;Response&gt;_

  自定义 [fetch](https://developer.mozilla.org/en-US/docs/Web/API/fetch) 实现。
  默认为全局 `fetch` 函数。
  你可以将其用作中间件来拦截请求，
  或为例如测试提供自定义 fetch 实现。

- **webSocket** _WebSocketConstructor_

  用于 Ink 2 流式转录的自定义 WebSocket 实现。
  默认为全局 `WebSocket` 构造函数。

## 语音模型

你可以使用 `.speech()` 工厂方法创建调用 [Cartesia 文本转语音 API](https://docs.cartesia.ai/api-reference/tts/bytes) 的模型。

第一个参数是模型 ID，例如 `sonic-3.5`。

```ts
const model = cartesia.speech('sonic-3.5');
```

你可以将该模型与 `generateSpeech` 函数一起使用。Cartesia 需要 `voice` ID：

```ts
import { generateSpeech } from 'ai';
import { cartesia } from '@ai-sdk/cartesia';

const result = await generateSpeech({
  model: cartesia.speech('sonic-3.5'),
  text: 'Hello, world!',
  voice: '694f9389-aac1-45b6-b726-9d9369183238',
});
```

你还可以使用 `providerOptions` 参数传递额外的提供商特定选项：

```ts highlight="7-12"
import { generateSpeech } from 'ai';
import { cartesia, type CartesiaSpeechModelOptions } from '@ai-sdk/cartesia';

const result = await generateSpeech({
  model: cartesia.speech('sonic-3.5'),
  text: 'Hello, world!',
  voice: '694f9389-aac1-45b6-b726-9d9369183238',
  providerOptions: {
    cartesia: {
      container: 'wav',
      encoding: 'pcm_s16le',
      sampleRate: 24000,
    } satisfies CartesiaSpeechModelOptions,
  },
});
```

以下提供商选项可用：

- **container** _string_

  输出音频的容器格式。
  支持的值：`'raw'`、`'wav'`、`'mp3'`。
  可选。

- **encoding** _string_

  音频输出的编码类型。
  支持的值：`'pcm_f32le'`、`'pcm_s16le'`、`'pcm_mulaw'`、`'pcm_alaw'`。
  可选。

- **sampleRate** _number_

  输出音频的采样率，单位为 Hz（例如 `8000`、`16000`、`22050`、`24000`、`44100`、`48000`）。
  可选。

- **bitRate** _number_

  `mp3` 输出的比特率，单位为比特每秒（例如 `32000`、`64000`、`128000`、`192000`）。
  可选。

- **speed** _number_

  控制生成语音的速度，范围为 `0.6` 到 `1.5`。
  可选。

- **language** _string_

  生成语音所使用的语言（ISO 639-1 代码）。
  可选。

## 实时转录模型

<Note type="warning">实时功能是实验性功能。</Note>

你可以使用 `.experimental_realtime()` 工厂方法为 Cartesia 的实时 [Ink 2](https://docs.cartesia.ai/build-with-cartesia/stt/latest) API 创建模型：

```ts
import { cartesia } from '@ai-sdk/cartesia';

const model = cartesia.experimental_realtime('ink-2');
```

实时会话在浏览器中运行，需要使用 `cartesia.experimental_realtime.getToken()` 在服务器上创建的短期访问令牌：

```ts
const token = await cartesia.experimental_realtime.getToken({
  model: 'ink-2',
  sessionConfig: {
    inputAudioFormat: { type: 'audio/pcm', rate: 24000 },
    inputAudioTranscription: { language: 'en' },
    turnDetection: { type: 'server-vad' },
  },
});
```

Ink 2 会生成输入转录事件并支持英语音频。轮次检测默认启用。如需改用手动最终化，请在会话配置中将 `turnDetection` 设置为 `null`，并在当前输入完成时调用 `commitAudio()`。

完整的浏览器会话设置请参见[实时](/docs/ai-sdk-core/realtime)。

## 流式转录模型

<Note type="warning">流式转录是实验性功能。</Note>

Ink 2 也可以通过转录流式 API 使用。使用 `.transcription()` 创建模型，并将其传递给 `experimental_streamTranscribe`：

```ts
import { cartesia } from '@ai-sdk/cartesia';
import { experimental_streamTranscribe as streamTranscribe } from 'ai';

const result = streamTranscribe({
  model: cartesia.transcription('ink-2'),
  audio, // ReadableStream<Uint8Array | string> containing raw audio chunks
  inputAudioFormat: { type: 'audio/pcm', rate: 24000 },
  providerOptions: {
    cartesia: {
      language: 'en',
    },
  },
});

for await (const part of result.fullStream) {
  if (part.type === 'transcript-partial') {
    console.log('partial:', part.text);
  }

  if (part.type === 'transcript-final') {
    console.log('final:', part.text);
  }
}
```

提供商在打开 WebSocket 之前会创建一个短期的、STT 作用域的 Cartesia 访问令牌，因此 API 密钥不会包含在 WebSocket URL 中。
请以大约播放速率发送音频块；Cartesia 的实时端点适用于实时音频，而非批量文件上传。

Ink 2 支持英语音频，并默认使用 Cartesia 的原生轮次检测。如需仅在输入音频流结束时才最终化，请传递 `providerOptions.cartesia.streaming.turnDetection: false`。

默认情况下，提供商将 `audio/pcm`、`audio/pcmu` 和 `audio/pcma` 分别映射为 16 位 PCM、G.711 μ-law 和 G.711 A-law。如需流式传输其他原始 PCM 表示，请将 `providerOptions.cartesia.streaming.encoding` 设置为 `pcm_s32le`、`pcm_f16le` 或 `pcm_f32le`。例如：

```ts
const result = streamTranscribe({
  model: cartesia.transcription('ink-2'),
  audio,
  inputAudioFormat: { type: 'audio/pcm', rate: 48000 },
  providerOptions: {
    cartesia: {
      streaming: {
        encoding: 'pcm_f32le',
      },
    },
  },
});
```

有关流式转录的更多信息，请参见[转录](/docs/ai-sdk-core/transcription)。

## 批量转录模型

你可以使用 `.transcription()` 工厂方法创建调用 [Cartesia 转录 API](https://docs.cartesia.ai/api-reference/stt/transcribe) 的模型。

第一个参数是模型 ID，例如 `ink-whisper`。

```ts
const model = cartesia.transcription('ink-whisper');
```

你可以将该模型与 `transcribe` 函数一起使用：

```ts
import { transcribe } from 'ai';
import { cartesia } from '@ai-sdk/cartesia';
import { readFile } from 'fs/promises';

const result = await transcribe({
  model: cartesia.transcription('ink-whisper'),
  audio: await readFile('audio.mp3'),
});
```

你还可以使用 `providerOptions` 参数传递额外的提供商特定选项：

```ts highlight="11-15"
import { transcribe } from 'ai';
import {
  cartesia,
  type CartesiaTranscriptionModelOptions,
} from '@ai-sdk/cartesia';
import { readFile } from 'fs/promises';

const result = await transcribe({
  model: cartesia.transcription('ink-whisper'),
  audio: await readFile('audio.mp3'),
  providerOptions: {
    cartesia: {
      language: 'en',
    } satisfies CartesiaTranscriptionModelOptions,
  },
});
```

以下提供商选项可用：

- **language** _string_

  音频的语言（ISO 639-1 代码）。如果未指定，默认为英语。
  可选。

- **timestampGranularities** _array of strings_

  要填充的时间戳粒度。目前仅支持 `'word'`。
  可选。
