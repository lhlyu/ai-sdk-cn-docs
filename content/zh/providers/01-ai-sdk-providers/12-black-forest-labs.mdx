# Black Forest Labs 提供商

[Black Forest Labs](https://bfl.ai/) 为开发者提供基于 FLUX 模型的生成式媒体平台。其平台提供快速、高质量且支持上下文感知的图像生成与编辑，以及使用 FLUX 3 的视频生成。

## 设置

Black Forest Labs 提供商通过 `@ai-sdk/black-forest-labs` 模块提供。你可以使用以下命令安装：

<InstallPackages packages="@ai-sdk/black-forest-labs" />

## 提供商实例

你可以从 `@ai-sdk/black-forest-labs` 导入默认提供商实例 `blackForestLabs`：

```ts
import { blackForestLabs } from '@ai-sdk/black-forest-labs';
```

如果你需要自定义设置，可以导入 `createBlackForestLabs` 并使用你的设置创建提供商实例：

```ts
import { createBlackForestLabs } from '@ai-sdk/black-forest-labs';

const blackForestLabs = createBlackForestLabs({
  apiKey: 'your-api-key', // optional, defaults to BFL_API_KEY environment variable
  baseURL: 'custom-url', // optional
  headers: {
    /* custom headers */
  }, // optional
});
```

你可以使用以下可选设置来自定义 Black Forest Labs 提供商实例：

- **baseURL** _string_

  为 API 调用使用不同的 URL 前缀，例如使用区域端点。
  默认前缀为 `https://api.bfl.ai/v1`。

- **apiKey** _string_

  通过 `x-key` 请求头发送的 API 密钥。
  默认为 `BFL_API_KEY` 环境变量。

- **headers** _Record&lt;string,string&gt;_

  要包含在请求中的自定义请求头。

- **fetch** _(input: RequestInfo, init?: RequestInit) => Promise&lt;Response&gt;_

  自定义 [fetch](https://developer.mozilla.org/en-US/docs/Web/API/fetch) 实现。
  你可以将其用作中间件来拦截请求，
  或提供用于测试等目的的自定义 fetch 实现。

- **pollIntervalMillis** _number_

  等待生成完成时轮询尝试之间的间隔（毫秒）。
  图像模型默认为 500ms，视频模型默认为 2000ms。

- **pollTimeoutMillis** _number_

  放弃之前轮询的总超时时间（毫秒）。
  图像模型默认为 60000ms（60 秒），视频模型默认为 600000ms（10 分钟）。

## 图像模型

你可以使用 `.image()` 工厂方法创建 Black Forest Labs 图像模型。
有关使用 AI SDK 进行图像生成的更多信息，请参阅 [generateImage()](/docs/reference/ai-sdk-core/generate-image)。

### 基本用法

```ts
import { writeFileSync } from 'node:fs';
import { blackForestLabs } from '@ai-sdk/black-forest-labs';
import { generateImage } from 'ai';

const { image, providerMetadata } = await generateImage({
  model: blackForestLabs.image('flux-pro-1.1'),
  prompt: 'A serene mountain landscape at sunset',
});

const filename = `image-${Date.now()}.png`;
writeFileSync(filename, image.uint8Array);
console.log(`Image saved to ${filename}`);
```

### 模型能力

Black Forest Labs 提供许多针对不同用例优化的模型。以下是一些常用示例。完整模型列表请参阅 [Black Forest Labs 模型页面](https://bfl.ai/models)。

| 模型                 | 描述                                                                                                                       |
| -------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| `flux-2-pro`         | FLUX.2 [pro]，在单个端点中实现文本到图像和基于参考的编辑                                                                   |
| `flux-2-max`         | FLUX.2 [max]，在 FLUX.2 系列中具有最高的提示词遵循度和细节                                                                 |
| `flux-2-flex`        | FLUX.2 [flex] 暴露 `steps` 和 `guidance`，让你可以在速度与质量之间权衡                                                     |
| `flux-2-klein-9b`    | FLUX.2 [klein] 9B，一个开放权重的蒸馏模型                                                                                  |
| `flux-2-klein-4b`    | FLUX.2 [klein] 4B，最小且最便宜的开放权重 FLUX.2 模型                                                                      |
| `flux-kontext-pro`   | FLUX.1 Kontext [pro] 同时处理文本和参考图像作为输入，支持定向编辑和复杂变换                                                |
| `flux-kontext-max`   | FLUX.1 Kontext [max]，具有改进的提示词遵循度和排版生成                                                                     |
| `flux-pro-1.1-ultra` | 超快速、超高分辨率图像创建                                                                                                 |
| `flux-pro-1.1`       | 从文本快速生成高质量图像。                                                                                                 |
| `flux-pro-1.0-fill`  | 用于用新内容填充图像蒙版区域的内补模型                                                                                     |

Black Forest Labs 模型支持从 3:7（竖版）到 7:3（横版）的宽高比。

FLUX.2 模型在与 Kontext 模型相同的 `prompt.images` 字段上接收参考图像，
因此单个模型 ID 即可覆盖文本到图像和编辑两种场景。请参阅下方的
[图像编辑](#image-editing)。

<Note>
  FLUX.2 生成可能超过默认的 60 秒轮询超时，
  尤其是在使用参考图像时。当请求报告
  `Black Forest Labs generation timed out.` 时，请提高 `pollTimeoutMillis`。
</Note>

### 图像编辑

Black Forest Labs Kontext 模型使用参考图像支持强大的图像编辑能力。通过 `prompt.images` 传入输入图像，以变换、组合或编辑现有图像。

#### 单图像编辑

使用文本提示词变换现有图像：

```ts
import {
  blackForestLabs,
  BlackForestLabsImageModelOptions,
} from '@ai-sdk/black-forest-labs';
import { generateImage } from 'ai';

const { images } = await generateImage({
  model: blackForestLabs.image('flux-kontext-pro'),
  prompt: {
    text: 'A baby elephant with a shirt that has the logo from the input image.',
    images: [
      'https://www.google.com/images/branding/googlelogo/1x/googlelogo_color_272x92dp.png',
    ],
  },
  providerOptions: {
    blackForestLabs: {
      width: 1024,
      height: 768,
    } satisfies BlackForestLabsImageModelOptions,
  },
});
```

#### 多参考编辑

组合多个参考图像以实现复杂变换。Black Forest Labs 最多支持 10 张输入图像：

```ts
import { blackForestLabs } from '@ai-sdk/black-forest-labs';
import { generateImage } from 'ai';

const { images } = await generateImage({
  model: blackForestLabs.image('flux-kontext-pro'),
  prompt: {
    text: 'Combine the style of image 1 with the subject of image 2',
    images: [
      'https://example.com/style-reference.jpg',
      'https://example.com/subject-reference.jpg',
    ],
  },
});
```

<Note>
  输入图像可以提供为 URL 或 base64 编码字符串。它们支持
  每张图像最大 20MB 或 20 兆像素。
</Note>

#### FLUX.2 编辑

FLUX.2 模型在相同的 `prompt.images` 字段上接受参考图像，因此无需
单独的编辑模型 ID：

```ts
import { blackForestLabs } from '@ai-sdk/black-forest-labs';
import { generateImage } from 'ai';

const { image } = await generateImage({
  model: blackForestLabs.image('flux-2-pro'),
  prompt: {
    text: 'Place this logo on a plain ceramic mug.',
    images: ['https://example.com/logo.png'],
  },
  providerOptions: {
    blackForestLabs: {
      pollTimeoutMillis: 240000,
    },
  },
});
```

`flux-2-flex` 还额外接受 `steps` 和 `guidance`，让你可以在
生成时间与质量之间权衡：

```ts
import { blackForestLabs } from '@ai-sdk/black-forest-labs';
import { generateImage } from 'ai';

const { image } = await generateImage({
  model: blackForestLabs.image('flux-2-flex'),
  prompt: 'A detailed macro shot of a dew-covered leaf',
  providerOptions: {
    blackForestLabs: {
      steps: 50,
      guidance: 4,
      pollTimeoutMillis: 240000,
    },
  },
});
```

#### 内补

`flux-pro-1.0-fill` 模型支持内补，允许你用新内容填充图像的蒙版区域。通过 `prompt.images` 传入源图像，并通过 `prompt.mask` 传入蒙版图像：

```ts
import { blackForestLabs } from '@ai-sdk/black-forest-labs';
import { generateImage } from 'ai';

const { images } = await generateImage({
  model: blackForestLabs.image('flux-pro-1.0-fill'),
  prompt: {
    text: 'A beautiful garden with flowers',
    images: ['https://example.com/source-image.jpg'],
    mask: 'https://example.com/mask-image.png',
  },
});
```

蒙版图像应为灰度图像，其中白色区域表示要填充的区域，黑色区域表示要保留的区域。

### 提供商选项

Black Forest Labs 图像模型通过 `providerOptions.blackForestLabs` 对象支持灵活的提供商选项。支持的参数取决于所使用的模型 ID：

- **width** _number_ - 输出宽度（像素，256–1920）。设置后，将覆盖从 `size` 派生的任何宽度。
- **height** _number_ - 输出高度（像素，256–1920）。设置后，将覆盖从 `size` 派生的任何高度。
- **outputFormat** _string_ - 输出图像的期望格式（`"jpeg"` 或 `"png"`）。
- **steps** _number_ - 推理步数。更高的值可能提高质量，但会增加生成时间。
- **guidance** _number_ - 生成的引导比例。更高的值会更紧密地遵循提示词。
- **imagePrompt** _string_ - 用作生成附加视觉上下文的 base64 编码图像。
- **imagePromptStrength** _number_ - 图像提示词对生成影响的强度（0.0 到 1.0）。
- **promptUpsampling** _boolean_ - 如果为 true，则对提示词执行上采样。
- **raw** _boolean_ - 启用原始模式以获得更自然、真实的美学效果。
- **safetyTolerance** _number_ - 输入和输出的审核级别（0 = 最严格，6 = 更宽松）。
- **pollIntervalMillis** _number_ - 轮询尝试之间的间隔（毫秒，默认 500ms）。
- **pollTimeoutMillis** _number_ - 超时之前轮询的总超时时间（毫秒，默认 60s）。
- **webhookUrl** _string_ - 用于异步完成通知的 URL。必须是有效的 HTTP/HTTPS URL。
- **webhookSecret** _string_ - 用于 webhook 签名验证的密钥，在 `X-Webhook-Secret` 请求头中发送。

<Note>
  要传入用于编辑的参考图像，请使用 `prompt.images` 而不是提供商
  选项。这支持最多 10 张图像，可以是 URL 或 base64 编码字符串。
</Note>

### 提供商元数据

`generateImage` 响应在 `providerMetadata.blackForestLabs.images[]` 中包含提供商特定的元数据。每个图像对象可能包含以下属性：

- **seed** _number_ - 用于生成的种子。可用于复现结果。
- **start_time** _number_ - 生成开始时的 Unix 时间戳。
- **end_time** _number_ - 生成完成时的 Unix 时间戳。
- **duration** _number_ - 生成持续时间（秒）。
- **cost** _number_ - 生成请求的成本。
- **inputMegapixels** _number_ - 输入图像大小（兆像素）。
- **outputMegapixels** _number_ - 输出图像大小（兆像素）。

```ts
import { blackForestLabs } from '@ai-sdk/black-forest-labs';
import { generateImage } from 'ai';

const { image, providerMetadata } = await generateImage({
  model: blackForestLabs.image('flux-pro-1.1'),
  prompt: 'A serene mountain landscape at sunset',
});

// Access provider metadata
const metadata = providerMetadata?.blackForestLabs?.images?.[0];
console.log('Seed:', metadata?.seed);
console.log('Cost:', metadata?.cost);
console.log('Duration:', metadata?.duration);
```

### 区域端点

默认情况下，请求发送到 `https://api.bfl.ai/v1`。你可以在创建提供商实例时通过设置 `baseURL` 来选择[区域端点](https://docs.bfl.ai/api_integration/integration_guidelines#regional-endpoints)：

```ts
import { createBlackForestLabs } from '@ai-sdk/black-forest-labs';

const blackForestLabs = createBlackForestLabs({
  baseURL: 'https://api.eu.bfl.ai/v1', // or https://api.us.bfl.ai/v1
});
```

## 视频模型

你可以使用
[`experimental_generateVideo`](/docs/reference/ai-sdk-core/generate-video)
函数通过 FLUX 3 视频模型生成视频：

```ts
import {
  blackForestLabs,
  type BlackForestLabsVideoModelOptions,
} from '@ai-sdk/black-forest-labs';
import { experimental_generateVideo as generateVideo } from 'ai';

const { video } = await generateVideo({
  model: blackForestLabs.video('flux-3-video'),
  prompt: 'A white kitten chases a butterfly across a sunlit garden.',
  aspectRatio: '16:9',
  duration: 8,
  poll: {
    intervalMs: 2000,
    timeoutMs: 600000, // 10 minutes
  },
  providerOptions: {
    blackForestLabs: {
      resolution: 'fhd',
    } satisfies BlackForestLabsVideoModelOptions,
  },
});
```

FLUX 3 每次调用生成一个视频。生成是异步的——模型
提交一个任务并轮询直到完成，然后将签名的 MP4 URL 传递给 AI
SDK Core。`generateVideo` 在解析之前下载它，因此 `video` 是一个
`GeneratedFile`。签名 URL 仍可在
`providerMetadata.blackForestLabs.videos[0].videoUrl` 中获取。

使用顶层 `poll` 选项让 AI SDK Core 编排轮询并设置
间隔和超时。FLUX 3 视频 API 目前不暴露
webhook 回调输入，因此顶层 `webhook` 会回退到轮询。

`duration` 接受从 5 到 20 的整数秒。小数值会被
四舍五入，超出范围的值会被钳制，两者都会发出警告。省略它可让
FLUX 3 根据内容调整时长。

音频默认生成，因此只需将 `generateAudio` 设置为关闭它。`fps` 和 `seed` 不受 API 支持，会作为警告报告。

<Note>
  提供商元数据中的 URL 有时间限制。请将返回的 `video`
  字节持久化到你自己的存储中。
</Note>

### 分辨率和宽高比

API 采用命名的分辨率层级，`hd` 或 `fhd`（默认为 `hd`），其中
`fhd` 由视频上采样器完成。确切的帧大小取决于
宽高比。

顶层 `resolution` 选项是 `{width}x{height}`，因此它按其较短边映射到
层级——`1280x720` 变为 `hd`，`1920x1080` 变为 `fhd`。
其他值在较短边最多为 720 像素时映射到 `hd`，超过 720 时映射到
`fhd`，并发出报告映射的警告。使用
`providerOptions.blackForestLabs.resolution` 直接设置层级。

`aspectRatio` 接受 `21:9`、`2:1`、`16:9`、`4:3`、`1:1`、`3:4` 和 `9:16`。API
默认值为 `auto`，它会从提示词和任何
条件媒体推断比例；由于顶层选项必须是 `{width}:{height}`，
`auto` 只能通过
`providerOptions.blackForestLabs.aspectRatio` 请求。

### 生成模式

FLUX 3 是带有 `mode` 判别器的单个端点。模式从你传入的输入
推断：

- **文本到视频** — 仅 `prompt`。
- **图像到视频** — 传入 `image`（或带有
  `frameType: 'first_frame'` 的 `frameImages` 条目）来为起始图像添加动画。添加 `last_frame`
  会在该图像上结束片段。没有 `first_frame` 的 `last_frame` 无法
  表达，会被丢弃并发出警告。
- **关键帧** — 对于超过两张图像，或固定到特定
  秒的图像，传入 `providerOptions.blackForestLabs.keyframes`。它优先于
  `image` 和 `frameImages`。
- **视频续接** — 在 `inputReferences` 中传入视频类型的条目，以
  从现有 MP4 的最后帧继续。FLUX 3 接受单个
  视频；关键帧和续接是互斥的。
- **草稿增强** — 传入 `providerOptions.blackForestLabs.draftCache`。请参阅
  [草稿模式](#draft-mode)。

FLUX 3 没有参考图像输入，因此在 `inputReferences` 中传入的图像会被
忽略，并发出指向 `image`、`frameImages` 或 `keyframes` 的警告。

### 关键帧

关键帧是位置性的：一张图像打开片段，两张打开并关闭它，而
更多时第一张和最后一张是端点，其他图像在它们之间均匀
分布。每张图像是 `http(s)` URL 或 base64 字符串，一个请求
接受 1 到 10 张。

三个或更多未定时的关键帧需要显式的 `duration`；提供商
在发送该组合时报告警告，因为 API 会拒绝它。

改为按时间顺序传入 `[seconds, image]` 对，将每张图像固定到
片段的某一秒：

```ts
import {
  blackForestLabs,
  type BlackForestLabsVideoModelOptions,
} from '@ai-sdk/black-forest-labs';
import { experimental_generateVideo as generateVideo } from 'ai';
import { readFileSync } from 'node:fs';

const asBase64 = (file: string) => readFileSync(file).toString('base64');

const { video } = await generateVideo({
  model: blackForestLabs.video('flux-3-video'),
  prompt: 'The cat, then the dog, then the owl each take a turn in the room.',
  duration: 12,
  providerOptions: {
    blackForestLabs: {
      keyframes: [
        [0, asBase64('cat.png')],
        [4.5, asBase64('dog.png')],
        [9, asBase64('owl.png')],
      ],
    } satisfies BlackForestLabsVideoModelOptions,
  },
});
```

### 草稿模式

设置 `draft: true` 会渲染快速、较低质量的预览，并留下一个
加密包，报告为
`providerMetadata.blackForestLabs.videos[0].draftCache`。将该包作为 `draftCache` 传回
会以完整质量复现相同的生成。

该包固定原始模式、提示词、种子和条件媒体，因此增强
请求除了 `safetyTolerance` 之外不接受任何内容。调用中设置的任何其他选项
都会报告为 `unsupported` 警告。`generateVideo` 需要一个
`prompt` 参数，因此传入空字符串表示没有要添加的内容。

```ts
import {
  blackForestLabs,
  type BlackForestLabsVideoModelOptions,
} from '@ai-sdk/black-forest-labs';
import { experimental_generateVideo as generateVideo } from 'ai';

const draft = await generateVideo({
  model: blackForestLabs.video('flux-3-video'),
  prompt: 'A white kitten chases a butterfly across a sunlit garden.',
  duration: 6,
  providerOptions: {
    blackForestLabs: { draft: true } satisfies BlackForestLabsVideoModelOptions,
  },
});

const draftCacheUrl = (
  draft.providerMetadata.blackForestLabs?.videos as
    | Array<{ draftCache?: string }>
    | undefined
)?.[0]?.draftCache;

// The download URL expires; sending the base64 `.bin` is the durable path,
// though the URL itself also works while the link is still valid.
const response = await fetch(draftCacheUrl!);
const arrayBuffer = await response.arrayBuffer();

const enhanced = await generateVideo({
  model: blackForestLabs.video('flux-3-video'),
  prompt: '',
  providerOptions: {
    blackForestLabs: {
      draftCache: Buffer.from(arrayBuffer).toString('base64'),
    } satisfies BlackForestLabsVideoModelOptions,
  },
});
```

<Note>
  草稿及其增强是两次单独的生成，每次都会
  单独计费。
</Note>

### 视频提供商选项

以下可选提供商选项可用于 FLUX 3 视频：

- **resolution** _'hd' | 'fhd'_

  输出分辨率层级。优先于顶层 `resolution`。

- **aspectRatio** _'21:9' | '2:1' | '16:9' | '4:3' | '1:1' | '3:4' | '9:16' | 'auto'_

  生成视频的宽高比。优先于顶层
  `aspectRatio`，并且与它不同，可以设置为 `auto`。

- **keyframes** _Array&lt;string | [number, string]&gt;_

  用于图像到视频生成的关键帧，适用于 `image` 和
  `frameImages` 无法表达的形式：超过两张图像，或固定到
  特定秒的图像。优先于两者。

- **safetyTolerance** _number_

  审核严格程度，从 0（最严格）到 4。默认为 2。无论
  请求如何，性内容上限为 3，仇恨内容上限为 2，任何携带
  条件媒体的请求上限为 2。

- **draft** _boolean_

  渲染快速、较低质量的预览，而不是完成的视频。默认为
  `false`。

- **draftCache** _string_

  来自先前 `draft` 生成的加密草稿缓存包，会将
  请求切换为草稿增强模式。

- **version** _string_

  要固定的模型版本。目前仅提供 `latest`。

### 视频提供商元数据

FLUX 3 视频结果包含 `providerMetadata.blackForestLabs.videos[]`。每个
视频对象可能包含以下属性：

- **id** _string_ - Black Forest Labs 生成请求的 ID。
- **videoUrl** _string_ - 签名的 MP4 URL（与 `video` 相同的 URL）。有时间限制。
- **draftCache** _string_ - 草稿包的下载 URL。仅在 `draft` 生成时存在。
- **seed** _number_ - 用于生成的种子，当 API 报告时提供。
- **start_time** _number_ - 生成开始时的 Unix 时间戳。
- **end_time** _number_ - 生成完成时的 Unix 时间戳。
- **duration** _number_ - API 报告的持续时间（秒）。
- **cost** _number_ - 生成请求的成本（以积分为单位）。
- **inputMegapixels** _number_ - 输入大小（兆像素）。
- **outputMegapixels** _number_ - 输出大小（兆像素）。
