# Moonshot AI 提供商

[Moonshot AI](https://www.moonshot.ai) 提供商通过 Moonshot API 提供对强大语言模型的访问，包括具有推理能力的 Kimi 系列模型。

API 密钥可以从 [Moonshot 平台](https://platform.moonshot.ai) 获取。

## 安装

Moonshot AI 提供商可通过 `@ai-sdk/moonshotai` 模块获得。您可以使用以下命令安装：

<InstallPackages packages="@ai-sdk/moonshotai" />

## 提供商实例

您可以从 `@ai-sdk/moonshotai` 导入默认提供商实例 `moonshotai`：

```ts
import { moonshotai } from '@ai-sdk/moonshotai';
```

对于自定义配置，您可以导入 `createMoonshotAI` 并使用您的设置创建提供商实例：

```ts
import { createMoonshotAI } from '@ai-sdk/moonshotai';

const moonshotai = createMoonshotAI({
  apiKey: process.env.MOONSHOT_API_KEY ?? '',
});
```

您可以使用以下可选设置来自定义 Moonshot AI 提供商实例：

- **baseURL** _string_

  为 API 调用使用不同的 URL 前缀。
  默认前缀为 `https://api.moonshot.ai/v1`

- **apiKey** _string_

  通过 `Authorization` 标头发送的 API 密钥。默认为
  `MOONSHOT_API_KEY` 环境变量

- **headers** _Record&lt;string,string&gt;_

  要包含在请求中的自定义标头

- **fetch** _(input: RequestInfo, init?: RequestInit) => Promise&lt;Response&gt;_

  自定义 [fetch](https://developer.mozilla.org/en-US/docs/Web/API/fetch) 实现

## 语言模型

您可以使用提供商实例创建语言模型：

```ts
import { moonshotai } from '@ai-sdk/moonshotai';
import { generateText } from 'ai';

const { text } = await generateText({
  model: moonshotai('kimi-k3'),
  prompt: '写一份适合 4 人的素食千层面食谱。',
});
```

您也可以使用 `.chatModel()` 或 `.languageModel()` 工厂方法：

```ts
const model = moonshotai.chatModel('kimi-k3');
// 或
const model = moonshotai.languageModel('kimi-k3');
```

Moonshot AI 语言模型可用于 `streamText` 函数
（参见 [AI SDK Core](/docs/ai-sdk-core)）。

#### 结构化输出

对于模型 ID 以 `kimi-` 开头的 Moonshot 模型，原生结构化输出已启用。

对于其他 Moonshot 模型，对象生成将回退到 JSON 模式，而不是受模式约束的解码。

为了获得最佳可靠性，强烈建议在提示词中包含您的模式要求，同时通过 `Output` 传递模式。

### 推理模型

Kimi K3 始终进行推理。它目前仅支持 `max` 推理强度，
您可以通过提供商选项进行配置：

```ts
import {
  moonshotai,
  type MoonshotAILanguageModelOptions,
} from '@ai-sdk/moonshotai';
import { generateText } from 'ai';

const { text, reasoningText } = await generateText({
  model: moonshotai('kimi-k3'),
  providerOptions: {
    moonshotai: {
      reasoningEffort: 'max',
    } satisfies MoonshotAILanguageModelOptions,
  },
  prompt: '单词 "strawberry" 中有多少个 "r"？',
});

console.log(reasoningText);
console.log(text);
```

Moonshot AI 提供思考模型，如 `kimi-k2-thinking`，这些模型在最终响应之前生成中间推理令牌。推理输出通过标准的 AI SDK 推理部分进行流式传输。

```ts
import {
  moonshotai,
  type MoonshotAILanguageModelOptions,
} from '@ai-sdk/moonshotai';
import { generateText } from 'ai';

const { text, reasoningText } = await generateText({
  model: moonshotai('kimi-k2-thinking'),
  providerOptions: {
    moonshotai: {
      thinking: { type: 'enabled', budgetTokens: 2048 },
      reasoningHistory: 'interleaved',
    } satisfies MoonshotAILanguageModelOptions,
  },
  prompt: '单词 "strawberry" 中有多少个 "r"？',
});

console.log(reasoningText);
console.log(text);
```

有关如何将推理集成到聊天机器人中的更多详细信息，请参阅 [AI SDK UI：聊天机器人](/docs/ai-sdk-ui/chatbot#reasoning)。

### 视频输入

Kimi K3、Kimi K2.7 Code、Kimi K2.6 和 Kimi K2.5 支持视频输入。将视频作为带有视频媒体类型的 `file` 内容部分传递：

```ts
import { moonshotai } from '@ai-sdk/moonshotai';
import { generateText } from 'ai';
import fs from 'node:fs';

const { text } = await generateText({
  model: moonshotai('kimi-k3'),
  messages: [
    {
      role: 'user',
      content: [
        { type: 'text', text: '总结这个视频中发生的事情。' },
        {
          type: 'file',
          data: fs.readFileSync('./video.mp4'),
          mediaType: 'video/mp4',
        },
      ],
    },
  ],
});

console.log(text);
```

您也可以传递 URL。由于 Moonshot AI 不获取外部 URL，AI SDK 会下载视频并在发送前将其内联为 base64：

```ts
{
  type: 'file',
  data: new URL('https://example.com/video.mp4'),
  mediaType: 'video/mp4',
}
```

<Note>
  Moonshot AI 建议视频分辨率不超过 1080p。对于较大的视频，或您需要在多个请求中重复使用的视频，请改用 [Moonshot 文件 API](https://platform.moonshot.ai/docs/api/files) 上传。Moonshot AI 聊天补全不支持音频和 PDF 输入。
</Note>

### 提供商选项

以下可选的提供商选项可用于 Moonshot AI 语言模型：

- **reasoningEffort** _'max'_

  Kimi K3 的推理强度。目前仅支持 `'max'`。

- **thinking** _object_

  针对思考/推理模型（如 Kimi K2 Thinking）的配置。
  - **type** _'enabled' | 'disabled'_

    是否启用思考模式

  - **budgetTokens** _number_

    思考的最大令牌数（最小 1024）

- **reasoningHistory** _'disabled' | 'interleaved' | 'preserved'_

  控制多轮对话中推理历史的处理方式：
  - `'disabled'`：从历史记录中移除推理
  - `'interleaved'`：在单轮对话中的工具调用之间包含推理
  - `'preserved'`：在历史记录中保留所有推理。映射到 Moonshot 的
    `thinking.keep: 'all'` 请求字段。
