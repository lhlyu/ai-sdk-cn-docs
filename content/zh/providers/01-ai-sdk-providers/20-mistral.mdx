# Mistral AI 提供商

[Mistral AI](https://mistral.ai/) 提供商包含对 Mistral API 的语言模型、嵌入模型、语音模型和转录模型支持。

## 设置

Mistral 提供商可在 `@ai-sdk/mistral` 模块中获得。你可以通过以下命令安装：

<InstallPackages packages="@ai-sdk/mistral" />

## 提供商实例

你可以从 `@ai-sdk/mistral` 导入默认提供商实例 `mistral`：

```ts
import { mistral } from '@ai-sdk/mistral';
```

如果你需要自定义设置，可以从 `@ai-sdk/mistral` 导入 `createMistral` 并使用你的设置创建提供商实例：

```ts
import { createMistral } from '@ai-sdk/mistral';

const mistral = createMistral({
  // 自定义设置
});
```

你可以使用以下可选设置来自定义 Mistral 提供商实例：

- **baseURL** _string_

  为 API 调用使用不同的 URL 前缀，例如使用代理服务器。默认前缀为 `https://api.mistral.ai/v1`。

- **apiKey** _string_

  通过 `Authorization` 标头发送的 API 密钥。默认为 `MISTRAL_API_KEY` 环境变量。

- **headers** _Record&lt;string,string&gt;_

  要包含在请求中的自定义标头。

- **fetch** _(input: RequestInfo, init?: RequestInit) => Promise&lt;Response&gt;_

  自定义 [fetch](https://developer.mozilla.org/en-US/docs/Web/API/fetch) 实现。默认为全局 `fetch` 函数。你可以将其用作中间件来拦截请求，或提供自定义 fetch 实现，例如用于测试。

## 语言模型

你可以使用提供商实例创建调用 [Mistral 聊天 API](https://docs.mistral.ai/api/#operation/createChatCompletion) 的模型。第一个参数是模型 ID，例如 `mistral-large-latest`。某些 Mistral 聊天模型支持工具调用。

```ts
const model = mistral('mistral-large-latest');
```

Mistral 聊天模型还支持不属于 [标准调用设置](/docs/ai-sdk-core/settings) 的额外模型设置。你可以将它们作为选项参数传递，并使用 `MistralLanguageModelChatOptions` 进行类型检查：

```ts
import { mistral, type MistralLanguageModelChatOptions } from '@ai-sdk/mistral';
const model = mistral('mistral-large-latest');

await generateText({
  model,
  providerOptions: {
    mistral: {
      safePrompt: true, // 可选的安全提示词注入
      parallelToolCalls: false, // 禁用并行工具调用（每个响应一个工具）
    } satisfies MistralLanguageModelChatOptions,
  },
});
```

以下可选提供商选项可用于 Mistral 模型：

- **safePrompt** _boolean_

  是否在所有对话之前注入安全提示词。

  默认为 `false`。

- **documentImageLimit** _number_

  文档中要处理的最大图像数量。

- **documentPageLimit** _number_

  文档中要处理的最大页数。

- **strictJsonSchema** _boolean_

  是否对结构化输出使用严格的 JSON Schema 验证。仅在提供 schema 时适用，并且除了使用 [自定义结构化输出](https://docs.mistral.ai/capabilities/structured-output/custom_structured_output/)（如果提供 schema，默认使用）之外，还会设置 [`strict` 标志](https://docs.mistral.ai/api/#tag/chat/operation/chat_completion_v1_chat_completions_post)。

  默认为 `false`。

- **structuredOutputs** _boolean_

  是否使用 [结构化输出](#structured-outputs)。启用后，工具调用和对象生成将严格遵循提供的 schema。

  默认为 `true`。

- **parallelToolCalls** _boolean_

  是否在工具使用期间启用并行函数调用。设置为 `false` 时，模型每个响应最多使用一个工具。

  默认为 `true`。

### 文档 OCR

Mistral 聊天模型支持 PDF 文件的文档 OCR。你可以使用提供商选项可选地设置图像和页数限制。

```ts
import { mistral, type MistralLanguageModelChatOptions } from '@ai-sdk/mistral';
import { generateText } from 'ai';

const result = await generateText({
  model: mistral('mistral-small-latest'),
  messages: [
    {
      role: 'user',
      content: [
        {
          type: 'text',
          text: '根据这份文档，什么是嵌入模型？',
        },
        {
          type: 'file',
          data: new URL(
            'https://github.com/vercel/ai/blob/main/examples/ai-functions/data/ai.pdf?raw=true',
          ),
          mediaType: 'application/pdf',
        },
      ],
    },
  ],
  // 可选设置：
  providerOptions: {
    mistral: {
      documentImageLimit: 8,
      documentPageLimit: 64,
    } satisfies MistralLanguageModelChatOptions,
  },
});
```

### 推理模型

Mistral 提供具有逐步思考能力的推理模型：

- **magistral-small-2507**：较小的推理模型，用于高效的逐步思考
- **magistral-medium-2507**：更强大的推理模型，平衡性能和成本

这些模型返回结构化推理内容，AI SDK 会自动提取。推理内容可通过结果中的 `reasoningText` 属性获取：

```ts
import { mistral } from '@ai-sdk/mistral';
import { generateText } from 'ai';

const result = await generateText({
  model: mistral('magistral-small-2507'),
  prompt: '15 * 24 等于多少？',
});

console.log('推理：', result.reasoningText);
// 输出："让我逐步计算..."

console.log('答案：', result.text);
// 输出："360"
```

SDK 会自动解析 Mistral 的原生推理格式，并在结果中提供独立的 `reasoningText` 和 `text` 属性。无需中间件。

#### 可配置推理

某些 Mistral 模型支持可配置推理，你可以通过 `reasoning` 参数进行控制。你可以使用 AI SDK 的顶层 `reasoning` 设置来控制推理强度：

```ts
import { mistral } from '@ai-sdk/mistral';
import { generateText } from 'ai';

const result = await generateText({
  model: mistral('mistral-small-latest'),
  reasoning: 'high',
  prompt: '15 * 24 等于多少？',
});

console.log('推理：', result.reasoningText);
console.log('答案：', result.text);
```

目前，Mistral 仅支持 `'high'` 和 `'none'` 作为推理强度级别。

### 示例

你可以使用 Mistral 语言模型通过 `generateText` 函数生成文本：

```ts
import { mistral } from '@ai-sdk/mistral';
import { generateText } from 'ai';

const { text } = await generateText({
  model: mistral('mistral-large-latest'),
  prompt: '写一份适合 4 人的素食千层面食谱。',
});
```

Mistral 语言模型也可以用于 `streamText` 函数，并支持使用 [`Output`](/docs/reference/ai-sdk-core/output) 进行结构化数据生成（参见 [AI SDK Core](/docs/ai-sdk-core)）。

#### 结构化输出

Mistral 聊天模型支持使用 JSON Schema 的结构化输出。你可以将 `generateText` 或 `streamText` 与 [`Output`](/docs/reference/ai-sdk-core/output) 以及 Zod、Valibot 或原始 JSON Schema 一起使用。SDK 会通过 Mistral 的 `response_format: { type: 'json_schema' }` 发送你的 schema。

```ts
import { mistral } from '@ai-sdk/mistral';
import { generateText, Output } from 'ai';
import { z } from 'zod';

const result = await generateText({
  model: mistral('mistral-large-latest'),
  output: Output.object({
    schema: z.object({
      recipe: z.object({
        name: z.string(),
        ingredients: z.array(z.string()),
        instructions: z.array(z.string()),
      }),
    }),
  }),
  prompt: '生成一个简单的意大利面食谱。',
});

console.log(JSON.stringify(result.output, null, 2));
```

你可以使用提供商选项启用严格的 JSON Schema 验证：

```ts highlight="7-11"
import { mistral, type MistralLanguageModelChatOptions } from '@ai-sdk/mistral';
import { generateText, Output } from 'ai';
import { z } from 'zod';

const result = await generateText({
  model: mistral('mistral-large-latest'),
  providerOptions: {
    mistral: {
      strictJsonSchema: true,
    } satisfies MistralLanguageModelChatOptions,
  },
  output: Output.object({
    schema: z.object({
      title: z.string(),
      items: z.array(
        z.object({ id: z.string(), qty: z.number().int().min(1) }),
      ),
    }),
  }),
  prompt: '生成一个小的购物清单。',
});
```

<Note>
  使用结构化输出时，SDK 不再注入额外的“用 JSON 回答”指令。它依赖 Mistral 原生的 `json_schema`/`json_object` 响应格式。你可以通过标准的结构化输出 API 自定义 schema 名称/描述。
</Note>

## 转录模型

你可以使用 `.transcription()` 工厂方法创建调用 [Mistral 音频转录 API](https://docs.mistral.ai/api/endpoint/audio/transcriptions) 的模型：

```ts
const model = mistral.transcription('voxtral-mini-latest');
```

将 Mistral 转录模型与 [`transcribe`](/docs/reference/ai-sdk-core/transcribe) 一起使用：

```ts
import { mistral } from '@ai-sdk/mistral';
import { transcribe } from 'ai';
import { readFile } from 'node:fs/promises';

const result = await transcribe({
  model: mistral.transcription('voxtral-mini-latest'),
  audio: await readFile('audio.mp3'),
});
```

Mistral 转录模型支持额外的提供商选项。通过 `providerOptions.mistral` 传递它们，并使用 `MistralTranscriptionModelOptions` 进行类型检查：

```ts highlight="9-13"
import {
  mistral,
  type MistralTranscriptionModelOptions,
} from '@ai-sdk/mistral';
import { transcribe } from 'ai';
import { readFile } from 'node:fs/promises';

const result = await transcribe({
  model: mistral.transcription('voxtral-mini-latest'),
  audio: await readFile('audio.mp3'),
  providerOptions: {
    mistral: {
      timestampGranularities: ['segment'],
      diarize: true,
      contextBias: ['Vercel', 'AI_SDK'],
    } satisfies MistralTranscriptionModelOptions,
  },
});
```

以下可选提供商选项可用：

- **language** _string_

  音频的语言，例如 `en`。提供它可以提高准确性。

- **temperature** _number_

  转录的采样温度。

- **timestampGranularities** _Array&lt;'segment' | 'word'&gt;_

  要包含在响应中的时间戳粒度。Mistral 不支持将此选项与 `language` 组合使用；当同时提供两者时，SDK 会抛出 `InvalidArgumentError`。

- **diarize** _boolean_

  是否在转录中识别说话人。

- **contextBias** _string[]_

  最多 100 个单词或短语，用于指导名称、技术术语或领域特定词汇的拼写。项目不能包含逗号或空白；多词短语请使用下划线。

规范化结果包括转录文本、语言、带时间戳的片段以及 Mistral 返回时的时长。Mistral token 和提示音频使用量可在 `result.providerMetadata.mistral.usage` 下获取。来自说话人分离的片段分数和说话人 ID 可在 `result.providerMetadata.mistral.segments` 下获取。

<Note>
  音频会上传到 Mistral 进行处理。此集成仅支持批量转录；Mistral 实时转录不通过此模型暴露。
</Note>

## 语音模型

你可以使用 `.speech()` 工厂方法创建调用 [Mistral 语音 API](https://docs.mistral.ai/api/endpoint/audio/speech) 的模型：

```ts
const model = mistral.speech('voxtral-mini-tts-2603');
```

使用预设或已保存的语音 ID 与 [`generateSpeech`](/docs/reference/ai-sdk-core/generate-speech) 一起使用：

```ts
import { mistral } from '@ai-sdk/mistral';
import { generateSpeech } from 'ai';

const result = await generateSpeech({
  model: mistral.speech('voxtral-mini-tts-2603'),
  text: '来自 AI SDK 的问候！',
  voice: 'en_paul_neutral',
  outputFormat: 'mp3',
});

const audio = result.audio.uint8Array;
```

Mistral 语音模型将 `voice` 映射到 Mistral 的 `voice_id`。它支持 `mp3`、`wav`、`pcm`、`flac` 和 `opus` 输出格式，默认为 `mp3`。`instructions`、`speed` 和 `language` 设置不受支持，提供时会产生警告。

Mistral 还支持使用 base64 编码的参考音频进行一次性语音克隆。通过 `providerOptions.mistral.refAudio` 传递它，并使用 `MistralSpeechModelOptions` 进行类型检查：

```ts highlight="9-13"
import { readFile } from 'node:fs/promises';
import { mistral, type MistralSpeechModelOptions } from '@ai-sdk/mistral';
import { generateSpeech } from 'ai';

const referenceAudio = await readFile('./reference.mp3');

const result = await generateSpeech({
  model: mistral.speech('voxtral-mini-tts-2603'),
  text: '来自 AI SDK 的问候！',
  providerOptions: {
    mistral: {
      refAudio: referenceAudio.toString('base64'),
    } satisfies MistralSpeechModelOptions,
  },
});
```

当提供 `refAudio` 时，它优先于 `voice`。参考音频会从请求元数据和提供商返回的 API 调用错误中编辑掉。

<Note>
  仅在使用说话人明确同意的情况下使用参考音频。遵循 Mistral 的语音克隆使用政策，并在需要时披露 AI 生成的音频。此提供商集成支持非流式语音生成；Mistral 的流式语音 API 不通过 `SpeechModelV4` 暴露。
</Note>

## 嵌入模型

你可以使用 `.embedding()` 工厂方法创建调用 [Mistral 嵌入 API](https://docs.mistral.ai/api/#operation/createEmbedding) 的模型。

```ts
const model = mistral.embedding('mistral-embed');
```

你可以使用 Mistral 嵌入模型通过 `embed` 函数生成嵌入：

```ts
import { mistral } from '@ai-sdk/mistral';
import { embed } from 'ai';

const { embedding } = await embed({
  model: mistral.embedding('codestral-embed-2505'),
  value: 'function add(a: number, b: number) { return a + b; }',
});
```

Mistral 嵌入模型通过 `providerOptions.mistral` 支持额外的提供商选项。你可以使用 `MistralEmbeddingModelOptions` 进行验证：

```ts
import { mistral, type MistralEmbeddingModelOptions } from '@ai-sdk/mistral';
import { embed } from 'ai';

const { embedding } = await embed({
  model: mistral.embedding('mistral-embed'),
  value: '阳光明媚的海滩日',
  providerOptions: {
    mistral: {
      metadata: { source: 'knowledge-base' },
      outputDimension: 1024,
      outputDtype: 'float',
    } satisfies MistralEmbeddingModelOptions,
  },
});
```

以下可选提供商选项可用于 Mistral 嵌入模型：

- **metadata** _Record&lt;string, unknown&gt;_

  要附加到嵌入请求的额外元数据。

- **outputDimension** _number_

  模型支持时输出嵌入的维度。

- **outputDtype** _string_

  模型支持时输出嵌入的数据类型。接受 `'float'`、`'int8'`、`'uint8'`、`'binary'` 或 `'ubinary'`。
