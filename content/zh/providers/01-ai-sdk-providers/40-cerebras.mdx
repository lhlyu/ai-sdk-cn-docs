# Cerebras 提供商

[Cerebras](https://cerebras.ai) 提供商通过 Cerebras API 提供对强大语言模型的访问，包括由晶圆级引擎和 CS-3 系统支持的高速推理能力。

API 密钥可从 [Cerebras 平台](https://cloud.cerebras.ai) 获取。

## 设置

Cerebras 提供商可通过 `@ai-sdk/cerebras` 模块获得。您可以使用以下命令安装：

<InstallPackages packages="@ai-sdk/cerebras" />

## 提供商实例

您可以从 `@ai-sdk/cerebras` 导入默认的提供商实例 `cerebras`：

```ts
import { cerebras } from '@ai-sdk/cerebras';
```

对于自定义配置，您可以导入 `createCerebras` 并使用您的设置创建提供商实例：

```ts
import { createCerebras } from '@ai-sdk/cerebras';

const cerebras = createCerebras({
  apiKey: process.env.CEREBRAS_API_KEY ?? '',
});
```

您可以使用以下可选设置来自定义 Cerebras 提供商实例：

- **baseURL** _string_

  为 API 调用使用不同的 URL 前缀。
  默认前缀为 `https://api.cerebras.ai/v1`。

- **apiKey** _string_

  通过 `Authorization` 标头发送的 API 密钥。默认值为
  `CEREBRAS_API_KEY` 环境变量。

- **headers** _Record&lt;string,string&gt;_

  要包含在请求中的自定义标头。

- **fetch** _(input: RequestInfo, init?: RequestInit) => Promise&lt;Response&gt;_

  自定义 [fetch](https://developer.mozilla.org/en-US/docs/Web/API/fetch) 实现。

## 语言模型

您可以使用提供商实例创建语言模型：

```ts
import { cerebras } from '@ai-sdk/cerebras';
import { generateText } from 'ai';

const { text } = await generateText({
  model: cerebras('llama3.1-8b'),
  prompt: '写一份供4人食用的素食千层面食谱。',
});
```

Cerebras 语言模型可用于 `streamText` 函数
（请参阅 [AI SDK Core](/docs/ai-sdk-core)）。

您可以使用提供商实例创建 Cerebras 语言模型。第一个参数是模型 ID，例如 `llama-3.3-70b`：

```ts
const model = cerebras('llama-3.3-70b');
```

您也可以使用 `.languageModel()` 和 `.chat()` 方法：

```ts
const model = cerebras.languageModel('llama-3.3-70b');
const model = cerebras.chat('llama-3.3-70b');
```

### 推理模型

Cerebras 提供多种推理模型，包括 `gpt-oss-120b`、`qwen-3-32b` 和 `zai-glm-4.7`，这些模型在最终响应之前会生成中间思考令牌。推理输出通过标准的 AI SDK 推理部分进行流式传输。

对于 `gpt-oss-120b`，您可以使用 `reasoningEffort` 提供商选项控制推理深度：

```ts
import { cerebras } from '@ai-sdk/cerebras';
import { streamText } from 'ai';

const result = streamText({
  model: cerebras('gpt-oss-120b'),
  providerOptions: {
    cerebras: {
      reasoningEffort: 'medium',
    },
  },
  prompt: '单词 "strawberry" 中有多少个字母 "r"？',
});

for await (const part of result.stream) {
  if (part.type === 'reasoning') {
    console.log('推理过程:', part.text);
  } else if (part.type === 'text-delta') {
    process.stdout.write(part.textDelta);
  }
}
```

有关如何将推理集成到聊天机器人的更多详细信息，请参阅 [AI SDK UI：聊天机器人](/docs/ai-sdk-ui/chatbot#reasoning)。

### 提供商选项

Cerebras 语言模型提供以下可选提供商选项：

- **reasoningEffort** _'low' | 'medium' | 'high'_

  控制 GPT-OSS 模型的推理深度。默认为 `'medium'`。

- **user** _string_

  代表最终用户的唯一标识符，有助于监控和滥用检测。

- **strictJsonSchema** _boolean_

  是否使用严格的 JSON Schema 验证。当为 `true` 时，模型使用约束解码来保证 Schema 合规性。默认为 `true`。
