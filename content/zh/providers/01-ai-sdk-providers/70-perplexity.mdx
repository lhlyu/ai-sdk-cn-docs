# Perplexity 提供商

[Perplexity](https://sonar.perplexity.ai) 提供商提供对 Sonar API 的访问——这是一种将实时网络搜索与自然语言处理独特结合的语言模型。每个响应都基于当前网络数据，并包含详细的引用，非常适合研究、事实核查和获取最新信息。

API 密钥可以从 [Perplexity 平台](https://docs.perplexity.ai) 获取。

## 安装

Perplexity 提供商可通过 `@ai-sdk/perplexity` 模块获得。您可以使用以下命令安装：

<InstallPackages packages="@ai-sdk/perplexity" />

## 提供商实例

您可以从 `@ai-sdk/perplexity` 导入默认提供商实例 `perplexity`：

```ts
import { perplexity } from '@ai-sdk/perplexity';
```

对于自定义配置，您可以导入 `createPerplexity` 并使用您的设置创建提供商实例：

```ts
import { createPerplexity } from '@ai-sdk/perplexity';

const perplexity = createPerplexity({
  apiKey: process.env.PERPLEXITY_API_KEY ?? '',
});
```

您可以使用以下可选设置来自定义 Perplexity 提供商实例：

- **baseURL** _string_

  为 API 调用使用不同的 URL 前缀。
  默认前缀为 `https://api.perplexity.ai`。

- **apiKey** _string_

  通过 `Authorization` 标头发送的 API 密钥。默认为
  `PERPLEXITY_API_KEY` 环境变量。

- **headers** _Record&lt;string,string&gt;_

  要包含在请求中的自定义标头。

- **fetch** _(input: RequestInfo, init?: RequestInit) => Promise&lt;Response&gt;_

  自定义 [fetch](https://developer.mozilla.org/en-US/docs/Web/API/fetch) 实现。

## 语言模型

您可以使用提供商实例创建 Perplexity 模型：

```ts
import { perplexity } from '@ai-sdk/perplexity';
import { generateText } from 'ai';

const { text } = await generateText({
  model: perplexity('sonar-pro'),
  prompt: '量子计算有哪些最新进展？',
});
```

### 来源

用于生成响应的网站包含在结果的 `sources` 属性中：

```ts
import { perplexity } from '@ai-sdk/perplexity';
import { generateText } from 'ai';

const { text, sources } = await generateText({
  model: perplexity('sonar-pro'),
  prompt: '量子计算有哪些最新进展？',
});

console.log(sources);
```

### 提供商选项与元数据

Perplexity 提供商通过 `providerMetadata` 在响应中包含额外的元数据。
通过 `providerOptions` 可以使用额外的配置选项。

```ts
import {
  perplexity,
  type PerplexityLanguageModelOptions,
} from '@ai-sdk/perplexity';
import { generateText } from 'ai';

const result = await generateText({
  model: perplexity('sonar-pro'),
  prompt: '量子计算有哪些最新进展？',
  providerOptions: {
    perplexity: {
      return_images: true, // 启用图像响应（仅限 Perplexity Tier-2 用户）
      search_recency_filter: 'week', // 按时间过滤搜索结果
    } satisfies PerplexityLanguageModelOptions,
  },
});

console.log(result.providerMetadata);
// 示例输出：
// {
//   perplexity: {
//     usage: { citationTokens: 5286, numSearchQueries: 1 },
//     images: [
//       { imageUrl: "https://example.com/image1.jpg", originUrl: "https://elsewhere.com/page1", height: 1280, width: 720 },
//       { imageUrl: "https://example.com/image2.jpg", originUrl: "https://elsewhere.com/page2", height: 1280, width: 720 }
//     ]
//   },
// }
```

#### 提供商选项

以下提供商特定选项可用：

- **return_images** _boolean_

  启用图像响应。设置为 `true` 时，响应可能包含相关图像。此功能仅对 Perplexity Tier-2 及以上用户可用。

- **search_recency_filter** _string_

  按时间过滤搜索结果。可能的值：`'hour'`、`'day'`、`'week'`、`'month'`、`'year'`。如果未指定，默认为所有时间。

<Note>
  任何其他 [Perplexity API
  参数](https://docs.perplexity.ai/api-reference/chat-completions) 也可以通过 `providerOptions.perplexity` 传递。
</Note>

#### 提供商元数据

响应元数据包括：

- `usage`：包含 `citationTokens` 和 `numSearchQueries` 指标的对象
- `images`：当启用 `return_images` 时（仅限 Tier-2 用户），图像对象数组。每个图像包含 `imageUrl`、`originUrl`、`height` 和 `width`。

### PDF 支持

Perplexity 提供商支持读取 PDF 文件。
您可以使用 `file` 类型将 PDF 文件作为消息内容的一部分传递：

```ts
const result = await generateText({
  model: perplexity('sonar-pro'),
  messages: [
    {
      role: 'user',
      content: [
        {
          type: 'text',
          text: '这份文档是关于什么的？',
        },
        {
          type: 'file',
          data: fs.readFileSync('./data/ai.pdf'),
          mediaType: 'application/pdf',
          filename: 'ai.pdf', // 可选
        },
      ],
    },
  ],
});
```

您也可以传递 PDF 的 URL：

```ts
{
  type: 'file',
  data: new URL('https://example.com/document.pdf'),
  mediaType: 'application/pdf',
  filename: 'document.pdf', // 可选
}
```

模型将能够访问 PDF 文件的内容并回答相关问题。

</Note>

## 嵌入模型

您可以使用 `.embedding()` 工厂方法创建调用 [Perplexity 嵌入 API](https://docs.perplexity.ai/docs/embeddings/quickstart) 的模型。

```ts
import { perplexity } from '@ai-sdk/perplexity';
import { embed } from 'ai';

const { embedding } = await embed({
  model: perplexity.embedding('pplx-embed-v1-4b'),
  value: '阳光明媚的海滩日',
});
```

<Note>
  Perplexity 返回**量化**嵌入（非浮点数）。值会被解码为数字——有符号 `int8` 值（默认）或每字节的打包位。
  使用余弦相似度比较 `base64_int8` 嵌入，使用汉明距离比较 `base64_binary` 嵌入。
</Note>

当 API 返回成本明细时，它会通过 `providerMetadata.perplexity.cost`（`inputCost`、`totalCost`、`currency`）暴露：

```ts
const { embedding, providerMetadata } = await embed({
  model: perplexity.embedding('pplx-embed-v1-4b'),
  value: '阳光明媚的海滩日',
});

console.log(providerMetadata?.perplexity?.cost);
// { inputCost: 0.0001, totalCost: 0.0001, currency: 'USD' }
```

### 提供商选项

您可以通过 `providerOptions.perplexity` 字段传递提供商特定选项：

```ts
const { embedding } = await embed({
  model: perplexity.embedding('pplx-embed-v1-4b'),
  value: '阳光明媚的海滩日',
  providerOptions: {
    perplexity: {
      // 输出向量的 Matryoshka 截断（128 到模型大小）。
      dimensions: 512,
      // 量化编码格式。默认为 'base64_int8'。
      encodingFormat: 'base64_int8',
    },
  },
});
```

以下可选的提供商选项可用于嵌入模型：

- **dimensions** _number_

  生成的输出嵌入应具有的维度数。
  范围从 128 到模型的完整大小（`0.6b` 模型为 1024，`4b` 模型为 2560）。

- **encodingFormat** _'base64_int8' | 'base64_binary'_

  API 返回的量化编码格式。默认为 `base64_int8`。

### 嵌入模型能力

| 模型                   | 维度 | 每次调用最大值 |
| ---------------------- | ---------- | ------------------- |
| `pplx-embed-v1-0.6b`   | 1024       | 512                 |
| `pplx-embed-v1-4b`     | 2560       | 512                 |
