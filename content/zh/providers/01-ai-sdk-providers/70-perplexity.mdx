# Perplexity 提供商

[Perplexity](https://www.perplexity.ai) 提供商提供对
[Agent API](https://docs.perplexity.ai/docs/agent-api/quickstart) 的访问。Agent API
可以跨模型路由、搜索网页、调用工具并返回带引用的答案。
该提供商还支持嵌入以及用于分类、评分和布尔判断的实验性决策模型。

你可以通过 [AI Gateway](/providers/ai-sdk-providers/ai-gateway)（推荐）使用 Perplexity 模型，或使用 `@ai-sdk/perplexity` 直接连接。

```ts provider="perplexity" model="perplexity/sonar"
import { generateText } from 'ai';
__PROVIDER_IMPORT__;

const { text } = await generateText({
  model: __MODEL__,
  prompt: 'Write a vegetarian lasagna recipe for 4 people.',
});

console.log(text);
```

## 使用 AI Gateway

AI SDK 默认对模型字符串使用 AI Gateway。Gateway 通过单个 API 密钥提供跨提供商的模型访问，并支持用量和成本跟踪。安装 `ai`：

<InstallPackages packages="ai" />

在环境中设置 [AI Gateway API 密钥](https://vercel.com/docs/ai-gateway/getting-started)：

```bash
export AI_GATEWAY_API_KEY=your_api_key_here
```

Vercel 部署还可以使用 [OIDC 身份验证](/providers/ai-sdk-providers/ai-gateway#oidc-authentication-vercel-deployments)。
有关配置，请参阅 [AI Gateway 提供商文档](/providers/ai-sdk-providers/ai-gateway)；有关可用模型，请参阅[模型目录](https://vercel.com/ai-gateway/models)。

Gateway 的功能和提供商选项支持取决于模型以及处理请求的提供商。请参阅 [Gateway 提供商选项](https://vercel.com/docs/ai-gateway/models-and-providers/provider-options)。

## 使用 `@ai-sdk/perplexity`

要直接访问 Perplexity，请安装 `ai` 和 `@ai-sdk/perplexity`：

<InstallPackages packages="ai @ai-sdk/perplexity" />

在 `PERPLEXITY_API_KEY` 环境变量中设置你的 Perplexity API 凭据：

```bash
export PERPLEXITY_API_KEY=your_api_key_here
```

AI Gateway 提供 Sonar 模型。对于 Perplexity Agent API 预设、原生工具和模型路由，请使用直接提供商，下文将对此进行说明。

<Note>
  以下各节介绍直接使用 `@ai-sdk/perplexity` 提供商，包括其模型工厂和设置。Gateway 的模型和功能可用性可能有所不同。
</Note>

API 密钥可从 [Perplexity Platform](https://docs.perplexity.ai) 获取。

## 提供商实例

你可以从 `@ai-sdk/perplexity` 导入默认提供商实例 `perplexity`：

```ts
import { perplexity } from '@ai-sdk/perplexity';
```

如需自定义配置，可以导入 `createPerplexity` 并使用你的设置创建提供商实例：

```ts
import { createPerplexity } from '@ai-sdk/perplexity';

const perplexity = createPerplexity({
  apiKey: process.env.PERPLEXITY_API_KEY ?? '',
});
```

你可以使用以下可选设置来自定义 Perplexity 提供商实例：

- **baseURL** _string_

  为 API 调用使用不同的 URL 前缀。
  默认前缀为 `https://api.perplexity.ai`。

- **apiKey** _string_

  通过 `Authorization` 标头发送的 API 密钥。默认使用
  `PERPLEXITY_API_KEY` 环境变量。

- **headers** _Record&lt;string,string&gt;_

  要包含在请求中的自定义标头。

- **fetch** _(input: RequestInfo, init?: RequestInit) => Promise&lt;Response&gt;_

  自定义 [fetch](https://developer.mozilla.org/en-US/docs/Web/API/fetch) 实现。

## 语言模型

你可以使用提供商实例创建 Perplexity 模型：

```ts
import { perplexity } from '@ai-sdk/perplexity';
import { generateText } from 'ai';

const { text } = await generateText({
  model: perplexity('low'),
  prompt: 'What are the latest developments in quantum computing?',
});
```

Agent API 提供 `fast`、`low`、`medium`、`high` 和 `xhigh`
预设。要直接选择模型，请传入其 Agent API 模型 ID，例如
`perplexity('perplexity/sonar')`。

这些示例使用 `PERPLEXITY_API_KEY` 直接调用 Perplexity。将
诸如 `model: 'perplexity/sonar'` 的纯模型字符串传递给 `generateText` 或
`streamText` 会使用 [AI Gateway](/providers/ai-sdk-providers/ai-gateway)，
它有自己的模型目录和身份验证。

版本 5 仅使用 Agent API。旧版 Sonar 模型 ID 和提供商
选项不会被映射；升级前请参阅[从 v4 Sonar 迁移到 v5 Agent
API](#migrating-from-v4-sonar-to-v5-agent-api)。

### 来源

用于生成响应的网站包含在结果的 `sources` 属性中：

```ts
import { perplexity } from '@ai-sdk/perplexity';
import { generateText } from 'ai';

const { text, sources } = await generateText({
  model: perplexity('low'),
  prompt: 'What are the latest developments in quantum computing?',
});

console.log(sources);
```

### Agent 工具

通过 `providerOptions.perplexity.tools` 传入原生 Agent API 工具：

```ts
import {
  perplexity,
  type PerplexityLanguageModelOptions,
} from '@ai-sdk/perplexity';
import { generateText } from 'ai';

const { text, sources } = await generateText({
  model: perplexity('low'),
  prompt: 'Summarize recent US federal AI policy from official sources.',
  providerOptions: {
    perplexity: {
      tools: [
        {
          type: 'web_search',
          filters: {
            search_domain_filter: [
              'whitehouse.gov',
              'congress.gov',
              'federalregister.gov',
            ],
            search_recency_filter: 'month',
          },
          max_results: 10,
          search_context_size: 'medium',
        },
      ],
    } satisfies PerplexityLanguageModelOptions,
  },
});
```

支持的原生工具包括 `web_search`、`fetch_url`、`people_search`、
`finance_search`、`sandbox`、`mcp` 和 `connector`。Agent API 预设包含
保持启用的预配置工具；`tools` 选项可以添加显式
工具，或在使用直接模型 ID 时提供工具。

搜索和获取结果会作为 AI SDK 来源公开。其他原生工具跟踪，
包括金融、沙盒和 MCP 结果，可在 `response.body`
和原始流块（`include: { rawChunks: true }`）中获取。它们不会作为
AI SDK 客户端工具调用公开。零数据保留的账户可能会拒绝
支持文件的工具，例如 `finance_search` 和 `sandbox`。

AI SDK 函数工具可以通过顶层 `tools` 选项传入：

```ts
import { perplexity } from '@ai-sdk/perplexity';
import { generateText, tool } from 'ai';
import { z } from 'zod';

const result = await generateText({
  model: perplexity('low'),
  prompt: 'What is the weather in San Francisco?',
  tools: {
    weather: tool({
      description: 'Get the weather for a city',
      inputSchema: z.object({ city: z.string() }),
      execute: async ({ city }) => ({ city, temperature: 18 }),
    }),
  },
});
```

### 提供商选项和元数据

Perplexity 提供商通过 `providerMetadata` 在响应中包含额外元数据。
其他配置选项可通过 `providerOptions` 使用。

```ts
import {
  perplexity,
  type PerplexityLanguageModelOptions,
} from '@ai-sdk/perplexity';
import { generateText } from 'ai';

const result = await generateText({
  model: perplexity('low'),
  prompt: 'What are the latest developments in quantum computing?',
  providerOptions: {
    perplexity: {
      max_steps: 5,
      store: true,
      reasoning: { effort: 'low' },
    } satisfies PerplexityLanguageModelOptions,
  },
});

console.log(result.providerMetadata);
// Example output:
// {
//   perplexity: {
//     usage: { citationTokens: null, numSearchQueries: 1 },
//     images: null,
//     cost: { totalCost: 0.006, currency: 'USD', ... },
//     toolCalls: { search_web: { invocation: 1 } },
//   },
// }
```

#### 提供商选项

以下 Agent API 选项可用：

- **instructions** _string_

  Agent API 运行的顶层指令。

- **tools** _array_

  原生 Agent API 工具及其配置。

- **models** _string[]_

  用于 Agent API 路由的备用模型列表。

- **max_steps** _number_

  智能体步骤的最大数量。

- **max_tool_calls** _number_

  原生工具调用的最大数量。将其设置为 `0` 会禁用所有
  预设工具。

- **previous_response_id** _string_

  从先前的 Agent API 响应继续对话。

- **store** _boolean_

  响应是否可以在之后检索。设置 `store: false` 会将其从检索中隐藏；
  它不会禁用持久化，响应仍可用作 `previous_response_id` 继续来源。有关保留行为和账户特定的零数据保留限制，请参阅 Perplexity 的
  [对话状态文档](https://docs.perplexity.ai/docs/agent-api/conversation-state)。

- **language_preference** _string_

  首选响应语言，使用 ISO 639-1 语言代码。

- **reasoning** _object_

  推理配置。`effort` 支持 `'minimal'`、`'low'`、`'medium'`、
  `'high'` 和 `'xhigh'`。

- **skills** _array_

  Agent API 技能配置。

<Note>
  有关原生请求字段的详细信息，请参阅 [Perplexity Agent API
  文档](https://docs.perplexity.ai/docs/agent-api/quickstart)。
</Note>

#### 提供商元数据

响应元数据包括：

- `usage`：`citationTokens`（对于 Agent API 响应始终为 `null`）以及
  搜索查询数量
- `cost`：Perplexity 返回的 token、工具和总成本
- `toolCalls`：按原生工具分组的调用次数
- `images`：始终为 `null`；Agent API 不返回 Sonar 图像结果

### 结构化输出

`Output.object` 和 `Output.array` 发送 Agent API JSON schema 响应
格式。不支持没有 schema 的 JSON 输出。

### 输入图像

图像 URL 和数据输入会转换为 Agent API `input_image` 部分。
Agent API 不提供与 Sonar 等效的 PDF 输入字段，因此不支持 PDF 文件
部分。

### 从 v4 Sonar 迁移到 v5 Agent API

<Note>
  版本 5 是从 Sonar Chat Completions 到 Agent
  API 的破坏性迁移。它不提供旧版模型别名、不转换 Sonar 提供商
  选项，也不会在运行时发出迁移警告。
</Note>

<Note type="warning">
  Perplexity 仅在 2026 年 9 月 27 日之前支持 Sonar Chat Completions。
  请在该日期之前将语言生成应用升级到 Agent API；
  继续使用版本 4 无法在 Sonar 关停后保留服务。
</Note>

将每个 Sonar 模型 ID 替换为 Agent API 预设或直接 Agent API 模型
ID。这些预设是建议的起点，并非等效别名：预设可能选择不同的模型和工具，因此成本、延迟和输出可能
发生变化。

| v4 Sonar 模型        | 建议的 v5 起点 |
| -------------------- | --------------------------- |
| `sonar`               | `fast`                      |
| `sonar-pro`           | `low`                       |
| `sonar-reasoning`     | `medium`                    |
| `sonar-reasoning-pro` | `medium`                    |
| `sonar-deep-research` | `high`                      |

例如：

```ts
// v4
perplexity('sonar-pro');

// v5
perplexity('low');
```

将 Sonar 搜索和推理选项移动到其 Agent API 位置：

| v4 提供商选项                       | v5 Agent API 选项                    |
| ---------------------------------------- | -------------------------------------- |
| 域、时效性和日期过滤器        | `web_search` 上的 `tools[].filters`      |
| `num_search_results`                     | `tools[].max_results`                  |
| `web_search_options.search_context_size` | `tools[].search_context_size`          |
| `web_search_options.user_location`       | `tools[].user_location`                |
| `reasoning_effort`                       | `reasoning.effort`                     |
| `disable_search`                         | 对于直接模型 ID，省略 `web_search` |

预设工具无法单独移除。当必须禁用搜索时，使用不带
`web_search` 工具的直接模型 ID，或设置 `max_tool_calls: 0` 以
禁用所有预设工具调用。

Agent API 没有与 Sonar PDF 或视频输入、图像或视频
结果、`search_language_filter` 或 `stream_mode` 等效的功能。相关问题需要
提示词或结构化输出。迁移期间请移除这些选项。

语言请求现在使用 `/v1/agent`。自定义 `baseURL` 代理必须路由该
路径。原始响应和流使用 Agent API 的类型化输出和 SSE 事件
格式，Perplexity 提供商元数据、用量、成本和来源标识符
可能有所不同。嵌入 API 保持不变。

对于 PDF 输入，请在发送到 Agent API 之前提取文档文本，
或选择另一个支持 PDF 输入的提供商。如果你的应用需要
图像/视频检索和语言过滤搜索，请将其移至单独的服务。为类型化 Agent
事件重写原始 Sonar 流事件的消费者。有关完整的 API 级比较，请参阅 Perplexity 的[迁移
指南](https://docs.perplexity.ai/docs/agent-api/migrate-from-sonar/how-to)。

## 嵌入模型

你可以使用 `.embedding()` 工厂方法创建调用 [Perplexity 嵌入 API](https://docs.perplexity.ai/docs/embeddings/quickstart)
的模型。

```ts
import { perplexity } from '@ai-sdk/perplexity';
import { embed } from 'ai';

const { embedding } = await embed({
  model: perplexity.embedding('pplx-embed-v1-4b'),
  value: 'sunny day at the beach',
});
```

<Note>
  Perplexity 返回**量化**嵌入（而非浮点数）。值会被
  解码为数字——有符号 `int8` 值（默认）或每字节打包位。
  使用余弦相似度比较 `base64_int8` 嵌入，使用汉明距离比较 `base64_binary`
  嵌入。
</Note>

当 API 返回成本明细时，会通过
`providerMetadata.perplexity.cost`（`inputCost`、`totalCost`、`currency`）公开：

```ts
const { embedding, providerMetadata } = await embed({
  model: perplexity.embedding('pplx-embed-v1-4b'),
  value: 'sunny day at the beach',
});

console.log(providerMetadata?.perplexity?.cost);
// { inputCost: 0.0001, totalCost: 0.0001, currency: 'USD' }
```

### 提供商选项

你可以通过 `providerOptions.perplexity` 字段传递提供商特定选项：

```ts
const { embedding } = await embed({
  model: perplexity.embedding('pplx-embed-v1-4b'),
  value: 'sunny day at the beach',
  providerOptions: {
    perplexity: {
      // Matryoshka truncation of the output vector (128 up to the model size).
      dimensions: 512,
      // Quantized encoding format. Defaults to 'base64_int8'.
      encodingFormat: 'base64_int8',
    },
  },
});
```

以下可选提供商选项可用于嵌入模型：

- **dimensions** _number_

  生成的输出嵌入应具有的维度数。
  范围为 128 到模型的完整大小（`0.6b` 模型为 1024，`4b` 模型为 2560）。

- **encodingFormat** _'base64_int8' | 'base64_binary'_

  API 返回的量化编码格式。默认为 `base64_int8`。

### 嵌入模型能力

| 模型                | 维度 | 每次调用最大值 |
| -------------------- | ---------- | ------------------- |
| `pplx-embed-v1-0.6b` | 1024       | 512                 |
| `pplx-embed-v1-4b`   | 2560       | 512                 |

## 决策模型

将 `perplexity.decisionModel()` 与
[`experimental_decide`](/docs/reference/ai-sdk-core/decide) 一起使用，以调用
[Perplexity Decisions API](https://docs.perplexity.ai/docs/decisions/quickstart)。
此 API 为实验性，可能会在补丁版本中更改。

```ts
import { perplexity } from '@ai-sdk/perplexity';
import { experimental_decide as decide } from 'ai';

const result = await decide({
  model: perplexity.decisionModel('pplx-decider-latest'),
  state: { review: 'Great sound, but the battery stopped charging.' },
  questions: {
    defect: {
      type: 'boolean',
      instructions: 'Does the review report a product defect?',
    },
    sentiment: {
      type: 'choice',
      instructions: 'What is the overall sentiment?',
      criteria: {
        positive: 'Mostly satisfied',
        mixed: 'Praise and complaints',
        negative: 'Mostly dissatisfied',
      },
    },
    severity: {
      type: 'score',
      instructions: 'How severe is the problem?',
      criteria: ['Cosmetic', 'Inconvenient', 'Product unusable'],
    },
  },
});

result.answers.defect.probability; // P(true), from 0 to 1
result.answers.sentiment.choice; // 'positive' | 'mixed' | 'negative'
result.answers.sentiment.probabilities;
result.answers.severity.score; // Expected zero-based level, from 0 to 2
result.answers.severity.probabilities;
```

该提供商将 SDK 的 `boolean` 问题映射到 Perplexity 原生的 `noul` 类型，
并将返回的 `noul` 值映射到 `probability`。Choice 和 Score 答案
包含 API 的概率分布，不进行舍入或归一化。
不支持 Box 问题。

### 图像和结构化状态

使用有序的文本、JSON 和文件部分将图像与其他证据组合。
支持 PNG、JPEG 和 WebP 图像，共享状态中最多八张图像。
Core 会在提供商将图像字节转换为 base64 数据 URL 之前下载文件 URL：

```ts
const result = await decide({
  model: perplexity.decisionModel('pplx-decider-latest'),
  state: [
    { type: 'text', text: 'Inspect the product for damage.' },
    { type: 'json', value: { product: 'glass vase' } },
    {
      type: 'file',
      mediaType: 'image/png',
      data: new URL('https://example.com/product.png'),
    },
  ],
  questions: {
    damaged: { type: 'boolean', instructions: 'Is the vase damaged?' },
  },
});
```

你还可以使用 Perplexity 的原生图像形状在 JSON 对象中保留图像的位置。
此类图像必须已包含 base64 数据 URL；SDK
不会下载嵌入在 JSON 中的 URL。给定 `imageBase64` 中的 base64 编码 PNG：

```ts
const state = {
  product: 'glass vase',
  evidence: {
    photo: {
      type: 'image_url',
      image_url: { url: `data:image/png;base64,${imageBase64}` },
    },
  },
};
```

将此对象作为 `state` 传递给 `decide`。要改为发送 JSON 数组，请在状态部分数组中将其包装为
`{ type: 'json', value: records }`。直接作为 `state` 传递的数组
会被解释为 SDK 部分。

### 置信度、图例和响应元数据

Perplexity 单独的置信度值和 Score 图例可在
`providerMetadata.perplexity` 中按问题 ID 获取。置信度不同于
所选选项的概率。图例保留原始评分标准条目，
包括结构化描述。

使用第一个示例的结果：

```ts
const metadata = result.providerMetadata?.perplexity;
console.log(metadata?.confidence); // Choice and Score confidence by question ID
console.log(metadata?.legend); // Score index-to-description maps by question ID
console.log(result.usage.inputTokens);
console.log(result.usage.outputTokens);
console.log(result.response.id); // x-request-id, when returned
console.log(result.response.modelId); // Model returned by the API
```

### 决策限制和选项

提供商在发送决策请求之前验证这些限制：

| 输入                  | 限制                         |
| ---------------------- | ----------------------------- |
| 问题              | 1–128，名称非空    |
| Choice 选项         | 1–255                         |
| Score 级别           | 1–10，全部非空            |
| 共享状态中的图像 | 最多 8 张；PNG、JPEG 或 WebP |

有关 API 强制执行的正文、token 和图像大小限制，请参阅 Perplexity 的[请求限制](https://docs.perplexity.ai/docs/decisions/quickstart#request-limits)。
SDK 不会调整图像大小。

决策模型没有 Perplexity 特定的提供商选项。在
`providerOptions.perplexity` 中传入的条目会产生不支持的选项警告，并且不会发送
到 API。使用 `decide` 上的标准 `abortSignal`、`headers` 和 `maxRetries` 选项
进行取消、请求标头和重试。
