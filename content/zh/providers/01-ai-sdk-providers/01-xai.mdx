# xAI Grok 提供商

[xAI Grok](https://x.ai) 提供商包含对 [xAI API](https://x.ai/api) 的语言模型支持。

## 安装

xAI Grok 提供商可通过 `@ai-sdk/xai` 模块获得。您可以使用以下命令安装它：

<InstallPackages packages="@ai-sdk/xai" />

## 提供商实例

您可以从 `@ai-sdk/xai` 导入默认提供商实例 `xai`：

```ts
import { xai } from '@ai-sdk/xai';
```

如果您需要自定义设置，可以从 `@ai-sdk/xai` 导入 `createXai` 并使用您的设置创建提供商实例：

```ts
import { createXai } from '@ai-sdk/xai';

const xai = createXai({
  apiKey: 'your-api-key',
});
```

您可以使用以下可选设置来自定义 xAI 提供商实例：

- **baseURL** _string_

  为 API 调用使用不同的 URL 前缀，例如使用代理服务器。默认前缀为 `https://api.x.ai/v1`。

- **apiKey** _string_

  通过 `Authorization` 标头发送的 API 密钥。默认为 `XAI_API_KEY` 环境变量。

- **headers** _Record&lt;string,string&gt;_

  要包含在请求中的自定义标头。

- **fetch** _(input: RequestInfo, init?: RequestInit) => Promise&lt;Response&gt;_

  自定义 [fetch](https://developer.mozilla.org/en-US/docs/Web/API/fetch) 实现。默认为全局 `fetch` 函数。您可以将其用作中间件来拦截请求，或提供自定义的 fetch 实现，例如用于测试。

## 语言模型

您可以使用提供商实例创建 [xAI 模型](https://console.x.ai)。第一个参数是模型 ID，例如 `grok-4.20-non-reasoning`。

```ts
const model = xai('grok-4.20-non-reasoning');
```

<Note>
  自 AI SDK 7 起，`xai(modelId)` 默认使用 xAI Responses API。要使用
  [Chat Completions
  API](https://docs.x.ai/docs/api-reference#chat-completions)（旧版），请使用
  `xai.chat(modelId)`。
</Note>

### 示例

您可以使用 xAI 语言模型通过 `generateText` 函数生成文本：

```ts
import { xai } from '@ai-sdk/xai';
import { generateText } from 'ai';

const { text } = await generateText({
  model: xai('grok-4.20-non-reasoning'),
  prompt: 'Write a vegetarian lasagna recipe for 4 people.',
});
```

xAI 语言模型也可以在 `streamText` 函数中使用，并支持通过 [`Output`](/docs/reference/ai-sdk-core/output) 进行结构化数据生成（参见 [AI SDK Core](/docs/ai-sdk-core)）。

### 推理努力

对于具有可配置推理能力的模型，您可以通过 `providerOptions.xai.reasoningEffort` 控制模型在响应前花费多少思考精力。这适用于 Responses API（默认）和 Chat Completions API（`xai.chat()`）。

```ts
import { xai } from '@ai-sdk/xai';
import { generateText } from 'ai';

const { text } = await generateText({
  model: xai('grok-4.3'),
  prompt: 'Explain quantum entanglement.',
  providerOptions: {
    xai: { reasoningEffort: 'medium' },
  },
});
```

AI SDK 选项接受以下值，但每个 xAI 模型支持其中一部分：

- `'none'` — 完全禁用推理；不使用思考令牌。最适合需要近乎即时响应的简单用例。
- `'low'` — 使用少量推理令牌，但仍然很快。适合一般的智能体使用和工具调用。
- `'medium'` — 为对延迟不太敏感的应用程序（如复杂数据分析和长上下文推理）提供更多思考。
- `'high'` — 使用更多推理令牌进行更深入的思考。适合非常具有挑战性的问题、复杂数学、多步逻辑和竞赛级任务。

<Note>
  支持和默认值因模型而异。`grok-4.3` 支持 `'none'`、
  `'low'`、`'medium'` 和 `'high'`。`grok-4.5` 支持 `'low'`、`'medium'`
  和 `'high'`，默认为 `'high'`，且无法禁用推理。
  `grok-4.20-reasoning` 和 `grok-4.20-non-reasoning` 变体不接受
  此选项。对于 `grok-4.20-multi-agent`，`'low'`、`'medium'` 和 `'high'`
  控制智能体数量而非推理深度。请参阅 xAI 的 [推理
  文档](https://docs.x.ai/developers/model-capabilities/text/reasoning) 和
  [Grok 4.3 模型页面](https://docs.x.ai/developers/models/grok-4.3) 了解
  当前详细信息。
</Note>

## 实时模型

<Note type="warning">实时功能为实验性功能。</Note>

您可以使用 `.experimental_realtime()` 工厂方法创建调用 [xAI Realtime API](https://docs.x.ai/docs/guides/realtime) 的模型。

```ts
import { xai } from '@ai-sdk/xai';

const model = xai.experimental_realtime('grok-voice-latest');
```

实时会话在浏览器中运行，需要您在服务器上使用 `xai.experimental_realtime.getToken()` 创建的短期令牌：

```ts
const token = await xai.experimental_realtime.getToken({
  model: 'grok-voice-latest',
});
```

请参阅 [Realtime](/docs/ai-sdk-core/realtime) 了解完整的设置和工具调用模式。

## Responses API（智能体工具）

xAI Responses API 是使用 `xai(modelId)` 时的默认 API（自 AI SDK 7 起）。您也可以显式使用 `xai.responses(modelId)`。这使模型能够在 xAI 服务器上自主编排工具调用和研究。

```ts
const model = xai.responses('grok-4.20-non-reasoning');
```

Responses API 提供模型在推理过程中可以自主执行的服务器端工具：

- **web_search**：实时网络搜索和页面浏览
- **x_search**：搜索 X（Twitter）帖子、用户和话题
- **code_execution**：执行 Python 代码进行计算和数据分析
- **view_image**：查看和分析图像
- **view_x_video**：查看和分析 X 帖子中的视频
- **mcp_server**：连接到远程 MCP 服务器并使用其工具
- **file_search**：在向量存储（集合）中搜索文档

### 视觉

Responses API 支持视觉模型的图像输入：

```ts
import { xai } from '@ai-sdk/xai';
import { generateText } from 'ai';

const { text } = await generateText({
  model: xai.responses('grok-3'),
  messages: [
    {
      role: 'user',
      content: [
        { type: 'text', text: 'What do you see in this image?' },
        {
          type: 'file',
          mediaType: 'image',
          data: fs.readFileSync('./image.png'),
        },
      ],
    },
  ],
});
```

您可以通过图像部分上的 `imageDetail` 提供商选项控制模型处理图像的分辨率：

```ts
import { xai } from '@ai-sdk/xai';
import { generateText } from 'ai';

const { text } = await generateText({
  model: xai('grok-4.3'),
  messages: [
    {
      role: 'user',
      content: [
        { type: 'text', text: 'What do you see in this image?' },
        {
          type: 'file',
          mediaType: 'image/png',
          data: fs.readFileSync('./image.png'),
          providerOptions: {
            xai: { imageDetail: 'low' },
          },
        },
      ],
    },
  ],
});
```

支持以下图像细节值：

- **low**：以降低的分辨率处理图像，消耗更少的输入令牌。
- **high**：以全分辨率处理图像。
- **auto**：让 xAI API 决定。

未设置时，图像将以全分辨率处理。

### 网络搜索工具

网络搜索工具支持自主网络研究，可选的域名过滤和图像理解：

```ts
import { xai } from '@ai-sdk/xai';
import { generateText } from 'ai';

const { text, sources } = await generateText({
  model: xai.responses('grok-4.20-non-reasoning'),
  prompt: 'What are the latest developments in AI?',
  tools: {
    web_search: xai.tools.webSearch({
      allowedDomains: ['arxiv.org', 'openai.com'],
      enableImageUnderstanding: true,
    }),
  },
});

console.log(text);
console.log('Citations:', sources);
```

#### 网络搜索参数

- **allowedDomains** _string[]_

  仅在指定域名内搜索（最多 5 个）。不能与 `excludedDomains` 同时使用。

- **excludedDomains** _string[]_

  从搜索中排除指定域名（最多 5 个）。不能与 `allowedDomains` 同时使用。

- **enableImageSearch** _boolean_

  允许模型在图像对答案有用时，以独立的网络搜索模式执行图像搜索。模型可以在常规网络搜索和图像搜索之间选择；相关时响应可以包含 Markdown 图像嵌入。

- **enableImageUnderstanding** _boolean_

  启用模型查看和分析搜索过程中发现的图像。会增加令牌使用量。要允许显式搜索图像，请使用 `enableImageSearch`。

### X 搜索工具

X 搜索工具支持搜索 X（Twitter）上的帖子，可按账号和日期范围过滤：

```ts
const { text, sources } = await generateText({
  model: xai.responses('grok-4.20-non-reasoning'),
  prompt: 'What are people saying about AI on X this week?',
  tools: {
    x_search: xai.tools.xSearch({
      allowedXHandles: ['elonmusk', 'xai'],
      fromDate: '2025-10-23',
      toDate: '2025-10-30',
      enableImageUnderstanding: true,
      enableVideoUnderstanding: true,
    }),
  },
});
```

#### X 搜索参数

- **allowedXHandles** _string[]_

  仅搜索指定 X 账号的帖子（最多 10 个）。不能与 `excludedXHandles` 同时使用。

- **excludedXHandles** _string[]_

  排除指定 X 账号的帖子（最多 10 个）。不能与 `allowedXHandles` 同时使用。

- **fromDate** _string_

  帖子的开始日期，ISO8601 格式（`YYYY-MM-DD`）。

- **toDate** _string_

  帖子的结束日期，ISO8601 格式（`YYYY-MM-DD`）。

- **enableImageUnderstanding** _boolean_

  启用模型查看和分析 X 帖子中的图像。

- **enableVideoUnderstanding** _boolean_

  启用模型查看和分析 X 帖子中的视频。

### 图像生成工具

图像生成工具让模型在对话中使用 Grok Imagine 创建和编辑图像。模型决定何时调用工具，编写图像提示词，并在文本响应旁边返回完成的图像：

```ts
import { xai } from '@ai-sdk/xai';
import { generateText } from 'ai';

const result = await generateText({
  model: xai.responses('grok-4.5'),
  prompt:
    'Generate an image of a corgi surfing a big wave, in the style of a Japanese woodblock print',
  tools: {
    image_generation: xai.tools.imageGeneration(),
  },
});

for (const toolResult of result.staticToolResults) {
  if (toolResult.toolName === 'image_generation') {
    const base64Image = toolResult.output.result;
  }
}
```

工具结果还包含模型为图像模型编写的提示词，这对于理解和调试生成的内容很有用。

#### 图像生成参数

- **action** _'auto' | 'generate' | 'edit'_

  限制工具可以执行的操作。默认为 `'auto'`。
  - `'auto'`：模型可以生成和编辑图像。
  - `'generate'`：仅文本到图像生成。
  - `'edit'`：仅图像编辑（编辑对话中已有的图像，包括模型之前生成的图像）。

<Note>
  该工具不接受尺寸或格式参数；模型会为每次调用选择宽高比。
  要控制它，请在提示词中说明（例如“以 9:16 垂直宽高比”）。
</Note>

### MCP 服务器工具

MCP 服务器工具使模型能够连接到远程 [Model Context Protocol (MCP)](https://modelcontextprotocol.io/) 服务器并使用其工具：

```ts
const { text } = await generateText({
  model: xai.responses('grok-4.20-non-reasoning'),
  prompt: 'Use the weather tool to check conditions in San Francisco',
  tools: {
    weather_server: xai.tools.mcpServer({
      serverUrl: 'https://example.com/mcp',
      serverLabel: 'weather-service',
      serverDescription: 'Weather data provider',
      allowedTools: ['get_weather', 'get_forecast'],
    }),
  },
});
```

#### MCP 服务器参数

- **serverUrl** _string_（必填）

  远程 MCP 服务器的 URL。

- **serverLabel** _string_

  用于标识 MCP 服务器的标签。

- **serverDescription** _string_

  对 MCP 服务器提供的功能的描述。

- **allowedTools** _string[]_

  允许模型从 MCP 服务器使用的工具名称列表。如果未指定，则允许使用所有工具。

- **headers** _Record&lt;string, string&gt;_

  连接到 MCP 服务器时要包含的自定义标头。

- **authorization** _string_

  用于向 MCP 服务器进行身份验证的 Authorization 标头值（例如 `'Bearer token123'`）。

### 文件搜索工具

文件搜索工具支持搜索存储在 xAI 向量存储（集合）中的文档：

```ts
import { xai, type XaiLanguageModelResponsesOptions } from '@ai-sdk/xai';
import { streamText } from 'ai';

const result = streamText({
  model: xai.responses('grok-4.20-reasoning'),
  prompt: 'What documents do you have access to?',
  tools: {
    file_search: xai.tools.fileSearch({
      vectorStoreIds: ['collection_your-collection-id'],
      maxNumResults: 10,
    }),
  },
  providerOptions: {
    xai: {
      include: ['file_search_call.results'],
    } satisfies XaiLanguageModelResponsesOptions,
  },
});
```

#### 文件搜索参数

- **vectorStoreIds** _string[]_（必填）

  要搜索的向量存储（集合）的 ID。

- **maxNumResults** _number_

  搜索返回的最大结果数。

#### 文件搜索的提供商选项

- **include** _Array&lt;'file_search_call.results'&gt;_

  在响应中包含文件搜索结果。设置为 `['file_search_call.results']` 时，响应将包含带有文件内容和分数的实际搜索结果。

<Note>
  文件搜索需要 grok-4 系列模型（包括 grok-4.20）和
  Responses API。可以使用 [xAI
  API](https://docs.x.ai/docs/guides/using-collections/api) 创建向量存储。
</Note>

### 多个工具

您可以组合多个服务器端工具进行全面的研究：

```ts
import { xai } from '@ai-sdk/xai';
import { streamText } from 'ai';

const { stream } = streamText({
  model: xai.responses('grok-4.20-non-reasoning'),
  prompt: 'Research AI safety developments and calculate risk metrics',
  tools: {
    web_search: xai.tools.webSearch(),
    x_search: xai.tools.xSearch(),
    code_execution: xai.tools.codeExecution(),
    file_search: xai.tools.fileSearch({
      vectorStoreIds: ['collection_your-documents'],
    }),
    data_service: xai.tools.mcpServer({
      serverUrl: 'https://data.example.com/mcp',
      serverLabel: 'data-service',
    }),
  },
});

for await (const part of stream) {
  if (part.type === 'text-delta') {
    process.stdout.write(part.text);
  } else if (part.type === 'source' && part.sourceType === 'url') {
    console.log('\nSource:', part.url);
  }
}
```

### 提供商选项

Responses API 支持以下提供商选项：

```ts
import { xai, type XaiLanguageModelResponsesOptions } from '@ai-sdk/xai';
import { generateText } from 'ai';

const result = await generateText({
  model: xai.responses('grok-4.5'),
  providerOptions: {
    xai: {
      reasoningEffort: 'high',
    } satisfies XaiLanguageModelResponsesOptions,
  },
  // ...
});
```

以下提供商选项可用：

- **reasoningEffort** _'none' | 'low' | 'medium' | 'high'_

  控制受支持模型的推理努力。请参阅 [推理努力](#推理努力) 了解模型特定的值和默认值。

- **logprobs** _boolean_

  返回输出令牌的对数概率。

- **topLogprobs** _number_

  每个令牌位置返回的最可能令牌数（0-8）。设置后，`logprobs` 会自动启用。

- **include** _Array&lt;'file_search_call.results'&gt;_

  指定要包含在模型响应中的额外输出数据。使用 `['file_search_call.results']` 包含带有分数和内容的文件搜索结果。

- **store** _boolean_

  是否存储输入消息和模型响应以供后续检索。默认为 `true`。

- **previousResponseId** _string_

  模型先前响应的 ID。您可以使用它来继续对话。

<Note>
  Responses API 仅支持服务器端工具。您不能在同一个请求中混合使用
  服务器端工具和客户端函数工具。
</Note>

## 语音模型

您可以使用 `.speech()` 工厂方法创建调用 [xAI 文本转语音 API](https://docs.x.ai/developers/model-capabilities/audio/text-to-speech) 的模型。xAI 的文本转语音端点不需要模型标识符。

```ts
const model = xai.speech();
```

使用 `generateSpeech` 函数使用 xAI 语音模型：

```ts
import { xai } from '@ai-sdk/xai';
import { generateSpeech } from 'ai';

const result = await generateSpeech({
  model: xai.speech(),
  text: 'Hello from the AI SDK!',
  voice: 'ara',
  language: 'en',
  outputFormat: 'mp3',
  speed: 1.1,
});
```

### 支持的参数

- **text** _string_（必填）

  要合成的文本。您可以在文本中直接包含 xAI 语音标签，例如 `[pause]`、
  `[laugh]` 或 `<whisper>...</whisper>`。

- **voice** _string_

  xAI 语音 ID。默认为 `'eve'`。内置语音 ID 为 `'eve'`、
  `'ara'`、`'rex'`、`'sal'` 和 `'leo'`；也接受自定义语音 ID。

- **language** _string_

  BCP-47 语言代码或 `'auto'` 用于自动检测。省略时默认为
  `'auto'`。

- **speed** _number_

  语速倍率，范围从 `0.7` 到 `1.5`。

- **outputFormat** _string_

  要生成的音频编解码器。支持的值有 `'mp3'`、`'wav'`、`'pcm'`、
  `'mulaw'` 和 `'alaw'`。默认为 `'mp3'`。

<Note>
  xAI 不提供单独的 `instructions` 字段用于文本转语音。使用
  `text` 中的语音标签来控制表达方式。
</Note>

### 提供商选项

您可以使用 `providerOptions.xai` 传递 xAI 特定的控制参数：

```ts
import { xai, type XaiSpeechModelOptions } from '@ai-sdk/xai';
import { generateSpeech } from 'ai';

const result = await generateSpeech({
  model: xai.speech(),
  text: 'A high fidelity narration sample.',
  outputFormat: 'mp3',
  providerOptions: {
    xai: {
      sampleRate: 44100,
      bitRate: 192000,
      optimizeStreamingLatency: 1,
      textNormalization: true,
    } satisfies XaiSpeechModelOptions,
  },
});
```

- **sampleRate** _8000 | 16000 | 22050 | 24000 | 44100 | 48000_

  输出音频的采样率（Hz）。

- **bitRate** _32000 | 64000 | 96000 | 128000 | 192000_

  MP3 比特率（每秒位数）。仅当 `outputFormat` 为
  `'mp3'` 时适用。

- **optimizeStreamingLatency** _0 | 1 | 2_

  延迟优化级别。较高的值会减少首次音频的时间，但在块边界处会有质量权衡。

- **textNormalization** _boolean_

  是否在合成语音之前对书面形式的输入文本进行规范化。

### 模型能力

| 模型      | 语言  | 速度     | 输出格式                     |
| --------- | --------- | --------- | -------------------------- |
| `default` | <Check /> | <Check /> | mp3, wav, pcm, mulaw, alaw |

## 转录模型

您可以使用 `.transcription()` 工厂方法创建调用 [xAI 语音转文本 API](https://docs.x.ai/developers/model-capabilities/audio/speech-to-text) 的模型。xAI 的批量转录端点不需要模型标识符。

```ts
const model = xai.transcription();
```

使用 `transcribe` 函数使用 xAI 转录模型：

```ts
import { xai } from '@ai-sdk/xai';
import { transcribe } from 'ai';
import { readFile } from 'fs/promises';

const result = await transcribe({
  model: xai.transcription(),
  audio: await readFile('meeting.mp3'),
});
```

### 提供商选项

您可以使用 `providerOptions.xai` 传递 xAI 特定的控制参数：

```ts
import { xai, type XaiTranscriptionModelOptions } from '@ai-sdk/xai';
import { transcribe } from 'ai';
import { readFile } from 'fs/promises';

const result = await transcribe({
  model: xai.transcription(),
  audio: await readFile('meeting.mp3'),
  providerOptions: {
    xai: {
      language: 'en',
      format: true,
      keyterm: ['AI SDK', 'Grok'],
      diarize: true,
    } satisfies XaiTranscriptionModelOptions,
  },
});
```

- **audioFormat** _`pcm` | `mulaw` | `alaw`_

  原始无头输入音频的音频编码。

- **sampleRate** _8000 | 16000 | 22050 | 24000 | 44100 | 48000_

  输入音频的采样率（Hz）。

- **language** _string_

  用于反向文本规范化的语言代码。

- **format** _boolean_

  启用反向文本规范化。需要 `language`。

- **multichannel** _boolean_

  为交错多声道音频启用逐声道转录。

- **channels** _2 | 3 | 4 | 5 | 6 | 7 | 8_

  交错音频声道数。

- **diarize** _boolean_

  启用说话人分离。

- **keyterm** _string | string[]_

  一个或多个用于偏向转录的术语。

- **fillerWords** _boolean_

  在转录中包含填充词，例如 `uh` 和 `um`。

- **streaming** _object_

  通过 WebSocket 进行流式语音转文本的选项。与 `experimental_streamTranscribe` 一起使用。
  - **interimResults** _boolean_

    在处理语音时发出部分转录。

  - **endpointing** _number_

    话语结束事件之前的静音持续时间（毫秒）。范围：0-5000。

  - **smartTurn** _number_

    话轮结束检测阈值。设置后，启用 Smart Turn。范围：0.0-1.0。

  - **smartTurnTimeout** _number_

    强制 `speech_final` 之前的最大静音持续时间（毫秒）。范围：1-5000。

### 模型能力

| 模型      | 请求/响应 | 流式传输 | 单词时间戳 | 说话人分离 | 多声道 |
| --------- | ---------------- | --------- | --------------- | ----------- | ------------ |
| `default` | <Check />        | <Check /> | <Check />       | <Check />   | <Check />    |

<Note>
  单词时间戳、说话人分离结果和分段仅在
  请求/响应路径（`transcribe`）上返回。流式转录
  （`experimental_streamTranscribe`）会发出部分和最终的转录文本以及
  话语级时间信息，但不会提供逐词时间戳、说话人
  标签或分段。
</Note>

## 图像模型

您可以使用 `.image()` 工厂方法创建 xAI 图像模型。有关使用 AI SDK 进行图像生成的更多信息，请参阅 [generateImage()](/docs/reference/ai-sdk-core/generate-image)。

```ts
import { xai } from '@ai-sdk/xai';
import { generateImage } from 'ai';

const { image } = await generateImage({
  model: xai.image('grok-imagine-image'),
  prompt: 'A futuristic cityscape at sunset',
});
```

<Note>
  xAI 图像模型不支持 `size` 参数。请改用 `aspectRatio`。
  支持的宽高比：`1:1`、`16:9`、`9:16`、`4:3`、`3:4`、`3:2`、
  `2:3`、`2:1`、`1:2`、`19.5:9`、`9:19.5`、`20:9`、`9:20` 和 `auto`。
</Note>

### 图像编辑

xAI 通过 `grok-imagine-image` 模型支持图像编辑。通过 `prompt.images` 传递输入图像以转换或编辑现有图像。

<Note>
  xAI 图像编辑不支持遮罩。编辑由提示词驱动——在文本提示词中描述
  您想要更改的内容。
</Note>

#### 基本图像编辑

使用文本提示词转换现有图像：

```ts
import { xai } from '@ai-sdk/xai';
import { generateImage } from 'ai';
import { readFileSync } from 'fs';

const imageBuffer = readFileSync('./input-image.png');

const { images } = await generateImage({
  model: xai.image('grok-imagine-image'),
  prompt: {
    text: 'Turn the cat into a golden retriever dog',
    images: [imageBuffer],
  },
});
```

#### 多图像编辑

在提示词中组合或引用多个输入图像：

```ts
import { xai } from '@ai-sdk/xai';
import { generateImage } from 'ai';
import { readFileSync } from 'fs';

const cat = readFileSync('./cat.png');
const dog = readFileSync('./dog.png');

const { images } = await generateImage({
  model: xai.image('grok-imagine-image'),
  prompt: {
    text: 'Combine these two animals into a group photo',
    images: [cat, dog],
  },
});
```

#### 风格迁移

将艺术风格应用于图像：

```ts
const imageBuffer = readFileSync('./input-image.png');

const { images } = await generateImage({
  model: xai.image('grok-imagine-image'),
  prompt: {
    text: 'Transform this into a watercolor painting style',
    images: [imageBuffer],
  },
  aspectRatio: '1:1',
});
```

<Note>
  输入图像可以作为 `Buffer`、`ArrayBuffer`、`Uint8Array` 或
  base64 编码的字符串提供。
</Note>

### 图像提供商选项

您可以通过 `providerOptions.xai` 使用提供商特定的设置自定义图像生成行为：

```ts
import { xai, type XaiImageModelOptions } from '@ai-sdk/xai';
import { generateImage } from 'ai';

const { images } = await generateImage({
  model: xai.image('grok-imagine-image-pro'),
  prompt: 'A futuristic cityscape at sunset',
  aspectRatio: '16:9',
  providerOptions: {
    xai: {
      resolution: '2k',
      quality: 'high',
    } satisfies XaiImageModelOptions,
  },
});
```

- **resolution** _'1k' | '2k'_

  输出分辨率。`1k` 生成约 1024×1024 的图像，`2k` 生成约 2048×2048
  的图像（实际尺寸因宽高比而异）。适用于
  `grok-imagine-image-pro`。

- **quality** _'low' | 'medium' | 'high'_

  图像质量级别。较高质量可能会增加生成时间。

### 图像模型能力

| 模型                     | 分辨率 | 宽高比                                                                                               | 图像编辑 |
| ------------------------ | ---------- | ----------------------------------------------------------------------------------------------------------- | ------------- |
| `grok-imagine-image-pro` | `1k`, `2k` | `1:1`, `16:9`, `9:16`, `4:3`, `3:4`, `3:2`, `2:3`, `2:1`, `1:2`, `19.5:9`, `9:19.5`, `20:9`, `9:20`, `auto` | <Check />     |
| `grok-imagine-image`     | `1k`       | `1:1`, `16:9`, `9:16`, `4:3`, `3:4`, `3:2`, `2:3`, `2:1`, `1:2`, `19.5:9`, `9:19.5`, `20:9`, `9:20`, `auto` | <Check />     |

## 视频模型

您可以使用 `.video()` 工厂方法创建 xAI 视频模型。
有关使用 AI SDK 进行视频生成的更多信息，请参阅 [generateVideo()](/docs/reference/ai-sdk-core/generate-video)。

该提供商支持从文本提示词或图像输入进行标准视频生成，以及显式视频编辑、视频扩展和参考到视频（R2V）操作。

### 文本到视频

从文本提示词生成视频：

```ts
import { xai, type XaiVideoModelOptions } from '@ai-sdk/xai';
import { experimental_generateVideo as generateVideo } from 'ai';

const { video } = await generateVideo({
  model: xai.video('grok-imagine-video'),
  prompt: 'A chicken flying into the sunset in the style of 90s anime.',
  aspectRatio: '16:9',
  duration: 5,
  providerOptions: {
    xai: {
      user: 'user-123',
      pollTimeoutMs: 600000, // 10 minutes
    } satisfies XaiVideoModelOptions,
  },
});
```

### 使用图像输入生成

使用图像作为起始帧并带有可选文本提示词生成视频。这使用标准生成路径，而不是单独的提供商模式：

```ts
import { xai, type XaiVideoModelOptions } from '@ai-sdk/xai';
import { experimental_generateVideo as generateVideo } from 'ai';

const { video } = await generateVideo({
  model: xai.video('grok-imagine-video'),
  prompt: {
    image: 'https://example.com/start-frame.png',
    text: 'The cat slowly turns its head and blinks',
  },
  duration: 5,
  providerOptions: {
    xai: {
      pollTimeoutMs: 600000, // 10 minutes
    } satisfies XaiVideoModelOptions,
  },
});
```

您也可以通过顶层的 `frameImages` 选项使用 `first_frame` 角色传递起始帧。这是提供商无关的，接受文件数据（例如 `Buffer`）或 `{ type: 'url', url }` 对象：

```ts
import { xai, type XaiVideoModelOptions } from '@ai-sdk/xai';
import { experimental_generateVideo as generateVideo } from 'ai';
import fs from 'node:fs';

const { video } = await generateVideo({
  model: xai.video('grok-imagine-video'),
  prompt: 'The cat slowly turns its head and blinks',
  frameImages: [
    {
      image: fs.readFileSync('./start-frame.png'),
      frameType: 'first_frame',
    },
  ],
  duration: 5,
  providerOptions: {
    xai: {
      pollTimeoutMs: 600000, // 10 minutes
    } satisfies XaiVideoModelOptions,
  },
});
```

<Note>
  xAI 不支持首尾帧插值。`frameImages` 中的 `last_frame` 条目
  会被忽略并发出警告——请改用 `extend-video` 模式
  从视频的最后一帧继续。
</Note>

### 视频编辑

通过提供商选项提供源视频 URL，使用文本提示词编辑现有视频：

```ts
import { xai, type XaiVideoModelOptions } from '@ai-sdk/xai';
import { experimental_generateVideo as generateVideo } from 'ai';

const { video } = await generateVideo({
  model: xai.video('grok-imagine-video'),
  prompt: 'Give the person sunglasses and a hat',
  providerOptions: {
    xai: {
      mode: 'edit-video',
      videoUrl: 'https://example.com/source-video.mp4',
      pollTimeoutMs: 600000, // 10 minutes
    } satisfies XaiVideoModelOptions,
  },
});
```

<Note>
  视频编辑接受最长 8.7 秒的输入视频。`duration`、
  `aspectRatio` 和 `resolution` 参数不支持编辑——输出
  与输入视频的属性匹配（上限为 720p）。
</Note>

### 链式编辑和并发编辑

xAI 托管的视频 URL 可在 `providerMetadata.xai.videoUrl` 中获取。
您可以使用它来链式执行顺序编辑，或使用 `Promise.all` 分支为并发编辑：

```ts
import { xai, type XaiVideoModelOptions } from '@ai-sdk/xai';
import { experimental_generateVideo as generateVideo } from 'ai';

const providerOptions = {
  xai: {
    mode: 'edit-video',
    videoUrl: 'https://example.com/source-video.mp4',
    pollTimeoutMs: 600000,
  } satisfies XaiVideoModelOptions,
};

// Step 1: Apply an initial edit
const step1 = await generateVideo({
  model: xai.video('grok-imagine-video'),
  prompt: 'Add a party hat to the person',
  providerOptions,
});

// Get the xAI-hosted URL from provider metadata
const step1VideoUrl = step1.providerMetadata?.xai?.videoUrl as string;

// Step 2: Apply two more edits concurrently, building on step 1
const [withSunglasses, withScarf] = await Promise.all([
  generateVideo({
    model: xai.video('grok-imagine-video'),
    prompt: 'Add sunglasses',
    providerOptions: {
      xai: {
        mode: 'edit-video',
        videoUrl: step1VideoUrl,
        pollTimeoutMs: 600000,
      },
    },
  }),
  generateVideo({
    model: xai.video('grok-imagine-video'),
    prompt: 'Add a scarf',
    providerOptions: {
      xai: {
        mode: 'edit-video',
        videoUrl: step1VideoUrl,
        pollTimeoutMs: 600000,
      },
    },
  }),
]);
```

### 视频扩展

从现有视频的最后一帧扩展视频。`duration` 仅控制扩展的长度，而不是总输出。输出继承源视频的 `aspectRatio` 和 `resolution`。

```ts
import { xai, type XaiVideoModelOptions } from '@ai-sdk/xai';
import { experimental_generateVideo as generateVideo } from 'ai';

// Step 1: Generate a source video
const source = await generateVideo({
  model: xai.video('grok-imagine-video'),
  prompt: 'A cat sitting on a sunlit windowsill, tail gently swishing.',
  duration: 5,
  aspectRatio: '16:9',
  providerOptions: {
    xai: {
      pollTimeoutMs: 600000,
    } satisfies XaiVideoModelOptions,
  },
});

const sourceUrl = source.providerMetadata?.xai?.videoUrl as string;

// Step 2: Extend the video with a new scene
const extended = await generateVideo({
  model: xai.video('grok-imagine-video'),
  prompt: 'The cat turns its head, notices a butterfly, and leaps off.',
  duration: 6,
  providerOptions: {
    xai: {
      mode: 'extend-video',
      videoUrl: sourceUrl,
      pollTimeoutMs: 600000,
    } satisfies XaiVideoModelOptions,
  },
});
```

<Note>
  视频扩展不支持自定义 `aspectRatio` 或 `resolution`——输出
  继承源视频的这些属性。支持 `duration`，它控制扩展的长度
  （不是总视频长度）。
</Note>

### 参考到视频（R2V）

提供参考图像来指导视频的风格和内容。与图像到视频不同，参考图像不用作第一帧——模型将其视觉元素融入生成的视频中。每个参考图像可以是公共 HTTPS URL 或 base64 数据 URI。

```ts
import { xai, type XaiVideoModelOptions } from '@ai-sdk/xai';
import { experimental_generateVideo as generateVideo } from 'ai';

const { video } = await generateVideo({
  model: xai.video('grok-imagine-video'),
  prompt:
    'The comic cat from <IMAGE_1> and the comic dog from <IMAGE_2> ' +
    'are having a playful chase through a sunlit park. ' +
    'Cinematic slow-motion, warm afternoon light.',
  duration: 8,
  aspectRatio: '16:9',
  providerOptions: {
    xai: {
      mode: 'reference-to-video',
      referenceImageUrls: [
        'https://example.com/comic-cat.png',
        'https://example.com/comic-dog.png',
      ],
      pollTimeoutMs: 600000,
    } satisfies XaiVideoModelOptions,
  },
});
```

在提示词中使用 `<IMAGE_1>`、`<IMAGE_2>` 等来引用特定图像。每个请求最多支持 7 个参考图像。

或者，使用提供商无关的顶层 `inputReferences` 选项。提供它会自动选择参考到视频模式，并且它接受文件数据（例如 `Buffer`）或 `{ type: 'url', url }` 对象：

```ts
import { xai, type XaiVideoModelOptions } from '@ai-sdk/xai';
import { experimental_generateVideo as generateVideo } from 'ai';
import fs from 'node:fs';

const { video } = await generateVideo({
  model: xai.video('grok-imagine-video'),
  prompt:
    'The comic cat and the comic dog are having a playful chase ' +
    'through a sunlit park. Cinematic slow-motion, warm afternoon light.',
  inputReferences: [
    fs.readFileSync('./comic-cat.png'),
    fs.readFileSync('./comic-dog.png'),
  ],
  duration: 8,
  aspectRatio: '16:9',
  providerOptions: {
    xai: {
      pollTimeoutMs: 600000,
    } satisfies XaiVideoModelOptions,
  },
});
```

`inputReferences` 仅接受图像引用。具有非图像媒体类型（例如视频或音频片段）的引用会被忽略并发出警告，而没有媒体类型的引用则被视为图像。如果没有剩余的图像引用，则不会选择参考到视频模式，也不会发送参考图像。

#### 参考音频

参考到视频还可以为对象提供声音。`referenceVoiceIds` 接受最多 3 个 xAI **预设** 语音 ID——您不能上传自己的音频片段。在提示词中使用 `<AUDIO_0>`、`<AUDIO_1>` 和 `<AUDIO_2>` 按传递顺序引用语音。

```ts
import { xai, type XaiVideoModelOptions } from '@ai-sdk/xai';
import { experimental_generateVideo as generateVideo } from 'ai';

const { video } = await generateVideo({
  model: xai.video('grok-imagine-video-1.5'),
  prompt:
    'The person from <IMAGE_0> stands in the room from <IMAGE_1> and speaks ' +
    'to the camera with the voice from <AUDIO_0>.',
  aspectRatio: '9:16',
  duration: 10,
  providerOptions: {
    xai: {
      mode: 'reference-to-video',
      referenceImageUrls: [
        'https://example.com/person.png',
        'https://example.com/room.png',
      ],
      referenceVoiceIds: ['eve'],
      resolution: '720p',
      pollTimeoutMs: 600000,
    } satisfies XaiVideoModelOptions,
  },
});
```

有效的语音 ID 来自 xAI
[文本转语音语音列表](https://docs.x.ai/developers/model-capabilities/audio/text-to-speech#voices)。
ID 不区分大小写，未知 ID 会返回 `400` 响应，列出可用的语音。当解析的操作不是参考到视频时，`referenceVoiceIds` 会被忽略并发出警告。

<Note>
  xAI 文档说明参考音频仅在美国可用，且仅限受信任的合作伙伴。
  没有访问权限的账户发出的请求会被 xAI API 拒绝。
</Note>

<Note>
  参考到视频支持 `duration`、`aspectRatio` 和 `resolution`。使用
  `mode` 选择操作——每种模式互斥。当同时提供时，
  `frameImages` 优先于 `inputReferences`，而
  `inputReferences` 优先于旧版的 `referenceImageUrls`
  提供商选项。参考到视频由 `grok-imagine-video`
  和 `grok-imagine-video-1.5` 模型支持；原生 1080p 需要
  `grok-imagine-video-1.5`。
</Note>

### 视频提供商选项

以下提供商选项可通过 `providerOptions.xai` 使用。
您可以使用 `XaiVideoModelOptions` 类型验证提供商选项。

- **pollIntervalMs** _number_

  检查任务状态的轮询间隔（毫秒）。默认为 5000。

- **pollTimeoutMs** _number_

  视频生成的最大等待时间（毫秒）。默认为 600000（10 分钟）。

- **resolution** _'480p' | '720p' | '1080p'_

  视频分辨率。使用 SDK 的标准 `resolution` 参数时，
  `1920x1080` 映射到 `1080p`，`1280x720` 映射到 `720p`，`854x480` 映射
  到 `480p`。使用此提供商选项直接传递原生格式。
  `1080p` 需要 `grok-imagine-video-1.5` 模型，适用于
  文本到视频和图像到视频；参考到视频上限为 `720p`
  （`1080p` 请求会降级并发出警告）。

- **user** _string_

  负责请求的最终用户的可选标识符。xAI 使用
  此值进行滥用监控。它会在视频生成（包括参考到视频）和视频编辑请求中原样发送，未配置时省略。它不会为视频扩展请求发送。使用不透明的稳定标识符，避免发送不必要的个人信息。

- **mode** _'edit-video' | 'extend-video' | 'reference-to-video'_

  选择显式的视频操作。每种模式互斥：
  - `'edit-video'` — 编辑现有视频（需要 `videoUrl`）
  - `'extend-video'` — 从视频的最后一帧扩展视频（需要 `videoUrl`）
  - `'reference-to-video'` — 从参考图像生成（需要 `referenceImageUrls`）

  省略时，使用标准生成。为了向后兼容，旧版输入仍会从字段中自动检测。

- **videoUrl** _string_

  源视频的 URL。与 `mode: 'edit-video'` 一起用于视频编辑，
  与 `mode: 'extend-video'` 一起用于视频扩展。

- **referenceImageUrls** _string[]_

  参考图像 URL（1-7 张图像）或 base64 数据 URI 的数组，用于
  参考到视频（R2V）生成。模型会融入这些图像的视觉元素，
  但不会将它们用作第一帧。在提示词中使用
  `<IMAGE_1>`、`<IMAGE_2>` 等来引用特定图像。与
  `mode: 'reference-to-video'` 一起使用。

- **referenceVoiceIds** _string[]_

  最多 3 个 xAI 预设语音 ID，用于在参考到视频（R2V）生成中为对象提供声音。仅限预设语音——不能上传音频片段。ID 不区分大小写，来自
  [文本转语音语音列表](https://docs.x.ai/developers/model-capabilities/audio/text-to-speech#voices)；
  未知 ID 会返回 `400` 并列出可用语音。在提示词中使用 `<AUDIO_0>`、
  `<AUDIO_1>` 和 `<AUDIO_2>` 标签引用语音。
  在参考到视频之外会被忽略并发出警告。参考音频
  文档说明仅限美国使用，且仅限受信任的合作伙伴。

<Note>
  视频生成是一个异步过程，可能需要几分钟。
  建议将 `pollTimeoutMs` 设置为至少 10 分钟（600000 毫秒）以确保
  可靠运行。生成的视频 URL 是临时的，应及时下载。
</Note>

### 宽高比和分辨率

对于**文本到视频**，您可以同时指定 `aspectRatio` 和 `resolution`。
默认宽高比为 `16:9`，默认分辨率为 `480p`。
`grok-imagine-video-1.5` 模型还支持文本到视频和图像到视频的原生 `1080p`。

对于**图像到视频**，输出默认为输入图像的宽高比。
如果您指定 `aspectRatio`，它将覆盖此设置并将图像拉伸到所需的
比例。

对于**视频编辑**，输出与输入视频的宽高比和分辨率匹配。
不支持自定义 `duration`、`aspectRatio` 和 `resolution`——输出分辨率上限为 720p（例如，1080p 输入
将缩小到 720p）。

对于**视频扩展**，输出继承源视频的 `aspectRatio` 和 `resolution`。
支持 `duration`，它仅控制扩展长度。

对于**参考到视频（R2V）**，您可以指定 `duration`、`aspectRatio`
和 `resolution`。与文本到视频不同，R2V 上限为 `720p`——`1080p`
请求会降级为 `720p` 并发出警告。
