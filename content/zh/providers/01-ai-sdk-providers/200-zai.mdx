# Z.AI 提供商

[Z.AI](https://z.ai/) 提供商让你可以通过 Z.AI API 访问 GLM 语言模型和视觉模型。
你可以通过 [AI Gateway](/providers/ai-sdk-providers/ai-gateway)（推荐）使用 Z.AI 模型，也可以使用 `@ai-sdk/zai` 直接连接。

```ts provider="zai" model="zai/glm-5.3"
import { generateText } from 'ai';
__PROVIDER_IMPORT__;

const { text } = await generateText({
  model: __MODEL__,
  prompt: 'Write a vegetarian lasagna recipe for 4 people.',
});

console.log(text);
```

## 使用 AI Gateway

AI SDK 默认对模型字符串使用 AI Gateway。Gateway 通过单个 API key 提供跨提供商的模型访问，并支持用量和成本跟踪。安装 `ai`：

<InstallPackages packages="ai" />

在环境中设置 [AI Gateway API key](https://vercel.com/docs/ai-gateway/getting-started)：

```bash
export AI_GATEWAY_API_KEY=your_api_key_here
```

Vercel 部署还可以使用 [OIDC 认证](/providers/ai-sdk-providers/ai-gateway#oidc-authentication-vercel-deployments)。
有关配置信息，请参阅 [AI Gateway 提供商文档](/providers/ai-sdk-providers/ai-gateway)；有关可用模型，请参阅[模型目录](https://vercel.com/ai-gateway/models)。

Gateway 的功能和提供商选项支持取决于模型以及处理请求的提供商。请参阅 [Gateway 提供商选项](https://vercel.com/docs/ai-gateway/models-and-providers/provider-options)。

## 使用 `@ai-sdk/zai`

如需直接访问 Z.AI，请安装 `ai` 和 `@ai-sdk/zai`：

<InstallPackages packages="ai @ai-sdk/zai" />

在 `ZAI_API_KEY` 环境变量中设置你的 Z.AI API 凭据：

```bash
export ZAI_API_KEY=your_api_key_here
```

AI Gateway 并未暴露 `@ai-sdk/zai` 中的每一个 API。如需使用提供商特定的 API 或自定义连接设置，请使用直接提供商。

<Note>
  以下章节介绍直接使用 `@ai-sdk/zai` 提供商，包括其模型工厂和设置。Gateway
  的模型和功能可用性可能有所不同。
</Note>

API key 可以在 [Z.AI API key 控制台](https://z.ai/manage-apikey/apikey-list)中创建。

## 提供商实例

从 `@ai-sdk/zai` 导入默认提供商实例 `zai`：

```ts
import { zai } from '@ai-sdk/zai';
```

如需自定义配置，请使用 `createZai`：

```ts
import { createZai } from '@ai-sdk/zai';

const zai = createZai({
  apiKey: process.env.ZAI_API_KEY,
  baseURL: 'https://api.z.ai/api/paas/v4',
});
```

该提供商接受以下可选设置：

- **apiKey** _string_

  在 `Authorization` 请求头中发送的 API key。默认使用 `ZAI_API_KEY` 环境变量。

- **baseURL** _string_

  API 请求的 URL 前缀。默认为 `https://api.z.ai/api/paas/v4`。

- **headers** _Record&lt;string, string&gt;_

  额外的请求头。

- **fetch** _FetchFunction_

  自定义 fetch 实现，例如用于在中间件中拦截请求。

## 语言模型

将模型 id 传给提供商即可创建语言模型：

```ts
import { zai } from '@ai-sdk/zai';
import { generateText } from 'ai';

const { text } = await generateText({
  model: zai('glm-5.3'),
  prompt: 'Explain quantum entanglement in simple terms.',
});
```

当前模型系列包括 GLM 5、GLM 4.7、GLM 4.6、GLM 4.5 以及 GLM 视觉模型。模型可用性会随时间变化；请参阅 [Z.AI 模型文档](https://docs.z.ai/guides/llm)了解当前目录。

该提供商支持：

- 文本生成和流式传输
- 推理输出和推理历史
- 函数调用，包括增量工具调用流式传输
- JSON 对象输出
- 在兼容的视觉模型上支持基于 URL 的图像和视频输入

## 提供商选项

Z.AI 特定选项可以通过 `providerOptions.zai` 传入：

```ts
import { zai } from '@ai-sdk/zai';
import { generateText } from 'ai';

const result = await generateText({
  model: zai('glm-5.3'),
  prompt: 'Compare two approaches to implementing a rate limiter.',
  providerOptions: {
    zai: {
      thinking: { type: 'enabled', clearThinking: true },
      reasoningEffort: 'high',
      requestId: 'request-123456',
      userId: 'user-123456',
    },
  },
});
```

以下选项可用：

- **doSample** _boolean_

  启用采样。禁用时，`temperature` 和 `topP` 不会生效。

- **thinking** _object_

  通过 `type: 'enabled' | 'disabled'` 控制思考。将 `clearThinking` 设为 `false` 可保留之前助手消息中的推理内容。

- **reasoningEffort** _'none' | 'minimal' | 'low' | 'medium' | 'high' | 'xhigh' | 'max'_

  在支持的模型上控制推理强度。

- **toolStream** _boolean_

  在支持的模型上启用增量函数调用参数流式传输。

- **requestId** _string_

  调用方提供的请求 id，长度为 6 到 64 个字符。

- **userId** _string_

  非敏感的最终用户 id，长度为 6 到 128 个字符。

## 流式工具调用

当你希望支持的 GLM 模型增量流式传输函数调用参数时，请启用 `toolStream`：

```ts
import { zai } from '@ai-sdk/zai';
import { streamText, tool } from 'ai';
import { z } from 'zod';

const result = streamText({
  model: zai('glm-5.3'),
  prompt: 'What is the weather in San Francisco?',
  tools: {
    weather: tool({
      description: 'Get the weather for a city',
      inputSchema: z.object({ city: z.string() }),
    }),
  },
  providerOptions: {
    zai: { toolStream: true },
  },
});

for await (const part of result.fullStream) {
  console.log(part);
}
```
