# Z.AI 提供商

[Z.AI](https://z.ai/) 提供商使您能够通过 Z.AI API 访问 GLM 语言和视觉模型。

API 密钥可以在 [Z.AI API 密钥控制台](https://z.ai/manage-apikey/apikey-list) 中创建。

## 设置

Z.AI 提供商可通过 `@ai-sdk/zai` 包获得。使用以下命令安装：

<InstallPackages packages="@ai-sdk/zai" />

设置 `ZAI_API_KEY` 环境变量：

```bash
ZAI_API_KEY=your-api-key
```

## 提供商实例

从 `@ai-sdk/zai` 导入默认提供商实例 `zai`：

```ts
import { zai } from '@ai-sdk/zai';
```

如需自定义配置，请使用 `createZai`：

```ts
import { createZai } from '@ai-sdk/zai';

const zai = createZai({
  apiKey: process.env.ZAI_API_KEY,
  baseURL: 'https://api.z.ai/api/paas/v4',
});
```

该提供商接受以下可选设置：

- **apiKey** _string_

  在 `Authorization` 请求头中发送的 API 密钥。默认使用 `ZAI_API_KEY` 环境变量。

- **baseURL** _string_

  API 请求的 URL 前缀。默认值为 `https://api.z.ai/api/paas/v4`。

- **headers** _Record&lt;string, string&gt;_

  额外的请求头。

- **fetch** _FetchFunction_

  自定义 fetch 实现，例如用于在中间件中拦截请求。

## 语言模型

通过将模型 ID 传递给提供商来创建语言模型：

```ts
import { zai } from '@ai-sdk/zai';
import { generateText } from 'ai';

const { text } = await generateText({
  model: zai('glm-5.3'),
  prompt: '用简单的语言解释量子纠缠。',
});
```

当前模型系列包括 GLM 5、GLM 4.7、GLM 4.6、GLM 4.5 以及 GLM 视觉模型。模型可用性会随时间变化；请参阅 [Z.AI 模型文档](https://docs.z.ai/guides/llm) 获取最新目录。

该提供商支持：

- 文本生成和流式传输
- 推理输出和推理历史
- 函数调用，包括增量工具调用流式传输
- JSON 对象输出
- 兼容视觉模型上的基于 URL 的图像和视频输入

## 提供商选项

Z.AI 特定选项可以通过 `providerOptions.zai` 传递：

```ts
import { zai } from '@ai-sdk/zai';
import { generateText } from 'ai';

const result = await generateText({
  model: zai('glm-5.3'),
  prompt: '比较实现速率限制器的两种方法。',
  providerOptions: {
    zai: {
      thinking: { type: 'enabled', clearThinking: true },
      reasoningEffort: 'high',
      requestId: 'request-123456',
      userId: 'user-123456',
    },
  },
});
```

以下选项可用：

- **doSample** _boolean_

  启用采样。禁用时，`temperature` 和 `topP` 不生效。

- **thinking** _object_

  通过 `type: 'enabled' | 'disabled'` 控制思考。将 `clearThinking` 设置为 `false` 以保留先前助手消息中的推理内容。

- **reasoningEffort** _'none' | 'minimal' | 'low' | 'medium' | 'high' | 'xhigh' | 'max'_

  控制受支持模型上的推理努力程度。

- **toolStream** _boolean_

  在受支持的模型上启用增量函数调用参数流式传输。

- **requestId** _string_

  调用方提供的请求 ID，长度为 6 到 64 个字符。

- **userId** _string_

  非敏感最终用户 ID，长度为 6 到 128 个字符。

## 流式传输工具调用

当您希望受支持的 GLM 模型增量流式传输函数调用参数时，请启用 `toolStream`：

```ts
import { zai } from '@ai-sdk/zai';
import { streamText, tool } from 'ai';
import { z } from 'zod';

const result = streamText({
  model: zai('glm-5.3'),
  prompt: '旧金山的天气怎么样？',
  tools: {
    weather: tool({
      description: '获取某个城市的天气',
      inputSchema: z.object({ city: z.string() }),
    }),
  },
  providerOptions: {
    zai: { toolStream: true },
  },
});

for await (const part of result.fullStream) {
  console.log(part);
}
```
