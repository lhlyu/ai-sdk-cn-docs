# Fish Audio 提供商

[Fish Audio](https://fish.audio/) 提供商支持语音生成（S1 和 S2 模型）以及语音转文字转录功能。

## 设置

Fish Audio 提供商位于 `@ai-sdk/fish-audio` 模块中。你可以通过以下方式安装：

<Tabs items={['pnpm', 'npm', 'yarn', 'bun']}>
  <Tab>

  </Tab>
  <Tab>

## 提供商实例

你可以从 `@ai-sdk/fish-audio` 导入默认提供商实例 `fishAudio`：

```ts
import { fishAudio } from '@ai-sdk/fish-audio';
```

如果你需要自定义设置，可以从 `@ai-sdk/fish-audio` 导入 `createFishAudio` 并使用你的设置创建提供商实例：

```ts
import { createFishAudio } from '@ai-sdk/fish-audio';

const fishAudio = createFishAudio({
  // 自定义设置，例如
  fetch: customFetch,
});
```

你可以使用以下可选设置来自定义 Fish Audio 提供商实例：

- **apiKey** _string_

  通过 `Authorization` 标头发送的 API 密钥。
  默认为 `FISH_AUDIO_API_KEY` 环境变量。

- **baseURL** _string_

  API 调用的基础 URL。
  默认为 `https://api.fish.audio`。

- **headers** _Record&lt;string,string&gt;_

  要包含在请求中的自定义标头。

- **fetch** _(input: RequestInfo, init?: RequestInit) => Promise&lt;Response&gt;_

  自定义 [fetch](https://developer.mozilla.org/en-US/docs/Web/API/fetch) 实现。
  默认为全局 `fetch` 函数。
  你可以将其用作中间件来拦截请求，或提供自定义的 fetch 实现，例如用于测试。

## 语音模型

你可以使用 `.speech()` 工厂方法创建调用 [Fish Audio 文本转语音 API](https://docs.fish.audio/api-reference/endpoint/openapi-v1/text-to-speech) 的模型。

```ts
import { fishAudio } from '@ai-sdk/fish-audio';
import { generateSpeech } from 'ai';

const { audio } = await generateSpeech({
  model: fishAudio.speech('s1'),
  text: 'Hello from Fish Audio!',
});
```

`voice` 选项用于选择 Fish Audio 语音模型 ID（`reference_id`），可以从 [Fish Audio 语音库](https://fish.audio/) 中选择，也可以使用你自己上传的模型。省略该选项则使用默认语音。

```ts
const { audio } = await generateSpeech({
  model: fishAudio.speech('s1'),
  text: 'Hello from Fish Audio!',
  voice: '933563129e564b19a115bedd57b7406a',
  outputFormat: 'opus',
  speed: 1.1,
});
```

语音列表不属于 AI SDK 语音模型规范的一部分，因此请直接通过 [Fish Audio 模型列表端点](https://docs.fish.audio/api-reference/endpoint/openapi-v1/list-models) 浏览语音：

```ts
const response = await fetch(
  'https://api.fish.audio/model?page_size=20&sort_by=task_count',
  { headers: { Authorization: `Bearer ${process.env.FISH_AUDIO_API_KEY}` } },
);
const { items } = await response.json();
// 每个项目的 `_id` 都是可以传递给 `voice` 的值。
```

添加 `self=true` 仅列出你自己上传的模型，或添加 `language=en` / `tag=narration` 进行筛选。

### 提供商选项

以下提供商选项可用：

- **referenceId** _string | 字符串数组_

  语音模型 ID。单个 ID 选择一个说话人；数组支持多说话人对话（S2-Pro 模型）。优先于顶层 `voice` 选项。
  可选。

- **sampleRate** _number_

  输出采样率（Hz）。未设置时回退到格式默认值（`wav`/`pcm`/`mp3` 为 44100 Hz，`opus` 为 48000 Hz）。
  可选。

- **mp3Bitrate** _64 | 128 | 192_

  `mp3` 输出的比特率（kbps）。其他格式忽略。
  可选。

- **opusBitrate** _-1000 | 24000 | 32000 | 48000 | 64000_

  `opus` 输出的比特率（bps），其中 `-1000` 表示自动选择。其他格式忽略。
  可选。

- **latency** _'low' | 'normal' | 'balanced'_

  延迟/质量权衡。`normal` 提供最佳质量，`balanced` 降低延迟，`low` 最快。
  可选。

- **volume** _number_

  音量偏移（dB）。负值更安静。
  可选。

- **normalizeLoudness** _boolean_

  响度归一化。S2 系列（`s2-pro` 和 `s2.1-pro`）支持。Fish Audio 在 `s1` 上接受但忽略此参数，因此提供商会在这种情况下丢弃它并发出警告。
  可选。

- **temperature** _number_

  控制表现力（0 到 1）。值越高变化越多。
  可选。

- **topP** _number_

  通过核采样控制多样性（0 到 1）。
  可选。

- **chunkLength** _number_

  处理的文本段大小（100 到 300）。
  可选。

- **minChunkLength** _number_

  拆分为新块之前的最小字符数（0 到 100）。
  可选。

- **normalize** _boolean_

  英文和中文的文本归一化。有助于数字的稳定性。
  可选。

- **maxNewTokens** _number_

  每个文本块生成的最大音频 token 数。
  可选。

- **repetitionPenalty** _number_

  高于 1.0 的值会抑制重复的音频模式。
  可选。

- **conditionOnPreviousChunks** _boolean_

  重用先前的音频作为上下文，以保持跨块的语音一致性。
  可选。

- **earlyStopThreshold** _number_

  批处理中使用的提前停止阈值（0 到 1）。
  可选。

- **features** _字符串数组_

  传递给推理后端的请求级标志，例如 `['quality-guard']`。
  可选。

### 多说话人对话

S2-Pro 模型支持多说话人对话。通过 `referenceId` 传递语音模型 ID 数组，并在文本中使用 `<|speaker:N|>` 标记轮次，其中 `N` 是该数组的索引。

```ts
const { audio } = await generateSpeech({
  model: fishAudio.speech('s2-pro'),
  text: '<|speaker:0|>Hello!<|speaker:1|>Hi there!',
  providerOptions: {
    fishAudio: {
      referenceId: [
        '933563129e564b19a115bedd57b7406a',
        'bf322df2096a46f18c579d0baa36f41d',
      ],
    },
  },
});
```

### 输出格式

Fish Audio 支持 `wav`、`pcm`、`mp3` 和 `opus` 输出格式。任何其他值都会回退到 `mp3` 并产生警告。

<Note>
  Fish Audio 根据输入文本和所选语音推断语言，没有语言参数。不支持 `language` 和 `instructions` 选项，并会产生警告。
</Note>

### 模型能力

| 模型             | 多说话人           | 备注                                                                       |
| --------------- | ------------------- | ------------------------------------------------------------------------- |
| `s1`            |                     | 忽略 `normalizeLoudness`                                                  |
| `s2-pro`        | <Check size={18} /> | 支持 `normalizeLoudness`                                                  |
| `s2.1-pro`      | <Check size={18} /> | 推荐的默认模型；支持 `normalizeLoudness`                                   |
| `s2.1-pro-free` |                     | 免费开发者层级；不保证首音频时间或数据处理                                  |

<Note>
  目前不支持流式文本转语音（Fish Audio 的 TTS-live WebSocket 和带时间戳的流式端点），也不支持通过 `references` 进行内联零样本语音克隆，后者需要 MessagePack 请求体。请将参考音频上传到 Fish Audio，并通过 `voice` 或 `referenceId` 传递其 `reference_id`。
</Note>

## 转录模型

你可以使用 `.transcription()` 工厂方法创建调用 [Fish Audio 语音转文字 API](https://docs.fish.audio/api-reference/endpoint/openapi-v1/speech-to-text) 的模型。

```ts
import { fishAudio } from '@ai-sdk/fish-audio';
import { transcribe } from 'ai';
import { readFile } from 'node:fs/promises';

const result = await transcribe({
  model: fishAudio.transcription(),
  audio: await readFile('audio.mp3'),
});
```

Fish Audio 语音转文字端点目前不提供模型选择器，仅提供单一模型，因此模型 ID 是可选的，默认为 `'transcribe-1'`。它是一个路由标签，不会发送到 API。Fish Audio 预计会增加更多 ASR 模型，并通过 `model` HTTP 标头进行选择，与文本转语音端点保持一致。

### 提供商选项

以下提供商选项可用：

- **language** _string_

  音频的语言。仅作为提示：Fish Audio 会将其传递给模型，但自动检测具有权威性并会覆盖它，因此它不会改变转录文本或报告的语言。
  可选。

- **ignoreTimestamps** _boolean_

  是否跳过精确时间戳。对应 Fish Audio 的 `ignore_timestamps` 参数，其 API 默认值为 `true`。此提供商将其默认值设为 `false`，以便填充 `segments`。Fish Audio 文档说明，对于短于 30 秒的音频会增加延迟成本；将此设置为 `true` 可以用 `segments` 换取该延迟。
  可选。

```ts
const result = await transcribe({
  model: fishAudio.transcription(),
  audio: await readFile('audio.mp3'),
  providerOptions: {
    fishAudio: {
      language: 'en',
      ignoreTimestamps: false,
    },
  },
});
```

`result.language` 以 ISO-639-1 代码（例如 `en`）报告检测到的语言。它始终是两位字母代码，绝不会是诸如 `en-US` 之类的区域设置，并且当 Fish Audio 未检测到语言时为 `undefined`。

人类可读的语言名称（例如 `English`）可作为提供商元数据使用：

```ts
console.log(result.language); // 'en'
console.log(result.providerMetadata?.fishAudio?.language); // 'English'
```

<Note>
  提供商元数据 `language` 是用于展示的显示名称。其确切形式不保证，因此避免基于它进行匹配或分支——任何程序化操作请使用 `result.language`。
</Note>

<Note>
  将 `ignoreTimestamps` 设置为 `true` 会使 Fish Audio 返回空的 `segments` 数组。因此，提供商默认请求时间戳。
</Note>
