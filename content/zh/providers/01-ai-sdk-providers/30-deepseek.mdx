# DeepSeek 提供商

[DeepSeek](https://www.deepseek.com) 提供商通过 DeepSeek API 提供对强大语言模型的访问。

API 密钥可从 [DeepSeek 平台](https://platform.deepseek.com/api_keys) 获取。

## 设置

DeepSeek 提供商通过 `@ai-sdk/deepseek` 模块提供。你可以使用以下命令安装：

<InstallPackages packages="@ai-sdk/deepseek" />

## 提供商实例

你可以从 `@ai-sdk/deepseek` 导入默认提供商实例 `deepSeek`：

```ts
import { deepSeek } from '@ai-sdk/deepseek';
```

如需自定义配置，你可以导入 `createDeepSeek` 并使用你的设置创建提供商实例：

```ts
import { createDeepSeek } from '@ai-sdk/deepseek';

const deepSeek = createDeepSeek({
  apiKey: process.env.DEEPSEEK_API_KEY ?? '',
});
```

你可以使用以下可选设置来自定义 DeepSeek 提供商实例：

- **baseURL** _string_

  为 API 调用使用不同的 URL 前缀。
  默认前缀为 `https://api.deepseek.com`。

- **apiKey** _string_

  通过 `Authorization` 请求头发送的 API 密钥。默认使用
  `DEEPSEEK_API_KEY` 环境变量。

- **headers** _Record&lt;string,string&gt;_

  要包含在请求中的自定义请求头。

- **fetch** _(input: RequestInfo, init?: RequestInit) => Promise&lt;Response&gt;_

  自定义 [fetch](https://developer.mozilla.org/en-US/docs/Web/API/fetch) 实现。

## 语言模型

你可以使用提供商实例创建语言模型：

```ts
import { deepSeek } from '@ai-sdk/deepseek';
import { generateText } from 'ai';

const { text } = await generateText({
  model: deepSeek('deepseek-v4-flash'),
  prompt: 'Write a vegetarian lasagna recipe for 4 people.',
});
```

你也可以使用 `.chat()` 或 `.languageModel()` 工厂方法：

```ts
const model = deepSeek.chat('deepseek-v4-flash');
// or
const model = deepSeek.languageModel('deepseek-v4-flash');
```

DeepSeek 语言模型可用于 `streamText` 函数
（参见 [AI SDK Core](/docs/ai-sdk-core)）。

DeepSeek 已于 2026 年 7 月 24 日停用 `deepseek-chat` 和 `deepseek-reasoner` 别名。对于当前 API，请使用 `deepseek-flash`（当前 V4.x Flash 版本的别名）、`deepseek-v4-flash` 或 `deepseek-v4-pro`。为兼容自定义
端点，自定义和旧版模型 ID 仍可作为字符串接受。

DeepSeek 模型可使用以下可选提供商选项：

- `logprobs` _boolean_

  可选。在 `providerMetadata.deepseek.logprobs` 中返回生成内容和推理
  token 的对数概率。

- `topLogprobs` _number_

  可选。在每个 token 位置返回指定数量的最可能 token。
  接受 `0` 到 `20` 的值，并自动启用
  `logprobs`。

- `userId` _string_

  可选。DeepSeek 用于内容安全
  追踪、KV 缓存隔离和调度隔离的不透明最终用户标识符。该值必须匹配
  `^[a-zA-Z0-9_-]+$` 且最多包含 512 个字符。请勿包含姓名、
  电子邮件地址或其他私人用户信息。

- `thinking` _object_

  可选。控制 DeepSeek V4 模型的思考模式（思维链推理）。
  - `type`：`'enabled' | 'disabled'` - 启用或禁用思考模式。参见 [DeepSeek 的思考模式文档](https://api-docs.deepseek.com/guides/thinking_mode)。

- `reasoningEffort` _'low' | 'high' | 'max'_

  可选。控制 DeepSeek V4 推理模型的思考强度。使用
  顶层 `reasoning` 设置时，`minimal` 会作为 `low` 发送，
  `medium` 会作为 `high` 发送，`xhigh` 会作为 `max` 发送。每当请求的值被映射时，
  都会返回兼容性警告。

为向后兼容，运行时提供的旧版提供商选项也会映射到文档化的值：`thinking.type: 'adaptive'` 变为
`'enabled'`，`reasoningEffort: 'medium'` 变为 `'high'`，`reasoningEffort: 'xhigh'` 变为 `'max'`。每次映射都会返回兼容性
警告，以便调用方迁移到规范值。

DeepSeek 已弃用顶层 `frequencyPenalty` 和 `presencePenalty`
设置。当使用这些设置时，提供商会省略它们并返回弃用警告。
在启用思考时（包括 DeepSeek V4 模型的默认思考模式），`temperature` 和 `topP` 不起作用，
因此提供商会省略它们并返回不支持警告。请显式将
`thinking.type` 设置为 `'disabled'` 以使用 `temperature` 和 `topP`。

```ts highlight="7-15"
import {
  deepSeek,
  type DeepSeekLanguageModelChatOptions,
} from '@ai-sdk/deepseek';
import { generateText } from 'ai';

const { text, reasoning } = await generateText({
  model: deepSeek('deepseek-v4-flash'),
  prompt: 'How many "r"s are in the word "strawberry"?',
  providerOptions: {
    deepseek: {
      userId: 'tenant_123-user',
      thinking: { type: 'enabled' },
      reasoningEffort: 'high',
    } satisfies DeepSeekLanguageModelChatOptions,
  },
});
```

### 消息名称

DeepSeek 支持在 system、user 和 assistant
消息上使用可选参与者名称。在应包含名称的每条消息上设置 `providerOptions.deepseek.name`：

```ts
import {
  deepSeek,
  type DeepSeekMessageProviderOptions,
} from '@ai-sdk/deepseek';
import { generateText } from 'ai';

const { text } = await generateText({
  model: deepSeek('deepseek-chat'),
  instructions: {
    role: 'system',
    content: 'Help the customer plan a short trip.',
    providerOptions: {
      deepseek: {
        name: 'travel_planner',
      } satisfies DeepSeekMessageProviderOptions,
    },
  },
  messages: [
    {
      role: 'user',
      content: 'I want to visit Lisbon for a weekend.',
      providerOptions: {
        deepseek: {
          name: 'customer',
        } satisfies DeepSeekMessageProviderOptions,
      },
    },
    {
      role: 'assistant',
      content: 'What kinds of activities do you enjoy?',
      providerOptions: {
        deepseek: {
          name: 'travel_planner',
        } satisfies DeepSeekMessageProviderOptions,
      },
    },
    {
      role: 'user',
      content: 'Food, architecture, and walking.',
      providerOptions: {
        deepseek: {
          name: 'customer',
        } satisfies DeepSeekMessageProviderOptions,
      },
    },
  ],
});
```

相同的消息选项也适用于 `streamText`：

```ts
import {
  deepSeek,
  type DeepSeekMessageProviderOptions,
} from '@ai-sdk/deepseek';
import { streamText } from 'ai';

const result = streamText({
  model: deepSeek('deepseek-chat'),
  messages: [
    {
      role: 'user',
      content: 'Suggest a name for my neighborhood book club.',
      providerOptions: {
        deepseek: {
          name: 'organizer',
        } satisfies DeepSeekMessageProviderOptions,
      },
    },
  ],
});

for await (const textPart of result.textStream) {
  process.stdout.write(textPart);
}
```

未设置该选项时会省略名称。`name` 值必须是
字符串。DeepSeek 不支持在 tool 消息上使用名称，因此提供商会
忽略该位置并返回不支持功能警告。请避免
在消息名称中包含不必要的个人或身份识别信息。

### 推理

DeepSeek V4 模型支持推理。推理通过流式传输暴露：

```ts
import { deepSeek } from '@ai-sdk/deepseek';
import { streamText } from 'ai';

const result = streamText({
  model: deepSeek('deepseek-v4-pro'),
  prompt: 'How many "r"s are in the word "strawberry"?',
});

for await (const part of result.stream) {
  if (part.type === 'reasoning') {
    // This is the reasoning text
    console.log('Reasoning:', part.text);
  } else if (part.type === 'text') {
    // This is the final answer
    console.log('Answer:', part.text);
  }
}
```

有关如何将推理集成到聊天机器人中的更多详细信息，请参见
[AI SDK UI: Chatbot](/docs/ai-sdk-ui/chatbot#reasoning)。

### 聊天前缀补全

DeepSeek 的 beta [聊天前缀补全](https://api-docs.deepseek.com/guides/chat_prefix_completion/)
会继续补全最后一条 assistant 消息的内容。使用
beta base URL 创建提供商，并在该 assistant 消息的提供商
选项中设置 `prefix: true`：

```ts highlight="8,20-26"
import {
  createDeepSeek,
  type DeepSeekAssistantMessageProviderOptions,
} from '@ai-sdk/deepseek';
import { generateText } from 'ai';

const deepSeek = createDeepSeek({
  baseURL: 'https://api.deepseek.com/beta',
});

const { text } = await generateText({
  model: deepSeek('deepseek-v4-flash'),
  messages: [
    {
      role: 'user',
      content: 'Write a short sentence about the color of the sky.',
    },
    {
      role: 'assistant',
      content: 'The sky is',
      providerOptions: {
        deepseek: {
          prefix: true,
        } satisfies DeepSeekAssistantMessageProviderOptions,
      },
    },
  ],
});
```

带前缀的消息必须是 assistant 消息，并且是
提示词中的最后一条消息。配置的 `baseURL` 必须以 `/beta` 结尾，包括使用
代理时也是如此。无效的位置或非 beta base URL 会导致请求在发送前
失败。

<Note>
  聊天前缀补全是 DeepSeek 的 beta 功能，其行为可能会发生变化。
</Note>

### 严格工具调用

DeepSeek 的严格工具调用模式是 beta 功能。使用
beta base URL 创建提供商，并在请求中的每个 function tool 上设置 `strict: true`：

```ts highlight="5,14"
import { createDeepSeek } from '@ai-sdk/deepseek';
import { generateText, tool } from 'ai';
import { z } from 'zod';

const deepSeek = createDeepSeek({
  baseURL: 'https://api.deepseek.com/beta',
});

const result = await generateText({
  model: deepSeek('deepseek-chat'),
  prompt: 'What is the weather in San Francisco?',
  tools: {
    weather: tool({
      description: 'Get the weather for a location.',
      inputSchema: z.object({ location: z.string() }),
      strict: true,
      execute: async ({ location }) => ({ location, temperature: 18 }),
    }),
  },
});
```

当 base URL 不以 `/beta` 结尾时，严格工具会在本地失败。当任何
function tool 为严格模式时，同一请求中的每个 function tool 都必须设置
`strict: true`。

### 提供商元数据

DeepSeek 通过 `providerMetadata` 属性暴露响应系统指纹和上下文缓存使用情况：

```ts
import { deepSeek } from '@ai-sdk/deepseek';
import { generateText } from 'ai';

const result = await generateText({
  model: deepSeek('deepseek-v4-flash'),
  prompt: 'Your prompt here',
});

console.log(result.providerMetadata);
// Example output:
// {
//   deepseek: {
//     systemFingerprint: 'fp_eaab8d114b_prod0820_fp8_kvcache',
//     promptCacheHitTokens: 1856,
//     promptCacheMissTokens: 5,
//   },
// }
```

元数据包括：

- `systemFingerprint`：响应的后端配置指纹
- `promptCacheHitTokens`：已缓存的输入 token 数量
- `promptCacheMissTokens`：未缓存的输入 token 数量

对于流式响应，会返回响应块中最新的非空指纹。

<Note>
  有关 DeepSeek 缓存系统的更多详细信息，请参见 [DeepSeek 缓存
  文档](https://api-docs.deepseek.com/guides/kv_cache#checking-cache-hit-status)。
</Note>

### 聊天响应元数据

DeepSeek 会在 `providerMetadata.deepseek` 中为生成和流式响应保留
提供商特定的响应字段：

- `responseObject`：`chat.completion` 或 `chat.completion.chunk`
- `choiceIndex`：所选的响应选项索引
- `messageRole`：响应消息角色（如果提供）
- `toolCallTypes`：每个返回调用的工具调用类型

这些字段保留在提供商元数据中，因为它们特定于
DeepSeek 的 Chat Completions 响应，而不是共享的 AI SDK 结果字段。

### 文件上传

对于内联图像或图像 URL，使用 file-part 提供商选项来选择
图像处理细节。DeepSeek 支持 `low`、`high`、`original` 和
`auto`：

```ts highlight="2,13-17"
import {
  deepSeek,
  type DeepSeekFilePartProviderOptions,
} from '@ai-sdk/deepseek';
import { generateText } from 'ai';

const { text } = await generateText({
  model: deepSeek('deepseek-v4-flash-vision-exp'),
  messages: [
    {
      role: 'user',
      content: [
        { type: 'text', text: 'Describe this image.' },
        {
          type: 'file',
          data: new URL('https://example.com/image.webp'),
          mediaType: 'image/webp',
          providerOptions: {
            deepseek: {
              imageDetail: 'low',
            } satisfies DeepSeekFilePartProviderOptions,
          },
        },
      ],
    },
  ],
});
```

在内联图像 file part 上设置 `fileData: true` 以使用 DeepSeek 的
`file_data` content-part 表示形式。这会保留 file part 的
`filename`。`fileData` 不能与图像 URL 或 `imageDetail` 一起使用。

DeepSeek 接受 JPEG、PNG、GIF 和 WebP 图像输入。HTTP 图像 URL 最多
可为 8,192 个字符。

你可以使用 [DeepSeek Files API](https://api-docs.deepseek.com/guides/files_api) 上传图像，并将返回的提供商引用传递给 `deepseek-v4-flash-vision-exp`。这样可以避免在每次请求中再次发送图像字节。

```ts
import { deepSeek, type DeepSeekFilesOptions } from '@ai-sdk/deepseek';
import { generateText, uploadFile } from 'ai';
import { readFile } from 'node:fs/promises';

const { providerReference, mediaType } = await uploadFile({
  api: deepSeek.files(),
  data: await readFile('./image.png'),
  filename: 'image.png',
  providerOptions: {
    deepseek: {
      expiresAfter: 3600,
    } satisfies DeepSeekFilesOptions,
  },
});

const { text } = await generateText({
  model: deepSeek('deepseek-v4-flash-vision-exp'),
  messages: [
    {
      role: 'user',
      content: [
        { type: 'text', text: 'Describe this image.' },
        {
          type: 'file',
          mediaType: mediaType ?? 'image/png',
          data: providerReference,
        },
      ],
    },
  ],
});
```

可选的 `expiresAfter` 设置指定生命周期（以秒为单位）。DeepSeek 接受从 3,600 秒（一小时）到 2,592,000 秒（30 天）的值。未指定过期时间时，文件为永久文件。

提供商要求成功上传响应中包含有效的文件 ID。它还会
验证返回的 `object` 和 `purpose` 判别字段以及数值元数据。
其他响应元数据保持可选，以兼容不完整的
响应；省略的值不会包含在 `providerMetadata` 中，省略的响应文件名会回退到提供给 `uploadFile` 的文件名。

DeepSeek 文件上传支持 JPEG（`.jpg` 和 `.jpeg`）、PNG、GIF 和 WebP
图像。每个文件最大可为 64 MiB，文件名最多可包含 512
个字符。AI SDK 会在发送上传请求之前验证这些约束。`image/jpg` 媒体类型别名会被接受，当媒体类型为通用类型时（例如
`application/octet-stream`），会使用受支持的文件名扩展名作为回退。即使声明的媒体类型或文件名表明是受支持的图像格式，可识别的非图像内容也会被拒绝。

## 模型能力

| 模型                           | 文本生成 | 对象生成 | 图像输入 | 工具使用 | 工具流式传输 |
| ------------------------------ | --------------- | ----------------- | ----------- | ---------- | -------------- |
| `deepseek-flash`               | <Check />       | <Check />         | <Cross />   | <Check />  | <Check />      |
| `deepseek-v4-flash`            | <Check />       | <Check />         | <Cross />   | <Check />  | <Check />      |
| `deepseek-v4-pro`              | <Check />       | <Check />         | <Cross />   | <Check />  | <Check />      |
| `deepseek-v4-flash-vision-exp` | <Check />       | <Check />         | <Check />   | <Check />  | <Check />      |

<Note>
  请参见 [DeepSeek
  文档](https://api-docs.deepseek.com/quick_start/pricing) 获取
  可用模型的完整列表。如有需要，你也可以将任何可用的提供商模型 ID 作为
  字符串传入。
</Note>
