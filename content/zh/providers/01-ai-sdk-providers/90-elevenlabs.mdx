# ElevenLabs 提供商

[ElevenLabs](https://elevenlabs.io/) 提供商包含对 ElevenLabs 转录和语音生成 API 的语言模型支持。

## 设置

ElevenLabs 提供商可在 `@ai-sdk/elevenlabs` 模块中使用。您可以通过以下命令安装：

<InstallPackages packages="@ai-sdk/elevenlabs" />

## 提供商实例

您可以从 `@ai-sdk/elevenlabs` 导入默认提供商实例 `elevenLabs`：

```ts
import { elevenLabs } from '@ai-sdk/elevenlabs';
```

如果您需要自定义设置，可以从 `@ai-sdk/elevenlabs` 导入 `createElevenLabs` 并使用您的设置创建提供商实例：

```ts
import { createElevenLabs } from '@ai-sdk/elevenlabs';

const elevenLabs = createElevenLabs({
  // 自定义设置，例如
  fetch: customFetch,
});
```

您可以使用以下可选设置来自定义 ElevenLabs 提供商实例：

- **apiKey** _string_

  通过 `xi-api-key` 请求头发送的 API 密钥。
  默认使用 `ELEVENLABS_API_KEY` 环境变量。

- **headers** _Record&lt;string,string&gt;_

  要包含在请求中的自定义请求头。

- **fetch** _(input: RequestInfo, init?: RequestInit) => Promise&lt;Response&gt;_

  自定义 [fetch](https://developer.mozilla.org/en-US/docs/Web/API/fetch) 实现。
  默认为全局 `fetch` 函数。
  您可以将其用作中间件来拦截请求，
  或提供自定义 fetch 实现，例如用于测试。

- **webSocket** _WebSocketConstructor_

  用于实时转录的自定义 WebSocket 实现。在原生 WebSocket
  构造函数无法发送 `xi-api-key` 身份验证请求头的运行时中，
  需要支持请求头的实现。

## 语音模型

您可以使用 `.speech()` 工厂方法创建调用 [ElevenLabs 语音 API](https://elevenlabs.io/text-to-speech) 的模型。

第一个参数是模型 ID，例如 `eleven_multilingual_v2`。

```ts
const model = elevenLabs.speech('eleven_multilingual_v2');
```

`voice` 参数可以设置为 [ElevenLabs 语音库](https://elevenlabs.io/app/voice-library) 中的语音 ID。
您可以通过在语音库中选择一个语音并复制其 ID 来找到语音 ID。

```ts highlight="6"
import { generateSpeech } from 'ai';
import { elevenLabs } from '@ai-sdk/elevenlabs';

const result = await generateSpeech({
  model: elevenLabs.speech('eleven_multilingual_v2'),
  text: 'Hello, world!',
  voice: '21m00Tcm4TlvDq8ikWAM', // Rachel 语音
});
```

您还可以使用 `providerOptions` 参数传递其他提供商特定选项：

```ts highlight="7-9"
import { generateSpeech } from 'ai';
import {
  elevenLabs,
  type ElevenLabsSpeechModelOptions,
} from '@ai-sdk/elevenlabs';

const result = await generateSpeech({
  model: elevenLabs.speech('eleven_multilingual_v2'),
  text: 'Hello, world!',
  voice: '21m00Tcm4TlvDq8ikWAM',
  providerOptions: {
    elevenlabs: {
      voiceSettings: {
        stability: 0.5,
        similarityBoost: 0.75,
      },
    } satisfies ElevenLabsSpeechModelOptions,
  },
});
```

- **languageCode** _string 或 null_  
  可选。用于强制模型使用某种语言的语言代码（ISO 639-1）。目前，只有 Turbo v2.5 和 Flash v2.5 支持语言强制。对于其他模型，提供语言代码将导致错误。

- **voiceSettings** _object 或 null_  
  可选。覆盖给定语音的已存储设置的语音设置。这些设置仅应用于当前请求。
  - **stability** _double 或 null_  
    可选。决定语音的稳定性以及每次生成之间的随机性。较低的值会引入更广泛的情感范围；较高的值会导致更单调的语音。
  - **useSpeakerBoost** _boolean 或 null_  
    可选。增强与原始说话者的相似度。会增加计算负载和延迟。
  - **similarityBoost** _double 或 null_  
    可选。控制 AI 应遵循原始语音的紧密程度。
  - **style** _double 或 null_  
    可选。放大原始说话者的风格。如果设置为高于 0，可能会增加延迟。

- **pronunciationDictionaryLocators** _object 数组 或 null_  
  可选。要按顺序应用于文本的发音词典定位器列表。每个请求最多 3 个定位器。  
  每个定位器对象：
  - **pronunciationDictionaryId** _string_（必填）  
    发音词典的 ID。
  - **versionId** _string 或 null_（可选）  
    词典的版本 ID。如果未提供，则使用最新版本。

- **seed** _integer 或 null_  
  可选。如果指定，系统将尝试确定性采样。必须在 0 到 4294967295 之间。不保证确定性。

- **previousText** _string 或 null_  
  可选。当前请求文本之前的文本。可以在拼接生成结果时提高连续性，或影响当前生成的连续性。

- **nextText** _string 或 null_  
  可选。当前请求文本之后的文本。可以在拼接生成结果时提高连续性，或影响当前生成的连续性。

- **previousRequestIds** _string 数组 或 null_  
  可选。在此样本之前生成的样本的请求 ID 列表。在拆分大型任务时提高连续性。最多 3 个 ID。如果同时发送 `previousText` 和 `previousRequestIds`，则忽略 `previousText`。

- **nextRequestIds** _string 数组 或 null_  
  可选。在此样本之后生成的样本的请求 ID 列表。在重新生成样本时有助于保持连续性。最多 3 个 ID。如果同时发送 `nextText` 和 `nextRequestIds`，则忽略 `nextText`。

- **applyTextNormalization** _enum_  
  可选。控制文本规范化。  
  允许的值：`'auto'`（默认）、`'on'`、`'off'`。
  - `'auto'`：系统决定是否应用规范化（例如，拼出数字）。
  - `'on'`：始终应用规范化。
  - `'off'`：从不应用规范化。  
    对于 `eleven_turbo_v2_5` 和 `eleven_flash_v2_5`，只能通过企业版计划启用。

- **applyLanguageTextNormalization** _boolean_  
  可选。默认为 `false`。控制语言文本规范化，有助于在某些支持的语言（目前仅限日语）中实现正确发音。可能会显著增加延迟。

- **enableLogging** _boolean_  
  可选。是否为此 API 调用启用请求日志记录。默认为账户级设置。

## 转录模型

您可以使用 `.transcription()` 工厂方法创建调用 [ElevenLabs 转录 API](https://elevenlabs.io/speech-to-text) 的模型。

第一个参数是模型 ID，例如 `scribe_v2`。

```ts
const model = elevenLabs.transcription('scribe_v2');
```

您还可以使用 `providerOptions` 参数传递其他提供商特定选项。例如，如果事先知道输入语言，以 ISO-639-1（例如 `en`）格式提供有时可以提高转录性能。

```ts highlight="10-14"
import { transcribe } from 'ai';
import {
  elevenLabs,
  type ElevenLabsTranscriptionModelOptions,
} from '@ai-sdk/elevenlabs';

const result = await transcribe({
  model: elevenLabs.transcription('scribe_v2'),
  audio: new Uint8Array([1, 2, 3, 4]),
  providerOptions: {
    elevenlabs: {
      languageCode: 'en',
    } satisfies ElevenLabsTranscriptionModelOptions,
  },
});
```

以下提供商选项可用：

- **languageCode** _string_

  与音频文件语言对应的 ISO-639-1 或 ISO-639-3 语言代码。
  如果事先知道，有时可以提高转录性能。
  默认为 `null`，此时会自动预测语言。

- **tagAudioEvents** _boolean_

  是否在转录中标记音频事件，如（笑声）、（脚步声）等。
  默认为 `true`。

- **numSpeakers** _integer_

  上传文件中说话者的最大数量。
  有助于预测谁在何时说话。
  可预测的最大说话者数量为 32。
  默认为 `null`，此时说话者数量设置为模型支持的最大值。

- **timestampsGranularity** _enum_

  转录中时间戳的粒度。
  默认为 `'word'`。
  允许的值：`'none'`、`'word'`、`'character'`。

- **diarize** _boolean_

  是否标注上传文件中当前正在说话的说话者。
  默认为 `true`。

- **fileFormat** _enum_

  输入音频的格式。
  默认为 `'other'`。
  允许的值：`'pcm_s16le_16'`、`'other'`。
  对于 `'pcm_s16le_16'`，输入音频必须是 16 位 PCM、16kHz 采样率、单声道（单声道）且为小端字节序。
  延迟将低于传递编码波形。

## 流式转录模型

<Note type="warning">流式转录是一项实验性功能。</Note>

Scribe v2 Realtime 支持通过 `experimental_streamTranscribe` 进行实时转录。它接受 8、16、22.05、24、44.1 或 48 kHz 的原始 PCM 音频，或 8 kHz mu-law 音频。

```ts
import {
  createElevenLabs,
  type ElevenLabsProviderSettings,
} from '@ai-sdk/elevenlabs';
import { experimental_streamTranscribe as streamTranscribe } from 'ai';
import { WebSocket } from 'ws';

const elevenLabs = createElevenLabs({
  webSocket: WebSocket as unknown as ElevenLabsProviderSettings['webSocket'],
});

const result = streamTranscribe({
  model: elevenLabs.transcription('scribe_v2_realtime'),
  audio,
  inputAudioFormat: { type: 'audio/pcm', rate: 16000 },
  providerOptions: {
    elevenlabs: {
      languageCode: 'en',
      streaming: {
        includeLanguageDetection: true,
        includeTimestamps: true,
      },
    },
  },
});

for await (const part of result.fullStream) {
  if (part.type === 'transcript-partial') {
    console.log('partial:', part.text);
  }

  if (part.type === 'transcript-final') {
    console.log('final:', part.text);
  }
}
```

ElevenLabs 实时端点使用 WebSocket 请求头进行身份验证。在原生 WebSocket 构造函数无法发送请求头的运行时中，请使用支持请求头的 WebSocket 实现，例如 `ws`。

`streaming` 提供商选项镜像了 ElevenLabs 的实时转录设置：`commitStrategy`、`enableLogging`、`filterBackgroundAudio`、`includeLanguageDetection`、`includeTimestamps`、`keyterms`、`minSilenceDurationMs`、`minSpeechDurationMs`、`noVerbatim`、`previousText`、`secondaryLanguages`、`vadSilenceThresholdSecs` 和 `vadThreshold`。

ElevenLabs 在其带有时间戳的提交事件中传递检测到的语言。当启用 `includeLanguageDetection` 时，提供商会在内部请求该事件，但仅在同时启用 `includeTimestamps` 时才返回时间戳分段。`filterBackgroundAudio` 不能与任一选项组合使用。

有关流式转录的更多信息，请参阅 [转录](/docs/ai-sdk-core/transcription)。
