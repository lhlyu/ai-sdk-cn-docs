# Prodia 提供商

[Prodia](https://prodia.com/) 是一个面向生成式 AI 的快速推理平台，提供基于 FLUX 和 Stable Diffusion 模型的高速图像生成能力。
你可以通过 [AI Gateway](/providers/ai-sdk-providers/ai-gateway)（推荐）使用 Prodia 模型，或使用 `@ai-sdk/prodia` 直接连接。

```ts provider="prodia" model="prodia/flux-fast-schnell"
import { generateImage } from 'ai';
__PROVIDER_IMPORT__;

const { image } = await generateImage({
  model: __IMAGE_MODEL__,
  prompt: 'A sunlit mountain village in watercolor.',
});

console.log(image.base64);
```

## 使用 AI Gateway

AI SDK 默认对模型字符串使用 AI Gateway。Gateway 通过单个 API 密钥提供对跨提供商模型的访问，并支持用量和成本跟踪。安装 `ai`：

<InstallPackages packages="ai" />

在环境中设置 [AI Gateway API 密钥](https://vercel.com/docs/ai-gateway/getting-started)：

```bash
export AI_GATEWAY_API_KEY=your_api_key_here
```

Vercel 部署还可以使用 [OIDC 身份验证](/providers/ai-sdk-providers/ai-gateway#oidc-authentication-vercel-deployments)。
有关配置信息，请参阅 [AI Gateway 提供商文档](/providers/ai-sdk-providers/ai-gateway)；有关可用模型，请参阅[模型目录](https://vercel.com/ai-gateway/models)。

Gateway 的功能和提供商选项支持取决于模型以及处理请求的提供商。请参阅 [Gateway 提供商选项](https://vercel.com/docs/ai-gateway/models-and-providers/provider-options)。

## 使用 `@ai-sdk/prodia`

如需直接访问 Prodia，请安装 `ai` 和 `@ai-sdk/prodia`：

<InstallPackages packages="ai @ai-sdk/prodia" />

在 `PRODIA_TOKEN` 环境变量中设置你的 Prodia API 凭据：

```bash
export PRODIA_TOKEN=your_api_key_here
```

AI Gateway 并未暴露 `@ai-sdk/prodia` 中的每一个 API。如需使用提供商特定的 API 或自定义连接设置，请使用直接提供商。

<Note>
  以下各节介绍直接使用 `@ai-sdk/prodia` 提供商的内容，
  包括其模型工厂和设置。Gateway 的模型和功能
  可用性可能有所不同。
</Note>

## 提供商实例

你可以从 `@ai-sdk/prodia` 导入默认提供商实例 `prodia`：

```ts
import { prodia } from '@ai-sdk/prodia';
```

如果你需要自定义设置，可以导入 `createProdia` 并使用你的设置创建提供商实例：

```ts
import { createProdia } from '@ai-sdk/prodia';

const prodia = createProdia({
  apiKey: 'your-api-key', // optional, defaults to PRODIA_TOKEN environment variable
  baseURL: 'custom-url', // optional
  headers: {
    /* custom headers */
  }, // optional
});
```

你可以使用以下可选设置来自定义 Prodia 提供商实例：

- **baseURL** _string_

  为 API 调用使用不同的 URL 前缀。
  默认前缀为 `https://inference.prodia.com/v2`。

- **apiKey** _string_

  通过 `Authorization` 请求头以 Bearer 令牌形式发送的 API 密钥。
  默认使用 `PRODIA_TOKEN` 环境变量。

- **headers** _Record&lt;string,string&gt;_

  要包含在请求中的自定义请求头。

- **fetch** _(input: RequestInfo, init?: RequestInit) => Promise&lt;Response&gt;_

  自定义 [fetch](https://developer.mozilla.org/en-US/docs/Web/API/fetch) 实现。
  你可以将其用作中间件来拦截请求，
  或为例如测试提供自定义 fetch 实现。

## 图像模型

你可以使用 `.image()` 工厂方法创建 Prodia 图像模型。
有关使用 AI SDK 进行图像生成的更多信息，请参阅 [generateImage()](/docs/reference/ai-sdk-core/generate-image)。

### 基本用法

```ts
import { writeFileSync } from 'node:fs';
import { prodia } from '@ai-sdk/prodia';
import { generateImage } from 'ai';

const { image } = await generateImage({
  model: prodia.image('inference.flux-fast.schnell.txt2img.v2'),
  prompt: 'A cat wearing an intricate robe',
});

const filename = `image-${Date.now()}.png`;
writeFileSync(filename, image.uint8Array);
console.log(`Image saved to ${filename}`);
```

### 模型能力

Prodia 为各种图像生成模型提供快速推理。以下是支持的模型类型：

| 模型                                     | 描述                                                 |
| ---------------------------------------- | ---------------------------------------------------- |
| `inference.flux-fast.schnell.txt2img.v2` | 用于文本到图像生成的快速 FLUX Schnell 模型           |
| `inference.flux.schnell.txt2img.v2`      | 用于文本到图像生成的 FLUX Schnell 模型               |

<Note>
  Prodia 支持更多模型 ID。请查看 [Prodia
  文档](https://docs.prodia.com/) 获取可用模型的完整列表。
</Note>

### 图像尺寸

你可以使用 `size` 参数以 `WIDTHxHEIGHT` 格式指定图像尺寸：

```ts
import { prodia } from '@ai-sdk/prodia';
import { generateImage } from 'ai';

const { image } = await generateImage({
  model: prodia.image('inference.flux-fast.schnell.txt2img.v2'),
  prompt: 'A serene mountain landscape at sunset',
  size: '1024x768',
});
```

### 提供商选项

Prodia 图像模型通过 `providerOptions.prodia` 对象支持额外选项：

```ts
import { prodia, type ProdiaImageModelOptions } from '@ai-sdk/prodia';
import { generateImage } from 'ai';

const { image } = await generateImage({
  model: prodia.image('inference.flux-fast.schnell.txt2img.v2'),
  prompt: 'A cat wearing an intricate robe',
  providerOptions: {
    prodia: {
      width: 1024,
      height: 768,
      steps: 4,
      stylePreset: 'cinematic',
    } satisfies ProdiaImageModelOptions,
  },
});
```

支持以下提供商选项：

- **width** _number_ - 输出宽度（像素，256–1920）。设置后，将覆盖从 `size` 派生的任何宽度。
- **height** _number_ - 输出高度（像素，256–1920）。设置后，将覆盖从 `size` 派生的任何高度。
- **steps** _number_ - 计算迭代次数（1–4）。更多步骤通常会产生更高质量的结果。
- **stylePreset** _string_ - 为输出图像应用视觉主题。支持的预设：`3d-model`、`analog-film`、`anime`、`cinematic`、`comic-book`、`digital-art`、`enhance`、`fantasy-art`、`isometric`、`line-art`、`low-poly`、`neon-punk`、`origami`、`photographic`、`pixel-art`、`texture`、`craft-clay`。
- **loras** _string[]_ - 使用最多 3 个 LoRA 模型增强输出。
- **progressive** _boolean_ - 使用 JPEG 输出时，返回渐进式 JPEG。

### 种子

你可以使用 `seed` 参数获得可复现的结果：

```ts
import { prodia } from '@ai-sdk/prodia';
import { generateImage } from 'ai';

const { image } = await generateImage({
  model: prodia.image('inference.flux-fast.schnell.txt2img.v2'),
  prompt: 'A serene mountain landscape at sunset',
  seed: 12345,
});
```

### 提供商元数据

`generateImage` 响应在 `providerMetadata.prodia.images[]` 中包含提供商特定的元数据。每个图像对象可能包含以下属性：

- **jobId** _string_ - 生成任务的唯一标识符。
- **seed** _number_ - 用于生成的种子。可用于复现结果。
- **elapsed** _number_ - 生成时间（秒）。
- **iterationsPerSecond** _number_ - 处理速度指标。
- **createdAt** _string_ - 任务创建时的时间戳。
- **updatedAt** _string_ - 任务最后更新时的时间戳。

```ts
import { prodia } from '@ai-sdk/prodia';
import { generateImage } from 'ai';

const { image, providerMetadata } = await generateImage({
  model: prodia.image('inference.flux-fast.schnell.txt2img.v2'),
  prompt: 'A serene mountain landscape at sunset',
});

// Access provider metadata
const metadata = providerMetadata?.prodia?.images?.[0];
console.log('Job ID:', metadata?.jobId);
console.log('Seed:', metadata?.seed);
console.log('Elapsed:', metadata?.elapsed);
```
