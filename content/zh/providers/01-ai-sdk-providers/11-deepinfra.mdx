# DeepInfra 提供商

[DeepInfra](https://deepinfra.com) 提供商通过 DeepInfra API 支持最先进的模型，包括 Llama 3、Mixtral、Qwen 以及许多其他流行的开源模型。
对于其目录中的模型，建议从 [AI Gateway](/providers/ai-sdk-providers/ai-gateway) 开始（推荐），或使用 `@ai-sdk/deepinfra` 直接连接到 DeepInfra。

```ts provider="deepinfra" model="meta/llama-4-scout"
import { generateText } from 'ai';
__PROVIDER_IMPORT__;

const { text } = await generateText({
  model: __MODEL__,
  prompt: 'Write a vegetarian lasagna recipe for 4 people.',
  __GATEWAY_OPTIONS__,
});

console.log(text);
```

## 使用 AI Gateway

AI SDK 默认对模型字符串使用 AI Gateway。Gateway 通过单个 API 密钥提供跨提供商的模型访问，并支持用量和成本跟踪。安装 `ai`：

<InstallPackages packages="ai" />

在环境中设置 [AI Gateway API 密钥](https://vercel.com/docs/ai-gateway/getting-started)：

```bash
export AI_GATEWAY_API_KEY=your_api_key_here
```

Vercel 部署还可以使用 [OIDC 身份验证](/providers/ai-sdk-providers/ai-gateway#oidc-authentication-vercel-deployments)。
有关配置信息，请参阅 [AI Gateway 提供商文档](/providers/ai-sdk-providers/ai-gateway)；有关可用模型，请参阅[模型目录](https://vercel.com/ai-gateway/models)。

该示例将 `providerOptions.gateway.order` 设置为 `['deepinfra']`。这会将请求首先发送到 DeepInfra，如果 DeepInfra 不可用或请求失败，则回退到同一模型的其他可用提供商。`order` 设置的是偏好，并不会将回退限制为仅 DeepInfra。请参阅[提供商排序](https://vercel.com/docs/ai-gateway/models-and-providers/provider-filtering-and-ordering)。

下拉列表列出了通过 Gateway 由 DeepInfra 提供服务的模型，并附有相应的直接提供商示例。提供商可用性取决于模型以及你团队的[提供商允许列表](https://vercel.com/docs/ai-gateway/models-and-providers/provider-filtering-and-ordering)。

## 使用 `@ai-sdk/deepinfra`

如需直接访问 DeepInfra，请安装 `ai` 和 `@ai-sdk/deepinfra`：

<InstallPackages packages="ai @ai-sdk/deepinfra" />

在 `DEEPINFRA_API_KEY` 环境变量中设置你的 DeepInfra API 凭据：

```bash
export DEEPINFRA_API_KEY=your_api_key_here
```

AI Gateway 并未公开 `@ai-sdk/deepinfra` 中的每一个 API。如需使用提供商特定的 API 或自定义连接设置，请使用直接提供商。

<Note>
  以下各节记录了直接 `@ai-sdk/deepinfra` 提供商，包括其模型工厂和设置。Gateway 的模型和功能可用性可能有所不同。
</Note>

## 提供商实例

你可以从 `@ai-sdk/deepinfra` 导入默认提供商实例 `deepInfra`：

```ts
import { deepInfra } from '@ai-sdk/deepinfra';
```

如果你需要自定义设置，可以从 `@ai-sdk/deepinfra` 导入 `createDeepInfra`，并使用你的设置创建提供商实例：

```ts
import { createDeepInfra } from '@ai-sdk/deepinfra';

const deepInfra = createDeepInfra({
  apiKey: process.env.DEEPINFRA_API_KEY ?? '',
});
```

你可以使用以下可选设置来自定义 DeepInfra 提供商实例：

- **baseURL** _string_

  为 API 调用使用不同的 URL 前缀，例如使用代理服务器。
  默认前缀为 `https://api.deepinfra.com/v1`。

  注意：语言模型和嵌入使用位于 `{baseURL}/openai` 的 OpenAI 兼容端点，
  而图像模型使用 `{baseURL}/inference`。

- **apiKey** _string_

  通过 `Authorization` 标头发送的 API 密钥。默认使用
  `DEEPINFRA_API_KEY` 环境变量。

- **headers** _Record&lt;string,string&gt;_

  要包含在请求中的自定义标头。

- **fetch** _(input: RequestInfo, init?: RequestInit) => Promise&lt;Response&gt;_

  自定义 [fetch](https://developer.mozilla.org/en-US/docs/Web/API/fetch) 实现。
  默认为全局 `fetch` 函数。
  你可以将其用作中间件来拦截请求，
  或提供自定义 fetch 实现，例如用于测试。

## 语言模型

你可以使用提供商实例创建语言模型。第一个参数是模型 ID，例如：

```ts
import { deepInfra } from '@ai-sdk/deepinfra';
import { generateText } from 'ai';

const { text } = await generateText({
  model: deepInfra('meta-llama/Meta-Llama-3.1-70B-Instruct'),
  prompt: 'Write a vegetarian lasagna recipe for 4 people.',
});
```

DeepInfra 语言模型也可以在 `streamText` 函数中使用（参见 [AI SDK Core](/docs/ai-sdk-core)）。

## 图像模型

你可以使用 `.image()` 工厂方法创建 DeepInfra 图像模型。
有关使用 AI SDK 进行图像生成的更多信息，请参阅 [generateImage()](/docs/reference/ai-sdk-core/generate-image)。

```ts
import { deepInfra, type DeepInfraImageModelOptions } from '@ai-sdk/deepinfra';
import { generateImage } from 'ai';

const { image } = await generateImage({
  model: deepInfra.image('stabilityai/sd3.5'),
  prompt: 'A futuristic cityscape at sunset',
  aspectRatio: '16:9',
});
```

<Note>
  模型对 `size` 和 `aspectRatio` 参数的支持因模型而异。请查看 [DeepInfra 模型页面](https://deepinfra.com/models/text-to-image)上的各个模型文档，了解支持的选项和其他参数。
</Note>

### 模型特定选项

你可以使用 `providerOptions.deepinfra` 字段传递模型特定参数：

```ts
import { deepInfra } from '@ai-sdk/deepinfra';
import { generateImage } from 'ai';

const { image } = await generateImage({
  model: deepInfra.image('stabilityai/sd3.5'),
  prompt: 'A futuristic cityscape at sunset',
  aspectRatio: '16:9',
  providerOptions: {
    deepinfra: {
      num_inference_steps: 30,
    } satisfies DeepInfraImageModelOptions,
  },
});
```

以下选项可通过 `providerOptions.deepinfra` 使用。你可以使用 `DeepInfraImageModelOptions` 为其提供类型。

- **negative_prompt** _string_

  对生成图像中应避免内容的文本描述。

- **num_inference_steps** _number_

  对于公开此选项的模型，指定去噪步数。

- **guidance_scale** _number_

  对于公开此选项的模型，指定引导比例。

- **guidance** _number_

  对于公开此选项的图像编辑模型，指定引导值。

- **response_format** _'b64_json'_

  OpenAI 兼容图像响应的格式。DeepInfra 目前支持 `b64_json`。

- **quality** _string_

  OpenAI 兼容的图像质量选项。

- **style** _string_

  OpenAI 兼容的图像风格选项。

- **user** _string_

  最终用户的唯一标识符。

<Note>
  DeepInfra 图像生成模型公开模型特定参数。其他字段可以通过 `providerOptions.deepinfra` 传递，并由 DeepInfra 进行验证。
</Note>

### 图像编辑

DeepInfra 通过 `Qwen/Qwen-Image-Edit` 等模型支持图像编辑。通过 `prompt.images` 传入输入图像以转换或编辑现有图像。

#### 基本图像编辑

使用文本提示词转换现有图像：

```ts
const imageBuffer = readFileSync('./input-image.png');

const { images } = await generateImage({
  model: deepInfra.image('Qwen/Qwen-Image-Edit'),
  prompt: {
    text: 'Turn the cat into a golden retriever dog',
    images: [imageBuffer],
  },
  size: '1024x1024',
});
```

#### 使用蒙版进行修复

使用蒙版编辑图像的特定部分。蒙版中的透明区域表示应编辑图像的位置：

```ts
const image = readFileSync('./input-image.png');
const mask = readFileSync('./mask.png');

const { images } = await generateImage({
  model: deepInfra.image('Qwen/Qwen-Image-Edit'),
  prompt: {
    text: 'A sunlit indoor lounge area with a pool containing a flamingo',
    images: [image],
    mask: mask,
  },
});
```

#### 多图像组合

将多张参考图像组合为单个输出：

```ts
const cat = readFileSync('./cat.png');
const dog = readFileSync('./dog.png');

const { images } = await generateImage({
  model: deepInfra.image('Qwen/Qwen-Image-Edit'),
  prompt: {
    text: 'Create a scene with both animals together, playing as friends',
    images: [cat, dog],
  },
});
```

<Note>
  输入图像可以提供为 `Buffer`、`ArrayBuffer`、`Uint8Array` 或 base64 编码字符串。DeepInfra 在 `https://api.deepinfra.com/v1/openai/images/edits` 使用 OpenAI 兼容的图像编辑 API。
</Note>

### 模型能力

对于支持宽高比的模型，通常支持以下比例：
`1:1 (默认), 16:9, 1:9, 3:2, 2:3, 4:5, 5:4, 9:16, 9:21`

对于支持尺寸参数的模型，尺寸通常必须满足：

- 32 的倍数
- 宽度和高度在 256 到 1440 像素之间
- 默认尺寸为 1024x1024

## 嵌入模型

你可以使用 `.embeddingModel()` 工厂方法创建 DeepInfra 嵌入模型。
有关使用 AI SDK 的嵌入模型的更多信息，请参阅 [embed()](/docs/reference/ai-sdk-core/embed)。

```ts
import { deepInfra } from '@ai-sdk/deepinfra';
import { embed } from 'ai';

const { embedding } = await embed({
  model: deepInfra.embeddingModel('BAAI/bge-large-en-v1.5'),
  value: 'sunny day at the beach',
});
```
