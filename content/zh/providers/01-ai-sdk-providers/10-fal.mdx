# Fal 提供商

[Fal AI](https://fal.ai/) 为开发者提供生成式媒体平台，具备极快的推理能力。其平台针对扩散模型运行进行了性能优化，速度最高可达其他方案的 4 倍。
对于下方展示的共享模型，可使用 [AI Gateway](/providers/ai-sdk-providers/ai-gateway)（由 Gateway 支持的提供商提供服务），或使用 `@ai-sdk/fal` 将请求直接发送至 Fal。Gateway 目前不会将请求路由到 Fal。

```ts provider="fal" model="bfl/flux-pro-1.1"
import { generateImage } from 'ai';
__PROVIDER_IMPORT__;

const { image } = await generateImage({
  model: __IMAGE_MODEL__,
  prompt: 'A sunlit mountain village in watercolor.',
});

console.log(image.base64);
```

## 使用 AI Gateway

AI SDK 默认对模型字符串使用 AI Gateway。Gateway 通过单个 API 密钥提供跨提供商的模型访问，并支持用量与成本跟踪。安装 `ai`：

<InstallPackages packages="ai" />

在环境中设置 [AI Gateway API 密钥](https://vercel.com/docs/ai-gateway/getting-started)：

```bash
export AI_GATEWAY_API_KEY=your_api_key_here
```

Vercel 部署还可以使用 [OIDC 身份验证](/providers/ai-sdk-providers/ai-gateway#oidc-authentication-vercel-deployments)。
有关配置信息，请参阅 [AI Gateway 提供商文档](/providers/ai-sdk-providers/ai-gateway)；有关可用模型，请参阅[模型目录](https://vercel.com/ai-gateway/models)。

当前的 [Gateway 提供商列表](https://vercel.com/docs/ai-gateway/models-and-providers/provider-options#available-providers)不包含 Fal 作为推理提供商。Gateway 标签页会调用 Fal 也提供的模型，但 Gateway 会通过其支持的推理提供商路由这些请求，而不会将请求发送至 Fal。请使用直接标签页调用 Fal；不要将 `providerOptions.gateway.order` 设置为不受支持的提供商 slug。

## 使用 `@ai-sdk/fal`

如需直接访问 Fal，请安装 `ai` 和 `@ai-sdk/fal`：

<InstallPackages packages="ai @ai-sdk/fal" />

在 `FAL_API_KEY` 环境变量中设置你的 Fal API 凭据：

```bash
export FAL_API_KEY=your_api_key_here
```

使用 `@ai-sdk/fal` 通过你的 Fal 账户进行身份验证，并直接调用其平台 API。上文的 Gateway 替代方案则使用受支持的推理提供商。

<Note>
  以下章节介绍直接使用 `@ai-sdk/fal` 提供商，包括其模型工厂和设置。Gateway 的模型与功能可用性可能有所不同。
</Note>

## 提供商实例

你可以从 `@ai-sdk/fal` 导入默认提供商实例 `fal`：

```ts
import { fal } from '@ai-sdk/fal';
```

如果需要自定义设置，可以导入 `createFal` 并使用你的设置创建提供商实例：

```ts
import { createFal } from '@ai-sdk/fal';

const fal = createFal({
  apiKey: 'your-api-key', // optional, defaults to FAL_API_KEY environment variable, falling back to FAL_KEY
  baseURL: 'custom-url', // optional
  headers: {
    /* custom headers */
  }, // optional
});
```

你可以使用以下可选设置来自定义 Fal 提供商实例：

- **baseURL** _string_

  为 API 调用使用不同的 URL 前缀，例如使用代理服务器。
  默认前缀为 `https://fal.run`。

- **apiKey** _string_

  通过 `Authorization` 标头发送的 API 密钥。
  默认使用 `FAL_API_KEY` 环境变量，回退到 `FAL_KEY`。

- **headers** _Record&lt;string,string&gt;_

  请求中包含的自定义标头。

- **fetch** _(input: RequestInfo, init?: RequestInit) => Promise&lt;Response&gt;_

  自定义 [fetch](https://developer.mozilla.org/en-US/docs/Web/API/fetch) 实现。
  你可以将其用作中间件来拦截请求，
  或为例如测试提供自定义 fetch 实现。

## 图像模型

你可以使用 `.image()` 工厂方法创建 Fal 图像模型。
有关使用 AI SDK 进行图像生成的更多信息，请参阅 [generateImage()](/docs/reference/ai-sdk-core/generate-image)。

### 基本用法

```ts
import { fal } from '@ai-sdk/fal';
import { generateImage } from 'ai';
import fs from 'fs';

const { image, providerMetadata } = await generateImage({
  model: fal.image('fal-ai/flux/dev'),
  prompt: 'A serene mountain landscape at sunset',
});

const filename = `image-${Date.now()}.png`;
fs.writeFileSync(filename, image.uint8Array);
console.log(`Image saved to ${filename}`);
```

Fal 图像模型可能会返回有关图像和请求的额外信息。

以下是为每张图像可能设置的一些属性示例

```js
providerMetadata.fal.images[0].nsfw; // boolean, image is not safe for work
providerMetadata.fal.images[0].width; // number, image width
providerMetadata.fal.images[0].height; // number, image height
providerMetadata.fal.images[0].contentType; // string, mime type of the image
```

#### 修改图像

使用文本提示词转换现有图像。

```ts
await generateImage({
  model: fal.image('fal-ai/flux-pro/kontext/max'),
  prompt: {
    text: 'Put a donut next to the flour.',
    images: [
      'https://v3.fal.media/files/rabbit/rmgBxhwGYb2d3pl3x9sKf_output.png',
    ],
  },
});
```

图像也可以作为 base64 编码字符串、`Uint8Array`、`ArrayBuffer` 或 `Buffer` 传入。
还可以传入蒙版

```ts
await generateImage({
  model: fal.image('fal-ai/flux-general/inpainting'),
  prompt: {
    text: 'Put a donut next to the flour.',
    images: [imageBuffer],
    mask: maskBuffer,
  },
});
```

### 提供商选项

Fal 图像模型通过 `providerOptions.fal` 对象支持灵活的提供商选项。你可以传入特定 Fal 模型 API 支持的任何参数。常见选项包括：

- **imageUrl** - 用于图生图的参考图像 URL（已弃用，请改用 `prompt.images`）
- **strength** - 控制输出与输入图像的差异程度
- **guidanceScale** - 控制对提示词的遵循程度（范围：1-20）
- **numInferenceSteps** - 去噪步数（范围：1-50）
- **enableSafetyChecker** - 启用/禁用安全过滤
- **outputFormat** - 输出格式：'jpeg' 或 'png'
- **syncMode** - 在返回响应前等待完成
- **acceleration** - 生成速度：'none'、'regular' 或 'high'
- **safetyTolerance** - 内容安全过滤级别（1-6，其中 1 最严格）
- **useMultipleImages** - 为 true 时，将多个输入图像转换为 `image_urls` 数组，适用于支持多图像的模型（例如 fal-ai/flux-2/edit）

<Note type="warning">
  **弃用通知**：snake_case 参数名（例如 `image_url`、
  `guidance_scale`）已弃用，并将在未来版本中移除。
  请改用 camelCase 名称（例如 `imageUrl`、`guidanceScale`）。
</Note>

有关模型特定参数，请参阅 [Fal AI 模型文档](https://fal.ai/models)。

## 转录模型

你可以使用 `.transcription()` 工厂方法创建调用 [Fal 转录 API](https://docs.fal.ai/guides/convert-speech-to-text)的模型。

第一个参数是模型 ID，不带 `fal-ai/` 前缀，例如 `wizper`。

```ts
const model = fal.transcription('wizper');
```

你还可以使用 `providerOptions` 参数传入额外的提供商特定选项。例如，提供 `batchSize` 选项将增加并行处理的音频块数量。

```ts highlight="6"
import { transcribe } from 'ai';
import { fal, type FalTranscriptionModelOptions } from '@ai-sdk/fal';
import { readFile } from 'fs/promises';

const result = await transcribe({
  model: fal.transcription('wizper'),
  audio: await readFile('audio.mp3'),
  providerOptions: {
    fal: { batchSize: 10 } satisfies FalTranscriptionModelOptions,
  },
});
```

以下提供商选项可用：

- **language** _string | null_
  音频文件的语言。默认为 'en'。如果设置为 null，将自动检测语言。
  接受 ISO 语言代码，如 'en'、'fr'、'zh' 等。
  可选。

- **diarize** _boolean_
  是否对音频文件进行说话人分离（识别不同说话人）。
  默认为 true。
  可选。

- **chunkLevel** _string_
  返回的块级别。可以是 'segment' 或 'word'。
  默认值："segment"
  可选。

- **version** _string_
  要使用的模型版本。所有模型都是 Whisper 大型变体。
  默认值："3"
  可选。

- **batchSize** _number_
  处理批大小。
  默认值：64
  可选。

- **numSpeakers** _number_
  音频文件中的说话人数量。如果未提供，将自动检测说话人数量。
  可选。

## 语音模型

你可以使用 `.speech()` 工厂方法创建调用 Fal 文本转语音端点的模型。

### 基本用法

```ts
import { generateSpeech } from 'ai';
import { fal } from '@ai-sdk/fal';

const result = await generateSpeech({
  model: fal.speech('fal-ai/minimax/speech-02-hd'),
  text: 'Hello from the AI SDK!',
});
```

### 模型能力

| 模型                                     | 描述                                                                                                                                                           |
| ----------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `fal-ai/minimax/voice-clone`              | 从示例音频克隆声音，并根据文本提示词生成语音                                                                                               |
| `fal-ai/minimax/voice-design`             | 根据文本描述设计个性化声音，并根据文本提示词生成语音                                                                             |
| `fal-ai/dia-tts/voice-clone`              | 从示例音频克隆对话声音，并根据文本提示词生成对话                                                                                        |
| `fal-ai/minimax/speech-02-hd`             | 根据文本提示词和不同声音生成语音                                                                                                                |
| `fal-ai/minimax/speech-02-turbo`          | 根据文本提示词和不同声音快速生成语音                                                                                                           |
| `fal-ai/dia-tts`                          | 直接从转录文本生成逼真的对话，并通过音频条件控制情绪。产生笑声和清嗓子等自然非语言声音     |
| `resemble-ai/chatterboxhd/text-to-speech` | 使用 Resemble AI 的 Chatterbox 生成富有表现力的自然语音。具有独特的情绪控制、从短音频即时克隆声音以及内置水印功能 |

### 提供商选项

根据模型不同，通过 `providerOptions.fal` 传入提供商特定选项：

- **voice_setting** _object_
  - `voice_id`（string）：预定义声音 ID
  - `speed`（number）：0.5–2.0
  - `vol`（number）：0–10
  - `pitch`（number）：-12–12
  - `emotion`（enum）：happy | sad | angry | fearful | disgusted | surprised | neutral
  - `english_normalization`（boolean）

- **audio_setting** _object_
  特定于模型的音频配置设置。

- **language_boost** _enum_
  Chinese | Chinese,Yue | English | Arabic | Russian | Spanish | French | Portuguese | German | Turkish | Dutch | Ukrainian | Vietnamese | Indonesian | Japanese | Italian | Korean | Thai | Polish | Romanian | Greek | Czech | Finnish | Hindi | auto

- **pronunciation_dict** _object_
  特定单词的自定义发音词典。

模型特定参数（例如 `audio_url`、`prompt`、`preview_text`、`ref_audio_url`、`ref_text`）可以直接在 `providerOptions.fal` 下传入，并将转发到 Fal API。
