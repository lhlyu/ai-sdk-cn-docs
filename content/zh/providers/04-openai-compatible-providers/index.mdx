# OpenAI 兼容提供商

你可以使用 [OpenAI 兼容提供商](https://www.npmjs.com/package/@ai-sdk/openai-compatible) 包来使用实现了 OpenAI API 的语言模型提供商。

下面我们重点介绍通用设置和提供商实例的创建。你也可以[基于 OpenAI 兼容包编写自定义提供商包](/providers/openai-compatible-providers/custom-providers)。

我们为以下 OpenAI 兼容提供商提供了详细文档：

- [LM Studio](/providers/openai-compatible-providers/lmstudio)
- [NIM](/providers/openai-compatible-providers/nim)
- [Heroku](/providers/openai-compatible-providers/heroku)
- [Clarifai](/providers/openai-compatible-providers/clarifai)
- [NEAR AI Cloud](/providers/openai-compatible-providers/nearai)

所有这些提供商的通用设置和提供商实例创建方式都是相同的。

## 设置

OpenAI 兼容提供商可通过 `@ai-sdk/openai-compatible` 模块获取。你可以使用以下命令安装：

<InstallPackages packages="@ai-sdk/openai-compatible" />

## 提供商实例

要使用 OpenAI 兼容提供商，你可以使用 `@ai-sdk/openai-compatible` 中的 `createOpenAICompatible` 函数创建一个自定义提供商实例：

```ts
import { createOpenAICompatible } from '@ai-sdk/openai-compatible';

const provider = createOpenAICompatible({
  name: 'providerName',
  apiKey: process.env.PROVIDER_API_KEY,
  baseURL: 'https://api.provider.com/v1',
  includeUsage: true, // Include usage information in streaming responses
});
```

你可以使用以下可选设置来自定义提供商实例：

- **baseURL** _string_

  设置 API 调用的 URL 前缀。

- **apiKey** _string_

  用于验证请求的 API 密钥。如果指定，会在请求头中添加一个 `Authorization`
  头，其值为 `Bearer <apiKey>`。这将在 `headers` 选项中可能指定的任何头之前添加。

- **headers** _Record&lt;string,string&gt;_

  可选的、要包含在请求中的自定义请求头。这些头将在使用 `apiKey` 选项可能添加的任何头之后添加到请求头中。

- **queryParams** _Record&lt;string,string&gt;_

  可选的、要包含在请求 URL 中的自定义 URL 查询参数。

- **fetch** _(input: RequestInfo, init?: RequestInit) => Promise&lt;Response&gt;_

  自定义 [fetch](https://developer.mozilla.org/en-US/docs/Web/API/fetch) 实现。
  默认为全局 `fetch` 函数。
  你可以将其用作中间件来拦截请求，
  或为例如测试提供自定义 fetch 实现。

- **includeUsage** _boolean_

  在流式传输响应中包含使用信息。启用后，使用数据将包含在流式传输请求的响应元数据中。默认为 `undefined`（`false`）。

- **supportsStructuredOutputs** _boolean_

  如果提供商支持结构化输出，则设置为 true。仅与 `provider()`、`provider.chatModel()` 和 `provider.languageModel()` 相关。

- **supportedUrls** _() =&gt; Record&lt;string, RegExp[]&gt;_

  定义聊天模型可以直接访问的 URL，按媒体类型分组。
  匹配的 URL 会传递给提供商，而不是由
  AI SDK 下载。

- **transformRequestBody** _(args: Record&lt;string, any&gt;) =&gt; Record&lt;string, any&gt;_

  可选函数，用于在将请求体发送到 API 之前对其进行转换。
  这对于可能需要与官方 OpenAI API 不同请求格式的代理提供商非常有用。

- **metadataExtractor** _MetadataExtractor_

  可选的元数据提取器，用于从 API 响应中捕获提供商特定的元数据。
  详情请参阅[自定义元数据提取](#custom-metadata-extraction)。

## 语言模型

你可以使用提供商实例创建提供商模型。
第一个参数是模型 ID，例如 `model-id`。

```ts
const model = provider('model-id');
```

你也可以使用以下工厂方法：

- `provider.languageModel('model-id')` - 创建一个聊天语言模型（与 `provider('model-id')` 相同）
- `provider.chatModel('model-id')` - 创建一个聊天语言模型

### 支持的能力

使用此提供商创建的聊天模型支持以下能力：

- **文本生成** - 生成文本补全
- **流式传输** - 实时流式传输文本响应
- **工具调用** - 调用工具/函数并支持流式传输
- **结构化输出** - 生成带 schema 验证的 JSON（当启用 `supportsStructuredOutputs` 时）
- **推理内容** - 支持返回推理/思考 token 的模型（例如 DeepSeek R1）
- **系统消息** - 支持系统提示词
- **多模态输入** - 支持图像和其他内容类型（取决于提供商）

### 示例

你可以使用提供商语言模型通过 `generateText` 函数生成文本：

```ts
import { createOpenAICompatible } from '@ai-sdk/openai-compatible';
import { generateText } from 'ai';

const provider = createOpenAICompatible({
  name: 'providerName',
  apiKey: process.env.PROVIDER_API_KEY,
  baseURL: 'https://api.provider.com/v1',
});

const { text } = await generateText({
  model: provider('model-id'),
  prompt: 'Write a vegetarian lasagna recipe for 4 people.',
});
```

### 视频输入

接受非标准 `video_url` 内容部分的 OpenAI 兼容提供商
可以接收视频文件部分。内联字节和 base64 编码数据会作为
数据 URL 发送：

```ts
import { createOpenAICompatible } from '@ai-sdk/openai-compatible';
import { generateText } from 'ai';
import fs from 'node:fs';

const provider = createOpenAICompatible({
  name: 'providerName',
  apiKey: process.env.PROVIDER_API_KEY,
  baseURL: 'https://api.provider.com/v1',
});

const { text } = await generateText({
  model: provider('video-capable-model'),
  messages: [
    {
      role: 'user',
      content: [
        { type: 'text', text: 'Describe the main action in this video.' },
        {
          type: 'file',
          mediaType: 'video/mp4',
          data: fs.readFileSync('./video.mp4'),
        },
      ],
    },
  ],
});
```

要直接传递托管的视频 URL 而不先下载它，请为提供商配置
`supportedUrls`：

```ts
const provider = createOpenAICompatible({
  name: 'providerName',
  apiKey: process.env.PROVIDER_API_KEY,
  baseURL: 'https://api.provider.com/v1',
  supportedUrls: () => ({
    'video/*': [/^https:\/\/cdn\.example\.com\//],
  }),
});

const { text } = await generateText({
  model: provider('video-capable-model'),
  messages: [
    {
      role: 'user',
      content: [
        { type: 'text', text: 'Summarize this video.' },
        {
          type: 'file',
          mediaType: 'video/mp4',
          data: new URL('https://cdn.example.com/video.mp4'),
        },
      ],
    },
  ],
});
```

`video_url` 是 OpenAI 兼容提供商的扩展，而不是官方 OpenAI
Chat Completions 内容类型。视频支持、接受的格式、大小和
时长限制，以及对公共 URL 或数据 URL 的支持取决于提供商和
模型。在支持的情况下，优先使用托管 URL，以避免在
请求体中嵌入大型视频。

### 包含模型 ID 以实现自动补全

```ts
import { createOpenAICompatible } from '@ai-sdk/openai-compatible';
import { generateText } from 'ai';

type ExampleChatModelIds =
  | 'meta-llama/Llama-3-70b-chat-hf'
  | 'meta-llama/Meta-Llama-3.1-8B-Instruct-Turbo'
  | (string & {});

type ExampleCompletionModelIds =
  | 'codellama/CodeLlama-34b-Instruct-hf'
  | 'Qwen/Qwen2.5-Coder-32B-Instruct'
  | (string & {});

type ExampleEmbeddingModelIds =
  | 'BAAI/bge-large-en-v1.5'
  | 'bert-base-uncased'
  | (string & {});

type ExampleImageModelIds = 'dall-e-3' | 'stable-diffusion-xl' | (string & {});

const model = createOpenAICompatible<
  ExampleChatModelIds,
  ExampleCompletionModelIds,
  ExampleEmbeddingModelIds,
  ExampleImageModelIds
>({
  name: 'example',
  apiKey: process.env.PROVIDER_API_KEY,
  baseURL: 'https://api.example.com/v1',
});

// Subsequent calls to e.g. `model.chatModel` will auto-complete the model id
// from the list of `ExampleChatModelIds` while still allowing free-form
// strings as well.

const { text } = await generateText({
  model: model.chatModel('meta-llama/Llama-3-70b-chat-hf'),
  prompt: 'Write a vegetarian lasagna recipe for 4 people.',
});
```

### 自定义查询参数

某些提供商可能需要自定义查询参数。一个例子是 [Azure AI
Model Inference
API](https://learn.microsoft.com/en-us/azure/machine-learning/reference-model-inference-chat-completions?view=azureml-api-2)，
它需要一个 `api-version` 查询参数。

你可以通过可选的 `queryParams` 提供商设置来设置这些参数。它们将被
添加到提供商发出的所有请求中。

```ts highlight="7-9"
import { createOpenAICompatible } from '@ai-sdk/openai-compatible';

const provider = createOpenAICompatible({
  name: 'providerName',
  apiKey: process.env.PROVIDER_API_KEY,
  baseURL: 'https://api.provider.com/v1',
  queryParams: {
    'api-version': '1.0.0',
  },
});
```

例如，使用上述配置，API 请求将在 URL 中包含查询参数，如下所示：
`https://api.provider.com/v1/chat/completions?api-version=1.0.0`。

## 图像模型

你可以使用 `.imageModel()` 工厂方法创建图像模型：

```ts
const model = provider.imageModel('model-id');
```

### 基本图像生成

```ts
import {
  createOpenAICompatible,
  type OpenAICompatibleImageModelOptions,
} from '@ai-sdk/openai-compatible';
import { generateImage } from 'ai';

const provider = createOpenAICompatible({
  name: 'providerName',
  apiKey: process.env.PROVIDER_API_KEY,
  baseURL: 'https://api.provider.com/v1',
});

const { images } = await generateImage({
  model: provider.imageModel('model-id'),
  prompt: 'A futuristic cityscape at sunset',
  size: '1024x1024',
  providerOptions: {
    providerName: {
      quality: 'high',
      output_format: 'jpeg',
      output_compression: 80,
      background: 'opaque',
    } satisfies OpenAICompatibleImageModelOptions,
  },
});
```

### 图像模型选项

图像模型可以使用以下通用提供商选项：

- **size** _string_

  生成图像的尺寸。使用顶层 `size` 选项来指定
  标准尺寸，或使用此提供商选项来指定提供商特定的值，
  例如 `auto`。

- **quality** _string_

  生成图像的质量。支持的值取决于提供商和
  模型。

- **output_format** _string_

  生成图像的文件格式。

- **output_compression** _number_

  对于 JPEG 和 WebP 等格式，压缩级别从 `0` 到 `100`。

- **background** _string_

  生成图像的背景行为。支持的值取决于
  提供商和模型。

提供商和模型可能支持将 `auto` 用于 `size`、`quality` 或 `background`。

`OpenAICompatibleImageModelOptions` 还接受额外的提供商特定
选项。这些选项会原样传递给提供商 API。

### 图像编辑

OpenAI 兼容提供商通过 `/images/edits` 端点支持图像编辑。通过 `prompt.images` 传入输入图像，以转换或编辑现有图像。

#### 基本图像编辑

```ts
import { createOpenAICompatible } from '@ai-sdk/openai-compatible';
import { generateImage } from 'ai';
import fs from 'fs';

const provider = createOpenAICompatible({
  name: 'providerName',
  apiKey: process.env.PROVIDER_API_KEY,
  baseURL: 'https://api.provider.com/v1',
});

const imageBuffer = fs.readFileSync('./input-image.png');

const { images } = await generateImage({
  model: provider.imageModel('model-id'),
  prompt: {
    text: 'Turn the cat into a dog but retain the style of the original image',
    images: [imageBuffer],
  },
});
```

#### 使用蒙版进行修复

使用蒙版编辑图像的特定部分：

```ts
import { createOpenAICompatible } from '@ai-sdk/openai-compatible';
import { generateImage } from 'ai';
import fs from 'fs';

const provider = createOpenAICompatible({
  name: 'providerName',
  apiKey: process.env.PROVIDER_API_KEY,
  baseURL: 'https://api.provider.com/v1',
});

const image = fs.readFileSync('./input-image.png');
const mask = fs.readFileSync('./mask.png');

const { images } = await generateImage({
  model: provider.imageModel('model-id'),
  prompt: {
    text: 'A sunlit indoor lounge area with a pool containing a flamingo',
    images: [image],
    mask,
  },
});
```

<Note>
  输入图像可以提供为 `Buffer`、`ArrayBuffer`、`Uint8Array`、
  base64 编码字符串或 URL。提供商将自动下载
  基于 URL 的图像并将其转换为适当的格式。
</Note>

## 嵌入模型

你可以使用 `.embeddingModel()` 工厂方法创建嵌入模型：

```ts
const model = provider.embeddingModel('model-id');
```

### 示例

```ts
import { createOpenAICompatible } from '@ai-sdk/openai-compatible';
import { embed } from 'ai';

const provider = createOpenAICompatible({
  name: 'providerName',
  apiKey: process.env.PROVIDER_API_KEY,
  baseURL: 'https://api.provider.com/v1',
});

const { embedding } = await embed({
  model: provider.embeddingModel('text-embedding-model'),
  value: 'The quick brown fox jumps over the lazy dog',
});
```

### 嵌入模型选项

嵌入模型可以通过 `providerOptions` 使用以下提供商选项：

- **dimensions** _number_

  生成的输出嵌入应具有的维度数。
  仅在允许配置维度的模型中受支持。

- **user** _string_

  表示你的最终用户的唯一标识符，可以帮助提供商
  监控和检测滥用行为。

```ts
const { embedding } = await embed({
  model: provider.embeddingModel('text-embedding-model'),
  value: 'The quick brown fox jumps over the lazy dog',
  providerOptions: {
    providerName: {
      dimensions: 512,
      user: 'user-123',
    },
  },
});
```

## 补全模型

你可以使用 `.completionModel()` 工厂方法创建补全模型（用于文本补全，而非聊天）：

```ts
const model = provider.completionModel('model-id');
```

### 示例

```ts
import { createOpenAICompatible } from '@ai-sdk/openai-compatible';
import { generateText } from 'ai';

const provider = createOpenAICompatible({
  name: 'providerName',
  apiKey: process.env.PROVIDER_API_KEY,
  baseURL: 'https://api.provider.com/v1',
});

const { text } = await generateText({
  model: provider.completionModel('completion-model-id'),
  prompt: 'The quick brown fox',
});
```

### 补全模型选项

补全模型可以通过 `providerOptions` 使用以下提供商选项：

- **echo** _boolean_

  在补全内容之外，同时回显提示词。

- **logitBias** _Record&lt;string, number&gt;_

  修改指定 token 出现在补全内容中的可能性。
  接受一个 JSON 对象，将 token（由其 token ID 指定）映射到
  从 -100 到 100 的关联偏置值。

- **suffix** _string_

  插入文本补全之后的后缀。

- **user** _string_

  表示你的最终用户的唯一标识符，可以帮助提供商
  监控和检测滥用行为。

```ts
const { text } = await generateText({
  model: provider.completionModel('completion-model-id'),
  prompt: 'The quick brown fox',
  providerOptions: {
    providerName: {
      echo: true,
      suffix: ' The end.',
      user: 'user-123',
    },
  },
});
```

## 聊天模型选项

聊天模型可以通过 `providerOptions` 使用以下提供商选项：

- **user** _string_

  表示你的最终用户的唯一标识符，可以帮助提供商
  监控和检测滥用行为。

- **reasoningEffort** _string_

  推理模型的推理强度。具体值取决于提供商。

- **textVerbosity** _string_

  控制生成文本的详细程度。具体值取决于提供商。

- **strictJsonSchema** _boolean_

  是否使用严格的 JSON schema 验证。当为 true 时，模型使用约束
  解码来保证 schema 合规性。仅在提供商支持
  结构化输出且提供了 schema 时使用。默认为 `true`。

```ts
const { text } = await generateText({
  model: provider('model-id'),
  prompt: 'Solve this step by step: What is 15 * 23?',
  providerOptions: {
    providerName: {
      user: 'user-123',
      reasoningEffort: 'high',
    },
  },
});
```

## 提供商特定选项

OpenAI 兼容提供商支持向请求体添加提供商特定选项。这些选项通过请求体中的 `providerOptions` 字段指定。

例如，如果你创建了一个名称为 `providerName` 的提供商实例，你可以像这样向请求体添加 `customOption` 字段：

```ts
const provider = createOpenAICompatible({
  name: 'providerName',
  apiKey: process.env.PROVIDER_API_KEY,
  baseURL: 'https://api.provider.com/v1',
});

const { text } = await generateText({
  model: provider('model-id'),
  prompt: 'Hello',
  providerOptions: {
    providerName: { customOption: 'magic-value' },
  },
});
```

请注意，`providerOptions` 键将采用 camelCase。如果你将提供商名称设置为 `provider-name`，选项仍然需要在 `providerOptions.providerName` 上设置。

发送给提供商的请求体将包含值为 `magic-value` 的 `customOption` 字段。这为你提供了一种简单的方法，无需修改提供商或 AI SDK 代码即可向请求添加提供商特定选项。

## 自定义元数据提取

OpenAI 兼容提供商支持通过元数据提取器从 API 响应中提取提供商特定的元数据。
这些提取器允许你捕获提供商返回的、超出标准响应格式的额外信息。

元数据提取器接收来自提供商的原始、未处理的响应数据，让你拥有完全的灵活性
来提取提供商可能包含的任何自定义字段或实验性功能。
这在以下情况下特别有用：

- 处理包含非标准响应字段的提供商
- 试验 beta 或预览功能
- 捕获提供商特定的指标或调试信息
- 在不更改 SDK 的情况下支持提供商 API 的快速演进

元数据提取器适用于流式传输和非流式传输聊天补全，由两个主要组件组成：

1. 一个从完整响应中提取元数据的函数
2. 一个流式提取器，可以在流式传输响应中跨块累积元数据

以下是一个元数据提取器示例，它同时捕获标准和自定义提供商数据：

```typescript
import { MetadataExtractor } from '@ai-sdk/openai-compatible';

const myMetadataExtractor: MetadataExtractor = {
  // Process complete, non-streaming responses
  extractMetadata: ({ parsedBody }) => {
    // You have access to the complete raw response
    // Extract any fields the provider includes
    return {
      myProvider: {
        standardUsage: parsedBody.usage,
        experimentalFeatures: parsedBody.beta_features,
        customMetrics: {
          processingTime: parsedBody.server_timing?.total_ms,
          modelVersion: parsedBody.model_version,
          // ... any other provider-specific data
        },
      },
    };
  },

  // Process streaming responses
  createStreamExtractor: () => {
    let accumulatedData = {
      timing: [],
      customFields: {},
    };

    return {
      // Process each chunk's raw data
      processChunk: parsedChunk => {
        if (parsedChunk.server_timing) {
          accumulatedData.timing.push(parsedChunk.server_timing);
        }
        if (parsedChunk.custom_data) {
          Object.assign(accumulatedData.customFields, parsedChunk.custom_data);
        }
      },
      // Build final metadata from accumulated data
      buildMetadata: () => ({
        myProvider: {
          streamTiming: accumulatedData.timing,
          customData: accumulatedData.customFields,
        },
      }),
    };
  },
};
```

你可以在创建提供商实例时提供元数据提取器：

```typescript
const provider = createOpenAICompatible({
  name: 'my-provider',
  apiKey: process.env.PROVIDER_API_KEY,
  baseURL: 'https://api.provider.com/v1',
  metadataExtractor: myMetadataExtractor,
});
```

提取的元数据将包含在响应的 `providerMetadata` 字段下：

```typescript
const { text, providerMetadata } = await generateText({
  model: provider('model-id'),
  prompt: 'Hello',
});

console.log(providerMetadata.myProvider.customMetric);
```

这使你能够访问提供商特定的信息，同时在不同提供商之间保持一致接口。
